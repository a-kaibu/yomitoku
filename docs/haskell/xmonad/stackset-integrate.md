## ひとことで

`integrate` は、`Stack` という「フォーカスの位置を持つ並び」を、普通のリストに戻す関数です。フォーカスされたウィンドウを真ん中に置き、左側と右側の並びを並べ直します。

xmonad は、画面上のウィンドウの並びを、この `Stack` で管理しています。画面に表示する順番を取り出すときに、この関数が使われます。

## コード

```haskell:line-numbers=315
integrate :: Stack a -> [a]
integrate (Stack x l r) = reverse l ++ x : r
```

## 前提知識

- **`Stack a`**: フォーカス位置を持つ並びの型です。`Stack x l r` は「現在の要素 `x`」「左側の要素のリスト `l`（近い順）」「右側の要素のリスト `r`」の 3 つを持ちます。
- **ジッパー（zipper）**: リストの途中の位置を、左右に分けて持つデータ構造です。位置の移動が、とても速く行えます。
- **`reverse`**: リストの順番を逆にする関数です。
- **`++`**: 2 つのリストをつなぐ演算子です。
- **`:`**: 先頭に 1 つの要素を付ける演算子です。

## 何をしているか

### 1. 左側を元の順番に戻す

```haskell:line-numbers=316
integrate (Stack x l r) = reverse l ++ x : r
```

`l` は、フォーカスから近い順に並んでいます。元の順番に戻すには、逆にする必要があります。そのため `reverse l` を使います。

### 2. 現在の要素と右側をつなぐ

`x : r` は、現在の要素 `x` を先頭に付けて、その後ろに右側の並び `r` をつなぎます。

### 3. 全部をつなぐ

`reverse l ++ x : r` は、「左側（元の順番）」「現在の要素」「右側」を、この順番で 1 本のリストにします。

具体例で見ます。`Stack 3 [2,1] [4,5]` は、`reverse [2,1]` の `[1,2]`、現在の `3`、右側の `[4,5]` をつないで、`[1,2,3,4,5]` になります。

## ここがすごい

フォーカスが移動しても、内部の表現は左右の 2 つのリストだけで済みます。フォーカスを 1 つ動かすには、リストの先頭を 1 つ付け替えるだけでよく、速く行えます。

一方、全体を見たいとき（画面に描くとき）に、必要なのは 1 本のリストだけです。`integrate` は、そのための変換を 1 か所にまとめています。「速い操作の表現」と「見せるための形」を分けた設計です。

この関数は、ジッパーと呼ばれるデータ構造の基本的な使い方です。ウィンドウを扱う他の関数の多くが、この考え方の上に作られています。

## まとめ

- フォーカスを持つ並びは、左右のリストに分けると移動が速い。
- 元の順番に戻すには、左側だけを `reverse` する。
- 内部の形と、外に見せる形を分けると、両方を簡単に保てる。
