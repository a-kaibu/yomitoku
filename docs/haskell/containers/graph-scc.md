## ひとことで

`scc` は、有向グラフを **強連結成分（SCC）** に分ける関数です。強連結成分とは、その中のどの頂点からどの頂点へも、辺をたどって行ける頂点のまとまりのことです。

たとえば、A から B へ行けて、B から A へも行けるなら、A と B は同じ成分に入ります。循環（ぐるぐる回れる部分）が、ここで見つかります。

## コード

```haskell:line-numbers=715
scc :: Graph -> [Tree Vertex]
scc g = dfs g (reversePostOrder' (dff (transposeG g)))
```

## 前提知識

- **強連結成分**: 互いに行き来できる頂点の最大のまとまりです。1 つの頂点だけの成分もあります。
- **`transposeG`**: 辺の向きを逆にしたグラフを作る関数です。前の記事で見ました。
- **`reversePostOrder'`**: 森の帰りがけ順を逆にする関数です。トポロジカルソートでも使われます。
- **`dfs`**: 出発点のリストから深さ優先探索を行い、森を返す関数です。

## 何をしているか

この関数は、右から左へ読むと流れがつかめます。まず `transposeG g` で、辺の向きを逆にします。次に、その逆向きのグラフで `dff` を行い、帰りがけ順の逆を取ります。最後に、その順番で元のグラフ `g` を `dfs` します。

### 1. 向きを逆にして、帰りがけ順を作る

```haskell:line-numbers=716
scc g = dfs g (reversePostOrder' (dff (transposeG g)))
```

`dff (transposeG g)` は、逆向きのグラフで全頂点から深さ優先探索をして、森を作ります。そこから `reversePostOrder'` で、頂点の並びを作ります。この並びは、元のグラフで「どこから探索を始めると、大きな塊を一度に抜けられるか」の手がかりになります。

### 2. その順番で元のグラフを探索する

`dfs g (...)` は、元のグラフ `g` を、先ほどの並びの順に深さ優先探索します。こうすると、一度たどり始めた塊からは、その成分の外へ出られないため、探索の木がそのまま 1 つの成分になります。

結果は、木の集まりです。それぞれの木が 1 つの強連結成分を表します。

## ここがすごい

この方法は、コサラジュのアルゴリズムと呼ばれる、2 回の深さ優先探索を使う手法です。1 回目で「終わった順」を記録し、2 回目で、その順番を逆向きのグラフに当てはめます。

1 回の探索で全部を解こうとすると、ややこしい状態管理が必要になります。この関数は、「逆向きにして、順番を取り、もう一度たどる」という単純な手順の組み合わせで、同じ結果を得ています。

また、関数の中身は、既に書いた部品（`transposeG`、`dff`、`reversePostOrder'`、`dfs`）をつないだだけです。部品を再利用すると、正しさを確かめやすいという利点もあります。

## まとめ

- 強連結成分は、互いに行き来できる頂点のまとまり。
- 逆向きのグラフで帰りがけ順を取り、その順番で元のグラフを探索すると分けられる。
- 小さな部品を組み合わせると、難しいアルゴリズムも短く書ける。
