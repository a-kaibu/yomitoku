## ひとことで

`buildG` は、頂点の範囲と辺の一覧から、グラフを作る関数です。グラフは「頂点ごとに、つながっている頂点のリストを持つ配列」として表します。この形を隣接リストといいます。

たとえば辺 `(0,1)` は「0 から 1 へ行ける」という意味です。`buildG` はその一覧を受け取り、0 番の頂点のリスト、1 番のリスト…を作ります。

## コード

```haskell:line-numbers=411
buildG :: Bounds -> [Edge] -> Graph
buildG = accumArray (flip (:)) []
```

## 前提知識

- **`Graph` の型**: `type Graph = Array Vertex [Vertex]` です。`Array` は添字で値を取り出せる配列で、添字が頂点、値が行き先のリストです。
- **`Bounds` と `Edge`**: `Bounds` は頂点の最小と最大の組、`Edge` は `(出発, 到着)` の組です。どちらも型の名前を付けただけの別名（type alias）です。
- **関数を渡す**: Haskell では、関数を引数に渡せます。`flip (:)` のように、関数を組み替えて渡すこともできます。
- **部分適用**: `buildG = accumArray (flip (:)) []` は、引数を書かずに関数を定義しています。引数を後から受け取る形になっています。

## 何をしているか

### 1. 配列の初期値は空リスト

```haskell:line-numbers=412
buildG = accumArray (flip (:)) []
```

`accumArray f initial bounds assocs` は、すべての頂点に `initial` を入れておき、辺のたびに値を `f` で足し込んでいく関数です。ここでは `initial` が `[]`（空のリスト）です。

### 2. 足し込みは「先頭へ付け足す」

`flip (:)` は、「リストを受け取り、その前に要素を付ける」関数です。通常の `(:)` は「要素, リスト」の順で受け取るので、`flip` で順番を入れ替えています。

具体的に見てみます。ドキュメントの例では、次のように書かれています。

```text
buildG (0,2) [(0,1), (0,2), (1,2)] == array (0,2) [(0,[2,1]),(1,[2]),(2,[])]
```

頂点 0 の行き先は、辺の順に `1`、次に `2` と追加されるので、先頭に付けていくと `[2,1]` になります。後から来た辺が前に出るので、リストは元の並びと逆順です。

### 3. 配列は 1 回の走査で完成する

`accumArray` は、辺の一覧を 1 回たどるだけで配列を作ります。頂点ごとに探し直す必要がなく、辺の数に比例した時間で済みます。

## ここがすごい

全体の処理は、ほとんど「配列を作って足し込む」だけです。ループや変数の更新を書かず、`accumArray` と `flip (:)` の組み合わせで、隣接リストを作る仕事が 1 行で言い切れています。

また、リストの先頭に付けるのは、後ろに付けるより速いという性質を利用しています。後ろへ付けると毎回リストを最後までたどる必要がありますが、先頭なら一瞬で済みます。その代わり、リストの順番は逆になります。

ドキュメントにある `== array ...` の例が、この逆順を明示しています。順番が意味を持つ場面では、この癖に注意が必要です。

## まとめ

- グラフは、頂点から行き先のリストを引ける配列（隣接リスト）で表せる。
- `accumArray` と `flip (:)` で、辺の一覧から隣接リストを 1 行で作れる。
- 先頭へ付け足すのは速いが、リストの順番は逆になる。
