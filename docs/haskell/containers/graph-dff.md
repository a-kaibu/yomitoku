## ひとことで

`dff` は、グラフのすべての頂点を出発点として、深さ優先探索（DFS）を行う関数です。グラフが一続きでつながっていなくても、どの頂点も必ず一度は訪問されます。

結果は「木の集まり（森）」です。最初の木は最初の頂点から、その次の木は、まだ訪問していない最初の頂点から、というように作られます。

## コード

```haskell:line-numbers=569
dff          :: Graph -> [Tree Vertex]
dff g         = dfs g (vertices g)
```

## 前提知識

- **`dfs`**: 前の記事で見た、出発点のリストを受け取って森を返す関数です。
- **`vertices g`**: グラフのすべての頂点を、番号順のリストとして返す関数です。
- **型 `Forest`**: 木のリスト（森）です。`[Tree Vertex]` と書かれているのは、木が複数あることを表します。

## 何をしているか

### 1. 出発点を全頂点にする

```haskell:line-numbers=570
dff g         = dfs g (vertices g)
```

`dff g = dfs g (vertices g)` の意味は、「出発点のリストとして、全部の頂点を渡す」です。`dfs` は、リストを先頭から順に見ていきます。

### 2. 訪問済みの頂点は飛ばされる

`dfs` の中で、すでに訪問した頂点は `contains` で見つかり、探索から外されます。そのため、前の木で訪問された頂点は、次の木の根にはなりません。

具体例で見ます。頂点 0 から 1 へ、頂点 2 が独立している 3 つの頂点のグラフを考えます。最初に 0 から探索すると、0 と 1 が 1 つの木に入ります。次に 2 は未訪問なので、2 だけの木が作られます。結果は 2 本の木です。

## ここがすごい

`dff` は、`dfs` を 1 行で呼ぶだけの関数です。それでも名前を分けて用意しているのは、「全頂点から探索する」という意味を、呼ぶ側に分かりやすく伝えるためです。

また、どの頂点から始めるかで木の形は変わりますが、全頂点を見るので、どの頂点も必ず結果に現れることが保証されます。この性質は、トポロジカルソートや強連結成分の計算で、とても大事になります。

この関数の役割は、グラフのすべての頂点を一度は必ず見るという保証です。`dfs` の結果は、どの頂点から始めるかで形が変わりますが、全頂点を含むことは変わりません。その性質が、連結成分の判定や、トポロジカルソートの前提になっています。

## まとめ

- 全頂点を出発点にすると、グラフのすべての頂点が探索の対象になる。
- 訪問済みの頂点は、探索の途中で飛ばされる。
- 1 行の関数でも、意味のある名前を付けると、使う側が読みやすくなる。
