## ひとことで

`utf8Length` は、1 文字が UTF-8 にすると何バイトになるかを返す関数です。ASCII の文字は 1 バイト、日本語の多くは 3 バイト、絵文字などは 4 バイトになります。

ふつうに書くと、「0x80 未満なら 1、0x800 未満なら 2…」と分岐を並べます。この関数は、その分岐を一つも使わずに答えを出します。

## コード

```haskell:line-numbers=81
utf8Length :: Char -> Int
utf8Length (C# c) = I# ((1# +# geChar# c (chr# 0x80#)) +# (geChar# c (chr# 0x800#) +# geChar# c (chr# 0x10000#)))
```

## 前提知識

- **`Char`**: Haskell の文字の型です。内部的には Unicode のコードポイントを表します。
- **UTF-8**: 1 文字を 1 〜 4 バイトで表す、文字コードの方式です。コードポイントの大きさで、バイト数が決まります。
- **`C#` と `I#`**: `Char` や `Int` の中身を取り出すための、値のラッパーです。`#` が付いた値は「ボックスなし」の値で、普通の値より速く計算されます。
- **`+#` と `geChar#`**: `#` の付いた演算子です。`geChar#` は「以上なら 1、そうでなければ 0」を返す演算で、真偽値を数に変換できます。

## 何をしているか

### 1. 文字の中身を取り出す

```haskell:line-numbers=82
utf8Length (C# c) = I# ((1# +# geChar# c (chr# 0x80#)) +# (geChar# c (chr# 0x800#) +# geChar# c (chr# 0x10000#)))
```

パターン `(C# c)` で、`Char` の中身（コードポイントを表す `c`）を取り出します。

### 2. 3 つの「以上か」の判定を足す

ここで使われている 3 つの比較は、次の意味です。

- `c >= 0x80` なら 1、そうでなければ 0（2 バイト以上か）
- `c >= 0x800` なら 1、そうでなければ 0（3 バイト以上か）
- `c >= 0x10000` なら 1、そうでなければ 0（4 バイト以上か）

これらを `1# +#` に加えると、結果は 1 から 4 のどれかになります。たとえば `'a'` は 3 つとも偽なので、`1` です。`'あ'`（U+3042）は、最初の 2 つが真なので、`3` になります。

## ここがすごい

ふつうの `if` や `case` は、CPU にとって「どちらに進むか」を予測しにくい分岐です。予測が外れると遅くなるので、文字列を大量に処理するとき、この差が効きます。

この関数は、分岐の代わりに比較の結果を数字として足すだけなので、CPU の処理が一直線に進みます。コメントにも、「分岐なしの版です」と明記されています。読みやすさより速さを選んだ、低レイヤのライブラリらしい書き方です。

## まとめ

- 文字のバイト数は、コードポイントの大きさを比べると分かる。
- 分岐をなくすと、予測が外れる遅さを避けられる。
- 真偽値を数字として足すと、条件の数を気にせず答えを作れる。
