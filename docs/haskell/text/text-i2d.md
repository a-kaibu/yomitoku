## ひとことで

`i2d` は、0 から 9 までの整数を、対応する数字の文字（`'0'` から `'9'`）に変える関数です。`show` を使わずに数字を文字に変えられるので、数を文字列にする処理の中で速く使えます。

## コード

```haskell:line-numbers=29
i2d :: Int -> Char
i2d (I# i#) = C# (chr# (ord# '0'# +# i#))
```

## 前提知識

- **文字コード**: 文字には、`'0'` は 48、`'1'` は 49 のように、順番に並んだ番号があります。
- **`Int` と `I#`**: `Int` は普通の整数です。`I#` は、その中身を生の整数として取り出すための書き方です。
- **`#` の付いた名前**: GHC の内部で使われる、生の値を扱う関数や型です。`MagicHash` という拡張を有効にして使います。
- **`chr#` と `ord#`**: 文字を生の番号に変えたり、番号を文字に戻したりする関数です。

## 何をしているか

### 1. 0 の文字コードを基準にする

```haskell:line-numbers=30
i2d (I# i#) = C# (chr# (ord# '0'# +# i#))
```

`ord# '0'#` は、`'0'` の文字コード（48）です。ここに、整数 `i#` を足すと、`i#` が 3 なら 51 になります。51 は `'3'` の文字コードです。

### 2. 生の値を文字に戻す

```haskell:line-numbers=30
i2d (I# i#) = C# (chr# (ord# '0'# +# i#))
```

`chr#` で生の番号を文字の値に戻し、`C#` で通常の `Char` の形にくるんで返します。

## ここがすごい

0 から 9 の数字は、文字コードが連続しているので、足し算 1 回で文字になります。表を引いたり、場合分けをしたりする必要がありません。

名前の通り「安全でない変換（unsafe）」です。0 から 9 以外の数を渡すと、数字ではない文字が返ります。その代わり、呼び出し側で範囲を確かめておけば、とても速く動きます。

## まとめ

- 文字コードが連続していることを使うと、数字の変換が足し算で済む。
- 生の値を扱う書き方は、速さのために使われることがある。
- 安全でない関数は、範囲の確認を呼び出し側で行う約束になっている。
