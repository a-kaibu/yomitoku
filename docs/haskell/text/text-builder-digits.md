## ひとことで

`digits` は、0 から 99 までの数字を、2 桁ずつ連続して並べた文字列の表です。整数を文字に変換するとき、この表から 2 桁ずつ取り出すと、1 桁ずつ計算するより速く済みます。

「00」「01」「02」…「99」が、1 つの長い文字列として並んでいます。たとえば「37」を取り出すには、先頭から 2 × 37 番目の位置から 2 文字を読めばよいのです。

## コード

```haskell:line-numbers=20
digits :: ByteString
digits = pack
  "0001020304050607080910111213141516171819\
  \2021222324252627282930313233343536373839\
  \4041424344454647484950515253545556575859\
  \6061626364656667686970717273747576777879\
  \8081828384858687888990919293949596979899"
```

## 前提知識

- **`ByteString`**: バイト列を表す型です。`pack` は、文字列をこの型に変換する関数です。
- **文字列の改行の書き方**: 行末の `\` と、次の行頭の `\` を組み合わせると、長い文字列リテラルを複数行に分けて書けます。途中の改行は、文字列に入りません。
- **整数から文字列へ**: 数を 10 で割った余りを、文字の番号に変えて並べるのが基本です。
- **表による変換**: 計算の代わりに、あらかじめ作った表から値を引く方法です。

## 何をしているか

### 1. 2 桁の数字を並べる

```haskell:line-numbers=21
digits = pack
  "0001020304050607080910111213141516171819\
```

`pack` に渡す文字列は、`0001020304…` のように、`00` から `09` を並べた部分から始まります。2 文字で 1 つの数を表すので、この文字列は全体で 200 文字になります。

### 2. 行末の `\` で、長い文字列を書き続ける

```haskell:line-numbers=23
  \2021222324252627282930313233343536373839\
  \4041424344454647484950515253545556575859\
  \6061626364656667686970717273747576777879\
  \8081828384858687888990919293949596979899"
```

行末の `\` は、文字列の続きをそのまま次の行に書くための印です。見た目は改行されていますが、データ上は 1 本の文字列です。

## ここがすごい

整数を文字列にするたびに、10 で割る計算を繰り返すと、遅くなります。この表は、2 桁ずつ取り出す方法を用意しておくことで、割り算の回数を半分にできます。

さらに、表が 1 つの連続した文字列なので、メモリ上で隣り合った位置にあり、読み出しが速いです。表を見れば数字の並びが分かるので、データの正しさを目で確かめやすいのも利点です。

コメントにもあるように、このモジュールは、C の前処理（プリプロセッサ）が複数行の文字列を扱うときの癖を避けるため、別のファイルにまとめられています。

## まとめ

- 変換の結果を表にしておくと、計算の回数を減らせる。
- 2 桁ずつ扱うと、割り算の回数を半分にできる。
- 長い文字列は、行末の `\` で見やすく書ける。
