## ひとことで

`lists:zip3/3` は、三つのリストから、要素を一つずつ取って `{X, Y, Z}` の三つ組を作ります。
長さが違うときは、既定の `fail` によって失敗します。

## コード

```erlang:line-numbers=838
zip3(Xs, Ys, Zs) -> zip3(Xs, Ys, Zs, fail).
```

## 前提知識

- **三つ組（3-tuple）**: 三つの値をまとめたタプルです。`{X, Y, Z}` の形で表されます。
- **`zip/2` との関係**: 二つのリストを組にする `zip/2` の、三つ版です。考え方は同じで、要素数だけが増えます。
- **`zip3/4`**: `How` を指定して三つ組を作る関数です。`zip3/3` は、`fail` を指定して、これを呼んでいます。
- **`fail`**: 長さが違うときに、失敗させる扱いです。

## 何をしているか

### 1. 既定の扱いを、`zip3/4` に渡す

```erlang:line-numbers=838
zip3(Xs, Ys, Zs) -> zip3(Xs, Ys, Zs, fail).
```

本体は一行です。三つのリストと、`fail` を `zip3/4` に渡しています。
呼び出し側は、長さの扱いを意識せずに、三つのリストを組にできます。

### 2. 三つとも要素があれば、組にして進む

```erlang:line-numbers=871
zip3([X | Xs], [Y | Ys], [Z | Zs], How) ->
    [{X, Y, Z} | zip3(Xs, Ys, Zs, How)];
```

先頭の三つを一つの三つ組 `{X, Y, Z}` にまとめます。残りの三つのリストに、同じ関数を当てます。

### 3. 三つとも空になれば、終わる

```erlang:line-numbers=873
zip3([], [], [], fail) ->
    [];
```

すべてのリストが空で、扱いが `fail` のときは、空のリストを返します。ここで組の作成が終わります。

## ここがすごい

### 同じ形を、要素数だけ増やす

`zip/2` の再帰と、ほぼ同じ形です。
先頭の要素を組にして、残りに同じ関数を当てます。読み手は、一度 `zip/2` を理解すれば、この関数も同じように読めます。

### 三つの長さを、同時に揃える

三つのリストのどれか一つが先に空になると、残りとの長さが合いません。
その場合、`fail` では失敗になります。三つの長さが同時に揃っているという前提を、関数の形が表しています。

### 短い入り口で、詳細を隠す

`zip3/3` は、`How` を省いた入り口です。
細かい扱いを変えたいときは、`zip3/4` を直接呼びます。通常の利用では、三つのリストを渡すだけで済みます。

### 三つのリストのうち一つだけ長いと、結果が欠ける

三つのリストのうち、一つだけ長さが違うと、`fail` の扱いで失敗します。
どのリストが短いかを、呼び出し側で確かめてから使うか、`lists:zip3/4` で `trim` を指定すると、長さの違いを切り捨てられます。

## まとめ

`lists:zip3([a, b], [1, 2], [x, y])` は、`[{a, 1, x}, {b, 2, y}]` を返します。
長さが違えば、`fail` の扱いで失敗します。
