## ひとことで

`calendar:day_of_the_week/3` は、年・月・日から曜日を求めます。戻り値は 1 から 7 の整数で、1 が月曜日、7 が日曜日です。
計算は、基準日からの通算日数を 7 で割った余りだけで行います。曜日の表や、ツェラーの公式のような手続きは使いません。

## コード

```erlang:line-numbers=288
day_of_the_week(Year, Month, Day) ->
    mod(date_to_gregorian_days(Year, Month, Day) + 5, 7) + 1.
```

負の余りを正にそろえる `mod/2` は、同じファイルで次のように書かれています。

```erlang:line-numbers=1042
mod(N, D) ->
    case N rem D of
	R when R < 0 -> mod(R + D, D);
	R -> R
    end.
```

## 前提知識

- **通算日数**: 紀元 0 年 3 月 1 日からの日数です。`date_to_gregorian_days/3` で求めます。
- **`rem` と `mod`**: `rem` は割り算の余りで、負の数に対しては負になることがあります。`mod` は、結果を 0 以上の範囲にそろえます。
- **曜日の番号**: 1 から 7 で、月曜を 1 とします。ISO 8601 の決まりに合わせています。
- **関数の合成**: `mod(...) + 1` で、余りを 1 から 7 の番号に変えます。

## 何をしているか

### 1. 通算日数を求める

```erlang:line-numbers=289
    mod(date_to_gregorian_days(Year, Month, Day) + 5, 7) + 1.
```

`date_to_gregorian_days/3` で、その日の通算日数を求めます。そこに 5 を足します。

### 2. 7 で割った余りを 1 から 7 にずらす

この 1 行の `mod(通算日数 + 5, 7) + 1` が、曜日を返す式の中心です。`mod/2` で 0 から 6 の余りを求め、1 を足して 1 から 7 にします。

例として、1970 年 1 月 1 日を考えます。この日の通算日数は 719528 です。5 を足すと 719533 になり、7 で割った余りは 3 です。1 を足して 4 になります。4 は木曜日なので、1970 年 1 月 1 日が木曜日だと分かります。

### 3. 負の余りを補正する

```erlang:line-numbers=1042
mod(N, D) ->
    case N rem D of
	R when R < 0 -> mod(R + D, D);
	R -> R
    end.
```

`rem` は、負の数が入ると負の余りを返すことがあります。その場合は、7 を足して正の値にしてから、もう一度 `mod` を行います。紀元 0 年より前の日付でも、正しい曜日が出ます。

## ここがすごい

### 曜日の表を持たない

曜日を求めるのに、年ごとや月ごとの表を持つ方法もあります。この関数は、通算日数という 1 つの数だけを使います。
7 日で循環するという性質を使い、余りだけで曜日が決まるのが、この方法の要点です。

### 基準日の選び方で、足す数が決まる

1970 年 1 月 1 日は木曜日です。その通算日数を 7 で割った余りに合わせて、足す数の 5 が決まっています。
基準日を変えれば、足す数も変わります。この定数は、基準日をどこに置くかで決まる、と理解すると読みやすくなります。

## まとめ

- 曜日は、通算日数を 7 で割った余りから求められます。
- 負の余りを扱うときは、`mod` で正の範囲にそろえます。
- 基準日の曜日が分かれば、足す数を決めて、どの日付でも曜日が求まります。
