## ひとことで

`queue:drop/1` は、キューの先頭の要素を取り除き、残りのキューを返します。
キューは、二つのリストで表されます。先頭の側が空のときは、後ろの側を反転して、取り除く場所を作ります。

## コード

```erlang:line-numbers=531
drop({[],[]}=Q) ->
    erlang:error(empty, [Q]);
drop({[_],[]}) ->
    {[],[]};
drop({[Y|R],[]}) ->
    [_|F] = lists:reverse(R, []),
    {[Y],F};
drop({R, [_]}) when is_list(R) ->
    r2f(R);
drop({R, [_|F]}) when is_list(R) ->
    {R,F};
drop(Q) ->
    erlang:error(badarg, [Q]).
```

## 前提知識

- **キュー（queue）**: 先に入れたものから順に取り出す、先入れ先出しのデータ構造です。
- **二つのリストの表し方**: 新しい要素は、一方のリストの先頭に積みます。取り出しは、もう一方のリストの先頭から行います。
- **`r2f/1`**: 後ろ側のリストを反転して、先頭側に移す補助関数です。ソースの別の箇所で定義されています。
- **`erlang:error/2`**: 空などの、してはいけない操作を例外にする関数です。

## 何をしているか

### 1. 空のキューは、例外にする

```erlang:line-numbers=531
drop({[],[]}=Q) ->
    erlang:error(empty, [Q]);
```

両方のリストが空なら、取り除く要素が無いので、`empty` の例外を投げます。

### 2. 要素が一つだけなら、空にする

```erlang:line-numbers=533
drop({[_],[]}) ->
    {[],[]};
```

先頭の側に要素が一つあり、後ろの側が空なら、取り除くと空のキューになります。

### 3. 先頭の側が空なら、後ろの側を反転する

```erlang:line-numbers=535
drop({[Y|R],[]}) ->
    [_|F] = lists:reverse(R, []),
    {[Y],F};
```

先頭の側が空で、後ろの側に要素があるとき、後ろの側を反転して、最も古い要素を取り出します。
取り除く要素を `_` に捨て、残りを先頭の側に移します。新しい要素 `Y` は、後ろの側に残します。

### 4. 先頭の側に要素があれば、その分を減らす

```erlang:line-numbers=538
drop({R, [_]}) when is_list(R) ->
    r2f(R);
drop({R, [_|F]}) when is_list(R) ->
    {R,F};
```

先頭の側に残りがあれば、一つ減らした形を返します。
一つだけのときは、反転して先頭側に移す `r2f/1` を使います。

## ここがすごい

### 反転は、必要なときだけ行う

キューの後ろの側を反転するのは、先頭の側が空になったときだけです。
その他の操作では、リストの反転は起きません。取り出しが続く限り、コストは平均して小さく抑えられます。

### 取り出しと追加を、別のリストで分ける

新しい要素は、後ろの側に積むだけです。取り出しは、先頭の側から行います。
二つの側を分けることで、どちらの操作も、リストの先頭への追加と取り出しで済みます。

### 空の場合は、例外で知らせる

空のキューから取り出すのは、意味のない操作です。
この関数は、戻り値で `empty` を表さず、例外にします。呼び出し側は、空でないことを確かめてから使う必要があります。

## まとめ

`queue:drop(queue:from_list([a, b, c]))` は、`b` と `c` だけを持つキューを返します。
空のキューに対して呼ぶと、例外になります。
