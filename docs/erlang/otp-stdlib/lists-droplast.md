## ひとことで

`lists:droplast/1` は、リストの最後の要素を取り除いたリストを返します。たとえば `lists:droplast([1, 2, 3])` は `[1, 2]` です。
Erlang のリストは、先頭からしか簡単にたどれません。そのため、末尾を取り除くには、先頭を残しながら末尾に近づく再帰の形が自然になります。

## コード

```erlang:line-numbers=442
droplast([_T])  -> [];
droplast([H|T]) -> [H|droplast(T)].
```

## 前提知識

- **リストの末尾**: Erlang のリストは、先頭の要素と残りの組で表されます。末尾は、残りが空になる場所です。
- **`[_T]`**: 要素がちょうど 1 つのリストです。`_T` は、残りの要素（ここでは空）を表す変数名で、使いません。
- **`[H|T]`**: 先頭 `H` と残り `T` の組です。
- **`[H|droplast(T)]`**: 先頭 `H` を残し、残りの結果をつなぎます。
- **再帰の終わり**: 要素が 1 つになったら、そこで止まります。

## 何をしているか

### 1. 要素が 1 つだけのとき

```erlang:line-numbers=442
droplast([_T])  -> [];
```

要素が 1 つだけなら、それが最後の要素です。取り除くと、残るものはありません。空のリスト `[]` を返します。

### 2. 要素が 2 つ以上のとき

```erlang:line-numbers=443
droplast([H|T]) -> [H|droplast(T)].
```

先頭の要素 `H` は、最後ではないので残します。残り `T` に対して同じ処理（末尾を取る）を行い、その結果の前に `H` をつなぎます。
再帰を重ねると、最後の要素だけが落ちていきます。

### 例で追う

`[1, 2, 3]` では、まず `1` を残して `[2, 3]` を処理します。次に `2` を残して `[3]` を処理します。`[3]` は 1 要素なので `[]` になります。結果を積み上げると、`[1, 2]` です。

## ここがすごい

### 1 行目の「1 要素の節」が、終わりを決める

この関数の書き方は、2 つの節だけです。1 要素の場合を先に書いておけば、それ以外は必ず 2 要素以上なので、残りの処理に何も特別な条件を入れなくて済みます。
終わりの条件を一つだけ丁寧に書き、残りを同じ形で続けるのが、リストの再帰の基本的な型です。

### 再帰の深さは、リストの長さに比例する

この書き方は、リストが長いと再帰が深くなります。結果を先頭から作るので、後ろからの処理は戻りながら行われます。
大きなリストでは、末尾再帰で反転を使う書き方と比べて、メモリの使い方が違うことを覚えておくとよいです。

## まとめ

- 末尾を取り除く処理は、先頭を残して残りを再帰で処理するのが、Erlang で自然な書き方です。
- 終わりの節（要素が 1 つのとき）を先に書くと、再帰の規則が単純になります。
- 再帰の深さや作り方の違いは、大きなリストを扱うときに効いてきます。
