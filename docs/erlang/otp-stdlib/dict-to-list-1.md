## ひとことで

`dict:to_list/1` は、辞書に入っているすべての `{Key, Value}` を、リストにして返します。
辞書の中身を、Erlang の普通のリストとして読みたいときに使います。

## コード

```erlang:line-numbers=153
to_list(D) ->
    fold(fun (Key, Val, List) -> [{Key,Val}|List] end, [], D).
```

## 前提知識

- **dict（辞書）**: キーで値を探すための、標準ライブラリのデータ構造です。ハッシュの考え方で、キーを格納先に振り分けます。
- **`fold/3`**: 辞書の要素を一つずつ関数に渡し、途中の結果を積み上げる関数です。
- **`[{Key, Val} | List]`**: リストの先頭に、組を一つ加える形です。`cons` とも呼ばれます。
- **順番**: 辞書の要素の順番は、キーの値の大小ではなく、内部のハッシュの並びで決まります。

## 何をしているか

### 1. 空の結果から始めて、要素を積む

```erlang:line-numbers=153
to_list(D) ->
    fold(fun (Key, Val, List) -> [{Key,Val}|List] end, [], D).
```

`fold/3` を使い、空のリスト `[]` を出発点にします。
辞書の要素を一つずつ取り出し、その組を先頭に加えていきます。

## ここがすごい

### 戻り値の形を、fold に任せる

この関数は、結果をリストにするための処理を、`fold/3` に一箇所でまとめています。
辞書の内部の構造を知らなくても、要素を一つずつ扱えます。

### 先頭に積むので、順番が逆になる

`[{Key,Val} | List]` は、リストの先頭に加える形です。
辞書の走査の順番と、結果の順番は逆になります。順番に意味を持たせたい場合は、結果を `lists:sort/1` などで並べ替える必要があります。

### 中身の順番に、約束をしない

辞書の要素の順番は、キーの大小とは関係がありません。
内部の並びを利用しているので、同じ内容の辞書でも、作り方が違えば並びが変わることがあります。順番を使うコードは書かないほうが安全です。

### 辞書を読むだけで、変更しない

`to_list/1` は、辞書を読むだけで、元の辞書を変えません。
得られたリストは、辞書とは別の値です。リストを並べ替えたり、加工したりしても、元の辞書の中身は変わりません。

### 空の辞書なら、空のリストを返す

辞書に要素が一つもなければ、`fold/3` は初期値の `[]` をそのまま返します。
結果が空でも、呼び出し側は、リストとして安心して扱えます。

## まとめ

`dict:to_list(dict:from_list([{a, 1}, {b, 2}]))` は、`a` と `b` の二つの組を含むリストを返します。
ただし、どちらが先に並ぶかは、辞書の内部の並びによって決まります。
