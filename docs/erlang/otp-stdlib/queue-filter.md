## ひとことで

`queue:filter/2` は、キューから条件に合う要素だけを残した新しいキューを作ります。キューは入れ側（`R0`）と取り出し側（`F0`）の 2 本のリストで表されているので、両方を絞り込みます。
絞り込んだあと、片方のリストが空になると、前の記事で見た `f2r` や `r2f` で分け直して、キューの形を保ちます。

## コード

```erlang:line-numbers=719
filter(Fun, {R0,F0}) when is_function(Fun, 1), is_list(R0), is_list(F0) ->
    F = filter_f(Fun, F0),
    R = filter_r(Fun, R0),
    if R =:= [] ->
	    f2r(F);
       F =:= [] ->
	    r2f(R);
       true ->
	    {R,F}
    end;
filter(Fun, Q) ->
    erlang:error(badarg, [Fun,Q]).
```

## 前提知識

- **2 本のリストのキュー**: 入れ側（`R`）と取り出し側（`F`）の組です。取り出しは `F` の先頭から行います。
- **`is_function(Fun, 1)`**: 引数を 1 つ取る関数かどうかを確かめます。
- **`R =:= []`**: 入れ側が空かどうかを、型も含めて比べます。
- **`if ... end`**: 条件が真になった最初の枝を実行します。`true` の枝は、どの条件にも当てはまらないときの既定の処理です。
- **`r2f/1` と `f2r/1`**: 前の記事で見た、キューの 2 本のリストを作り直す補助関数です。

## 何をしているか

### 1. 両方のリストを絞り込む

```erlang:line-numbers=720
    F = filter_f(Fun, F0),
    R = filter_r(Fun, R0),
```

取り出し側 `F0` と、入れ側 `R0` のそれぞれに、`filter_f/2` と `filter_r/2` を使って条件を適用します。どちらのリストも、条件に合う要素だけが残ります。

### 2. 入れ側が空になったとき

```erlang:line-numbers=722
    if R =:= [] ->
	    f2r(F);
```

入れ側 `R` が空になったら、取り出し側 `F` を `f2r/1` にかけます。`f2r/1` は、取り出し側の要素を、入れ側と取り出し側の両方に分け直します。

### 3. 取り出し側が空になったとき

```erlang:line-numbers=724
       F =:= [] ->
	    r2f(R);
```

取り出し側 `F` が空になったら、入れ側 `R` を `r2f/1` にかけて、取り出し側を作ります。前の記事で見た、半分に分けて反転する処理です。

### 4. どちらも空でないとき

```erlang:line-numbers=726
       true ->
	    {R,F}
```

両方のリストに要素が残っているときは、そのまま組にして返します。

### 5. キューでないとき

```erlang:line-numbers=729
filter(Fun, Q) ->
    erlang:error(badarg, [Fun,Q]).
```

引数がキューの形でないときは、`badarg` の例外を起こします。

## ここがすごい

### 絞り込んだあとの形を、そのまま放置しない

キューの片方だけを絞り込むと、取り出し側が空のまま、入れ側だけに要素が溜まってしまいます。そのままだと、次の取り出しで大きな反転が起きます。
この関数は、片方が空になったときに、もう片方を分け直して、取り出し側を補います。キューの取り出しを速く保つための、後始末です。

### 空になった側だけを作り直す

両方のリストを毎回作り直すと、無駄が増えます。この関数は、空になった側だけを作り直します。
空でないときは、そのまま組にするので、ほとんどの場合は絞り込みの結果をそのまま使えます。

## まとめ

- キューを絞り込むときは、2 本のリストを両方とも絞り込む必要があります。
- 片方が空になったら、分け直して取り出しの形を保つと、後の操作が速く保てます。
- 空になった側だけを作り直すと、無駄な処理を減らせます。
