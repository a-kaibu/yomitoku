## ひとことで

`lists:sort/1` は、リストを昇順に並べ替えて返す関数です。
この関数の入口では、先頭の 2 要素を比べて、リストがすでに並んでいるかどうかを確かめます。要素が 1 つか 2 つ、3 つしかないような短いリストは、特別な形で一気に並べます。

## コード

```erlang:line-numbers=1084
sort([X, Y | L] = L0) when X =< Y ->
    case L of
	[] -> 
	    L0;
	[Z] when Y =< Z ->
	    L0;
	[Z] when X =< Z ->
	    [X, Z, Y];
	[Z] ->
	    [Z, X, Y];
	_ when X == Y ->
	    sort_1(Y, L, [X]);
	_ ->
	    split_1(X, Y, L, [], [])
    end;
sort([X, Y | L]) ->
    case L of
	[] ->
	    [Y, X];
	[Z] when X =< Z ->
	    [Y, X | L];
	[Z] when Y =< Z ->
	    [Y, Z, X];
	[Z] ->
	    [Z, Y, X];
	_ ->
	    split_2(X, Y, L, [], [])
    end;
sort([_] = L) ->
    L;
sort([] = L) ->
    L.
```

## 前提知識

- **`X =< Y`**: 「X は Y 以下」という比較です。Erlang では、数値も文字列（リスト）もタプルも、同じ規則で比べられます。
- **`[X, Y | L] = L0`**: 先頭の 2 要素 `X`、`Y` と、残りの `L` に分けます。`= L0` は、この全体のリストに `L0` という名前も付けます。
- **`case ... of`**: 値の形で分岐します。`L` が空か、1 要素か、それ以外かを見分けます。
- **`when` の付いた節**: `[Z] when Y =< Z` のように、一致した後で追加の条件を確かめます。
- **`[Z]`**: 要素がちょうど 1 つのリストです。
- **`split_1` と `split_2`**: この部分で大きなリストを扱います。ここでは中身を詳しく追わず、「並べ替えの本体へ進む入口」として読んでください。

## 何をしているか

### 1. 先頭 2 要素がすでに昇順のとき

```erlang:line-numbers=1085
    case L of
	[] -> 
	    L0;
```

`X =< Y` が成り立つ場合です。`L` が空なら、`X` と `Y` だけのリストは、もう並んでいます。そのまま `L0` を返します。

### 2. 残りが 1 要素のとき

```erlang:line-numbers=1088
	[Z] when Y =< Z ->
	    L0;
	[Z] when X =< Z ->
	    [X, Z, Y];
	[Z] ->
	    [Z, X, Y];
```

3 要素のリストのとき、残りの `Z` との大小関係で結果を決めます。たとえば `X =< Y =< Z` なら、そのまま `L0` です。`X =< Z < Y` なら `[X, Z, Y]` です。`Z` がいちばん小さい場合は `[Z, X, Y]` になります。比較は高々 2 回で済みます。

### 3. 先頭 2 要素が等しいとき

```erlang:line-numbers=1094
	_ when X == Y ->
	    sort_1(Y, L, [X]);
```

`X == Y` のときは、同じ値が続いているので `sort_1/3` へ渡します。等しい値をまとめて、後の処理を短くするための分岐です。

### 4. 残りが多いとき

```erlang:line-numbers=1096
	_ ->
	    split_1(X, Y, L, [], [])
```

ここまでの特別な場合に当てはまらなければ、`split_1/5` で大きなリストを分けて並べていきます。

### 5. 先頭 2 要素が逆順のとき

```erlang:line-numbers=1099
sort([X, Y | L]) ->
    case L of
	[] ->
	    [Y, X];
	[Z] when X =< Z ->
	    [Y, X | L];
	[Z] when Y =< Z ->
	    [Y, Z, X];
	[Z] ->
	    [Z, Y, X];
	_ ->
	    split_2(X, Y, L, [], [])
    end;
```

2 つ目の節は、`X > Y` のときです。`Y` を先に置くように、比較の結果に合わせて並べ替えます。残りが 1 要素のときや、2 要素の並びのときも、比較の回数を少なくするための場合分けがあります。

### 6. 空と 1 要素のリスト

```erlang:line-numbers=1112
sort([_] = L) ->
    L;
sort([] = L) ->
    L.
```

0 個や 1 個のリストは、すでに並んでいるので、そのまま返します。

## ここがすごい

### 「並んでいる」を、先頭の比較で見分ける

素朴な並べ替えは、どんな入力でも同じ量の比較をします。`lists:sort/1` は、先頭 2 要素の比べ方から、すでに並んでいる部分や、逆順の部分を見つけます。
入力がほぼ整列されているときには、その分だけ仕事が減ります。

### 短い入力は、専用の式で一気に終わらせる

3 要素までのリストには、場合分けによる一発の答えを用意しています。小さな入力で汎用の並べ替えを呼ぶと、再帰や中間リストの作成で時間がかかります。
その無駄を、パターンの形だけで省いています。

## まとめ

- 並べ替えでは、入力がすでに並んでいるかどうかを、最初の比較で見分けると効率が上がります。
- 要素数が少ない場合を専用の節で処理すると、汎用の処理を呼ぶ手間が減ります。
- 等しい値は、後の処理で扱いやすいようにまとめます。
