## ひとことで

`string:pad/2` は、文字列の末尾に空白を足して、指定の長さに揃えます。
表の列を、左に寄せて揃えたいときに使います。長さがすでに足りていれば、何も足しません。

## コード

```erlang:line-numbers=427
pad(CD, Length) ->
    pad(CD, Length, trailing, $\s).
```

## 前提知識

- **`string:pad/4`**: 埋める方向（`leading`、`trailing`、`both`）と、埋める文字を指定できる関数です。`pad/2` は、その既定値の形です。
- **`trailing`**: 文字列の後ろに埋める指定です。
- **`$\s`**: 空白の文字です。`\s` は、Erlang で空白を表す文字の書き方です。
- **既定値**: 引数を省いたときに、自動で使われる値です。

## 何をしているか

### 1. 既定の方向と文字を決めて、pad/4 に渡す

```erlang:line-numbers=427
pad(CD, Length) ->
    pad(CD, Length, trailing, $\s).
```

`pad/2` は、方向に `trailing`（後ろ）、文字に `$\s`（空白）を選び、`pad/4` を呼びます。
呼び出し側は、長さだけを渡せば、後ろに空白が付いた文字列を得られます。

## ここがすごい

### 既定値で、よくある呼び出しを短くする

表の列を揃えるとき、多くの場合は、後ろに空白を足すだけで十分です。
その典型的な形を、既定値として `pad/2` に用意しています。引数を一つ減らせるので、呼び出しの意図が一目で伝わります。

### 細かい指定は、pad/4 に任せる

方向や文字を変えたいときは、`pad/4` を使います。
`pad/2` は、そのための入口を、一つだけ用意しています。機能の入れ子を、役割で分けた設計です。

### 長い文字列は、そのまま返る

`pad/4` の中で、足りない文字数が 0 以下なら、何も足されません。
既に長い文字列を渡しても、切り詰められることはありません。長さを揃えるだけの関数なので、内容を壊さないことが保証されています。

### 表の列を揃える、典型的な使い方

複数の行の文字列を、同じ幅の列にそろえるとき、各行を `pad/2` で同じ長さにしておけば、列の右端がきれいに揃います。
長さを決めるのは呼び出し側で、足す文字は既定の空白です。役割を、二つの引数だけに絞った形です。

### 足りない文字数の計算は、pad/4 の仕事

`pad/2` は、足りない文字数を自分では計算しません。`pad/4` の中で、長さの差を数え、`max(0, ...)` で負の差を打ち消します。
だから、長さが足りているかどうかの判定は、一箇所にまとまったままです。

## まとめ

`string:pad("ab", 5)` は、`"ab   "` 相当の値を返します。
足りない三つの空白が、後ろに付きます。
