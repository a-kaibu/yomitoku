## ひとことで

`array:to_list/1` は、配列の要素を、添字の小さい順に並べたリストにして返します。
中身の作り方は、`foldr` で、後ろの要素から先頭へ向かって積むだけです。

## コード

::: code-group

```erlang:line-numbers=1161 [日本語訳]
to_list(Array) ->
    %% 型検査ツールに、この部分の警告を無視させる注釈
    foldr(fun (_I, V, A) -> [V|A] end, [], Array).
```

```erlang:line-numbers=1161 [原文]
to_list(Array) ->
    %% eqwalizer:ignore ambiguous_union
    foldr(fun (_I, V, A) -> [V|A] end, [], Array).
```

## 前提知識

- **配列（array）**: 添字で要素を持つデータ構造です。
- **`foldr/3`**: リストや配列を、後ろから前へ畳み込みます。関数は、要素と後ろの結果を受け取ります。
- **`[V|A]`**: 値 `V` を、残りの結果 `A` の先頭に付ける形です。
- **`fun (_I, V, A) -> ...`**: 添字 `_I` は使わず、要素 `V` と途中の結果 `A` だけを使う無名関数です。

## 何をしているか

### 1. 後ろから、要素を先頭に積む

```erlang:line-numbers=1162
    %% eqwalizer:ignore ambiguous_union
    foldr(fun (_I, V, A) -> [V|A] end, [], Array).
```

`foldr` は、配列の要素を後ろから一つずつ取り出します。無名関数は、要素 `V` を、途中の結果 `A` の先頭に付けます。
空の `[]` から始めるので、最後の要素から、リストが組み上がります。

## ここがすごい

### 後ろから積むと、前から並ぶ

先頭に付ける操作は、リストの先頭に追加する形です。後ろから順に付けていくと、最後に、添字の小さい順に並んだリストになります。
反転のための `reverse` は要りません。畳み込みの向きと、積む向きが、ちょうど噛み合っています。

### 添字を使わない

無名関数は、添字を `_I` として無視しています。
添字の順番は、畳み込みの向きに任せています。要素の値だけを並べたいので、必要な情報だけを使っています。

### 既定値の扱い

配列の説明文に「既定値の要素は省く」とあるように、配列には初期値のままの場所があります。
この関数の仕組みは、そのような扱いを対象にしています。詳しい決まりは、配列の定義側の処理に従います。

### 空の配列でも、空のリスト

要素が一つもない配列でも、`foldr` は初期値の `[]` を返します。
つまり、この関数は、空の配列に対しても、きちんと空のリストを返します。特別な場合分けは要りません。

### 畳み込みの向きと、リストの作り方

`foldr` は、後ろから処理します。リストを作るときの `[V|A]` は、先頭に積みます。
この二つの向きが合うので、結果の順番は、配列の添字の順と一致します。向きの組み合わせを、読み手が理解すれば、この関数の読み方が身につきます。

## まとめ

`array:to_list(array:from_list([a, b, c]))` は、`[a, b, c]` を返します。
添字の順番どおりに、要素が並びます。
