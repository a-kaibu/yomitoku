## ひとことで

`ordsets:union/2` は、2 つの集合の和集合を作ります。`ordsets` は、昇順に並んだリストで集合を表します。
2 つのリストの先頭どうしを比べて、小さい方から順に取り出すので、1 回の走査で結果ができます。同じ要素が両方にあれば、1 つだけ残します。

## コード

::: code-group

```erlang:line-numbers=288 [日本語訳]
union([E1|Es1], [E2|_]=Set2) when E1 < E2 ->
    [E1|union(Es1, Set2)];
union([E1|_]=Set1, [E2|Es2]) when E1 > E2 ->
    [E2|union(Es2, Set1)];			% 引数を入れ替えて、同じ処理を逆向きに使う
union([E1|Es1], [_E2|Es2]) ->			%両方の先頭が等しいとき
    [E1|union(Es1, Es2)];
union([], Es2) -> Es2;
union(Es1, []) -> Es1.
```

```erlang:line-numbers=288 [原文]
union([E1|Es1], [E2|_]=Set2) when E1 < E2 ->
    [E1|union(Es1, Set2)];
union([E1|_]=Set1, [E2|Es2]) when E1 > E2 ->
    [E2|union(Es2, Set1)];			% switch arguments!
union([E1|Es1], [_E2|Es2]) ->			%E1 == E2
    [E1|union(Es1, Es2)];
union([], Es2) -> Es2;
union(Es1, []) -> Es1.
```

:::

## 前提知識

- **`ordsets`（順序付き集合）**: 要素を昇順に並べたリストで、集合を表すモジュールです。要素の重複はありません。
- **`[E1|Es1]` の形**: 先頭の要素 `E1` と残りの `Es1` の組です。
- **`when` ガードの比較**: `E1 < E2` は、Erlang の項の全順序で比べます。数値、アトム、タプルなど、どの型も比べられます。
- **`_E2` の名前**: 先頭に `_` を付けた変数は、使わない値を表します。`[_E2|Es2]` は、比べていない側の先頭を捨てるという意味になります。
- **`[]` の節**: 片方が空になったら、もう片方をそのまま返します。

## 何をしているか

### 1. 第 1 集合の先頭が小さいとき

```erlang:line-numbers=288
union([E1|Es1], [E2|_]=Set2) when E1 < E2 ->
    [E1|union(Es1, Set2)];
```

`E1 < E2` なら、`E1` は第 2 集合のどの要素よりも小さいので、結果の先頭に確定します。`E1` を先頭に付けて、`Es1` と `Set2` の和集合を再帰的に作ります。第 2 集合は、まだ先頭を比べていないので変えません。

### 2. 第 2 集合の先頭が小さいとき

```erlang:line-numbers=290
union([E1|_]=Set1, [E2|Es2]) when E1 > E2 ->
    [E2|union(Es2, Set1)];			% switch arguments!
```

今度は逆に、`E2` が小さい場合です。`E2` を先頭に付けて、残りの和集合を作ります。

### 3. 同じ要素のとき

```erlang:line-numbers=292
union([E1|Es1], [_E2|Es2]) ->			%E1 == E2
    [E1|union(Es1, Es2)];
```

`E1` と `E2` が等しいと、ここに来ます。先頭どうしが同じなので、1 つだけ `E1` を残します。両方の先頭を 1 つずつ進めます。`E2` は捨てる（`_E2`）ので、重複は結果に入りません。

### 4. 片方が空になったとき

```erlang:line-numbers=294
union([], Es2) -> Es2;
union(Es1, []) -> Es1.
```

どちらかのリストが空になったら、残りのリストをそのまま返します。残りは、すでに昇順で重複がないので、そのまま和集合の一部になります。

## ここがすごい

### 「マージ」の 1 回の走査

2 つの昇順リストを先頭から比べて、小さい方を取り出す処理は、マージソートの統合（merge）と同じ形です。
素朴に「第 2 集合の要素を第 1 集合に 1 つずつ探して足す」と、要素数の二乗に近い時間がかかります。ここでは、どちらの集合も 1 回だけ読むので、要素数の和に比例する時間で済みます。

### 重複の扱いが 1 つの節に入っている

3 番目の節が、等しい要素を 1 つにまとめる役目をします。重複を取り除く別の処理は要りません。
ソートされているという前提を使って、比較の結果から直接判断しています。

## まとめ

- 昇順に並んだリストは、先頭どうしを比べながら 1 回の走査でまとめられます。
- 等しい要素は 1 つにまとめ、集合として重複を残しません。
- 片方が空になったら残りをそのまま使えるので、後始末の処理が要りません。
