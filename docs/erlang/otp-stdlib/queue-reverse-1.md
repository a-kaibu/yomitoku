## ひとことで

`queue:reverse/1` は、キューの要素の並びを逆にします。
キューは、二つのリストで表されています。この関数は、二つのリストの役割を入れ替えるだけで、逆向きのキューを作ります。要素を一つも移動させません。

## コード

```erlang:line-numbers=596
reverse({R,F}) when is_list(R), is_list(F) ->
    {F,R};
reverse(Q) ->
    erlang:error(badarg, [Q]).
```

## 前提知識

- **キューの二つのリスト**: 一方は取り出し側、もう一方は入れ側です。どちらのリストも、要素の順番を、片方向で持ちます。
- **組 `{R, F}` の入れ替え**: 二つの要素の位置を交換して、新しい組を作ることです。
- **`badarg`**: キューの形でない値が渡されたときの、標準的なエラーです。

## 何をしているか

### 1. 形が正しいキューなら、組の順番を入れ替える

```erlang:line-numbers=596
reverse({R,F}) when is_list(R), is_list(F) ->
    {F,R};
```

`R` と `F` が、どちらもリストであれば、`{F, R}` という新しい組を返します。
つまり、取り出し側と入れ側の役割が、そっくり入れ替わります。

### 2. 形が正しくなければ、badarg

```erlang:line-numbers=598
reverse(Q) ->
    erlang:error(badarg, [Q]).
```

キューの形でない値が渡されたときは、`badarg` を投げます。

## ここがすごい

### 中身を動かさず、役割だけを替える

要素の並べ替えや、反転のための作業は、一つもありません。
二つのリストを、そのまま入れ替えるだけです。大きなキューでも、かかる時間は一定です。

### 取り出し順の反転を、組の入れ替えで表す

キューの先頭は、取り出し側のリストの先頭です。入れ替えると、もとの末尾が、新しい取り出し側の先頭になります。
この関係があるので、「取り出す順番が逆になる」という結果が、組の入れ替えだけで得られます。

### 形の確かめを、入り口で行う

`when is_list(R), is_list(F)` のガードで、キューの形を確かめます。
形が違う値は、二つ目の節に当たり、`badarg` として呼び出し元に知らされます。

### 反転を二回すると、元に戻る

もう一度 `reverse` を呼ぶと、組が再び入れ替わり、元の並びに戻ります。
取り出しの順番を反転させる操作は、何度でも行えます。入れ替えは、どちらの向きにも対になっている操作です。

### 空のキューの反転は、空のまま

両方が空のキューを反転しても、組の入れ替えの結果は、やはり両方が空です。
要素が無いことは、どちらの向きから見ても同じなので、この関数は特別な場合を持ちません。

## まとめ

`queue:reverse(queue:from_list([1, 2, 3]))` を、順に `queue:to_list/1` で見ると、`[3, 2, 1]` の順になります。
取り出される順番が、元の逆になります。
