## ひとことで

`dict:get_slot/2` は、キーからスロットの番号を求める関数です。
ハッシュ値をそのまま使うのではなく、表がいまどこまで広がっているかに合わせて補正します。
辞書の表は、一度に全部作り直さず、少しずつ広げるので、この補正が必要になります。

## コード

```erlang:line-numbers=675
get_slot(T, Key) ->
    H = erlang:phash(Key, T#dict.maxn),
    if
	H > T#dict.n -> H - T#dict.bso;
	true -> H
    end.
```

## 前提知識

- **ハッシュ値**: キーから計算された整数です。同じキーなら、同じ値になります。`erlang:phash/2` は、この値を指定の範囲に収めて計算します。
- **`maxn`**: 表が最終的に持てるスロットの数です。ハッシュ値は、この範囲の中で作られます。
- **`n`**: いま使っているスロットの数です。`n` より大きいハッシュ値は、まだ分割されていないスロットを指すので、補正が必要です。
- **`bso`**: 補正の幅です。`H - bso` で、古いスロットの番号に寄せます。
- **線形ハッシュ**: 表を一度に二倍にせず、スロットを一つずつ分割して広げる方式です。この関数は、その途中の状態を扱います。

## 何をしているか

### 1. キーのハッシュ値を、最大の範囲で作る

```erlang:line-numbers=676
    H = erlang:phash(Key, T#dict.maxn),
```

`erlang:phash(Key, T#dict.maxn)` で、キーを `1` から `maxn` までの番号にします。
ここで作る番号は、最終的な表の大きさを前提にしています。表がまだ小さいうちは、番号の一部が使われていません。

### 2. まだ使っていないスロットを避ける

```erlang:line-numbers=677
    if
	H > T#dict.n -> H - T#dict.bso;
	true -> H
```

`H > T#dict.n` のとき、番号 `H` は、まだ作られていないスロットを指しています。その場合は、`H - bso` で、すでに作られたスロットに寄せます。
それ以外のときは、番号 `H` をそのまま使います。

## ここがすごい

### 表を一度に広げない

スロットを一気に倍にすると、すべてのキーを移し替えることになり、一回の処理が重くなります。
この辞書は、スロットを少しずつ分割します。その途中で、まだ分割されていない番号が来たら、ここで補正して、正しい古いスロットに振り分けます。
補正は一つの `if` だけなので、読み手はこの一箇所を見れば、途中の状態の扱いがわかります。

### 最大の番号で作ってから、絞る

先に `maxn` を使って番号を作り、あとで `n` と比べて絞るという順番です。
ハッシュ値は、表の現在の大きさに関係なく、同じ範囲から作られます。その後で、現在の大きさに合わせて絞るので、計算の仕方を変えずに済みます。

### 条件を一つだけ書く

`if` には、`H > T#dict.n` という一つの条件しかありません。
それ以外の場合は、`true` の節で番号をそのまま返します。単純な形なので、補正の条件が増えても、この関数だけを見れば判断できます。

## まとめ

`dict:get_slot(D, Key)` は、キーに対応するスロットの番号を返します。
表の現在の状態を読んで、まだ作られていないスロットを避けるのが、この関数の役目です。
