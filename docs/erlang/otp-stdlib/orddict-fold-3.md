## ひとことで

`orddict:fold/3` は、順序付き辞書の組を、キーの昇順に一つずつ関数へ渡します。
関数は、キーと値と、途中の結果を受け取り、新しい途中の結果を返します。最後の途中の結果が、答えになります。

## コード

```erlang:line-numbers=518
fold(F, Acc, [{Key,Val}|D]) ->
    fold(F, F(Key, Val, Acc), D);
fold(F, Acc, []) when is_function(F, 3) -> Acc.
```

## 前提知識

- **畳み込み（fold）**: リストを一つの値にまとめる操作です。途中の結果を次の要素に引き継ぎます。
- **`F(Key, Val, Acc)`**: 関数 `F` は、キーと値、途中の結果の三つを受け取ります。
- **アキュムレータ（`Acc`）**: 途中の結果を持ち回る引数です。
- **空の辞書**: 組が無いので、初期値 `Acc` がそのまま答えになります。

## 何をしているか

### 1. 先頭の組で、関数を呼び、結果を次へ渡す

```erlang:line-numbers=518
fold(F, Acc, [{Key,Val}|D]) ->
    fold(F, F(Key, Val, Acc), D);
```

`fold/3` は、先頭の組 `{Key, Val}` について、`F(Key, Val, Acc)` を計算します。その結果を、残りの組を処理するための新しい途中の結果として渡します。
この呼び出しは、関数の最後にあるので、末尾再帰です。

### 2. 組が無くなったら、途中の結果を返す

```erlang:line-numbers=520
fold(F, Acc, []) when is_function(F, 3) -> Acc.
```

組が空になったら、持ち回ってきた `Acc` を答えとして返します。空の辞書に対しては、初期値そのものが答えになります。

## ここがすごい

### キーと値を、同時に関数へ渡す

`lists:foldl/3` は要素一つを渡しますが、この関数は、キーと値の両方を渡します。
キーの大きさを使いながら集計する、といった処理を、一つの関数で書けます。

### 昇順の順番で、必ず処理される

辞書は、キーの昇順に並んでいます。関数は、その順番どおりに、先頭から一つずつ呼ばれます。
そのため、「最後に処理されたキーが一番大きい」といった性質を、前提として使えます。

### 末尾再帰で、結果だけを運ぶ

途中の結果は、引数で持ち回られ、外に保存されません。
関数の最後の呼び出しなので、組の数が多くても、呼び出しの積み重ねは起きません。

### 途中の結果の型は、自由に決められる

途中の結果は、数でも、リストでも、組でも構いません。関数の戻り値と、初期値の型をそろえれば、どんな集計にも使えます。
たとえば、キーの一覧を作るなら、初期値を空のリストにして、関数の中で先頭に積みます。

## まとめ

`orddict:fold(fun(K, V, Acc) -> Acc + V end, 0, [{a, 1}, {b, 2}])` は、`3` を返します。
値を一つずつ足して、最後の合計を得ています。
