## ひとことで

`lists:sum/1` は、数のリストを受け取り、すべての要素の合計を返します。
空のリストの合計は `0` です。計算は、補助の関数 `sum/2` に任せ、途中の合計を引数で持ち回ります。

## コード

```erlang:line-numbers=570
sum(L)          -> sum(L, 0).

sum([H|T], Sum) -> sum(T, Sum + H);
sum([], Sum)    -> Sum.
```

## 前提知識

- **アキュムレータ（累積の引数）**: 途中の結果を、引数として持ち回る考え方です。ここでは `Sum` がそれにあたります。
- **末尾再帰**: 関数が自分を呼ぶ位置が、関数の最後にある再帰です。Erlang では、この形の呼び出しは、呼び出しの積み重ねを増やしません。
- **パターンマッチ**: `[H|T]` は、先頭の要素 `H` と残りの `T` に分けます。`[]` は、空のリストにマッチします。
- **`sum/1` と `sum/2`**: Erlang では、引数の数が違えば、別の関数として扱われます。`sum/1` は入口、`sum/2` は作業用です。

## 何をしているか

### 1. 入口で合計を `0` から始める

```erlang:line-numbers=570
sum(L)          -> sum(L, 0).
```

`sum/1` は、初期値 `0` を用意して、`sum/2` を呼びます。合計を持ち回るための出発点です。

### 2. 先頭の要素を足して、残りへ進む

```erlang:line-numbers=572
sum([H|T], Sum) -> sum(T, Sum + H);
```

リストの先頭 `H` を、いまの合計 `Sum` に足します。そして残りの `T` と、新しい合計を、もう一度 `sum/2` に渡します。
この呼び出しは、関数の最後にあるので、末尾再帰です。

### 3. リストが空になったら、合計を返す

```erlang:line-numbers=573
sum([], Sum)    -> Sum.
```

空のリストに当たったときは、持ち回ってきた `Sum` を、そのまま結果として返します。

## ここがすごい

### 合計を引数に持たせる

普通の再帰で書くと、「先頭の要素と、残りの合計を足す」という形になります。
それでは、リストが長いほど、呼び出しが積み重なります。この関数は、先に足してしまい、その結果を次の呼び出しに渡します。計算の順番は、先頭から末尾へと一直線です。

### 入口と作業を分ける

`sum/1` は、引数が一つだけの、使いやすい入口です。
`sum/2` は、途中の合計を受け取る作業用の関数です。呼び出し側は、初期値を気にせず、リストだけを渡せます。

### 空のリストの節が、終わりを決める

再帰の終わりは、`[]` にマッチする一行だけです。
合計をそのまま返すので、最後に必要な処理はありません。読み手は、終わりの条件を一箇所で確かめられます。

## まとめ

`lists:sum([1, 2, 3])` は、`6` を返します。
空のリスト `lists:sum([])` は、`0` を返します。
