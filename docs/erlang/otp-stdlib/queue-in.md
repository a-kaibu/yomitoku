## ひとことで

`queue:in/2` は、待ち行列（キュー）に要素を 1 つ追加する関数です。Erlang のキューは、`{In, Out}` という 2 本のリストの組で表されます。新しい要素は `In` の先頭に積むだけで追加できます。
ただし `Out` が空で `In` がちょうど 1 要素のときだけ、少し違う形になります。

## コード

```erlang:line-numbers=287
in(X, {[_]=In,[]}) ->
    {[X], In};
in(X, {In,Out}) when is_list(In), is_list(Out) ->
    {[X|In],Out};
in(X, Q) ->
    erlang:error(badarg, [X,Q]).
```

## 前提知識

- **待ち行列（キュー）**: 先に入った要素から順に取り出すデータ構造です。
- **不変データ**: Erlang の値は後から書き換えられません。`in/2` は元のキューを変えず、新しいキューを返します。
- **リスト `[H|T]`**: 先頭の要素 `H` と残りの `T` の組です。`[X|L]` は、`L` の先頭に `X` を付けた新しいリストを作ります。元の `L` は変わりません。
- **タプル `{A, B}`**: 複数の値を 1 つにまとめます。`{In, Out}` の 2 本のリストは、この形で持ちます。
- **パターンマッチ**: 関数の引数の形で、場合分けをします。`{[_]=In, []}` は、`Out` が空リストで、`In` が要素 1 個のリストのときだけ一致します。`=In` は、一致した値に `In` という名前を付けます。
- **ガード `when`**: パターンに追加の条件を付けます。`is_list(In)` は、`In` がリストかどうかを確かめます。
- **`erlang:error/2`**: 想定外の引数で例外を起こします。`badarg` は「引数が不正」という意味です。

## 何をしているか

### 1. 通常の場合は、先頭に積むだけ

```erlang:line-numbers=289
in(X, {In,Out}) when is_list(In), is_list(Out) ->
    {[X|In],Out};
```

`Out` が空でないとき、または `In` が 2 要素以上のときは、この節に一致します。`[X|In]` で `In` の先頭に新しい要素を付けます。`Out` はそのまま残ります。

例として、空のキューに `a`、`b`、`c` の順で `in/2` を呼ぶと、`In` は `[c, b, a]` の順になります。新しい要素ほど先頭に来ます。

### 2. 特別な場合は、`In` を `Out` に回す

```erlang:line-numbers=287
in(X, {[_]=In,[]}) ->
    {[X], In};
```

`Out` が空で、`In` がちょうど 1 要素 `[Y]` のときは、この節に一致します。戻り値は `{[X], In}` です。新しい要素 `X` が `In` に入り、古い `Y` は `Out` の側に移ります。

`Out` が空のまま `In` に積み続けると、次に取り出すときに `In` 全体を反転させる手間がかかります。1 要素のときだけ先に `Out` へ移しておけば、取り出しは `Out` の先頭を読むだけで済みます。

### 3. 引数が不正なとき

```erlang:line-numbers=291
in(X, Q) ->
    erlang:error(badarg, [X,Q]).
```

どちらの節にも一致しなければ、`erlang:error(badarg, [X, Q])` で例外を起こします。`Q` が 2 本のリストの組でない場合などが該当します。

## ここがすごい

### 追加は O(1)、反転は必要になるまで遅らせる

Erlang のリストは先頭への追加が速く、末尾への追加は全体をコピーする必要があります。そのため、キューの末尾に新しい要素を足す操作を、`In` の先頭への追加に置き換えています。

一方、取り出し側の `Out` は、必要になったときにだけ `In` を反転して作ります。追加と取り出しの両方を、ならし計算量で O(1) に近づけるための設計です。

### 「1 要素だけ」の特別扱い

`Out` が空の状態でも取り出せるように、1 要素のときだけ `Out` に移します。この 1 行の節がなければ、キューの状態によっては取り出しのたびに大きなリストを反転することになります。
「普通の場合は単純に、ただし空の `Out` を作らない」という割り切りが、この関数の要点です。

## まとめ

- 不変データで待ち行列を作るときは、2 本のリストで「入れる側」と「取り出す側」を分けると効率が良くなります。
- 新しい要素は `In` の先頭に積むだけなので、追加は速く行えます。
- 取り出す側を空にしないよう、1 要素の場合を特別扱いしています。
