## ひとことで

`lists:subtract/2` は、一つ目のリストから、二つ目のリストの要素を取り除きます。
取り除き方は、要素の値ごとに一つずつです。二つ目のリストに同じ値が一つあれば、一つ目のリストの同じ値も一つだけ消えます。

## コード

```erlang:line-numbers=275
subtract(L1, L2) -> L1 -- L2.
```

## 前提知識

- **`--` 演算子**: 左のリストから、右のリストの要素を一つずつ取り除く演算子です。Erlang の標準の演算子です。
- **リストの重複**: リストには同じ値が何回も入れられます。`--` は、その回数を一対一で扱います。
- **同じ値の判定**: `--` は、要素が完全に一致するかを比べます。型が違えば、別の値として扱われます。
- **`lists:subtract/2`**: `--` の名前付きの呼び出しです。関数として渡したいときに使えます。

## 何をしているか

### 1. 本体は、演算子の一行だけ

```erlang:line-numbers=275
subtract(L1, L2) -> L1 -- L2.
```

`L1 -- L2` は、`L1` から、`L2` の要素を左から順に一つずつ取り除きます。
たとえば、`[1, 2, 2, 3]` から `[2]` を引くと、`2` は一つだけ消えます。結果は `[1, 2, 3]` です。

### 2. 引かれない値は残る

`L2` に無い値は、`L1` にそのまま残ります。`L2` の値が `L1` に無いときは、何も起きません。

## ここがすごい

### 関数の中身を、演算子に任せる

`subtract/2` は、新しい処理を書いていません。`--` の一行で、集合の差に近い操作を表しています。
同じ仕事を、自分で再帰で書く必要がありません。読み手は、`--` の意味を覚えれば、この関数もすぐに理解できます。

### 重複を一対一で消す

集合の差と違い、`--` は、同じ値の数を数えて消します。
`[1, 1, 2]` から `[1]` を引くと、`1` は一つ消えて、`[1, 2]` が残ります。重複のあるリストで、回数を正しく扱うための性質です。

### 型と値の一致を使う

比べるのは、値が完全に一致するかです。`1` と `1.0` は、Erlang では等しいとは限りません。
数の型の違いで、消えるかどうかが変わる点は、使うときに注意が必要です。

### 引く順番は結果に影響しない

同じ値を消す個数が決まれば、どの位置の値が消えても、並びの見た目は同じです。
ただし、同じ値でも位置が違えば、区別されない点に注意してください。

## まとめ

`lists:subtract([1, 2, 2, 3], [2])` は、`[1, 2, 3]` を返します。
同じ `2` が一つだけ消えて、残りの `2` は残るところがポイントです。
