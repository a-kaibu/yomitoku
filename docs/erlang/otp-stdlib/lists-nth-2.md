## ひとことで

`lists:nth/2` は、リストの `N` 番目の要素を返します。番号は `1` から数えます。
リストは先頭からしか辿れないので、`N` の値だけ先頭を捨てながら進み、目的の位置に来たら取り出します。

## コード

```erlang:line-numbers=318
nth(1, [H|_]) -> H;
nth(N, [_|_]=L) when is_integer(N), N > 1 ->
    nth_1(N, L).

nth_1(1, [H|_]) -> H;
nth_1(N, [_|T]) ->
    nth_1(N - 1, T).
```

## 前提知識

- **1 から数える**: `nth(1, L)` は先頭の要素です。`0` 番目は存在しないので、この関数の節には当たりません。
- **リストの先頭からの移動**: リストは、先頭の要素と残りに分けることでしか進めません。
- **補助関数 `nth_1/2`**: `N` を一つずつ減らして、先頭を捨てていく関数です。
- **負の番号**: 範囲外の番号は、どの節にも当たりません。呼び出しは失敗します。

## 何をしているか

### 1. N が 1 なら、先頭が答え

```erlang:line-numbers=318
nth(1, [H|_]) -> H;
```

`N` が 1 のとき、先頭の要素 `H` がそのまま答えです。

### 2. N が 2 以上なら、補助関数に任せる

```erlang:line-numbers=319
nth(N, [_|_]=L) when is_integer(N), N > 1 ->
    nth_1(N, L).
```

`N` が 1 より大きいときは、リスト全体を `nth_1/2` に渡します。ガードで、整数であることも確かめています。

### 3. N が 1 になるまで、先頭を捨てる

```erlang:line-numbers=322
nth_1(1, [H|_]) -> H;
nth_1(N, [_|T]) ->
    nth_1(N - 1, T).
```

`nth_1/2` は、`N` が 1 なら先頭を答えとして返します。
そうでなければ、先頭を捨てて、`N - 1` と残りのリストを使って続けます。

## ここがすごい

### 数えながら、リストを前に進める

リストには、添字で直接アクセスできません。
この関数は、番号を一つずつ減らし、同時にリストの先頭を一つずつ捨てます。番号と位置を、同じ回数だけ進めるので、ずれが起きません。

### 答えになる位置を、節で表す

番号が 1 の節は、ちょうど目的の位置を表します。
その節の戻り値が、そのまま答えになります。終わりの条件を、パターンマッチで書いています。

### 範囲外は、失敗で知らせる

リストが `N` 個より短いときは、先頭を捨てすぎて、空のリストに当たります。
空のリストに対応する節は無いので、呼び出しは失敗します。範囲外の番号を、わざわざ特別な値で返していません。

### 番号と位置を同じだけ進める

`N` が一つ減るたびに、リストの先頭が一つ捨てられます。二つの数が、必ず同じ回数だけ動きます。
そのため、残りの番号が 1 になったときには、目的の要素がちょうど先頭に来ています。この関係が、関数全体の正しさを支えています。

## まとめ

`lists:nth(2, [a, b, c])` は、`b` を返します。
`lists:nth(5, [a, b, c])` は、リストが短いので、失敗します。
