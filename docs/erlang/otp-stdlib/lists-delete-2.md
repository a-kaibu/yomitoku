## ひとことで

`lists:delete/2` は、リストから `Item` と一致する要素を一つだけ取り除きます。
同じ値が複数あっても、先頭に近い最初の一つだけが消えます。一致する要素が無ければ、リストは元のままです。

## コード

```erlang:line-numbers=726
delete(Item, [Item|Rest]) -> Rest;
delete(Item, [H|Rest]) -> 
    [H|delete(Item, Rest)];
delete(_, []) -> [].
```

## 前提知識

- **一致の判定**: 関数の頭でパターンに同じ変数 `Item` を使うと、両方の値が完全に一致したときだけ、その節が選ばれます。
- **`[Item|Rest]`**: 先頭の要素が `Item` と一致する場合にマッチします。
- **`[H|Rest]`**: 先頭の要素を `H` に受けて、残りを進めるときに使います。
- **空のリスト `[]`**: 消すものが無いので、空のリストを返します。

## 何をしているか

### 1. 先頭が一致したら、先頭だけを捨てる

```erlang:line-numbers=726
delete(Item, [Item|Rest]) -> Rest;
```

先頭の要素が `Item` と一致したら、その要素を捨てて、残りの `Rest` をそのまま返します。
ここで、消す作業は終わりです。後ろの要素は、一つも変わりません。

### 2. 一致しなければ、先頭を残して進む

```erlang:line-numbers=727
delete(Item, [H|Rest]) -> 
    [H|delete(Item, Rest)];
```

先頭が `Item` と違えば、先頭の `H` を結果に残し、残りの `Rest` の中から `Item` を消す処理を続けます。

### 3. 空になったら、空を返す

```erlang:line-numbers=729
delete(_, []) -> [].
```

リストが空になったら、消すものは見つからなかったので、空のリストを返します。

## ここがすごい

### 消すのは最初の一つだけ

`delete/2` は、一致した最初の要素で、消す作業を止めます。
後ろに同じ値があっても、それらは残ります。`lists:subtract/2` が、同じ値の数だけ消すのに対して、`delete/2` は一つだけです。違いは、この節の形が決めています。

### 一致の節を先に書く

関数の最初の節が、一致した場合だけに当たります。
二つ目の節は、それ以外のすべてに当たります。読み手は、上から順に読むと、「見つけたら消す、見つけるまで残す」という流れが分かります。

### 見つからない場合も、同じ形を保つ

一致が無い場合は、リスト全体が新しく組み直されるだけで、中身は変わりません。
見つからないことを、特別な値で知らせていません。結果は、いつも同じ型のリストです。

### 一致の判定は、完全な一致で行う

パターンに同じ変数 `Item` を使うと、比べるのは「値が完全に一致するか」です。
たとえば、`1` と `1.0` は、この判定では一致しません。数の型まで含めて消したいときは、この関数の仕組みをそのまま使えます。

## まとめ

`lists:delete(b, [a, b, c, b])` は、`[a, c, b]` を返します。
最初の `b` だけが消えて、後ろの `b` は残ります。
