## ひとことで

`queue:out/1` は、キューの先頭の要素を取り出します。戻り値は `{{value, V}, 残りのキュー}` か、空のとき `{empty, Q}` です。
取り出す側のリスト `Out` が空になったときに、入れる側のリスト `In` を反転して補う処理が、この関数の中心です。

## コード

```erlang:line-numbers=341
out({[],[]}=Q) ->
    {empty,Q};
out({[V],[]}) ->
    {{value,V},{[],[]}};
out({[Y|In],[]}) ->
    [V|Out] = lists:reverse(In, []),
    {{value,V},{[Y],Out}};
out({In,[V]}) when is_list(In) ->
    {{value,V},r2f(In)};
out({In,[V|Out]}) when is_list(In) ->
    {{value,V},{In,Out}};
out(Q) ->
    erlang:error(badarg, [Q]).
```

## 前提知識

- **`{value, V}` と `empty`**: キューから取り出せたかどうかを、戻り値の形で伝えます。Erlang では、このように結果を値で表すことがよくあります。
- **`lists:reverse/2`**: リストを反転します。第 2 引数は、反転した結果を後ろにつなぐ先の尾です。`lists:reverse(L, [])` は、`L` を反転したものになります。
- **`r2f/1`**: 同じ `queue` モジュールにある補助関数です。今回のコードでは、詳しくは説明しません。`In` を半分ずつに分けて、取り出し側と入れ側を作ります。
- **パターンマッチの順番**: 関数の節は上から順に試されます。最初に一致した節が使われます。

## 何をしているか

### 1. 空のキュー

```erlang:line-numbers=341
out({[],[]}=Q) ->
    {empty,Q};
```

`{[], []}` のとき、キューは空です。`{empty, Q}` を返します。

### 2. 要素が 1 つだけのキュー

```erlang:line-numbers=343
out({[V],[]}) ->
    {{value,V},{[],[]}};
```

`In` に 1 つだけ要素があり、`Out` が空のときです。その要素を返し、残りは空のキュー `{[], []}` になります。

### 3. 取り出し側が空で、入れ側に要素が多いとき

```erlang:line-numbers=345
out({[Y|In],[]}) ->
    [V|Out] = lists:reverse(In, []),
    {{value,V},{[Y],Out}};
```

`Out` が空で、`In` に 2 つ以上の要素があるときです。`In` の先頭 `Y` は、いちばん新しい要素なので残します。`In` の残りを `lists:reverse` で反転すると、いちばん古い要素が先頭に来ます。その先頭を `V` として取り出します。

例えば `In` が `[3, 2, 1]`（1 が最も古い）のとき、`Y` は `3`、残りの `[2, 1]` を反転して `[1, 2]` にします。`V` は `1` で、`Out` は `[2]` になります。

### 4. 取り出し側に要素が 1 つだけあるとき

```erlang:line-numbers=348
out({In,[V]}) when is_list(In) ->
    {{value,V},r2f(In)};
```

`Out` が `[V]` のときは、`V` を返します。残りは `In` を `r2f/1` で分け直して作ります。`Out` が空になったあとも、次の取り出しの手間をならすための処理です。

### 5. 取り出し側に要素があるとき

```erlang:line-numbers=350
out({In,[V|Out]}) when is_list(In) ->
    {{value,V},{In,Out}};
```

`Out` の先頭 `V` を取り出すだけです。`In` は変えずに、`Out` の残りとそのまま組にします。最も普通の場合で、いちばん速く終わります。

### 6. どれにも一致しないとき

```erlang:line-numbers=352
out(Q) ->
    erlang:error(badarg, [Q]).
```

引数が正しいキューの形でないときは、`badarg` の例外を起こします。

## ここがすごい

### 反転の回数を、ならし計算量で抑える

`In` の要素を 1 つずつ `Out` へ移すと、取り出しは `O(1)` になります。しかし、取り出しのたびに反転すると、要素数に比例する時間がかかります。
この関数は、`Out` が空になったときにまとめて反転し、取り出しの多くを `Out` の先頭を読むだけで済ませます。反転の代償を、後の複数の取り出しに分散させているわけです。

### 半分ずつ分け直す

4 番目の節で `r2f/1` を使うのは、`Out` に要素が 1 つだけ残ったときです。このとき `In` が大きいままだと、次に `Out` が空になったとき、大きなリストを丸ごと反転することになります。
`r2f/1` は `In` を半分に分け、一方を `Out` 側として取り出せる形にします。大きな反転を避けて、取り出しの時間を平均で一定に近づけています。

## まとめ

- 2 本のリストのキューは、取り出す側が空になったときだけ、入れる側をまとめて反転します。
- 反転の代償は、後続の複数の取り出しで平均化されます（ならし計算量）。
- 残りが 1 つになったとき分け直すことで、次の大きな反転を防いでいます。
