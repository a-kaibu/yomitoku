## ひとことで

`dict:from_list/1` は、`{Key, Value}` の組のリストから、辞書を作ります。
リストの先頭から順に、一つずつ辞書に入れていきます。同じキーがあれば、後から入れた値で上書きされます。

## コード

```erlang:line-numbers=171
from_list(L) ->
    lists:foldl(fun ({K,V}, D) -> store(K, V, D) end, new(), L).
```

## 前提知識

- **dict（辞書）**: キーで値を探すためのデータ構造です。キーの値を、ハッシュで格納先に振り分けます。
- **`store/3`**: 辞書に一つのキーと値を入れる関数です。同じキーがあれば、値を書き換えます。
- **`lists:foldl/3`**: リストの要素を一つずつ関数に渡し、途中の結果を積み上げる関数です。
- **`new/0`**: 空の辞書を作る関数です。

## 何をしているか

### 1. 空の辞書から始めて、組を入れていく

```erlang:line-numbers=171
from_list(L) ->
    lists:foldl(fun ({K,V}, D) -> store(K, V, D) end, new(), L).
```

`new()` で空の辞書を作り、`lists:foldl/3` の初期値にします。
リストの組を先頭から順に取り出し、`store/3` で辞書に入れていきます。途中の辞書が、次の入力になります。

## ここがすごい

### 作り方を、畳み込みで一行にする

辞書の作成は、「空から始めて、一つずつ入れる」という形です。
`lists:foldl/3` を使うと、その流れを一行で書けます。途中の辞書を変数に入れて持ち回る必要がありません。

### 同じキーは、後ろが勝つ

`store/3` は、同じキーがあれば値を書き換えます。
そのため、リストの後ろにある組が、前の組を上書きします。重複を前もって取り除かなくても、結果は一つのキーにつき一つの値になります。

### 辞書の中身は、store が決める

この関数は、辞書の内部の形を知りません。
入れる処理はすべて `store/3` に任せています。辞書の作り方が変わっても、この関数の書き方は変えなくて済みます。

### 空の辞書から始めるので、入力が空でも動く

入力のリストが空なら、畳み込みは一度も `store/3` を呼びません。結果は、最初に作った空の辞書です。
特別な場合の分岐を書かなくても、空のリストが自然に空の辞書になります。

### 同じキーの扱いは、畳み込みの順番で決まる

畳み込みは、リストを先頭から順に進みます。そのため、同じキーが並んだときは、後に現れた組が最後に `store/3` されます。
「後ろが勝つ」という結果は、この順番から来ています。順番を逆にすれば、結果も変わります。

## まとめ

`dict:from_list([{a, 1}, {b, 2}, {a, 3}])` は、キー `a` の値が `3` の辞書を返します。
`dict:find(a, Dict)` で、`{ok, 3}` が得られます。
