## ひとことで

`lists:max/1` は、リストの中で一番大きい要素を返します。
先頭の要素を仮の最大値とし、残りの要素を一つずつ比べて、大きいものが見つかれば入れ替えます。最後に残った値が、最大値です。

## コード

```erlang:line-numbers=638
max([H|T]) -> max(T, H).

max([H|T], Max) when H > Max -> max(T, H);
max([_|T], Max)              -> max(T, Max);
max([],    Max)              -> Max.
```

## 前提知識

- **仮の最大値（`Max`）**: 比べている途中で、一番大きいと分かっている値です。
- **比較演算子 `>`**: Erlang の項の比較です。数同士なら、大小で比べられます。
- **補助関数 `max/2`**: 先頭の仮の最大値 `Max` と、残りのリストを引数に持つ関数です。
- **空のリスト**: 最大値を決められないので、`max/1` には空のリストを渡せません。

## 何をしているか

### 1. 先頭を仮の最大値にする

```erlang:line-numbers=638
max([H|T]) -> max(T, H).
```

`max/1` は、先頭の要素 `H` を仮の最大値として、残りの `T` と一緒に `max/2` に渡します。

### 2. 大きい要素が見つかれば、入れ替える

```erlang:line-numbers=640
max([H|T], Max) when H > Max -> max(T, H);
```

残りの先頭 `H` が、いまの `Max` より大きければ、`H` を新しい `Max` にして続けます。

### 3. そうでなければ、そのまま続ける

```erlang:line-numbers=641
max([_|T], Max)              -> max(T, Max);
```

`H` が `Max` 以下なら、`Max` は変えずに、残りのリストを調べます。

### 4. 残りが無くなったら、最大値を返す

```erlang:line-numbers=642
max([],    Max)              -> Max.
```

リストが空になったら、持っている `Max` が最大値です。それを結果として返します。

## ここがすごい

### 一回の走査で答えを決める

最大値を探すには、リストを一度だけ先頭から辿れば十分です。
ソートしてから先頭を取る方法より、要素の順番を整える作業が要りません。

### 仮の値を、引数で持ち回る

`Max` を引数に持たせることで、途中の状態を、関数の中に隠さずに済みます。
最後の節が `Max` を返すだけなので、結果は読み手にとって明らかです。

### 空のリストは、わざと扱わない

`max/1` の節は、先頭の要素が必ずあることを前提にしています。空のリストを渡すと、どの節にも当たらず、呼び出しが失敗します。
最大値は、比べる相手がいないと決められません。その事実を、節の形がそのまま表しています。

### 比べる回数は、要素の数より一つ少ない

先頭を仮の最大値にするので、残りの要素の数だけ比べれば済みます。
要素が `N` 個なら、比べるのは `N - 1` 回です。最大値を探すための、最も少ない比較の回数です。

## まとめ

`lists:max([3, 7, 2])` は、`7` を返します。
空のリスト `lists:max([])` は、失敗します。
