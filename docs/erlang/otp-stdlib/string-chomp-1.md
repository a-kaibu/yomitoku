## ひとことで

`string:chomp/1` は、文字列の末尾にある改行を取り除いた文字列を返します。
ファイルの一行を読み込んだあとに、末尾の改行だけを消したいときに使います。改行の形は、Windows の `\r\n` と Unix の `\n` の両方を扱えます。

## コード

```erlang:line-numbers=554
chomp(Str) ->
    trim(Str, trailing, [[$\r,$\n],$\n]).
```

## 前提知識

- **`trim/3`**: 文字列の端から、指定の文字列を取り除く関数です。`Dir` が `trailing` のときは、末尾だけを対象にします。
- **改行 `\n` と `\r\n`**: `\n` は改行の文字です。Windows の改行は、`\r`（復帰）と `\n` の二文字の並びです。
- **`$\r` と `$\n`**: 文字 `\r` と `\n` の、Erlang での書き方です。`$` は、文字の一つ書きを表します。
- **区切りのリスト**: `[[$\r,$\n],$\n]` は、「`\r\n` の並び」と「`\n`」の二つの候補を並べたリストです。

## 何をしているか

### 1. 末尾だけを対象に、改行の候補を渡す

```erlang:line-numbers=554
chomp(Str) ->
    trim(Str, trailing, [[$\r,$\n],$\n]).
```

`chomp/1` は、`trim/3` を `trailing` の指定で呼びます。取り除く候補は、`\r\n` と `\n` の二つです。
`trim` は、文字列の末尾が候補のどれかに一致すれば、その部分を取り除きます。結果として、末尾の改行だけが消え、本文の文字は残ります。

## ここがすごい

### 改行の形を、データとして渡す

改行の判定を、関数の中で `if` や正規表現で書く必要がありません。
取り除きたい文字列の候補を、リストとして `trim/3` に渡すだけです。候補を増やしたいときも、リストに一つ足せば済みます。

### Windows と Unix の両方を、一つの関数で

`\r\n` を先に、`\n` を後に並べています。候補は、どちらも末尾に一致する可能性があるので、両方を用意しておきます。
読み手は、候補のリストを見れば、どの改行が消えるかをすぐに把握できます。

### 本文の中の改行は残る

`trailing` は、末尾だけを対象にします。
文字列の途中にある改行は、残ります。一行だけを扱うときに、安心して使える性質です。

### 改行が無い文字列は、そのまま返る

末尾に改行が無ければ、取り除くものがありません。その場合は、元の文字列と同じ内容が返ります。
ファイルの最後の行のように、改行の無い行が混ざっていても、安心して同じ関数を使えます。

## まとめ

`string:chomp("abc\n")` は、`"abc"` を返します。
`string:chomp("abc\r\n")` も、同じく `"abc"` を返します。
