## ひとことで

`lists:ukeymerge/3` は、二つのリストを、タプルの指定した位置の値の順で一つにまとめます。
どちらのリストも、その位置の値で並んでいる前提です。同じキーを持つ要素が両方にあれば、一つ目のリストの要素を残します。

## コード

```erlang:line-numbers=1739
ukeymerge(Index, L1, L2) when is_integer(Index), Index > 0 ->
    ukeymerge_1(Index, L1, L2).
```

## 前提知識

- **キー位置**: タプルの中で、比べるための値が入っている位置です。`Index` で、先頭から何番目かを指定します。
- **マージ（併合）**: 並んだ二つのリストを、一つの並んだリストにまとめる処理です。両方の先頭を比べて、小さい方を先に取ります。
- **`element/2`**: タプルの指定した位置の要素を取り出す関数です。
- **`ukeymerge` の `u`**: 同じキーの要素を、一つにまとめるという意味です。`u` が付く関数は、重複を取り除きます。

## 何をしているか

### 1. 引数を確かめて、本体へ渡す

```erlang:line-numbers=1739
ukeymerge(Index, L1, L2) when is_integer(Index), Index > 0 ->
    ukeymerge_1(Index, L1, L2).
```

`Index` が正の整数であるときだけ、`ukeymerge_1/3` を呼びます。
位置が `0` 以下なら、この節には当たらず、例外になります。

### 2. 両方の先頭からキーを取り出す

```erlang:line-numbers=1742
ukeymerge_1(Index, [H1 | T1], [_|_]=T2) ->
    E1 = element(Index, H1),
    M = ukeymerge2_2(Index, T1, E1, H1, T2, []),
```

一つ目のリストの先頭 `H1` から、キー `E1` を取り出します。そして、残りの処理に、二つ目のリストと一緒に渡します。
途中の結果は、`ukeymerge2_2/6` が積み上げ、最後に `lists:reverse/2` で順番を戻します。

### 3. 順番に小さい方から取る

キーの比較で、より小さい方の要素を結果に入れ、そのリストの先頭を進めます。
同じキーのときは、一つ目のリストの要素を残し、二つ目の方を捨てます。この規則が、「一つ目が優先される」という意味です。

## ここがすごい

### 並んでいる前提を、速さの根拠にする

二つのリストを一度ずつ読むだけで、結果が作られます。
並べ替えを毎回し直すより、ずっと少ない比較で済みます。並んでいることを前提にしているので、この速さが出ます。

### 重複を、一箇所で決める

同じキーの要素が両方にあるとき、どちらを残すかを、この関数は決めています。
呼び出し側は、「一つ目が優先」という規則を覚えておけば、結果を予想できます。

### 積み上げて、最後に反転する

併合の途中では、結果を先頭に積む方が簡単です。
そのため、最後に `lists:reverse/2` で、順番を正しい向きに戻しています。この形は、リストを作る Erlang のコードで、よく使われる書き方です。

## まとめ

`lists:ukeymerge(1, [{a, 1}, {c, 3}], [{b, 2}, {c, 9}])` は、キーの順で `a`、`b`、`c` が並んだリストを返します。
`c` は両方にありますが、一つ目のリストの `{c, 3}` が残ります。
