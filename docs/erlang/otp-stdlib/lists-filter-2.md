## ひとことで

`lists:filter/2` は、リストの要素のうち、述語 `Pred` が `true` を返すものだけを集めて、新しいリストを返します。
元のリストの順番は、そのまま保たれます。

## コード

```erlang:line-numbers=2526
filter(Pred, List) when is_function(Pred, 1) ->
    [ E || E <- List, Pred(E) ].
```

## 前提知識

- **述語（`Pred`）**: 要素を一つ受け取り、`true` か `false` を返す関数です。
- **内包表記（list comprehension）**: `[式 || 要素 <- リスト, 条件]` の形で、リストから条件に合う要素を取り出して、新しいリストを作る書き方です。
- **ガード付きの条件 `Pred(E)`**: 内包表記の条件は、`true` のときだけ、その要素が結果に入ります。
- **`is_function(Pred, 1)`**: 関数の引数の数を確かめる部分です。

## 何をしているか

### 1. 述語が一引数の関数であることを確かめる

```erlang:line-numbers=2526
filter(Pred, List) when is_function(Pred, 1) ->
```

`filter/2` は、`Pred` が引数を一つ取る関数であることを、ガードで確かめます。違えば、呼び出しは失敗します。

### 2. 内包表記で、条件に合う要素を集める

```erlang:line-numbers=2527
    [ E || E <- List, Pred(E) ].
```

`E <- List` で、リストの要素を先頭から一つずつ取り出します。`Pred(E)` が `true` なら、その `E` を結果に入れます。
結果は、元のリストの順番を保ったまま、条件を満たす要素だけを並べたリストです。

## ここがすごい

### 一行で、絞り込みと順番の保存を表す

内包表記は、要素の取り出し、条件の判定、結果の組み立てを、一つの式にまとめます。
一つずつ再帰で書くより、読み手は「何を取り出すか」を一度で読み取れます。

### 順番を変えない

`filter` は、結果の順番を、元のリストと同じに保ちます。
そのため、並んでいることに意味があるリストでも、安心して絞り込めます。並べ替えが要る場合は、別に `sort` を使います。

### 残りと除外を分けない

`filter` は、条件を満たすものを集めるだけです。条件を満たさないものを捨てる処理は、暗黙に起きます。
もし、条件を満たさない方を集めたいなら、`Pred` を否定した述語を渡します。`lists:partition/2` は、両方の結果を一度に作ります。

### 空のリストと、全部が落ちる場合

元のリストが空なら、結果も空です。条件を満たす要素が一つも無い場合も、結果は空のリストになります。
どちらの場合も、呼び出し側は、結果の長さを見て「該当なし」を判断できます。例外を使わないので、後の処理を書きやすくなります。

## まとめ

`lists:filter(fun(X) -> X rem 2 =:= 0 end, [1, 2, 3, 4])` は、`[2, 4]` を返します。
偶数だけが、元の順番のまま残ります。
