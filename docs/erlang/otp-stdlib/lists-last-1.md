## ひとことで

`lists:last/1` は、リストの最後の要素を返します。
空のリストには最後の要素が無いので、呼び出しは失敗します。リストの長さを先に数えずに、一度の走査で答えを出します。

## コード

```erlang:line-numbers=467
last([E|Es]) -> last(E, Es).

last(_, [E|Es]) -> last(E, Es);
last(E, []) -> E.
```

## 前提知識

- **末尾の要素**: リストの一番後ろにある要素です。リストは先頭からしか辿れないので、末尾を知るには全体を進む必要があります。
- **引数に持つ「直前の要素」**: 補助関数 `last/2` は、いま見ている要素を `E` として持ち回ります。次の要素が来れば、`E` はその値に置き換わります。
- **空のリスト `[]`**: 要素が一つも無いので、この関数の節には当たりません。
- **パターン `[E|Es]`**: 先頭の要素 `E` と残り `Es` に分けます。

## 何をしているか

### 1. 先頭を、仮の最後の要素にする

```erlang:line-numbers=467
last([E|Es]) -> last(E, Es).
```

`last/1` は、先頭の要素 `E` を仮の最後として、残りの `Es` と一緒に `last/2` に渡します。

### 2. 残りがあれば、より後ろの要素で置き換える

```erlang:line-numbers=469
last(_, [E|Es]) -> last(E, Es);
```

残りに要素があれば、その先頭を新しい仮の最後にします。今の `E` は捨てて、残りの `Es` を調べます。

### 3. 残りが空になったら、いま持っている要素が答え

```erlang:line-numbers=470
last(E, []) -> E.
```

残りが空になれば、持っている `E` が最後の要素です。それを返します。

## ここがすごい

### 持ち回るのは、一つの値だけ

`last/2` は、いま見ている要素を一つだけ持ち回ります。
全部の要素を、リストに集めてから末尾を取るやり方より、メモリを使いません。必要なのは、直前に見た値だけです。

### 節の形で、終わりを判定する

`last/2` の二つの節は、残りが空かどうかで分かれます。
残りが空のときは、`E` を返す節に当たり、そうでなければ、もう一つの節で続けます。比較文を使わず、パターンマッチで終わりを表しています。

### 空のリストは、わざと扱わない

`last/1` は、先頭の要素があることを前提にしています。空のリストを渡すと、どの節にも当たらず、呼び出しは失敗します。
最後の要素は、そもそも無いので、失敗が正しい結果です。

### 後ろから進む処理との違い

末尾の要素を後ろから取る操作は、単方向のリストでは、そのままでは書けません。
先頭から一度進むだけで答えが得られるのは、この関数が「今の答えの候補」を常に持っているからです。

## まとめ

`lists:last([1, 2, 3])` は、`3` を返します。
空のリスト `lists:last([])` は、失敗します。
