## ひとことで

`lists:join/2` は、リストの要素と要素の間に、区切りの値を挟んだリストを返します。
たとえば、文字列のリストに `", "` を挟めば、カンマで区切った文字列の材料になります。最初と最後には、区切りを付けません。

## コード

```erlang:line-numbers=2904
join(Sep, [H|T]) -> [H|join_prepend(Sep, T)].

join_prepend(_Sep, []) -> [];
```

## 前提知識

- **区切り（`Sep`）**: 要素の間に挟む値です。文字列でも、数でも、どんな値でも構いません。
- **`[H|join_prepend(...)]`**: 先頭の要素 `H` は、そのまま結果の先頭に置き、残りを補助関数で作ります。
- **`join_prepend/2`**: 残りの要素の前に、区切りと要素の組を付けていく補助関数です。
- **空のリスト**: 要素が一つもない場合、この関数の節には当たりません。`join/2` は、要素が少なくとも一つあるリストを前提にしています。

## 何をしているか

### 1. 先頭の要素はそのまま置く

```erlang:line-numbers=2904
join(Sep, [H|T]) -> [H|join_prepend(Sep, T)].
```

`join/2` は、先頭の要素 `H` の前には区切りを置かず、結果の先頭に置きます。残りの `T` は、補助関数に任せます。

### 2. 残りが空なら、何も足さない

```erlang:line-numbers=2905

```

残りの要素が無ければ、区切りを足す必要はありません。空のリストを返します。

### 3. 残りの要素の前に、区切りと要素を付ける

```erlang:line-numbers=2906
join_prepend(_Sep, []) -> [];
```

残りの先頭 `H` の前に、区切り `Sep` を付けます。その後ろには、さらに残りの要素について、同じ補助関数を続けます。
この形で、要素と要素の間に、区切りが一つずつ入ります。

## ここがすごい

### 先頭だけ特別扱いする

区切りは、要素の「間」にだけ入ります。最初の要素の前と、最後の要素の後には入りません。
この関数は、先頭の要素を `join` の節で別に置き、残りだけを補助関数に渡します。そのため、区切りの位置を、節の形で正しく決められます。

### 前に付ける形で作る

補助関数は、「区切りと要素」の組を、残りの結果の前に付けていきます。
末尾に付け足すと、リストを何度も辿ることになります。前に付ける形なら、一度の走査で結果が組み上がります。

### 区切りの型を選ばない

区切りは、文字列のリストに対しても、数のリストに対しても使えます。
この関数は、要素の型を見ていません。値を挟むだけなので、どんなリストにも同じ形で使えます。

## まとめ

`lists:join(", ", ["a", "b", "c"])` は、`["a", ", ", "b", ", ", "c"]` を返します。
この結果を `lists:flatten/1` でまとめると、`"a, b, c"` になります。
