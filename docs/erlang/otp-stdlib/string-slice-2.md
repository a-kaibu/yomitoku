## ひとことで

`string:slice/2` は、文字列の先頭から、指定した数の文字を取り出します。
数は、書記素（見た目の一文字）の単位で数えます。文字列の方が短ければ、あるだけを返します。

## コード

```erlang:line-numbers=377
slice(CD, N) when is_integer(N), N >= 0 ->
    case slice_l0(CD, N) of
        [] when is_binary(CD) -> <<>>;
        Res -> Res
    end.
```

## 前提知識

- **書記素（grapheme）**: 見た目の一文字の単位です。一つの書記素が、複数のコードポイントでできていることがあります。
- **`slice_l0/2`**: 指定した数だけ先頭から取り出す補助関数です。この記事では中身には踏み込みません。
- **ガード `N >= 0`**: 取り出す数が、負の値でないことを、節の入口で確かめています。
- **バイナリと文字列**: Erlang の文字列は、リストかバイナリで表せます。どちらで渡されたかで、空の値の形が違います。

## 何をしているか

### 1. 数が正しいかを、先に確かめる

```erlang:line-numbers=377
slice(CD, N) when is_integer(N), N >= 0 ->
```

`N` が整数で、`0` 以上であるときだけ、この節が選ばれます。
負の数や、整数でない値は、この節に当たりません。

### 2. 先頭から取り出す

```erlang:line-numbers=378
    case slice_l0(CD, N) of
```

`slice_l0/2` に、文字列 `CD` と数 `N` を渡し、取り出した結果を `case` で受けます。

### 3. 空の結果の形を、入力に合わせる

```erlang:line-numbers=379
        [] when is_binary(CD) -> <<>>;
        Res -> Res
```

結果が空の `[]` で、入力がバイナリのときは、空のバイナリ `<<>>` を返します。
それ以外の場合は、取り出した結果をそのまま返します。

## ここがすごい

### 数えるのは、見た目の単位

文字列の長さを、コードポイントの数で数えると、絵文字や結合文字で数が狂います。
この関数は、書記素の単位で数えるので、人が見た文字数と一致しやすくなります。

### 空の値の形を、入力に合わせる

空のリストと空のバイナリは、Erlang では違う値です。
入力がバイナリなのに、空のリストを返すと、呼び出し側の後続の処理で型が合わなくなります。この関数は、その食い違いを、一箇所で防いでいます。

### 結果を一度 case で受ける

`slice_l0/2` の結果を変数に入れてから、`case` で形を確かめています。
戻り値の形を決める処理が、この一つの `case` にまとまっています。

### 足りないときは、長さを確かめずに済む

`string:slice/2` は、文字列の長さを先に数えません。
`slice_l0/2` が、取り出せるだけ取り出して、足りなければ残りを返します。呼び出し側は、文字列が十分に長いかを、自分で確かめる必要がありません。
この性質は、長い文字列の先頭だけが欲しいときに効きます。文字列を最後まで走査せずに、必要な分だけ読めるからです。

### 空の結果は、型を保ったまま返す

入力が空だったり、数が `0` だったりしたときも、結果は入力と同じ種類の値になります。
リストならば `[]`、バイナリならば `<<>>` です。この約束があるので、後続の関数で型の違いによる失敗が起きにくくなります。

## まとめ

`string:slice("abcdef", 3)` は、`"abc"` を返します。
`string:slice("ab", 5)` は、足りない分を気にせず、あるだけの `"ab"` を返します。
