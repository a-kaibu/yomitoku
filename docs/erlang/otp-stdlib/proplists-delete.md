## ひとことで

`proplists:delete/2` は、プロパティリストから、キーに一致する項目をすべて取り除いた新しいリストを返します。
`verbose` のようなアトムの項目と、`{timeout, 100}` のようなタプルの項目の両方が対象です。

## コード

```erlang:line-numbers=363
delete(Key, [P | Ps]) ->
    if is_atom(P), P =:= Key ->
	    delete(Key, Ps);
       tuple_size(P) >= 1, element(1, P) =:= Key ->
	    delete(Key, Ps);
       true ->
	    [P | delete(Key, Ps)]
    end;
delete(_, []) ->
    [].
```

## 前提知識

- **プロパティリスト**: アトムやタプルを並べたリストです。
- **`tuple_size/1` と `element/2`**: タプルの大きさと、指定の位置の要素を調べます。
- **`[P | delete(Key, Ps)]`**: 残すべき項目 `P` を先頭に付け、残りの処理結果をつなぎます。
- **再帰で作る新しいリスト**: 元のリストは変えず、残す項目だけで新しいリストを作ります。

## 何をしているか

### 1. アトムの項目がキーと同じとき

```erlang:line-numbers=364
    if is_atom(P), P =:= Key ->
	    delete(Key, Ps);
```

項目がアトムで、キーと同じなら、その項目は捨てます。残りの項目だけを、同じ方法で処理します。

### 2. タプルの項目がキーと同じとき

```erlang:line-numbers=366
       tuple_size(P) >= 1, element(1, P) =:= Key ->
	    delete(Key, Ps);
```

項目が 1 つ以上の要素を持つタプルで、その 1 番目がキーと同じなら、これも捨てます。値が何であっても捨てる点に注意してください。

### 3. それ以外の項目

```erlang:line-numbers=368
       true ->
	    [P | delete(Key, Ps)]
```

キーと関係ない項目は、先頭に残します。残りを同じ方法で処理して、結果をつなぎます。

### 4. 空のリストのとき

```erlang:line-numbers=371
delete(_, []) ->
    [].
```

リストが空になったら、空のリストを返します。

## ここがすごい

### 書き方が違っても、同じ基準で取り除く

`verbose` と `{verbose, true}` は、同じ設定を表す違う書き方です。この関数は、どちらの形でも、キーが一致すれば取り除きます。
利用者は書き方を混ぜても、削除の結果を予測できます。

### 元の順番を保ったまま、残りを作る

残す項目は、元の順番のまま新しいリストに入ります。取り除く項目だけが、結果から消えます。
設定の順番に意味がある場合でも、残りの並びが崩れないので安心です。

同じキーが何個あっても、この関数は同じ 1 つの再帰で処理します。項目の数を数えたり、途中で止めたりする仕組みはありません。そのため、重複が多い設定でも、読み方は変わりません。

## まとめ

- 同じキーの項目を全部消すには、先頭から見て、一致しないものだけを残すと簡単に書けます。
- 書き方の違い（アトムかタプルか）を、同じ判定の中で扱うと、利用者の書き方に左右されません。
- 元の順番を保つ再帰は、設定の並びを読み書きするときに役立ちます。
