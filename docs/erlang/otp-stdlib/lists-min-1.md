## ひとことで

`lists:min/1` は、リストの中で一番小さい要素を返します。
空のリストには、小さい要素がありません。そのため、空のリストを渡すと、例外になります。

## コード

```erlang:line-numbers=614
min([H|T]) -> min(T, H).

min([H|T], Min) when H < Min -> min(T, H);
min([_|T], Min)              -> min(T, Min);
min([],    Min)              -> Min. 
```

## 前提知識

- **項の比較**: Erlang では、数、文字列、タプルなどを、一つの順序で比べられます。`<` は、その順序で比較します。
- **アキュムレータ**: 途中の結果を、引数として持ち回る形です。ここでは `Min` が、それにあたります。
- **ガード**: `when H < Min` のように、節の選択条件を書く仕組みです。

## 何をしているか

### 1. 最初の要素を、最小値の候補にする

```erlang:line-numbers=614
min([H|T]) -> min(T, H).
```

`min/1` は、先頭の要素 `H` を候補として、残りの `T` を `min/2` に渡します。
リストに要素が一つでもあれば、この節で始まります。

### 2. 新しい要素が小さければ、候補を入れ替える

```erlang:line-numbers=616
min([H|T], Min) when H < Min -> min(T, H);
```

先頭の `H` が、今の候補 `Min` より小さければ、`H` を新しい候補にします。残りの `T` を、同じ関数で読み続けます。

### 3. 小さくなければ、候補を残す

```erlang:line-numbers=617
min([_|T], Min)              -> min(T, Min);
```

`H` が `Min` 以上なら、候補は変えません。要素だけを捨てて、残りを読み続けます。

### 4. 読み終わったら、候補を返す

```erlang:line-numbers=618
min([],    Min)              -> Min. 
```

リストが空になったら、持ち回った `Min` を返します。この節は、`min/2` の最後の節です。

## ここがすごい

### 一度だけ読む

最小値を探す方法には、並べ替えてから先頭を取る方法もあります。
しかし、この関数は、リストを一回だけ読みます。並べ替えの手間がないので、要素数に対して、一直線に進む形になります。

### 候補を引数で持ち回る

途中の最小値を、再帰の引数として渡します。
関数の中で、変数の値を書き換える必要がありません。Erlang の値は変わらないという性質に、この形はよく合っています。

### 空の場合は、答えが無いと決める

`min/1` は、空のリストに対しては節を持っていません。
最小値が無い入力を、勝手な既定値で埋めず、例外として知らせます。呼び出し側は、空でないことを確かめてから使う必要があります。

### 比較の結果は、候補の更新にだけ使う

`H < Min` の比較は、候補を入れ替えるかどうかの判断にだけ使われます。
候補が変わらないときは、要素を捨てるだけで、次の要素に進みます。比較の回数は、要素の数と同じ程度に抑えられます。

## まとめ

`lists:min([3, 1, 2])` は、`1` を返します。
`lists:min([])` は、節に当たらないので、例外になります。
