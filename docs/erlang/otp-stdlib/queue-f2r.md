## ひとことで

`queue:f2r/1` は、取り出し側のリスト `F` を、入れ側と取り出し側の 2 本に分け直します。戻り値は `{入れ側, 取り出し側}` です。
前の記事の `r2f/1` が、入れ側から取り出し側を作るのに対して、こちらは取り出し側の一部を入れ側へ移す操作です。取り出し側が空になったとき、大きな反転を避けるのに使います。

## コード

```erlang:line-numbers=1303
f2r([]) ->
    {[],[]};
f2r([_]=F) ->
    {F,[]};
f2r([X,Y]) ->
    {[Y],[X]};
f2r(List) ->
    {FF,RR} = lists:split(length(List) div 2, List),
    {lists:reverse(RR, []),FF}.
```

## 前提知識

- **取り出し側（Out）**: 先頭から取り出す順番に、要素が並んでいます。
- **入れ側（In）**: 新しい要素が先頭に並んでいます。取り出すときは、反転して使います。
- **`lists:split/2`**: リストを、指定の位置で前後に分けます。
- **`lists:reverse/2`**: 反転して、後ろのリストにつなぎます。
- **空と 1 要素、2 要素**: 小さな大きさは、特別な式で分けます。

## 何をしているか

### 1. 空と 1 要素

```erlang:line-numbers=1303
f2r([]) ->
    {[],[]};
f2r([_]=F) ->
    {F,[]};
```

空なら、2 本とも空です。要素が 1 つなら、その要素を取り出し側に残し、入れ側は空のままにします。

### 2. 要素が 2 つ

```erlang:line-numbers=1307
f2r([X,Y]) ->
    {[Y],[X]};
```

2 つの要素 `X`、`Y` は、`X` を取り出し側に、`Y` を入れ側に分けます。取り出しの順番は `X` が先なので、`X` が取り出し側に残ります。

### 3. 3 つ以上

```erlang:line-numbers=1309
f2r(List) ->
    {FF,RR} = lists:split(length(List) div 2, List),
    {lists:reverse(RR, []),FF}.
```

長さの半分の位置で、前半 `FF` と後半 `RR` に分けます。前半 `FF` は、取り出し側としてそのまま使います。後半 `RR` は、反転して入れ側にします。戻り値は `{lists:reverse(RR, []), FF}` です。

例えば取り出し側が `[a, b, c, d]` なら、前半は `[a, b]`、後半は `[c, d]` です。入れ側は `[d, c]`（新しい方が先頭）になります。取り出しは `a`、`b` と進み、取り出し側が空になったら、入れ側の `[d, c]` を `r2f/1` で作り直して続けます。

## ここがすごい

### 半分ずつ分けると、どちらの側も小さいまま

取り出し側を全部入れ側へ回すと、次に入れ側から取り出し側を作るときに、大きな反転が必要になります。この関数は、半分だけ回すので、どちらの側も大きくなりすぎません。
取り出しの回数ごとに、作業量が平均化されます。

### 同じ反転のしかたで、r2f/1 と対になる

`r2f/1` は、入れ側を半分に割って、後半を反転して取り出し側にします。`f2r/1` は、取り出し側を半分に割って、後半を反転して入れ側にします。
2 つの関数は、同じ考え方を逆向きに使っています。対になっていることを押さえると、キューの全体の仕組みがつかみやすくなります。

## まとめ

- 取り出し側が長いときは、後半を反転して入れ側へ回すと、両側の大きさを保てます。
- 前半は取り出し側にそのまま残し、後半だけ反転するのが、順番を保つ要点です。
- `r2f/1` と `f2r/1` は対になっていて、キューの形を整える役割を分担しています。
