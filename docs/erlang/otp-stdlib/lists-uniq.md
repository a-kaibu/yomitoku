## ひとことで

`lists:uniq/1` は、リストから重複を取り除きます。`lists:uniq([3, 1, 3, 2, 1])` は `[3, 1, 2]` です。並べ替えはしません。
最初に出てきた要素だけを残すので、元の順番が保たれます。

## コード

```erlang:line-numbers=2931
uniq(L) ->
    uniq_1(L, #{}).

uniq_1([X | Xs], M) ->
    case is_map_key(X, M) of
        true ->
            uniq_1(Xs, M);
        false ->
            [X | uniq_1(Xs, M#{X => true})]
    end;
uniq_1([], _) ->
    [].
```

## 前提知識

- **マップ（map）**: キーと値の組を持つデータ構造です。`#{}` が空のマップです。
- **`is_map_key/2`**: マップに、そのキーがあるかを調べます。
- **`M#{X => true}`**: マップ `M` に、キー `X` を追加した新しいマップを作ります。元の `M` は変わりません。
- **重複**: 同じ値が 2 回以上出てくることです。最初の 1 回だけを残します。
- **再帰の形**: `[X | uniq_1(Xs, M)]` のように、結果の先頭に要素を付けながら、残りを処理します。

## 何をしているか

### 1. 入口

```erlang:line-numbers=2931
uniq(L) ->
    uniq_1(L, #{}).
```

`uniq/1` は、空のマップを用意して `uniq_1/2` に渡します。マップは、ここまでに出てきた要素の記録です。

### 2. 既に出た要素のとき

```erlang:line-numbers=2935
    case is_map_key(X, M) of
        true ->
            uniq_1(Xs, M);
```

`is_map_key/2` で、要素 `X` がすでに記録されていれば、その要素は捨てます。マップは変えずに、残りの要素を続けて調べます。

### 3. 初めて出た要素のとき

```erlang:line-numbers=2938
        false ->
            [X | uniq_1(Xs, M#{X => true})]
```

記録にない要素なら、結果の先頭に `X` を残します。同時に、マップへ `X` を追加して、次からは重複として扱います。

### 4. 空のリストのとき

```erlang:line-numbers=2941
uniq_1([], _) ->
    [].
```

最後まで読み終わったら、空のリストで終わります。

## ここがすごい

### 「見たかどうか」を、マップのキーで判定する

重複を消す素朴な方法は、それまでの結果を毎回走査して、要素があるかを調べることです。この場合、要素数の 2 乗に近い時間がかかります。
この関数は、見た要素をマップのキーにしておくので、1 回の判定が要素数によらず速く済みます。

### 順番を変えずに、先頭の出現だけを残す

並べ替えてから重複を消す方法では、元の順番が失われます。この関数は、先頭から順に読んで、初めて出た要素だけを残すので、元の並びが保たれます。
「初めての出現を残す」という素直な規則が、そのまま再帰の形になっています。

## まとめ

- 重複の判定には、見た要素をマップのキーとして覚えておくと、速く調べられます。
- 順番を保ったまま重複を消すには、先頭から読んで初めての要素だけを残します。
- 状態（見た要素の集まり）を引数で持ち回すと、関数型の書き方でも自然に書けます。
