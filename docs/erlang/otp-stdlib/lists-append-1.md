## ひとことで

`lists:append/1` は、リストを並べたリストを受け取り、それらを順番に一本のリストにつなげます。
たとえば、`[[1], [2, 3]]` は `[1, 2, 3]` になります。

## コード

```erlang:line-numbers=251
append([E]) -> E;
append([H|T]) -> H ++ append(T);
append([]) -> [].
```

## 前提知識

- **`++` 演算子**: 二つのリストをつなげます。左のリストは、先頭から全部コピーされます。
- **`lists:append/2`**: 二つのリストをつなぐ関数です。`append/1` は、その考え方を複数のリストに広げたものです。
- **要素が一つだけのリスト `[E]`**: この形なら、結果は `E` そのものです。つなぐ作業が要りません。
- **空のリスト `[]`**: つなぐものが無いので、空のリストを返します。

## 何をしているか

### 1. 要素が一つだけなら、その要素を返す

```erlang:line-numbers=251
append([E]) -> E;
```

外側のリストに要素が一つだけあれば、その要素を結果として返します。`++` を使わずに済むので、最後の一つはコピーされません。

### 2. 先頭のリストと、残りのつなぎ合わせ

```erlang:line-numbers=252
append([H|T]) -> H ++ append(T);
```

先頭の要素 `H` と、残り `T` を再帰でつなぎ合わせた結果を、`H ++ append(T)` で作ります。
`H` は、左側として先頭から全部コピーされます。

### 3. 空なら、空を返す

```erlang:line-numbers=253
append([]) -> [].
```

外側のリストが空なら、つなぐものが無いので、空のリストを返します。

## ここがすごい

### 最後の一つだけは、コピーしない

`++` は、左側のリストを全部コピーします。
最後の要素は、コピーされずに、そのまま結果に入ります。`[E]` の節があるので、一番右のリストは、余計な作業をせずに使えます。

### 右から組み立てる

`H ++ append(T)` は、残りのつなぎ合わせを先に作り、その前に `H` を付けます。
つまり、右側から順に組み立てていきます。書き方はシンプルで、読み手は、一つずつ前に付けていく様子を、そのまま頭に描けます。

### 左側のコピーの重さ

`++` の左側は、要素数に比例して時間がかかります。長いリストを何度もつなぐと、全体の作業が増えます。
要素が多くて遅いと感じたら、`lists:flatten/1` のように、一度に平らにする方法を検討すると良いでしょう。

### 二つだけのリストでの動き

`[[1], [2, 3]]` のように二つのリストがあると、先頭の `[1]` は `++` の左側になり、コピーされます。
残りの `[[2, 3]]` は、要素が一つなので `[2, 3]` そのものが返ります。結果は `[1] ++ [2, 3]` と同じ形になります。

## まとめ

`lists:append([[1], [2, 3], []])` は、`[1, 2, 3]` を返します。
空のリストを含んでいても、結果には影響しません。
