## ひとことで

`lists:umerge/2` は、昇順に並んだ二つのリストを、一つの昇順のリストにまとめます。
同じ値が両方にあれば、一つだけを残します。

## コード

```erlang:line-numbers=2024
umerge(Fun, L1, L2) when is_function(Fun, 2) ->
    umerge_1(Fun, L1, L2).
```

## 前提知識

- **昇順**: 小さい値から大きい値へ並んでいることです。`umerge` は、この並びを前提に動きます。
- **マージ**: 並んだリストの先頭を比べて、小さい方を取り出していく処理です。
- **`umerge_1/3`**: 二つのリストを受け取り、実際の併合を行う補助関数です。
- **`ufmerge2_2/5`**: 併合の途中で、結果を積み上げる補助関数です。この記事では中身には踏み込みません。

## 何をしているか

### 1. 比較の方法を受け取る

```erlang:line-numbers=2024
umerge(Fun, L1, L2) when is_function(Fun, 2) ->
    umerge_1(Fun, L1, L2).
```

`umerge/2` の本体は、一行だけです。引数の `L1` と `L2` を、`umerge_1/3` に渡します。
二つの名前の違いは、比較の仕方を一種類に決めていることです。

### 2. 両方が空でなければ、併合する

```erlang:line-numbers=2027
umerge_1(Fun, [H1 | T1], [_|_]=T2) ->
    lists:reverse(ufmerge2_2(H1, T1, Fun, T2, []), []);
```

両方のリストに要素があれば、先頭どうしを比べながら、結果を積み上げます。
結果は、積み上げた順が逆になっているので、`lists:reverse/2` で向きを戻します。

### 3. 片方が空になったら、残りをそのまま返す

```erlang:line-numbers=2029
umerge_1(_Fun, [_|_]=L1, []) ->
    L1;
```

`L2` が空なら、`L1` をそのまま返します。併合する相手が無いので、残りは、もう並んだ状態です。

## ここがすごい

### 並びを、一度の走査で保つ

二つのリストは、それぞれ一度ずつ先頭から読まれます。
並べ替えを使わないので、要素の数に比例した時間で結果が作られます。

### 空の場合を、先に分ける

両方が空でないときと、片方が空のときを、別の節に分けています。
空のリストは、併合の対象としては扱いにくいので、先に返してしまう形の方が、読み手にも分かりやすくなっています。

### 同じ値は、一つに減らす

併合の途中で、同じ値が両方にあれば、片方だけを結果に入れます。
集合のような性質を、ソートされたリストで手軽に作れるのが、この関数の使いどころです。

### 片方が空の場合は、比べる相手がない

併合では、両方の先頭を比べながら進みます。片方のリストが空になると、比べる相手が無くなります。
その時点で、もう一方の残りは、すでに並んだ状態なので、比較を続けずにそのまま結果に含められます。

## まとめ

`lists:umerge([1, 3, 5], [2, 3, 6])` は、`[1, 2, 3, 5, 6]` を返します。
同じ `3` は、両方にありますが、結果では一つだけになります。
