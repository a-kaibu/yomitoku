## ひとことで

`rand:uniform_real/0` は、0 以上 1 未満の浮動小数点数の乱数を 1 つ返します。
Erlang の値は書き換えられないので、乱数の状態（次の乱数の種）は、呼び出しのたびに新しい値になります。この関数は、その状態をプロセス辞書に保存して、利用者から見えないようにしています。

## コード

```erlang:line-numbers=1285
uniform_real() ->
    {X, Seed} = uniform_real_s(seed_get()),
    _ = seed_put(Seed),
    X.
```

## 前提知識

- **乱数の状態（seed）**: 次の乱数を作るための内部の値です。同じ状態から始めると、同じ乱数の列が出ます。
- **純粋な関数**: 同じ入力から、いつも同じ出力を返し、外の値を変えない関数です。Erlang の関数の多くは、この形で書かれます。
- **`_s` 版**: 名前の末尾に `_s` が付いた関数（`uniform_real_s/1` など）は、状態を引数で受け取り、新しい状態を一緒に返します。状態を明示的に持ち回すための形です。
- **プロセス辞書**: プロセスごとに持てる、キーと値の表です。`put/2`、`get/1` で値を書き込み、読みます。
- **組 `{X, Seed}`**: 乱数と、次の状態を一緒に返す形です。

## 何をしているか

### 1. 状態を読む

```erlang:line-numbers=1286
    {X, Seed} = uniform_real_s(seed_get()),
```

`seed_get()` は、プロセス辞書から現在の状態を取り出します。まだ設定されていないときは、既定の状態を使う仕組みです。
その状態を `uniform_real_s/1` に渡します。`_s` 版は、乱数 `X` と、次の状態 `Seed` の組を返します。

### 2. 状態を書き戻す

```erlang:line-numbers=1287
    _ = seed_put(Seed),
```

新しい状態 `Seed` を `seed_put/1` でプロセス辞書に書き戻します。`_ =` は、書き戻しの戻り値を捨てるという意味です。

### 3. 乱数を返す

```erlang:line-numbers=1288
    X.
```

計算した乱数 `X` を、利用者へ返します。

## ここがすごい

### 純粋な関数と、状態の保存を分けている

乱数の計算そのものは、`uniform_real_s/1` という純粋な関数に任せています。プロセス辞書を触るのは、この薄い層だけです。
そのため、テストや再現が必要なときは、`_s` 版を直接使い、状態を自分で管理できます。

### 利用者は状態を意識しなくてよい

普段の利用者は、`rand:uniform_real()` を呼ぶだけです。状態を渡し回す必要がないので、呼び出しの書き方が単純になります。
ただし、乱数の状態は、そのプロセスごとに別々に保たれます。別のプロセスで呼ぶと、違う列の乱数が出る点は覚えておく必要があります。

## まとめ

- 不変の値で乱数を作るには、状態を明示的に持ち回す「_s 版」の関数を使います。
- プロセス辞書は、状態を利用者から隠すための、手軽な保存場所として使えます。
- 薄い層で状態の読み書きを包むと、中心の計算を純粋なまま保てます。
