## ひとことで

`lists:nthtail/2` は、リストの先頭から `N` 個の要素を飛ばし、残りのリストを返します。
`N` が 0 なら、リスト全体をそのまま返します。リストが `N` 個より短いときは、呼び出しが失敗します。

## コード

```erlang:line-numbers=349
nthtail(0, []) -> [];
nthtail(0, [_|_]=L) -> L;
nthtail(1, [_|T]) -> T;
nthtail(N, [_|_]=L) when is_integer(N), N > 1 ->
    nthtail_1(N, L).

nthtail_1(1, [_|T]) -> T;
nthtail_1(N, [_|T]) ->
    nthtail_1(N - 1, T).
```

## 前提知識

- **`N` 個を飛ばす**: 先頭から `N` 個の要素を捨てる、という意味です。`nthtail(2, [a,b,c])` は、`[c]` になります。
- **パターン `[_|_]`**: 少なくとも一つの要素があるリストにマッチします。中身は見ません。
- **ガード `N > 1`**: 数が `1` より大きいときだけ、この節を選びます。
- **補助関数 `nthtail_1/2`**: `N` を一つずつ減らしながら、先頭を捨てていきます。

## 何をしているか

### 1. N が 0 のとき

```erlang:line-numbers=349
nthtail(0, []) -> [];
nthtail(0, [_|_]=L) -> L;
```

`N` が 0 なら、飛ばすものがありません。空のリストなら空、要素があればそのリストをそのまま返します。

### 2. N が 1 のとき

```erlang:line-numbers=351
nthtail(1, [_|T]) -> T;
```

`N` が 1 なら、先頭を一つだけ捨てた残りを返します。

### 3. N が 2 以上のとき

```erlang:line-numbers=352
nthtail(N, [_|_]=L) when is_integer(N), N > 1 ->
    nthtail_1(N, L).
```

`N` が 1 より大きいときは、補助関数 `nthtail_1/2` に任せます。

### 4. 補助関数で、N を減らして数える

```erlang:line-numbers=355
nthtail_1(1, [_|T]) -> T;
nthtail_1(N, [_|T]) ->
    nthtail_1(N - 1, T).
```

補助関数は、`N` が 1 になるまで、先頭を一つずつ捨てながら `N` を減らします。`N` が 1 になった時点で、残りのリストを返します。

## ここがすごい

### 節の数で、特別な場合を先に処理する

`N` が 0 と 1 の場合を、先に節で書いています。よくある小さな値を、速く、わかりやすく処理できます。
大きい `N` だけを、補助関数で数えるという分け方です。

### 数えるための引数を一つ減らす

補助関数は、`N - 1` を次の呼び出しに渡して、一つずつ減らします。
ループの回数を、引数の値そのものが表しているので、終わりの条件が一目でわかります。

### 足りないときは、失敗で知らせる

リストが `N` 個より短いと、どの節にも当たらず、呼び出しは失敗します。
この関数は、足りなかったときの値を用意していません。呼び出し側が、長さを先に確かめておく前提です。

### 一つずつ数える形の、利点と限界

補助関数は、`N` を一つずつ減らして、同じ形の呼び出しを繰り返します。
引数が増えないので、`N` が大きくても、途中の結果を積み上げる必要がありません。一方で、`N` が非常に大きいときは、回数の分だけ呼び出しが増えます。

## まとめ

`lists:nthtail(2, [a, b, c, d])` は、`[c, d]` を返します。
`lists:nthtail(0, [a, b])` は、`[a, b]` をそのまま返します。
