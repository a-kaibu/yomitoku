## ひとことで

`random:uniform_s/1` は、3 つの状態 `{A1, A2, A3}` を受け取って、0 以上 1 未満の小数 `R` と、次の状態の組を返します。
内部では、3 つの小さな乱数の列を、それぞれ割り算の余りで進めます。その出力を比率にして足し合わせ、整数部分を捨てて小数だけを残します。

## コード

```erlang:line-numbers=211
uniform_s({A1, A2, A3}) ->
    B1 = (A1*171) rem ?PRIME1,
    B2 = (A2*172) rem ?PRIME2,
    B3 = (A3*170) rem ?PRIME3,
    R = B1/?PRIME1 + B2/?PRIME2 + B3/?PRIME3,
    {R - trunc(R), {B1,B2,B3}}.
```

定数は、ファイルの上のほうで決められています。

```erlang:line-numbers=73
-define(PRIME1, 30269).
-define(PRIME2, 30307).
-define(PRIME3, 30323).
```

## 前提知識

- **乱数の状態**: 次の乱数を作るための値です。状態が同じなら、同じ乱数の列が出ます。
- **剰余 `rem`**: 割り算のあまりです。`(A1*171) rem 30269` は、30269 で割った余りです。値はいつも 0 以上 30269 未満になります。
- **素数の定数**: `PRIME1`、`PRIME2`、`PRIME3` は、互いに素な大きさの定数です。周期を長くするための工夫です。
- **`trunc/1`**: 小数の整数部分を取り除いて、整数にします。`R - trunc(R)` で、小数部分だけが残ります。
- **組 `{R, {B1,B2,B3}}`**: 乱数と、次の状態を一緒に返します。Erlang では、状態を値として持ち回します。
- **`_s` の名前**: 状態を引数で受け取り、新しい状態を返す関数であることを表します。

## 何をしているか

### 1. 3 つの状態を、別々に進める

```erlang:line-numbers=212
    B1 = (A1*171) rem ?PRIME1,
    B2 = (A2*172) rem ?PRIME2,
    B3 = (A3*170) rem ?PRIME3,
```

`A1` に 171 を掛けて、30269 で割った余りを `B1` にします。`A2`、`A3` にも、別の掛け算と、別の素数の割り算を使います。
3 つの掛け算の数（171、172、170）と、割る数（30269、30307、30323）はどれも違います。それぞれの列が、別々の周期で動くようにしています。

### 2. 比率を足し合わせる

```erlang:line-numbers=215
    R = B1/?PRIME1 + B2/?PRIME2 + B3/?PRIME3,
```

`B1 / 30269` は、0 以上 1 未満の小数です。同じように、`B2`、`B3` もそれぞれ 0 以上 3 未満の範囲の小数になります。3 つを足し合わせると、0 以上 3 未満の小数になります。

### 3. 小数部分だけを取り出す

```erlang:line-numbers=216
    {R - trunc(R), {B1,B2,B3}}.
```

`R - trunc(R)` で、整数部分を捨てます。結果は 0 以上 1 未満の小数です。新しい状態は `{B1, B2, B3}` として、そのまま返します。

## ここがすごい

### 3 つの周期を、互いに素にそろえる

1 つの乱数列だけでは、周期が短いことがあります。この関数は、3 つの列の周期がそろわないように、異なる素数で割っています。
3 つの列を足すことで、1 つずつの列の偏りを打ち消し合わせる、というのが考え方です。

### 状態を値で返し、関数の外に置かない

`uniform_s/1` は、外の変数を一切書き換えません。新しい状態を組にして返すだけです。
そのため、同じ状態から呼べば、いつも同じ結果が得られます。テストや再現のための処理が書きやすい、Erlang らしい形です。

## まとめ

- 乱数は、状態を値として引数と戻り値で持ち回すと、関数型の書き方になります。
- 異なる素数で割る複数の列を足すと、1 つの列よりも偏りが減らせます。
- 小数の整数部分は、`R - trunc(R)` で簡単に捨てられます。
