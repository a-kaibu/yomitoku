## ひとことで

`orddict:map/2` は、順序付き辞書の各組に、関数 `F` を適用します。
`F` は、キーと値の両方を受け取り、新しい値を返します。キーの並びは変わらないので、結果も、昇順の辞書のままです。

## コード

```erlang:line-numbers=540
map(F, [{Key,Val}|D]) ->
    [{Key,F(Key, Val)}|map(F, D)];
map(F, []) when is_function(F, 2) -> [].
```

## 前提知識

- **順序付き辞書（orddict）**: `{Key, Value}` の組を、キーの昇順に並べたリストです。
- **`F(Key, Val)`**: 関数 `F` は、キーと値を受け取り、新しい値を返します。`lists:map/2` の関数と違い、二引数です。
- **再帰による変換**: 先頭の組を変換してから、残りを同じ方法で変換します。
- **空の辞書**: 空の辞書は、そのまま空の辞書を返します。

## 何をしているか

### 1. 先頭の組の値を、関数で替える

```erlang:line-numbers=540
map(F, [{Key,Val}|D]) ->
    [{Key,F(Key, Val)}|map(F, D)];
```

先頭の組 `{Key, Val}` について、`F(Key, Val)` で新しい値を作ります。キーは変えず、その組を結果の先頭に付けます。
残り `D` にも、同じ変換を続けます。

### 2. 空の辞書なら、空を返す

```erlang:line-numbers=542
map(F, []) when is_function(F, 2) -> [].
```

組が無くなったら、空のリストを返します。ここで再帰が終わります。

## ここがすごい

### キーを変えないことが、並びの保証になる

変換するのは値だけで、キーは同じものが使われます。
キーの昇順という前提は、変換の前後で保たれます。そのため、結果を、同じ辞書として次の操作に使えます。

### キーも使える変換

`lists:map/2` の関数は、要素一つだけを受け取ります。
`orddict:map/2` は、キーを一緒に受け取るので、キーの内容によって値を変える処理が書けます。たとえば、キーが偶数なら値を二倍にする、といった変換です。

### 関数が二引数であることを、節の形で確かめる

二つ目の節のガードで、`F` が二引数の関数であることを確かめています。
空の辞書のときに限って、この確かめをしている点が、節の作りの特徴です。

### 変換の結果は、元の辞書と同じ形

新しく作られる辞書は、元の辞書と同じキーを同じ順番で持ちます。値だけが違います。
そのため、変換の前後で、キーを使った検索の結果は、キーごとに対応づけられたまま保たれます。

### 空の辞書で止まる、単純な終わり方

再帰の終わりは、空の辞書の一行だけです。途中で結果を組み直したり、最後に並べ替えたりする処理はありません。
順序を変えない変換は、これだけで書き切れます。読み手は、一つの節を読むだけで、関数全体の形がつかめます。

## まとめ

`orddict:map(fun(K, V) -> K + V end, [{1, 10}, {2, 20}])` は、`[{1, 11}, {2, 22}]` を返します。
キーは変わらず、値だけがキーと合わせて変換されます。
