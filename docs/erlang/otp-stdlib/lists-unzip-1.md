## ひとことで

`lists:unzip/1` は、`{X, Y}` の組が並んだリストを、`X` だけを並べたリストと、`Y` だけを並べたリストの組に分けます。
`lists:zip/2` の逆の操作にあたります。

## コード

```erlang:line-numbers=823
unzip(Ts) -> unzip(Ts, [], []).

unzip([{X, Y} | Ts], Xs, Ys) -> unzip(Ts, [X | Xs], [Y | Ys]);
unzip([], Xs, Ys) -> {reverse(Xs), reverse(Ys)}.
```

## 前提知識

- **二要素のタプル `{X, Y}`**: 二つの値を一組にした形です。ここでは、片方が左、片方が右の列に入ります。
- **アキュムレータ**: 途中の結果を、引数で持ち回ります。ここでは、`Xs` と `Ys` の二つを持ち回ります。
- **`lists:reverse/1`**: リストの順番を逆にします。
- **タプルのパターン**: `{X, Y}` の形の要素だけにマッチします。

## 何をしているか

### 1. 入口で二つの空の列を用意する

```erlang:line-numbers=823
unzip(Ts) -> unzip(Ts, [], []).
```

`unzip/1` は、空の `Xs` と `Ys` を用意して、`unzip/3` に渡します。

### 2. 組を一つずつ分けて、前に積む

```erlang:line-numbers=825
unzip([{X, Y} | Ts], Xs, Ys) -> unzip(Ts, [X | Xs], [Y | Ys]);
```

先頭の組 `{X, Y}` を見つけたら、`X` を `Xs` の先頭に、`Y` を `Ys` の先頭に付けます。残りの組に対して、同じ関数を呼びます。

### 3. 空になったら、順番を戻して返す

```erlang:line-numbers=826
unzip([], Xs, Ys) -> {reverse(Xs), reverse(Ys)}.
```

組が空になったら、積んだ二つのリストを、`lists:reverse/1` で元の順番に戻します。二つのリストの組を、結果として返します。

## ここがすごい

### 前に積んで、最後に戻す

リストの末尾に付けるのは、毎回リストを辿る必要があり、遅くなります。
この関数は、先頭に付けるので一回ずつの処理が軽く済みます。順番の狂いは、最後の `reverse` で直します。

### 二つの列を同時に作る

一度の走査で、左と右の列を同時に作ります。
左の列と右の列をそれぞれ別の関数で作ると、リストを二回辿ることになります。

### 失敗しない入力の形

組でない要素が混ざると、どの節にも当たらず、呼び出しは失敗します。
この関数は、組の形を節の頭で確かめるので、入力の形が正しいことを、そのまま前提にできます。

### 出来上がった二つの列は、必ず同じ長さになる

組のリストの要素一つずつから、左の列に一つ、右の列に一つが追加されます。
そのため、結果の二つの列は、いつも同じ長さです。呼び出し側は、左と右を先頭から一緒に読めます。

### 組の形を、関数の頭で確かめる

`unzip/3` の最初の節は、要素を `{X, Y}` の形で受け取ります。この形に合わない要素は、どの節にも当たりません。
入力の形を、関数の頭の一箇所で決めているので、中の処理は、二つの値を取り出して積むだけで済みます。

## まとめ

`lists:unzip([{a, 1}, {b, 2}])` は、`{[a, b], [1, 2]}` を返します。
