## ひとことで

`save_context 名前` は、**直前のコンテキストの名前をファイルに保存する** 関数です。ただし、すでに同じ名前が保存されていれば、書き込みは行いません。

保存先は、`KUBECTX` という変数で指定されたファイルです。名前を 1 行で書いておき、あとで `read_context` で読み出します。

## コード

```bash:line-numbers=105
save_context() {
  local saved
  saved="$(read_context)"

  if [[ "${saved}" != "${1}" ]]; then
    printf %s "${1}" > "${KUBECTX}"
  fi
}
```

## 前提知識

- **ファイルへの書き込み**: `printf %s 値 > ファイル` は、値をそのまま書き込みます。改行を付けないので、ファイルの中身は名前だけになります。
- **`>` と `>>`**: `>` はファイルを作り直して書き込み、`>>` は末尾に追加します。この関数は `>` を使うので、常に 1 つの値だけが残ります。
- **`read_context`**: ファイルから保存されている値を読み出す関数です。
- **`!=`**: 2 つの文字列が違うかを調べます。

## 何をしているか

### 1. 保存されている値を読む

```bash:line-numbers=107
  saved="$(read_context)"
```

`read_context` で、今ファイルに入っている値を取り出します。

### 2. 違う場合だけ書き込む

```bash:line-numbers=109
  if [[ "${saved}" != "${1}" ]]; then
    printf %s "${1}" > "${KUBECTX}"
  fi
```

今の値と新しい値が違うときだけ、`printf` でファイルへ書き込みます。同じなら、何もしません。

## ここがすごい

- **不要な書き込みを省く**: 同じ値を繰り返し書き込むと、ファイルの更新時刻が変わったり、ディスクへの負担が増えたりします。その無駄を防いでいます。
- **`printf %s` で改行なし**: `echo` を使うと改行が付くので、読み出すときに余計な空白が混ざることがあります。`printf` で、値だけを正確に書いています。
- **1 つの値だけを残す**: `>` で書き込むので、古い値が残りません。ファイルは常に最新の 1 つの名前だけを持ちます。

## まとめ

- 同じ値の書き込みは省くと、無駄な更新を減らせる。
- 改行を付けたくないときは `echo` より `printf %s` を使う。
- 1 つの値だけを保存するなら、`>` で上書きするのが簡単。
