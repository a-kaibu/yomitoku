## ひとことで

`takedir` は、ディレクトリを作ってすぐにその中へ移動する関数です。`mkcd` という別名でも呼べます。

```sh
takedir projects/new-app   # 作って、その中へ移動
```

`mkdir -p projects/new-app && cd projects/new-app` と 2 回同じパスを打つ手間がなくなります。たった 1 行ですが、「最後の引数を取り出す」書き方がポイントです。

## コード

```zsh:line-numbers=49
function mkcd takedir() {
  mkdir -p $@ && cd ${@:$#}
}
```

## 前提知識

- **`function mkcd takedir() { ... }`**: zsh では、`function` の後に名前を複数並べると、**同じ中身の関数を複数の名前で** 定義できます。
- **`mkdir -p`**: 途中のディレクトリもまとめて作ります。すでにあってもエラーになりません。
- **`$@`**: 関数に渡されたすべての引数です。
- **`$#`**: 引数の個数です。
- **`${@:N}`**: N 番目以降の引数です。`${@:$#}` は「引数の個数番目以降」、つまり **最後の引数だけ** になります。
- **`&&`**: 左が成功したときだけ右を実行します。

## 何をしているか

### 1. ディレクトリを作る

```zsh:line-numbers=50
  mkdir -p $@ && cd ${@:$#}
```

`mkdir -p $@` で、渡されたディレクトリを全部作ります。`takedir a b c` なら `a`、`b`、`c` の 3 つができます。`mkdir` のオプション（`-m 700` など）を渡すこともできます。

### 2. 最後の引数に移動する

```zsh:line-numbers=50
  mkdir -p $@ && cd ${@:$#}
```

作るのに成功したら、`cd ${@:$#}` で移動します。

`takedir a b c` なら、`$#` は `3` です。`${@:3}` は 3 番目以降、つまり `c` だけになります。`takedir -m 700 secret` なら、`$#` は `3`、`${@:3}` は `secret` です。

### 3. 失敗したら移動しない

```zsh:line-numbers=50
  mkdir -p $@ && cd ${@:$#}
```


`&&` でつないでいるので、権限が無いなどで `mkdir` が失敗したら `cd` はしません。

## ここがすごい

- **「最後の引数」を取り出す簡潔な書き方**: `${@:$#}` は「位置 = 個数」の部分から後ろ、という発想で最後の 1 つを取り出しています。bash でも同じ書き方ができ、ほかに `${@: -1}`（後ろから 1 番目）という書き方もあります。
- **オプションもそのまま渡せる**: `$@` を丸ごと `mkdir` に渡すので、`mkdir` のオプションが使えます。移動先は最後の引数なので、オプションが前にあっても問題ありません。
- **関数でなければできない**: `cd` はシェル自身の場所を変えるので、別のスクリプトファイルにしても効果がありません（スクリプトは別プロセスで動くため）。シェルの関数として定義することで、今いるシェルの場所を変えられます。
- **複数の名前を一度に定義**: `mkcd` という昔からある名前と、`take` 系の名前の両方で使えるようにしています。

なお、この書き方では引数をクォートしていないので、空白を含むパスはうまく扱えません。zsh は既定で変数を空白分割しないため、通常の使い方では問題になりにくくなっています。

## まとめ

- `${@:$#}` で、引数の最後の 1 つを取り出せる。
- `cd` を含む処理は、スクリプトではなく関数として定義する必要がある。
- zsh の `function a b() {}` で、1 つの関数に複数の名前を付けられる。
