## ひとことで

`zsh_stats` を実行すると、これまで打ったコマンドの中で **よく使ったもの上位 20 個** が、回数と割合つきで表示されます。

```
     1  412  20.6%  git
     2  301  15.05% cd
     3  188  9.4%   ls
```

やっていることは、履歴を取り出す → 数える → 並べる → 上位を取る → 整形する、の 5 段階です。それぞれを得意なコマンドに任せて、パイプ（`|`）でつないでいます。

## コード

```zsh:line-numbers=1
function zsh_stats() {
  fc -l 1 \
    | awk '{ CMD[$2]++; count++; } END { for (a in CMD) print CMD[a] " " CMD[a]*100/count "% " a }' \
    | grep -v "./" | sort -nr | head -n 20 | column -c3 -s " " -t | nl
}
```

## 前提知識

- **パイプ `|`**: 左のコマンドの出力を、右のコマンドの入力に流します。いくつもつなげられます。
- **行末の `\`**: 1 つのコマンドを複数行に分けて書くための記号です。
- **`fc -l 1`**: zsh の履歴を 1 番目から全部表示します。各行は `番号  コマンド 引数...` の形です。
- **awk の連想配列 `CMD[$2]++`**: `$2`（2 列目＝コマンド名）をキーにして回数を 1 増やします。
- **`END { for (a in CMD) ... }`**: 全行を読み終えた後に、配列の全キーについて処理します。
- **`grep -v "./"`**: パターンに一致する行を **除外** します。
- **`sort -nr`**: 数値として（`-n`）大きい順に（`-r`）並べます。
- **`head -n 20`**: 先頭 20 行だけを残します。
- **`column -t`**: 列をそろえて表にします。**`nl`**: 行番号を付けます。

## 何をしているか

### 1. 履歴を出す（2 行目）

`fc -l 1` で `  15  git status` のような行が全部出てきます。

### 2. 数える（3 行目）

awk が 1 行ごとに `CMD[$2]++` を実行します。`$2` は `git` なので `CMD["git"]` が 1 増えます。同時に総数 `count` も数えます。最後に `回数 割合% コマンド名` を全コマンド分出力します。

### 3. 余計なものを除く（4 行目）

`./configure` のように `./` で始まるコマンド（その場のスクリプト）を除きます。正確には `.` は任意の 1 文字なので、「何かの文字の後に `/` がある」行が除かれます。

### 4. 並べて上位を取る（4 行目）

回数の大きい順に並べ、上位 20 個を残します。

### 5. 整形する（4 行目）

`column` で表の形にそろえ、`nl` で順位の番号を付けます。

## ここがすごい

- **1 つのことをうまくやる道具を組み合わせる**: 数えるのは awk、並べるのは sort、切り取るのは head。どれも単独では単純ですが、つなぐとランキングが作れます。これが UNIX の考え方です。
- **連想配列で集計**: awk の配列はキーを何でも使えるので、「種類ごとに数える」処理が 1 行で書けます。SQL の `GROUP BY` と同じ働きです。
- **中間ファイルが要らない**: 各段階の結果はパイプで直接次に渡るので、一時ファイルを作ったり消したりする必要がありません。

## まとめ

- パイプでコマンドをつなぐと、小さな道具の組み合わせで複雑な集計ができる。
- `awk '{ C[$n]++ } END { for (k in C) print C[k], k }'` は「種類ごとに数える」定番の形。
- `sort -nr | head -n N` で上位 N 個を取り出せる。
