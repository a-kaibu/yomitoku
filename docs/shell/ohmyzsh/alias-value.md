## ひとことで

`alias_value ll` は、`ll` というエイリアスの **中身**（たとえば `ls -lh`）を表示する関数です。エイリアスが無ければ何も表示せず、失敗を返します。

zsh では、定義済みのエイリアスが `aliases` という **連想配列** として見えるようになっています。この関数はそれを読むだけです。

## コード

```zsh:line-numbers=101
function alias_value() {
    (( $+aliases[$1] )) && echo $aliases[$1]
}
```

## 前提知識

- **エイリアス**: `alias ll='ls -lh'` のように、コマンドに付けた短い別名です。
- **連想配列**: 文字列をキーにして値を取り出せる配列（辞書）です。`$aliases[ll]` で `ll` に対応する値が取り出せます。
- **`aliases`**: zsh の `zsh/parameter` モジュールが用意する特殊な連想配列です。キーがエイリアス名、値がその中身です。普通の配列と同じように読めます。
- **`$+名前`**: zsh の書き方で、変数（や配列の要素）が **存在すれば 1、しなければ 0** になります。`$+aliases[ll]` は「`ll` というキーがあるか」です。
- **`(( 式 ))`**: 算術式を評価し、結果が 0 以外なら成功、0 なら失敗になります。
- **`&&`**: 左が成功したときだけ右を実行します。

## 何をしているか

この関数は次の 1 行だけです。

### 1. キーがあるか調べる

`(( $+aliases[$1] ))` で、引数 `$1` という名前のエイリアスがあるかを調べます。`ll` があれば `(( 1 ))` で成功、無ければ `(( 0 ))` で失敗です。

### 2. あれば値を表示

成功したときだけ `echo $aliases[$1]` で中身を表示します。

### 3. 結果

関数の終了ステータスは最後のコマンドの結果なので、

- エイリアスがあれば、`echo` の成功で 0
- 無ければ、`(( ))` の失敗で 1

になります。コメントに書かれた仕様どおりです。

同じファイルの `try_alias_value` は、これを使って「エイリアスがあれば中身、無ければ元の名前」を返します。

## ここがすごい

- **シェルの内部情報をデータとして読む**: エイリアスの中身を知りたいとき、bash では `alias ll` の出力（`alias ll='ls -lh'`）を文字列として加工する必要があります。zsh は内部の情報を連想配列として公開しているので、そのまま読むだけで済みます。
- **存在確認と値の取得を分ける**: 値が空文字のエイリアスもありうるので、「値が空か」ではなく「キーがあるか」で判定するほうが正確です。`$+` はまさにそのための記法です。
- **終了ステータスまで設計されている**: `&&` で 2 つをつなぐだけで、出力と成功・失敗の両方がきちんと決まります。

## まとめ

- zsh では `aliases`、`functions`、`commands` などの特殊な連想配列で、シェルの内部情報を読める。
- `$+var[key]` で、キーがあるかを 0/1 で調べられる。
- `(( 条件 )) && 処理` は、条件付きの処理を 1 行で書く定番の形。
