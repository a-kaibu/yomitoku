## ひとことで

`_filter_listen_port ポート番号` は、ネットワークの待ち受け状態の一覧から、**指定したポートで待ち受けている行だけ** を残す関数です。`netstat` や `ss` の出力を、標準入力から受け取って絞り込みます。

acme.sh は、証明書の確認のときに、指定したポートが使われているかを調べることがあります。その判定の前段で、この関数が一覧を絞り込みます。

## コード

```bash:line-numbers=1492
_filter_listen_port() {
  _flp_port="$1"
  if [ -z "$_flp_port" ]; then
    return
  fi
  grep -i "LISTEN" | grep "[:.]$_flp_port "
}
```

## 前提知識

- **LISTEN（待ち受け）**: サーバーが接続を受けつけるために、ポートを開いている状態です。
- **`netstat` や `ss`**: 通信の状態を一覧で表示するコマンドです。出力に、LISTEN などの状態の文字が含まれます。
- **`grep -i`**: 大文字と小文字を区別せずに一致を調べます。
- **`[:.]`**: コロンかドットのどちらかの 1 文字に一致します。IPv6 のアドレスの区切りや、IPv4 の区切りの両方に対応するために使われています。
- **`$_flp_port `**: ポート番号の後ろに空白を付けています。`:80 ` のように、番号の後ろで区切ることで、`:800` などと誤って一致するのを防ぎます。

## 何をしているか

### 1. ポート番号を確かめる

```bash:line-numbers=1493
  _flp_port="$1"
  if [ -z "$_flp_port" ]; then
    return
  fi
```

ポート番号が空なら、何も出さずに終わります。

### 2. LISTEN の行を選ぶ

```bash:line-numbers=1497
  grep -i "LISTEN" | grep "[:.]$_flp_port "
```

まず `LISTEN` を含む行を選びます。次に、その中から、ポート番号の前がコロンかドットで、後ろに空白が続く行だけを残します。

## ここがすごい

- **番号の後ろの空白で区切る**: ポート番号だけを探すと、80 は 8080 にも一致してしまいます。後ろに空白を付けることで、番号の終わりまで正しく一致させています。
- **2 段の絞り込み**: 状態の文字で大まかに絞り、その後でポート番号を探す、という順番です。読みやすく、処理も軽くなります。
- **区切り文字を両方受け入れる**: IPv4 のドットと IPv6 のコロンの両方に対応しています。

## まとめ

- 数字を探すときは、前後の区切りも含めて書くと誤一致を防げる。
- 絞り込みは、大まかな条件から順に行うと分かりやすい。
- 区切り文字は、想定する形式をすべて受け入れる。
