## ひとことで

`_ascii_hex 文字列` は、文字列の **1 文字ずつの文字コードを 16 進数で表示** する関数です。`abc` を渡すと ` 61 62 63` と出します。

暗号の処理では、文字列をバイト列として扱いたい場面がよくあります。ところが、環境によっては `od` や `xxd` のような、16 進数に変換するコマンドがないことがあります。この関数は、そうした最小限の環境のための代わりの方法です。

## コード

```bash:line-numbers=643
_ascii_hex() {
  _debug2 "Using _ascii_hex"
  _str="$1"
  _str_len=${#_str}
  _h_i=1
  while [ "$_h_i" -le "$_str_len" ]; do
    _str_c="$(printf "%s" "$_str" | cut -c "$_h_i")"
    printf " %02x" "'$_str_c"
    _h_i="$(_math "$_h_i" + 1)"
  done
}
```

## 前提知識

- **文字コード**: 文字を数値で表したものです。`a` は 16 進数で `61`、`b` は `62` です。
- **`printf "%02x"`**: 数値を 16 進数で、最低 2 桁になるように 0 で埋めて出力します。
- **`cut -c 番号`**: 文字列から、指定した位置の 1 文字を取り出します。
- **`"'$_str_c"`**: `printf` では、シングルクォートを前に付けた文字は、その文字の文字コードとして扱われます。
- **`_math`**: acme.sh が用意している算術の関数です。ここでは、番号を 1 つ進めるために使われています。

## 何をしているか

### 1. 文字列と長さを準備する

```bash:line-numbers=645
  _str="$1"
  _str_len=${#_str}
  _h_i=1
```

引数を `_str` に入れ、その長さを `_str_len` に入れます。`_h_i` は、今何文字目を見ているかを表す番号です。

### 2. 1 文字ずつ取り出して、16 進数にする

```bash:line-numbers=649
    _str_c="$(printf "%s" "$_str" | cut -c "$_h_i")"
    printf " %02x" "'$_str_c"
```

`cut -c` で `_h_i` 番目の 1 文字を取り出し、その文字コードを `%02x` の形で表示します。`printf` の書式の中で、シングルクォートが文字コードを求める働きをしています。

### 3. 番号を進めて、末尾まで繰り返す

```bash:line-numbers=648
  while [ "$_h_i" -le "$_str_len" ]; do
```

番号が文字列の長さ以下の間、ループを続けます。`_math` で番号を 1 つ増やします。

## ここがすごい

- **外部のツールに頼らない**: `od` も `xxd` もない環境でも、`cut` と `printf` だけで動きます。最小限の環境で使える保険になっています。
- **`printf` の文字コード指定を利用**: 文字コードを得るための変換を、`printf` の仕組みそのものに任せています。
- **結果の形を揃える**: 各バイトを 2 桁に揃えるので、後の処理で区切りの位置が分かりやすくなります。

ただし、1 文字ずつ外部コマンドを呼ぶので、長い文字列では遅くなります。acme.sh はこの関数を、最後の手段として使います。

## まとめ

- 代わりのツールは、最小限の環境でも動く形で用意しておくと安心。
- `printf` の文字コード指定は、バイトの値を得る手段として使える。
- 速さより汎用性を選ぶ場面では、単純な方法で十分なことがある。
