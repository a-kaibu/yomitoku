## ひとことで

`_egrep_o パターン` は、入力の中で正規表現に一致した **部分だけ** を表示する関数です。`grep -o` と同じ働きを目指しています。

ただし、`-o` に対応していない古い grep もあります。そこで、スクリプトの最初に 1 度だけ動作を確かめておき、使えるときは `egrep -o`、使えないときは `sed` で代用します。

## コード

```bash:line-numbers=958
_egrep_o() {
  if [ "$__USE_EGREP" ]; then
    egrep -o -- "$1" 2>/dev/null
  else
    sed -n 's/.*\('"$1"'\).*/\1/p'
  fi
}
```

## 前提知識

- **`egrep -o`**: 一致した部分だけを 1 行ずつ表示するオプションです。`-o` は POSIX の規格には含まれないため、環境によって使えないことがあります。
- **`echo abc | egrep -o b`**: 動作確認のための簡単なテストです。`b` と表示されれば、`-o` が使えるとみなします。
- **`__USE_EGREP`**: 判定の結果を覚える変数です。空なら sed を、1 なら egrep を使います。
- **`sed -n 's/.*\(...\).*/\1/p'`**: 行の中で一致した部分だけを取り出して表示する、sed の定番の書き方です。
- **`--`**: オプションの終わりを表す記号です。パターンが `-` で始まっても、オプションと誤解されないようにします。

## 何をしているか

### 1. 最初に使えるかを確かめる

```bash:line-numbers=952
if [ "$(echo abc | egrep -o b 2>/dev/null)" = "b" ]; then
  __USE_EGREP=1
else
  __USE_EGREP=""
fi
```

`echo abc | egrep -o b` の結果が `b` なら、変数 `__USE_EGREP` に 1 を入れます。そうでなければ空にします。この判定はスクリプトの読み込み時に 1 度だけ行われます。

### 2. egrep が使えるなら、それを使う

```bash:line-numbers=959
  if [ "$__USE_EGREP" ]; then
    egrep -o -- "$1" 2>/dev/null
```

変数が 1 なら、`egrep -o -- パターン` で一致した部分を表示します。

### 3. 使えないなら sed で代用する

```bash:line-numbers=961
  else
    sed -n 's/.*\('"$1"'\).*/\1/p'
  fi
```

それ以外の場合は、sed で、一致した部分だけを取り出して表示します。`.*` で前後を取り除き、括弧で囲んだ部分だけを残す形です。

## ここがすごい

- **判定は起動時に 1 回だけ**: 関数を呼ぶたびに確かめるのではなく、読み込みのときに決めておきます。無駄な処理がありません。
- **動作そのもので確かめる**: `-o` の有無を、OS の名前やバージョンで決めるのではなく、実際に動かして結果を見ています。確実な方法です。
- **同じ結果を得る代替手段**: 2 つの方法で、呼ぶ側には同じ結果を返します。環境による違いを隠しています。

## まとめ

- 外部コマンドのオプションは、OS の名前ではなく動作で確かめると確実。
- 判定は読み込み時に 1 回だけ行うと、無駄な処理を減らせる。
- 同じ結果を得られる代替手段を用意すると、移植性が上がる。
