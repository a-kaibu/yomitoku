## ひとことで

`nvm_is_alpha_version` は、バージョン番号が `vN.0.0-alpha.X.Y.Z` という **特殊な形かどうか** を判定する関数です。たとえば `v4.0.0-alpha.1.2.3` は成功、`v4.0.0-rc.1` や `v4.0.0-alpha.1` は失敗です。

`-alpha.` の前と後ろがどちらも「数字.数字.数字」の形かを、**同じ検査を 2 回、for ループで** かけて確かめています。

## コード

```sh:line-numbers=2116
nvm_is_alpha_version() {
  local NVM_ALPHA_VERSION
  NVM_ALPHA_VERSION="${1#v}"
  case "${NVM_ALPHA_VERSION}" in
    *-alpha.*) ;;
    *) return 1 ;;
  esac
  local NVM_ALPHA_PART
  for NVM_ALPHA_PART in "${NVM_ALPHA_VERSION%%-alpha.*}" "${NVM_ALPHA_VERSION#*-alpha.}"; do
    case "${NVM_ALPHA_PART}" in
      *[!0-9.]* | .* | *. | *..* | *.*.*.*) return 1 ;;
      *.*.*) ;;
      *) return 1 ;;
    esac
  done
}
```

## 前提知識

- **`${1#v}`**: 引数の先頭の `v` を取り除きます。
- **`${X%%-alpha.*}`**: 末尾から `-alpha.` 以降を最長で取り除きます。つまり `-alpha.` より **前** が残ります。
- **`${X#*-alpha.}`**: 先頭から `-alpha.` までを最短で取り除きます。つまり `-alpha.` より **後ろ** が残ります。
- **`for 変数 in 値1 値2; do ... done`**: 値を順に変数に入れて繰り返します。
- **`case` のパターン**: `*` は任意の文字列、`[!0-9.]` は数字とドット以外の 1 文字です。`;;` で分岐が終わり、何もしない分岐は `) ;;` と書きます。
- **関数の結果**: 最後まで `return 1` に当たらなければ、関数は成功（0）で終わります。

## 何をしているか

`v4.0.0-alpha.1.2.3` を例に追います。

### 1. `v` を取って形を確認

```sh:line-numbers=2120
    *-alpha.*) ;;
```


`4.0.0-alpha.1.2.3` に `-alpha.` が含まれていなければ、すぐに失敗を返します。

### 2. 前後に分けて検査

for ループの値として、次の 2 つを渡します。

- `${…%%-alpha.*}` → `4.0.0`
- `${…#*-alpha.}` → `1.2.3`

それぞれに対して、次の検査をかけます。

- 数字とドット以外が入っている、ドットで始まる・終わる、ドットが連続する、ドットが 3 つ以上ある → 失敗
- ちょうどドットが 2 つ（`*.*.*`）→ 合格
- それ以外（ドットが 0〜1 個）→ 失敗

`4.0.0` も `1.2.3` も合格なので、ループを抜けて成功で終わります。`v4.0.0-alpha.1` なら、後ろの `1` が「それ以外」に当たって失敗します。

## ここがすごい

- **同じ検査を 1 回だけ書く**: 前と後ろを別々に検査すると、同じ `case` を 2 回書くことになります。for ループの値に 2 つの部分を並べれば、検査は 1 回書くだけで済みます。
- **配列が無くても「リストを回す」**: POSIX シェルには配列がありませんが、`for x in "$A" "$B"` と書けば、任意の値の並びを回せます。ダブルクォートで囲んでいるので、値に空白があっても 1 つの要素として扱われます。
- **パラメータ展開で分割**: `%%` と `#` を使い分けて、区切り文字列の前後を外部コマンドなしで取り出しています。

## まとめ

- 複数の値に同じ処理をするなら、`for x in "$a" "$b"` で並べて回すと重複が減る。
- `${X%%区切り*}` で前、`${X#*区切り}` で後ろを取り出せる。
- `case` で「数字.数字.数字」の形を見分ける定番パターンは、ほかの場面でも使い回せる。
