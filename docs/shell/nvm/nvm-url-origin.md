## ひとことで

`nvm_url_origin` は URL から **オリジン**（スキーム + ホスト + ポート）だけを取り出す関数です。

たとえば `nvm_url_origin https://user@example.com:8080/dist/v20/node.tar.gz` と呼ぶと `https://user@example.com:8080` を返します。たった 3 行ですが、シェルの「パラメータ展開」という文字列操作を上手に組み合わせた例です。

## コード

```sh:line-numbers=239
nvm_url_origin() {
  local NVM_URL_REST
  NVM_URL_REST="${1#*://}"
  nvm_echo "${1%%://*}://${NVM_URL_REST%%/*}"
}
```

## 前提知識

- **オリジン**: Web の世界で「同じ相手かどうか」を判断する単位です。`https://example.com:8080` のように、スキーム（`https`）・ホスト名・ポート番号の組み合わせで決まります。パス（`/dist/...`）は含みません。
- **`$1`**: 関数に渡された 1 番目の引数です。
- **パラメータ展開による文字列の削除**: シェルには、変数の値の一部を取り除く記法があります。`*` は「任意の文字列」を表すワイルドカードです。
  - `${var#パターン}` … 先頭から、パターンに一致する **最短** 部分を削除
  - `${var##パターン}` … 先頭から、**最長** 部分を削除
  - `${var%パターン}` … 末尾から、**最短** 部分を削除
  - `${var%%パターン}` … 末尾から、**最長** 部分を削除
- **`local`**: 関数の中だけで使う変数を宣言します。

覚え方として、キーボードで `#` は `$` の左、`%` は `$` の右にあるので、`#` は左（先頭）、`%` は右（末尾）を削る、と覚えると便利です。

## 何をしているか

入力を `https://user@example.com:8080/dist/v20/node.tar.gz` として追ってみます。

### 1. スキームより後ろを取り出す（241 行目）

`${1#*://}` は、先頭から `*://` に一致する最短部分、つまり `https://` を削除します。結果は次のとおりです。

```
NVM_URL_REST = user@example.com:8080/dist/v20/node.tar.gz
```

### 2. スキームを取り出す（242 行目の前半）

`${1%%://*}` は、末尾から `://*` に一致する最長部分を削除します。`://` 以降すべてが消えて `https` だけが残ります。

### 3. ホスト部分を取り出す（242 行目の後半）

`${NVM_URL_REST%%/*}` は、末尾から `/*` に一致する最長部分、つまり **最初の `/` 以降すべて** を削除します。結果は `user@example.com:8080` です。

### 4. つなげる

最後に `https` + `://` + `user@example.com:8080` をつなげて `nvm_echo` で表示します。

## ここがすごい

- **外部コマンドを一切使わない**: 同じことを `sed` や `awk` でやると、プロセスを起動するぶん遅くなり、正規表現の方言の違い（GNU と BSD）にも気を使う必要があります。パラメータ展開は POSIX で決まっているので、どのシェルでも同じように動きます。
- **最短一致と最長一致の使い分けが的確**: スキームを削るときは `#`（最短）、パスを削るときは `%%`（最長）を選んでいます。もし 242 行目で `%%/*` ではなく `%/*` を使うと、末尾から最短の `/node.tar.gz` だけが消えてしまい、パスが残ってしまいます。
- **用途がはっきりしている**: nvm ではこの関数を、ダウンロードがリダイレクトされたとき「同じオリジンのまま転送されたか」を確かめるのに使っています。認証ヘッダを別のサーバーに送ってしまう事故を防ぐための、セキュリティ上大切な部品です。

なお、この関数は URL の完全な解析器ではありません。たとえば `?` や `#` で始まる部分がホストの直後に来る URL（`https://example.com?x=1`）では、`?x=1` までホスト扱いになります。nvm の用途ではダウンロード用の URL しか来ないので、単純さを優先しています。

## まとめ

- `#`/`##` は先頭から、`%`/`%%` は末尾から削る。1 つは最短、2 つは最長。
- パラメータ展開を組み合わせれば、外部コマンドなしで文字列を分解できる。
- 「完全な解析」が不要なら、用途に合わせた最小限の処理で十分なことが多い。
