## ひとことで

`nvm_num_version_groups` は、バージョン番号がいくつの要素からできているかを数える関数です。`20` なら `1`、`20.1` なら `2`、`v20.1.3` なら `3` を返します。

「ドットで分割して数える」のではなく、**ドット以外を全部消して、残った文字の数を数える** という発想で書かれています。

## コード

```sh:line-numbers=1508
nvm_num_version_groups() {
  local VERSION
  VERSION="${1-}"
  VERSION="${VERSION#v}"
  VERSION="${VERSION%.}"
  if [ -z "${VERSION}" ]; then
    nvm_echo "0"
    return
  fi
  local NVM_NUM_DOTS
  NVM_NUM_DOTS=$(nvm_echo "${VERSION}" | command sed -e 's/[^\.]//g')
  local NVM_NUM_GROUPS
  NVM_NUM_GROUPS=".${NVM_NUM_DOTS}" # add extra dot, since it's (n - 1) dots at this point
  nvm_echo "${#NVM_NUM_GROUPS}"
}
```

## 前提知識

- **`${VERSION#v}`**: 先頭の `v` を取り除きます。
- **`${VERSION%.}`**: 末尾のドットを 1 つ取り除きます（`20.` → `20`）。
- **`[ -z 文字列 ]`**: 空なら真です。
- **`sed -e 's/[^\.]//g'`**: sed の置換です。`s/A/B/g` は「A を B に全部置き換える」、`[^\.]` は「ドット以外の 1 文字」です。B が空なので、ドット以外が全部消えます。
- **`${#変数}`**: 変数の値の文字数です。
- **`return`**: 引数なしで書くと、直前のコマンドの終了ステータスで関数を終わります。

## 何をしているか

`v20.1.3` を例に追います。

### 1. 前後を整える（1510〜1512 行目）

`v` を取って `20.1.3` にします。末尾がドットなら取り除きます。

### 2. 空なら 0（1513〜1516 行目）

何も残らなければ、要素は 0 個です。

### 3. ドットだけを残す（1518 行目）

`sed 's/[^\.]//g'` で、数字などドット以外をすべて消します。`20.1.3` → `..` になります。

### 4. ドットを 1 つ足して数える（1520〜1521 行目）

要素の数は「ドットの数 + 1」です。そこで `.` を 1 つ前に足して `...` とし、`${#NVM_NUM_GROUPS}` で文字数 `3` を得ます。1520 行目のコメント「n - 1 個のドットなので、1 つ足す」はこのことです。

## ここがすごい

- **数え方の発想を変えている**: シェルで「区切って数える」には、`IFS` を変えたりループを書いたりする必要があります。「数えたいもの以外を消して長さを測る」なら、置換 1 回と `${#}` だけで済みます。
- **算術を使わずに +1 する**: `$(( n + 1 ))` を使わず、文字を 1 つ足してから長さを測ることで、「数える」と「1 を足す」を同時にやっています。
- **前処理で例外をなくす**: 末尾のドット（`20.`）を先に取り除いておくことで、`20.` が 2 要素と数えられるのを防いでいます。

同じ「消して数える」技は、たとえば `tr -cd '\n' | wc -c` で改行の数を数えるときなど、いろいろな場面で使えます。

## まとめ

- 「特定の文字がいくつあるか」は、それ以外を消して長さを測ると簡単に数えられる。
- `${#var}` で文字数がわかる。
- 区切りの数と要素の数は 1 つずれることに注意する。
