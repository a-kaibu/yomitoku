## ひとことで

`strip_sequences 文字列` は、文字列の中に含まれる **色を変えるための制御文字**（エスケープシーケンス）を取り除いて、見た目の文字だけを返す関数です。

たとえば `\e[31mred\e[0m` は `red` になります。色の指定は、画面には文字として見えませんが、文字列の長さとしては数えられてしまいます。見た目の幅を計算するときには、先に取り除いておく必要があります。

## コード

```bash:line-numbers=4662
strip_sequences() {
    strip="${1//$'\e['3[0-9]m}"
    strip="${strip//$'\e['[0-9]m}"
    strip="${strip//\\e\[[0-9]m}"
    strip="${strip//$'\e['38\;5\;[0-9]m}"
    strip="${strip//$'\e['38\;5\;[0-9][0-9]m}"
    strip="${strip//$'\e['38\;5\;[0-9][0-9][0-9]m}"

    printf '%s\n' "$strip"
}
```

## 前提知識

- **エスケープシーケンス**: `\e` で始まる特殊な文字列で、端末に色や太字などを指示します。`\e[31m` は赤、`\e[0m` は元に戻す、という意味です。
- **`${変数//パターン/置換}`**: 変数の中のパターンに一致する部分を、すべて置き換えます。置換が空なら、一致した部分を消します。
- **`$'\e['`**: bash の ANSI-C 形式の文字列で、`\e` を ESC 文字として扱います。
- **`[0-9]`**: 0 から 9 までの 1 文字に一致するパターンです。
- **`\;`**: パターンの中で、セミコロンを文字そのものとして扱うための記号です。

## 何をしているか

### 1. 色の番号ごとに消す

```bash:line-numbers=4663
    strip="${1//$'\e['3[0-9]m}"
    strip="${strip//$'\e['[0-9]m}"
    strip="${strip//\\e\[[0-9]m}"
```

`\e[3X m`（文字色）と、`\e[X m`（1 桁の番号）の形を消します。ここでは、30 から 39 までの色と、0 から 9 までの指定を消します。

### 2. 256 色の指定を消す

```bash:line-numbers=4666
    strip="${strip//$'\e['38\;5\;[0-9]m}"
    strip="${strip//$'\e['38\;5\;[0-9][0-9]m}"
    strip="${strip//$'\e['38\;5\;[0-9][0-9][0-9]m}"
```

`\e[38;5;N m` の形は、256 色の指定です。番号が 1 桁、2 桁、3 桁のものをそれぞれ消します。

### 3. 結果を表示する

```bash:line-numbers=4670
    printf '%s\n' "$strip"
```

消し終わった文字列を、`printf` で改行を付けて表示します。

## ここがすごい

- **桁数ごとに分けて消している**: 256 色の番号は 1 桁から 3 桁まであるため、それぞれの形を明示して消しています。単純な 1 つのパターンでは、全部は取れません。
- **外部コマンドを使わない**: `sed` を呼ばず、シェルの変数置換だけで処理しています。neofetch は情報を素早く表示するツールなので、起動のオーバーヘッドを減らしています。
- **置換の順番に注意**: 長い形のものを先に消すのではなく、順番に確実に消していく書き方です。同じ処理を繰り返すので、読みやすく、直しやすくなっています。

## まとめ

- 色の制御文字を除くと、文字の幅を正しく数えられる。
- シェルの変数置換は、外部コマンドを使わずに文字列を加工できる。
- 256 色のように番号の桁数が違う形は、それぞれを明示して扱う。
