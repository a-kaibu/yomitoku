## ひとことで

`color 番号` は、端末の文字色を変えるための **エスケープ文字列** を表示する関数です。`color 1` なら赤、`color 200` なら 256 色パレットの 200 番の色を指定する文字列を出します。

neofetch は、ロゴや情報の文字に色を付けるとき、この関数を使います。色の番号の範囲によって、基本色と 256 色のどちらの形式を使うかを、`case` で切り替えています。

## コード

```bash:line-numbers=4725
color() {
    case $1 in
        [0-6])    printf '%b\e[3%sm'   "$reset" "$1" ;;
        7 | "fg") printf '\e[37m%b'    "$reset" ;;
        *)        printf '\e[38;5;%bm' "$1" ;;
    esac
}
```

## 前提知識

- **`case 値 in パターン) ... ;; esac`**: 値をパターンと順番に照合し、最初に一致した分岐だけを実行します。
- **`[0-6]`**: 0 から 6 までの 1 文字に一致するパターンです。
- **`printf '%b...'`**: `%b` は、文字列の中のエスケープ（`\e` など）を解釈して出力します。
- **`${reset}`**: 色を元に戻すエスケープの文字列です。
- **`\e[38;5;Nm`**: 256 色の文字色を指定する形式です。`38;5` は「256 色を使う」という意味、`N` が色の番号です。
- **`\e[3Nm`**: 基本の 8 色の文字色を指定する形式です。`N` は 0 から 7 です。

## 何をしているか

### 1. 基本色の番号

```bash:line-numbers=4727
        [0-6])    printf '%b\e[3%sm'   "$reset" "$1" ;;
```

0 から 6 の番号は、`\e[3Nm` の形で基本の色にします。`%s` の位置に番号が入ります。

### 2. 白の指定

```bash:line-numbers=4728
        7 | "fg") printf '\e[37m%b'    "$reset" ;;
```

7 または `fg` の指定は、白の色を表す `\e[37m` に変換します。

### 3. それ以外は 256 色

```bash:line-numbers=4729
        *)        printf '\e[38;5;%bm' "$1" ;;
```

それ以外の値は、`\e[38;5;Nm` の形で 256 色の番号として扱います。`color 200` なら 200 番の色になります。

どの場合も、出力の前に `reset` を付けて、前の色の影響を消しています。

## ここがすごい

- **番号の範囲で形式を切り替える**: 基本の色と 256 色で、エスケープの書き方が違います。`case` の順番で、その違いを 1 か所で扱っています。
- **同じ見た目の指定を統一**: 7 と `fg` の両方を白として扱うなど、呼ぶ側が覚えやすい指定にしています。
- **色の処理を 1 つにまとめる**: 色の番号から文字列を作る部分を関数にしたので、ロゴの色も情報の色も同じ方法で指定できます。

## まとめ

- 数字の範囲によって、処理を切り替えると指定方法を単純にできる。
- 端末の色は、基本色と 256 色で書き方が違うので、両方に対応する。
- 色を変えたら、元に戻す指定を忘れずに付ける。
