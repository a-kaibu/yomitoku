## ひとことで

`throw` は、**JSON の解析が失敗したとき、理由を出して終了する** 関数です。例外の仕組みを持たないシェルで、エラーを扱うための簡単な代わりです。

`jsonsh` の中に置かれていて、解析の各段階から呼ばれます。失敗したら、その場で止めるという単純な作りです。

## コード

```bash:line-numbers=98
  throw() {
    echo "$*" >&2
    exit 1
  }
```

## 前提知識

- **例外**: 他の言語では、エラーを投げて途中の処理を飛ばす仕組みがあります。シェルにはこの仕組みがありません。
- **`$*`**: 関数に渡された引数を、全部まとめた 1 つの文字列として扱う指定です。
- **入れ子の関数**: 関数の中で定義された関数です。ここでは、`jsonsh` の中だけで使えます。
- **`exit 1`**: エラーを示す終了コードで、スクリプト全体を止めます。

## 何をしているか

### 1. 渡されたメッセージを標準エラーに出す

```bash:line-numbers=99
    echo "$*" >&2
```

引数を全部まとめて、標準エラーに書き出します。どの内容で失敗したかが、そのまま見えます。

### 2. スクリプトを終了させる

```bash:line-numbers=100
    exit 1
```

終了コード 1 で止めます。途中の解析は続けません。

## ここがすごい

- **失敗を隠さない**: 途中で止めて、メッセージを出すので、壊れた結果が後へ流れません。
- **例外の代わりを用意する**: シェルに無い仕組みを、単純な関数で補っています。
- **範囲を閉じる**: 入れ子の関数にしたので、`jsonsh` の外からは見えません。名前の衝突も避けられます。

## まとめ

- 例外の無い言語では、失敗を標準エラーに出して止める関数を作ると分かりやすい。
- 入れ子の関数にすると、影響の範囲を閉じられる。
- 失敗時は途中の結果を残さず、すぐ終わる。
