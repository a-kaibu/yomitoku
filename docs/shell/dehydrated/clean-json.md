## ひとことで

`clean_json` は、**JSON の文字列から改行と余分な空白を取り除き、1 行に整える** 関数です。整えた文字列は、後の解析や比較がしやすくなります。

API の応答は、見やすさのために改行や空白を含むことがあります。それを機械的に扱うには、形を揃えておく必要があります。

## コード

```bash:line-numbers=918
clean_json() {
  tr -d '\r\n' | _sed -e 's/ +/ /g' -e 's/\{ /{/g' -e 's/ \}/}/g' -e 's/\[ /[/g' -e 's/ \]/]/g'
}
```

## 前提知識

- **`tr -d '\r\n'`**: 改行の文字（CR と LF）を、削除する指定です。
- **正規表現による置き換え**: `sed` の `-e` で、複数の置き換えを順に行えます。
- **`_sed`**: この実装で使われる sed の包みです。
- **JSON の構造**: 波括弧 `{}` と角括弧 `[]` で、値の入れ物を表します。

## 何をしているか

### 1. 改行と復帰を消す

```bash:line-numbers=919
  tr -d '\r\n' | _sed -e 's/ +/ /g' -e 's/\{ /{/g' -e 's/ \}/}/g' -e 's/\[ /[/g' -e 's/ \]/]/g'
```

`tr` で、CR と LF の文字を取り除きます。これで、1 行の文字列になります。

### 2. 空白を整える

```bash:line-numbers=919
  tr -d '\r\n' | _sed -e 's/ +/ /g' -e 's/\{ /{/g' -e 's/ \}/}/g' -e 's/\[ /[/g' -e 's/ \]/]/g'
```

連続する空白を 1 つにまとめ、括弧の内側や前後の空白を詰めます。たとえば `{ "a": 1 }` は `{"a": 1}` のようになります。

## ここがすごい

- **段階的な置き換え**: 空白の整理と括弧の整理を、順番に `-e` で並べています。それぞれの意図が分かりやすい書き方です。
- **改行の除去を最初に**: 改行を先に消すので、後の置き換えが 1 行の前提で書けます。
- **解析の前処理に向く**: 形が一定になるので、後の読み取りが単純になります。

## まとめ

- 外部からの文字列は、解析の前に形を揃えると扱いやすい。
- 置き換えは順番を意識して並べると、意図が伝わる。
- 改行の除去は最初に行うと、後の処理を単純にできる。
