## ひとことで

`get_json_string_value キー` は、JSON の中の **文字列の値** を 1 つ取り出して表示する関数です。たとえば `"contact"` に対応する `"mailto:admin@example.com"` の中身を返します。

JSON を正しく読むには、本来は専用のパーサーが必要です。しかし dehydrated は、追加のツールを増やさずに動くことを重視しています。そこで、1 行の中から「キー」の後ろにある文字列だけを、正規表現で切り出す方法を使っています。

## コード

```bash:line-numbers=60
get_json_string_value() {
  local filter
  filter="$(printf 's/.*\[%s\][[:space:]]*"\([^"]*\)"/\\1/p' "$(json_path "${1:-}" "${2:-}")")"
  sed -n "${filter}"
}
```

## 前提知識

- **`sed -n '...p'`**: `sed` は行を 1 つずつ処理するコマンドです。`-n` は通常の出力を止め、`p` が付いた行だけを表示します。
- **`s/パターン/置換/p`**: パターンに一致する部分を置換し、置き換わった行を表示します。
- **`\(...\)` と `\1`**: 正規表現の中で `\(...\)` は、一致した部分を覚える印です。置換側の `\1` で、その覚えた部分を取り出せます。
- **`[^"]*`**: ダブルクォート以外の文字が 0 個以上続く、という意味です。文字列の中身を取り出すときによく使われます。
- **`local filter`**: 関数の中だけで使う変数を作ります。

## 何をしているか

### 1. 検索と取り出しのパターンを作る

```bash:line-numbers=62
  filter="$(printf 's/.*\[%s\][[:space:]]*"\([^"]*\)"/\\1/p' "$(json_path "${1:-}" "${2:-}")")"
```

`json_path` でキーのパターンを作り、`printf` で `sed` 用の置換命令の形にします。たとえばキーが `contact` なら、次のような命令ができます。

```
s/.*\[contact\][[:space:]]*"\([^"]*\)"/\1/p
```

これは「`[contact]` の後に空白があり、ダブルクォートで囲まれた文字列を、その中身だけに置き換えて表示する」という意味です。

### 2. sed で行を処理する

```bash:line-numbers=63
  sed -n "${filter}"
```

作った命令を `sed -n` に渡します。標準入力から行が流れてきて、キーに一致する行だけが、値の部分に置き換えられて表示されます。

## ここがすごい

- **依存するツールが少ない**: `jq` のような外部ツールを入れなくても、`sed` と `printf` だけで動きます。サーバーで設定を読むだけのスクリプトには、この手軽さが大切です。
- **パターンを組み立てて使う**: 検索するキーの名前を、そのまま正規表現に埋め込んでいます。`json_path` で引用符などを整えてから使うので、キーの書き方の違いに対応できます。
- **限界を理解して使う**: この方法は、1 行に 1 つのキーと値がある、という前提で動きます。どんな JSON でも正しく読めるわけではありません。dehydrated はその前提に合った使い方をしています。

## まとめ

- JSON の一部を取り出すだけなら、正規表現と `sed` で十分なことがある。
- 置換の `\(...\)` と `\1` で、一致した部分の一部を取り出せる。
- 前提（1 行 1 項目）を理解して使えば、道具を減らせる。
