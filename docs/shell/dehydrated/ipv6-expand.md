## ひとことで

`ipv6_expand` は、**`::` で省略された IPv6 アドレスを、省略なしの完全な形に広げる** 関数です。たとえば `2001:db8::1` は、8 つの区切りを持つ形になります。

IPv6 のアドレスは、省略の書き方が何通りもあります。同じアドレスでも、表記が違うと比べられません。完全な形に揃えると、比較と変換が確実になります。

## コード

::: code-group

```bash:line-numbers=256 [日本語訳]
ipv6_expand() {
  # 区切りが 8 つになるまで、:: を広げます。
  # 残った :: を 1 つの : に直します。
  # すべての区切りを、先頭に 0 を補って 4 桁にします。
  _sed \
    -e ':addsegs; /^([^:]*:){0,7}[^:]*$/{ s/::/:0000::/g; t addsegs; }' \
    -e 's/::/:/' \
    -e ':padsegs; s/(:|^)([^:]{0,3})(:|$)/\10\2\3/g; t padsegs;'
}
```

```bash:line-numbers=256 [原文]
ipv6_expand() {
  # expand double colons until 8 segments exist
  # replace remaining double colon with single colon
  # pad all segments to 4 characters with leading zeros
  _sed \
    -e ':addsegs; /^([^:]*:){0,7}[^:]*$/{ s/::/:0000::/g; t addsegs; }' \
    -e 's/::/:/' \
    -e ':padsegs; s/(:|^)([^:]{0,3})(:|$)/\10\2\3/g; t padsegs;'
}
```

:::

## 前提知識

- **IPv6 アドレス**: 16 ビットの区切りを 8 つ、コロンで並べた表記です。
- **`::`**: 連続する 0 の区切りをまとめて省略する書き方です。1 つのアドレスに 1 回だけ使えます。
- **正規表現の繰り返し `{0,7}`**: 直前の部分を、0 回から 7 回まで繰り返すことを表します。
- **`t` 命令**: sed で、置き換えが成功したら、指定のラベルへ戻る命令です。ループの仕組みです。

## 何をしているか

### 1. 区切りが 8 つになるまで省略を広げる

```bash:line-numbers=259
  # すべての区切りを、先頭に 0 を補って 4 桁にします。
```

区切りが足りないあいだ、`::` を `:0000::` に置き換えて、0 の区切りを増やします。`t` で、置き換えが続くかぎり繰り返します。

### 2. 残った `::` を 1 つの `:` にする

```bash:line-numbers=260
  _sed \
```

区切りが揃ったあと、残っている `::` を 1 つの `:` に直します。

### 3. 各区切りを 4 桁にそろえる

```bash:line-numbers=261
    -e ':addsegs; /^([^:]*:){0,7}[^:]*$/{ s/::/:0000::/g; t addsegs; }' \
    -e 's/::/:/' \
```

3 桁以下の区切りの先頭に 0 を補って、どの区切りも 4 桁にそろえます。ループを使い、すべての区切りに適用します。

## ここがすごい

- **規則をそのまま書く**: 区切りを増やし、省略を戻し、桁を揃える、という手順が、コメントの順に並んでいます。
- **同じ道具で完結する**: sed の繰り返しだけで、すべての変換を行います。外部の IPv6 の道具は要りません。
- **比較の土台になる**: 完全な形にそろえると、表記の違うアドレスも同じ文字列として比べられます。

## まとめ

- 表記が揺れるデータは、正規の完全な形に広げてから比べる。
- 繰り返しの変換は、ループの命令で段階的に書くと分かりやすい。
- 段階の順番を、コメントで先に示すと読み手が流れを追える。
