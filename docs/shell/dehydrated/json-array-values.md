## ひとことで

`get_json_array_values` は、**JSON の配列の中身を、1 行に 1 つずつ取り出す** 関数です。JSON を解析して得た `パス 値` の形の行から、配列の値だけを選び出します。

外部の JSON 解析ツールを使わず、シェルの道具だけで配列を読むための仕組みです。dehydrated は、この方法で設定を読みます。

## コード

```bash:line-numbers=67
get_json_array_values() {
  grep -E '^\['"$(json_path "${1:-}" "${2:-}")"',[0-9]*\]' | sed -e 's/\[[^\]*\][[:space:]]*//g' -e 's/^"//' -e 's/"$//'
}
```

## 前提知識

- **JSON の配列**: `["a", "b"]` のように、順番のある値の並びです。
- **`json_path`**: 配列の位置や名前を、解析結果の行の形に直す関数です。同じファイル内で定義されています。
- **`grep -E`**: 正規表現に一致する行だけを出すコマンドです。
- **`sed`**: 行の文字列を置き換える道具です。引用符や余分な空白を取り除くのに使われます。

## 何をしているか

### 1. 配列の要素の行を選ぶ

```bash:line-numbers=68
  grep -E '^\['"$(json_path "${1:-}" "${2:-}")"',[0-9]*\]' | sed -e 's/\[[^\]*\][[:space:]]*//g' -e 's/^"//' -e 's/"$//'
```

`json_path` で作った条件を使い、配列の要素の行だけを `grep` で選びます。`[0-9]*` が、添字の数に対応します。

### 2. 値を整えて表示する

```bash:line-numbers=68
  grep -E '^\['"$(json_path "${1:-}" "${2:-}")"',[0-9]*\]' | sed -e 's/\[[^\]*\][[:space:]]*//g' -e 's/^"//' -e 's/"$//'
```

`sed` で、パスの部分と、前後の引用符を取り除きます。残った値を、1 行ずつ表示します。

## ここがすごい

- **外部ツールに頼らない**: JSON の解析器を入れずに、標準の道具で配列を読めます。移植性が高く、導入の手間がありません。
- **条件を 1 か所にまとめる**: パスの作り方を `json_path` に任せているので、この関数は値の抽出だけに集中しています。
- **引用符の後始末**: 文字列の値は、前後の引用符を外して返します。後続の処理で、そのまま使えます。

## まとめ

- JSON を標準の道具で扱うときは、行の形に変えてから抜き出すと簡単。
- パスの作成と値の抽出を分けると、役割が明確になる。
- 文字列の後始末は、必ず最後にまとめて行う。
