## ひとことで

`verbose_log 項目 値` は、環境変数 `SHOW_VERBOSE_LOG` が `true` のときだけ、項目名と値を表示する関数です。表示先は **標準エラー**（ターミナルの警告やエラーと同じ場所）です。

`n` は Node.js のバージョンを切り替えるツールです。普段は静かに動き、問題の調査をしたいときだけ、詳しい情報を見られるようにしています。

## コード

```bash:line-numbers=19
verbose_log() {
  if [[ "${SHOW_VERBOSE_LOG}" == "true" ]]; then
    >&2 printf "  ${SGR_CYAN}%10s${SGR_RESET} : ${SGR_FAINT}%s${SGR_RESET}\n" "$1" "$2"
  fi
}
```

## 前提知識

- **標準出力と標準エラー**: 通常の結果は標準出力に、警告やエラーは標準エラーに出します。標準エラーに出せば、結果をファイルに保存しても、ログは画面に残ります。
- **`>&2`**: その命令の出力を、標準エラーに送るという意味です。
- **`printf 書式 引数`**: 書式に従って出力します。`%10s` は、10 文字の幅で右寄せに表示します。
- **`${SGR_CYAN}` などの変数**: 色や文字の飾りを表すエスケープの文字列です。`${SGR_RESET}` で元に戻します。
- **`[[ 文字列 == 文字列 ]]`**: 2 つの文字列が等しいかを調べる条件式です。

## 何をしているか

### 1. 表示するかを決める

```bash:line-numbers=20
  if [[ "${SHOW_VERBOSE_LOG}" == "true" ]]; then
```

`SHOW_VERBOSE_LOG` が `true` と等しいときだけ、次の行を実行します。それ以外では、何も表示されません。

### 2. 項目名と値を表示する

```bash:line-numbers=21
    >&2 printf "  ${SGR_CYAN}%10s${SGR_RESET} : ${SGR_FAINT}%s${SGR_RESET}\n" "$1" "$2"
```

`>&2` で標準エラーに送り、`%10s` で項目名を 10 文字の幅に揃えて色を付けて表示します。値は薄い色で続けます。最後の `\n` で改行します。

このため、ログは次のように、項目ごとに縦にそろって表示されます。

```
     ARCH : x64
     PATH : /home/me/.n/bin
```

## ここがすごい

- **通常の出力を汚さない**: 標準エラーに出すので、`n` の結果を別のコマンドに渡しても、ログが混ざりません。
- **普段は完全に静か**: 変数が `true` でなければ、何も表示しません。調べたいときだけ、環境変数を付けて実行します。
- **表示を整える**: 幅を揃えて表示するので、ログを読むときに項目が見つけやすくなります。

## まとめ

- デバッグ用のログは、標準エラーに出すと結果と混ざらない。
- 環境変数のスイッチで、ログの有無を切り替えられる。
- `printf` の幅指定で、ログを縦にそろえて読みやすくできる。
