## ひとことで

`_fzf_complete_ssh` は、`ssh` コマンドの補完で **ホスト名の候補を fzf で選ばせる** 関数です。`ssh user@` と入力したあとにタブを押すと、`user@` を付けた形のホスト名が候補になります。

ただし、`-i` や `-F` などのオプションの直後は、ホスト名ではなく **ファイル名** を入力する場面です。そのときは、通常のパス補完に切り替えます。状況に応じて補完の中身を変えるのが、この関数の役割です。

## コード

```bash:line-numbers=593
_fzf_complete_ssh() {
  case $3 in
    -i | -F | -E)
      _fzf_path_completion "$@"
      ;;
    *)
      local user=
      [[ $2 =~ '@' ]] && user="${2%%@*}@"
      _fzf_complete +m -- "$@" < <(__fzf_list_hosts | __fzf_exec_awk -v user="$user" '{print user $0}')
      ;;
  esac
}
```

## 前提知識

- **補完の関数**: bash では、コマンドごとに補完の関数を登録して、タブキーで候補を出します。この関数も、その 1 つです。
- **`$3`**: 補完の関数に渡される引数のうち、3 番目です。ここでは、直前に打った単語を表しています。
- **`case ... esac`**: 値を順番に照合して、一致した分岐だけを実行します。
- **`[[ $2 =~ '@' ]]`**: 文字列にアットマーク `@` が含まれるかを調べます。
- **`${2%%@*}`**: 末尾から `@` 以降を最長で取り除きます。残るのは、`@` より前のユーザー名の部分です。
- **`< <(...)`**: コマンドの出力を、入力としてプロセス置換で渡します。

## 何をしているか

### 1. オプションの直後ならパス補完

```bash:line-numbers=595
    -i | -F | -E)
      _fzf_path_completion "$@"
      ;;
```

`-i`、`-F`、`-E` の直後は、ファイル名を入力する場面なので、`_fzf_path_completion` を呼びます。

### 2. ユーザー名の部分を覚える

```bash:line-numbers=599
      local user=
      [[ $2 =~ '@' ]] && user="${2%%@*}@"
```

`user=` を空にしてから、`@` が含まれていればその前の部分を取り出します。`user@` の形で、後で候補に付け直すためです。

### 3. ホスト名の候補を作って選ばせる

```bash:line-numbers=601
      _fzf_complete +m -- "$@" < <(__fzf_list_hosts | __fzf_exec_awk -v user="$user" '{print user $0}')
```

`__fzf_list_hosts` でホスト名の一覧を作り、`__fzf_exec_awk` で各行の先頭に `user@` を付けます。その結果を `_fzf_complete` に渡して、fzf で選ばせます。

## ここがすごい

- **状況に応じて候補の種類を変える**: ホスト名とファイル名という、まったく違う候補を、同じ補完の入り口で切り替えています。
- **入力を壊さない**: ユーザー名の部分を取り出して、候補に付け直しているので、入力途中の `user@` が消えません。
- **既存の仕組みを組み合わせる**: パス補完、ホスト一覧、fzf の選択を、それぞれの関数に任せています。この関数は組み合わせと振り分けだけを担当します。

## まとめ

- 補完の候補は、直前の入力によって種類を変えられる。
- 入力途中の文字列は、取り出して候補に付け直すと保てる。
- 小さな関数を組み合わせると、補完の振り分けがシンプルになる。
