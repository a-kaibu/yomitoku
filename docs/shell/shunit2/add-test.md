## ひとことで

`suite_addTest` は、**テストの関数名を一覧へ加える** 関数です。テストの実行前に、どの関数を走らせるかを登録します。

shUnit2 では、テストは普通の関数として書きます。その名前を、この関数で一覧に入れておくと、後でまとめて実行されます。

## コード

```bash:line-numbers=1020
suite_addTest() {
  shunit_func_=${1:-}

  __shunit_suite="${__shunit_suite:+${__shunit_suite} }${shunit_func_}"
  __shunit_testsTotal=`expr "${__shunit_testsTotal}" + 1`

  unset shunit_func_
}
```

## 前提知識

- **テストスイート**: 複数のテストをひとまとめにして、一度に実行する単位です。
- **`${1:-}`**: 引数が無いときに、空の文字列を入れる書き方です。エラーで止まるのを防ぎます。
- **`${変数:+値}`**: 変数が空でなければ、指定した値を使う書き方です。空の一覧に、余計な空白を入れないために使われます。
- **`expr`**: 数式を計算する外部のコマンドです。ここでは、テストの総数に 1 を足すために使われています。

## 何をしているか

### 1. テスト名を受け取る

```bash:line-numbers=1021
  shunit_func_=${1:-}
```

最初の引数を、一時的な変数に入れます。引数が無いときは、空の文字列になります。

### 2. 一覧の末尾に空白区切りで足す

```bash:line-numbers=1023
  __shunit_suite="${__shunit_suite:+${__shunit_suite} }${shunit_func_}"
```

すでに一覧があれば、空白を 1 つ挟んで足します。一覧がまだ空なら、空白を入れずに名前だけを入れます。

### 3. テストの総数を 1 増やす

```bash:line-numbers=1024
  __shunit_testsTotal=`expr "${__shunit_testsTotal}" + 1`

```

`expr` で、総数に 1 を足します。結果は、後で報告する件数として使われます。

## ここがすごい

- **名前だけを集める**: テストの本体は関数として別に書かれています。この関数は、名前の一覧を作るだけなので、仕組みが小さく済みます。
- **空白の扱いが丁寧**: 最初の 1 件だけ空白を入れないようにしています。余計な空白が入ると、後で名前を取り出すときに問題が出るためです。
- **数を同時に数える**: 追加するたびに総数も増やします。実行の前に、件数が正しく分かります。

## まとめ

- テストは関数の名前を一覧にして管理すると、後からまとめて扱える。
- 区切り文字は、最初の要素だけ特別扱いすると、余分な空白を防げる。
- 件数のような集計は、登録と同時に更新すると、ずれにくい。
