## ひとことで

Scala の標準ライブラリに入っている MurmurHash3 で、ハッシュ値の途中経過に 32 ビット分のデータを混ぜ込む `mix` です。使っているのは XOR（排他的論理和）、回転、掛け算、足し算だけで、どれも 1 命令で終わる軽い計算です。

## コード

```scala:line-numbers=20
  final def mix(hash: Int, data: Int): Int = {
    var h = mixLast(hash, data)
    h = rotl(h, 13)
    h * 5 + 0xe6546b64
  }
```

## 前提知識

- `Int` は 32 ビットの整数です。`*` は掛け算、`+` は足し算、`^` は XOR（ビットごとに「違うときだけ 1」にする演算）です。
- ハッシュ値は、任意のデータを「ほぼ散らばった数値」に変換した結果です。`Map` や `Set` のキーを格納場所に振り分けるときに使われます。
- 「回転（rotate）」は、ビット列を左にずらし、左端からはみ出したビットを右端に戻す操作です。`rotl(h, 13)` は 13 ビット左に回転させます。
- `final def` は、子クラスで上書きできないメソッドです。Scala では `def` で関数を書き、`=` の後ろに本体を書きます。
- `var` は後から書き換えられる変数です。ここでは `h` の値を段階的に変えています。

## 何をしているか

### 1. 混ぜる対象のデータを先に処理する

最初の行で、`mixLast` を呼んでデータを混ぜ込みます。`mixLast` は引数 `data` を掛け算と回転で撹拌し、その結果を `hash` と XOR します。

```scala:line-numbers=21
    var h = mixLast(hash, data)
```

ここでは `h` に、今までのハッシュと新しいデータの混ぜ合わせが入ります。

### 2. ビットを回して上位と下位を入れ替える

次の行では、`h` を 13 ビット左に回転させます。掛け算は下位ビットを上位に押し上げ、上位ビットは捨てられます。回転を挟むことで、上位に寄ったビットも下位に戻り、次の掛け算で再び混ざります。

```scala:line-numbers=22
    h = rotl(h, 13)
```

### 3. 定数で掛けて足す

最後の行は、`h` を 5 倍して `0xe6546b64` を足します。`5` と `0xe6546b64` は MurmurHash3 の仕様で決められた定数です。定数を足すことで、入力が全部 0 のときでも値が 0 のままにならないようになっています。

```scala:line-numbers=23
    h * 5 + 0xe6546b64
```

これで 1 ブロック分の混ぜ込みが終わり、戻り値が次の `mix` 呼び出しの `hash` になります。

## ここがすごい

- ハッシュは「データを順に読んで少しずつ状態を更新する」形で作られます。`mix` は状態を 1 回の呼び出しで大きく変えるため、少し違う入力でも結果が大きく変わります。
- XOR だけで混ぜると、同じデータを 2 回入れたときに打ち消し合ってしまいます。掛け算と回転を組み合わせることで、その打ち消しを防いでいます。
- `mix` と `mixLast` を分けている点も工夫です。途中のブロックはすべてを撹拌し、最後のブロックは撹拌を省いて速くします。最後の仕上げは `finalizeHash` でまとめて行うので、結果の質は落ちません。
- 素直に「文字列を 1 文字ずつ `hashCode` にする」方法と比べると、ビット演算だけで完結するので、JVM 上でも余計なオブジェクトを作らずに済みます。

## まとめ

- ハッシュは、データを 1 ブロックずつ状態に混ぜ込んでいく処理で作れます。
- XOR・回転・掛け算の組み合わせで、入力の小さな違いをハッシュ全体へ広げられます。
- 定数は仕様で決まっています。自分で作るときも、同じ種類の演算を組み合わせるのが基本です。
