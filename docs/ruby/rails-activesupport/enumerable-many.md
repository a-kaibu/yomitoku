## ひとことで

`many?` は、コレクション（配列など）に **要素が 2 つ以上あるか** を調べるメソッドです。
`[1, 2].many?` は `true`、`[1].many?` は `false` です。
ブロックを渡すと、`people.many? { |p| p.age > 26 }` のように「条件に合うものが 2 つ以上あるか」も調べられます。

## コード

```ruby:line-numbers=99
  def many?
    cnt = 0
    if block_given?
      any? do |*args|
        cnt += 1 if yield(*args)
        cnt > 1
      end
    else
      any? { (cnt += 1) > 1 }
    end
  end
```

## 前提知識

- **Enumerable モジュール**: Ruby で「要素を順番に取り出せるもの」（配列、ハッシュ、範囲など）が共通して使えるメソッドの詰め合わせです。`each` さえ定義すれば、`map` や `select`、`any?` などが使えるようになります。Rails はここに `many?` を追加しています。
- **`any? { ... }`**: ブロックが真を返す要素が 1 つでもあれば `true` を返します。**真になった時点で残りの要素を見ずに終わります。**
- **ブロックは外側の変数を変更できる**: ブロックの中から、メソッドの中で作った変数 `cnt` を読み書きできます（クロージャ）。
- **`|*args|`**: ブロックが受け取る引数をすべて配列にまとめます。ハッシュのように 1 回に 2 つ（キーと値）渡される場合にも対応できます。
- **`(cnt += 1) > 1`**: `cnt` を 1 増やし、その **増やした後の値** が 1 より大きいかを調べます。

## 何をしているか

### 1. カウンタを用意する

```ruby:line-numbers=100
    cnt = 0
```
見つけた要素の数を数える `cnt` を 0 にします。

### 2. ブロックがあるとき

```ruby:line-numbers=101
    if block_given?
      any? do |*args|
        cnt += 1 if yield(*args)
        cnt > 1
      end
```
`any?` に「条件に合えば数を増やし、2 以上になったら真を返す」ブロックを渡します。
`[30, 20, 40, 50].many? { |age| age > 26 }` で追うと、

1. 30 → 条件に合うので `cnt = 1`。`1 > 1` は偽なので続ける。
2. 20 → 条件に合わない。`cnt` は 1 のまま。偽。
3. 40 → `cnt = 2`。`2 > 1` は真なので `any?` が終わり、`true` を返す。

4 つ目の 50 は調べられません。

### 3. ブロックがないとき

```ruby:line-numbers=107
      any? { (cnt += 1) > 1 }
```
要素の中身は気にせず、取り出すたびに数えるだけです。2 つ目の要素で `true` になって終わります。要素が 0 個か 1 個なら最後まで真にならず、`false` になります。

## ここがすごい

### 数え切らない

`to_a.size > 1` や `count > 1` でも答えは出ます。しかし、それでは要素を **全部** 数えることになります。100 万件のコレクションでも、知りたいのは「2 つ以上か」だけなので、2 つ見つけた時点で止まれば十分です。

### 早期終了を自分で書かずに any? に任せる

`each` でループして `return true` する書き方もできますが、このコードは `any?` の「真になったら止まる」性質を借りています。カウンタの更新と判定を 1 つのブロックにまとめることで、ループと脱出の処理を書かずに済んでいます。

### `each` が重いものほど効く

データベースの問い合わせ結果のように、要素を 1 つ取り出すのにコストがかかるコレクションでは、途中で止まることの効果が大きくなります（Active Record の関連には、さらに専用の `many?` が用意されています）。

## まとめ

- 「n 個以上あるか」を知りたいときは、全部数えず n 個目で止めるとよいです。
- `any?` や `find` のような「見つかったら止まる」メソッドは、早期終了の部品として使えます。
- ブロックから外側の変数を更新できるので、状態を持った判定も短く書けます。
