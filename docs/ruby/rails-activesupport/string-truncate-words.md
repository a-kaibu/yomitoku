## ひとことで

`truncate_words(n)` は、文字列を **先頭から n 単語だけ残して切り詰める** メソッドです。
`"Once upon a time in a world far far away".truncate_words(4)` は `"Once upon a time..."` になります。
区切りは既定で空白ですが、`separator: "<br>"` のように文字列や正規表現も指定できます。

## コード

```ruby:line-numbers=182
  def truncate_words(words_count, options = {})
    sep = options[:separator] || /\s+/
    sep = Regexp.escape(sep.to_s) unless Regexp === sep
    if self =~ /\A((?>.+?#{sep}){#{words_count - 1}}.+?)#{sep}.*/m
      $1 + (options[:omission] || "...")
    else
      dup
    end
  end
```

## 前提知識

- **`Regexp === sep`**: `===` はクラスに対して使うと「そのクラスのオブジェクトか」を調べます。ここでは「`sep` が正規表現か」です。
- **`Regexp.escape`**: `.` や `*` など正規表現で特別な意味を持つ文字の前に `\` を付け、文字そのものとして扱えるようにします。
- **`=~` と `$1`**: `文字列 =~ 正規表現` でマッチを試し、成功すると `$1` に 1 番目の `( )` にマッチした部分が入ります。
- **正規表現の中の `#{...}`**: Ruby の正規表現リテラルにも式展開が使えます。実行時に値を埋め込んだ正規表現が作られます。
- **`.+?`**: 1 文字以上の「最短一致」です。できるだけ短くマッチしようとします。
- **`{3}`**: 直前のものをちょうど 3 回繰り返します。
- **`(?>...)`**: アトミックグループです。中身が一度マッチしたら、あとで後戻り（バックトラック）してやり直すことをしません。
- **`\A` と `m` フラグ**: `\A` は文字列の先頭、`m` フラグは `.` が改行にもマッチするようにします。

## 何をしているか

### 1. 区切りを正規表現の部品にする（183〜184 行目）

区切りが指定されなければ `/\s+/`（1 つ以上の空白）を使います。文字列が渡された場合は `Regexp.escape` しておきます。`"."` を区切りにしたいのに「任意の 1 文字」と解釈されては困るからです。

### 2. n 単語分の正規表現を組み立てる（185 行目）

`truncate_words(4)` のとき、正規表現はおおよそ次の形になります。

```
\A((?>.+?\s+){3}.+?)\s+.*
```

- `(?>.+?\s+){3}`: 「単語＋区切り」を 3 回
- `.+?`: 4 つ目の単語
- `\s+.*`: その後に区切りがあり、さらに何か続く

`"Once upon a time in a world"` なら、`$1` は `"Once upon a time"` になります。

### 3. 結果を返す（186〜188 行目）

マッチすれば `$1` に省略記号を付けて返します。単語が n 個以下だとマッチしない（4 つ目の後に区切りが続かない）ので、コピーをそのまま返します。

## ここがすごい

### ループを書かずに正規表現エンジンに数えさせる

素直に書くなら `split` で単語に分け、`first(n)` を取り、`join` でつなぎ直すことになります。しかしそれでは、元の区切り（空白 2 つ、改行など）が失われ、すべて 1 つの空白になってしまいます。
この実装は **元の文字列から必要な部分をそのまま切り出す** ので、区切りの形が保たれます。また、長い文章でも全体を分割せず、先頭から n 単語ぶんだけを見れば済みます。

### アトミックグループで後戻りを抑える

`.+?` のような柔軟なパターンを繰り返すと、マッチに失敗したときに正規表現エンジンが「区切り方を変えてもう一度」と大量にやり直すことがあり、とても遅くなることがあります。
`(?>...)` で「1 単語＋区切り」のかたまりを確定させることで、無駄なやり直しを減らしています。

### 実行時に正規表現を作る

単語数 `n` は呼び出すたびに違うので、`#{words_count - 1}` で繰り返し回数を埋め込んだ正規表現をその場で作っています。正規表現もデータのように組み立てられるのは Ruby の強みです。

## まとめ

- 「最初の n 個」を正規表現で切り出すと、元の区切りの形を保ったまま取り出せます。
- 正規表現に式展開で値を埋め込むときは、文字列を `Regexp.escape` しておくと安全です。
- アトミックグループ `(?>...)` は、無駄なバックトラックを防ぐのに使えます。
- `$1` などのマッチ結果の変数で、`( )` で囲んだ部分を取り出せます。
