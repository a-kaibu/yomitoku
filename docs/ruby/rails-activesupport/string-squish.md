## ひとことで

`squish` は、文字列の **前後の空白を取り除き、途中の連続した空白をスペース 1 つにまとめる** メソッドです。
`" foo   bar    \n   \t   boo".squish` は `"foo bar boo"` になります。
フォームに入力された名前や、HTML から取り出したテキストを整えるときに便利です。

## コード

```ruby:line-numbers=17
  def squish
    dup.squish!
  end

  # Performs a destructive squish. See String#squish.
  #
  # ```
  # str = " foo   bar    \n   \t   boo"
  # str.squish!                         # => "foo bar boo"
  # str                                 # => "foo bar boo"
  # ```
  #: () -> self
  def squish!
    # Search for two or more `[[:space:]]` OR a single
    # [[:space:]] that isn't `" "`.
    gsub!(/([[:space:]]{2,}|[[[:space:]]&&[^ ]])/, " ")
    strip!
    self
  end
```

## 前提知識

- **`!` 付きと `!` なしのメソッド**: Ruby では、自分自身を書き換える版に `!` を付け（`squish!`）、新しいオブジェクトを返す版には付けない（`squish`）のが習慣です。
- **`dup`**: 文字列のコピーを作ります。
- **`gsub!(正規表現, 置換文字列)`**: マッチした部分をすべて置き換えます（自分自身を書き換えます）。
- **`strip!`**: 前後の空白を取り除きます。
- **`[[:space:]]`**: 正規表現の「空白文字」のクラスです。半角スペースだけでなく、タブ、改行、全角スペースなど Unicode の空白も含みます。
- **`{2,}`**: 直前のものが 2 回以上続く、という意味です。
- **`[A&&[^B]]`**: 文字クラスの **積集合** です。「A に含まれ、かつ B に含まれない文字」を表します。`[[[:space:]]&&[^ ]]` は「半角スペース以外の空白文字」です。
- **`|`**: 正規表現の「または」です。

## 何をしているか

### 1. squish はコピーしてから squish!（17〜19 行目）

`dup.squish!` で、元の文字列を変えずに結果だけを返します。処理の本体は `squish!` にまとめ、2 つの版で同じコードを書かないようにしています。

### 2. 置き換えが必要な空白だけを探す（32 行目）

正規表現は 2 つのパターンの「または」です。

- `[[:space:]]{2,}`: 空白文字が 2 つ以上続く部分
- `[[[:space:]]&&[^ ]]`: 1 文字だけの、半角スペース以外の空白（タブや改行など）

これらを半角スペース 1 つに置き換えます。`"a  \t b\nc"` なら、`"  \t "`（4 文字の連続）と `"\n"`（1 文字）がマッチし、`"a b c"` になります。

### 3. 前後を削って自分を返す（33〜34 行目）

`strip!` で前後の空白を削り、最後に `self` を返します。`gsub!` や `strip!` は「変更がなかったとき `nil` を返す」ので、そのまま返すと困ります。明示的に `self` を返すのはそのためです。

## ここがすごい

### 「すでに正しい空白」には触らない

`/[[:space:]]+/` を `" "` に置き換えるだけでも結果は同じになります。しかしそれだと、`"foo bar"` のような **ふつうの 1 文字の半角スペースまで、全部置き換え対象** になってしまいます。
この正規表現は、30〜31 行目のコメントのとおり「2 文字以上の空白」か「半角スペース以外の 1 文字の空白」だけを狙います。すでに正しい形の部分はマッチしないので、置き換えの回数が減ります。

### 文字クラスの積集合

「空白だけど半角スペースではない」を表すのに、`[\t\n\r\f\v]` のように列挙せず、`&&` による積集合を使っています。列挙だと全角スペースなどの Unicode の空白を書き忘れがちですが、この書き方なら `[[:space:]]` の定義に従うので漏れがありません。

### `!` 版に本体を置き、戻り値は self

本体を破壊的な版に置き、非破壊版はコピーして呼ぶだけ、という分け方は Rails や Ruby でよく見るパターンです。また、組み込みの `!` メソッドが `nil` を返すことがある落とし穴を、`self` を返すことで避けています。

## まとめ

- 置き換えの正規表現は「直す必要がある部分だけ」にマッチさせると無駄が減ります。
- 正規表現の `[A&&[^B]]` で「A だけど B ではない」文字を表せます。
- 破壊的な版に処理をまとめ、非破壊版は `dup` して呼ぶと重複がなくなります。
- Ruby の `gsub!` や `strip!` は変更がないと `nil` を返すので、戻り値の扱いに注意します。
