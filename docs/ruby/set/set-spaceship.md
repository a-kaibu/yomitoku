## ひとことで

`Set#<=>` は、2 つの集合の「大小」を比べるメソッドです。
数の大小と同じように `-1`、`0`、`+1` で結果を返しますが、基準は **含まれている要素の関係** です。
片方がもう片方にすべて含まれていれば大小が決まり、どちらにも含まれない要素があれば `nil`（比べられない）を返します。

## コード

```ruby:line-numbers=459
  def <=>(set)
    return unless set.is_a?(Set)

    case size <=> set.size
    when -1 then -1 if proper_subset?(set)
    when +1 then +1 if proper_superset?(set)
    else 0 if self.==(set)
    end
  end
```

## 前提知識

- **部分集合（サブセット）**: ある集合の要素が、すべて別の集合にも含まれている関係です。`{1, 2}` は `{1, 2, 3}` の部分集合です。
- **`<=>`（宇宙船演算子）**: 左右を比べて、小さければ `-1`、同じなら `0`、大きければ `+1` を返す演算子です。並べ替えの基準にもよく使われます。
- **`return unless 条件`**: 条件が偽のとき、そこで戻ります。ここでは、比べる相手が集合でなければ `nil` を返します。
- **`case ... when ... then`**: 値ごとに 1 行で結果を決める書き方です。`when -1 then -1 if ...` は「値が -1 のときで、かつ条件が真なら -1」です。
- **`else 0 if ...`**: 要素数が同じときだけ、中身が完全に同じかを `==` で確かめます。

## 何をしているか

### 1. 集合以外との比較は `nil`

```ruby:line-numbers=460
    return unless set.is_a?(Set)
```

集合と集合でないものは、包含関係を考えられません。その場合は `nil` を返して「比べられない」と伝えます。

### 2. 要素数の差で、まず大まかに分ける

```ruby:line-numbers=462
    case size <=> set.size
    when -1 then -1 if proper_subset?(set)
    when +1 then +1 if proper_superset?(set)
    else 0 if self.==(set)
    end
```

`size <=> set.size` は、要素数だけを比べる数の比較です。

- 要素数が少ないなら、`proper_subset?` で「完全に含まれているか」を調べます。含まれていれば `-1`（小さい方）です。
- 要素数が多いなら、`proper_superset?` で「完全に含んでいるか」を調べます。含んでいれば `+1`（大きい方）です。
- 要素数が同じで、`==` で等しければ `0` です。

例えば `Set[1, 2]` と `Set[1, 2, 3]` なら、要素数は 2 と 3 で、前者は後者に完全に含まれるので `-1` です。
`Set[1, 2]` と `Set[2, 3]` は要素数が同じで等しくないので、`nil` になります。

## ここがすごい

### 要素数で先に絞る

包含関係をいちばん重い処理で調べる前に、要素数の比較で候補を減らしています。
要素数が少ない集合が多い方の部分集合になることはありえないため、その時点で結果を決められる場合があります。

### `nil` で「比べられない」を表す

数の大小は必ず決まりますが、集合の包含関係は決まらないことがあります。
`0` や `-1` にごまかさず、`nil` を返すことで、「大小はない」という状態を正直に表しています。

### `case` と `then` で 1 行に収める

条件ごとの結果を、1 行の `when` で並べています。どの条件でどの値になるかが一目で読めます。

## まとめ

- 集合の大小は、要素数と包含関係の組み合わせで決まります。
- 比較の結果が決まらないことを `nil` で表すと、呼び出し側が「比べられない」場合を扱えます。
- 軽い比較（要素数）から先に行うと、重い比較を減らせます。
