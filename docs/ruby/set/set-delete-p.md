## ひとことで

`Set#delete?` は、要素を集合から削除します。
要素がもともと含まれていて、消せたときは集合自身を返します。含まれていなかったときは `nil` を返します。
「本当に消えたのか」を、戻り値で判断できる点が特徴です。

## コード

```ruby:line-numbers=542
  def delete?(o)
    delete(o) if include?(o)
  end
```

## 前提知識

- **`delete`**: 集合から要素を消すメソッドです。含まれていなくてもエラーにはならず、そのまま `self` を返します。
- **`include?`**: 集合に要素が含まれるかを調べるメソッドです。
- **`if` の修飾子**: 文の後ろに `if 条件` を書いて、条件が真のときだけ実行する書き方です。条件が偽なら、`nil` が結果になります。
- **`nil`**: 「値が無い」ことを表す Ruby の値です。ここでは「何も消さなかった」という合図として使われています。
- **`?` で終わるメソッド**: 結果が「成功したか」を表すことが多い、Ruby の慣習です。`add?` と同じ名前の付け方です。

## 何をしているか

### 1. 含まれているかを、先に確かめる

```ruby:line-numbers=543
    delete(o) if include?(o)
```

`include?(o)` が真なら、`delete(o)` が実行されます。偽なら、この行の結果は `nil` になります。
ここで、消す前の確認を 1 行で行っています。

### 2. 消せたら、集合自身を返す

`delete(o)` は、削除のあとに集合自身を返します。そのため、消せたときの戻り値は、集合（`self`）になります。
呼び出し側は、結果が `nil` でなければ、消えたと判断できます。

### 3. 消せなかったら、nil を返す

要素が含まれていなければ、`if` の条件が偽になり、`nil` が返されます。
この `nil` は、「何もしなかった」を表します。

## ここがすごい

### 「消したか」を、戻り値で返す

`delete` は、要素が無くても、そのまま `self` を返します。消したかどうかは、呼び出し側からは分かりません。
`delete?` は、戻り値の `nil` で「消せなかった」を伝えます。判定と削除を、1 つの式で書けるようになります。

### 2 回の検索を、1 行で表す

`include?` で探してから `delete` で消すので、内部では 2 回の検索が行われます。
それでも、読み手にとっては「あれば消す」という 1 つの意図として読めます。

### `add?` と対になっている

`Set#add?` は、要素が無いときだけ追加し、追加できたかを戻り値で伝えます。
`delete?` は、その逆に、要素があるときだけ削除し、消せたかを伝えます。2 つを並べて覚えると、集合の操作が分かりやすくなります。

## まとめ

- `delete?` は、要素が含まれていれば削除し、集合自身を返します。
- 含まれていなければ、何もせず `nil` を返します。
- 戻り値で、消えたかどうかを判断できます。
- `add?` と対になる API として、同じ考え方で作られています。
