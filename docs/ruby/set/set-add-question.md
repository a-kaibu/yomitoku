## ひとことで

`Set#add?` は、要素を集合に **まだ無いときだけ追加** するメソッドです。
追加できたときは、集合自身（`self`）を返し、すでに含まれていたときは `nil` を返します。
`add` と違い、追加したかどうかを、戻り値で判断できます。

## コード

```ruby:line-numbers=529
  def add?(o)
    add(o) unless include?(o)
  end
```

## 前提知識

- **`add`**: 要素を集合に追加します。すでに含まれていても、特に問題は起きません。
- **`include?`**: 集合に、その要素が含まれるかを調べます。
- **`unless`**: 条件が偽のときだけ、式を実行する修飾子です。
- **戻り値の `nil`**: 「何もしなかった」ことを表す値として、`unless` の結果に使われています。
- **`?` で終わるメソッド**: Ruby では、真偽を表すメソッドの名前の末尾に `?` を付けることが多いです。ここでは、戻り値が「追加できたか」の情報を含みます。

## 何をしているか

### 1. 含まれていなければ、追加する

```ruby:line-numbers=530
    add(o) unless include?(o)
```

`unless include?(o)` は、含まれていない場合だけ `add(o)` を実行します。`add` は `self` を返すので、追加できたときは集合自身が結果になります。

### 2. 含まれていれば、何もしない

```ruby:line-numbers=530
    add(o) unless include?(o)
```

含まれているときは、`unless` の節が実行されず、結果は `nil` になります。これは「追加しなかった」という合図です。

## ここがすごい

### 戻り値で、変化の有無を伝える

`add` の結果は、いつも集合自身です。そのため、追加されたかどうかは分かりません。
`add?` は、`nil` かどうかで、変化があったかを伝えます。これを使うと、追加した後に別の処理をするかを、簡潔に決められます。

### 「確かめてから追加」を 1 行で書く

含まれているかを確かめてから、追加する、という 2 段の処理を、`unless` で 1 行に書いています。
読み手は、「まだ無ければ追加」という意図を、そのまま読み取れます。

### 同じ要素を 2 回入れても、結果は変わらない

集合は、同じ要素を 1 つだけ持ちます。`add?` は、重複を許さない集合の性質を、戻り値として外に見せています。

## まとめ

- 追加したかどうかを知りたいときは、戻り値が `nil` かどうかで判断できます。
- 「確かめてから追加」は、`unless` で 1 行にまとめられます。
- 集合の重複をなくす性質は、追加の結果を戻り値で伝えると、より役立ちます。
