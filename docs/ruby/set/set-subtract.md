## ひとことで

`Set#subtract` は、集合から、渡された要素をまとめて取り除きます。
集合の「引き算」を、その集合の中身を書き換える形で行います。
戻り値は、変更された集合自身です。

## コード

```ruby:line-numbers=615
  def subtract(enum)
    do_with_enum(enum) { |o| delete(o) }
    self
  end
```

## 前提知識

- **集合の引き算**: 集合 A から、集合 B の要素をすべて除いた残りを求める演算です。数学の「A − B」にあたります。
- **破壊的なメソッド**: 元のオブジェクトの中身を書き換えるメソッドです。Ruby では、名前の末尾に `!` が付くことが多いですが、`subtract` は付いていません。
- **`do_with_enum`**: 渡された値を 1 つずつ取り出して、ブロックを実行する内部メソッドです。列挙できない値なら、ここで例外になります。
- **ブロック `{ |o| ... }`**: 取り出した要素 `o` を使って、処理を書くための書き方です。
- **`self`**: いま処理しているオブジェクト自身です。最後に返すことで、メソッドチェーンができます。

## 何をしているか

### 1. 渡された要素を、1 つずつ取り除く

```ruby:line-numbers=616
    do_with_enum(enum) { |o| delete(o) }
```

`enum` の要素を 1 つずつ `o` に取り出し、それぞれを `delete` で消します。
`delete` は、含まれていない要素を渡しても、エラーにはなりません。そのため、「渡された中に、無いものがあっても構わない」という動きになります。

### 2. 自分自身を返す

```ruby:line-numbers=617
    self
```

集合は、取り除いたあとの自分自身を返します。
新しい集合は作られず、元の集合が書き換わっています。

## ここがすごい

### 引き算を、コピーせずに行う

「A から B を引いた集合」を新しく作るなら、A をコピーしてから、B の要素を消す必要があります。
`subtract` は、コピーを作らず、元の集合を直接書き換えます。大きな集合でも、無駄な複製を避けられます。

### 「含まれていなくてもよい」という寛容さ

引き算の対象の中に、元の集合に無い要素があっても、問題は起きません。
利用者は、対象が完全に含まれているかを事前に確かめる必要がありません。

### 列挙できる値なら、何でも引ける

`do_with_enum` によって、引数は集合でも、配列でも、範囲でも構いません。
同じ `subtract` で、いろいろな種類の列挙を引けるのは、この設計のおかげです。

## まとめ

- `subtract` は、渡された列挙の要素を、集合からまとめて取り除きます。
- 新しい集合を作らず、元の集合を書き換えます。
- 含まれていない要素があっても、エラーにはなりません。
- 戻り値は自分自身なので、そのまま続けて別のメソッドを呼べます。
