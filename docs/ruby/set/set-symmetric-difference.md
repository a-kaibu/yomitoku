## ひとことで

`Set#^` は、2 つの集合の **対称差**（どちらか片方にだけ入っている要素の集まり）を返すメソッドです。
`Set[1, 2] ^ Set[2, 3]` は、両方にある `2` を除いた `{1, 3}` になります。
「`(集合 | 相手) - (集合 & 相手)` と同じ」と、ドキュメントにも書かれています。

## コード

```ruby:line-numbers=667
  def ^(enum)
    n = self.class.new(enum)
    each { |o| n.add(o) unless n.delete?(o) }
    n
  end
```

## 前提知識

- **集合の演算**: `|`（和集合）は両方の要素をすべて集めた集合、`&`（積集合）は両方にある要素だけの集合です。`-`（差集合）は左にだけある要素の集合です。
- **`self.class.new(enum)`**: 今の集合と同じクラスの新しい集合を、`enum`（配列や範囲など）の要素で作ります。
- **`each { |o| ... }`**: 今の集合の要素を 1 つずつ `o` に入れて、ブロックを実行します。
- **`unless`**: 条件が偽のときだけ実行する修飾子です。`x unless 条件` は、条件が真なら何もしません。
- **`delete?`**: 要素があれば削除して `self` を返し、なければ `nil` を返すメソッドです。

## 何をしているか

### 1. 相手の要素で、新しい集合を作る

```ruby:line-numbers=668
    n = self.class.new(enum)
```

まず、引数の `enum` の要素を全部入れた新しい集合 `n` を作ります。ここまでは「相手の集合」そのものです。

### 2. 自分の要素を 1 つずつ、`n` と打ち消し合わせる

```ruby:line-numbers=669
    each { |o| n.add(o) unless n.delete?(o) }
```

自分の要素 `o` を見ながら、次のように処理します。

- `n.delete?(o)` が成功した（`n` にもあった）なら、両方にある要素なので、`n` から削除したまま何もしません。
- 失敗した（`n` になかった）なら、自分だけにある要素なので `n.add(o)` で追加します。

`unless` の条件は「削除できなかったとき」なので、`add` は「相手になかった要素」だけに実行されます。

### 3. 残った `n` を返す

```ruby:line-numbers=670
    n
```

最後に `n` に残っているのは、片方だけにある要素の集合です。

例えば `Set[1, 2] ^ Set[2, 3]` では、`n` は最初 `{2, 3}` です。自分の `1` は `n` になく追加されて `{2, 3, 1}`、自分の `2` は `n` にあるので削除されて `{3, 1}` になります。

## ここがすごい

### 作業用の集合 1 つで済ませる

素直に書くと、`(self | enum) - (self & enum)` のように、中間の集合を 3 つも作ることになります。
このコードは、相手の集合を 1 つ作るだけで、削除と追加を同じ `n` の上で行うので、無駄が少なくなります。

### 「削除できたか」を判定に使う

`delete?` は、要素が存在していたかどうかを戻り値で教えてくれます。
「あったら消す、なければ足す」を、1 つの式（`unless n.delete?(o)`）で書けるのがこの書き方の工夫です。

### 演算子の意味をドキュメントで示す

`^` が何を意味するかは、ドキュメントコメントの中で、他の演算子を組み合わせた式として説明されています。
読み手は、既に知っている演算子の組み合わせで、新しい演算子の意味をすぐにつかめます。

## まとめ

- 対称差は「片方だけにある要素」で、集合の差や和を組み合わせて書けます。
- 作業用の集合を 1 つにまとめると、中間の集合を減らせます。
- `delete?` のように「あったかどうか」を返すメソッドは、条件つきの更新を短く書く助けになります。
