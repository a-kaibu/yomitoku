## ひとことで

`Set#join` は、集合のすべての要素を文字列にし、区切り文字でつないだ文字列を返すメソッドです。
中身は、いったん配列に直してから `Array#join` に任せています。

## コード

```ruby:line-numbers=809
  def join(separator=nil)
    to_a.join(separator)
  end
```

## 前提知識

- **`Array#join`**: 配列の要素を文字列にして、区切り文字でつなぎます。区切り文字を省くと、要素を空文字でつなぎます。
- **`to_a`**: 集合の要素を、順番どおり配列にして返します。
- **既定値（`separator=nil`）**: 引数を省略したとき、その変数に入る値です。ここでは `nil` が入ります。
- **レシーバ**: メソッドを呼ばれたオブジェクト自身です。ここでは `join` を呼ばれた集合を指します。

## 何をしているか

### 1. 集合を配列に直す

```ruby:line-numbers=810
    to_a.join(separator)
```

`to_a` で、集合の要素を配列にします。集合そのものには `join` を書かず、配列の機能を借りる形です。

### 2. 配列の `join` に任せる

```ruby:line-numbers=810
    to_a.join(separator)
```

`to_a.join(separator)` で、配列の `join` を呼びます。区切り文字は、そのまま引数として渡します。
`separator` が `nil` のときは、`Array#join` の既定の動作、つまり区切りなしでつなぐ動作になります。

これで要素が文字列でないものでも、`to_s` によって文字列に変換されます。整数や記号を含む集合も、そのまま文字列にできます。

## ここがすごい

このメソッドは一行しかありませんが、設計として重要なことを示しています。

一つ目は、機能の重複を避けていることです。`Set` が `join` の変換ロジックを一から持つと、`Array` と挙動がずれる危険があります。配列に任せれば、要素の変換や区切りの扱いが常に同じになります。

二つ目は、`Set` のメソッドが `Enumerable` の仕組みを活かしていることです。集合は `to_a` を持つので、それを経由すれば、配列用に作られた多くの機能が使えます。

ただし、`to_a` は毎回新しい配列を作ります。要素が多い集合で何度も `join` を呼ぶ場合は、その分のメモリと時間がかかります。そうした場面では、一度だけ `to_a` して配列を使い回すほうが効率的です。

`Set#join` は、集合を人に見せる文字列にしたいときや、ログやファイルに書き出すときに役立ちます。

## まとめ

`Set#join` は、集合を配列に直して `Array#join` に任せるだけの薄いメソッドです。挙動を配列と揃えられ、変換のロジックを二重に持たずに済む、という利点があります。
