## ひとことで

`comma_breakable` は、カンマを出力し、その直後に「改行してもよい場所」を置く部品です。
行が画面に収まるときは、カンマのあとに空白が入ります。
行が長すぎるときだけ、その場所で改行されます。

## コード

```ruby:line-numbers=238
    def comma_breakable
      text ','
      breakable
    end
```

## 前提知識

- **`PrettyPrint`**: 長いデータを、決まった幅に収まるように改行しながら出力する、Ruby の標準ライブラリです。`pp` の土台になっています。
- **`text`**: 改行できない、そのままの文字列を出力する命令です。
- **`breakable`**: 改行してもよい場所を表す命令です。行に収まれば空白になり、収まらなければ改行になります。
- **グループ**: 複数の `text` や `breakable` を、まとめて扱う単位です。グループごとに、改行するかどうかが決まります。
- **`pp` の出力**: 短い配列は 1 行に、長い配列は 1 要素ずつ改行されて表示されます。その改行の場所を決めているのが、この `breakable` です。

## 何をしているか

### 1. カンマを、まず確定の文字として出す

```ruby:line-numbers=239
      text ','
```

カンマは、改行の位置にかかわらず、必ずその位置に出力されます。
そのため、`text` を使います。改行されても、カンマの文字が消えることはありません。

### 2. カンマの直後に、改行できる場所を置く

```ruby:line-numbers=240
      breakable
```

`breakable` は、その時点で行が収まるかを見ます。収まるなら空白を、収まらないなら改行を出します。
つまり、カンマと区切りの場所を、2 つに分けて書くことで、「改行は、区切りの位置でだけ起きる」ことが保証されます。

## ここがすごい

### 「何を出すか」と「改行するか」を分けている

カンマは固定、改行は画面の幅で決まる、と役割を分けています。
この 2 つを 1 つの文字列に混ぜると、改行の位置をあとから変えられません。
`text` と `breakable` を分けたことで、表示の幅が変わっても、同じコードで整形できます。

### カンマの後に改行する、という表示の約束

`pp` で長い配列を見ると、カンマのあとで改行されています。その見た目は、この `comma_breakable` の繰り返しで作られています。
要素を並べるたびに、ここを使うので、どの場所の区切りも同じ書き方で統一されています。

### 単純な 2 行で、整形の規則を表す

`text` と `breakable` だけで、区切りの振る舞いが書けます。複雑な判定は、`PrettyPrint` の側がまとめて担当します。
この部品を読めば、`pp` の見た目の規則が分かります。

## まとめ

- `comma_breakable` は、カンマと改行できる場所を、順に出力します。
- カンマは `text` で固定し、改行は `breakable` に任せています。
- 行が長いときだけ改行になり、短いときは空白になります。
- 区切りの見た目を、1 つの部品にまとめているので、`pp` 全体で統一されています。
