## ひとことで

`Time#month_days` は、**年と月を受け取って、その月の日数を返す** 内部メソッドです。
2 月の日数は、うるう年なら 29、そうでなければ 28 になります。
日付の計算で、月末を超えたかどうかを判定するときに使われます。

## コード

```ruby:line-numbers=148
    def month_days(y, m)
      if ((y % 4 == 0) && (y % 100 != 0)) || (y % 400 == 0)
        LeapYearMonthDays[m-1]
      else
        CommonYearMonthDays[m-1]
      end
    end
```

## 前提知識

- **うるう年**: 2 月が 29 日まである年です。西暦では、4 で割り切れる年がうるう年ですが、100 で割り切れる年は除き、ただし 400 で割り切れる年はうるう年になります。
- **剰余（`%`）**: 割ったときの余りです。`2024 % 4` は `0` です。
- **表（配列）**: `LeapYearMonthDays` と `CommonYearMonthDays` は、各月の日数を並べた配列です。月の番号から 1 を引いて、添字にします。
- **`&&`、`||`**: 論理積と論理和です。`||` は、どちらか一方が真なら真です。

## 何をしているか

### 1. うるう年かを判定する

```ruby:line-numbers=149
      if ((y % 4 == 0) && (y % 100 != 0)) || (y % 400 == 0)
```

「4 で割り切れて、100 では割り切れない」か、「400 で割り切れる」なら、うるう年です。

### 2. うるう年なら、うるう年の表から日数を取り出す

```ruby:line-numbers=150
        LeapYearMonthDays[m-1]
```

うるう年の表の `m-1` 番目（月の番号を添字にしたもの）を返します。2 月なら 29 です。

### 3. それ以外は、平年の表から取り出す

```ruby:line-numbers=152
        CommonYearMonthDays[m-1]
```

平年の表から、同じように日数を返します。2 月は 28 です。

## ここがすごい

### 規則を、そのまま条件式にする

うるう年の 3 つの規則を、そのまま `||` と `&&` で書いています。
数学の決まりを読み取るだけで、コードの意味がわかります。

### 日数を表にして、計算を省く

月ごとの日数を、毎回計算せずに、表から取り出しています。
表を使うと、どの月の値も 1 回の添字で得られます。

### 2 つの表で、分岐を簡潔にする

うるう年のときだけ 2 月を変える、という考え方もできます。
この実装は、2 つの表を用意することで、分岐を 1 か所にまとめています。

## まとめ

- うるう年の判定は、4・100・400 の規則を、そのまま条件として書けます。
- 月ごとの値は、表にして添字で引くと、読みやすく速くなります。
- 規則の数が少ない計算は、表と条件の組み合わせで、簡潔に表せます。
