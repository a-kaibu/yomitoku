## ひとことで

`shuffle` は、スライスの要素の並びを **ランダムに並べ替える** 関数です。`futures` の内部で、処理の順番をばらすために使われます。

並べ替えには **Fisher-Yates 法** を使います。末尾から順に 1 つずつ見て、その位置と、先頭からそこまでのどこかの位置を選んで、要素を入れ替えていきます。理論上は、すべての並び方が同じ確率で現れます。

## コード

```rust:line-numbers=13
pub fn shuffle<T>(slice: &mut [T]) {
    for i in (1..slice.len()).rev() {
        slice.swap(i, gen_index(i + 1));
    }
}
```

この関数は、乱数を作るために `gen_index` を呼びます。`gen_index` は、`random` が返す 64 ビットの値を、指定された範囲の添字に変換します。

## 前提知識

- **シャッフル**: 並びの順番を、どの並び方も同じ確率になるように並べ替えることです。偏りがあると、ある順番が出やすくなってしまいます。
- **Fisher-Yates 法**: 末尾から順に、残りの中からランダムに 1 つ選んで入れ替える方法です。公平なシャッフルとして知られています。
- **`swap`**: 2 つの位置の要素を入れ替えます。
- **`rev()`**: 範囲を逆順に並べて読みます。`(1..len).rev()` は、`len - 1` から 1 まで降りていきます。
- **剰余（`%`）**: 割り算の余りです。乱数を、範囲の大きさに収めるのに使います。

## 何をしているか

### 1. 末尾から順に位置を決める

```rust:line-numbers=14
    for i in (1..slice.len()).rev() {
        slice.swap(i, gen_index(i + 1));
    }
```

`i` を末尾から先頭へ向かって動かします。各ステップで、`0` 以上 `i` 以下の位置を 1 つ選びます。`gen_index(i + 1)` は、`0` 以上 `i + 1` 未満の値を返すので、その範囲を指定しています。

### 2. 選んだ位置と入れ替える

```rust:line-numbers=15
        slice.swap(i, gen_index(i + 1));
```

選んだ位置と `i` の要素を入れ替えます。`i` より後ろはすでに確定しているので、残りの範囲の中で入れ替えるだけで、全体が一様なシャッフルになります。

## ここがすごい

- **すべての並び方が同じ確率**: 各ステップで、残りの要素から等しい確率で 1 つを選んでいます。そのため、結果の並び方に偏りは生じません。剰余による小さな偏りは、64 ビットの乱数ではごくわずかです。
- **追加の領域が要らない**: 入れ替えは元のスライスの中で行うので、新しい配列を作りません。メモリの使い方が、要素の数と同じ量で済みます。
- **乱数は軽い方法で**: 乱数は、前の記事で見た `random` から作ります。シャッフルのたびに、重い乱数生成器を持ち込みません。

## まとめ

- 末尾から順に、先頭側のランダムな位置と入れ替えるのが Fisher-Yates 法。
- すべての並び方が同じ確率になり、新しい領域を使わずに済む。
- 乱数は剰余で範囲に収め、軽い乱数の仕組みを使う。
