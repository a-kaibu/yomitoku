## ひとことで

`utf8_is_cont_byte` は、1 バイトの値が **UTF-8 の継続バイト**（多バイト文字の 2 バイト目以降）かどうかを判定する関数です。
継続バイトは必ず 2 進数で `10xxxxxx`、つまり `0x80`〜`0xBF` の範囲にあります。

ふつうなら `byte & 0xC0 == 0x80` や `0x80 <= byte && byte <= 0xBF` と書くところを、この関数は **`(byte as i8) < -64`** という比較 1 回で済ませています。

## コード

::: code-group

```rust:line-numbers=20 [日本語訳]
/// バイトが UTF-8 の継続バイト（先頭が `10` のバイト）かどうかを調べる。
///（先頭 2 ビットが `10` かどうか）
#[inline]
pub(super) const fn utf8_is_cont_byte(byte: u8) -> bool {
```

```rust:line-numbers=20 [原文]
/// Checks whether the byte is a UTF-8 continuation byte (i.e., starts with the
```

## 前提知識

- **`u8` と `i8`**: `u8` は 0〜255 を表す符号なし 8 ビット整数、`i8` は -128〜127 を表す符号付き 8 ビット整数です。
- **`as` による型変換**: `byte as i8` は、**ビットの並びはそのままに** 符号付きとして読み替えます。最上位ビットが 1 のバイトは負の数になります。たとえば `0x80`（`1000 0000`）は `-128`、`0xBF`（`1011 1111`）は `-65`、`0xFF` は `-1` です。これは 2 の補数という負の数の表し方によるものです。
- **`pub(super)`**: 「1 つ上のモジュールからだけ使える」という公開範囲の指定です。
- **`const fn`**: コンパイル時にも実行できる関数です。
- **`->` と最後の式**: `-> bool` は戻り値の型、`(byte as i8) < -64` の式がそのまま戻り値です。

## 何をしているか

### 1. 符号付きとして並べ直す

```rust:line-numbers=23
pub(super) const fn utf8_is_cont_byte(byte: u8) -> bool {
    (byte as i8) < -64
}
```

符号付きとして読み替えたとき、各バイトは次のように並びます。

```
0x00〜0x7F (0xxxxxxx) →    0 〜  127  ASCII
0x80〜0xBF (10xxxxxx) → -128 〜  -65  継続バイト
0xC0〜0xFF (11xxxxxx) →  -64 〜   -1  先頭バイト
```

継続バイトはちょうど **いちばん小さい側にまとまっている** ので、「-64 より小さいか」だけで判定できます。

### 2. 具体的な値で判定する

具体例:

- `0x81`（「あ」の 2 バイト目）→ `-127` → `-127 < -64` なので `true`
- `0xE3`（「あ」の 1 バイト目）→ `-29` → `false`
- `0x61`（`a`）→ `97` → `false`

## ここがすごい

- **範囲チェック 2 回を 1 回に**: `0x80 <= b && b <= 0xBF` は比較が 2 つ必要ですが、符号付きに読み替えると下限の `-128` は型の最小値なので、上限の比較だけで済みます。
- **マスクも不要**: `b & 0xC0 == 0x80` という書き方も 2 演算（AND と比較）ですが、こちらは型の読み替え（実行時のコストはゼロ）と比較 1 回だけです。
- **UTF-8 の設計の美しさを利用**: UTF-8 は、ASCII・継続バイト・先頭バイトが最上位の 2 ビットできれいに分かれるように設計されています。符号付きの数直線上でも 3 つの区間に分かれるので、こうした判定ができます。
- **小さいが頻出**: この関数は文字数のカウント、文字境界の判定、逆向きのデコードなど、文字列処理のあちこちで使われます。こうした基本部品を 1 命令でも短くする価値は大きいのです。

## まとめ

- `as` で符号付きに読み替えると、ビットはそのままで数の大小関係が変わる。
- 範囲の端が型の最小値・最大値に重なるなら、比較を 1 つ省ける。
- UTF-8 の継続バイトは `0x80`〜`0xBF`、符号付きでは `-128`〜`-65`。
