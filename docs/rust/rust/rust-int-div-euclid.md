## ひとことで

`div_euclid` は、符号付き整数どうしの割り算で、**余りが必ず 0 以上になる商** を返す関数です。たとえば `-7` を `4` で割ると、普通の `/` は `-1` ですが、`div_euclid` は `-2` を返します。
余りは `rem_euclid` で求められ、`-7 = 4 × (-2) + 1` のように、余りは 0 以上の 1 になります。

## コード

```rust:line-numbers=3250
        pub const fn div_euclid(self, rhs: Self) -> Self {
            let q = self / rhs;
            if self % rhs < 0 {
                return if rhs > 0 { q - 1 } else { q + 1 }
            }
            q
        }
```

この関数の下にある `rem_euclid` は、同じ考え方で余りの方を 0 以上にする関数です。この 2 つを組み合わせると、正しい割り算の組になります。

## 前提知識

- **`/` と `%`**: Rust の符号付き整数の割り算は、答えを 0 に向かって切り捨てます。余りは、割られる数と同じ符号になります。
- **切り捨ての向き**: `-7 / 4` は、−1.75 を 0 の方向へ切り捨てるので −1 です。床関数（床は負の無限大の方向へ切る）とは違います。
- **`self % rhs < 0`**: 余りが負かどうかを確かめます。負の余りは、商が切り捨てで 1 ずれていることを意味します。
- **`if` 式**: `return if ... { ... } else { ... }` の形で、値を返せます。
- **`rhs` の符号**: 除数が正か負かで、ずらす向きが変わります。

## 何をしているか

### 1. 普通の割り算で商と余りを求める

```rust:line-numbers=3251
            let q = self / rhs;
```

まず `q = self / rhs` で、0 に向かって切り捨てた商を求めます。`-7 / 4` なら `q = -1` です。

### 2. 余りが負なら、商を 1 ずらす

```rust:line-numbers=3252
            if self % rhs < 0 {
                return if rhs > 0 { q - 1 } else { q + 1 }
            }
```

`self % rhs` が負のとき、切り捨てた分だけ商が大きすぎるので、商を 1 小さくします。除数が正なら `q - 1`、除数が負なら `q + 1` です。`-7` を `4` で割った場合は `-1 - 1 = -2` です。
確かめると、`4 × (-2) + 1 = -7` で、余りは `1` になります。

### 3. 余りが 0 以上のときは、そのまま返す

```rust:line-numbers=3255
            q
```

余りが負でなければ、普通の割り算の商がそのまま正しい答えです。

## ここがすごい

- **普通の `/` と違う性質**: 余りを常に 0 以上にすると、`x = 除数 × 商 + 余り` の式で、いつも `0 ≤ 余り < |除数|` になります。配列の添字を、負の数からでも安全に求められます。
- **分岐は 1 回だけ**: 余りの符号を見て、必要なときだけ商をずらします。割り切れる場合は分岐を通らず、そのまま返します。
- **除数の符号に対応**: 除数が負の場合は `q + 1` になります。この分岐があるので、どちらの符号でも正しい組が得られます。
- **`/` と `%` が同じ割り算**: 商と余りは、2 回の割り算ではなく、コンパイラが同時に求められる形です。
- **周期的な処理に便利**: 時刻や角度など、周期のある値を負の数から扱うときに、余りが常に正になる利点があります。

## まとめ

- 符号付きの割り算は、0 に向かって切り捨てるので、余りが負になることがある。
- 余りが負のときだけ商を 1 ずらすと、余りを 0 以上にできる。
- 除数の符号によって、ずらす向きが変わる。
