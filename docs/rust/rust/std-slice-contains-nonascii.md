## ひとことで

`contains_nonascii` は、`usize` の 1 語（64 ビット環境なら 8 バイト）の中に、**ASCII でない（128 以上の）バイトがあるかどうか** を調べる小さな関数です。`is_ascii` という、バイト列がすべて ASCII かを判定する処理の中で使われます。

1 バイトずつ調べる代わりに、8 バイトを 1 回の演算で確かめます。ポイントは、ASCII のバイトの最上位ビットは必ず 0、そうでないバイトは 1 になる、という性質です。

## コード

```rust:line-numbers=615
            const fn contains_nonascii(v: usize) -> bool {
                const NONASCII_MASK: usize = usize::repeat_u8(0x80);
                (NONASCII_MASK & v) != 0
            }
```

この関数は、`is_ascii` の中に定義された内部の関数です。読み込んだ 1 語を引数に取り、真なら「この語には ASCII でないバイトがある」ことを表します。`is_ascii` は、この判定を語の単位で繰り返します。

## 前提知識

- **ASCII**: 0 から 127 までの文字を表す規格です。1 バイトの最上位ビット（128 の位）は必ず 0 です。
- **`usize`**: 機械語の 1 語の大きさの整数です。64 ビット環境では 8 バイトになります。
- **マスク**: 特定のビットだけを取り出すための数です。ここでは、各バイトの最上位ビットだけを残すために使います。
- **`usize::repeat_u8`**: 1 バイトの値を、語のすべてのバイトに並べた整数を作ります。`0x80` を並べると、すべてのバイトの最上位ビットが 1 になります。
- **論理積（`&`）**: 両方のビットが 1 のときだけ 1 になる演算です。マスクで必要なビットを残すのに使います。

## 何をしているか

### 1. 最上位ビットのマスクを作る

```rust:line-numbers=616
                const NONASCII_MASK: usize = usize::repeat_u8(0x80);
```

`NONASCII_MASK` は、`0x80` を全バイトに並べた定数です。`0x8080_8080_8080_8080` のような値になります。コンパイル時に計算されるので、実行時の費用はありません。

### 2. マスクを当てて、0 でないかを調べる

```rust:line-numbers=617
                (NONASCII_MASK & v) != 0
```

`v` と `NONASCII_MASK` の論理積を取ります。どのバイトでも最上位ビットが 1 なら、その位置のビットは残ります。結果が 0 でなければ、ASCII でないバイトがあります。

## ここがすごい

- **8 バイトを 1 回で判定**: 1 バイトずつ比較する代わりに、語の単位で判定します。長い文字列では、ループの回数が 8 分の 1 になります。
- **分岐がない**: 判定は論理積と比較だけです。CPU が分岐の予測に失敗することがなく、速く動きます。
- **コードは 2 行**: 関数の本体は論理積の一行だけです。性質を正しく理解していれば、読むのも簡単です。

## まとめ

- ASCII の判定は、最上位ビットが立っていないかを見る問題になる。
- 全バイトに `0x80` を並べたマスクで、8 バイトを一度に判定できる。
- 結果が 0 かどうかで、ASCII でないバイトの有無が分かる。
