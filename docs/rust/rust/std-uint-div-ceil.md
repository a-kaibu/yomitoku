## ひとことで

`div_ceil` は、整数どうしの割り算の答えを **切り上げ** して返す関数です。たとえば `7.div_ceil(4)` は、7 ÷ 4 = 1.75 を切り上げて 2 を返します。
普通の `/` は小数点以下を切り捨てるので、「全部を入れるために必要な箱の数」のような場面では、このように切り上げた答えが必要になります。

Rust 1.73 で安定化された機能で、標準ライブラリの整数型すべてに用意されています。

## コード

```rust:line-numbers=3804
        pub const fn div_ceil(self, rhs: Self) -> Self {
            let d = self / rhs;
            let r = self % rhs;
            if r > 0 {
                d + 1
            } else {
                d
            }
        }
```

この関数は符号なしの整数型のメソッドです。`rhs` が 0 のときはパニックします。

## 前提知識

- **切り捨てと切り上げ**: 切り捨ては小数点以下を捨てる操作です。切り上げは、小数点以下に 1 でも残っていれば、1 大きい値にします。
- **`/` と `%`**: `/` は商（切り捨てた割り算の答え）、`%` は余りを返します。`a = b × (a / b) + (a % b)` が成り立ちます。
- **`if` 式**: Rust の `if` は値を返せる式です。`if r > 0 { d + 1 } else { d }` は、条件によって値を選ぶ式になります。
- **`#[track_caller]`**: パニックが起きたとき、表示される場所を呼び出し側の行にする属性です。ここでは 0 で割ったときに、利用者のコードの行が表示されます。
- **`must_use`**: 戻り値を捨てると警告を出す属性です。割り算の結果を使い忘れることを防ぎます。

## 何をしているか

### 1. 商と余りを求める

```rust:line-numbers=3805
            let d = self / rhs;
            let r = self % rhs;
```

`d` は切り捨てた商、`r` は余りです。たとえば `7` と `4` なら、`d = 1`、`r = 3` です。

### 2. 余りがあれば 1 足す

```rust:line-numbers=3807
            if r > 0 {
                d + 1
            } else {
                d
            }
```

余りが 0 より大きいとき、割り切れていないので、商を 1 増やします。余りが 0 のときは割り切れているので、商をそのまま返します。
`7.div_ceil(4)` では `r = 3 > 0` なので、`1 + 1 = 2` になります。`8.div_ceil(4)` では `r = 0` なので、`2` のままです。

## ここがすごい

- **溢れにくい**: 切り上げの素直な書き方は、`(a + b - 1) / b` です。この式は `a + b - 1` の部分が型の最大値を超えて溢れるおそれがあります。`div_ceil` は、割り算と余りだけで判定するので、その心配がありません。
- **割り算は 1 回で済む**: 商と余りは、CPU の割り算命令で同時に得られることが多いです。コンパイラは `/` と `%` を並べて書くと、まとめて 1 回の割り算にできます。
- **意図がそのまま読める**: `(a + b - 1) / b` は「なぜ 1 を引くのか」を考えないと読めません。`div_ceil` と書けば、名前から意味が分かります。
- **0 で割るとパニックする**: 割る数が 0 のときは、`/` と同じくパニックします。呼び出し側でその条件を確かめる必要があります。
- **安定化の経緯**: 切り上げの割り算は、ページ数やブロック数の計算でよく使われます。そのため、長く `(a + b - 1) / b` と書かれてきました。標準ライブラリに入ったことで、この定番の書き方が 1 つのメソッドに置き換えられました。

## まとめ

- 切り上げの割り算は、商と余りを求め、余りがあれば商を 1 増やすことで書ける。
- 素朴な `(a + b - 1) / b` は、溢れる危険があるので、`div_ceil` を使うほうが安全。
- 割り算は `/` と `%` の組み合わせで行い、コンパイラに任せると効率よく動く。
