## ひとことで

`u8_impl` は、1〜255 の整数 `val` について `floor(log10(val))`、つまり「10 進で何桁か − 1」を返します。
`7` なら `0`、`57` なら `1`、`200` なら `2` です。

ふつうは `if val < 10` と `if val < 100` の 2 回の比較で書けますが、この関数は **足し算 2 回と AND 1 回、シフト 1 回** だけで答えを出します。`u8::ilog10()` の中身です。

## コード

::: code-group

```rust:line-numbers=6 [日本語訳]
// 0 < val <= u8::MAX
#[inline]
const fn u8_impl(val: u8) -> u32 {
    let val = val as u32;

    // 速くするため、分岐をやめて答えを下位 8 ビットより上に組み立てる。
    //

    // val に c1 を足すと、val < 10 なら上位は 10、val >= 10 なら 11 になる。
    const C1: u32 = 0b11_00000000 - 10; // 758
    // val に c2 を足すと、val < 100 なら上位は 01、val >= 100 なら 10 になる。
    const C2: u32 = 0b10_00000000 - 100; // 412

    // 上位ビットの値:
    //            +c1  +c2  1&2
    //     0..=9   10   01   00 = 0
    //   10..=99   11   01   01 = 1
    // 100..=255   11   10   10 = 2
    ((val + C1) & (val + C2)) >> 8
}
```

```rust:line-numbers=6 [原文]
// 0 < val <= u8::MAX
#[inline]
const fn u8_impl(val: u8) -> u32 {
    let val = val as u32;

    // For better performance, avoid branches by assembling the solution
    // in the bits above the low 8 bits.

    // Adding c1 to val gives 10 in the top bits for val < 10, 11 for val >= 10
    const C1: u32 = 0b11_00000000 - 10; // 758
    // Adding c2 to val gives 01 in the top bits for val < 100, 10 for val >= 100
    const C2: u32 = 0b10_00000000 - 100; // 412

    // Value of top bits:
    //            +c1  +c2  1&2
    //     0..=9   10   01   00 = 0
    //   10..=99   11   01   01 = 1
    // 100..=255   11   10   10 = 2
    ((val + C1) & (val + C2)) >> 8
}
```

## 前提知識

- **`const fn` と `-> u32`**: `fn` は関数定義、`const` はコンパイル時にも呼べることを表します。`-> u32` は戻り値が 32 ビットの符号なし整数であることを表します。
- **`u8` と `as`**: `u8` は 0〜255 の 1 バイト整数です。`val as u32` で 32 ビット整数に変換しています。足し算で 255 を超えるので、先に大きい型に広げておく必要があります。
- **変数の上書き（シャドーイング）**: `let val = val as u32;` は、同じ名前の新しい変数を作って前の `val` を隠す書き方です。Rust では型を変えるときによく使います。
- **`0b11_00000000`**: 2 進数の書き方で、`_` は区切りです。下位 8 ビットが 0、その上が `11` の数（= 768）です。
- **最後の式が戻り値**: 関数本体の最後の式は末尾に `;` がないので、その値が関数の戻り値になります。

## 何をしているか

### 1. 繰り上がりを作る定数

```rust:line-numbers=15
    const C1: u32 = 0b11_00000000 - 10; // 758
    // Adding c2 to val gives 01 in the top bits for val < 100, 10 for val >= 100
    const C2: u32 = 0b10_00000000 - 100; // 412
```


`C1 = 768 - 10 = 758` です。`val + C1` は、

- `val < 10` なら 768 未満なので、8 ビット目より上は `10`（512〜767）
- `val >= 10` なら 768 以上なので、上は `11`

になります。同じく `C2 = 512 - 100 = 412` で、`val + C2` の上位は `val < 100` なら `01`、`val >= 100` なら `10` です。
`val` は最大 255 なので、どちらも 2 ビットの範囲を超えることはありません。

### 2. AND で答えを組み立てる

```rust:line-numbers=24
    ((val + C1) & (val + C2)) >> 8
```


コメントの表の通り、2 つの上位ビットを AND すると、ちょうど 0・1・2 が得られます。`val = 57` で試します。

```rust:line-numbers=19
    // Value of top bits:
    //            +c1  +c2  1&2
    //     0..=9   10   01   00 = 0
    //   10..=99   11   01   01 = 1
    // 100..=255   11   10   10 = 2
```


```
57 + 758 = 815 = 0b11_00101111  → 上位 11
57 + 412 = 469 = 0b01_11010101  → 上位 01
AND                              → 01 = 1
```

答えは `1`、57 は 2 桁です。`val = 200` なら上位は `11` と `10` で AND は `10`（= 2）、`val = 7` なら `10` と `01` で AND は `00`（= 0）です。
最後に `>> 8` で下位 8 ビット（`val` の残骸）を捨てて完成です。

## ここがすごい

- **比較 2 回を足し算 2 回に変えた**: 比較と分岐の代わりに、「しきい値を足すと繰り上がる」性質を利用しています。足し算は CPU にとってとても安い命令です。
- **上位ビットのパターン設計**: `C1` の結果を `10`/`11`、`C2` の結果を `01`/`10` と、わざと異なるパターンにしているのがポイントです。AND を取ったときに `00`/`01`/`10` の 3 通りがきれいに出るように選ばれています。単に `0b01_00000000 - 10` のような定数にすると、AND で区別できなくなります。
- **コメントの表**: 「値の範囲ごとに上位ビットがどうなるか」が表になっているので、魔法のような定数でも読み手が自分で検算できます。
- **分岐予測に左右されない**: どんな入力でも同じ命令を通るので、ランダムな値を大量に処理しても速度がぶれません。

同じファイルの `less_than_5` は、この考え方を 4 つのしきい値に拡張したものです。

## まとめ

- 比較「`x >= k`」は「`x + (2^n - k)` が `2^n` 以上か」、つまり繰り上がりで表せる。
- 結果ビットのパターンを工夫すれば、複数の比較を AND 1 回でまとめられる。
- 足し算で値が型の範囲を超えるときは、先に大きい型へ変換しておく。
