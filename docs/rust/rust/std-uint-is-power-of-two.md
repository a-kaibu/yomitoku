## ひとことで

`is_power_of_two` は、整数が **2 のべき乗**（1, 2, 4, 8, 16, …）かどうかを返す関数です。たとえば 16 は `true`、10 は `false` です。
この関数は、整数の中で **1 になっているビットの数** を数え、それがちょうど 1 つかどうかを見ています。2 のべき乗は、2 進数で表したときに 1 が 1 つだけ立っている数だからです。

## コード

```rust:line-numbers=3907
        #[inline(always)]
        pub const fn is_power_of_two(self) -> bool {
            self.count_ones() == 1
        }
```

この関数は `#[inline(always)]` という属性を付けていて、コンパイラに関数の本体を呼び出し先へ展開するよう強く指示しています。計算がとても短いので、呼び出しの手間を省いています。

## 前提知識

- **2 進数**: 数を 0 と 1 のビットで表す方法です。たとえば 16 は `10000`、10 は `1010` です。
- **2 のべき乗**: 2 を何回か掛けた数です。2 進数では、最上位の 1 ビットだけが 1 で、ほかはすべて 0 になります。
- **`count_ones`**: 整数の中で 1 になっているビットの数を返すメソッドです。CPU に専用の命令（popcnt）があれば、1 回の命令で求められます。
- **`==`**: 2 つの値が等しいかを比べる演算子です。結果は `bool` になります。
- **`const fn`**: コンパイル時に実行できる関数です。この関数も定数の式で使えます。

## 何をしているか

### 1. 1 のビットの数を数える

```rust:line-numbers=3909
            self.count_ones() == 1
```

`self.count_ones()` は、`self` の中で 1 になっているビットの数を返します。たとえば `16` は `10000` なので 1、`10` は `1010` なので 2 です。

### 2. 数がちょうど 1 かを比べる


結果が 1 のときだけ `true` を返します。`16` は `true`、`10` は `2 == 1` なので `false` です。
`0` は 1 のビットが 0 個なので、`0 == 1` で `false` になります。0 は 2 のべき乗に含めない、という数学の定義と一致しています。

## ここがすごい

- **1 行で済む**: ビットを数えて比べるだけなので、本体は 1 行です。読み手が一目で意味を取れます。
- **CPU の命令と相性が良い**: 1 の数を数える命令は、多くの CPU に専用のものがあります。その場合は、ループを回さずに 1 回の命令で答えが出ます。
- **別の書き方と比べられる**: 古くからよく使われる書き方は、`x != 0 && (x & (x - 1)) == 0` です。最も下の 1 を消して 0 になるかを見る方法で、こちらも速く動きます。`count_ones` 版は、意味が直接読めるので、標準ライブラリでは読みやすさを選んだと考えられます。
- **0 の扱いが正しい**: `0 & (0 - 1)` は、`x - 1` が溢れるため扱いが難しい場合があります。`count_ones` 版は、0 を自然に `false` として扱えます。
- **`#[inline(always)]` の意図**: 関数の呼び出しを省いて、コンパイラが定数の計算まで行いやすくしています。

## まとめ

- 2 のべき乗は、1 のビットがちょうど 1 つだけある数。
- `count_ones() == 1` と書くと、0 を含めて正しく判定できる。
- CPU の命令を使える場合は、ループなしで速く求まる。
