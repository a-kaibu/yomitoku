## ひとことで

`max_pow10_no_more_than` は、与えられた数 `x` を超えない **最大の 10 の冪** を求める関数です。たとえば `x` が 5 なら、10^0 の 1 を返します。`x` が 12345 なら、10^4 の 10000 を返します。

戻り値は、10 の何乗かを表す数と、その値の組です。浮動小数点の数を文字列にする Grisu 法で、桁の位置を決めるために使われます。

## コード

```rust:line-numbers=134
pub fn max_pow10_no_more_than(x: u32) -> (u8, u32) {
    debug_assert!(x > 0);

    const X9: u32 = 10_0000_0000;
    const X8: u32 = 1_0000_0000;
    const X7: u32 = 1000_0000;
    const X6: u32 = 100_0000;
    const X5: u32 = 10_0000;
    const X4: u32 = 1_0000;
    const X3: u32 = 1000;
    const X2: u32 = 100;
    const X1: u32 = 10;

    if x < X4 {
        if x < X2 {
            if x < X1 { (0, 1) } else { (1, X1) }
        } else {
            if x < X3 { (2, X2) } else { (3, X3) }
        }
    } else {
        if x < X6 {
            if x < X5 { (4, X4) } else { (5, X5) }
        } else if x < X8 {
            if x < X7 { (6, X6) } else { (7, X7) }
        } else {
            if x < X9 { (8, X8) } else { (9, X9) }
        }
    }
}
```

すべての比較は、`if` を入れ子にした 2 分木になっています。ループや対数の計算を使わず、決まった数の比較だけで答えが決まります。

## 前提知識

- **10 の冪**: 10、100、1000 のように、10 を何回か掛けた数です。数の桁数を決めるのに使えます。
- **二分探索**: 範囲を半分ずつ絞り込んで、目的の値を探す方法です。比較の回数が、対象の数の対数に比例します。
- **戻り値の組 `(u8, u32)`**: 1 つ目が指数（10 の何乗か）、2 つ目が 10 の冪そのものです。両方を返すことで、呼び出し側は再計算が要りません。
- **`debug_assert!`**: デバッグのときだけ確かめる条件です。`x > 0` が前提で、0 は対象外です。
- **定数の名前**: `X1` は 10、`X2` は 100 と、指数に対応した名前を付けています。

## 何をしているか

### 1. 下位の桁数を判定する

```rust:line-numbers=147
    if x < X4 {
        if x < X2 {
            if x < X1 { (0, 1) } else { (1, X1) }
        } else {
            if x < X3 { (2, X2) } else { (3, X3) }
        }
```

まず `x` が 10000 より小さいかを確かめます。小さいなら、さらに 100 より小さいかで分けます。たとえば 100 未満なら、10 未満か 10 以上 100 未満かで答えが決まります。

### 2. 上位の桁数を判定する

```rust:line-numbers=153
    } else {
        if x < X6 {
            if x < X5 { (4, X4) } else { (5, X5) }
        } else if x < X8 {
            if x < X7 { (6, X6) } else { (7, X7) }
        } else {
            if x < X9 { (8, X8) } else { (9, X9) }
        }
```

`x` が 10000 以上なら、100000 未満か、10^6 から 10^8 の区間かなどで分けていきます。どの枝を通っても、比較は 4 回以内です。

### 3. 答えを返す

各枝の末尾には、`(指数, 10 の冪)` の組があります。たとえば `(4, X4)` は、10^4 を表します。`x` が 10000 以上 100000 未満なら、`(4, 10000)` が返ります。

## ここがすごい

- **比較の回数が一定**: 9 種類の答えを、4 回前後の比較で決めます。ループで順に比べるより、分岐が少なくて速くなります。
- **表を使わない**: 必要な値は定数だけで、配列の表を引く必要がありません。コードが短く、読めば答えが分かります。
- **返す値が揃っている**: 指数と値を一緒に返すので、呼び出し側が 10 の冪を計算し直さずに済みます。

## まとめ

- 数を超えない最大の 10 の冪は、入れ子の比較で決められる。
- 比較は 4 回前後で、ループを使わずに答えが出る。
- 指数と値を組で返すと、呼び出し側の計算が減る。
