## ひとことで

`is_multiple_of` は、`self` が `rhs` の **倍数かどうか** を `bool` で返す関数です。たとえば 12 は 4 の倍数で、10 は 4 の倍数ではありません。
普通に `self % rhs == 0` と書くと、`rhs` が 0 のとき割り算でパニックします。この関数は、**`rhs` が 0 の場合を先に分けて**、パニックを避けています。

## コード

```rust:line-numbers=3887
        #[must_use]
        #[inline]
        pub const fn is_multiple_of(self, rhs: Self) -> bool {
            match rhs {
                0 => self == 0,
                _ => self % rhs == 0,
            }
        }
```

`match rhs` で、除数が 0 かどうかを先に見ています。0 のときは、`self` が 0 かどうかを判定します。

## 前提知識

- **倍数**: ある数の整数倍です。0 は、どんな数の倍数でもあります（0 = 0 × k）。
- **ゼロ除算**: 0 で割る計算です。整数の割り算では、パニックになります。
- **`%` と `==`**: 余りを求めて、0 と比べると、割り切れるかが分かります。
- **`match` の値のパターン**: `0 =>` のように、特定の値の場合を書けます。`_` は、それ以外のすべてを表します。
- **`bool`**: `true` か `false` の値です。

## 何をしているか

### 1. 除数が 0 の場合

```rust:line-numbers=3890
            match rhs {
                0 => self == 0,
```

`rhs` が 0 のときは、割り算ができません。このときは、`self` が 0 かどうかで答えます。0 は 0 の倍数とみなし、それ以外の数は 0 の倍数ではないとします。

### 2. それ以外の場合

```rust:line-numbers=3892
                _ => self % rhs == 0,
```

`rhs` が 0 でなければ、`self % rhs` の余りが 0 かどうかで判定します。余りが 0 なら割り切れて、倍数です。

## ここがすごい

- **パニックを型の外に出さない**: 判定の関数が、呼び出し側に例外を投げないように作られています。0 の場合の答えを、定義どおりに決めています。
- **0 の扱いを数学の定義に合わせる**: 0 は、どんな整数の倍数としても扱えます。この関数の `self == 0` が、その定義を表しています。
- **`%` 1 回で済む**: 判定に必要な割り算は 1 回だけです。結果を `bool` にして、比べる処理も含めて短く書けています。
- **`next_multiple_of` と対になる**: 倍数を求める関数と、倍数かを判定する関数が、同じ「倍数」の考え方で作られています。
- **標準ライブラリで名前が付いた**: 以前は `self % rhs == 0` と書くのが普通でした。この関数が加わったことで、0 の扱いを含めた判定が 1 つの名前で書けます。

## まとめ

- 倍数の判定は、除数が 0 のときを先に分けてから、`%` の結果を 0 と比べる。
- 0 は、どんな数の倍数とも扱う。
- パニックを避けることで、呼び出し側が安全に判定できる。
