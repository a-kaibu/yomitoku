## ひとことで

`mul_shift_64` は、64 ビットの整数 `m` に、128 ビットの定数を掛けて、**その結果を指定した量だけ右にずらした値** を返す関数です。
Rust で 128 ビットの掛け算は直接書けるので、ここでは `u128` を使い、積の上位 64 ビットを取り出して足し、最後に残りのビットを捨てています。

この関数は、浮動小数点数の値を 10 進数の文字列に変えるライブラリ `ryu` の中心にある処理です。掛け算とずらしを 1 回ずつ行うだけで、割り算を使わずに「10 のべき乗で割った値」を近似的に求めます。

## コード

```rust:line-numbers=71
pub fn mul_shift_64(m: u64, mul: &(u64, u64), j: u32) -> u64 {
    let b0 = m as u128 * mul.0 as u128;
    let b2 = m as u128 * mul.1 as u128;
    (((b0 >> 64) + b2) >> (j - 64)) as u64
}
```

`mul` は、128 ビットの定数を 2 つの 64 ビットの値に分けて持つ組です。定数そのものは `ryu` のテーブルに入っていて、この関数はその値を受け取るだけです。

## 前提知識

- **`u128`**: 128 ビットの符号なし整数です。`u64` どうしを掛けると、結果が 128 ビットに収まるので、オーバーフローせずに積を表せます。
- **`as u128`**: 64 ビットの値を 128 ビットに広げる変換です。値は変わらず、上の位が 0 で埋められます。
- **上位と下位**: 128 ビットの値は、上の 64 ビット（上位）と下の 64 ビット（下位）に分けられます。`x >> 64` は上位を取り出し、`x as u64` は下位を取り出します。
- **固定小数点**: 小数点の位置を決めて、整数の中に小数を入れて扱う方法です。ここでは「右に `j` ビットずらす」ことが、2 の `j` 乗で割ることに相当します。
- **`>>` と割り算**: 符号なしの整数を右に `j` ビットずらすと、2 の `j` 乗で割って小数点以下を切り捨てた結果になります。

## 何をしているか

### 1. 定数を 2 つの 64 ビットの部分と掛ける

```rust:line-numbers=72
    let b0 = m as u128 * mul.0 as u128;
    let b2 = m as u128 * mul.1 as u128;
```

`mul` は 128 ビットの定数を、`mul.0`（下の 64 ビット側）と `mul.1`（上の 64 ビット側）に分けたものです。`m` にそれぞれを掛けると、2 つの 128 ビットの積 `b0` と `b2` ができます。
`m` を 128 ビットの定数 `M` と考えると、`m × M` は `b2 × 2^64 + b0` と書けます。

### 2. 下位の積を上位に繰り上げて足す

```rust:line-numbers=74
    (((b0 >> 64) + b2) >> (j - 64)) as u64
```

`b0 >> 64` は、`b0` の上位 64 ビットです。これは `b0` を 2^64 で割ったものの切り捨てなので、`b2 × 2^64 + b0` を 2^64 で割ったときの繰り上がりに相当します。
そのため、`(b0 >> 64) + b2` は、`m × M` を 2^64 で割った値（小数点以下を切り捨てたもの）になります。

### 3. 残りのビットをずらして捨てる

```rust:line-numbers=74
    (((b0 >> 64) + b2) >> (j - 64)) as u64
```

最後に `>> (j - 64)` で、さらに `j - 64` ビット右にずらします。全体として `m × M` を `2^j` で割った値になり、`u64` に変換して返します。
`j` は呼び出し側が決めます。`j` が大きいほど、結果の小数点の位置が下がり、より細かい値を捨てることになります。

## ここがすごい

- **浮動小数点の演算を使わない**: 10 進数への変換で、浮動小数点の割り算や対数を使うと、誤差が入りやすく、遅くもなります。この関数は整数の掛け算とずらしだけで、正確な位置の値を取り出せます。
- **128 ビットを 2 回の掛け算で扱う**: 64 ビットの `m` と 128 ビットの `M` を、そのまま掛ける命令は一般的ではありません。`M` を 2 つに分けて、64 ビットどうしの掛け算 2 回に置き換えています。
- **繰り上がりを 1 回の足し算で扱う**: 下位の積の上位を取り出して上位の積に足すだけで、桁上がりを正しく反映できます。途中の値が 128 ビットに収まるように、項の順序も工夫されています。
- **引数を変えるだけで使い回せる**: `j` を変えれば、いろいろな桁の値を同じ関数で取り出せます。`ryu` では、`mul_shift_all_64` がこの関数を 3 回呼び、下限・中心・上限の 3 つの値を求めています。
- **`no-panic` を意識した書き方**: 関数の上にある `cfg_attr` は、パニックしないことを確かめる機能を有効にしたときに `inline` を付けます。計算だけで答えが出る小さな関数として設計されています。

## まとめ

- 64 ビットの値と 128 ビットの定数の掛け算を、上位と下位に分けて計算すると、割り算なしで小数点の位置をずらせる。
- 繰り上がりは、下位の積の上位 64 ビットを上位の積に足すことで反映する。
- 最後のずらしで、必要な桁の値を取り出す。
