## ひとことで

`decimal_length17` は、与えられた整数 `v` の **10 進数の桁数** を返す関数です。たとえば `12345` は 5、`7` は 1 を返します。
ただし、扱えるのは 17 桁以下の数だけです。浮動小数点数を文字列にするときに、出力の長さを先に知るために使われています。

関数の中では、`if ... else if ...` の列で、大きい桁から順に比べています。どの条件を満たしたかで、桁数が決まります。

## 前提知識

- **桁数**: 10 進数で表したときの桁の数です。`0` は 1 桁、`99` は 2 桁、`100` は 3 桁です。
- **10 のべき乗のしきい値**: `10000000000000000` は 10^16 です。`v` がこの値以上なら、17 桁になります。
- **`debug_assert!`**: デバッグビルドでだけ条件を確かめます。ここでは、`v` が 17 桁未満であることを確かめています。
- **`if ... else if` の連鎖**: 条件を上から順に確かめ、最初に満たしたものの結果を返す書き方です。
- **浮動小数点数の文字列化**: ryu は、浮動小数点数を最短の 10 進表記に直すライブラリです。その途中で、仮数部（整数）の桁数が必要になります。

## 何をしているか

### 1. 17 桁、16 桁、15 桁を先に判定する

```rust:line-numbers=45
    if v >= 10000000000000000 {
        17
    } else if v >= 1000000000000000 {
        16
    } else if v >= 100000000000000 {
        15
```

`v` が 10^16 以上なら 17 桁、そうでなければ 10^15 以上なら 16 桁、という順に比べていきます。前提では 17 桁以下なので、一番上の条件から始めます。

### 2. 中くらいの桁数を判定する

```rust:line-numbers=51
    } else if v >= 10000000000000 {
        14
    } else if v >= 1000000000000 {
        13
    } else if v >= 100000000000 {
        12
    } else if v >= 10000000000 {
        11
    } else if v >= 1000000000 {
        10
    } else if v >= 100000000 {
        9
    } else if v >= 10000000 {
        8
    } else if v >= 1000000 {
        7
```

同じ形で、しきい値を 10 分の 1 ずつ下げていきます。ここでは 14 桁から 7 桁までを、大きい順に判定しています。

### 3. 小さい桁数を判定して、1 桁を返す

```rust:line-numbers=67
    } else if v >= 100000 {
        6
    } else if v >= 10000 {
        5
    } else if v >= 1000 {
        4
    } else if v >= 100 {
        3
    } else if v >= 10 {
        2
    } else {
        1
    }
}
```

6 桁から 1 桁まで、同じ形で判定します。どの条件にも当たらなければ、最後の `else` で 1 を返します。0 も 1 桁として扱われます。

## ここがすごい

- **ループより速い**: コメントにあるように、10 で割りながら桁を数えるループより、比較の列の方が速く動きます。割り算を使わず、比較だけで済みます。
- **よく出る長さを先に比べる**: 平均の出力の長さが 16.38 桁なので、大きい桁から順に調べると、多くの値が早く判定されます。コメントの設計理由が、順番に反映されています。
- **前提を明示している**: 18 桁以上の数は扱わない、と前提がコメントと `debug_assert!` で書かれています。呼び出し側の約束が明確です。
- **分岐の順序が一定**: 値の大きさに応じた分岐なので、同じ処理の中で条件の判定が連続します。CPU の予測がよく当たるように、順番が決まっています。
- **結果が 1 から 17 の範囲に収まる**: 比較の列は、必ず 1 から 17 のどれかを返すので、呼び出し側が範囲を心配しなくて済みます。

## まとめ

- 整数の桁数は、10 のべき乗のしきい値と大きい桁からの比較で求められる。
- 割り算のループをやめて、比較の列にすると速くなる。
- 出力の平均的な長さに合わせて順番を決めると、よく出る値が早く決まる。
