## ひとことで

`fastrand` は、tokio の内部で使われる **32 ビットの乱数を 1 つ返す** 関数です。外部の乱数ライブラリを使わず、2 つの状態 `one` と `two` だけで動きます。タスクを振り分けるなど、暗号のような強さは要らないが、とにかく速さが欲しい場面に向いています。

状態を更新するたびに、古い 2 つの値を入れ替えるように持ち越します。出力は 2 つの状態を足した値です。この形は、**xorshift+** と呼ばれる方式に近いものです。

## コード

```rust:line-numbers=78
    fn fastrand(&mut self) -> u32 {
        let mut s1 = self.one;
        let s0 = self.two;

        s1 ^= s1 << 17;
        s1 = s1 ^ s0 ^ s1 >> 7 ^ s0 >> 16;

        self.one = s0;
        self.two = s1;

        s0.wrapping_add(s1)
    }
```

この関数は、`FastRand` という構造体のメソッドです。`one` と `two` は、初期化のときに 0 以外の値が入るように作られています。0 のままだと、乱数が 0 しか出なくなるからです。

## 前提知識

- **乱数の状態**: 次の乱数を決めるための値です。前の状態から、決まった計算で次の状態が決まります。
- **xorshift**: シフトと排他的論理和で状態を混ぜる乱数の方法です。計算が軽く、質も実用的です。
- **`wrapping_add`**: 2^32 で折り返す足し算です。溢れても止まらないので、乱数の出力に向いています。
- **`s0`・`s1`**: この関数では、古い状態と新しい状態を表す変数名です。`s0` が前の `two`、`s1` が新しい値になります。
- **排他的論理和（`^`）**: 2 つのビットが異なるとき 1 になる演算です。状態を混ぜるのに使われます。

## 何をしているか

### 1. 状態を読み、1 つ目を変える

```rust:line-numbers=79
        let mut s1 = self.one;
        let s0 = self.two;

        s1 ^= s1 << 17;
```

`one` と `two` を読みます。`s1` を左に 17 ビットずらし、自分自身と排他的論理和を取ります。ここで 1 つ目の状態が大きく混ざります。

### 2. 2 つの状態を混ぜて、次の状態にする

```rust:line-numbers=83
        s1 = s1 ^ s0 ^ s1 >> 7 ^ s0 >> 16;
```

`s1` を、`s0` と、さらに右にずらした値と混ぜ合わせます。これで、2 つの状態の両方の情報が次の状態に持ち越されます。

### 3. 状態を入れ替え、足して返す

```rust:line-numbers=85
        self.one = s0;
        self.two = s1;

        s0.wrapping_add(s1)
```

`one` には古い `s0` を、`two` には新しい `s1` を書き込みます。戻り値は `s0 + s1` の折り返し足し算です。この足し算で、出力のビットがさらに混ざります。

## ここがすごい

- **状態が 2 つだけ**: 64 ビットの状態で、乱数の列が長く続きます。スレッドごとや、タスクごとに持っても負担になりません。
- **分岐がない**: シフトと排他的論理和と足し算だけで書かれています。CPU のパイプラインを乱さず、とても速く動きます。
- **足し算で偏りを減らす**: 状態をそのまま返すと、下位のビットに偏りが出やすくなります。2 つの状態を足すと、その偏りが和らぎます。

## まとめ

- 2 つの 32 ビットの状態を、シフトと排他的論理和で混ぜる。
- 出力は 2 つの状態の足し算にして、ビットの偏りを減らす。
- 軽く速いので、暗号ではない用途で大量の乱数を作るのに向いている。
