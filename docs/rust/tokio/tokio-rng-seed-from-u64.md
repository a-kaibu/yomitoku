## ひとことで

`from_u64` は、64 ビットの **乱数の種（seed）** を、32 ビットの 2 つの値に分けて、乱数生成器の初期の状態を作る関数です。その後、`from_pair` が、2 つの値が両方とも 0 になっていないかを確かめます。
乱数生成器の中には、状態がすべて 0 になると、いつまでも 0 しか出さなくなるものがあります。この 2 つの関数は、その事故を初期化の段階で防いでいます。

## コード

```rust:line-numbers=40
    fn from_u64(seed: u64) -> Self {
        let one = (seed >> 32) as u32;
        let two = seed as u32;

        Self::from_pair(one, two)
    }

    fn from_pair(s: u32, r: u32) -> Self {
        if s == 0 && r == 0 {
            Self { s: 0, r: 1 }
        } else {
            Self { s, r }
        }
    }
```

`from_u64` は、種を受け取って `from_pair` に渡すだけです。`from_pair` は、2 つの値を見て、0 の組み合わせを避けます。

## 前提知識

- **種（seed）**: 乱数生成器を初期化する値です。同じ種からは、同じ乱数の列が出ます。
- **xorshift**: 状態を、ビットのずらしと排他的論理和で進める乱数生成器です。状態が 0 になると、ずっと 0 のままになります。
- **ビットのシフト `>>`**: 右にずらして、上の位を下の位へ移します。`seed >> 32` は、上の 32 ビットを取り出します。
- **`as u32`**: 64 ビットの値を 32 ビットに切り詰めます。下の 32 ビットが残ります。
- **タプルのような 2 つの状態**: `FastRand` は 2 つの 32 ビットの状態 `one` と `two` を持ちます。

## 何をしているか

### 1. 種を上下 32 ビットに分ける

```rust:line-numbers=41
        let one = (seed >> 32) as u32;
        let two = seed as u32;
```

`seed >> 32` で上の 32 ビットを、`seed as u32` で下の 32 ビットを取り出します。2 つの値が、そのまま乱数生成器の状態になります。

### 2. 全部 0 のときだけ 1 を入れる

```rust:line-numbers=47
    fn from_pair(s: u32, r: u32) -> Self {
        if s == 0 && r == 0 {
            Self { s: 0, r: 1 }
        } else {
            Self { s, r }
        }
```

`s` と `r` の両方が 0 のときは、`r` だけを 1 にして返します。そうでなければ、受け取った値をそのまま使います。両方が 0 でなければ、状態が 0 にならないので、乱数生成器は止まりません。

## ここがすごい

- **種の 64 ビットを無駄なく使う**: 64 ビットの種を、そのまま 2 つの 32 ビットの状態に分けています。種の情報を捨てずに、乱数生成器の状態を作れます。
- **0 の状態を 1 つだけ避ける**: 0 になってはいけないのは「両方が 0」の組み合わせだけです。その 1 つの場合だけ、1 を入れています。ほかの値は変えずに使えるので、種との対応がほとんど崩れません。
- **初期化の段階で防ぐ**: 乱数の列を作る途中で止まってしまうと、直すのが難しくなります。最初の状態を確かめることで、その事故を防いでいます。
- **同じ種で同じ状態**: 分けて、必要なら 1 を入れるだけなので、同じ種からは常に同じ状態が作られます。テストや再現性に役立ちます。
- **`from_u64` と `from_pair` の役割分担**: 種を分ける処理と、状態を確かめる処理を分けています。`from_pair` は、2 つの 32 ビットの値があれば使えるので、別の入口からも呼べます。

## まとめ

- 64 ビットの種は、上下 32 ビットの 2 つの状態に分ける。
- 両方が 0 のときだけ、`r` を 1 にして、状態が止まらないようにする。
- 初期化で防ぐことで、乱数生成器が全部 0 を出し続ける事故を避ける。
