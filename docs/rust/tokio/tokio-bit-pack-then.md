## ひとことで

`Pack::then` は、1 つの `usize` の中に **値の置き場所（欄）を 1 つ追加する** 関数です。既存の欄より **上の位** に、指定した幅の新しい欄を作ります。
たとえば、下の 3 ビットに状態、その上の 4 ビットに数、という形で 1 つの整数にまとめられます。`then` を続けて呼ぶことで、欄を何個でも並べられます。

tokio では、I/O の準備完了の状態などを、1 つの原子的な整数に詰めて扱う場面（`runtime/io/scheduled_io.rs`）で使われています。整数を 1 つにまとめると、複数の値をまとめて 1 回の操作で更新できます。

## コード

```rust:line-numbers=18
    pub(crate) const fn then(&self, width: u32) -> Pack {
        let shift = usize::BITS - self.mask.leading_zeros();
        let mask = mask_for(width) << shift;

        Pack { mask, shift }
    }
```

`Pack` は、欄の位置を表す `shift`（何ビット左にずらすか）と、欄を切り出すための `mask`（その欄のビットを 1 にした値）の 2 つを持つ構造体です。

## 前提知識

- **ビットフィールド**: 1 つの整数の中に、いくつかの小さな値を並べて入れる方法です。欄ごとに、何ビット目から何ビット幅かが決まっています。
- **マスク（mask）**: 欄の部分だけ 1 になっている整数です。`&` で欄を取り出し、`|` や `!` で欄を書き換えるときに使います。
- **`leading_zeros`**: 最上位の 1 より上の 0 の数を数えます。`usize::BITS - leading_zeros` は、最上位の 1 の位置 + 1、つまり使われているビット数になります。
- **`<<`（左シフト）**: 値を指定したビット数だけ左へ動かします。欄の位置を決めるときに使います。
- **`const fn`**: コンパイル時に計算できる関数です。欄の定義を定数として作れます。

## 何をしているか

### 1. 既存の欄が使っているビット数を求める

```rust:line-numbers=19
        let shift = usize::BITS - self.mask.leading_zeros();
```

`self.mask` の 1 が立っている一番上の位置を求めます。`usize::BITS - self.mask.leading_zeros()` は、その位置に 1 を足した値、つまり既存の欄がすべて収まるビットの数です。この値が、新しい欄の `shift`（左にずらす量）になります。

### 2. 新しい欄のマスクを作り、ずらす

```rust:line-numbers=20
        let mask = mask_for(width) << shift;

        Pack { mask, shift }
```

`mask_for(width)` で、幅 `width` の欄のビットをすべて 1 にしたマスクを作ります。それを `shift` だけ左にずらすと、既存の欄より上の位置に、同じ幅の欄が並びます。
新しい `Pack` は、この `mask` と `shift` を持ちます。

## ここがすごい

- **位置の計算を自動化**: 呼び出し側は、欄の順番と幅だけを書けばよく、何ビット目から始まるかを数えなくて済みます。欄の並びが変わっても、`then` の連鎖で自動的に正しい位置が決まります。
- **既存の欄を壊さない**: 新しい欄は、既存の欄の上の位に置かれるので、お互いのビットが重なりません。マスクの範囲を分けることで、安全に組み合わせられます。
- **すべて定数式で書ける**: `const fn` なので、欄の定義をコンパイル時に決められます。実行時の計算がほとんど要りません。
- **欄の情報を `Pack` に閉じ込める**: 位置とマスクを 1 つの値にまとめるので、使う側は値を詰める・取り出すメソッドだけを覚えればよくなります。
- **ビットの並べ方が読める**: 下の欄から順に `least_significant` と `then` で組み立てる形は、その整数の中身を読み手が追いやすい書き方です。

## まとめ

- `then` は、既存の欄の上に、指定した幅の新しい欄を作る。
- 欄の位置は、使われているビット数から自動で決まる。
- 欄を並べた `Pack` は、マスクとずらし量だけで値を詰めたり取り出したりできる。
