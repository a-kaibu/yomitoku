## ひとことで

`mask_for(n)` は、**一番下（最下位）から n ビットを 1 にした整数** を返す関数です。たとえば `n` が 3 なら `0b111`、つまり 7 を返します。
ビットの欄を切り出すための「マスク」を作るときの、基本になる値です。`tokio` の `Pack` は、このマスクを使って欄の範囲を決めています。

## コード

```rust:line-numbers=56
pub(crate) const fn mask_for(n: u32) -> usize {
    let shift = 1usize.wrapping_shl(n - 1);
    shift | (shift - 1)
}
```

関数の上の説明は、「最下位から `n` 個のビットを 1 にした値を返す」という意味です。この関数自体は、コードの 2 行だけで求めています。

## 前提知識

- **マスク**: 特定のビットだけを残したり、書き換えたりするための整数です。`&` で使うと、マスクが 1 の位置だけが残ります。
- **`1 << k`**: 1 を `k` ビット左にずらすと、2 の `k` 乗になります。この値の 1 のビットは、ちょうど 1 つだけです。
- **`x | (x - 1)`**: 最下位の 1 とその下にあるすべての 0 を 1 に変える計算です。`2^(n−1)` に使うと、下位 n ビットが 1 の `2^n − 1` になります。
- **`wrapping_shl`**: ずらす量が型のビット数以上でも、パニックせずに、ずらす量をビット数で割った余りを使う左シフトです。
- **`u32` の引き算**: `n - 1` は `n` が 0 のとき溢れます。この関数は 1 以上の値で使う前提になっています。

## 何をしているか

### 1. 1 を n−1 ビット左にずらす

```rust:line-numbers=57
    let shift = 1usize.wrapping_shl(n - 1);
```

`1usize.wrapping_shl(n - 1)` は、2^(n−1) を作ります。例えば `n = 3` なら、`1` を 2 ビット左にずらして `0b100`、つまり 4 になります。この値は、ちょうど n 番目のビットだけが 1 の数です。

### 2. その下の 1 をすべて立てる

```rust:line-numbers=58
    shift | (shift - 1)
```

`shift - 1` は、2^(n−1) − 1 で、下位 n−1 ビットがすべて 1 の値です。`shift | (shift - 1)` で、最上位の 1 と下位の 1 を合わせて、下位 n ビットが 1 のマスクになります。`n = 3` なら `0b100 | 0b011 = 0b111` です。

## ここがすごい

- **ループを使わない**: 「1 を n 回左にずらして足す」書き方もできますが、この関数は 1 回のずらしと 1 回の `|` だけです。`const fn` でもそのまま使えます。
- **`wrapping_shl` で型の幅を超えても安全**: 通常の `<<` は、ずらす量がビット数以上だとパニックします。`wrapping_shl` を使うと、ずらす量の扱いが決まった形になります。
- **`n = 64` でも正しく動く**: `usize` が 64 ビットのとき、`n = 64` の場合は 2^63 から 2^64 − 1 のマスクになります。最上位の 1 を含めた、全ビットのマスクです。
- **引き算の 1 つで完結**: `shift - 1` は、2 のべき乗から 1 を引くと下のビットがすべて 1 になる性質を使っています。
- **Pack の土台になる**: `least_significant` や `then` の欄の幅は、すべてこの関数から作られます。小さな関数が、ビットフィールド全体の基礎になっています。

## まとめ

- 下位 n ビットのマスクは、1 を n−1 ビット左にずらして、下位のビットを全部立てると作れる。
- `wrapping_shl` と `|` の組み合わせで、ループなしに求まる。
- この関数は `n` が 1 以上の前提で使う。
