## ひとことで

`wmul` は、2 つの整数を掛けて、その結果を **上位の半分（hi）と下位の半分（lo）の 2 つ** に分けて返すメソッドです。たとえば `u32` どうしを掛けると、結果は 64 ビットになり、その上の 32 ビットと下の 32 ビットが、2 つの値として返ります。
この操作は、乱数を範囲に写す方法（Lemire の方法など）の中心で使われています。rand クレートでは、整数型ごとにこのトレイトを実装しています。

## コード

```rust:line-numbers=27
            #[inline(always)]
            fn wmul(self, x: $ty) -> Self::Output {
                let tmp = (self as $wide) * (x as $wide);
                ((tmp >> $shift) as $ty, tmp as $ty)
            }
```

この実装は、マクロの中で定義されています。`$ty` と `$wide` は、それぞれ元の型と 2 倍の幅の型に置き換わります。

## 前提知識

- **2 倍の幅の型**: `u32` なら `u64`、`u64` なら `u128` です。2 つの値の積を溢れずに表せます。
- **`as`**: 型を別の型に変換します。`self as $wide` は値を広い型に広げ、`tmp as $ty` は上位を捨てて下位だけを取り出します。
- **`>>` と `$shift`**: 右にずらすと、下のビットが捨てられ、上のビットが下に来ます。`$shift` は元の型のビット幅なので、ずらすと上の半分だけが残ります。
- **タプル**: `(a, b)` の形で、2 つの値をまとめて返す型です。ここでは `(hi, lo)` の順で返します。
- **トレイト**: 型に共通の操作を決めておく仕組みです。`WideningMultiply` トレイトは、`wmul` という名前の操作を、整数型ごとに実装しています。

## 何をしているか

### 1. 両方を 2 倍の幅に広げて掛ける

```rust:line-numbers=28
            fn wmul(self, x: $ty) -> Self::Output {
```

（関数の宣言です。`self` と `x` は、同じ元の型です。）
本体の最初の行で、`self` と `x` をそれぞれ `$wide` に広げて掛けます。`tmp` は、2 倍の幅の積です。元の型では溢れてしまう結果も、2 倍の型なら全部残ります。

### 2. 上位と下位を分けて返す

本体の最後の行で、`tmp >> $shift` は積の上の半分を、`tmp as $ty` は積の下の半分を、それぞれ取り出しています。この 2 つをタプルにまとめて返します。
上位の半分は `hi`、下位の半分は `lo` と呼ばれ、`lo` は範囲サンプリングで偏りの判定に使われます。

## ここがすごい

- **溢れを 1 回の掛け算で扱う**: 2 倍の幅の型に広げるので、積を正確に得られます。溢れを避けるために、型を分けたり、余分な計算をしたりする必要がありません。
- **上位と下位を同時に得る**: 乱数の範囲変換では、上位の値と下位の値を両方使います。`wmul` が 2 つを一度に返すので、掛け算は 1 回で済みます。
- **マクロで型の数だけ展開する**: 同じ形の実装を、型ごとに 1 行の指定で作れます。`u8` から `u128` まで、同じ書き方で揃います。
- **ベクトル版の実装がある**: コメントにあるように、SIMD 用のベクトルでも同じ操作ができる実装があります。ベクトルの乱数を一度に変換するときにも使えます。
- **コンパイラの最適化に乗る**: 広い型への変換と右シフトは、CPU の 1 命令（上位ビットを返す掛け算）に対応することが多いです。そのため、素朴に書いても速く動きます。

## まとめ

- 2 倍の幅の型に広げて掛けると、積の上位と下位を溢れずに得られる。
- `wmul` は、上位と下位を `(hi, lo)` のタプルで返す。
- 乱数を範囲に写す方法で、この 2 つの値が使われる。
