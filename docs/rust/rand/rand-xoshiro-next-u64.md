## ひとことで

`try_next_u64` は、乱数生成器 `Xoshiro256PlusPlus` の **次の 64 ビットの乱数** を返し、同時に内部の状態を 1 ステップ進める関数です。
内部の状態は、64 ビットの整数 4 つ（`s[0]` から `s[3]`）です。この 4 つを、足し算、左へのシフト、回転、排他的論理和だけで混ぜ直すことで、乱数の並びを作ります。

rand では `StdRng` とは別に、速さを重視した生成器としても用意されています。

## コード

```rust:line-numbers=76
    #[inline]
    fn try_next_u64(&mut self) -> Result<u64, Infallible> {
        let res = self.s[0]
            .wrapping_add(self.s[3])
            .rotate_left(23)
            .wrapping_add(self.s[0]);

        let t = self.s[1] << 17;

        self.s[2] ^= self.s[0];
        self.s[3] ^= self.s[1];
        self.s[1] ^= self.s[2];
        self.s[0] ^= self.s[3];

        self.s[2] ^= t;

        self.s[3] = self.s[3].rotate_left(45);

        Ok(res)
    }
```

この関数は `TryRng` トレイトの実装の一部です。`try_next_u32` はこの関数の上位 32 ビットを取り出して使います。

## 前提知識

- **状態（state）**: 乱数生成器が次の値を作るために覚えている数です。同じ状態から始めると、同じ乱数の並びが出ます。
- **`wrapping_add`**: 足し算が 64 ビットの範囲を超えても、止まらずに 2^64 で割った余りを返す足し算です。
- **`rotate_left(k)`**: ビットを左に `k` 個回転させる操作です。左端から出たビットが右端に戻ってきます。普通のシフトと違い、ビットが失われません。
- **`<<`（左シフト）**: ビットを左に動かし、右端に 0 を入れます。`s[1] << 17` は、ビットを 17 個分左へ押し出す操作です。
- **排他的論理和（`^`）**: 2 つのビットが違うときに 1 になる演算です。同じ値を 2 回 `^` すると元に戻ります。

## 何をしているか

### 1. 出力する値を作る

```rust:line-numbers=78
        let res = self.s[0]
            .wrapping_add(self.s[3])
            .rotate_left(23)
            .wrapping_add(self.s[0]);
```

`s[0]` と `s[3]` を足し、23 ビット左に回転させ、最後にもう一度 `s[0]` を足します。この値が今回の乱数の結果です。状態はまだ変えていません。

### 2. 状態を混ぜ直す

```rust:line-numbers=83
        let t = self.s[1] << 17;

        self.s[2] ^= self.s[0];
        self.s[3] ^= self.s[1];
        self.s[1] ^= self.s[2];
        self.s[0] ^= self.s[3];
```

`t` に `s[1]` を 17 ビット左にずらした値を保存してから、4 つの状態を排他的論理和で混ぜ直します。`s[2]` と `s[3]` は、残りの状態を使って更新されます。

### 3. 残りの状態を仕上げる

```rust:line-numbers=90
        self.s[2] ^= t;

        self.s[3] = self.s[3].rotate_left(45);
```

`s[2]` に `t` を混ぜ、`s[3]` を 45 ビット回転させます。これで次の呼び出しに使う状態ができます。

### 4. 結果を返す

```rust:line-numbers=94
        Ok(res)
```

作った値を `Ok` に包んで返します。この生成器は失敗しないので、エラーの型は `Infallible`（決して起きないエラー）です。

## ここがすごい

- **状態の更新が一度に済む**: 4 つの値の更新は、同じ位置を何度も読み直さずに 1 回ずつ行われます。命令の数が少なく、速く動きます。
- **状態の 1 つずつが違う役割を持つ**: 出力は `s[0]` と `s[3]` の和の回転で作り、状態の更新は別の組み合わせで行います。出力と状態の関係を分けることで、統計的な偏りを抑えています。
- **32 ビットの乱数は上位を使う**: `try_next_u32` は上位 32 ビットを取り出します。コメントにあるように、下位ビットには線形な依存関係があるため、上位を使うほうが良い乱数になります。
- **回転を使って情報を捨てない**: 通常のシフトでは、端のビットが失われます。回転を使うと、ビットがすべて状態の中に残ります。
- **標準的な小さな生成器**: 外部の大きな仕組みに頼らず、数行の計算だけで次の値を作れます。組み込み用途や大量の乱数が必要なときにも向いています。

## まとめ

- 出力は `s[0] + s[3]` を回転させて `s[0]` を足す。状態は 4 つの値の混ぜ直しで進める。
- 回転と排他的論理和の組み合わせで、ビットを失わずに乱数の並びを作る。
- 上位 32 ビットを使うと、32 ビットの乱数としても質の良い値が得られる。
