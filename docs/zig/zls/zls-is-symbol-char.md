## ひとことで

`isSymbolChar` は、1 バイトの文字が「識別子（変数名や関数名）に使える文字」かを判定する関数です。
Zig の識別子には、英大文字、英小文字、アンダースコア `_`、数字が使えます。この関数は、それらのときだけ `true` を返します。

ZLS では、補完の候補を作る処理（`features/completions.zig`）や、識別子の範囲を決める処理（`offsets.zig`）から、この判定が呼ばれています。

## コード

```zig:line-numbers=384
pub fn isSymbolChar(char: u8) bool {
    return switch (char) {
        'a'...'z', 'A'...'Z', '_', '0'...'9' => true,
        else => false,
    };
}
```
## 前提知識

- **識別子（identifier）**: プログラムの中で、変数や関数に付ける名前です。`my_value` や `Count2` のようなものです。
- **1 バイトの文字（`u8`）**: ASCII の文字を表す値です。`'a'` は 97 です。
- **`switch`**: 値に応じて処理を選ぶ書き方です。`else` は、どの場合にも当てはまらないときの処理です。
- **範囲付きの分岐（`'a'...'z'`）**: `'a'` から `'z'` までの範囲をまとめて書く Zig の書き方です。両端を含みます。
- **`true` と `false`**: 真偽値です。条件が成り立つかどうかを表します。
- **ZLS**: Zig 言語のエディタ支援ツール（言語サーバー）です。補完や定義へのジャンプを提供します。

## 何をしているか

### 1. 英小文字、英大文字、アンダースコア、数字を受け付ける

```zig:line-numbers=386
        'a'...'z', 'A'...'Z', '_', '0'...'9' => true,
```

`'a'...'z'` は英小文字、`'A'...'Z'` は英大文字、`'_'` はアンダースコア、`'0'...'9'` は数字です。どれか 1 つでも当てはまれば、`true` を返します。

範囲をまとめて書くことで、26 個ずつの文字を並べずに済みます。

### 2. それ以外は false

```zig:line-numbers=387
        else => false,
```

空白、記号、かっこ、そして日本語のような多バイトの文字の一部は、ここで `false` になります。`false` が返ると、名前がそこで終わったと判断されます。

### 3. 全体の形

```zig:line-numbers=385
    return switch (char) {
```

`switch` は式なので、判定の結果をそのまま `return` できます。場合分けが 1 つの式にまとまり、読みやすくなっています。

## ここがすごい

- **表を使わずに判定できる**: 文字の表を用意しなくても、範囲の比較だけで判定します。コンパイラが、範囲の比較を効率のよい命令に変えてくれます。
- **名前の定義と一致している**: 判定に使う文字が、Zig の識別子の規則そのものです。読む人は、この 4 つの範囲を見るだけで仕様が分かります。
- **1 バイトの値だけで答えが出る**: 引数が `u8` なので、どんな文字列でも 1 バイトずつ判定できます。余計な変換が要りません。
- **エディタの動きに直結**: 文字を前後へたどって名前の範囲を決めるとき、この判定が使われます。小さな関数ですが、補完の正確さを支えています。

## まとめ

- 識別子に使える文字は、英字、数字、アンダースコアです。
- 範囲付きの `switch` を使うと、1 行で判定の仕様を書けます。
- 1 バイトずつ判定できるので、文字列の走査に組み込みやすい関数です。
- ZLS では、補完や識別子の範囲の判定でこの関数が使われています。
