## ひとことで

`sipRound` は、SipHash という暗号的なハッシュ関数の内部で使われる 1 ラウンドの計算です。4 つの 64 ビットの状態 `v0`、`v1`、`v2`、`v3` を、足し算、回転、XOR だけで混ぜ合わせます。
SipHash は、メッセージを 8 バイトずつ読み込み、この `sipRound` を何回も回して、最後にハッシュ値を作ります。

## コード

```zig:line-numbers=138
        fn sipRound(d: *Self) void {
            d.v0 +%= d.v1;
            d.v1 = math.rotl(u64, d.v1, @as(u64, 13));
            d.v1 ^= d.v0;
            d.v0 = math.rotl(u64, d.v0, @as(u64, 32));
            d.v2 +%= d.v3;
            d.v3 = math.rotl(u64, d.v3, @as(u64, 16));
            d.v3 ^= d.v2;
            d.v0 +%= d.v3;
            d.v3 = math.rotl(u64, d.v3, @as(u64, 21));
            d.v3 ^= d.v0;
            d.v2 +%= d.v1;
            d.v1 = math.rotl(u64, d.v1, @as(u64, 17));
            d.v1 ^= d.v2;
            d.v2 = math.rotl(u64, d.v2, @as(u64, 32));
        }
```
## 前提知識

- **ハッシュ関数**: 任意の長さのデータを、固定長の値にする関数です。SipHash は、鍵（key）を使って、外部から予測しにくい値を作ります。
- **ARX**: 足し算（Add）、回転（Rotate）、XOR の 3 つの組み合わせです。この 3 つは、CPU で速く、ソフトウェアで安全に計算しやすい操作です。
- **`d: *Self`**: 構造体の状態への参照（ポインタ）です。`d.v0` のように、中の値を書き換えられます。
- **`+%=`**: 溢れたら折り返す足し算です。
- **`math.rotl(u64, x, n)`**: `x` を `n` ビット左に回転させます。
- **`fn` が構造体の中にある書き方**: `Self` は、ここで定義している型そのものを指す名前です。

## 何をしているか

### 1. v0 と v1 を混ぜる

```zig:line-numbers=139
            d.v0 +%= d.v1;
            d.v1 = math.rotl(u64, d.v1, @as(u64, 13));
            d.v1 ^= d.v0;
            d.v0 = math.rotl(u64, d.v0, @as(u64, 32));
```

まず、`v0` に `v1` を足します。次に、`v1` を 13 ビット回転させて、新しい `v0` と XOR します。最後に、`v0` を 32 ビット回転させます。

この 4 行で、`v0` と `v1` の値が互いに影響し合います。

### 2. v2 と v3 を混ぜる

```zig:line-numbers=143
            d.v2 +%= d.v3;
            d.v3 = math.rotl(u64, d.v3, @as(u64, 16));
            d.v3 ^= d.v2;
```

同じ考え方で、`v2` と `v3` を混ぜます。`v2` に `v3` を足し、`v3` を 16 ビット回転させて、`v2` と XOR します。

### 3. 2 組の値を交差させる

```zig:line-numbers=146
            d.v0 +%= d.v3;
            d.v3 = math.rotl(u64, d.v3, @as(u64, 21));
            d.v3 ^= d.v0;
            d.v2 +%= d.v1;
            d.v1 = math.rotl(u64, d.v1, @as(u64, 17));
            d.v1 ^= d.v2;
            d.v2 = math.rotl(u64, d.v2, @as(u64, 32));
```

ここで、「`v0` と `v3`」「`v2` と `v1`」の組に分けて混ぜます。前半の 2 組の混ぜ合わせで作られた値が、今度は別の組に入っていきます。

1 ラウンドのあいだに、4 つの値はすべて何度も他の値の影響を受けます。ひとつのビットの変化が、短いあいだに全体へ広がります。

### 4. ハッシュ関数の中での役割

```zig:line-numbers=155
        fn hash(msg: []const u8, key: *const [key_length]u8) T {
            const aligned_len = msg.len - (msg.len % 8);
```

`hash` 関数は、メッセージを 8 の倍数の長さに切り、`update` で `sipRound` を回します。残りのバイトは `final` で処理します。`sipRound` は、このハッシュの最も基本となる部品です。

## ここがすごい

- **ARX だけで強い攪拌**: 掛け算やテーブル参照を使わないので、速さが安定し、キャッシュの影響を受けにくいです。
- **鍵で出力が決まる**: `key` を使うので、攻撃者が入力を選んでも、ハッシュ値を予測しにくくなります。ハッシュテーブルへの攻撃（大量の衝突を狙う攻撃）を防ぐためによく使われます。
- **ラウンド構造が対称**: 同じ形の 3 つの組（足す、回す、XOR）を繰り返すので、読みやすく、検証もしやすいです。
- **小さいコードで済む**: 1 ラウンドは 16 行で、ほぼ同じ形の計算が並んでいます。

## まとめ

- SipHash の 1 ラウンドは、4 つの 64 ビット値を足し算、回転、XOR で混ぜる計算です。
- 2 組の値を交互に混ぜることで、1 ビットの変化を全体に広げます。
- 鍵を使うので、外部から予測されにくいハッシュ値になります。
- ハッシュテーブルを狙った攻撃を防ぐ用途でよく使われます。
