## ひとことで

`rotate` は、配列の要素を左へ `amount` 個分まわす関数です。たとえば `[5, 3, 1, 2, 4]` を `2` だけ回すと、`[1, 2, 4, 5, 3]` になります。先頭の 2 つが末尾に回り込んだ形です。

回転という操作は、一見すると要素を 1 つずつ移す必要がありそうです。しかしこの関数は、**反転（reverse）** を 3 回呼ぶだけで答えを出します。追加の配列を作らないので、メモリの心配もありません。

## コード

```zig:line-numbers=4020
pub fn rotate(comptime T: type, items: []T, amount: usize) void {
    reverse(T, items[0..amount]);
    reverse(T, items[amount..]);
    reverse(T, items);
}
```
## 前提知識

- **配列（スライス）**: `items: []T` は、要素が並んだ範囲です。`items[0..amount]` のように、一部を切り出せます。
- **反転（reverse）**: 範囲の要素の並びを、前後逆にする操作です。`[1, 2, 3]` を反転すると `[3, 2, 1]` になります。
- **`items[amount..]`**: `amount` 番目から最後までの範囲です。
- **`items[0..amount]`**: 先頭から `amount` 個の範囲です（`amount` 番目は含みません）。
- **回転（rotate）**: 先頭の要素が末尾に回り込む操作です。左に 2 回まわすと、先頭の 2 つが末尾へ移ります。

## 何をしているか

### 1. 前半を反転させる

```zig:line-numbers=4021
    reverse(T, items[0..amount]);
```

先頭から `amount` 個の要素を反転させます。`[5, 3, 1, 2, 4]` で `amount = 2` なら、先頭の `5, 3` が `3, 5` になります。配列は `[3, 5, 1, 2, 4]` です。

### 2. 後半を反転させる

```zig:line-numbers=4022
    reverse(T, items[amount..]);
```

残りの部分 `1, 2, 4` を反転させると、`4, 2, 1` になります。配列は `[3, 5, 4, 2, 1]` です。ここまでで、前半と後半が、それぞれ逆順に並んでいます。

### 3. 全体を反転させる

```zig:line-numbers=4023
    reverse(T, items);
```

最後に、配列全体を反転させます。`[3, 5, 4, 2, 1]` を反転すると `[1, 2, 4, 5, 3]` になります。これが、左へ 2 回回した結果です。

### 4. テストで確かめる

```zig:line-numbers=4026
test rotate {
    var arr = [_]i32{ 5, 3, 1, 2, 4 };
    rotate(i32, arr[0..], 2);

    try testing.expect(eql(i32, &arr, &[_]i32{ 1, 2, 4, 5, 3 }));
}
```

テストは、上の 3 ステップで計算した結果と一致するかを確かめています。

## ここがすごい

- **反転を 2 回重ねると、入れ替えになる**: 前半と後半を反転させてから全体を反転させると、「後半が前へ、前半が後ろへ」移ります。この性質を使うと、回転を「入れ替え」として組み立てられます。
- **一時的な配列が要らない**: 要素を一時的に別の場所へ移す方法では、追加のメモリが必要です。反転は、配列の中だけで入れ替えるので、メモリの使用量が変わりません。
- **同じ関数を使い回す**: 回転のために新しく書くコードは 3 行だけです。反転の関数が速ければ、回転も速くなります。実際、`reverse` は SIMD（一度に複数の要素を扱う命令）を使う経路を持っています。
- **計算量が要素数に比例する**: 要素を 3 回たどるだけなので、要素数が多くても時間は線形で増えます。

## まとめ

- 配列の回転は、前半の反転、後半の反転、全体の反転の 3 回で求められます。
- 追加のメモリを使わず、配列の中だけで完結します。
- 「反転」という単純な操作を組み合わせると、難しそうな操作も短く書けます。
- テストの `[5, 3, 1, 2, 4]` を `2` だけ回すと `[1, 2, 4, 5, 3]` になることで、動きを確かめられます。
