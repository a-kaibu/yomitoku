## ひとことで

`eqlIgnoreCase` は、2 つの文字列が大文字と小文字の違いを無視すると同じになるかを調べる関数です。
たとえば `"Hello"` と `"hELLO"` は同じとみなされ、`true` を返します。

ここで対象になるのは ASCII の英字だけです。日本語や絵文字は、大文字と小文字の区別がないので、そのままバイト単位で比べられます。

## コード

```zig:line-numbers=328
pub fn eqlIgnoreCase(a: []const u8, b: []const u8) bool {
    if (a.len != b.len) return false;
    for (a, 0..) |a_c, i| {
        if (toLower(a_c) != toLower(b[i])) return false;
    }
    return true;
}
```
## 前提知識

- **文字列（`[]const u8`）**: バイトの列です。ASCII の英字は 1 バイトで、`'A'` は 65、`'a'` は 97 です。
- **`toLower`**: 1 バイトの ASCII の英字を小文字にする関数です。英字以外は、そのまま返します。
- **`a.len != b.len`**: 長さを比べる式です。長さが違えば、中身を見る前に別の文字列だとわかります。
- **`for (a, 0..) |a_c, i|`**: `a` の要素と、その番号（0 から）を同時に取り出す繰り返しです。
- **`return false`**: 関数の結果を返して、すぐ終わらせる文です。

## 何をしているか

### 1. 長さが違えば、すぐに答えを出す

```zig:line-numbers=329
    if (a.len != b.len) return false;
```

バイト数が違えば、文字列が同じになることはありません。ここで答えを出すので、残りの処理は不要になります。

### 2. 1 バイトずつ、小文字にそろえて比べる

```zig:line-numbers=330
    for (a, 0..) |a_c, i| {
        if (toLower(a_c) != toLower(b[i])) return false;
    }
```

`a` の各バイトと、同じ位置の `b` のバイトを、それぞれ小文字にしてから比べます。違うバイトが 1 つでもあれば、すぐに `false` を返します。

たとえば、`'H'` は `'h'` に、`'E'` は `'e'` になり、同じ文字とみなされます。一方、`'é'` のような UTF-8 の多バイト文字は、`toLower` の対象外なので、そのままのバイトで比べます。

### 3. 最後まで同じなら true

```zig:line-numbers=333
    return true;
```

すべてのバイトが一致したら、同じ文字列とみなします。

テストでは、`"HEl💩Lo!"` と `"hel💩lo!"` が同じとみなされることが確かめられています。絵文字の部分は、大文字と小文字の違いがないので、そのままのバイトで一致します。

## ここがすごい

- **ASCII だけに絞る**: 大文字と小文字の対応は、言語や文字によって複雑です。ASCII だけに限ると、1 バイトの変換で済み、とても単純です。
- **長さの比較を先に行う**: 同じ長さでなければ、中身を見ずに終わります。無駄な比較を省けます。
- **一致しないバイトで止まる**: 違うところが見つかった時点で `false` を返すので、長い文字列でも途中で止まることが多いです。
- **絵文字や日本語もそのまま比べられる**: 変換の対象でないバイトは、そのまま比べるので、文字化けを起こさずに比較できます。ただし、日本語どうしの大文字小文字の区別は、ここでは扱われません。

## まとめ

- 大文字と小文字を無視した比較は、両方を小文字にそろえてから比べると簡単にできます。
- 長さが違えば、中身を比べる前に不一致と分かります。
- この関数は ASCII の英字だけを対象にし、それ以外のバイトはそのまま比べます。
- 違いが見つかった時点で終わるので、無駄な処理を省けます。
