## ひとことで

`mix` は、2 つの 64 ビットの値 `a_` と `b_` から、1 つの 64 ビットの値を作る関数です。Wyhash という高速なハッシュ関数の中心の部品です。
中では `mum` という関数で、2 つの値を 128 ビットの大きさで掛けます。その結果の下位 64 ビットと上位 64 ビットを XOR（違うビットだけ 1 になる演算）で合わせると、答えになります。

## コード

```zig:line-numbers=137
    inline fn mum(a: *u64, b: *u64) void {
        const x = @as(u128, a.*) *% b.*;
        a.* = @as(u64, @truncate(x));
        b.* = @as(u64, @truncate(x >> 64));
    }

    inline fn mix(a_: u64, b_: u64) u64 {
        var a = a_;
        var b = b_;
        mum(&a, &b);
        return a ^ b;
    }
```
## 前提知識

- **128 ビットの整数（`u128`）**: 64 ビットの 2 倍の大きさの整数です。64 ビット同士の掛け算の結果は、最大で 128 ビットになります。
- **掛け算の結果の分け方**: 128 ビットの結果は、下位 64 ビットと上位 64 ビットに分けられます。下位は `@truncate(x)`、上位は `x >> 64` で取り出します。
- **`*%`**: 溢れたら折り返す掛け算です。ここでは `u128` 同士なので、結果は 128 ビットに収まります。
- **`^`（XOR）**: 2 つの値のビットが違うところだけ 1 になる演算です。
- **`inline fn`**: 呼び出し先の中身を、呼び出す場所に展開する指定です。
- **ポインタ `*u64`**: 値を書き換えるための参照です。`mum` は、`a` と `b` の中身を直接書き換えます。

## 何をしているか

### 1. 2 つの値を 128 ビットで掛ける

```zig:line-numbers=138
        const x = @as(u128, a.*) *% b.*;
```

`a` と `b` の値を、`u128` に広げてから掛けます。64 ビット同士の掛け算では溢れてしまう部分も、128 ビットならすべて残ります。

たとえば、`a` と `b` がどちらも `2^63` 付近の大きな値でも、結果の全部のビットが `x` に入ります。

### 2. 下位 64 ビットを a に、上位 64 ビットを b に入れる

```zig:line-numbers=139
        a.* = @as(u64, @truncate(x));
        b.* = @as(u64, @truncate(x >> 64));
```

`@truncate(x)` で、下位の 64 ビットを `a` に入れます。`x >> 64` で上位の 64 ビットを下にずらし、同じく `@truncate` で取り出して `b` に入れます。

ここで、`a` と `b` は、掛け算の結果の 2 つの半分になります。

### 3. 2 つの半分を XOR で合わせる

```zig:line-numbers=144
        var a = a_;
        var b = b_;
        mum(&a, &b);
        return a ^ b;
```

`mix` は、`a_` と `b_` の値を作業用の変数にコピーして、`mum` を呼びます。`mum` のあとの `a` と `b` は、掛け算の下位と上位です。その 2 つを XOR した値を返します。

上位と下位を XOR するので、掛け算の結果のどのビットも、最後の答えに影響します。

## ここがすごい

- **1 回の掛け算で強く混ざる**: 掛け算は、下位のビットの変化を上位へ、上位の変化を下位へ広げます。128 ビットの結果を上下で混ぜるので、入力のわずかな違いが全体に広がります。
- **命令が少ない**: 掛け算 1 回と XOR だけで、良い混ぜ方が得られます。ハッシュの計算は、この部品を何回も使うので、速さに直接効きます。
- **コンパイラの対応**: 128 ビットの掛け算は、多くの CPU で 64 ビットの掛け算命令の組み合わせとして、効率よく作られます。
- **`inline` で呼び出しを消す**: 小さな部品なので、関数呼び出しのコストを残さないように展開されます。

## まとめ

- Wyhash の `mix` は、2 つの 64 ビットの値を 128 ビットで掛けます。
- 掛け算の結果の下位と上位を、XOR で 1 つの 64 ビットにまとめます。
- 1 回の掛け算で、入力のビットが全体に広がります。
- この `mix` を何回も使って、文字列全体のハッシュ値を作ります。
