## ひとことで

`log2_int` は、符号なし整数 `x` の 2 を底とする対数を、小数点以下を切り捨てた整数で返す関数です。
2 進数で言えば、いちばん上の「1」のビットが何番目にあるかを表します。たとえば `log2_int(u32, 8)` は `3` です（8 は `1000` で、1 の位置が 3 番目だから）。

ループを回して 1 ビットずつ数える代わりに、CPU の命令 `@clz`（先頭の 0 の数）を 1 回使って答えを出します。

## コード

```zig:line-numbers=1284
pub fn log2_int(comptime T: type, x: T) Log2Int(T) {
    if (@typeInfo(T) != .int or @typeInfo(T).int.signedness != .unsigned)
        @compileError("log2_int requires an unsigned integer, found " ++ @typeName(T));
    assert(x != 0);
    return @as(Log2Int(T), @intCast(@typeInfo(T).int.bits - 1 - @clz(x)));
}
```
## 前提知識

- **対数（log2）**: 2 を何回掛けるとその数になるかを表します。整数の場合は、切り捨てた値を使います。
- **2 進数の桁**: 各桁は 0 か 1 で、右から 0、1、2 … と番号が付きます。`1000` の 1 は、3 番目（0 から数えて）の桁にあります。
- **`@clz(x)`**: 整数 `x` の一番上（先頭）から連続して並ぶ 0 の数です。`u32` で `x = 8`（`1000`）なら、先頭の 0 は 28 個です。
- **`@typeInfo(T).int.bits`**: 型のビット数です。`u32` なら `32`。
- **`Log2Int(T)`**: 結果を入れるのに十分な大きさの整数型です。
- **`@intCast`**: 値の型を別の整数型に変換します。範囲外だと安全モードでエラーになります。
- **`assert(x != 0)`**: 0 の対数は定義されないので、0 を渡すのを禁止する確認です。

## 何をしているか

### 1. 符号なし整数だけを受け付ける

```zig:line-numbers=1285
    if (@typeInfo(T) != .int or @typeInfo(T).int.signedness != .unsigned)
        @compileError("log2_int requires an unsigned integer, found " ++ @typeName(T));
```

整数型でないものや、符号付きの型を渡すと、コンパイルの段階でエラーになります。符号付きの値は、負の数の対数が定義されないので、この関数の対象外です。

### 2. 0 を禁止する

```zig:line-numbers=1287
    assert(x != 0);
```

`x = 0` の対数は存在しません。ここで確かめて、間違った使い方をすぐ見つけられるようにしています。

### 3. 先頭の 0 の数から桁の位置を出す

```zig:line-numbers=1288
    return @as(Log2Int(T), @intCast(@typeInfo(T).int.bits - 1 - @clz(x)));
```

ビット数から 1 を引いて、そこから先頭の 0 の数を引きます。たとえば `u32`（32 ビット）で `x = 8` なら、`32 - 1 - 28 = 3` です。

計算の意味は、「全体の最上位の位置（31）から、先頭の 0 の数を引いた位置が、いちばん上の 1 の位置である」ということです。`x = 1` なら `clz = 31` なので、`31 - 31 = 0` になります。

### 4. テストで確かめる

```zig:line-numbers=1292
    try testing.expect(log2_int(u32, 1) == 0);
```

テストでは、`1` は `0` になることを確かめています。そのほかにも、`2` と `3` は `1`、`4` から `7` は `2`、`8` から `10` は `3` になることを、同じ書き方で並べて確かめています。2 のべき乗の境目で値が変わるのがポイントです。

## ここがすごい

- **ループが要らない**: 1 ビットずつ右にずらして数える方法は、ビット数に比例する時間がかかります。`@clz` は CPU の命令で一瞬に終わります。
- **型の大きさに合わせて計算**: `bits - 1 - clz` の式は、どの符号なし整数型でも同じ形で書けます。`u8` でも `u128` でも、同じ関数で動きます。
- **`Log2Int` で結果の型を決める**: 戻り値は、ビット数に合わせて小さい整数型になります。`u64` の対数は `u6` で十分な範囲なので、無駄に大きな型を返しません。
- **間違った使い方を型とアサートで防ぐ**: 符号付きの型は `@compileError`、0 は `assert` で弾くので、誤りが実行時の結果に紛れ込みません。

## まとめ

- 整数の log2（切り捨て）は、いちばん上の 1 の桁の位置です。
- `@clz`（先頭の 0 の数）を使うと、ループなしで計算できます。
- `bits - 1 - clz` の式で、型のビット数に合わせた答えが出ます。
- 符号なし整数に限り、0 を禁止することで、対数の定義に合った使い方を強制しています。
