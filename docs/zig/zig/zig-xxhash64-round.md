## ひとことで

`round` は、XXH64 というハッシュで、入力の 8 バイトを 1 つの状態（accumulator）へ取り込む関数です。入力を掛け算と回転で混ぜながら、状態の値を少しずつ変えていきます。

## コード

```zig:line-numbers=211
    fn round(acc: u64, lane: u64) u64 {
        const a = acc +% (lane *% prime_2);
        const b = rotl(u64, a, 31);
        return b *% prime_1;
    }
```

## 前提知識

- **accumulator（アキュムレータ）**: 途中までの計算結果を保つ変数です。この関数は、その値を入力から更新します。
- **lane（レーン）**: 入力の 8 バイトを、64 ビットの整数として読んだ値です。
- **回転（rotate）**: ビットを左にずらし、あふれた上位のビットを下位へ戻す操作です。シフトと違い、ビットは捨てられません。
- **`rotl(u64, a, 31)`**: 64 ビットの値 `a` を、左に 31 ビット回転させる関数です。
- **ラップする足し算と掛け算（`+%`、`*%`）**: 溢れても折り返す演算です。

## 何をしているか

関数は、3 段階の計算をします。掛けて足し、回転して、また掛ける、という形です。

### 1. 入力を掛けて状態へ足す

```zig:line-numbers=212
        const a = acc +% (lane *% prime_2);
```

`lane *% prime_2` で入力に定数を掛け、`acc +% ...` で状態へ足します。

### 2. 31 ビット回転させる

```zig:line-numbers=213
        const b = rotl(u64, a, 31);
```

`rotl(u64, a, 31)` で、結果を 31 ビット回転させます。どのビットも捨てずに位置だけ変わります。

### 3. 掛けて返す

```zig:line-numbers=214
        return b *% prime_1;
```

回転した値に `prime_1` を掛けて返します。前後の掛け算で、値の偏りを減らしています。

## ここがすごい

- **回転で捨てない**: シフトだと上位のビットが失われます。回転なら、すべてのビットが残ったまま、位置だけ変わります。
- **掛け算の順番が意味を持つ**: 最初の掛け算は入力の値を広げ、後の掛け算は回転で散らばった値を整えます。2 回の掛け算で、ビットの偏りを減らしています。
- **状態を並列に持つ**: 実際の XXH64 では、この `round` を 4 つの状態に並べて使い、CPU の並列な計算を生かします。
- **値の変換を 1 行で書く**: 入力の読み込みと、状態の更新を分けて考えられるように、関数を小さくしています。

## まとめ

- `round` は、入力の 8 バイトを、掛け算と回転で状態へ取り込みます。
- 回転を使うことで、ビットが捨てられずに、全体へ混ざります。
- 前後の掛け算で、値の偏りを減らしています。
