## ひとことで

`norm_f` は、標準正規分布（平均 0、標準偏差 1 の正規分布）の確率の密度を、x の位置で返す関数です。値が 0 のときに一番高く、遠くなるほど急に低くなる、ベルの形の曲線です。

## コード

```zig:line-numbers=107
pub fn norm_f(x: f64) f64 {
    return @exp(-x * x / 2.0);
}
```

## 前提知識

- **正規分布**: 平均の周りに値が集まる、ベルの形の分布です。自然界の誤差や測定値によく現れます。
- **密度関数**: 値の位置ごとの、確率の高さを表す関数です。面積が確率になります。
- **`exp(-x²/2)`**: 標準正規分布の密度の形です。`x` が 0 で 1 になり、離れると急に小さくなります。
- **`@exp`**: e の累乗を求める組み込み関数です。
- **ジグラット法での役割**: この曲線の下を、長方形の表で覆うために使われます。

## 何をしているか

### 1. 指数の部分を作る

```zig:line-numbers=108
    return @exp(-x * x / 2.0);
```

`-x * x / 2.0` で、指数の値を作ります。`x` が大きいほど、この値は負に大きくなります。

### 2. e の累乗で高さを返す

```zig:line-numbers=108
    return @exp(-x * x / 2.0);
```

`@exp` で、その指数の e 乗を求めます。結果は 0 から 1 の間の値になり、`x` が 0 のときは 1 です。

## ここがすごい

- **一行の式**: 標準正規分布の密度が、そのまま 1 行で書かれています。数式とコードが一致します。
- **定数を省いている**: 密度の正規化の係数 `1/√(2π)` は含めていません。ジグラット法では、高さの相対的な比だけが必要だからです。
- **逆関数と対**: 同じファイルの `norm_f_inv` は、高さから `x` を求める逆の関数です。対で表を作れます。
- **表の土台**: 曲線の値を並べて長方形を作る、という設計の出発点になっています。

## まとめ

- `norm_f` は、標準正規分布の密度を `exp(-x²/2)` で返します。
- 定数の係数は省いて、比だけを使います。
- 逆関数の `norm_f_inv` と組で、表を作るのに使われます。
