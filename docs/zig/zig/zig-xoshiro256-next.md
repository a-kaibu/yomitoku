## ひとことで

`next` は、Xoshiro256 乱数生成器の 1 回分の出力を作る関数です。4 つの `u64` の状態を、XOR（ビットの違いを取る演算）とシフト、回転だけで入れ替えます。
出力は、状態の一部を足して回転させ、もう一度足したものです。この形は、論文の名前から **xoshiro256++** と呼ばれます。

## コード

```zig:line-numbers=24
pub fn next(self: *Xoshiro256) u64 {
    const r = math.rotl(u64, self.s[0] +% self.s[3], 23) +% self.s[0];

    const t = self.s[1] << 17;

    self.s[2] ^= self.s[0];
    self.s[3] ^= self.s[1];
    self.s[1] ^= self.s[2];
    self.s[0] ^= self.s[3];

    self.s[2] ^= t;

    self.s[3] = math.rotl(u64, self.s[3], 45);

    return r;
}
```
## 前提知識

- **状態（`s`）**: `s[0]` から `s[3]` の 4 つの `u64` です。配列として `self.s[0]` のように書きます。
- **`+%`**: オーバーフローしたら折り返して足す演算です。
- **`<<` と `>>`**: ビットを左または右にずらす演算です。`<< 17` は左に 17 ビットずらします。
- **`^=`**: XOR（違うビットだけ 1 になる演算）を代入する書き方です。同じ値で 2 回 XOR すると元に戻ります。
- **`math.rotl`**: ビットを左に回転させる関数です。
- **`const r`、`const t`**: 更新の前に値を保存する一時的な変数です。

## 何をしているか

### 1. 出力を先に作る

```zig:line-numbers=25
    const r = math.rotl(u64, self.s[0] +% self.s[3], 23) +% self.s[0];
```

`s[0]` と `s[3]` を足して、23 ビット回転させ、さらに `s[0]` を足したものが出力 `r` です。

状態の更新より前に出力を決めることで、出力が「今の状態」だけで決まります。

### 2. 途中の値を保存する

```zig:line-numbers=27
    const t = self.s[1] << 17;
```

`s[1]` を 17 ビット左にずらした値を `t` に保存します。このあと `s[1]` が変わりますが、`t` は古い `s[1]` から作られたままです。

### 3. XOR で 4 つの状態を入れ替える

```zig:line-numbers=29
    self.s[2] ^= self.s[0];
    self.s[3] ^= self.s[1];
    self.s[1] ^= self.s[2];
    self.s[0] ^= self.s[3];
```

4 つの XOR で、状態同士を混ぜ合わせます。順番が大切です。`s[1] ^= s[2]` のとき、`s[2]` は直前の行で変わっています。この順番が論文どおりの構造になっています。

### 4. 残りのシフトと回転を行う

```zig:line-numbers=34
    self.s[2] ^= t;

    self.s[3] = math.rotl(u64, self.s[3], 45);
```

保存しておいた `t` を `s[2]` に XOR し、`s[3]` を 45 ビット回転させます。これで、4 つの状態すべてが少しずつ変わります。最後に出力 `r` を返します。

## ここがすごい

- **XOR と回転だけで攪拌**: 掛け算を使わず、XOR、シフト、回転だけで状態を混ぜます。命令の種類が少なく、CPU 上で速く動きます。
- **状態の大きさで周期が決まる**: 4 つの `u64`、つまり 256 ビットの状態を持つので、同じ値に戻るまでの長さが非常に長くなります。
- **出力の工夫**: 出力を `s[0] + s[3]` から作ることで、状態の一部が直接出てこないようにしています。単純に状態をそのまま出すより、統計検定に通りやすくなります。
- **ジャンプ関数も用意されている**: 同じファイルには `jump` 関数があり、乱数の列を大きく飛ばした位置から並行に使えます。並列処理で同じ列が重ならないようにするための仕組みです。

## まとめ

- Xoshiro256++ は、4 つの 64 ビット状態を XOR、シフト、回転で回す乱数生成器です。
- 出力は、状態の一部を足して回転し、もう一度足したものです。
- 更新の順番を守ることで、論文どおりの性質が保たれます。
- 256 ビットの状態があるので、周期が非常に長く、統計的にも品質が高い乱数になります。
