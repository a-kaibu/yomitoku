## ひとことで

`hashUint64WithSeed` は、64 ビットの整数 `v` を、MurmurHash2（64 ビット版）でハッシュする関数です。
文字列のハッシュは、バイト列を 8 バイトずつ読みますが、整数 1 つのハッシュは、その 1 ブロックだけを処理すれば済みます。ループも、文字列の余りの処理も要りません。

同じ考え方で、整数を素早くハッシュテーブルに入れられます。

## コード

```zig:line-numbers=150
    pub fn hashUint64WithSeed(v: u64, seed: u64) u64 {
        const m: u64 = 0xc6a4a7935bd1e995;
        const len: u64 = 8;
        var h1: u64 = seed ^ (len *% m);
        var k1: u64 = undefined;
        k1 = v *% m;
        k1 ^= k1 >> 47;
        k1 *%= m;
        h1 ^= k1;
        h1 *%= m;
        h1 ^= h1 >> 47;
        h1 *%= m;
        h1 ^= h1 >> 47;
        return h1;
    }
```
## 前提知識

- **MurmurHash2（64 ビット版）**: 文字列のハッシュを、掛け算、シフト、XOR で作る方法です。同じ作者の方式を、前の記事（文字列版）で説明しています。
- **`seed`（種）**: ハッシュの初期値です。同じ値でも、種が違えば別のハッシュ値になります。
- **`m`**: 掛け算に使う定数です。`0xc6a4a7935bd1e995` のような奇数の大きな値です。
- **`len`**: 入力のバイト数です。ここでは `u64` の値なので、8 です。
- **`*%`、`*%=`**: 溢れたら折り返す掛け算です。
- **`undefined`**: 値を後で代入する前提の、未初期化の変数です。読む前に代入されます。

## 何をしているか

### 1. 初期値を、種と長さから作る

```zig:line-numbers=151
        const m: u64 = 0xc6a4a7935bd1e995;
        const len: u64 = 8;
        var h1: u64 = seed ^ (len *% m);
```

定数 `m` と、入力の長さ `len`（8 バイト）を使って、初期値 `h1` を作ります。文字列版と同じく、長さを混ぜておくことで、長さが違う入力の値が区別されます。

### 2. 値を 1 ブロックとして混ぜる

```zig:line-numbers=154
        var k1: u64 = undefined;
        k1 = v *% m;
        k1 ^= k1 >> 47;
        k1 *%= m;
        h1 ^= k1;
        h1 *%= m;
```

`v` に `m` を掛けてから、右シフトと XOR で上位を下位に混ぜ、もう一度 `m` を掛けます。これは、文字列版で 8 バイトのブロックを処理する手順と同じです。そのあと `h1` と混ぜ合わせます。

文字列版では、`v` にあたる部分を、バイト列から読み取っていました。ここでは、整数そのものを使うので、読み取りの処理がありません。

### 3. 仕上げをする

```zig:line-numbers=160
        h1 ^= h1 >> 47;
        h1 *%= m;
        h1 ^= h1 >> 47;
        return h1;
```

最後に、シフト、掛け算、シフトを行い、下位に上位の変化を届けます。この仕上げは、どの長さの入力でも共通の手順です。

## ここがすごい

- **余りの処理がない**: 入力が必ず 8 バイトなので、文字列版にある「余りのバイトを処理する」手順がまるごと消えています。
- **ループがない**: 8 バイトの 1 ブロックだけなので、ループの管理が要りません。関数の中の処理が、そのまま一本道になります。
- **`hashUint32` や `hashUint64` の関係**: 同じファイルには、`u32` 版（長さ 4）もあります。長さの値だけを変えて、同じ形の処理を使い回しています。
- **種を指定できる**: `WithSeed` の関数に種を渡せば、ハッシュ値を変えられます。ハッシュテーブルを狙った攻撃を避けるときに、種を変える使い方が役立ちます。

## まとめ

- 整数 1 つのハッシュは、文字列のハッシュの中で 1 ブロックだけを処理した形と同じです。
- 余りのバイトの処理やループが要らないので、整数の値を素早くハッシュできます。
- 初期値には、種と長さを混ぜます。仕上げのシフトと掛け算で、ビットを十分に混ぜます。
- 種を変えると、ハッシュ値が変わるので、衝突を狙った攻撃の対策にも使えます。
