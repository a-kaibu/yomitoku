## ひとことで

`mulbyi` は、複素数に虚数単位 `i` を掛けた結果を返す関数です。掛け算の一般の式を使わずに、実部と虚部を入れ替えるだけで求められます。複素平面では、原点のまわりに 90 度回転させることに当たります。

## コード

```zig:line-numbers=98
        pub fn mulbyi(self: Self) Self {
            return Self{
                .re = -self.im,
                .im = self.re,
            };
        }
```

## 前提知識

- **虚数単位 `i`**: 2 乗すると -1 になる数です。
- **`(a + bi) × i`**: 分配法則で展開すると、`ai + bi² = -b + ai` になります。
- **90 度の回転**: 複素平面で、`i` を掛けることは、原点のまわりに反時計回りに 90 度回すことです。
- **入れ替え**: 実部と虚部を、互いに移す操作です。
- **`Self`**: 型の中で、自分自身の型を指す名前です。

## 何をしているか

### 1. 新しい実部は元の虚部の符号を反転したもの

```zig:line-numbers=99
            return Self{
                .re = -self.im,
```

`-self.im` が新しい実部です。展開したときの `bi × i = -b` の部分にあたります。

### 2. 新しい虚部は元の実部

```zig:line-numbers=101
                .im = self.re,
            };
```

`self.re` が新しい虚部です。展開したときの `a × i = ai` の部分にあたります。

## ここがすごい

- **掛け算を使わない**: 一般の掛け算の式を書かずに、符号と入れ替えだけで結果が出ます。
- **回転の意味が明確**: 90 度の回転だと知っていれば、この 2 行の意味が一目で分かります。
- **誤差が生まれない**: 掛け算がないので、浮動小数点数の丸めの誤差が入りません。
- **速く計算できる**: 符号の反転と代入だけなので、非常に軽い処理です。

## まとめ

- `mulbyi` は、実部と虚部を入れ替え、新しい実部の符号を反転させます。
- 掛け算を使わず、90 度の回転を表します。
- 誤差がなく、速い操作です。
