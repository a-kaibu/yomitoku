## ひとことで

`next` は、乱数生成器 SplitMix64 の 1 回分の出力を作る関数です。内部の状態 `s` を 1 つ進めて、その値を `u64` の乱数として返します。
状態は単純に一定の値を足していくだけですが、返す前にビットを混ぜるので、出力は一見ばらばらに見えます。

Zig 標準ライブラリでは、ほかの乱数生成器の初期値（種）を作るためにも使われています。

## コード

```zig:line-numbers=14
pub fn next(self: *SplitMix64) u64 {
    self.s +%= 0x9e3779b97f4a7c15;

    var z = self.s;
    z = (z ^ (z >> 30)) *% 0xbf58476d1ce4e5b9;
    z = (z ^ (z >> 27)) *% 0x94d049bb133111eb;
    return z ^ (z >> 31);
}
```
## 前提知識

- **乱数生成器（PRNG）**: 決まった計算を繰り返して、乱数のように見える数列を作る仕組みです。同じ種からは、毎回同じ数列が出ます。
- **`*Self` と `self.s`**: `self` は、この構造体の値への参照（ポインタ）です。`self.s` で中の状態を読んだり書いたりします。
- **`+%=`**: オーバーフローしたら折り返して足す代入です。`u64` の最大値を超えたら 0 に戻ります。
- **`*%`**: 同じく折り返し付きの掛け算です。
- **`^`（XOR）と `>>`**: XOR はビットの違いを取る演算、`>>` はビットを右にずらす演算です。
- **定数 `0x9e3779b97f4a7c15`**: 黄金比に由来する 64 ビットの定数です。状態を進める幅として使われます。

## 何をしているか

### 1. 状態を一定の幅で進める

```zig:line-numbers=15
    self.s +%= 0x9e3779b97f4a7c15;
```

最初に、状態 `s` に大きな定数を足します。この足し算だけなら、数列は単純な「等差数列」です。`u64` の範囲を超えたら折り返すので、ずっと同じ仕組みで回り続けます。

### 2. 値をコピーして、混ぜる準備をする

```zig:line-numbers=17
    var z = self.s;
```

状態そのものは、次の回のために残しておきます。出力用の `z` だけを混ぜていくので、状態の進みと出力の計算が分かれています。

### 3. 掛け算と右シフトを繰り返す

```zig:line-numbers=18
    z = (z ^ (z >> 30)) *% 0xbf58476d1ce4e5b9;
    z = (z ^ (z >> 27)) *% 0x94d049bb133111eb;
    return z ^ (z >> 31);
```

この 3 行が混ぜる部分です。`z ^ (z >> 30)` は、上位のビットを下位に混ぜ込みます。そのあと定数を掛けると、下位の変化が上位へ広がります。これを 2 回繰り返し、最後にもう一度 `z ^ (z >> 31)` で仕上げます。

たとえば、`s` が 1 増えただけでも、掛け算とシフトを通ると、出力の多くのビットが変わります。連続した状態からでも、見た目が規則正しくない値になります。

## ここがすごい

- **状態が単純なので、軽くて速い**: 状態は `u64` が 1 つだけです。メモリも計算もほとんど要りません。
- **出力の混ぜ方が強い**: 足し算だけの数列でも、この混ぜ方を通すと、連続する値の関係が見えにくくなります。
- **ほかの乱数生成器の種作り**: 状態が 1 つの `u64` で済むので、64 ビットの種から、より大きな状態（たとえば `RomuTrio` の 192 ビット）を作るのに向いています。Zig の `RomuTrio.seed` は、この SplitMix64 を 3 回呼んで状態を埋めています。
- **暗号には使わない**: 出力を見れば次の値が予測できる構造です。乱数の種や統計的な用途に向いていますが、パスワードや鍵の生成には使ってはいけません。

## まとめ

- 乱数生成器は、状態を進めて、その状態を混ぜた値を返す仕組みです。
- 状態を一定幅で進め、掛け算と XOR シフトで混ぜるのが SplitMix64 の基本です。
- 状態が 1 つだけで軽いので、ほかの乱数生成器の種を作るのに使われます。
- 予測できる仕組みなので、暗号用途には使えません。
