## ひとことで

`negate` は、値の符号を反転させる関数です。ただし、結果が型の範囲に収まらなければ、エラーとして返します。符号付きの最小値を反転すると、最大値を超えてしまうので、この場合が典型的な溢れです。

## コード

```zig:line-numbers=577
pub fn negate(x: anytype) !@TypeOf(x) {
    return sub(@TypeOf(x), 0, x);
}
```

## 前提知識

- **負の数**: 0 から値を引いた数です。`negate(x)` は、`0 - x` と同じ意味です。
- **符号付きの最小値**: `i8` の -128 は、符号を反転すると 128 になり、`i8` に収まりません。
- **`sub`**: 同じファイルの、溢れを検出する引き算の関数です。
- **`@TypeOf(x)`**: 引数の型を取り出す組み込み関数です。戻り値の型を、引数と同じにするために使います。
- **`!@TypeOf(x)`**: 結果の型か、エラーのどちらかを返す戻り値の型です。

## 何をしているか

### 1. 0 から引く

```zig:line-numbers=578
    return sub(@TypeOf(x), 0, x);
```

`sub(@TypeOf(x), 0, x)` で、型を引数と同じにして、0 から `x` を引きます。溢れがあれば、`sub` がエラーを返します。

## ここがすごい

- **既存の関数の再利用**: 符号の反転を、溢れを検出する `sub` の 1 行で書けます。溢れの判定を重複させません。
- **型が引数と同じ**: 戻り値は引数と同じ型になります。型の変換を気にせずに済みます。
- **符号なしでも正しい**: 符号なしの型では、0 以外の値の反転は溢れになります。`sub` がその判定を行います。
- **典型的な溢れを明示**: 符号付きの最小値の反転が溢れになる、という落とし穴を、この関数が防いでいます。

## まとめ

- `negate` は、0 から値を引いて、符号を反転させます。
- 溢れは `sub` が検出し、エラーとして返します。
- 符号付きの最小値の反転は、溢れになります。
