## ひとことで

`isPowerOfTwo` は、整数が 2 のべき乗（1、2、4、8、16 …）かどうかを判定する関数です。バッファの大きさがきれいな 2 のべきになっているかを確かめるときなどに使われます。

## コード

```zig:line-numbers=1122
pub fn isPowerOfTwo(int: anytype) bool {
    assert(int > 0);
    return (int & (int - 1)) == 0;
}
```

## 前提知識

- **2 のべき乗**: 2 を何回か掛けてできる数です。2 進数で書くと、1 が 1 個だけ立っている形になります（例: 8 は `1000`）。
- **ビットの AND（`&`）**: 2 つの値の同じ位置のビットが両方 1 のところだけ 1 になる演算です。
- **`int - 1`**: 2 のべき乗から 1 を引くと、その 1 のビットが 0 になり、下の桁がすべて 1 になります（例: 8 - 1 は `0111`）。
- **`assert`**: 前提の条件を確かめる関数です。ここでは正の値だけを受け付けます。
- **`anytype`**: 任意の整数型を受け付けるための書き方です。

## 何をしているか

### 1. 正の値であることを確かめる

```zig:line-numbers=1123
    assert(int > 0);
```

0 以下の値は、2 のべき乗ではありません。また、0 から 1 を引くと溢れてしまうので、`assert` で最初に弾いています。

### 2. 1 を引いて AND を取る

```zig:line-numbers=1124
    return (int & (int - 1)) == 0;
```

`int & (int - 1)` は、最も下の 1 のビットを 0 にした値との AND です。2 のべき乗なら 1 のビットが 1 つだけなので、結果は必ず 0 になります。1 のビットが 2 つ以上あれば、結果は 0 になりません。

## ここがすごい

- **1 回の演算で判定**: ループで 2 で割り続ける方法と違い、計算は引き算と AND の 2 回だけです。
- **ビットの性質を使う**: 「1 のビットが 1 つだけ」という 2 進数の性質を、そのまま式にしています。
- **前提を明示**: `assert` で正の値に限定しているので、0 のときに起きる溢れを防いでいます。
- **型を選ばない**: `anytype` なので、`u32` でも `usize` でも同じ式で使えます。

## まとめ

- 2 のべき乗は、2 進数で 1 のビットが 1 つだけの数です。
- `値 & (値 - 1)` が 0 なら 2 のべき乗です。
- 0 以下の値は `assert` で弾いて、溢れを防いでいます。
