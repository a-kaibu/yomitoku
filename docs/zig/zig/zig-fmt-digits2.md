## ひとことで

`digits2` は、0 から 99 までの値を、ちょうど 2 文字の数字の文字列に変える関数です。たとえば `digits2(7)` は `"07"`、`digits2(42)` は `"42"` を返します。
数を文字列にして表示するときに、1 桁ずつ計算するより速く、2 桁まとめて作れます。

ビルドの種類によって、2 通りの方法を選んでいます。

## コード

```zig:line-numbers=258
pub fn digits2(value: u8) [2]u8 {
    if (builtin.mode == .ReleaseSmall) {
        return .{ @intCast('0' + value / 10), @intCast('0' + value % 10) };
    } else {
        return "00010203040506070809101112131415161718192021222324252627282930313233343536373839404142434445464748495051525354555657585960616263646566676869707172737475767778798081828384858687888990919293949596979899"[value * 2 ..][0..2].*;
    }
}
```
## 前提知識

- **ASCII の数字**: `'0'` は 48、`'1'` は 49 という番号を持つ 1 バイトの文字です。数字の値に `'0'` を足すと、その数字の文字になります。
- **`[2]u8`**: 1 バイトが 2 個並んだ、固定長の配列です。ここでは 2 文字の文字列を表します。
- **`builtin.mode`**: 今のビルドの種類（デバッグ、リリース、小さいリリースなど）を表す定数です。`.ReleaseSmall` は、実行ファイルの大きさを小さくするためのビルドです。
- **`value / 10` と `value % 10`**: 割り算の商と余りです。2 桁の数の、十の位と一の位を取り出せます。
- **`[value * 2 ..][0..2].*`**: 文字列の、`value * 2` の位置から 2 文字を取り出して、配列の値にする書き方です。
- **`@intCast`**: 値を別の整数型に変換します。ここでは、`u8` の計算結果を文字として使える型にしています。

## 何をしているか

### 1. 小さいビルドでは、割り算で作る

```zig:line-numbers=259
    if (builtin.mode == .ReleaseSmall) {
        return .{ @intCast('0' + value / 10), @intCast('0' + value % 10) };
```

`ReleaseSmall` のビルドでは、十の位を `value / 10` で、一の位を `value % 10` で求めます。それぞれに `'0'` を足すと、数字の文字になります。

たとえば `value = 42` なら、`42 / 10 = 4` と `42 % 10 = 2` で、`'4'` と `'2'` になります。表を持たないので、プログラムの大きさが小さくなります。

### 2. ふつうのビルドでは、表を引く

```zig:line-numbers=262
        return "00010203040506070809101112131415161718192021222324252627282930313233343536373839404142434445464748495051525354555657585960616263646566676869707172737475767778798081828384858687888990919293949596979899"[value * 2 ..][0..2].*;
```

ここでは、`"00"`、`"01"` … `"99"` を順に並べた長い文字列を表として使います。`value * 2` の位置から、ちょうど 2 文字を取ります。

たとえば `value = 7` なら、位置 14 から 2 文字で `"07"` です。割り算をせず、文字列の位置を計算するだけで済みます。

## ここがすごい

- **割り算を消す**: 通常のビルドでは、割り算と余りを使いません。表の位置を、掛け算 1 回で求めるだけです。数の表示が多い場面では、この差が効きます。
- **サイズと速さを使い分ける**: 小さいビルドでは表を持たず、速さを少し犠牲にしてサイズを減らします。ふつうのビルドでは表を使い、速さを優先します。同じ関数で両方の要求を満たしています。
- **文字列の表は 1 つの定数**: 表は、プログラムの中の 1 つの文字列として持ちます。実行時に作る必要がなく、とても速く使えます。
- **2 桁まとめて扱う**: 1 桁ずつ変換すると、桁の数だけ処理が増えます。2 桁を 1 度に作れば、数を文字にする処理の回数が減ります。

## まとめ

- 0 から 99 の数は、2 文字の数字の文字列に変換できます。
- 通常のビルドは表を引き、小さいビルドは割り算で作ります。
- 表の位置は、数に 2 を掛けるだけで求まります。
- 数を文字列にする処理を、速く、小さく保つための工夫です。
