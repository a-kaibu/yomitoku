## ひとことで

`smartQuote(str)` は、文字列を表示するときに使う引用符を選ぶ関数です。文字列の中に `"` が含まれていて `'` が含まれていなければ `'` で囲み、そうでなければ `"` で囲んで中の `"` を `\"` にします。`inspect` で値を見たときに、余計な `\` が増えないようにするための工夫です。

## コード

```lua:line-numbers=97
local function smartQuote(str)
   if match(str, '"') and not match(str, "'") then
      return "'" .. str .. "'"
   end
   return '"' .. gsub(str, '"', '\\"') .. '"'
end
```

## 前提知識

- **引用符**: 文字列を囲む記号です。Lua では `"..."` と `'...'` のどちらも使えます。
- **エスケープ**: 文字列の中で特別な意味を持つ文字を、`\` を付けた形で書くことです。`"` を `"` 自身で囲んだ文字列の中に書くには `\"` と書く必要があります。
- **`match`と`gsub`**: `match(str, パターン)` は、文字列の中にパターンに合う部分があるかを調べます。`gsub(str, 検索, 置換)` は、一致した部分をすべて置き換えます。
- **`not`**: 真偽値を反転させる演算子です。`not match(...)` は「見つからない」を意味します。

## 何をしているか

### 1. 単引用符で囲めるかを判断する

`"` が含まれていて、かつ `'` が含まれていなければ、単引用符で囲みます。この場合、中の `"` は `\` を付けなくても正しく読めます。

```lua:line-numbers=98
   if match(str, '"') and not match(str, "'") then
      return "'" .. str .. "'"
   end
```

たとえば `say "hi"` は `'say "hi"'` と表示されます。`\"` が 2 つ並んだ形より、ずっと読みやすくなります。

### 2. それ以外は二重引用符で囲み、`"` をエスケープする

単引用符が使えない場合は、二重引用符で囲みます。そのときは中の `"` を `gsub` で `\"` に置き換えます。

```lua:line-numbers=101
   return '"' .. gsub(str, '"', '\\"') .. '"'
```

`gsub` は置き換えた個数も返しますが、ここでは文字列の連結に使うので、戻り値の 1 つ目だけが自然に使われます。

## ここがすごい

- **見た目の文字数を減らす**: 二重引用符しか使わないと、中の `"` がすべて `\"` になって読みにくくなります。状況に応じて囲みを変えるだけで、この問題が減ります。
- **両方の記号があるときは確実に動く**: 単引用符を使えない（中に両方含まれる）ときは、二重引用符と `\"` の組み合わせで必ず正しく表せます。どちらの場合も、結果は必ず正しい Lua の文字列になります。
- **表示のための工夫**: 値を人が読むための表示なので、「正しく読めるか」と「短く見えるか」を両方考えて決めています。
- **注意点**: この関数は `"` と `'` の囲みだけを扱います。改行や制御文字の扱いは、別の関数 `escape` が担当しています。

## まとめ

- 引用符は、中身に含まれる記号を見て選ぶと、エスケープを減らせる。
- 両方使えないときは、片方をエスケープして必ず正しい形にする。
- 表示用の関数では、読みやすさを優先して分岐を入れる価値がある。
