## ひとことで

`outSine(t, b, c, d)` は、正弦関数を使って、始めに速く、終わりに近づくほどゆっくり止まる動きを表す関数です。指数関数を使う `outExpo` より、やさしい減速になります。正弦関数の四分の一周期を、時間の範囲に当てはめています。

## コード

```lua:line-numbers=103
local function outSine(t, b, c, d) return c * sin(t / d * (pi / 2)) + b end
```

## 前提知識

- **正弦関数 `sin`**: 角度に対して、`-1` から `1` の間を往復する値を返す関数です。角度はラジアンで渡します。
- **四分の一周期 `pi / 2`**: 正弦関数は、`0` から `pi / 2` の間で、`0` から `1` まで増えます。その範囲だけを使えば、ゆっくり増えて止まる曲線になります。
- **時間の正規化 `t / d`**: 経過時間を、全体の長さで割って、`0` から `1` の範囲に直す計算です。
- **`pi`**: 円周率の値です。`math.pi` として、この関数の先頭で取り出されています。

## 何をしているか

### 1. 時間を角度に直す

```lua:line-numbers=103
local function outSine(t, b, c, d) return c * sin(t / d * (pi / 2)) + b end
```

`t / d * (pi / 2)` で、経過の割合を、四分の一周期の角度に変えます。`t` が `0` なら角度は `0`、`d` なら角度は `pi / 2` になります。

### 2. 正弦を取り、変化量を掛ける

```lua:line-numbers=103
local function outSine(t, b, c, d) return c * sin(t / d * (pi / 2)) + b end
```

`sin` で角度から値を求め、変化量 `c` を掛けて、開始の値 `b` を足します。終わりに近い角度では、正弦の変化が小さくなるので、動きが止まって見えます。

## ここがすごい

- **減速がやさしい**: 正弦の曲線は、指数よりも穏やかに減速します。派手さの少ない、落ち着いた動きが作れます。
- **式が短い**: 一行で、時間の変換、正弦、変化量の掛け算、開始値の足し算が書かれています。読みやすく、覚えやすいです。
- **端点が正しい**: 時間が `0` のとき `b`、`d` のとき `b + c` になるように作られています。途中の値は滑らかです。
- **注意点**: 正弦関数の角度は、ラジアンで渡されます。度数で扱いたい場合は、変換を忘れないようにしてください。

## まとめ

- 穏やかな減速は、正弦関数の四分の一周期で表すと、やさしい動きになる。
- 角度の単位がラジアンであることを、式の中で確かめておく。
- 端点の値が正しくなるように式を作ると、アニメーションの始めと終わりが揃う。
