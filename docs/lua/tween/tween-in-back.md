## ひとことで

`inBack(t, b, c, d, s)` は、動き出す前に、わずかに逆向きへ引いてから進む動きを表す関数です。たとえば、ジャンプの前に少し沈むような動きを作れます。係数 `s` で、引く量の大きさを調整できます。省略すると、既定の値 `1.70158` を使います。

## コード

```lua:line-numbers=184
local function inBack(t, b, c, d, s)
  s = s or 1.70158
  t = t / d
  return c * t * t * ((s + 1) * t - s) + b
end
```

## 前提知識

- **オーバーシュート（backの動き）**: 目的の方向へ動く前に、一度逆向きに動く動きのことです。アニメーションに、ためや勢いを出すために使われます。
- **既定値 `s or 1.70158`**: `s` が渡されなければ、既定値を使います。この数は、引きの大きさを自然に見せるために決められた値です。
- **三次式**: `t` の三乗を含む式です。ここでは、`t * t * (...)` の形で表します。
- **時間の正規化 `t / d`**: 経過時間を、全体の長さで割って、`0` から `1` の範囲に直します。

## 何をしているか

### 1. 係数と時間を整える

`s` が省略されていれば、既定の値を入れます。時間 `t` は、全体の長さ `d` で割って正規化します。

```lua:line-numbers=185
  s = s or 1.70158
  t = t / d
```

### 2. 三次式で、引きと進みを表す

`c * t * t * ((s + 1) * t - s) + b` の式が、動きの値を決めます。`s` が大きいほど、途中で大きく引いてから進みます。

```lua:line-numbers=187
  return c * t * t * ((s + 1) * t - s) + b
```

## ここがすごい

- **係数で表情を変える**: 同じ関数で、引きの強さを `s` で変えられます。デザイナーが好みの動きを、数字だけで調整できます。
- **既定値で手軽に使える**: `s` を省くと、一般的に好まれる動きになります。呼ぶ側は、時間と値だけを渡せます。
- **式が一行で完結**: 三次式が一行にまとまっているので、動きの形を式から読み取れます。
- **注意点**: `s` を大きくしすぎると、引きが極端になり、画面の外へ飛び出すことがあります。値は、見た目を確かめながら決めてください。

## まとめ

- 動きの表情は、係数を引数にすると、同じ関数で何通りもの動きを作れる。
- 既定値を用意すると、細かい調整をしない場合も、すぐに使える。
- 式の係数は、結果の見た目を試しながら決めると、思わぬ動きを防げる。
