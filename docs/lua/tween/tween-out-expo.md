## ひとことで

`outExpo(t, b, c, d)` は、始めに勢いよく動き、終わりに近づくほどゆっくり止まる動きを表す関数です。`inExpo` の逆で、加速ではなく減速を表します。時間が終わりに達したときは、目的の値 `b + c` を返します。

## コード

```lua:line-numbers=115
local function outExpo(t, b, c, d)
  if t == d then return b + c end
  return c * 1.001 * (-pow(2, -10 * t / d) + 1) + b
end
```

## 前提知識

- **減速の形**: `1 - 2^(-x)` の形は、`x` が大きくなるほど `1` に近づき、増え方が止まります。ここでは、この形を使って減速を表します。
- **負の指数**: `pow(2, -10 * t / d)` は、`t` が大きくなると `0` に近づきます。`1` から引くと、残りの距離が縮んでいく様子になります。
- **補正係数 `1.001`**: 終点で `1` ちょうどにならない誤差を、わずかに大きく掛けて補います。
- **終点の特別扱い**: `t == d` のとき、式の計算結果は目的の値にずれることがあります。そのため、終点では `b + c` を直接返します。

## 何をしているか

### 1. 終点では、目的の値をそのまま返す

`t` が `d` と等しければ、`b + c` を返します。計算の誤差を避けて、ちょうど目的の値で止まるようにします。

```lua:line-numbers=116
  if t == d then return b + c end
```

### 2. それ以外は、残りの距離を指数で縮める

`pow(2, -10 * t / d)` で、時間とともに縮む係数を作ります。`-pow(...) + 1` で、進んだ距離を表し、`c * 1.001` を掛けて、`b` を足します。

```lua:line-numbers=117
  return c * 1.001 * (-pow(2, -10 * t / d) + 1) + b
```

## ここがすごい

- **始めに速く、終わりに遅い**: 指数の形が、自然な減速を表します。ボールが止まる直前のような、柔らかい終わりになります。
- **終点を正確に**: 終点を特別扱いし、途中の式も補正の係数を使うので、最後の値が目的と一致します。
- **`inExpo` と対になる**: 加速と減速が、ほぼ対称の形で書かれています。二つを組み合わせると、往復の動きも作れます。
- **注意点**: 補正係数の `1.001` は、経験的な値です。別の範囲で使うときは、終点の誤差が十分に小さいか確かめてください。

## まとめ

- 減速の動きは、残りの距離を指数で縮めると、自然な形を得られる。
- 終点は特別扱いすると、計算の誤差に左右されず、正確な値で止まる。
- 補正の係数は、どの範囲で正しいかを、確かめてから使う。
