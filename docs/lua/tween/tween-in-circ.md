## ひとことで

`inCirc(t, b, c, d)` は、円の弧の形を使って、始めはゆっくり、終わりに向けて急に速くなる動きを表す関数です。円の式の平方根を使うので、弧の形がそのまま動きになります。一行で書かれていて、式の形が分かりやすい関数です。

## コード

```lua:line-numbers=132
local function inCirc(t, b, c, d) return(-c * (sqrt(1 - pow(t / d, 2)) - 1) + b) end
```

## 前提知識

- **円の式**: 半径 `1` の円では、`x` の二乗と `y` の二乗の和が `1` になります。`y = sqrt(1 - x²)` は、その円の上半分の高さを表します。
- **`sqrt`**: 平方根を求める関数です。`sqrt(1 - pow(t / d, 2))` は、円の高さを求めます。
- **弧の反転**: `1 - x²` の平方根を `1` から引くと、円弧の下の部分を表せます。`inCirc` は、この形で始まりを緩やかにしています。
- **`return(...)`**: `return` の後の括弧は、戻り値をひとまとめにする書き方です。式の範囲をはっきりさせるために使われています。

## 何をしているか

### 1. 時間の割合から、円の高さを求める

```lua:line-numbers=132
local function inCirc(t, b, c, d) return(-c * (sqrt(1 - pow(t / d, 2)) - 1) + b) end
```

`pow(t / d, 2)` で割合を二乗し、`1` から引いて平方根を取ります。この値は、円弧の高さに対応します。

### 2. 高さの変化を、動きに変える

```lua:line-numbers=132
local function inCirc(t, b, c, d) return(-c * (sqrt(1 - pow(t / d, 2)) - 1) + b) end
```

`-c * (sqrt(...) - 1)` で、円弧の高さを、`0` から `c` の増加に直します。最後に `b` を足して、開始の値に合わせます。

## ここがすごい

- **円の形がそのまま動きに**: 式の形が、円弧の幾何学的な意味を持っています。図で考えると、動きの形を理解しやすくなります。
- **始まりがゆっくり、終わりが急**: 円弧は、端で垂直に近づくので、終わりに向けて急に速くなる形になります。
- **一行で完結**: 平方根の式が一つにまとまっています。計算の量も少なく、毎フレームの呼び出しに向いています。
- **注意点**: 平方根の中が負になると、値が計算できません。`t / d` が `1` を超えないように、時間の範囲を守ってください。

## まとめ

- 円弧の形は、平方根を使うと、始まりのゆっくりさと終わりの急さを表せる。
- 幾何の式を動きに使うと、形の意味を図で確かめながら理解できる。
- 平方根の中身が負にならないように、入力の範囲を確かめておく。
