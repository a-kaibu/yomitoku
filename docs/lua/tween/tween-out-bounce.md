## ひとことで

`outBounce(t, b, c, d)` は、ボールが床に落ちて跳ね、だんだん小さく跳ねて止まる動きを表す関数です。時間 `t` を四つの区間に分け、区間ごとに同じ形の二次式を使います。区間が進むほど、跳ねの高さが小さくなるように、係数が変わります。

## コード

```lua:line-numbers=207
local function outBounce(t, b, c, d)
  t = t / d
  if t < 1 / 2.75 then return c * (7.5625 * t * t) + b end
  if t < 2 / 2.75 then
    t = t - (1.5 / 2.75)
    return c * (7.5625 * t * t + 0.75) + b
  elseif t < 2.5 / 2.75 then
    t = t - (2.25 / 2.75)
    return c * (7.5625 * t * t + 0.9375) + b
  end
  t = t - (2.625 / 2.75)
  return c * (7.5625 * t * t + 0.984375) + b
end
```

## 前提知識

- **区間で式を分ける**: 一つの式で全体を表すのではなく、時間の範囲ごとに式を変える考え方です。`if` で区間を選びます。
- **二次式 `7.5625 * t * t`**: 落下の動きを近似するための係数です。定数 `7.5625` は、跳ねの形を整える値として決められています。
- **`1 / 2.75`**: 区間の境目を表す数です。ボールが一回跳ねて戻るまでの時間を、区切りとして使っています。
- **`t = t - (...)`**: 区間の中で、時間を区間の始まりに合わせて直す計算です。各区間の式が、0 から始まるようになります。

## 何をしているか

### 1. 最初の区間では、落下の式を使う

`t` が最初の境目より小さければ、落下の二次式をそのまま使います。ボールが最初に床へ落ちる部分にあたります。

```lua:line-numbers=208
  t = t / d
  if t < 1 / 2.75 then return c * (7.5625 * t * t) + b end
```

### 2. 次の区間では、少し低い跳ねを表す

二つ目の区間では、時間を区間の始まりに直してから、定数を足した二次式で値を出します。跳ねの頂点が、前より低くなります。

```lua:line-numbers=210
  if t < 2 / 2.75 then
    t = t - (1.5 / 2.75)
    return c * (7.5625 * t * t + 0.75) + b
```

### 3. 後の区間は、さらに小さな跳ね

残りの区間でも、同じ形の式を、少しずつ大きな定数で使います。最後は、ほぼ床に着いた状態を表します。

```lua:line-numbers=213
  elseif t < 2.5 / 2.75 then
    t = t - (2.25 / 2.75)
    return c * (7.5625 * t * t + 0.9375) + b
  end
  t = t - (2.625 / 2.75)
  return c * (7.5625 * t * t + 0.984375) + b
```

## ここがすごい

- **わずかな式で跳ねを表す**: 物理の計算をしなくても、同じ形の式を区間ごとに変えるだけで、跳ねる動きになります。
- **区間の境目が繋がる**: 各区間の式は、境目で同じ値になるように作られています。途中で値が飛ばず、自然に見えます。
- **時間を毎回直す**: 区間ごとに時間を 0 から始め直すので、式が同じ形のまま使えます。
- **注意点**: 区間の境目は、定数で決まっています。跳ねの回数や高さを変えたいときは、定数を調べ直す必要があります。

## まとめ

- 複雑な動きは、時間を区間に分けて、区間ごとの簡単な式で表すと作りやすい。
- 区間の境目で値が繋がるように式を作ると、動きが滑らかになる。
- 区間の中で時間を 0 から数え直すと、式の形を揃えて使い回せる。
