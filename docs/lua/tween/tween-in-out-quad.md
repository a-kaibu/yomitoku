## ひとことで

`inOutQuad(t, b, c, d)` は、アニメーションの進み具合を、加速してから減速する曲線に変換する関数です。`t` は経過時間、`b` は開始の値、`c` は変化量、`d` は全体の時間です。前半は二次関数で加速し、後半は同じ形で減速します。滑らかな動きを作るための、イージングの一つです。

## コード

```lua:line-numbers=51
local function inOutQuad(t, b, c, d)
  t = t / d * 2
  if t < 1 then return c / 2 * pow(t, 2) + b end
  return -c / 2 * ((t - 1) * (t - 3) - 1) + b
end
```

## 前提知識

- **イージング（easing）**: 時間の進み方を、直線ではなく曲線に変える仕組みです。動きの始まりや終わりを、自然に見せるために使います。
- **二次関数**: `t` の二乗を使う式です。`pow(t, 2)` のように書きます。二乗は、最初は小さく、後で大きくなるので、加速を表せます。
- **変化量 `c` と開始値 `b`**: 値は `b + c * (進み具合)` で決まります。進み具合が `0` なら `b`、`1` なら `b + c` になります。
- **`t = t / d * 2`**: 時間を `0` から `2` の範囲に直す計算です。前半と後半を、同じ式の範囲で扱うための準備です。

## 何をしているか

### 1. 前半は、二乗で加速する

`t` を `2` 倍にした結果が `1` より小さければ、前半です。`c / 2 * pow(t, 2) + b` で、ゆっくり始まる曲線になります。

```lua:line-numbers=52
  t = t / d * 2
  if t < 1 then return c / 2 * pow(t, 2) + b end
```

### 2. 後半は、ひっくり返した二乗で減速する

前半を過ぎたら、`t - 1` と `t - 3` の積を使う式で、後半の減速を表します。終わりに近づくほど、動きが緩やかになります。

```lua:line-numbers=54
  return -c / 2 * ((t - 1) * (t - 3) - 1) + b
```

## ここがすごい

- **前半と後半が繋がる**: 二つの式は、中央で同じ値になるように作られています。途中で値が飛ばず、動きが滑らかです。
- **一つの関数で両側を扱う**: 加速と減速を、一つの関数に収めています。呼ぶ側は、時間だけを渡せば済みます。
- **式が短い**: 二つの式だけで、動きの全体が決まります。計算の量も少なく、アニメーションの毎フレームで使えます。
- **注意点**: `d` が `0` だと、時間の割り算で値が崩れます。時間の長さは、必ず正の数で渡してください。

## まとめ

- 滑らかな動きは、前半と後半を同じ値で繋いだ二つの式で表せる。
- 加速と減速を一つの関数にまとめると、呼ぶ側の指定が一つで済む。
- 割り算の分母になる時間は、正の値であることを確かめておく。
