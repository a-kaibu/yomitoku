## ひとことで

`inExpo(t, b, c, d)` は、始めはゆっくり動き、終わりに向けて急に速くなる動きを表す関数です。指数関数を使うので、加速が急に効いてきます。時間が 0 のときは、計算せずに開始の値 `b` を返します。

## コード

```lua:line-numbers=111
local function inExpo(t, b, c, d)
  if t == 0 then return b end
  return c * pow(2, 10 * (t / d - 1)) + b - c * 0.001
end
```

## 前提知識

- **指数関数**: `2` の何乗かを求める関数です。指数が大きくなるほど、値が急に増えます。ここでは `pow(2, ...)` で表します。
- **`pow`**: べき乗を計算する関数です。`pow(2, x)` は、`2` の `x` 乗を返します。
- **時間の正規化 `t / d`**: 経過時間を、全体の長さで割って `0` から `1` の範囲に直す計算です。
- **補正 `- c * 0.001`**: 指数の式は、`t` が `d` のときに、ぴったり終点に届きません。その差を、小さな補正で合わせています。

## 何をしているか

### 1. 始まりの時間は、開始の値を返す

`t` が `0` なら、`b` をそのまま返します。指数の式で、始まりの値を計算すると、わずかな誤差が出るので、ここで特別に扱います。

```lua:line-numbers=112
  if t == 0 then return b end
```

### 2. それ以外は、指数の式で値を求める

`pow(2, 10 * (t / d - 1))` は、時間が進むほど大きくなります。これに変化量 `c` を掛けて、開始の値 `b` を足します。最後の `- c * 0.001` が、終点の誤差を補正します。

```lua:line-numbers=113
  return c * pow(2, 10 * (t / d - 1)) + b - c * 0.001
```

## ここがすごい

- **終わりに向けて急に加速**: 指数関数の形によって、後半だけが大きく動きます。ゆっくりした始まりから、勢いのある動きが表せます。
- **端点を丁寧に扱う**: 始まりの値を特別扱いし、終わりの誤差を補正します。アニメーションが、ぴったり正しい値で始まり、終わることを保証します。
- **式が一行に収まる**: 時間の正規化と指数の計算が、一つの式にまとまっています。読んで意味を追いやすいです。
- **注意点**: `d` が `0` だと、正規化の割り算で値が崩れます。時間は必ず正の値で渡してください。

## まとめ

- 急に加速する動きは、指数関数で表すと、少ない計算で作れる。
- 端点の誤差は、特別な場合として扱うか、補正の項で合わせると、正確な値を得られる。
- 時間の正規化の分母は、正の値であることを確かめておく。
