## ひとことで

`inOutSine(t, b, c, d)` は、動き出しと止まり際の両方を、ゆるやかにする動きを表す関数です。余弦関数の一周期の半分を使い、前半は加速し、後半は減速します。始まりと終わりが、どちらもなめらかになる点が特徴です。

## コード

```lua:line-numbers=104
local function inOutSine(t, b, c, d) return -c / 2 * (cos(pi * t / d) - 1) + b end
```

## 前提知識

- **余弦関数 `cos`**: 角度に対して、`-1` から `1` の間を往復する値を返す関数です。`cos(0)` は `1`、`cos(pi)` は `-1` です。
- **半周期 `pi * t / d`**: 時間の割合を、`0` から `pi` の角度に直します。`cos` は、この範囲で `1` から `-1` へ変化します。
- **`-c / 2 * (cos(...) - 1)`**: 余弦の値を、`0` から `1` の増加に変えるための式です。`cos - 1` は、`0` から `-2` の範囲を取るので、符号を反転させて `c / 2` を掛けます。
- **なめらかな端点**: 余弦の変化は、始めと終わりで傾きが `0` になります。そのため、止まっている状態から動き出し、止まる動きになります。

## 何をしているか

### 1. 時間を半周期の角度に直す

```lua:line-numbers=104
local function inOutSine(t, b, c, d) return -c / 2 * (cos(pi * t / d) - 1) + b end
```

`pi * t / d` で、経過の割合を、`0` から `pi` の角度にします。時間の全体が、余弦の半周期にあたります。

### 2. 余弦の変化を、増加に直す

```lua:line-numbers=104
local function inOutSine(t, b, c, d) return -c / 2 * (cos(pi * t / d) - 1) + b end
```

`cos(...) - 1` で、値を `0` から `-2` の範囲にします。`-c / 2` を掛けると、`0` から `c` の増加になります。最後に `b` を足して、開始の値を合わせます。

## ここがすごい

- **始まりと終わりが同時になめらか**: 傾きが始めと終わりで `0` になるので、止まった状態からの動き出しと、止まり際が、どちらも自然に見えます。
- **前半と後半が対称**: 前半の加速と後半の減速が、同じ曲線の半分として対称になっています。往復する動きにも向いています。
- **式が一行**: 余弦の一つの式で、全体が決まります。動きの形を、式の中で完全に表せます。
- **注意点**: `d` が `0` のときは、割り算で値が崩れます。時間は正の値で渡してください。

## まとめ

- 始めと終わりを両方なめらかにするには、余弦の半周期を使うと、対称な動きを表せる。
- 余弦の値を増加に直すときは、範囲と符号を確かめて、式を組み立てる。
- 傾きが端で `0` になる曲線は、止まる直前や動き出しで自然に見える。
