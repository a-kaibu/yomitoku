## ひとことで

`util.LQ(s)` は、文字列 `s` を、Lua のソースコードとして読める引用符つきの形に変える関数です。中の引用符や改行などは、正しくエスケープされます。LuaRocks が設定ファイルを書き出すときに、文字列をそのまま埋め込むために使われます。

## コード

```lua:line-numbers=354
function util.LQ(s)
   return ("%q"):format(s)
end
```

## 前提知識

- **`string.format` と `%q`**: 書式指定の一つで、文字列を Lua のリテラルとして読める形にします。両端に引用符を付け、特別な文字をエスケープします。
- **メソッド呼び出し `("%q"):format(s)`**: 文字列の値にメソッドを付けて呼ぶ書き方です。文字列は、`string` のメソッドを直接使えます。
- **リテラル**: ソースコードの中に直接書かれた値のことです。`"abc"` の `abc` を含む、引用符ごとの書き方を指します。
- **エスケープ**: 引用符や改行などを、文字列の中に安全に書くための書き方です。`"` や `
` のように表されます。

## 何をしているか

### 1. 書式指定で、リテラルの形にする

`("%q"):format(s)` は、`s` を引用符で囲み、引用符、バックスラッシュ、改行などをエスケープした文字列を返します。関数は、この結果をそのまま返すだけです。

```lua:line-numbers=355
   return ("%q"):format(s)
```

## ここがすごい

- **標準の機能に任せる**: 引用符や改行の扱いを、自分で書く必要がありません。`%q` は、Lua の文法に合った形を正しく作ってくれます。
- **読み込み直せる形になる**: 結果を `load` などで読み直すと、元の文字列に戻ります。書き出したファイルを、後で正しく読めるという利点があります。
- **一行の小さな関数**: 役割が一つだけなので、呼ぶ側の意図が名前から伝わります。
- **注意点**: `%q` は、数の値に対しては、数の書き方で出力します。文字列として欲しい場合は、先に `tostring` で変換しておいてください。

## まとめ

- 文字列を別のコードに埋め込むときは、言語の書式指定に任せると、エスケープの間違いを防げる。
- 結果を読み直せる形にしておくと、書き出したデータを後で確かめやすい。
- 数と文字列の違いは、書式指定の結果に表れるので、型を意識する。
