## ひとことで

`util.split_namespace(ns_name)` は、`"lpeg/lpeg"` のように `名前空間/パッケージ名` と書かれた文字列を、2 つに分ける関数です。`/` が 1 つだけあって、その前後に文字がある形のときに分けられます。分けられなければ、元の文字列をそのまま返します。

## コード

```lua:line-numbers=361
function util.split_namespace(ns_name)
   local p1, p2 = ns_name:match("^([^/]+)/([^/]+)$")
   if p1 then
      return p2, p1
   end
   return ns_name
end
```

## 前提知識

- **パターンの `^` と `$`**: `^` は文字列の先頭、`$` は末尾に一致します。両方を付けると、文字列全体がその形かどうかを確かめられます。
- **`[^/]`**: 「`/` 以外の文字」を表す集合です。`^` を集合の先頭に付けると、否定の意味になります。
- **`+`**: 直前の文字や集合が 1 回以上続くことを表します。`[^/]+` は、`/` 以外の文字が 1 文字以上続くことです。
- **`match`の複数の戻り値**: `()` で囲んだ部分は、それぞれ別の戻り値として返ります。

## 何をしているか

### 1. 2 つの部分に分けてみる

`^([^/]+)/([^/]+)$` は、「`/` より前に `/` 以外の文字が続き、`/`、その後ろに `/` 以外の文字が続き、末尾で終わる」という形です。一致すれば、`/` の前を `p1`、後ろを `p2` として取り出します。

```lua:line-numbers=362
   local p1, p2 = ns_name:match("^([^/]+)/([^/]+)$")
```

### 2. 形が合えば、順番を入れ替えて返す

分けられたら（`p1` が `nil` でなければ）、`p2`（パッケージ名）を先に、`p1`（名前空間）を後に返します。関数の呼び出し側は、名前を先頭に受け取る形になっています。

```lua:line-numbers=363
   if p1 then
      return p2, p1
   end
```

### 3. 形が合わなければ元の名前

`/` がない、または `/` が複数ある場合は、一致しないので `p1` は `nil` です。その場合は、元の文字列を名前としてそのまま返します。

```lua:line-numbers=366
   return ns_name
```

## ここがすごい

- **1 つのパターンで、形の確認と分割を同時に行う**: 形が正しいかどうかを確かめるのと、中身を取り出すのを、1 回の `match` でまとめています。
- **不正な形でも壊れない**: `/` が 2 つあるような形は、一致しないので分けられません。その場合は、名前として元の文字列をそのまま使い、後で別の処理に任せます。
- **返す順番で意味を持たせる**: 名前を先に、名前空間を後に返すことで、呼び出し側は名前をまず受け取れます。
- **注意点**: 名前が空の場合（`"/name"`）は、`[^/]+` に一致しないので、分けられません。この関数はその場合を「分けられない名前」として扱います。

## まとめ

- 決まった形の文字列を 2 つに分けるときは、形の確認と取り出しを 1 つのパターンでまとめられる。
- 形が合わないときに元の文字列を返すと、呼び出し側が安全に続けられる。
- 返す値の順番を、呼び出し側の使い方に合わせて決めると、読みやすくなる。
