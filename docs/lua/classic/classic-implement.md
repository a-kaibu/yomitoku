## ひとことで

`Object:implement(...)` は、引数に渡した複数のテーブル（mixin と呼ばれる部品）から、関数を 1 つずつ借りてきてクラスに足す関数です。ただし、クラスがすでに同じ名前のメソッドを持っていれば、そちらを優先して上書きしません。継承を使わずに、機能の部品を組み合わせるための仕組みです。

## コード

```lua:line-numbers=33
function Object:implement(...)
  for _, cls in pairs({...}) do
    for k, v in pairs(cls) do
      if self[k] == nil and type(v) == "function" then
        self[k] = v
      end
    end
  end
end
```

## 前提知識

- **mixin（ミックスイン）**: 機能のまとまりを 1 つのテーブルにしておき、必要なクラスに部品として足す設計の考え方です。継承よりも柔軟に機能を組み合わせられます。
- **可変長引数 `...`**: 関数に渡された引数をいくつでも受け取る書き方です。`{...}` とすると、引数を配列にまとめられます。
- **`pairs`**: テーブルのキーと値を順番に取り出す関数です。
- **`type(v) == "function"`**: 値が関数かどうかを調べます。ここでは、データの値は無視して、メソッドだけを借りるために使います。

## 何をしているか

### 1. 渡された部品を順番に見る

`{...}` で引数の部品を配列にし、`pairs` で 1 つずつ取り出します。ひとつひとつが `cls` という名前のテーブルです。

```lua:line-numbers=34
  for _, cls in pairs({...}) do
```

### 2. 関数だけを選んで、足りないものを足す

`cls` の中のキーと値を 1 つずつ見て、`self[k] == nil` のとき（クラスにまだその名前がないとき）だけ代入します。`type(v) == "function"` で、関数だけを対象にしています。

```lua:line-numbers=36
      if self[k] == nil and type(v) == "function" then
        self[k] = v
      end
```

### 3. 先に来た定義が勝つ

部品が複数あって同じ名前のメソッドがあれば、先に足されたものが残ります。後から足すものは `self[k] == nil` で弾かれるからです。また、クラス自身のメソッドは最初から存在するので、上書きされることはありません。

## ここがすごい

- **既存の定義を壊さない**: `self[k] == nil` の 1 行で、クラス本体のメソッドを守っています。部品を後から足しても、もとの動きが変わりません。
- **継承を使わずに機能を組み合わせられる**: 親は 1 つだけという制限がありません。複数の部品を並べて足せるので、機能ごとにファイルを分けやすくなります。
- **素直な書き方との比較**: 単純に `self[k] = v` と書くと、部品が元のクラスを上書きしてしまいます。`nil` の確認を入れるだけで、この問題を防げます。
- **トレードオフ**: 同じ名前が衝突したとき、どちらが使われるかは引数の順番で決まります。順番を間違えると気づきにくいので、名前の衝突は避けるほうがよいです。

## まとめ

- 部品のメソッドを借りるときは、既存の名前を上書きしない条件を付ける。
- 可変長引数を `{...}` で配列にすると、部品の数に関係なく同じ処理で扱える。
- 継承の代わりに mixin を使うと、機能を柔軟に組み合わせられる。
