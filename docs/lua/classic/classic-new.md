## ひとことで

`Object:new()` は、インスタンスが作られたときに呼ばれる初期化の関数です。中身は空で、何もしません。基底のクラスに、この空の入口を置いておくことで、子クラスは必要なときだけ `new` を書けば済みます。空でも、初期化の約束を決めておく大切な関数です。

## コード

```lua:line-numbers=15
function Object:new()
end
```

## 前提知識

- **`Object:__call`**: `Class(...)` と書いたときに、インスタンスを作って `new` を呼ぶ関数です。`new` は、その後で呼ばれる初期化の一歩です。
- **メソッドの上書き**: 子クラスで同じ名前の関数を書くと、子の関数が優先されます。`new` も、この仕組みで子ごとに書き換えられます。
- **空の関数の役割**: 何もしない関数でも、呼び出しの約束として存在することに意味があります。呼ぶ側が、場合分けなしに `new` を呼べます。
- **`...` の受け渡し**: `__call` が受け取った引数を、そのまま `new` に渡します。空の関数では、それを受け取って捨てています。

## 何をしているか

### 1. 何もしない初期化を用意する

`Object:new()` の本体は空です。そのため、基底のクラスから作ったインスタンスは、何の値も持たずに作られます。

```lua:line-numbers=15
function Object:new()
end
```

## ここがすごい

- **呼び出しが統一される**: どのクラスでも、`new` を呼べば初期化が行われます。子クラスが書いていなくても、呼び出しでエラーになりません。
- **子が必要な分だけ書く**: 初期化が要らないクラスは、何も書かずに済みます。書く量が、必要な分だけになります。
- **約束を残す**: 初期化の入口を基底に置くことで、「インスタンスには `new` がある」という約束が、すべての子に伝わります。
- **注意点**: 子クラスで `new` を書くときは、親の `new` を呼ぶかどうかを決める必要があります。呼び忘れると、親が用意した初期値が入りません。

## まとめ

- 初期化の入口は、基底で空の関数として用意すると、呼び出しを全体で統一できる。
- 何もしない関数でも、約束として置いておく価値がある。
- 子で初期化を書くときは、親の初期化を呼ぶかどうかを意識する。
