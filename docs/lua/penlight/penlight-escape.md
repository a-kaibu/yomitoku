## ひとことで

`utils.escape(s)` は、文字列 `s` の中の、Lua のパターンで特別な意味を持つ記号を、`%` で守った形に変える関数です。`utils.escape("1+1")` は `"1%+1"` になります。こうすると、`s` をパターンとして検索したときに、記号が「ただの文字」として一致します。

## コード

```lua:line-numbers=695
function utils.escape(s)
    utils.assert_string(1,s)
    return (s:gsub('[%-%.%+%[%]%(%)%$%^%%%?%*]','%%%1'))
end
```

## 前提知識

- **Lua のパターン**: `find`、`match`、`gsub` で使う検索の書き方です。`.`（任意の 1 文字）、`+`（1 回以上の繰り返し）、`%` などの記号に特別な意味があります。
- **`%` のエスケープ**: パターンの中で `%` を前に付けると、その記号を普通の文字として扱えます。`%.` は `.` の文字そのものです。
- **`gsub` の置き換え**: `s:gsub(パターン, 置き換え)` は、一致したところを置き換えます。`%1` は、パターンの 1 つ目の `( )` に一致した文字を指します。
- **`utils.assert_string`**: 引数が文字列でなければエラーにする Penlight の確認関数です。

## 何をしているか

### 1. 文字列であることを確かめる

最初に `utils.assert_string(1, s)` で、引数が文字列かを確かめます。数字や `nil` が渡されると、ここでエラーになります。

```lua:line-numbers=696
    utils.assert_string(1,s)
```

### 2. 特別な記号の前に `%` を付ける

パターンの `[ ]` の中に、対象の記号を並べています。`%-`、`%.`、`%+` などのように、それぞれの記号に `%` を付けた形で書かれています。見つかった記号は、`'%%%1'` の置き換えで、`%` と記号自身の組に変わります。

```lua:line-numbers=697
    return (s:gsub('[%-%.%+%[%]%(%)%$%^%%%?%*]','%%%1'))
```

外側の `( )` は、`gsub` が返す「置き換えた個数」を捨てて、文字列だけを返すためのものです。

## ここがすごい

- **パターンの記号を一覧で守る**: `. + - * ? [ ] ( ) $ ^ %` の 12 種類が、1 つの集合にまとめて書かれています。対象の記号を取りこぼさないように、全部を並べています。
- **`%` 自身も忘れない**: 最後の `%%` を守らないと、置き換えた `%` が次の記号と組み合わさって、壊れたパターンになります。この関数は、その基本も押さえています。
- **元の文字列を検索に使える**: ユーザーが入力した文字列を、そのままパターンに埋め込むと、記号が特別な意味を持って誤動作します。この関数を通せば、安全に検索できます。
- **注意点**: この関数は、Lua のパターン用です。正規表現（PCRE など）とは記号の集まりが違うので、他の検索方式には使えません。

## まとめ

- 外から受け取った文字列をパターンに入れるときは、特別な記号を `%` で守る。
- 記号の一覧は、取りこぼしがないように一度にすべて並べる。
- 検索の方式が変わると記号の意味も変わるので、対応する方式に合わせてエスケープする。
