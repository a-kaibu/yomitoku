## ひとことで

`escape_char(c)` は、JSON の文字列の中で特別な意味を持つ文字を、`\` で始まる書き方に置き換える関数です。改行は `\n`、タブは `\t` のような短い記号に変えます。対応する記号がない制御文字は `\u0001` のように 16 進数で表します。

## コード

```lua:line-numbers=49
local function escape_char(c)
  return "\\" .. (escape_char_map[c] or string.format("u%04x", c:byte()))
end
```

この関数は、変換の対応表 `escape_char_map` を使います。読むのに必要なので、そのまま引用します。

```lua:line-numbers=33
local escape_char_map = {
  [ "\\" ] = "\\",
  [ "\"" ] = "\"",
  [ "\b" ] = "b",
  [ "\f" ] = "f",
  [ "\n" ] = "n",
  [ "\r" ] = "r",
  [ "\t" ] = "t",
}
```

## 前提知識

- **制御文字**: 画面に表示されない文字のことです。改行 `\n`、タブ `\t`、改ページ `\f` などがあり、ASCII の 0〜31 の番号を持ちます。
- **エスケープ**: 文字列の中で特別な意味を持つ文字を、別の書き方で表すことです。JSON では `\"` や `\\` が代表例です。
- **`c:byte()`**: 1 文字の数値（バイト）を返します。`"\n"` なら `10` です。
- **`string.format("%04x", n)`**: 数値 `n` を 16 進数にして、4 桁になるように `0` で埋めます。`%x` は小文字の 16 進数です。
- **`or`**: 左の値が `nil` なら右の値を使います。対応表にない文字に、代わりの書き方を用意するために使われています。

## 何をしているか

### 1. 対応表を先に探す

`escape_char_map[c]` で、その文字に対応する短い記号を探します。`"\n"` なら `"n"`、`"\t"` なら `"t"` が返ります。

```lua:line-numbers=50
  return "\\" .. (escape_char_map[c] or string.format("u%04x", c:byte()))
```

### 2. 表になければ 16 進数の形にする

対応表に `c` がなければ、`escape_char_map[c]` は `nil` になるので、`or` の右側が使われます。`string.format("u%04x", c:byte())` は、文字の番号を 4 桁の 16 進数にします。たとえば文字 `\1`（番号 1）は `u0001` になります。

### 3. 先頭に `\` を付ける

最後に `"\\" ..` で、`\` を先頭に付けます。`\n` の場合は `\` と `n` がつながって `\n` という 2 文字になり、JSON の文字列として正しい書き方になります。

### 4. 他の関数から呼ばれる場所

この関数は、文字列をまとめて変換する `encode_string` から使われます。文字列中の制御文字や `\`、`"` を見つけると、この関数に 1 文字ずつ渡されます。

```lua:line-numbers=101
local function encode_string(val)
  return '"' .. val:gsub('[%z\1-\31\\"]', escape_char) .. '"'
end
```

`[%z\1-\31\\"]` は、「ヌル文字（`%z`）、`\1` から `\31`、`\`、`"`」のどれかに一致するパターンです。`gsub` は、一致した文字だけを `escape_char` で変換します。

## ここがすごい

- **よく使う文字は短く、残りは番号で**: 改行やタブを `\u000a` のように書くと読みにくくなります。対応表で短い記号を優先し、表にない文字だけを番号で表す二段構えになっています。
- **`or` 1 つで分岐を書ける**: 表にあれば表の値、なければ番号の形を使う、という分岐を 1 行で書いています。対応表を増やしても、この関数の形は変わりません。
- **`\` と `"` を忘れない**: 対応表の 1 つ目と 2 つ目の行で、`\` と `"` 自身も `\\` と `\"` に変換されています。ここを忘れると、JSON の形が壊れてしまいます。
- **注意点**: 対応表にない文字の場合、`string.format("%04x")` は 1 バイトの値を前提にしています。マルチバイトの UTF-8 文字は、この関数に来る前に別の処理で扱われる前提です。

## まとめ

- 特別な文字は対応表で短い記号に、表にない制御文字は `\u` と 4 桁の 16 進数にする。
- `or` で「表になければ別の書き方」を 1 行で書ける。
- 変換の対象は、`gsub` のパターンで一度に絞り込むと効率よく処理できる。
