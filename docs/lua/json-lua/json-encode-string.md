## ひとことで

`encode_string(val)` は、Lua の文字列を JSON の文字列の形に変換する関数です。引用符、バックスラッシュ、制御文字を、エスケープした形に置き換えてから、前後に引用符を付けます。JSON の文字列として正しい形にするための、最後の一歩にあたります。

## コード

```lua:line-numbers=101
local function encode_string(val)
  return '"' .. val:gsub('[%z\1-\31\\"]', escape_char) .. '"'
end
```

## 前提知識

- **パターンの文字集合 `[...]`**: 角括弧の中に並べた文字のどれか一つに一致する書き方です。ここでは、制御文字、バックスラッシュ、引用符が対象です。
- **`%z`**: 値が `0` の文字（ヌル文字）を表すパターンの指定です。Lua 5.2 以降では `\0` を直接書けますが、古い書き方として残っています。
- **`gsub`**: 文字列の中のパターンを、別の文字列や関数で置き換える Lua の関数です。置き換えた文字列と、置き換えた回数の 2 つを返します。
- **`..` による連結**: 文字列どうしを、前後につなぐ演算子です。

## 何をしているか

### 1. 特別な文字を一か所で置き換える

```lua:line-numbers=102
  return '"' .. val:gsub('[%z\1-\31\\"]', escape_char) .. '"'
```

`val:gsub('[%z\1-\31\\"]', escape_char)` は、対象の文字を見つけるたびに `escape_char` に渡し、その戻り値で置き換えます。`escape_char` は、文字ごとに、JSON で正しいエスケープの形を返す関数です。

### 2. 両端に引用符を付ける

```lua:line-numbers=102
  return '"' .. val:gsub('[%z\1-\31\\"]', escape_char) .. '"'
```

置き換えた文字列の前後に、`"` を連結します。これで、JSON の文字列としての形が完成します。

## ここがすごい

- **パターンで対象を一度に指定**: 制御文字、バックスラッシュ、引用符を、一つの文字集合にまとめています。対象を一つずつ書き並べる必要がありません。
- **戻り値の数に気をつける**: `gsub` は 2 つの値を返しますが、連結の式の中では、最初の値だけが使われます。そのため、`..` で続けて書いても、余計な数が混ざりません。
- **置き換えを関数に任せる**: 文字ごとの変換を、`escape_char` という別の関数に分けています。処理の中身が、読みやすく分かれています。
- **注意点**: 対象の文字集合を変えると、JSON として正しくない文字列が生まれることがあります。また、この関数は UTF-8 の多バイト文字には手を入れないので、そのまま出力されます。

## まとめ

- 文字列を安全に埋め込むときは、特別な文字を集合で一度に指定すると、対象の抜けを防げる。
- `gsub` の戻り値は、連結の中で一つだけ使われるので、余計な値を気にせず書ける。
- 置き換えの中身は関数に分けると、変換の規則を一か所で読める。
