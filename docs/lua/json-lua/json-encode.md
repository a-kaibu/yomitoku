## ひとことで

`json.encode(val)` は、Lua の値を JSON の文字列にして返す公開の関数です。中身は、内部の `encode` に任せています。その結果を括弧で囲んでいるのが特徴で、これで戻り値は一つだけになります。利用者が使う入口として、形をきれいに揃えるための小さな工夫です。

## コード

```lua:line-numbers=134
function json.encode(val)
  return ( encode(val) )
end
```

## 前提知識

- **複数の戻り値**: Lua の関数は、カンマで区切って複数の値を返せます。内部の関数が二つ以上返す場合、そのまま返すと、呼ぶ側に余計な値が渡ってしまいます。
- **括弧による戻り値の絞り込み**: `(f(x))` と括弧で囲むと、戻り値は最初の一つだけになります。余分な値を捨てる、Lua の標準的な書き方です。
- **`encode`**: 値の種類ごとに、JSON の形を作る内部の関数です。`nil`、表、文字列、数などを、それぞれ適切に変換します。
- **公開と内部の分け方**: 公開の関数は利用者が直接呼ぶものです。内部の関数は、外から見せずに、細かい処理を分担します。

## 何をしているか

### 1. 内部の encode に任せる

`encode(val)` は、値の種類に応じた変換を行い、JSON の文字列を返します。この関数は、変換の中身を知らなくても使えるように、入口だけを提供します。

```lua:line-numbers=135
  return ( encode(val) )
```

## ここがすごい

- **戻り値が一つに揃う**: 括弧で囲むので、内部の関数がどれだけ値を返しても、利用者には文字列一つだけが渡ります。思わぬ値が混ざる心配がありません。
- **入口がとても薄い**: 公開の関数は、内部の処理に委ねるだけです。変換の規則を変えても、この関数は書き換えずに済みます。
- **読んでも迷わない**: 一行で、「何を返すか」が明確です。利用者は、中身を読まなくても、使い方を理解できます。
- **注意点**: 括弧を外すと、内部の関数の戻り値が全部外に出るおそれがあります。この一行は、見た目より重要な役割を持っています。

## まとめ

- 公開の関数で戻り値を絞ると、利用者に余計な値を渡さずに済む。
- 入口を薄く保つと、内部の変換規則を変えても、外側の形は変わらない。
- 括弧のように小さな書き方も、戻り値の数を制御するという意味を持つ。
