## ひとことで

`zeros()` は、値 `0` を無限に繰り返すイテレータを作る関数です。引数はなく、呼ぶだけで列ができます。初期値を埋めたり、足し算の土台にしたりするときに使えます。`ones` は、同じ仕組みで値 `1` を繰り返します。

## コード

```lua:line-numbers=270
local zeros = function()
    return wrap(duplicate_gen, 0, 0)
end
```

## 前提知識

- **無限の列と遅延**: 値を先に全部作らず、使われたときに一つずつ作る列です。`zeros` は、終わりのない列を、わずかな情報で表します。
- **`duplicate_gen`**: 同じ値を繰り返す内部のイテレータの関数です。値を一つ渡して、それを返し続けます。
- **`wrap`**: 3 つ組のイテレータを、Lua Fun の扱う形にまとめる関数です。
- **引数の固定**: `zeros` は、繰り返す値をあらかじめ `0` に決めています。呼ぶ側は、値を指定しなくて済みます。

## 何をしているか

### 1. 繰り返す値 0 を、材料として渡す

`wrap(duplicate_gen, 0, 0)` の最初の `0` が、繰り返される値です。二つ目の `0` は、数え始めの状態です。

```lua:line-numbers=271
    return wrap(duplicate_gen, 0, 0)
```

### 2. 列を呼び出し元に返す

`wrap` が作った、イテレータの形を返します。呼ぶ側は、これを他の関数に渡して使えます。

```lua:line-numbers=271
    return wrap(duplicate_gen, 0, 0)
```

## ここがすごい

- **引数なしで使える**: 値を決めて呼ぶ必要がなく、呼ぶだけで列が手に入ります。書く量が少なくなります。
- **メモリを使わない**: 列の全体を表に作らないので、どれだけ長く使っても、必要なメモリはほとんど増えません。
- **他の関数と組み合わせやすい**: `take_n` で個数を決めたり、`zip` で別の列と並べたりと、遅延の列の部品として使えます。
- **注意点**: 無限の列を、そのまま全部回すと、終わりません。必ず、個数を決める関数と組み合わせて使ってください。

## まとめ

- 決まった値を無限に並べたいときは、値を固定した関数を用意すると、呼び出しが簡単になる。
- 遅延の列は、使う部分だけを作るので、メモリを節約できる。
- 無限の列は、終わりを決める処理と組み合わせて使う。
