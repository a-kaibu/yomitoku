## ひとことで

`is_null(gen, param, state)` は、イテレータが空かどうかを調べる関数です。空なら `true`、値が一つでもあれば `false` を返します。大事なのは、調べるために使った状態をコピーしてから進める点で、元のイテレータは、この関数の前と後で同じ位置のままです。

## コード

```lua:line-numbers=643
local is_null = function(gen, param, state)
    return gen(param, deepcopy(state)) == nil
end
```

## 前提知識

- **状態の共有**: イテレータの状態が表のような書き換えられる値だと、一度進めると元の位置も変わってしまいます。
- **`deepcopy`**: 表の中身を、すべて新しく作り直す関数です。Lua Fun は、状態を複製するためにこの関数を持っています。
- **値を見るだけの判定**: 空かどうかは、最初の一つを取り出せるかで決まります。取り出した値は、判定にだけ使います。
- **`== nil`**: 次の状態が `nil` なら、列は終わりです。この比べ方で、空かどうかを判定しています。

## 何をしているか

### 1. 状態をコピーしてから、一つ進める

`deepcopy(state)` で、状態の写しを作ります。その写しを使って `gen(param, ...)` を一回呼びます。元の `state` は、この呼び出しの影響を受けません。

```lua:line-numbers=644
    return gen(param, deepcopy(state)) == nil
```

### 2. 次の状態が nil かで答える

呼んだ結果が `nil` なら、一つも値がなかったことになります。そのとき `is_null` は `true` を返します。値があれば、`false` を返します。

## ここがすごい

- **元の列を変えない**: 判定のために進めても、呼び出し元のイテレータは、まだ先頭のままです。調べた後も、同じ列を続けて使えます。
- **一行で書ける**: 写し、進める、比べる、の三つが、一つの式で表されています。短く、目的が明確です。
- **状態の型を選ばない**: 深いコピーを使うので、表でできた状態でも、数や文字列でも、同じように扱えます。
- **注意点**: 深いコピーは、状態が大きいと時間とメモリを使います。空かどうかだけを、何度も調べる場合は、コピーの量を意識してください。

## まとめ

- 列を消費せずに空かどうかを知るには、状態の写しを使って一つだけ進めると安全である。
- 状態が表のような可変の値なら、コピーを挟まないと、元の列が壊れる。
- 判定の処理は、状態の大きさに応じて、コストを見積もっておく。
