## ひとことで

`head_call(state, ...)` は、列の先頭の値を取り出す処理の中で、列が空かどうかを確かめる関数です。状態が `nil` なら、列が空なので、`head: iterator is empty` というエラーを起こします。そうでなければ、残りの引数、つまり先頭の値を返します。

## コード

```lua:line-numbers=333
local head_call = function(state, ...)
    if state == nil then
        error("head: iterator is empty")
    end
    return ...
end
```

## 前提知識

- **可変長の戻り値 `...`**: 関数は、列の値をいくつでも返せます。`head_call` は、状態のあとに続く値を、そのまま返します。
- **状態による空の判定**: イテレータは、次の状態が `nil` になると、列が終わったことを示します。最初の呼び出しで `nil` が返れば、列は空です。
- **`error` の文字列**: エラーの内容を、人が読める文字列で伝えます。どの関数で起きたかが分かるように、関数名を含めています。
- **先頭だけを取る**: `head` は、列の先頭一つだけを必要とする関数です。残りの値は使いません。

## 何をしているか

### 1. 状態が nil なら、空として止める

最初の引数の状態が `nil` なら、列には値がありません。`error` で、空だというエラーを起こします。

```lua:line-numbers=334
    if state == nil then
        error("head: iterator is empty")
    end
```

### 2. 空でなければ、先頭の値を返す

状態が `nil` でないなら、状態のあとの値を、そのまま戻り値として返します。これが、列の先頭の値です。

```lua:line-numbers=337
    return ...
```

## ここがすごい

- **空の列を早く止める**: 値がないのに、それを使おうとして、おかしな結果になるのを防ぎます。
- **可変長で受けて、そのまま返す**: 値が一つでも複数でも、余計な変換なしに返せます。
- **分かりやすいエラー**: 関数名を含むメッセージなので、どの処理で空だったのかがすぐ分かります。
- **注意点**: 空の列でエラーにするため、呼ぶ前に空かどうかを確かめたい場合は、`is_null` を使う必要があります。

## まとめ

- 先頭の値を取る処理は、列が空のときの扱いを先に決めておくと安全である。
- 戻り値を可変長で受けると、余計な変換をせずに値をそのまま渡せる。
- エラーの文字列に関数名を入れると、どこで起きたかをすぐ追える。
