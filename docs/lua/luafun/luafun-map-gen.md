## ひとことで

`map_gen(tab, key)` は、表 `tab` の鍵と値を、一つずつ順に返すイテレータの関数です。返す値は三つあり、先頭の二つは同じ鍵、三つ目は値です。鍵を二つ返すのは、状態と、列の最初の値の両方に、鍵を使うためです。

## コード

```lua:line-numbers=104
local map_gen = function(tab, key)
    local key, value = pairs_gen(tab, key)
    return key, key, value
end
```

## 前提知識

- **`pairs_gen`**: `pairs` が内部で使う、鍵の次を返す関数です。ファイルの先頭で、`pairs({ a = 0 })` から取り出されています。
- **鍵を状態にする**: 表を回すとき、次に読む位置は前回の鍵で決まります。そのため、鍵そのものを状態として返します。
- **複数の戻り値**: 関数は、カンマで区切って複数の値を返せます。ここでは、鍵、鍵、値の三つを返しています。
- **列の値と状態の役割**: Lua Fun の列では、最初の戻り値が状態、残りが列の値として扱われます。

## 何をしているか

### 1. 次の鍵と値を取り出す

`pairs_gen(tab, key)` で、前回の鍵の次にある鍵と値を取り出します。表の中を、順に進む仕組みです。

```lua:line-numbers=105
    local key, value = pairs_gen(tab, key)
```

### 2. 鍵を状態に、鍵と値を列の値にする

戻り値は、鍵、鍵、値の順に並べられます。先頭の鍵が次の状態になり、残りの鍵と値が、列の値として使われます。

```lua:line-numbers=106
    return key, key, value
```

## ここがすごい

- **表を遅延で回せる**: 表の全体を先に配列に作らず、必要な分だけ鍵と値を取り出します。
- **状態と値の役割が明確**: 鍵を状態として返すので、次の位置を表す情報が、そのまま引き継がれます。
- **既存の仕組みを再利用**: `pairs` の鍵の順番と、同じ規則で回るので、表示の順番が予測しやすいです。
- **注意点**: 表を回している間に、鍵を追加したり削除したりすると、結果が不確かになります。回す間は、表の形を変えないでください。

## まとめ

- 表を列として扱うときは、次の鍵を状態にして返すと、途中から再開しやすい。
- 列の値と状態の役割を分けて考えると、三つ組の戻り値の意味が分かる。
- 回している最中に表を変えると、列の結果が不確かになるので避ける。
