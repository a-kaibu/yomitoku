## ひとことで

`lume.first(t, n)` は、表 `t` の先頭を取り出す関数です。`n` を省くと、先頭の値 1 つを返します。`n` を渡すと、先頭から `n` 個の要素を集めた新しい表を返します。同じ名前の関数で、「1 つ」と「いくつか」の両方を扱えるようにしています。

## コード

```lua:line-numbers=424
function lume.first(t, n)
  if not n then return t[1] end
  return lume.slice(t, 1, n)
end
```

## 前提知識

- **引数の省略と `nil`**: Lua では、渡されなかった引数は `nil` になります。`if not n then` で、省略されたかを確かめられます。
- **`t[1]`**: 配列の先頭は、添字 `1` で取り出せます。Lua の配列は 1 から数えます。
- **`lume.slice`**: 表の一部を、新しい表として切り出す lume の関数です。開始と終了の位置を指定します。
- **戻り値の型の違い**: 引数の有無で、値 1 つを返すか、表を返すかが変わります。呼ぶ側は、どちらを受け取るかを意識する必要があります。

## 何をしているか

### 1. 数が無ければ、先頭の値を返す

`n` が省略されたときは、`t[1]` をそのまま返します。

```lua:line-numbers=425
  if not n then return t[1] end
```

### 2. 数があれば、先頭から切り出す

`n` が渡されたときは、`lume.slice(t, 1, n)` で、1 番目から `n` 番目までを表にして返します。

```lua:line-numbers=426
  return lume.slice(t, 1, n)
```

## ここがすごい

- **1 つの名前で二つの使い方**: 「先頭の 1 つ」と「先頭のいくつか」を、同じ関数で扱えます。覚える名前が 1 つで済むので、呼び出しが読みやすくなります。
- **切り出しを再利用**: 複数の要素を返す処理は、`slice` に任せています。同じ処理を二重に書かずに済みます。
- **注意点**: 表が空のときは、`t[1]` が `nil` になります。また、`n` が表の長さより大きいと、`slice` の結果は表の終わりまでになります。

## まとめ

- 省略できる引数で、一つの関数に「1 つ」と「いくつか」の両方を持たせられる。
- 部分の取り出しは、既にある切り出しの関数に任せると、重複がない。
- 空の表と、大きすぎる数の場合を考えておくと、安心して使える。
