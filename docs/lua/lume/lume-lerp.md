## ひとことで

`lume.lerp(a, b, amount)` は、値 `a` と `b` の間にある値を、比率 `amount` で決める関数です。`amount` が `0` なら `a`、`1` なら `b`、`0.5` なら中間の値を返します。位置の移動や、色の変化などを、滑らかに表すときに使われます。

## コード

```lua:line-numbers=98
function lume.lerp(a, b, amount)
  return a + (b - a) * lume.clamp(amount, 0, 1)
end
```

## 前提知識

- **線形補間（linear interpolation）**: 二つの値の差に比率を掛け、最初の値に足す計算です。`a + (b - a) * t` と表されます。
- **比率の範囲**: `amount` を `0` から `1` の範囲に収めると、結果は必ず `a` と `b` の間に入ります。範囲の外の値は、ここでは収められます。
- **`lume.clamp`**: 値を最小値と最大値の間に収める lume の関数です。`lerp` は、この関数で比率を整えます。
- **差の計算**: `b - a` は、二つの値の隔たりです。その隔たりに比率を掛けると、どこまで進むかが決まります。

## 何をしているか

### 1. 比率を 0 から 1 に収める

`lume.clamp(amount, 0, 1)` で、比率を範囲に収めます。範囲外の比率を渡しても、結果が `a` と `b` の外に出ないようにします。

```lua:line-numbers=99
  return a + (b - a) * lume.clamp(amount, 0, 1)
```

### 2. 差に比率を掛けて、最初の値に足す

`b - a` を比率で掛けて、`a` に足します。`amount` が `0` なら `a`、`1` なら `b` になります。

```lua:line-numbers=99
  return a + (b - a) * lume.clamp(amount, 0, 1)
```

## ここがすごい

- **短くて意味が明確**: 補間の式が、一行にそのまま書かれています。数学の式を、そのままコードにした形です。
- **範囲外に強い**: 比率を先に収めるので、途中で値が飛び出しません。利用者の計算が多少ずれても、安全です。
- **汎用性が高い**: 数なら何にでも使えます。位置、色の成分、音量など、同じ式で扱えます。
- **注意点**: 比率を範囲外にしたいときには、この関数では収まってしまいます。外への延長が必要なら、別の式を使ってください。

## まとめ

- 二つの値の間を進める計算は、差に比率を掛けて最初の値に足すと表せる。
- 比率は範囲に収めると、結果が必ず二つの値の間に残る。
- 数学の式は、そのまま一行で書けることが多い。読みやすさを優先する。
