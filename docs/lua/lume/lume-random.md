## ひとことで

`lume.random(a, b)` は、範囲の中の小数の乱数を返す関数です。引数を省くと、`0` から `1` の間の値になります。一つだけ渡すと、`0` から `a` の間になります。二つ渡すと、`a` から `b` の間になります。範囲の指定を、引数の数で切り替える関数です。

## コード

```lua:line-numbers=133
function lume.random(a, b)
  if not a then a, b = 0, 1 end
  if not b then b = 0 end
  return a + math.random() * (b - a)
end
```

## 前提知識

- **`math.random()`**: 引数がないときは、`0` 以上 `1` 未満の小数を返す標準関数です。ここでは、その値に範囲の幅を掛けて使います。
- **省略時の既定値**: `a` が `nil` なら、範囲を `0` から `1` とみなします。`b` が `nil` のときは、`0` を上限として扱います。
- **線形の対応づけ**: 乱数の `0` から `1` の値を、`a` から `b` の範囲に移すには、`a + 乱数 * (b - a)` と計算します。
- **整数との違い**: `math.random(m, n)` は整数を返します。`lume.random` は、小数の値を返します。

## 何をしているか

### 1. 引数が省略されたら、既定の範囲にする

`a` がなければ、`a` を `0`、`b` を `1` にします。`a` だけあって `b` がなければ、`b` を `0` にします。このあとの計算で、範囲が決まるようにします。

```lua:line-numbers=134
  if not a then a, b = 0, 1 end
  if not b then b = 0 end
```

### 2. 範囲に移して返す

`math.random()` の小数を、範囲の幅 `b - a` に掛けて、`a` に足します。結果は、`a` と `b` の間の小数になります。

```lua:line-numbers=136
  return a + math.random() * (b - a)
```

## ここがすごい

- **引数の数で書き方が変わる**: 範囲なしの乱数、上限だけの乱数、範囲つきの乱数を、一つの関数で書けます。
- **式が短く、意味が明確**: 「範囲の幅を掛けて、下限を足す」という一般的な変換を、一行で表しています。
- **整数でない乱数が欲しいとき便利**: 色の成分や、移動の量など、小数を使う場面で、そのまま使えます。
- **注意点**: `a` と `b` の大きさが逆だと、`b - a` が負になり、結果は範囲の外ではなく、逆向きの範囲になります。順序は呼ぶ側で確かめてください。

## まとめ

- 乱数の範囲は、小さい値を掛けて下限を足す、という定番の変換で表せる。
- 引数の省略を既定値にすると、同じ関数で複数の使い方に対応できる。
- 範囲の順序など、前提の条件は、呼ぶ前に確かめておく。
