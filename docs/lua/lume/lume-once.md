## ひとことで

`lume.once(fn, ...)` は、関数 `fn` を「一度だけ動く版」に包み直す関数です。包まれた関数は、最初に呼ばれたときだけ `fn` を実行し、2 回目以降は何もせず戻ります。初期化の処理や、イベントの通知を 1 回だけにしたいときに使えます。

## コード

```lua:line-numbers=478
function lume.once(fn, ...)
  local f = lume.fn(fn, ...)
  local done = false
  return function(...)
    if done then return end
    done = true
    return f(...)
  end
end
```

## 前提知識

- **クロージャ**: 関数の中で作られた関数が、外側の変数（ここでは `done` と `f`）を覚えたまま使い続けられる仕組みです。
- **`lume.fn`**: 関数と、先に決めておく引数を組にして、残りの引数だけを受け取る関数を作る lume の関数です。ここでは `fn` と最初の引数を組にしています。
- **`done` フラグ**: 「済んだかどうか」を 1 つの真偽値で覚えておく書き方です。
- **`return`**: 関数を途中で終わらせる文です。値を返さずに終わると、`nil` が返ります。

## 何をしているか

### 1. 最初に、呼ぶ準備を整える

`lume.fn(fn, ...)` で、渡された引数を最初から組み込んだ関数 `f` を作ります。`done` は `false` で、まだ一度も動いていないことを表します。

```lua:line-numbers=479
  local f = lume.fn(fn, ...)
  local done = false
```

### 2. 2 回目以降は何もしない

包んだ関数は、最初に `done` を確かめます。すでに `true` なら、`return` で何もせずに戻ります。

```lua:line-numbers=482
    if done then return end
```

### 3. 最初の一回だけ `f` を動かす

まだ動いていなければ、`done` を `true` にしてから `f(...)` を呼び、その戻り値を返します。順番が「先に `done` を変える」なので、呼び出しの中でもう一度呼ばれても、二重には動きません。

```lua:line-numbers=483
    done = true
    return f(...)
```

## ここがすごい

- **状態は 1 つの変数だけ**: 「済んだか」を真偽値 1 つで覚えます。余計な表や仕組みは要りません。
- **変更の順番が安全**: `done` を先に `true` にしてから `f` を呼ぶので、`f` の中からもう一度呼ばれても、無限に入れ子になりません。
- **引数を先に組み込める**: `lume.fn` で最初の引数を固定しておけるので、包んだ後は、残りの引数を渡すだけで済みます。
- **注意点**: 一度だけの結果を覚えていないので、2 回目以降は `nil` が返ります。結果を毎回使いたい場合は、`lume.memoize` のように値を覚える仕組みが必要です。

## まとめ

- 一度だけ実行する仕組みは、「済んだか」の真偽値を 1 つ覚えておけば作れる。
- 状態を変える順番を、呼び出しの前にすると、再入しても二重に動かない。
- 値を覚えたいか、動作だけ 1 回にしたいかで、使う関数を選ぶ。
