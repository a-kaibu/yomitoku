## ひとことで

`lume.invert(t)` は、表 `t` のキーと値を入れ替えた新しい表を返す関数です。`{a = 1, b = 2}` は `{[1] = "a", [2] = "b"}` になります。値から元のキーを引きたいときに使えます。

## コード

```lua:line-numbers=436
function lume.invert(t)
  local rtn = {}
  for k, v in pairs(t) do rtn[v] = k end
  return rtn
end
```

## 前提知識

- **表のキー**: Lua の表は、文字列でも数字でも、`nil` 以外なら何でもキーにできます。
- **`pairs`**: 表のキーと値を順に回す標準関数です。順番は決まっていません。
- **逆引き**: 値からキーを探す仕組みです。通常の表は、キーから値を探すようになっています。

## 何をしているか

### 1. 新しい表を用意する

`rtn` は、入れ替えた結果を入れる空の表です。元の表 `t` は変えません。

### 2. 値をキーにして、キーを値に入れる

`pairs(t)` で、キー `k` と値 `v` を取り出します。`rtn[v] = k` で、値を新しいキーに、キーを新しい値にします。

```lua:line-numbers=438
  for k, v in pairs(t) do rtn[v] = k end
```

## ここがすごい

- **1 行で逆引きができる**: 入れ替えの処理がたった 1 行で書けます。Lua の表のキーを何でも使える性質を、そのまま利用しています。
- **元の表は変わらない**: 結果を新しい表に作るので、元の表を使い続けられます。
- **注意点**: 同じ値が複数のキーにあると、後から回ったキーだけが残ります。`pairs` の順番は決まっていないので、どちらが残るかは保証されません。値が重複しないと分かっている表に使ってください。

## まとめ

- キーと値の入れ替えは、`pairs` で回して反対の代入をすると 1 行で書ける。
- 値が重複すると情報が消えるので、一意性を確かめてから使う。
