## ひとことで

`lume.push(t, ...)` は、配列 `t` の末尾に、渡された値を全部足す関数です。足した値は、戻り値として返されます。そのため、`local a, b = lume.push(t, 1, 2)` のように、追加した値を受け取ることもできます。

## コード

```lua:line-numbers=165
function lume.push(t, ...)
  local n = select("#", ...)
  for i = 1, n do
    t[#t + 1] = select(i, ...)
  end
  return ...
end
```

## 前提知識

- **`#t + 1`**: 配列の末尾の次の位置です。`#t` は配列の長さです。
- **可変長引数**: `...` は、渡された値すべてを表します。`select` で個数や順番に取り出せます。
- **複数の戻り値**: `return ...` は、受け取った値をそのまま全部返します。

## 何をしているか

### 1. 渡された値の個数を数える

`select("#", ...)` で、渡された値の数を取ります。`nil` が含まれていても、この個数には数えられます。

```lua:line-numbers=166
  local n = select("#", ...)
```

### 2. 末尾に 1 つずつ足す

`t[#t + 1]` は、今の末尾の次の位置です。そこに `select(i, ...)` で取り出した値を入れます。これを、渡された数だけ繰り返します。

```lua:line-numbers=168
    t[#t + 1] = select(i, ...)
```

### 3. 足した値を返す

`return ...` で、渡された値をそのまま返します。呼び出し側は、追加した値を別の変数で受け取れます。


補足として、`push` は、追加したい値が複数あるときに、1 回の呼び出しでまとめて入れられる点が便利です。`table.insert` を何度も書く代わりに、値を並べて渡せます。戻り値を使えば、追加した値をそのまま変数に受け取れるので、関数の途中での使い方も簡単になります。


また、`push` は配列の末尾にしか足さないので、先頭に入れたいときには別の操作が必要です。その場合は `table.insert(t, 1, v)` を使います。末尾に足す処理を繰り返すだけなら、`push` が意図を短く表せます。

## ここがすごい

- **足した値をそのまま返す**: 追加と同時に値を使えるので、`local x = lume.push(t, makeItem())` のような書き方ができます。
- **`nil` を含む引数にも対応**: 個数を `select("#")` で数えているので、途中の `nil` も、その位置に入ります。
- **注意点**: `#t` は、穴のある配列では正しい末尾を示さないことがあります。穴のない配列に使ってください。

## まとめ

- 配列の末尾に値を足すときは、`#t + 1` の位置へ順に入れる。
- 追加した値を返すと、追加と利用を 1 つの式で書ける。
