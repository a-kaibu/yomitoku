## ひとことで

`lume.shuffle(t)` は、配列 `t` の要素をランダムに並べ替えた新しい配列を返す関数です。元の配列は変わりません。ゲームのカードを配ったり、選択肢の順番を変えたりするときに使えます。

## コード

```lua:line-numbers=213
function lume.shuffle(t)
  local rtn = {}
  for i = 1, #t do
    local r = math.random(i)
    if r ~= i then
      rtn[i] = rtn[r]
    end
    rtn[r] = t[i]
  end
  return rtn
end
```

## 前提知識

- **乱数**: `math.random(i)` は、1 から `i` までの整数を 1 つ返します。
- **偏りのない並べ替え**: どの並びも同じ確率で出るような並べ替えです。順番に決めるなら、各位置に入る値の確率を均等にする必要があります。
- **配列の複製**: 元の配列を変えずに、新しい配列を作る方法です。

## 何をしているか

### 1. 乱数で差し込む位置を選ぶ

`i` 番目の値を取るとき、`math.random(i)` で、`1` から `i` のどこに入れるかを決めます。先頭から `i` 個の中で、ランダムな位置を選ぶ形です。

```lua:line-numbers=216
    local r = math.random(i)
```

### 2. 押しのけて場所を空ける

選んだ位置 `r` が `i` と違うなら、`rtn[r]` の値を `rtn[i]` へ移します。これで、`r` の位置に新しい値を入れる場所ができます。

```lua:line-numbers=217
    if r ~= i then
      rtn[i] = rtn[r]
    end
```

### 3. 新しい値を入れる

最後に `t[i]` を `rtn[r]` に入れます。これで、`i` 番目の値が、ランダムな位置に入りました。

```lua:line-numbers=220
    rtn[r] = t[i]
```


補足として、`shuffle` の戻り値は新しい配列なので、ゲームの山札を作るときは、元の山札の並びを残したまま、配り順だけを取り出せます。複数回シャッフルしても、元の配列は毎回同じものから始まります。


さらに、乱数の並びを確かめたいときは、`math.randomseed` で同じ種を与えると、同じ並びが再現できます。テストで結果を固定したい場合に、この性質が役立ちます。

## ここがすごい

- **1 回だけ回る**: 配列を 1 回走るだけで、ランダムな並べ替えが終わります。何回も入れ替えを繰り返す方法より、速く済みます。
- **偏りが出にくい**: 各要素を、それまでの並びの中の一様な位置へ入れるので、どの並びも同じ確率で出ます。
- **元を変えない**: 新しい配列 `rtn` に作るので、元の配列は並んだままです。
- **注意点**: `math.random` の種を設定していないと、毎回同じ並びになることがあります。Lua 5.1 では、起動時に `math.randomseed` で種を決めてください。

## まとめ

- 配列を 1 回だけ回して、ランダムな位置へ差し込んでいくと、偏りのない並べ替えになる。
- 元の配列を変えずに、新しい配列へ結果を作る。
