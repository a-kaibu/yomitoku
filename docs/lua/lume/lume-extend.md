## ひとことで

`lume.extend(t, ...)` は、最初の表 `t` に、後ろに渡された表のキーと値を写し込む関数です。同じキーがあれば、後のものが勝って上書きされます。設定の初期値に、利用者の設定を重ねるような場面でよく使われます。

## コード

```lua:line-numbers=200
function lume.extend(t, ...)
  for i = 1, select("#", ...) do
    local x = select(i, ...)
    if x then
      for k, v in pairs(x) do
        t[k] = v
      end
    end
  end
  return t
end
```

## 前提知識

- **`select("#", ...)`**: 可変長引数の個数を返す標準関数です。
- **`if x then`**: `nil` や `false` の表を飛ばすための確認です。
- **`pairs`**: 表のキーと値を順に回す標準関数です。
- **同じキーの上書き**: Lua の表への代入は、同じキーがあれば古い値を消して新しい値にします。

## 何をしているか

### 1. 渡された表を 1 つずつ見る

`select(i, ...)` で、後ろに渡された表を先頭から順に取り出します。`nil` なら、そこは飛ばします。

```lua:line-numbers=202
    local x = select(i, ...)
```

### 2. キーと値を写す

`pairs(x)` で表の中身を回り、`t[k] = v` で `t` に写します。同じキーがあれば、その値は後から来たもので上書きされます。

```lua:line-numbers=205
        t[k] = v
```

### 3. 最初の表を返す

戻り値は、写し込まれた最初の表 `t` です。新しい表は作らないので、元の表そのものが更新されます。


補足として、`extend` は「設定の重ね合わせ」によく使われます。たとえば、既定の設定の表に、利用者が指定した表を後ろから重ねると、指定された項目だけが上書きされ、残りは既定のまま残ります。この使い方では、後ろに渡す表ほど強い、という約束を覚えておくと読みやすくなります。

## ここがすごい

- **重ね合わせが自然に書ける**: 後から渡す表ほど優先されるので、初期値と利用者の設定を並べるだけで、設定の上書きが表せます。
- **`nil` を気にしなくてよい**: 途中に `nil` が入っても、`if x` で飛ばすので、エラーになりません。
- **注意点**: 最初の表 `t` そのものが変わります。元の値を残したいときは、先に `lume.clone` で複製してから渡してください。

## まとめ

- 複数の表を重ねるには、後ろほど優先する形で写し込むと、設定の上書きが簡単に書ける。
- `nil` の引数を飛ばすようにしておくと、呼ぶ側の条件分岐が減る。
- 元の表を変えたくないときは、先に複製する。
