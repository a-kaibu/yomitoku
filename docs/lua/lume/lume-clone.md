## ひとことで

`lume.clone(t)` は、表 `t` の 1 段目だけを写した新しい表を返す関数です。新しい表のキーや値を変えても、元の表は変わりません。ただし、値が入れ子の表だと、その中身は元と同じものを指したままです。

## コード

```lua:line-numbers=461
function lume.clone(t)
  local rtn = {}
  for k, v in pairs(t) do rtn[k] = v end
  return rtn
end
```

## 前提知識

- **浅いコピー（shallow copy）**: 表の最初の段だけを新しく作るコピーです。入れ子の中身は共有されます。
- **深いコピー（deep copy）**: 入れ子の表まで、すべて新しく作るコピーです。前の記事の LuaRocks の `deep_copy` がそれにあたります。
- **`pairs`**: 表のキーと値を順に回す標準関数です。

## 何をしているか

### 1. 新しい表に、キーと値を 1 つずつ写す

`pairs(t)` で、1 段目の項目を取り出して、`rtn` に入れます。値がテーブルでも、そのテーブルの参照だけが入ります。

```lua:line-numbers=463
  for k, v in pairs(t) do rtn[k] = v end
```

ここで大事なのは、値を「コピーする」のではなく「そのまま渡す」ことです。数字や文字列は、もともと値そのものなので、代入すれば独立した値になります。一方、表は「表への参照」なので、代入されるのは同じ表への入口です。そのため、`rtn` と `t` の両方から同じ入れ子の表が見えます。

使い方の例で考えると分かりやすいです。`local a = lume.clone({x = 1, list = {1, 2}})` のあとに `a.x = 9` としても、元の表の `x` は `1` のままです。しかし `a.list[1] = 9` とすると、元の表の `list` も同じ中身が変わります。同じ表を、2 か所から見ているからです。

## ここがすごい

- **短くて速い**: 1 段だけ写すので、再帰が要らず、処理がとても単純です。
- **多くの場合に十分**: 値が数字や文字列だけの表なら、浅いコピーで独立した表になります。
- **注意点**: 入れ子の表を変えると、元の表にも影響が出ます。入れ子を含む表を独立させたい場合は、深いコピーを使ってください。

## まとめ

- 値が単純な表なら、1 段だけ写す浅いコピーで十分。
- 入れ子の表は共有されるので、必要なら深いコピーを選ぶ。
