## ひとことで

`lume.map(t, fn)` は、表 `t` の各値に関数 `fn` を適用して、その結果を新しい表に集めて返す関数です。キーは元の表と同じに保たれます。値を一つずつ変換する処理を、ループを書かずに表すための基本の関数です。

## コード

```lua:line-numbers=259
function lume.map(t, fn)
  fn = iteratee(fn)
  local iter = getiter(t)
  local rtn = {}
  for k, v in iter(t) do rtn[k] = fn(v) end
  return rtn
end
```

## 前提知識

- **`map`（写像）**: 配列の要素を一つずつ変換して、新しい配列を作る操作です。関数型プログラミングの基本の一つです。
- **`iteratee`**: 変換の指定を、関数の形に整える lume の関数です。関数だけでなく、キーや値の指定も受け付けます。
- **キーの保存**: 結果の表は、元の表と同じキーを持ちます。配列なら番号の並びが、連想配列ならキーの名前が、そのまま残ります。
- **元の表を変えない**: 結果は新しい表なので、元の表はそのまま残ります。

## 何をしているか

### 1. 変換の指定と、回す方法を用意する

`fn` を `iteratee` で関数の形に整えます。`getiter` で、表を回すための関数を取り出します。結果の表 `rtn` は空で用意します。

```lua:line-numbers=260
  fn = iteratee(fn)
  local iter = getiter(t)
  local rtn = {}
```

### 2. 各値を変換して、同じキーに入れる

表を回して、キーと値の組を一つずつ受け取ります。`rtn[k] = fn(v)` で、変換した値を同じキーに入れます。

```lua:line-numbers=263
  for k, v in iter(t) do rtn[k] = fn(v) end
```

### 3. 結果を返す

すべての値を変換し終えたら、`rtn` を返します。元の表とは別の表なので、どちらも独立して使えます。

```lua:line-numbers=264
  return rtn
```

## ここがすごい

- **キーを崩さない**: 変換しても、キーは同じ位置に残ります。連想配列の名前付きの値も、対応が保たれます。
- **一行で変換を書く**: ループの中身は一行だけです。変換の意図が、そのまま読み取れます。
- **変換の指定が柔軟**: `iteratee` を通すので、関数を渡すほか、キーの名前などの指定も使えます。
- **注意点**: 変換の結果が `nil` になると、その位置は表から消えたように見えます。配列の途中で `nil` が入ると、後の番号の扱いが変わるので注意してください。

## まとめ

- 値を一つずつ変換する処理は、キーを保ったまま新しい表を作ると、元の表を壊さずに済む。
- 変換の結果が `nil` になる場合は、表の形が変わることを意識する。
- 指定の形を一か所で整えると、関数を渡すのも指定するのも、同じように書ける。
