## ひとことで

`lume.angle(x1, y1, x2, y2)` は、点 `(x1, y1)` から点 `(x2, y2)` に向かう線が、x 軸の正の向きとなす角度を返す関数です。角度はラジアンで返します。`atan2` を使うので、どの象限にある点どうしでも、正しい向きが得られます。

## コード

```lua:line-numbers=123
function lume.angle(x1, y1, x2, y2)
  return math_atan2(y2 - y1, x2 - x1)
end
```

## 前提知識

- **`atan2(y, x)`**: 座標 `(x, y)` の方向を、角度で返す関数です。`atan` と違い、`x` と `y` の符号を見て、四つの象限を区別できます。
- **差のベクトル**: `x2 - x1` と `y2 - y1` は、一つの点から別の点へ向かうベクトルの成分です。その向きが、そのまま角度になります。
- **ラジアン**: 角度を、円周の比で表す単位です。一周は `2π` ラジアンです。
- **`lume.vector` との対**: `lume.vector` は角度から成分を作ります。`lume.angle` は、成分の向きから角度を求めます。二つは逆の関係です。

## 何をしているか

### 1. 二点の差から向きを求める

`y2 - y1` と `x2 - x1` を `math_atan2` に渡します。これは、点 `(x1, y1)` から `(x2, y2)` への向きを表します。

```lua:line-numbers=124
  return math_atan2(y2 - y1, x2 - x1)
```

## ここがすごい

- **象限を正しく扱う**: `atan2` は、`x` と `y` の符号を両方見るので、どの方向に進んでいても、正しい角度になります。
- **一行で完結**: 差を取って、向きを求めるまでが、一つの式にまとまっています。読んで意味がすぐ分かります。
- **`vector` の逆として使える**: 角度を求めたあと、`lume.vector` で成分に戻せます。向きの計算を、往復させられます。
- **注意点**: 二つの点が同じ位置だと、向きは決まりません。`atan2(0, 0)` は、実装によって `0` になりますが、向きとしての意味はありません。

## まとめ

- 向きを求めるには、差のベクトルを `atan2` に渡すと、四つの象限すべてで正しく計算できる。
- 角度と成分の変換を対にして使うと、向きの計算を行き来できる。
- 同じ点どうしの向きは定まらないので、その場合の扱いを決めておく。
