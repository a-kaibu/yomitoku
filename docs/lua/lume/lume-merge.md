## ひとことで

`lume.merge(...)` は、渡された複数の表を一つにまとめた、新しい表を返す関数です。キーと値の組をそのまま集めます。同じキーが複数の表にあるときは、後に渡された表の値で上書きされます。設定の初期値に、利用者の設定を重ねるような場面で役立ちます。

## コード

```lua:line-numbers=348
function lume.merge(...)
  local rtn = {}
  for i = 1, select("#", ...) do
    local t = select(i, ...)
    local iter = getiter(t)
    for k, v in iter(t) do
      rtn[k] = v
    end
  end
  return rtn
end
```

## 前提知識

- **可変長引数 `...`**: 関数に、いくつでも引数を渡せる書き方です。`select("#", ...)` で数を、`select(i, ...)` で `i` 番目の値を取り出せます。
- **キーによる上書き**: 表に同じキーで代入すると、古い値は新しい値に置き換わります。`rtn[k] = v` は、その仕組みを使っています。
- **`pairs` と `getiter`**: 表のキーと値を順に回す方法です。`getiter` は、表の種類に応じて回し方を選ぶ lume の仕組みです。
- **浅い結合**: 値に入れ子の表があった場合、その中身は作り直されず、参照のまま共有されます。

## 何をしているか

### 1. 結果の表を用意し、引数を順に取り出す

空の表 `rtn` を作ります。`select("#", ...)` で引数の数を決め、`select(i, ...)` で `i` 番目の表を取り出します。

```lua:line-numbers=349
  local rtn = {}
  for i = 1, select("#", ...) do
    local t = select(i, ...)
```

### 2. 各表のキーと値を、結果へ書き込む

取り出した表を回して、キーと値の組を一つずつ `rtn[k] = v` で書き込みます。同じキーがあれば、ここで上書きが起きます。

```lua:line-numbers=352
    local iter = getiter(t)
    for k, v in iter(t) do
      rtn[k] = v
    end
```

### 3. 最後の結果を返す

すべての表を回し終わったら、`rtn` を返します。渡された表は、どれも変わりません。

```lua:line-numbers=357
  return rtn
```

## ここがすごい

- **後勝ちで重ねられる**: 引数の並びが、そのまま優先順位になります。「基本の設定、利用者の設定」の順に渡せば、利用者の設定が勝ちます。
- **引数の数に制限がない**: 可変長引数なので、二つでも十個でも、同じ書き方で重ねられます。
- **元の表を変えない**: 結果は新しい表なので、渡された表を他の処理で使い続けられます。
- **注意点**: 入れ子の表は共有されるので、結果の中身を書き換えると、元の表にも影響が出ます。深く重ねたいときは、別の仕組みが必要です。

## まとめ

- 複数の表を重ねるときは、後に渡すものを優先する、という約束を決めておくと分かりやすい。
- 可変長引数で受けると、重ねる表の数を自由に変えられる。
- 入れ子の値は共有されるので、書き換えが必要なら深いコピーを考える。
