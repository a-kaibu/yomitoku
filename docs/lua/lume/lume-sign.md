## ひとことで

`lume.sign(x)` は、数 `x` の符号を返す関数です。`x` が負なら `-1`、そうでなければ `1` を返します。`0` は `1` の側に入るのが、この関数の決まりです。向きを反転させる掛け算などで、符号だけを取り出すときに使えます。

## コード

```lua:line-numbers=93
function lume.sign(x)
  return x < 0 and -1 or 1
end
```

## 前提知識

- **符号（sign）**: 数の正負を表す記号です。正なら `+1`、負なら `-1` として扱われます。
- **`and` と `or` の式**: `x < 0 and -1 or 1` は、`x` が負なら `-1`、それ以外なら `1` を返す書き方です。`-1` は真の値なので、この書き方が安全に使えます。
- **`0` の扱い**: 数学の符号関数では、`0` の符号を `0` とすることがあります。この関数では、`0` は `1` と同じ側に入ります。
- **向きの掛け算**: 速度などに符号を掛けると、向きを反転させられます。符号は、その掛け算の係数として使われます。

## 何をしているか

### 1. 負かどうかを確かめる

`x < 0` が真かどうかを調べます。負の数なら、式の結果は `-1` になります。

```lua:line-numbers=94
  return x < 0 and -1 or 1
```

### 2. 負でなければ 1 を返す

`x < 0` が偽なら、`or` の後ろの `1` が返ります。`0` もここに入るので、正と零は同じ結果になります。

```lua:line-numbers=94
  return x < 0 and -1 or 1
```

## ここがすごい

- **一行で完結**: 符号の判定と返す値が、一つの式にまとまっています。読んで、すぐ意味が分かります。
- **安全な `and or`**: 真になる値が `-1` なので、`and` と `or` の罠に当たりません。
- **掛け算で向きを変えられる**: 符号を取り出せると、速度や移動量の向きを、掛け算だけで扱えます。
- **注意点**: `0` を符号 `0` として扱いたい場合には、この関数では足りません。`0` の判定を別に書いてください。

## まとめ

- 符号だけを取り出すときは、負かどうかの判定を一行で書けば十分である。
- `and` と `or` の式は、真の値に `false` や `nil` を含まない形で使うと安全である。
- `0` の扱いは関数ごとに違うので、目的に合った定義を選ぶ。
