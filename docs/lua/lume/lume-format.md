## ひとことで

`lume.format(str, vars)` は、文字列の中の `{名前}` や `{番号}` を、テーブル `vars` の値で置き換える関数です。`lume.format("{a} + {b}", {a = 1, b = 2})` は `"1 + 2"` になります。Lua の標準の `string.format` とは違い、書式の番号ではなく、名前や番号で値を指定できます。

## コード

```lua:line-numbers=650
function lume.format(str, vars)
  if not vars then return str end
  local f = function(x)
    return tostring(vars[x] or vars[tonumber(x)] or "{" .. x .. "}")
  end
  return (str:gsub("{(.-)}", f))
end
```

## 前提知識

- **`gsub` と関数の置き換え**: `str:gsub(パターン, 関数)` は、一致した部分を関数の戻り値に置き換えます。関数には、キャプチャされた文字列が渡されます。
- **`tonumber`**: 文字列を数字に変換します。`"1"` は `1` になり、`"name"` は `nil` になります。
- **`or` の連鎖**: 左から順に値を試し、最初に `nil` でも `false` でもないものを使います。すべてダメなら最後の値が使われます。
- **`tostring`**: 値を文字列に変換します。数字をそのまま連結できるようにするために使われます。

## 何をしているか

### 1. `{ }` の中の文字を取り出して置き換える関数

`{(.-)}` は、`{` から最短で `}` までの中身を取り出すパターンです。取り出した中身が `x` として関数 `f` に渡されます。

```lua:line-numbers=652
  local f = function(x)
```

### 2. 名前か番号で値を探す

`vars[x]` で名前を探します。見つからなければ、`tonumber(x)` で数字に変えて `vars[番号]` を探します。`{1}` のように書いた場合、文字列の `"1"` は数字の `1` として扱われ、配列の 1 番目が使われます。

```lua:line-numbers=653
    return tostring(vars[x] or vars[tonumber(x)] or "{" .. x .. "}")
```

### 3. 見つからなければ元の書き方を残す

どちらでも見つからなければ、`"{" .. x .. "}"` が返されます。つまり、値がない `{name}` は、そのまま文字として残ります。書き忘れに気づきやすい動きです。

### 4. 置き換えた結果を返す

`gsub` は、置き換えた個数も返します。外側の `(...)` で囲んで、文字列だけを返すようにしています。

```lua:line-numbers=655
  return (str:gsub("{(.-)}", f))
```

## ここがすごい

- **名前と番号を同じ仕組みで扱える**: `vars[x]` と `vars[tonumber(x)]` の 2 段の `or` で、名前でも番号でも同じ書き方で値が取れます。分岐を書かずに済みます。
- **見つからないものを壊さない**: 値がないときに空文字にせず、元の `{…}` を残すので、テンプレートの書き漏れが見つかりやすくなります。
- **`(.-)` で必要最小限だけ**: 最短一致にすることで、`{a} and {b}` の 2 つが別々に置き換わります。`.*` だと、最初の `{` から最後の `}` まで 1 つにまとまってしまいます。
- **注意点**: 値が `false` のときは、`or` の次に進んでしまいます。`vars` に `false` を入れたい場合は、この動きに注意が要ります。

## まとめ

- 文字列の中の印を値で置き換えるには、`gsub` に関数を渡すと分岐を簡潔に書ける。
- 名前と番号は、`or` の連鎖で 1 行にまとめられる。
- 最短一致 `.-` を使うと、複数の差し込み位置を別々に扱える。
