## ひとことで

`lume.unique(t)` は、表 `t` の値から重複を取り除いた、新しい配列を返す関数です。値を一度キーにしてしまうと、同じ値は一つのキーにまとまる、という Lua の表の性質を使っています。並び順は保証されませんが、重複のない一覧を素早く作れます。

## コード

```lua:line-numbers=305
function lume.unique(t)
  local rtn = {}
  for k in pairs(lume.invert(t)) do
    rtn[#rtn + 1] = k
  end
  return rtn
end
```

## 前提知識

- **表のキーは一意**: 同じキーで代入すると、後の値で上書きされます。つまり、同じ値を複数のキーに入れると、キーは 1 つずつ別々に残ります。ここでは逆に、値をキーにします。
- **`lume.invert`**: 表のキーと値を入れ替える lume の関数です。値が重なると、一つのキーにまとまります。
- **`pairs`**: 表のキーを順に回す標準関数です。その順番は、言語の仕様では決まっていません。
- **`rtn[#rtn + 1]`**: 配列の末尾に 1 つ足す書き方です。

## 何をしているか

### 1. 値をキーにして、重複を消す

`lume.invert(t)` は、値をキーとする表を作ります。同じ値は、この表の中で一つのキーにまとまります。つまり、重複はここで自然に消えます。

```lua:line-numbers=307
  for k in pairs(lume.invert(t)) do
```

### 2. キーを一覧にして返す

重複のないキーを、`rtn` の末尾に順に足していきます。キーは、もとの値そのものなので、結果は重複のない配列になります。

```lua:line-numbers=306
  local rtn = {}
  for k in pairs(lume.invert(t)) do
    rtn[#rtn + 1] = k
  end
  return rtn
```

## ここがすごい

- **重複を探す処理がない**: 同じ値が来たかを、一つずつ比べる必要がありません。表のキーが、その役目を果たします。
- **短くて速い**: 配列を二重に回すような比較が要らないので、要素が多いときにも効率が良いです。
- **元の表を変えない**: 結果は新しい配列です。もとの表は、そのまま残ります。
- **注意点**: 結果の順番は、`pairs` の順番に従うので、元の並びは保たれません。順番が必要なら、結果を並べ直してください。また、キーに使えない値（`nil` や `NaN`）は扱えません。

## まとめ

- 重複を消すときは、値をキーにすると、比較の処理を省ける。
- 重複のない結果の順番は、保証されないと考えて使う。
- キーにできない値があると、この方法は使えないので、確かめておく。
