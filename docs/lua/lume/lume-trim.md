## ひとことで

`lume.trim(str, chars)` は、文字列の前後にある余分な文字を取り除く関数です。省略すると空白を取り除きます。Lua には、この目的の標準関数がありません。この関数は、パターン 1 つで前後と中身を同時に書き分けることで、短く実現しています。

## コード

```lua:line-numbers=611
function lume.trim(str, chars)
  if not chars then return str:match("^[%s]*(.-)[%s]*$") end
  chars = patternescape(chars)
  return str:match("^[" .. chars .. "]*(.-)[" .. chars .. "]*$")
end
```

## 前提知識

- **`match`**: パターンに一致した部分を返す関数です。`()` で囲んだ部分だけを、戻り値として取り出せます。
- **`^` と `$`**: `^` は文字列の先頭、`$` は末尾に一致するパターンです。両方を付けると、文字列全体を対象にできます。
- **`*`（0 回以上の繰り返し）**: 直前の文字や文字の集合が 0 回以上続くことを表します。`[%s]*` は、空白が何個続いてもよいという意味です。
- **`.-`（最短一致）**: 任意の文字を、できるだけ短く一致させる書き方です。`*` が「できるだけ長く」なのに対して、`-` は「できるだけ短く」です。

## 何をしているか

### 1. 指定がなければ空白を落とす

`chars` が省略されたときは、`[%s]*` で前の空白を、`[%s]*$` で後ろの空白を取り除きます。その間の `(.-)` が、残したい中身です。

```lua:line-numbers=612
  if not chars then return str:match("^[%s]*(.-)[%s]*$") end
```

`"  hello  "` に対して、前の `  ` が `[%s]*` で一致し、中身の `hello` が `(.-)` に入り、後ろの `  ` が `[%s]*$` で一致します。

### 2. 指定された文字を安全なパターンにする

`chars` が指定されたときは、まず `patternescape` で特殊文字を `%` でエスケープします。`chars` の `]` や `-` が、集合の中で別の意味を持たないようにするためです。

```lua:line-numbers=613
  chars = patternescape(chars)
```

### 3. 文字の集合を前後に当てはめる

`"[" .. chars .. "]*"` は、「指定された文字だけの並び」を表すパターンです。これを先頭と末尾に当てはめ、中身を `(.-)` で取り出します。

```lua:line-numbers=614
  return str:match("^[" .. chars .. "]*(.-)[" .. chars .. "]*$")
```

## ここがすごい

- **1 行の中で前後と中身を同時に表す**: 削る処理と取り出す処理を、1 つのパターンに入れています。途中で文字列を切り貼りする必要がありません。
- **最短一致 `.-` が要**: 中身を `.*` で取ると、後ろの空白まで中身に含まれてしまいます。`.-` にすることで、末尾の `[%s]*$` が後ろの空白を確実に吸い取ります。
- **集合の指定を文字列連結で組み立てる**: `chars` を外から受け取り、同じ形のパターンに差し込む方法です。`patternescape` と組み合わせれば、どんな文字でも安全に指定できます。
- **注意点**: 中身が空の文字列（すべて空白）のときは、空の文字列が返ります。これは期待通りですが、`nil` を期待する場合は別に判定が要ります。

## まとめ

- 前後の余分な文字を消すときは、先頭と末尾の繰り返しを 1 つのパターンで書ける。
- 中身を取り出すには、`.*` ではなく最短一致 `.-` を使うと、末尾の削除と両立する。
- 外から受け取った文字の集合は、パターンに差し込む前にエスケープする。
