## ひとことで

`lume.split(str, sep)` は、文字列を区切り文字 `sep` で分けて、配列にして返す関数です。`lume.split("a,b,c", ",")` は `{"a", "b", "c"}` になります。区切りを省略すると、空白で区切られた単語を取り出します。Lua には標準の分割関数がないため、パターンの仕組みを使って作られています。

## コード

```lua:line-numbers=600
function lume.split(str, sep)
  if not sep then
    return lume.array(str:gmatch("([%S]+)"))
  else
    assert(sep ~= "", "empty separator")
    local psep = patternescape(sep)
    return lume.array((str..sep):gmatch("(.-)("..psep..")"))
  end
end
```

区切り文字を正規表現の意味から守るための `patternescape` も、読むのに必要なので引用します。

```lua:line-numbers=43
local patternescape = function(str)
  return str:gsub("[%(%)%.%%%+%-%*%?%[%]%^%$]", "%%%1")
end
```

## 前提知識

- **`gmatch`**: パターンに一致する部分を、先頭から順に取り出すイテレータを返します。`for` 文と組み合わせて使うことが多いです。
- **キャプチャ `( ... )`**: パターンの中で `(` と `)` で囲んだ部分は、一致した文字列の中から取り出せる値になります。
- **パターンの特殊文字**: `.`、`%`、`+`、`-` などは、パターンの中で特別な意味を持ちます。区切り文字がこれらを含むと、そのままでは正しく一致しません。
- **`lume.array`**: 渡された値を、配列として集めるための関数です。`gmatch` が返す複数の値を 1 つの配列にまとめます。

## 何をしているか

### 1. 区切りがなければ空白で分ける

`sep` が省略されたときは、`[%S]+` で「空白でない文字の並び」を単語として取り出します。連続する空白は、ひとまとめに無視されます。

```lua:line-numbers=602
    return lume.array(str:gmatch("([%S]+)"))
```

### 2. 区切り文字をパターンの意味から守る

`patternescape(sep)` は、`.` や `+` などの特殊文字の前に `%` を付けます。たとえば区切りが `.` のとき、そのまま使うとどんな文字にも一致してしまいます。`%.` にすると、ただの `.` として一致します。

```lua:line-numbers=605
    local psep = patternescape(sep)
```

### 3. 末尾に区切りを足してから読む

ここが最大の工夫です。`(str..sep)` と、末尾に区切りを付け足してから `gmatch` にかけます。`"(.-)("..psep..")"` は、「区切りの前までを最短で取り、その後ろに区切りがある」という形のパターンです。

```lua:line-numbers=606
    return lume.array((str..sep):gmatch("(.-)("..psep..")"))
```

`"a,b"` は `"a,b,"` になり、「`a` と `,`」「`b` と `,`」の 2 組として読まれます。区切りの部分は `(...)` の 2 つ目に入るだけで、結果には使われません。最後の `b` にも区切りが付いているので、特別な処理なしで取り出せます。

## ここがすごい

- **最後の欄の特別扱いが要らない**: 普通に読むと、最後の欄は区切りがないため、取り出すための特別な処理が必要です。末尾に番兵として区切りを足すだけで、どの欄も同じ形で読めます。
- **空の欄も正しく扱える**: `"a,,b"` は `a`、空文字、`b` の 3 つになります。`(.-)` は 0 文字でも一致するので、空欄も取り出せます。
- **特殊文字を安全に扱う**: `patternescape` を通すことで、`.` や `|` のような記号を区切りに使えます。パターンの仕組みを正しく理解していないと、この問題は見落としやすいです。
- **注意点**: 区切りが長い文字列のとき、`(.-)` の最短一致が思った通りに働くかは、区切りの中身によります。複雑な区切りでは、自分で確かめることが大切です。

## まとめ

- 最後の欄が区切りで閉じていないときは、末尾に区切りを足してから読むと、同じ形で取り出せる。
- パターンで区切り文字を使うときは、特殊文字を `%` でエスケープする。
- 空白の区切りと文字列の区切りを分けて書くと、用途に合った動きが選べる。
