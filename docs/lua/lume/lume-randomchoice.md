## ひとことで

`lume.randomchoice(t)` は、配列 `t` の要素から、どれか一つを無作為に選んで返す関数です。ゲームでのランダムなイベントや、一覧からのおすすめの一つを選ぶときに使えます。

## コード

```lua:line-numbers=140
function lume.randomchoice(t)
  return t[math.random(#t)]
end
```

## 前提知識

- **`math.random(n)`**: `1` から `n` までの整数を、無作為に返す標準関数です。ここでは、配列の番号の範囲を指定しています。
- **`#t`**: 配列の長さを返す演算子です。要素の数と同じになるので、乱数の上限にそのまま使えます。
- **乱数の種（seed）**: 乱数の並びの出発点です。`math.randomseed` で決めないと、毎回同じ並びになることがあります。
- **空の配列**: 要素がない配列では、`#t` が `0` になり、選ぶ番号がありません。この関数はその場合を特別に扱っていません。

## 何をしているか

### 1. 番号を無作為に一つ決める

`math.random(#t)` は、`1` から配列の長さまでの整数を一つ返します。この数が、選ばれる要素の番号になります。

```lua:line-numbers=141
  return t[math.random(#t)]
```

### 2. その番号の要素を返す

`t[番号]` で要素を取り出して、そのまま返します。呼ぶ側は、選ばれた値を受け取ります。

## ここがすごい

- **一行で完結**: 乱数の範囲と、要素の取り出しを、一つの式で書いています。覚えることが少なく、読んで理解しやすいです。
- **番号と範囲が一致**: 乱数の上限を `#t` にしているので、範囲外の番号が選ばれることがありません。
- **値を返すだけ**: 元の配列は変えません。選んだ要素を取り除きたい場合は、別の処理が必要です。
- **注意点**: 空の配列では、`t[0]` のような存在しない要素を返すので、呼ぶ前に長さを確かめてください。また、`math.random` の乱数の種を設定しないと、毎回同じ結果になることがあります。

## まとめ

- 無作為に一つ選ぶときは、乱数の上限を配列の長さにすると、範囲を間違えずに済む。
- 空の配列を渡さないように、呼ぶ前に確かめておく。
- 乱数の種を決めておくと、実行ごとに違う結果が得られる。
