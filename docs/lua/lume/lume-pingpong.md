## ひとことで

`lume.pingpong(x)` は、増え続ける値 `x` を、`0` から `1` の間を行き来する値に変える関数です。`x` が `0` から `1` まで増えると、値も `0` から `1` へ増えます。その後 `1` から `2` へ進むと、値は `1` から `0` へ戻ります。往復する動きを、一つの式で表すための関数です。

## コード

```lua:line-numbers=110
function lume.pingpong(x)
  return 1 - math_abs(1 - x % 2)
end
```

## 前提知識

- **剰余 `x % 2`**: `x` を `2` で割った余りです。`x` が `0` から `2` の範囲で、周期的に `0` から `2` へ進む値になります。
- **`math_abs`**: 絶対値を求める関数です。ここでは、`1 - x % 2` の大きさを取ります。
- **三角波**: 値が直線的に上がり、下がり、また上がるような、往復する波形のことです。この関数は、その形を作ります。
- **周期 2**: `x` が `2` 増えるたびに、値は元の位置に戻ります。往復が一回りする長さが、`2` です。

## 何をしているか

### 1. 周期 2 の中での位置を求める

`x % 2` で、`x` の周期の中での位置を求めます。`0` から `2` の範囲の値になります。

### 2. 中心からの距離を取り、反転させる

`1 - x % 2` は、位置と `1` の差を表します。その絶対値 `math_abs` を取り、`1` から引くと、`0` から `1` を行き来する値になります。

```lua:line-numbers=111
  return 1 - math_abs(1 - x % 2)
```

## ここがすごい

- **一つの式で往復を表す**: 増えていく時間を、そのまま入力にすれば、往復する動きが得られます。状態を持つ必要がありません。
- **端で折り返す**: 値が `0` と `1` で向きを変えるので、跳ね返るような自然な往復になります。
- **周期が明確**: 周期が `2` であることが、式から読み取れます。動きの長さを、見積もりやすいです。
- **注意点**: 負の値を渡すと、`%` の結果が正の範囲に戻るので、往復の位相がずれることがあります。入力は、増える値を使うのが基本です。

## まとめ

- 往復する動きは、剰余と絶対値を組み合わせると、一つの式で表せる。
- 周期の長さを式から読み取ると、動きの速さを調整しやすい。
- 増え続ける時間を入力にすれば、状態を持たずに往復を作れる。
