## ひとことで

`lume.smooth(a, b, amount)` は、値 `a` と `b` の間を、ゆるやかに補間する関数です。比率 `amount` を、そのまま使うのではなく、三次式で曲げてから使います。その結果、始めと終わりの動きが穏やかになり、直線よりも自然に見えます。

## コード

```lua:line-numbers=103
function lume.smooth(a, b, amount)
  local t = lume.clamp(amount, 0, 1)
  local m = t * t * (3 - 2 * t)
  return a + (b - a) * m
end
```

## 前提知識

- **線形補間**: `a + (b - a) * 比率` で、二つの値の間を比率で進める計算です。比率がそのまま進み具合になります。
- **三次式による曲げ**: `t * t * (3 - 2 * t)` は、`0` から `1` の範囲で、始めと終わりの傾きが `0` になる形です。値の変化が、両端で緩やかになります。
- **`lume.clamp`**: 値を範囲に収める関数です。比率を `0` から `1` に収めるために使います。
- **比率の意味**: `amount` が `0` なら `a`、`1` なら `b` を返します。途中の値は、曲げられた比率で決まります。

## 何をしているか

### 1. 比率を範囲に収める

`lume.clamp(amount, 0, 1)` で、比率を `0` から `1` の範囲に収めます。範囲外の値でも、結果が二つの値の外に出ないようにします。

```lua:line-numbers=104
  local t = lume.clamp(amount, 0, 1)
```

### 2. 比率を三次式で曲げる

`t * t * (3 - 2 * t)` で、比率を曲げた値 `m` を求めます。この式は、`0` と `1` で端の傾きが `0` になるので、動きが滑らかになります。

```lua:line-numbers=105
  local m = t * t * (3 - 2 * t)
```

### 3. 曲げた比率で補間する

`a + (b - a) * m` で、曲げた比率を使って値を求めます。直線の補間と同じ形ですが、比率が曲がっているので、動きが変わります。

```lua:line-numbers=106
  return a + (b - a) * m
```

## ここがすごい

- **線形の式に曲げを足すだけ**: 補間の形は同じままで、比率だけを変えています。仕組みが理解しやすいです。
- **端で止まって見える**: 始めと終わりの傾きが `0` なので、動き出しと止まり際が自然に見えます。
- **計算が軽い**: 三次式の計算だけで済むので、毎フレームの呼び出しにも向いています。
- **注意点**: 端の傾きが `0` なので、途中の変化は直線より速くなります。一定の速さで動かしたいときは、線形の補間を使ってください。

## まとめ

- 補間の比率を曲げると、同じ補間の式で動きの印象を変えられる。
- 比率は範囲に収めてから曲げると、端の外に値が出ない。
- 目的の動きに合わせて、線形と曲線の補間を使い分ける。
