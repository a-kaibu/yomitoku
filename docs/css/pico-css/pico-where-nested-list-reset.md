## ひとことで

リストの中にさらにリストを入れたとき、内側のリストの余白を整えるルールです。内側の `ol`、`ul`、`dl` の外側の余白をゼロにして、上だけに少しの余白を残します。親の項目との間が詰まりすぎず、二重に広がることもない、という見た目になります。

## コード

```css:line-numbers=857
:where(dl, ol, ul) :where(dl, ol, ul) {
  margin: 0;
  margin-top: calc(var(--pico-typography-spacing-vertical) * 0.25);
}
```

## 前提知識

- **dl 要素**: 用語と説明の組を並べる HTML 要素です。
- **子孫セレクタ**: 空白でつないで、祖先と子孫の関係で要素を選ぶ書き方です。`A B` は、A の中のどこかにある B に一致します。
- **margin-top**: 要素の上の余白です。
- **:where()**: 括弧の中の条件を、詳細度に数えない疑似クラスです。

## 何をしているか

### 1. 入れ子の中のリストを選ぶ

```css:line-numbers=857
:where(dl, ol, ul) :where(dl, ol, ul) {
```

`:where(dl, ol, ul) :where(dl, ol, ul)` は、リストの中にあるリストに一致します。外側の一つ目のリストは対象外です。空白の位置で、親と子の関係を表しています。

### 2. 上の余白だけを残す

```css:line-numbers=858
  margin: 0;
  margin-top: calc(var(--pico-typography-spacing-vertical) * 0.25);
```

`margin: 0` で、内側のリストの外側の余白をすべてゼロにします。そのあと `margin-top` だけを、基準の余白の 4 分の 1 に戻します。親の項目の文とつながって見えるように、上にだけ少し隙間を残す形です。

## ここがすごい

- 余白を一度ゼロにしてから、上だけ戻すという順番で書かれています。下の余白が二重にならないように、考えて組まれています。
- 上の余白は、基準の変数に係数を掛けているので、テーマの変更に追従します。
- 素直に入れ子のリストに個別のクラスを付けると、入れ子の深さが増えるたびに書き足す必要があります。セレクタの親子関係で決めれば、深さに関係なく同じ見た目になります。
- `:where()` で詳細度がゼロなので、利用者は内側のリストだけ別の余白にできます。

## まとめ

- 子孫セレクタで、入れ子の中の要素だけを選べます。
- 余白を一度ゼロにしてから、必要な方向だけ戻すと、二重の余白を防げます。
- 基準の変数を使うと、見た目の調子が全体と揃います。
