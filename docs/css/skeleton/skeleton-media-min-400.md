## ひとことで

画面の幅が 400px 以上になったとき、コンテナの幅を `85%` に広げ、左右の余白を取り除くルールです。小さな画面では余白で端を守り、少し広くなったら、画面の幅を有効に使う、という段階的な切り替えです。

## コード

```css:line-numbers=45
@media (min-width: 400px) {
  .container {
    width: 85%;
    padding: 0; }
}
```

## 前提知識

- **media query**: 画面の幅などの条件に応じて、適用する CSS を切り替える仕組みです。
- **min-width: 400px**: 画面の幅が 400px 以上のときに一致する条件です。
- **padding**: 要素の内側の余白です。ここでは、左右の余白を取り除いています。
- **%（割合）**: 親要素の幅に対する割合です。`85%` は、親の 85% の幅になります。

## 何をしているか

### 1. 幅を 85% に広げる

```css:line-numbers=46
  .container {
    width: 85%;
```

400px 以上の画面では、コンテナの幅が `85%` になります。小さな画面の `100%` よりも狭いので、左右にほどよい余白が残ります。

### 2. 余白を取り除く

```css:line-numbers=48
    padding: 0; }
```

`padding: 0` によって、左右の余白をなくします。幅が 85% になると、画面の端の余白だけで、本文は十分に守られるという判断です。

## ここがすごい

- 幅の割合と余白を、同じ条件で切り替えています。どちらか一方だけを変えると、余白が二重になったり、狭すぎたりするので、組み合わせて調整されています。
- 400px という境目は、当時の小さなスマートフォンと、その少し広い端末を分けるための値です。
- 素直に、幅を px で書くと、画面の大きさが変わるたびに、その値を調整する必要があります。割合にすると、画面に合わせて自然に伸び縮みします。
- 基本の定義では左右の余白を入れ、広い画面でだけ余白をなくすという、小さい画面を優先した書き方です。

## まとめ

- `min-width` の media query で、画面が広くなったときだけ別の値を当てられます。
- 幅の割合と余白を同時に変えると、画面に合った見た目になります。
- 小さい画面を基本にして、広い画面で広げる順番が、読みやすさを守ります。
