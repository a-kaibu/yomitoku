## ひとことで

Skeleton の列の幅は、`4.66666666667%` や `13.3333333333%` のような、割り切れない数字で書かれています。これは、12 列と、列の間の 4% の隙間を合わせて、100% に収まるように計算された値です。数式を一度確かめると、この数字の意味がわかります。

## コード

```css:line-numbers=62
  .one.column,
  .one.columns                    { width: 4.66666666667%; }
  .two.columns                    { width: 13.3333333333%; }
  .three.columns                  { width: 22%;            }
  .four.columns                   { width: 30.6666666667%; }
  .five.columns                   { width: 39.3333333333%; }
  .six.columns                    { width: 48%;            }
  .seven.columns                  { width: 56.6666666667%; }
  .eight.columns                  { width: 65.3333333333%; }
  .nine.columns                   { width: 74.0%;          }
  .ten.columns                    { width: 82.6666666667%; }
  .eleven.columns                 { width: 91.3333333333%; }
  .twelve.columns                 { width: 100%; margin-left: 0; }
```

## 前提知識

- **割合（%）**: 親の幅に対する割合です。合計が 100% になるように、列の幅を決めます。
- **隙間（ガター）**: 列と列の間に入る余白です。ここでは、列の左に入る 4% が隙間になります。
- **12 分割**: 一行を 12 の単位に分けて、列を数で指定する考え方です。
- **循環小数**: 3 で割り切れない割り算の結果が、小数点以下で繰り返されることです。ここでは `4.6666…` がそれにあたります。

## 何をしているか

### 1. 一列の幅を計算する

```css:line-numbers=62
  .one.column,
  .one.columns                    { width: 4.66666666667%; }
```

一列の幅は `4.6666…%` です。12 列並ぶと、列の間の隙間が 11 か所あります。全体の 100% から、隙間の合計 44%（4% × 11）を引くと 56% になり、それを 12 で割ると一列分の 4.6666…% になります。

### 2. 二列以上の幅も同じ考え方で決まる

```css:line-numbers=64
  .two.columns                    { width: 13.3333333333%; }
  .three.columns                  { width: 22%;            }
```

二列の幅は `13.3333…%` です。二列は、一列分の幅を二つ分と、その間の隙間 4% を足したものです。`4.6666… × 2 + 4 = 13.3333…` と確かめられます。

## ここがすごい

- 割り切れない数字を、そのまま書いています。四捨五入すると、列の合計が 100% を超えたり、足りなくなったりするので、正確な値を残しています。
- 隙間を固定の 4% にしているので、列の幅を変えるときも、一つの式で他の列の幅が決まります。
- 素直に、列の幅を 5% のような切りのいい値で書くと、12 列並べたときに隙間が合いません。割り切れない値を使うことで、きれいに並びます。
- 同じ計算で、三分の一や三分の二の幅（`.one-third.column` など）も決まっています。

## まとめ

- 列の幅は、全体の幅から隙間を引いて、列の数で割る式で決まります。
- 割り切れない数字は、計算の結果をそのまま書いたものです。
- 隙間の割合を一つ決めると、ほかの列の幅も一緒に決まります。
