## ひとことで

見出しの `h1` から `h6` まで、文字の大きさを段階的に小さくしていくルールです。`h1` は本文の 2.35 倍、`h6` は本文と同じ 1 倍です。見出しの番号が大きくなるほど、文字が小さくなるので、文章の階層が見た目からも読み取れます。

## コード

```css:line-numbers=44
h1 {
  font-size: 2.35em;
}

h2 {
  font-size: 2em;
}

h3 {
  font-size: 1.75em;
}

h4 {
  font-size: 1.5em;
}

h5 {
  font-size: 1.25em;
}

h6 {
  font-size: 1em;
}
```

## 前提知識

- **見出しの階層**: `h1` が最も重要な見出し、`h6` が最も細かい見出しです。文書の構造を表すための番号です。
- **em 単位の比率**: `2em` は、親の文字の大きさの 2 倍です。見出しは本文の文字サイズを基準に決まるので、本文の大きさを変えると見出しも連動します。
- **font-size**: 文字の大きさを決めるプロパティです。
- **段階（スケール）**: 値を一定の比率で並べたものです。ここでは約 0.75 倍ずつ小さくなっています。

## 何をしているか

### 1. 大きい見出しから順に

```css:line-numbers=44
h1 {
  font-size: 2.35em;
}

h2 {
  font-size: 2em;
}
```

`h1` は `2.35em`、`h2` は `2em`、`h3` は `1.75em` です。番号が一つ増えるたびに、文字が少しずつ小さくなります。`h1` と `h2` の差は、全体の流れを崩さないように、少し大きめに取られています。

### 2. 小さい見出しまで続ける

```css:line-numbers=52
h3 {
  font-size: 1.75em;
}

h4 {
  font-size: 1.5em;
}

h5 {
  font-size: 1.25em;
}

h6 {
  font-size: 1em;
```

`h4` は `1.5em`、`h5` は `1.25em`、`h6` は `1em` です。`h6` は本文と同じ大きさになるので、最も細かい見出しは、本文の中に自然に溶け込みます。見出しの太さは `700` で統一されています。

## ここがすごい

- 見出しの大きさが、すべて本文の大きさを基準にした比率で書かれています。本文を一つ変えるだけで、見出しの全体が比例して変わります。
- 6 段階を覚えやすい数字で並べています。`h6` だけは 1em と、本文に合わせて、読者が階層の終わりを見失いにくくしています。
- 素直に `h1 { font-size: 36px; }` のように px で書くと、本文の大きさを変えたときに、見出しとの比率が崩れます。em なら、その比率が保たれます。
- 見出しの大きさを一つずつ書いているので、どの見出しがどの大きさかが一目でわかります。

## まとめ

- 見出しの大きさは、本文の大きさを基準にした比率で決めると、比例して変わります。
- 見出しの番号が大きいほど、小さく並べると階層が伝わります。
- 最も細かい見出しは本文と同じにすると、溶け込みやすくなります。
- 段階の数字を一覧で書くと、見出しの体系が一目で把握できます。
