## ひとことで

画面の幅が 684px 以下になったときに、本文の文字サイズを `1.53rem` に下げるルールです。画面が狭くなると、文字が大きすぎて一行に入る文字数が減り、読みにくくなります。その問題を、文字を少し小さくすることで和らげています。

## コード

```css:line-numbers=22
@media (max-width: 684px) {
  body {
    font-size: 1.53rem;
  }
}
```

## 前提知識

- **media query**: 画面の幅などに応じて、適用する CSS を切り替える仕組みです。
- **max-width: 684px**: 画面の幅が 684px 以下のときに一致する条件です。
- **rem**: html の文字サイズを基準にした単位です。このファイルでは `1rem` が 10px です。
- **段階的な縮小**: 画面の幅ごとに、値を何段階かに分けて変えることです。

## 何をしているか

### 1. 684px 以下で文字を小さくする

```css:line-numbers=22
@media (max-width: 684px) {
  body {
    font-size: 1.53rem;
  }
}
```

`body` の文字の大きさだけを変えています。通常は `1.8rem`（18px）ですが、684px 以下では `1.53rem`（約 15px）になります。文字が少し小さくなるので、狭い画面でも一行に入る文字の数が極端に減りません。

同じ書き方で、382px 以下のブロックはさらに `1.35rem`（13.5px）に下げます。このブロックは、ここには引用していませんが、ファイルの続きに書かれています。

## ここがすごい

- 文字の大きさだけを変えていて、幅や余白には手を付けていません。レイアウトの崩れを防ぎつつ、読みやすさを調整しています。
- 大きさを段階的に変えるので、スマートフォンの横幅が違う端末にも、ある程度合わせられます。
- 素直に文字サイズをビューポートの単位（vw）で決めると、文字が極端に小さくなることがあります。段階的な media query なら、最小値を自分で決められます。
- 本文の幅が em で決まっているので、文字が小さくなると、箱の幅もそれに合わせて小さくなります。

## まとめ

- 狭い画面では、文字を少し小さくすると一行の文字数を保てます。
- media query を段階で書くと、画面ごとの大きさを決め打ちできます。
- 文字の大きさを下げるだけなら、レイアウトは崩れません。
- 最小の大きさを自分で決めておくと、読みにくくなる範囲を防げます。
