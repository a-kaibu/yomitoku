## ひとことで

`h1` から `h6` までの見出しの文字サイズと太さを、親の値から受け継ぐように戻すルールです。ブラウザは見出しを大きく、太く表示する既定のスタイルを持っています。このルールは、その既定のスタイルを消して、見出しの見た目を利用者が自分で決める前提を作ります。

## コード

```css:line-numbers=78
h1,
h2,
h3,
h4,
h5,
h6 {
  font-size: inherit;
  font-weight: inherit;
}
```

## 前提知識

- **見出し要素（h1〜h6）**: 文書の構造を示す HTML 要素です。数字が小さいほど重要な見出しを表します。
- **font-size と font-weight**: 文字の大きさと太さを決めるプロパティです。
- **既定のスタイル**: ブラウザが最初から持つ見た目の指定です。見出しは、ほとんどの場合で大きく太く表示されます。
- **inherit**: 親要素の値を受け継ぐキーワードです。見出しの中に入った親が変われば、見出しも一緒に変わります。

## 何をしているか

### 1. 見出し全体の大きさと太さを継承にする

```css:line-numbers=78
h1,
h2,
h3,
h4,
h5,
h6 {
  font-size: inherit;
  font-weight: inherit;
}
```

6 つのセレクタに、同じ 2 つの宣言を当てています。`font-size: inherit` で大きさを、`font-weight: inherit` で太さを、親の値に戻します。これにより、`h1` でも `h6` でも、周りの文字と同じ大きさと太さになります。

コメントにあるように、このルールの目的は「既定の見出しスタイルを消すこと」です。見出しに強い見た目を与えたいときは、クラスなどを使って、自分で大きさを指定します。

## ここがすごい

- 見出しの階層を HTML で正しく書いても、見た目はいったん白紙になります。文書の構造と見た目を、切り離して扱えるようになります。
- 6 つを一つのルールにまとめているので、どの見出しも同じ方針で扱われます。書き忘れがないことが、一目で確認できます。
- 素直に書くと、`h1 { font-size: 2em; }` のように見出しごとに大きさを決めることになります。これは見た目の設計を CSS に埋め込むことになり、デザインを変えるときの修正箇所が増えます。
- 継承に戻すだけなので、特別な数値は書かれていません。ブラウザの既定を「消す」だけという、とても控えめなリセットです。

## まとめ

- 見出しは、ブラウザの既定で大きく太く表示されます。
- `font-size` と `font-weight` を `inherit` にすると、見出しを本文と同じ見た目に戻せます。
- 構造と見た目を分けて、見た目は必要な場所で自分で決めます。
- 複数のセレクタをまとめると、リセットの方針が一目でわかります。
