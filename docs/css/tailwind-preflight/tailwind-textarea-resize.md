## ひとことで

複数行の入力欄 `textarea` に `resize: vertical` を指定して、利用者が入力欄の角をドラッグするときに、縦方向にしか広げられないようにするルールです。ブラウザは既定で縦横どちらにも広げられますが、横に広がると周りのレイアウトを壊してしまうことがあります。

## コード

```css:line-numbers=307
textarea {
  resize: vertical;
}
```

## 前提知識

- **textarea 要素**: 複数行の文字を入力する HTML 要素です。
- **resize**: 利用者が要素の大きさを、ドラッグで変えられるかどうかを決めるプロパティです。`both` は縦横両方、`vertical` は縦だけ、`none` は変えられない、という値です。
- **レイアウトの崩れ**: 入力欄が横に広がると、隣の要素を押しのけたり、画面の右側からはみ出したりします。
- **リセット**: ブラウザの既定の見た目を、あらかじめ決めた状態に戻すことです。

## 何をしているか

### 1. 縦方向だけリサイズを許す

```css:line-numbers=308
  resize: vertical;
```

`resize: vertical` は、利用者が入力欄の角をドラッグしても、縦の高さだけが変わります。入力する文章が長くなったときに、縦に広げて読み返せるという、必要な機能は残されています。

## ここがすごい

- 横への広がりを止めることで、ページの幅が予想外に広がる事故を防げます。入力欄を置いた場所のレイアウトを、利用者の操作から守っています。
- 縦のリサイズを残しているので、長い文章を書く人の使い勝手は損なわれません。「完全に固定」ではなく、「必要な方向だけ許す」という選び方です。
- 素直に `resize: none` にすると、長い文章を書くときに入力欄を広げられなくなります。`vertical` にすると、その不便を避けられます。
- 対象は `textarea` だけなので、他の要素の動きには影響しません。

## まとめ

- `resize` は、利用者がドラッグで大きさを変えられる方向を決めます。
- 横方向を止めると、レイアウトが入力欄の操作で崩れにくくなります。
- 縦の変更を残すと、長い文章も書きやすいままです。
- リセットは「全部禁止」ではなく、どこまで許すかを決めることが大切です。
