## ひとことで

`img` と `video` の幅の上限を 100% にして、親要素の幅を超えないようにするルールです。高さは `auto` にして、元の縦横比のまま縮むようにします。スマートフォンのように画面が狭い環境でも、画像がはみ出さないための基本の指定です。

## コード

```css:line-numbers=230
img,
video {
  max-width: 100%;
  height: auto;
}
```

## 前提知識

- **max-width**: 要素の幅の上限を決めるプロパティです。`100%` は、親要素の幅と同じ長さを意味します。
- **height: auto**: 高さを、幅に応じて自動で決めるという値です。画像は縦横比を保ったまま、高さが決まります。
- **縦横比（aspect ratio）**: 幅と高さの比率のことです。16:9 の動画などでは、この比率を崩さないことが大切です。
- **親要素**: ある要素を囲んでいる一つ外側の要素のことです。`max-width: 100%` は、その要素の幅を基準にします。

## 何をしているか

### 1. 幅の上限を親に合わせる

```css:line-numbers=230
img,
video {
  max-width: 100%;
```

`max-width: 100%` は、画像の幅の上限を、親要素の幅にします。親より大きな画像は、親の幅まで縮みます。逆に、親より小さい画像は元の大きさのまま表示されます。

### 2. 高さを自動で決める

```css:line-numbers=233
  height: auto;
```

`height: auto` は、幅を縮めたときに高さも一緒に縮めるという指定です。これにより、縦横比が崩れません。もし高さを固定すると、幅だけが縮んで画像が縦長や横長に歪んでしまいます。

## ここがすごい

- 2 行の宣言だけで、画像とビデオのレスポンシブな対応ができます。画面幅に合わせて、特別なメディアクエリを書く必要がありません。
- `max-width` を使うのがポイントです。`width: 100%` と書くと、小さい画像まで拡大されて、ぼやけてしまいます。`max-width` なら、縮むだけで拡大はしません。
- 素直に `width: 100%` だけを書くと、画像が大きく引き伸ばされることがあります。この 2 行は、その問題を防ぎつつ、縮小だけを行います。
- 対象を `img` と `video` に限り、ほかの要素には触れていません。影響範囲が小さい書き方です。

## まとめ

- `max-width: 100%` で、画像が親の幅を超えないようにします。
- `height: auto` で、縦横比を保ったまま高さが決まります。
- `width` ではなく `max-width` を使うと、小さな画像が拡大されません。
- 画像とビデオに限って指定すると、ほかの見た目を変えずに済みます。
