## ひとことで

normalize.css は、`body` の外側の余白を 0 にしています。ブラウザが既定で付けている余白を消して、ページの端から配置を始められるようにします。

## コード

```css:line-numbers=23
body {
  margin: 0;
}
```

## 前提知識

- **body 要素**: ページの本文を囲む要素です。見える内容は、ほとんどこの中に入ります。
- **margin**: 要素の外側の余白です。ブラウザは body に既定の余白を付けるため、ページの端と内容の間に隙間ができます。
- **既定の余白の差**: 余白の大きさは、ブラウザごとに異なります。そのままにすると、同じページでも端の隙間が変わってしまいます。

## 何をしているか

### 1. 外側の余白を消す

```css:line-numbers=24
  margin: 0;
```

body の margin を 0 にします。ヘッダーや背景の色が、ブラウザの端まで届くようになります。

## ここがすごい

一行の指定で、ブラウザの違いを一度に消せます。余白の扱いを、CSS の側で決められるようになる、最初の土台です。

ページの端から配置を始めると、ヘッダーや背景の色を画面の端まで伸ばせます。余白が残ったままだと、この色が端で切れて見えてしまいます。normalize は余白を消すだけで、余白を再び付けるかどうかは、作る人が決めます。その意味で、この一行は、何を自分で決めるかを明確にする指定です。

この指定は、ページ全体の見た目を一度に変えるため、後から追加するレイアウトの影響範囲も広くなります。最初に一度だけ書いておくことが、後の調整を分かりやすくする工夫になります。

## まとめ

body の余白を消すことは、normalize の中でも最も小さく、影響の大きな指定です。
