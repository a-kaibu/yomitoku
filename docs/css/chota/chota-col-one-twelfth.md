## ひとことで

一つ分の列 `col-1` の幅を決めるルールです。画面の 100% を 12 等分した一つ分から、列の間隔（ガター）を引いて、列の幅にします。`flex: 0 0 …` と `max-width` にも同じ値を入れて、列の幅が勝手に変わらないようにしています。

## コード

```css:line-numbers=30
.col-1 {
  flex: 0 0 calc((100% / (12/1)) - var(--grid-gutter));
  max-width: calc((100% / (12/1)) - var(--grid-gutter));
}
```

## 前提知識

- **12 分割グリッド**: 一行を 12 個の単位に分けて、列を 1 から 12 の数で指定する考え方です。`col-4` なら 3 分の 1 の幅になります。
- **calc()**: 数式を CSS の中で計算する関数です。`%` と変数を混ぜて計算できます。
- **flex の三つの値**: `flex-grow`、`flex-shrink`、`flex-basis` を並べた省略形です。ここでは「伸びない、縮まない、基準の幅はこの値」を表します。
- **max-width**: 要素の幅の上限です。

## 何をしているか

### 1. 幅の数式

```css:line-numbers=31
  flex: 0 0 calc((100% / (12/1)) - var(--grid-gutter));
  max-width: calc((100% / (12/1)) - var(--grid-gutter));
```

`100% / (12/1)` は、100% を 12 で割った値に相当する数式です。`12/1` と書いてあるのは、列の数を分子に、分割数を分母にするという読みやすさのための書き方です。そこからガターを引いて、列の実際の幅にします。

`flex: 0 0 …` は、列の幅を固定し、伸びも縮みもさせない指定です。`max-width` に同じ値を入れることで、中身が多くても幅が広がりません。

## ここがすごい

- 列の幅を、割合と変数の組み合わせで書いているので、ガターを変えると、すべての列の幅が一度に合わせて変わります。
- `12/1` のように、分子と分母を分けて書いているので、`col-2` などの数字の違いが、式の中の数字だけで表せます。読む人にも規則がはっきりします。
- 素直に幅を `8.33%` と小さい数字で書くと、ガターを変えたときに列の合計がずれます。`calc()` で計算すると、ずれを防げます。
- `flex` と `max-width` の両方に同じ値を入れているので、ブラウザや内容によって幅が変わりにくくなります。

## まとめ

- 12 分割の列は、100% を 12 で割った値で決まります。
- ガターを引くと、列の間の隙間を含めた幅に収まります。
- `calc()` で数式を書くと、ガターの変更に自動で追従します。
- `flex` と `max-width` の両方に同じ幅を書くと、列の幅が安定します。
