## ひとことで

タグが二つ以上並んでいるとき、二つ目以降のタグの左に余白を付けるルールです。隣接セレクタ `+` を使うので、直前にタグがある要素だけが対象になります。先頭のタグは余白が付かず、左端にそろいます。

## コード

```css:line-numbers=21
.tag + .tag {
  margin-left: 1rem;
}
```

## 前提知識

- **隣接兄弟セレクタ（+）**: `A + B` は、直前に A がある B に一致します。
- **margin-left**: 要素の左側の外の余白です。
- **inline-block**: タグが文字と同じ行に並ぶ指定です。この並びの間に、余白が効きます。
- **タグ**: 前のページで見た `.tag` の部品です。

## 何をしているか

### 1. 直前にタグがあるものだけ

```css:line-numbers=21
.tag + .tag {
  margin-left: 1rem;
}
```

`.tag + .tag` は、直前に別の `.tag` がある `.tag` に一致します。`margin-left: 1rem` で、左側に 1rem（既定の文字の大きさで 10px、ここでは 1rem）の余白を入れます。

## ここがすごい

- 余白を「後ろのタグの左に付ける」形にしているので、先頭のタグの左側には何もなく、行の端が揃います。
- 隣接セレクタを使うことで、並んだタグの間だけに隙間が生まれます。タグの数が増えても、規則は変わりません。
- 素直に、すべての `.tag` に右側の余白を付けると、最後のタグの右側にも余白が残ります。左側だけにすると、その問題がありません。
- 余白の単位を `rem` にしているので、ページ全体の文字の大きさに合わせて、タグの間隔も変わります。

## まとめ

- `+` は、直前に同じ要素がある要素だけを選びます。
- 余白を後ろの要素の左側に付けると、先頭が揃います。
- `rem` で余白を決めると、文字の大きさと連動します。
