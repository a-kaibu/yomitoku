## ひとことで

`h1` から `h6` までの見出しに共通の、上下の余白と文字の太さを決めるルールです。余白は `em` で書かれているので、見出しの文字が大きくなると、余白も比例して広がります。見出しの大きさは、この後の個別のルールで決まります。

## コード

```css:line-numbers=44
h1,
h2,
h3,
h4,
h5,
h6 {
  font-weight: 500;
  margin: 0.35em 0 0.7em;
}
```

## 前提知識

- **em 単位**: 現在の要素の文字の大きさを基準にした単位です。見出しでは、その見出しの文字サイズが基準になります。
- **margin の省略形**: `margin: 上 左右 下` の形で、上と下の余白をまとめて書く指定です。ここでは左右は 0 です。
- **font-weight**: 文字の太さです。`500` は、標準より少し太い値です。
- **見出しの大きさ**: `h1` は 2em、`h6` は 0.85em のように、個別に決められています。

## 何をしているか

### 1. 太さと余白

```css:line-numbers=50
  font-weight: 500;
  margin: 0.35em 0 0.7em;
```

`font-weight: 500` で、見出しは本文より少し太くなります。`margin: 0.35em 0 0.7em` は、上に 0.35em、下に 0.7em の余白です。上の余白を小さく、下の余白を大きくして、見出しが本文との関係で読みやすくなるようにしています。

## ここがすごい

- 余白の単位を `em` にしているので、見出しの大きさを変えると、余白も連動して変わります。`px` で書いたときのように、見出しごとに調整する必要がありません。
- 上を小さく、下を大きくした非対称の余白は、見出しが次の本文に結びつくという読み方を助けます。
- 素直に `margin: 20px 0;` と書くと、小さな見出しに大きすぎる余白が付いてしまいます。`em` にすると、その問題を防げます。
- 見出しの共通の性質を一つのルールにまとめ、大きさだけを個別に書いています。

## まとめ

- 見出しの余白は `em` で書くと、見出しの大きさに比例します。
- 上の余白を小さく、下の余白を大きくすると、見出しが本文に結びつきます。
- 共通の性質と個別の大きさを分けると、読みやすい構造になります。
