## ひとことで

画面の幅が 599px 以下のとき、列の並びを変えるルールです。コンテナの幅を 100% にし、すべての列を全幅の 1 行にします。画面が狭くて列が押しつぶされるのを防ぎ、列が上から下へ積み重なります。

## コード

```css:line-numbers=90
@media screen and (max-width: 599px) {
  .container {
    width: 100%;
  }

  .col,
  [class*="col-"],
  [class^="col-"] {
    flex: 0 1 100%;
    max-width: 100%;
  }
}
```

## 前提知識

- **media query**: 画面の幅などの条件によって、適用する CSS を切り替える仕組みです。
- **max-width: 599px**: 画面の幅が 599px 以下のときに一致する条件です。スマートフォンの縦向きなどが対象になります。
- **flex: 0 1 100%**: 列の基準の幅を 100% にし、縮むことはできるが伸びないという指定です。
- **ブレークポイント**: 画面の幅で CSS を切り替える境目の値のことです。このファイルでは 599px と 900px、1200px が使われています。

## 何をしているか

### 1. コンテナを画面いっぱいに広げる

```css:line-numbers=91
  .container {
    width: 100%;
  }
```

小さな画面では、コンテナの幅を 96% から 100% に変えます。左右の余白を取る分を、箱の幅に回すわけです。

### 2. すべての列を全幅にする

```css:line-numbers=95
  .col,
  [class*="col-"],
  [class^="col-"] {
    flex: 0 1 100%;
    max-width: 100%;
  }
```

列のクラスすべてに、`flex: 0 1 100%` と `max-width: 100%` を当てます。どの列も 1 行を占めるので、横に並ばず、上から順に積み重なります。

## ここがすごい

- 幅の指定を media query で一か所にまとめているので、画面が狭くなったときの振る舞いを一つのブロックで読めます。
- 列のセレクタは、前に見た属性セレクタと同じ形を使っています。新しい列のクラスを作っても、ここで自動的に全幅になります。
- 素直に列ごとに media query を書くと、列の数だけ同じ宣言が増えます。接頭辞のセレクタで一括に扱うと、その手間が減ります。
- 境目を 599px にしているのは、スマートフォンの縦向きと、タブレットの横向きを分けるための値です。

## まとめ

- media query で、狭い画面だけ列の並び方を変えられます。
- コンテナと列の幅を 100% にすると、列が上から積み重なります。
- 属性セレクタと組み合わせると、列のクラスを一括で扱えます。
- ブレークポイントの値を明確にしておくと、後で見直しやすくなります。
