## ひとことで

列を表すクラスに、共通の余白を付けるルールです。`.col` のクラスに加えて、クラス名に `col-` を含むものと、`col-` で始まるものも同じ対象にします。こうすると、`col-6-md` のような新しいクラス名が増えても、余白のルールを書き足す必要がありません。

## コード

```css:line-numbers=20
.col {
  flex: 1;
}

.col,
[class*=" col-"],
[class^="col-"] {
  margin: 0 calc(var(--grid-gutter) / 2) calc(var(--grid-gutter) / 2);
}
```

## 前提知識

- **属性セレクタ**: `[class*="..."]` のように、属性の値の一部で要素を選ぶセレクタです。`*=` は「含む」、`^=` は「で始まる」という意味です。
- **class 属性**: 要素が持つクラスの名前を、空白で区切って並べた属性です。`class="row col-6"` のように複数書けます。
- **margin**: 要素の外側の余白です。ここでは列の間隔を作ります。
- **グリッド**: 画面を縦と横の格子に分けて、部品を並べる考え方です。Chota では 12 分割の列で作ります。

## 何をしているか

### 1. 列のクラスを一つずつ書かない

```css:line-numbers=24
.col,
[class*=" col-"],
[class^="col-"] {
```

`.col` は単独の列です。`[class*=" col-"]` は、class 属性の中に「空白 + col-」を含む要素に一致します。`[class^="col-"]` は、class 属性が「col-」で始まる要素に一致します。この三つを並べると、列の幅を指定するクラスが何であっても、同じ余白が付きます。

### 2. 余白の計算

```css:line-numbers=27
  margin: 0 calc(var(--grid-gutter) / 2) calc(var(--grid-gutter) / 2);
```

`margin: 0 calc(var(--grid-gutter) / 2) calc(var(--grid-gutter) / 2)` は、左右と下に、ガターの半分の余白を付けます。上には余白を付けないので、行の頭がずれません。

## ここがすごい

- 列のクラス名（col-1 から col-12、col-1-md など）を一つずつ列挙する代わりに、接頭辞で一括に対象を決めています。新しいクラスを増やしても、余白のルールは変えずに済みます。
- 属性セレクタには、要素の種類を制限しない効果もあります。`div` でも `section` でも、クラスの名前さえ合えば同じ余白になります。
- 素直に `.col-1, .col-2, ..., .col-12` と書くと、列が増えるたびに一覧を直す必要が出てきます。接頭辞のセレクタは、その手間を省きます。
- ただし、同じ接頭辞の別の用途のクラスにも効いてしまうことがあります。その点はこのフレームワークの前提として割り切っています。

## まとめ

- 属性セレクタの `*=` は「含む」、`^=` は「で始まる」という条件です。
- 接頭辞で対象を選ぶと、クラスが増えても CSS を直さずに済みます。
- 列の余白は、上を空けて下と左右に付けるという設計です。
- 接頭辞の規則を決めておくと、属性セレクタの効きが予測しやすくなります。
