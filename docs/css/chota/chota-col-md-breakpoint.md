## ひとことで

`col-1-md` のように、クラス名の末尾に `-md` が付いた列の幅を、画面の幅が 900px 以上のときだけ決めるルールです。小さな画面では通常の列の幅が使われ、中くらいの画面から別の幅に切り替わります。

## コード

```css:line-numbers=104
  .col-1-md {
    flex: 0 0 calc((100% / (12/1)) - var(--grid-gutter));
    max-width: calc((100% / (12/1)) - var(--grid-gutter));
  }
```

## 前提知識

- **min-width**: 画面の幅が、この値以上のときに一致する条件です。`min-width: 900px` は 900px 以上を意味します。
- **接尾辞の命名**: `col-1-md` のように、基本の名前の後ろに画面サイズを表す文字を付ける名前の付け方です。`md` は medium（中くらい）、`lg` は large（大きい）を意味します。
- **flex-basis**: flex の子要素の基準の幅です。ここでは列の幅そのものを表します。
- **二重定義**: 同じ要素に別々の幅が書かれたとき、後から読まれたものが優先されることがあるため、クラスの書き方は慎重に決められます。

## 何をしているか

### 1. 大きな画面だけで効く列のクラス

```css:line-numbers=104
  .col-1-md {
    flex: 0 0 calc((100% / (12/1)) - var(--grid-gutter));
    max-width: calc((100% / (12/1)) - var(--grid-gutter));
  }
```

`.col-1-md` は、900px 以上の画面だけで有効になる列のクラスです。`flex: 0 0 …` で列の幅を固定し、`max-width` でも同じ幅に制限します。

この規則は、`col-1` と同じ計算式ですが、media query の中に置いてあります。だから、画面が狭いときは効かず、広くなると効きます。

## ここがすごい

- 大きな画面と小さな画面で、同じ HTML のまま列の幅を変えられます。マークアップはそのままで、クラス名だけで切り替える設計です。
- 数式が `col-1` と同じなので、ガターの計算を変えるときも、一か所を直せば済む形になっています。
- 素直に、画面の幅ごとに別々の CSS ファイルを作ると、管理が大変になります。一つのファイルに media query を並べると、全体を一度に見渡せます。
- クラス名の末尾に画面の大きさを付ける命名は、どのクラスがどの画面で効くのかを名前だけで伝えられます。

## まとめ

- `min-width` の media query で、大きな画面だけに効くルールを書けます。
- クラス名の接尾辞で、画面の大きさに応じた列の幅を選べます。
- 同じ計算式を使うと、画面サイズによる差だけに集中して読めます。
- 命名の規則を決めておくと、クラスの効く範囲が読み取りやすくなります。
