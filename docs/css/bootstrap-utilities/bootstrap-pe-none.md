## ひとことで

`pe-none` クラスを付けた要素が、マウスのクリックやホバーを受け取らないようにするユーティリティです。要素は画面に見えたままですが、その下にある要素がクリックできるようになります。装飾の層や、重ねた画像などで役立ちます。

## コード

```css:line-numbers=3194
  .pe-none {
    pointer-events: none;
  }
```

## 前提知識

- **pointer-events**: マウスやタッチの操作を、要素が受け取るかどうかを決めるプロパティです。`none` は、操作を受け取りません。
- **重なり**: 要素が別の要素の上に重なっている状態です。上の要素が操作を受け取ると、下の要素はクリックできません。
- **装飾の層**: 見た目を整えるための、透明な箱や飾りの画像などのことです。
- **表示と操作**: 見えることと、操作を受け取ることは別の性質です。

## 何をしているか

### 1. 操作を受け取らないようにする

```css:line-numbers=3195
    pointer-events: none;
```

`pointer-events: none` で、この要素はクリックもホバーも受け取りません。要素自体は見えたままです。マウスのイベントは、この要素をすり抜けて、下の要素に届きます。

## ここがすごい

- 見た目の装飾を重ねても、下のボタンやリンクが押せなくなる問題を防げます。見た目と操作を、別々に扱えます。
- 一つのプロパティで、要素の操作を止められます。非表示にする `display: none` と違って、要素の位置や大きさは変わりません。
- 素直に、装飾の箱を `display: none` にすると、見た目も消えてしまいます。操作だけを止めると、見た目は残せます。
- 子要素には `pointer-events` が継承されるので、子の装飾も同じように操作を通します。ただし、子に `auto` を書けば、その要素だけ操作を戻せます。

## まとめ

- `pointer-events: none` は、要素の操作を受け取らないようにします。
- 見た目と操作は別々に扱えるので、装飾の重なりを安全に作れます。
- `display: none` と違って、場所を残したまま操作を通せます。
