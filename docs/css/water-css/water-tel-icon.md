## ひとことで

Water.css は、電話番号へのリンクの前に、受話器の絵文字を付けます。電話をかけられるリンクだと、一目で分かるようにするための指定です。

## コード

```css:line-numbers=77
a[href^='tel']::before {
  content: '📞 ';
}
```

## 前提知識

- **tel リンク**: `href="tel:..."` の形で書いたリンクです。スマートフォンでは、タップすると発信の画面が開きます。
- **属性の前方一致**: `^=` は、属性の値が指定した文字列で始まるものを選ぶ記号です。tel: で始まる href が対象です。
- **絵文字**: 文字として扱われる記号です。フォントに依存しますが、多くの環境で受話器の形として表示されます。

## 何をしているか

### 1. 電話のリンクを選ぶ

```css:line-numbers=77
a[href^='tel']::before {
```

href が tel で始まる a 要素だけを選びます。メールや通常の外部リンクには、この印は付きません。

### 2. 受話器を前に置く

```css:line-numbers=78
  content: '📞 ';
```

content に受話器の絵文字を入れます。電話番号の前に印が付き、発信できるリンクだと分かります。

## ここがすごい

mailto の指定と並べて書くことで、連絡の方法ごとに印を揃えています。ルールを一つ足すだけで、新しい連絡の種類にも同じ仕組みを広げられます。

電話番号は、スマートフォンでは押すと発信できるため、連絡先の中でも特に分かりやすく示す価値があります。受話器の印を付けると、その番号がタップで操作できることを、読み手が理解できます。メールの印と並べて使うと、連絡手段の種類を、同じ仕組みで揃えて見せられます。

## まとめ

属性で連絡先の種類を選び、絵文字を前に置く書き方は、連絡の手段を見分ける軽い工夫です。
