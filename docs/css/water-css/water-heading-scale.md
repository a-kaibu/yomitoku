## ひとことで

Water.css は、最も大きい見出しの `h1` を、本文より大きく見せます。見出しの下に余白を取り、本文との間隔も一定にしています。

## コード

```css:line-numbers=17
h1 {
  font-size: 2.2em;
  margin-top: 0;
}

h1,
h2,
h3,
h4,
h5,
h6 {
  margin-bottom: 12px;
}
```

## 前提知識

- **em**: 親の文字の大きさを 1 とする単位です。2.2em は、本文の 2.2 倍です。
- **margin-top**: 要素の上の余白です。ページの先頭の見出しは、上に余白を付けると、本体の上端からずれてしまいます。
- **見出しの階層**: h1 から h6 までは、文書の構造を表します。数字が小さいほど大きな見出しです。

## 何をしているか

### 1. 一番大きい見出し

```css:line-numbers=17
h1 {
  font-size: 2.2em;
  margin-top: 0;
}
```

h1 は本文の 2.2 倍になり、上の余白を 0 にします。ページの先頭で、タイトルが上端から自然に始まります。

### 2. 見出しの下の余白

```css:line-numbers=22
h1,
h2,
h3,
h4,
h5,
h6 {
  margin-bottom: 12px;
}
```

h1 から h6 までの全部に、下に 12px の余白を入れます。見出しの後ろの間隔が、どのレベルでも同じになります。

## ここがすごい

見出しの階層ごとに余白を書く代わりに、まとめて一つのルールで揃えています。サイズだけは h1 に特別に与えられています。

見出しの大きさは、文書の階層を示す最も分かりやすい手がかりです。h1 だけを大きくして、残りの見出しは本文に近い大きさに保つことで、どこが章の始まりかがすぐ分かります。下の余白をそろえると、見出しの後に続く本文の位置も、どの見出しでも同じ間隔になります。

## まとめ

見出しの大きさと余白を先に決めると、文書の骨格が、ひと目で分かる形になります。
