## ひとことで

Water.css は、画像の幅に上限を付けて、本文の幅より大きくならないようにします。小さな画面でも、画像が横にはみ出さず、文章と並んで読めます。

## コード

```css:line-numbers=194
img {
  max-width: 100%;
}
```

## 前提知識

- **img 要素**: 画像を表示する HTML の要素です。既定では、元の大きさで表示されます。
- **max-width**: 幅の上限を決めるプロパティです。画像が上限より大きい場合は、上限の幅に縮みます。
- **親の幅**: 画像の上限は、画像を置いた箱の幅を基準にします。本文の幅が 800px なら、その範囲に収まります。

## 何をしているか

### 1. 幅の上限

```css:line-numbers=195
  max-width: 100%;
```

画像の幅を親の 100% までに制限します。元の画像が大きくても、本文の幅を超えません。

## ここがすごい

一行の指定で、すべての画像に同じ規則を当てられます。画面の幅を変えたときも、画像が自然に縮んで、読みやすさを保ちます。

画像は、元の大きさのまま表示すると、狭い画面で本文の幅を超えてしまいます。上限を 100% にすると、画像は必要なときだけ縮み、大きな画面では元の大きさを保てます。画像の縦横の比率は、ブラウザが保ったまま縮むため、形が歪むこともありません。

画像を本文の幅に収めると、文章と画像の左右の端がそろい、ページ全体が一本の流れとして読めます。大きすぎる画像を横へはみ出させると、読み手は左右にスクロールする手間が増えます。縮む規則を一つのクラスとして決めておけば、どの画像にも同じ扱いが保証されます。

## まとめ

img に max-width を 100% で与えると、画像は本文の幅に収まり、小さな画面でも崩れずに表示されます。
