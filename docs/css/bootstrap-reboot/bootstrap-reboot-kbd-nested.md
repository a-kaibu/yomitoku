## ひとことで

`kbd` の中にさらに `kbd` が入ったときに、内側の余白と文字の大きさをゼロと 1em に戻すルールです。外側の `kbd` の余白と文字サイズが、内側でも繰り返されて、二重に大きくなるのを防ぎます。

## コード

```css:line-numbers=699
  kbd kbd {
    padding: 0;
    font-size: 1em;
  }
```

## 前提知識

- **入れ子の要素**: 要素の中に、同じ種類の要素が入っている状態です。`kbd kbd` は、その内側の `kbd` に一致します。
- **子孫セレクタ**: 空白で区切って、祖先と子孫の関係で要素を選ぶ書き方です。
- **em 単位**: 現在の文字の大きさを基準にした単位です。`1em` は、親と同じ大きさです。
- **padding**: 要素の内側の余白です。

## 何をしているか

### 1. 内側の余白をゼロにする

```css:line-numbers=700
    padding: 0;
```

内側の `kbd` の `padding` を 0 にします。外側の `kbd` が余白を持っているので、内側にも余白が付くと、キーの中の枠が二重に広がります。

### 2. 文字の大きさを親に合わせる

```css:line-numbers=701
    font-size: 1em;
```

`font-size: 1em` で、内側の文字を外側と同じ大きさに戻します。`kbd` 自身は小さな文字サイズを持っているので、そのまま入れ子になると、文字が二重に小さくなるのを防いでいます。

## ここがすごい

- 二つのプロパティを消すだけの指定ですが、入れ子の要素が出たときの不具合を、先回りして防いでいます。
- 子孫セレクタで対象を入れ子の内側に限っているので、外側の `kbd` の見た目には触れていません。
- 素直に、入れ子の `kbd` にクラスを付けて打ち消す方法もあります。セレクタで入れ子を判定すると、HTML を書く人が毎回気を付ける必要がありません。
- 「キーの組み合わせ」の表示（Ctrl+K のように、キーを並べて書く場合）に関係する場面で役立ちます。

## まとめ

- 入れ子の要素は、外側の余白や大きさが重なって、二重に見えることがあります。
- 子孫セレクタで内側だけ打ち消すと、外側の見た目を変えずに済みます。
- 文字の大きさを `1em` にすると、親の大きさに揃えられます。
