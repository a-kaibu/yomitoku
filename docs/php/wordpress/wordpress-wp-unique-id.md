## ひとことで

`wp_unique_id` は、ページの中で **重ならない ID** を作る関数です。`wp_unique_id('menu-')` と呼ぶと、`menu-1`、`menu-2` のように連番がつきます。HTML の `id` 属性に使うときに便利です。

## コード

```php:line-numbers=8285
function wp_unique_id( $prefix = '' ) {
	static $id_counter = 0;
	return $prefix . (string) ++$id_counter;
}
```

## 前提知識

- **HTML の id 属性**: 1 つのページの中で、同じ値を 2 回使ってはいけない属性です。ラベルと入力欄を結ぶときなどに使います。
- **`static` 変数**: 関数の中に書いても、関数が終わったあとも値が残る変数です。呼ぶたびに同じ変数を使います。
- **前置インクリメント `++$x`**: 先に 1 増やしてから、その値を使う書き方です。
- **`(string)` キャスト**: 値を文字列にする書き方です。
- **連結 `.`**: 文字列どうしをつなぐ演算子です。

## 何をしているか

### 1. 関数の中に、番号を覚える変数を置く

```php:line-numbers=8286
	static $id_counter = 0;
```

`static $id_counter = 0;` は、この関数専用の変数です。初めて呼ばれたときだけ 0 で作られ、次からは前回の値を引き継ぎます。関数の外からは見えないので、ほかの処理と名前がぶつかりません。

### 2. 番号を増やして、接頭辞と連結する

```php:line-numbers=8287
	return $prefix . (string) ++$id_counter;
```

`++$id_counter` で、先に 1 増やしてから、その値を文字列にします。`$prefix` を前につないで返します。

具体例として、`wp_unique_id('faq-')` を 2 回呼ぶと、1 回目は `faq-1`、2 回目は `faq-2` になります。接頭辞を変えれば、用途ごとに分けられます。

## ここがすごい

### 関数の中で状態を持つ、もっとも小さな例

グローバル変数を使うと、どこからでも書き換えられてしまいます。この関数は `static` 変数を使うことで、状態を関数の中に閉じ込めています。呼び出し側は、番号が増えていることを心配せずに使えます。

### 同じページの中でだけ、重ならないことを保証する

番号はページの中で増え続けるので、同じページでは必ず違う値になります。ただし、リクエストが変わると番号は 1 からやり直します。ID の一意性は「1 回のページの中」で保証される、という範囲を理解して使うことが大切です。

### 前置インクリメントの使い方

`++$id_counter` と書くことで、増やした後の値をそのまま連結に使えます。増やす処理と使う処理を 1 行にまとめているので、番号の付けすぎや付け忘れがありません。

## まとめ

- 関数の中で状態を持たせたいときは、`static` 変数が手軽な方法になる。
- 一意な ID は、その範囲（ページ、リクエスト、プロセス）を決めて使う。
- 接頭辞を付けると、用途の違う ID を見分けやすくなる。
- 増やしてから使う前置インクリメントで、1 行にまとめられる。
