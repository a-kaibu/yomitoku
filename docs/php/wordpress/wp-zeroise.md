## ひとことで

`zeroise` は、数字を指定した桁数の文字列にして、足りない桁を `0` で埋める関数です。`zeroise(5, 3)` は `005` になります。月や日を「03 月」のように 2 桁で表示するときなどに使われます。

## コード

```php:line-numbers=2848
function zeroise( $number, $threshold ) {
	return sprintf( '%0' . $threshold . 's', $number );
}
```

## 前提知識

- **`sprintf`**: 書式の文字列に値を埋め込んで、新しい文字列を作る PHP の関数です。`%s` は文字列、`%d` は整数を入れる場所を表します。
- **書式の中の `0`**: `%05s` のように、`%` のすぐあとに `0` を書くと、その幅に足りない分を `0` で埋める指定になります。
- **連結 `.`**: 文字列をつなぐ演算子です。`'%0' . $threshold . 's'` は、`%03s` のような書式を組み立てます。
- **`$threshold`**: 桁数を表す引数です。ここでは、埋めたあとの全体の長さを指定します。

## 何をしているか

### 1. 桁数から書式を組み立てる

```php:line-numbers=2849
	return sprintf( '%0' . $threshold . 's', $number );
```

`$threshold` が `3` なら、`'%0' . 3 . 's'` は `%03s` になります。この書式を `sprintf` に渡すと、`$number` の文字列が、3 桁になるように左側を `0` で埋められます。

具体的に見てみます。

- `zeroise(5, 3)` は `%03s` で、`005` になります。
- `zeroise(42, 2)` は `%02s` で、`42` のまま（すでに 2 桁）です。
- `zeroise(7, 2)` は `%02s` で、`07` になります。

桁数より長い数字は、切り詰められずにそのまま出ます。そこがこの関数の特徴です。

### 2. 書式を外から作る

この関数の中心は、書式を値として組み立てる点です。数字の部分を `sprintf` の仕組みに任せることで、埋める処理を自分で書く必要がありません。

## ここがすごい

- **1 行で桁合わせが済む**: 数字を文字列にして、長さを数え、足りない分だけ `0` を付ける、という手順を `sprintf` の書式 1 つで表しています。
- **桁数を変えるだけ**: 桁数を引数にしたので、2 桁でも 4 桁でも同じ関数で扱えます。
- **溢れを切らない**: 桁数より長い値は切り詰めないので、番号などが壊れません。表示の用途に向いた性質です。
- **書式を連結で作る**: 桁数を埋め込む部分を文字列の連結にしているので、書式の意味が読み取りやすくなっています。

## まとめ

- 桁合わせは、`sprintf` の `%0Ns` の書式で行える。
- 書式は、連結で桁数を埋め込むと動的に作れる。
- 桁数より長い値は切り詰めず、そのまま表示される。
- 表示のための小さな関数は、1 行で意図を伝えるように書くと読みやすい。
