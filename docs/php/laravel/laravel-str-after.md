## ひとことで

`Str::after` は、文字列の中で `$search` が最初に現れた位置より後ろの部分を返す関数です。`user@example.com` から `@` より後ろの `example.com` を取り出すような場面で使われます。見つからなければ、空文字を返します。

## コード

```php:line-numbers=108
    public static function after($subject, $search)
    {
        return $search === '' ? $subject : array_reverse(explode($search, $subject, 2))[0];
    }
```

## 前提知識

- **`explode`**: 文字列を区切り文字で分けて、配列にする PHP の関数です。`explode('@', 'a@b')` は `['a', 'b']` を返します。
- **第 3 引数の制限**: `explode` の第 3 引数（ここでは `2`）は、分ける最大の数です。`2` を指定すると、最初の区切りだけで分けて、残りは最後の要素にまとまります。
- **`array_reverse`**: 配列の順番を逆にする関数です。
- **配列の添字 `[0]`**: 配列の先頭の要素を取り出します。`配列()[0]` のように、関数の結果から直接取り出せます。
- **三項演算子 `? :`**: 条件によって 2 つの値のどちらかを返します。

## 何をしているか

### 1. 空の区切りを特別扱いする

```php:line-numbers=110
        return $search === '' ? $subject : array_reverse(explode($search, $subject, 2))[0];
```

まず `$search === ''` を確かめます。空の区切りで `explode` を呼ぶと、PHP はエラーにします。そこで、空の区切りのときは元の文字列をそのまま返すことにしています。

### 2. 最初の区切りで 2 つに分ける

同じ行の `explode($search, $subject, 2)` は、最初に見つかった区切りで文字列を 2 つに分けます。`a@b@c` を `@` で分けると、`['a', 'b@c']` になります。

分ける数を 2 に制限しているので、2 つめ以降の区切りは分割の対象になりません。残りの部分は、まとめて最後の要素に入ります。

### 3. 後ろの要素を選ぶ

`array_reverse` で配列の順番を逆にすると、`['b@c', 'a']` になります。その先頭 `[0]` が `b@c` です。

つまり「区切りより後ろ」は、分けた結果の最後の要素を取り出すことで得られます。`array_reverse(...)[0]` は、その最後の要素を書く短い方法です。

区切りが見つからない場合は、`explode` が 1 つだけの配列を返すので、その唯一の要素（元の文字列全体）が返ります。ここでは、`after('abc', 'x')` が `abc` になる、という挙動になります。

## ここがすごい

- **分割数の制限で読みやすさを確保**: 分割数を制限しないと、`a@b@c` は 3 つに分かれて、最後の要素だけを取ると `c` になってしまいます。2 に制限すると、「最初の区切りより後ろ全部」という意味が正しく保たれます。
- **空の区切りの防御**: `explode` は空の区切りを受け付けません。関数の最初で弾くことで、呼び出し側が例外を気にせずに済みます。
- **`array_reverse` を使う工夫**: 配列の最後の要素を取るのに、`end()` のような関数を使うこともできます。ここでは、式の流れの中で 1 行にまとめるために、逆順の先頭を取る書き方を選んでいます。
- **対になる関数**: 同じ作りの `before` は、区切りより前の部分を返します。2 つを並べると、どちらの意味か迷いにくくなります。

## まとめ

- 区切りより後ろの部分は、`explode` の分割数を 2 にして、最後の要素を取ると得られる。
- 空の区切りは `explode` が受け付けないので、先に判定する。
- 区切りが見つからないときは、元の文字列がそのまま返る。
- 対になる関数を並べると、意味の違いが分かりやすい。
