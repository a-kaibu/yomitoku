## ひとことで

`Str::swap` は、対応表（連想配列）に従って、文字列の中の語を別の語に一度に置き換える関数です。`str_replace` を語ごとに呼ぶ代わりに、PHP の `strtr` にまとめて任せています。

## コード

```php:line-numbers=1959
    public static function swap(array $map, $subject)
    {
        return strtr($subject, $map);
    }
```

## 前提知識

- **連想配列**: `'元の語' => '置き換え後'` の組を並べた配列です。`['a' => 'x', 'b' => 'y']` のように書きます。
- **`strtr`**: 文字列の中の語を、対応表に従って置き換える PHP の関数です。文字を 1 つずつ変える `strtr($s, 'ab', 'xy')` の形と、配列を使う形の両方があります。
- **`str_replace` との違い**: `str_replace` は、置き換えを語ごとに順番に行います。そのため、前の置き換えの結果が後の置き換えに影響することがあります。
- **型の宣言 `array`**: 第 1 引数は配列でなければならない、という指定です。

## 何をしているか

### 1. 対応表を一度に適用する

```php:line-numbers=1961
        return strtr($subject, $map);
```

`strtr` に、元の文字列と対応表を渡すだけです。`['cat' => 'dog']` なら、文字列の中の `cat` が `dog` に変わります。

### 2. 長い語を優先する

PHP の `strtr` に配列を渡すと、置き換えの候補の中で、長い語が優先されます。たとえば `['a' => 'x', 'ab' => 'y']` で `ab` を含む文字列を処理すると、`ab` は `y` になり、`a` の置き換えは使われません。

この性質のおかげで、語の一部が別の語と重なっていても、大きい語のまとまりを先に置き換えられます。

### 3. 置き換えが連鎖しない

`strtr` は、1 回の走査で置き換えを行います。置き換えた結果が、また別の対応の置き換え対象になることはありません。`str_replace` を順に呼ぶと起きる連鎖の問題を避けられます。

## ここがすごい

- **1 回の走査で完了**: 語ごとに文字列を何度も走査せず、まとめて置き換えます。語の数が多くても効率が落ちにくくなっています。
- **連鎖を防ぐ**: 置き換えた語がまた置き換わる、という問題が起きません。`a → b` と `b → c` の対応表でも、元の `a` は `b` になり、そこから `c` へは進みません。
- **長い語の優先が自然**: 短い語が長い語の一部であっても、長い語のほうが選ばれます。手で順番を並べ替える必要がありません。
- **1 行で済む**: 関数の本体は 1 行です。対応表を渡すだけで、置き換えの全体が表せます。

## まとめ

- 複数の語を一度に置き換えるには、対応表を `strtr` に渡すとよい。
- `strtr` は長い語を優先するので、語の重なりを手で処理しなくてよい。
- 1 回の走査で置き換えるので、置き換えの連鎖が起きない。
- 置き換えを 1 行の式にまとめると、対応の全体が読みやすい。
