## ひとことで

`Str::wrap` は、文字列の前と後ろに印を付けて囲む関数です。`Str::wrap('abc', '"')` のように後ろの印を省略すると、前と同じ印で囲みます。引用符や括弧で囲む処理を、短く書けます。

## コード

```php:line-numbers=523
    public static function wrap($value, $before, $after = null)
    {
        return $before.$value.($after ?? $before);
    }
```

## 前提知識

- **デフォルト引数**: 引数に `= null` のような既定値を入れておくと、呼び出し側は省略できます。
- **`??`（null 合体演算子）**: 左側が `null` なら、右側の値を使います。`$after ?? $before` は、`$after` が無ければ `$before` を使う、という意味です。
- **連結 `.`**: 文字列をつなぐ演算子です。`$before.$value.(...)` の順番で、前から並べます。
- **括弧 `( )`**: 式の順番を明示する記号です。ここでは `??` の部分を先に計算させるために使われています。

## 何をしているか

### 1. 後ろの印を決める

```php:line-numbers=525
        return $before.$value.($after ?? $before);
```

後ろの印は `$after` です。ただし `$after` が `null`（省略された）なら、前の印 `$before` を使います。これで、同じ記号で両側を囲む場合は引数を 1 つ書くだけで済みます。

### 2. 前、値、後ろの順につなぐ

同じ行の `$before.$value.(...)` が、3 つの部分をつなぎます。順番は、前の印、値、後ろの印です。

たとえば `Str::wrap('abc', '"')` は、前が `"`、値が `abc`、後ろが `"` なので、結果は `"abc"` です。`Str::wrap('abc', '(', ')')` なら `(abc)` になります。

## ここがすごい

- **よく使う形を短く書ける**: 引用符のように前後が同じ場合、引数を 1 つ省略するだけで済みます。書き手の手間が減ります。
- **`null` で省略を表す**: 省略を `null` で表すと、「後ろの印を指定していない」と「後ろの印が空文字」を区別できます。空文字を指定すれば、後ろには何も付きません。
- **式が 1 行**: 関数の本体は 1 行です。どんな印で囲むかが、式の形からそのまま読めます。
- **値を変えない**: 値そのものは加工せず、前後に連結するだけです。エスケープが必要なら、呼び出し側で別に行う前提の関数です。

## まとめ

- 前後を同じ印で囲むなら、後ろの引数を省略できるようにすると呼びやすい。
- `null` を省略の印にすると、空文字との区別が保てる。
- 連結だけの処理は、1 行の式で読みやすく書ける。
- 値の加工（エスケープなど）は、この関数の役割に含めないと決めておくと分かりやすい。
