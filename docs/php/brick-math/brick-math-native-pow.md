## ひとことで

`pow` は、大きな整数の **累乗**（たとえば 2 の 100 乗）を求める関数です。`brick/math` は PHP の整数の限界を超える数を、文字列として扱って計算します。その中で、掛け算の回数を減らすために「2 乗しながら指数を半分にする」方法を使っています。

## コード

```php:line-numbers=205
    public function pow(string $a, int $e): string
    {
        if ($e === 0) {
            return '1';
        }

        if ($e === 1) {
            return $a;
        }

        $odd = $e % 2;
        $e -= $odd;

        $aa = $this->mul($a, $a);

        $result = $this->pow($aa, $e / 2);

        if ($odd === 1) {
            $result = $this->mul($result, $a);
        }

        return $result;
    }
```

## 前提知識

- **累乗**: 同じ数を何回も掛けることです。`3^5` は `3 × 3 × 3 × 3 × 3` のことです。
- **任意精度整数**: PHP の整数の範囲を超えても、桁数に制限なく計算できる数のことです。`brick/math` はこれを文字列で表します。
- **指数の偶奇**: 指数が偶数か奇数かで、計算の手順を変えます。`% 2` で余りを調べて判定します。
- **再帰**: 関数が自分自身を呼ぶ書き方です。ここでは指数が小さくなるまで呼びます。
- **`$e / 2`**: 割り算の結果が整数になるように、偶数の指数だけを割ります。

## 何をしているか

### 1. 指数が 0 と 1 の場合は、すぐ答える

```php:line-numbers=207
        if ($e === 0) {
            return '1';
        }

        if ($e === 1) {
            return $a;
        }
```

`a^0` は 1、`a^1` は `a` そのものです。ここで再帰を止めます。

### 2. 指数が奇数なら、1 つだけ分けておく

```php:line-numbers=215
        $odd = $e % 2;
        $e -= $odd;
```

`$odd = $e % 2` で、指数が奇数なら 1、偶数なら 0 になります。奇数のときは、指数から 1 を引いて偶数にします。`$e -= $odd;` がその処理です。

### 3. 2 乗を作って、指数を半分にする

```php:line-numbers=218
        $aa = $this->mul($a, $a);

        $result = $this->pow($aa, $e / 2);
```

`$aa = $this->mul($a, $a);` で、`a` の 2 乗を作ります。そして `pow($aa, $e / 2)` を呼びます。`a^e` は `(a^2)^(e/2)` と同じなので、指数が半分になります。

### 4. 奇数だったら、最後に 1 つ掛ける

```php:line-numbers=222
        if ($odd === 1) {
            $result = $this->mul($result, $a);
        }

        return $result;
```

さっき引いた 1 を戻すために、奇数だったときだけ、結果に `a` をもう 1 回掛けます。

具体例として `3^5` を見ましょう。指数 5 は奇数なので、`3` を分けて指数 4 にします。`3^2 = 9` を作り、`9^2 = 81` を計算します。最後に `81 × 3 = 243` になります。

## ここがすごい

### 掛け算の回数が、指数の対数で済む

素直に `a` を `e` 回掛けると、指数が大きいほど時間がかかります。この方法は、指数を半分にしながら 2 乗を作るので、掛け算の回数が指数の大きさの対数（桁数のような増え方）で済みます。`2^1000` のような大きな計算でも、ほんの数十回の掛け算で済みます。

### 文字列で扱うから、桁数の上限がない

`mul` は、数を文字列として掛け算します。PHP の `int` の範囲を超えても、結果が正しく得られます。大きな数を扱う計算機の部品として、この関数は仕組みの中心にあります。

### 奇数の 1 つ分を、先に取り除く

奇数のときに 1 を引いておくと、残りの指数はいつも偶数になります。偶数の指数は、きれいに半分にできるので、計算の手順が単純になります。

## まとめ

- 累乗は、指数を半分にしながら 2 乗を作ると、掛け算の回数が少なくて済む。
- 指数が奇数のときは、1 つ分を先に外すと、残りを半分にできる。
- 数を文字列で扱うと、PHP の整数の上限を超える計算もできる。
- 再帰は、基本の場合（0 と 1）を先に書くと、止まる条件が明確になる。
