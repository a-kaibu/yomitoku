## ひとことで

`calculateTrace` は、2 つの配列の差を取るための探索の本体です。Myers という有名な差分アルゴリズムを使い、「古い配列を新しい配列にするのに、追加と削除が最も少なくて済む経路」を見つけます。PHP-Parser はこの結果を使って、整形前後のコードのどこが変わったかを判断します。

## コード

```php:line-numbers=62
    private function calculateTrace(array $old, array $new): array {
        $n = \count($old);
        $m = \count($new);
        $max = $n + $m;
        $v = [1 => 0];
        $trace = [];
        for ($d = 0; $d <= $max; $d++) {
            $trace[] = $v;
            for ($k = -$d; $k <= $d; $k += 2) {
                if ($k === -$d || ($k !== $d && $v[$k - 1] < $v[$k + 1])) {
                    $x = $v[$k + 1];
                } else {
                    $x = $v[$k - 1] + 1;
                }

                $y = $x - $k;
                while ($x < $n && $y < $m && ($this->isEqual)($old[$x], $new[$y])) {
                    $x++;
                    $y++;
                }

                $v[$k] = $x;
                if ($x >= $n && $y >= $m) {
                    return [$trace, $x, $y];
                }
            }
        }
        throw new \Exception('Should not happen');
    }
```

## 前提知識

- **配列の差分**: 古い配列 `old` を新しい配列 `new` にするには、要素を「残す」「削除する」「追加する」の 3 種類の操作を組み合わせます。その組み合わせのうち、削除と追加の合計が最も少ないものを探すのが目的です。
- **`(\count($old))`**: 配列の要素数を返す関数です。`\` は名前空間の外にある組み込み関数を指します。
- **`$this->isEqual`**: クラスに保存された関数（コールバック）です。`($this->isEqual)(a, b)` のように括弧で囲んで呼びます。比較の方法を外から変えられるようにしています。
- **`while`**: 条件が真の間、本体を繰り返す制御構文です。
- **`throw`**: 例外を投げて処理を中断する文です。ここでは「ありえない状況」の保険です。

## 何をしているか

### 1. 変数を準備する

```php:line-numbers=63
        $n = \count($old);
        $m = \count($new);
        $max = $n + $m;
        $v = [1 => 0];
        $trace = [];
```

`$n` と `$m` は 2 つの配列の長さです。`$max` は、どれだけ編集を重ねても超えない上限です。

`$v` は、「対角線 `k` ごとに、古い配列の何番目まで進めたか」を覚える表です。`k` は `x - y`（古い側の位置から新しい側の位置を引いた値）で、同じ `k` の点は同じ斜めの線上にあります。`$trace` は、各段階の `$v` を保存しておく履歴です。後で経路をたどり直すのに使います。

### 2. 編集の回数 `d` を 1 つずつ増やす

```php:line-numbers=68
        for ($d = 0; $d <= $max; $d++) {
            $trace[] = $v;
            for ($k = -$d; $k <= $d; $k += 2) {
```

`$d` は「ここまでに使った編集の回数」です。`d = 0` から始め、1 増やすたびに、それまでの結果から 1 手多く進んだ位置を調べます。`$k` は `-d` から `d` まで 2 ずつ増えるので、`d` の偶奇に合った対角線だけを調べます。

### 3. 次の位置を選ぶ

```php:line-numbers=70
            for ($k = -$d; $k <= $d; $k += 2) {
                if ($k === -$d || ($k !== $d && $v[$k - 1] < $v[$k + 1])) {
                    $x = $v[$k + 1];
                } else {
                    $x = $v[$k - 1] + 1;
                }
```

ここが探索の分かれ道です。隣の対角線 `k-1` と `k+1` のどちらから来るかを選びます。`x = $v[$k + 1]` は、`k+1` の線から縦に 1 つ下へ進む動きで、新しい配列から要素を追加することに当たります。`x = $v[$k - 1] + 1` は、`k-1` の線から横に 1 つ進む動きで、古い配列の要素を削除することに当たります。

どちらの動きでも 1 手増えるので、同じ `d` の中では「より遠くまで進めた」方を選ぶのが自然です。`$v[$k - 1] < $v[$k + 1]` の比較は、その判断をしています。

### 4. 同じ要素が続くあいだは、コストなしで進む

```php:line-numbers=77
                $y = $x - $k;
                while ($x < $n && $y < $m && ($this->isEqual)($old[$x], $new[$y])) {
                    $x++;
                    $y++;
                }
```

`y` は `x - k` から求めます。両方の配列の要素が等しいあいだは、編集の回数を増やさずに斜めに進めます。これが Myers 法の速さの理由です。

### 5. 終点に着いたら経路を返す

```php:line-numbers=83
                $v[$k] = $x;
                if ($x >= $n && $y >= $m) {
                    return [$trace, $x, $y];
                }
```

`$v[$k]` に到達位置を書き込みます。`x` と `y` の両方が配列の末尾まで届いたら、そのとき `d` 回の編集で目的地に着いたことになります。`$trace` と終点を返すと、呼び出し側はそれを逆向きにたどって、実際の追加・削除の列を組み立てられます。

## ここがすごい

- **同じ経路を何度も数えない**: 同じ `d` と `k` の組に対しては、最も遠くまで届いた位置だけを `$v` に残します。すべての経路を全部試す方法と比べて、必要な情報だけで済みます。
- **編集回数で探索を区切る**: 差が小さいときは `d` が小さいうちに終わるので、長い配列でも短い時間で差を見つけられます。Myers 法は、差が少ないほど速くなる性質を持ちます。
- **履歴を残す**: `$trace` を保存しておくと、結果から経路を復元できます。結果だけを返す書き方より実装は少し長くなりますが、どこが変わったかを正確に示せます。
- **比較を外から差し替えられる**: `isEqual` をコールバックにしているので、単純な `===` でも、ノードの内容だけを比べる関数でも使えます。

## まとめ

- 差分は「追加と削除の最小回数」を探す問題で、Myers 法は編集回数 `d` を 1 つずつ増やしながら探す。
- `k = x - y` の斜めの線上で、到達位置だけを覚えれば十分。
- 等しい要素が続くあいだは、コストを増やさずに斜めに進める。
- 探索の途中の表を `$trace` に残すと、後から変更の経路を組み立てられる。
