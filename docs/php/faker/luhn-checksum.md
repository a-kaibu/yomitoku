## ひとことで

`checksum` は、数字の並びから Luhn（ルーン）アルゴリズムの合計を計算する関数です。Luhn は、クレジットカード番号や一部の ID の誤入力を見つけるために使われる、昔からの検査方式です。この関数は、その検査で使う合計の 10 で割った余りを返します。

## コード

```php:line-numbers=18
    private static function checksum(string $number)
    {
        $number = (string) $number;
        $length = strlen($number);
        $sum = 0;

        for ($i = $length - 1; $i >= 0; $i -= 2) {
            $sum += $number[$i];
        }

        for ($i = $length - 2; $i >= 0; $i -= 2) {
            $sum += array_sum(str_split($number[$i] * 2));
        }

        return $sum % 10;
    }
```

## 前提知識

- **Luhn アルゴリズム**: 右端から数えて 1 つおきの数字を 2 倍し、2 桁になったらその各桁を足す、という計算です。全部を足して 10 の倍数になれば正しい番号とみなします。
- **文字列の添字**: `$number[$i]` は、文字列の `$i` 番目の 1 文字を取り出す書き方です。0 から数えます。
- **`for` 文の刻み幅**: `$i -= 2` は、2 つずつ左へ進むという意味です。
- **`str_split`**: 文字列を 1 文字ずつの配列に分ける関数です。`str_split("14")` は `["1", "4"]` を返します。
- **`array_sum`**: 配列の要素の合計を返す関数です。
- **`%`**: 割った余りです。`$sum % 10` は、合計の一の位になります。

## 何をしているか

### 1. 右端から 2 つおきの数字を足す

```php:line-numbers=24
        for ($i = $length - 1; $i >= 0; $i -= 2) {
            $sum += $number[$i];
        }
```

最初のループは、右端の桁（`$length - 1`）から始めて、2 つおきに左へ進みます。ここで取り出した桁は、2 倍せずにそのまま `$sum` に足します。

Luhn では、チェックディジット（最後の 1 桁）を付けたあと、その位置から数えて偶数番目の桁を 2 倍します。この関数の入力では、後で付け足す 0 が右端にあるので、その位置をずらした形で右から奇数番目の桁を素通しにします。

### 2. 残りの桁を 2 倍して足す

```php:line-numbers=28
        for ($i = $length - 2; $i >= 0; $i -= 2) {
            $sum += array_sum(str_split($number[$i] * 2));
        }
```

2 つめのループは、1 つずらした位置から、同じく 2 つおきに桁を取り出します。`$number[$i] * 2` で 2 倍し、`str_split` で桁に分けて、`array_sum` で合計します。

たとえば桁が `7` なら、2 倍して `14` になります。`str_split("14")` は `["1", "4"]` なので、合計は `5` です。桁が `4` なら `8` で、そのまま `8` になります。2 倍した数字を「十の位と一の位に分けて足す」のと同じ結果です。

### 3. 10 で割った余りを返す

```php:line-numbers=32
        return $sum % 10;
    }
```

合計の一の位だけを返します。0 なら、その番号は Luhn の規則を満たしていることになります。

ここでは例として `79927398713` を使います。右から足すと、合計は `0` になり、規則を満たすことが確かめられます。

## ここがすごい

- **1 つの関数で 2 通りの位置を扱う**: 2 つのループは、開始の位置を 1 つずらしただけです。どちらが 2 倍されるかを `if` で分けず、ループの開始位置だけで表しています。
- **2 桁の処理を文字列で済ませる**: `str_split` で桁に分けて足すと、`10` 以上の数を計算で分解する必要がありません。短い書き方で、正しい結果になります。
- **入力を文字列のまま扱う**: 数字を整数に直さず、1 桁ずつ読みます。カード番号のように先頭に 0 があるものでも、桁が失われません。
- **10 で割るだけで判定できる**: 全体を 10 の倍数にする判定は、一の位を見るだけで済みます。

## まとめ

- Luhn のチェックは、右から 2 つおきの桁を 2 倍して足す。
- 2 倍した数が 2 桁になったら、各桁を足す。
- 合計の一の位が 0 なら、規則を満たす番号になる。
- 2 つのループの開始位置をずらすだけで、2 通りの規則を表せる。
