## ひとことで

`mod97` は、大きな数字の並びを 97 で割った余りを求める関数です。IBAN（国際銀行口座番号）の検査で使われる計算で、数字が何十桁あっても、PHP の整数の範囲を超えずに答えを出せます。

## コード

```php:line-numbers=49
    public static function mod97(string $number)
    {
        $checksum = (int) $number[0];

        for ($i = 1, $size = strlen($number); $i < $size; ++$i) {
            $checksum = (10 * $checksum + (int) $number[$i]) % 97;
        }

        return $checksum;
    }
```

## 前提知識

- **剰余（余り）**: 割り算の余りです。`%` 演算子で求めます。
- **合同算術**: 途中で余りを取っても、最後の余りは変わらないという数学の性質です。大きな数を一度に計算せず、少しずつ余りを更新できます。
- **IBAN**: 国際的な銀行口座番号の形式です。国コードと検査数字の後に、口座情報が続きます。検査数字が正しいと、全体を 97 で割った余りが 1 になります。
- **`(int)`**: 1 桁の文字を整数に変換します。`(int) '7'` は `7` です。
- **`++$i`**: 変数を 1 増やしてから使う書き方です。
- **`for` 文の変数の宣言**: `$i = 1, $size = strlen($number)` のように、カンマで複数の変数を一度に準備できます。

## 何をしているか

### 1. 先頭の桁で始める

```php:line-numbers=51
        $checksum = (int) $number[0];
```

先頭の 1 桁を整数にして、最初の値とします。まだ余りを取っていないので、1 桁の数字はそのまま値になります。

### 2. 1 桁ずつ取り込んで余りを更新する

```php:line-numbers=53
        for ($i = 1, $size = strlen($number); $i < $size; ++$i) {
            $checksum = (10 * $checksum + (int) $number[$i]) % 97;
        }
```

2 桁目から最後の桁まで、順番に読みます。`10 * $checksum` は、今までの値を 1 桁左にずらすことに当たります。そこへ次の桁を足して、97 で割った余りを新しい値にします。

たとえば数字 `1234567` を読むと、途中の値は次のように変わります。

- 最初: `1`
- 2 桁目: `10 * 1 + 2 = 12`（97 未満なのでそのまま）
- 3 桁目: `10 * 12 + 3 = 123`、97 で割った余りは `26`
- 4 桁目: `10 * 26 + 4 = 264`、余りは `70`
- 5 桁目: `10 * 70 + 5 = 705`、余りは `26`
- 6 桁目: `10 * 26 + 6 = 266`、余りは `72`
- 7 桁目: `10 * 72 + 7 = 727`、余りは `48`

最後に残るのは `1234567` を 97 で割った余り `48` です。1234567 を一度に計算しなくても、同じ答えになります。

### 3. 最後の余りを返す

```php:line-numbers=57
        return $checksum;
```

ループが終わったら、その値が全体の余りです。

## ここがすごい

- **大きな整数を作らない**: IBAN は 30 桁を超えることがあり、PHP の整数（64 ビット）では収まりません。途中で余りを取るので、どんなに長くても扱えます。
- **1 行の式で読める**: 「1 桁左にずらして足し、97 で割る」が、そのまま 1 行の式になっています。数学の書き方を、そのままプログラムにしています。
- **文字列を直接読む**: 数字の文字列から 1 桁ずつ取り出すので、分割の処理を別に書く必要がありません。
- **途中の値が小さいまま**: 余りを取り続けるので、値は常に 0 から 96 の間に収まります。計算の途中で溢れる心配がありません。

## まとめ

- 大きな数の余りは、途中で余りを取りながら 1 桁ずつ計算できる。
- `10 * 現在値 + 次の桁` を 97 で割る、という更新を繰り返す。
- 途中の値は 0 から 96 の範囲に収まるので、溢れずに済む。
- 検査数字の計算は、長い番号でも同じ方法で扱える。
