## ひとことで

`computeCheckDigit` は、途中までの数字から、Luhn 規則を満たす最後の 1 桁を計算する関数です。Faker が偽のクレジットカード番号などを作るときに使われます。仮の 0 を付けて合計を求め、その余りから必要な桁を逆算します。

## コード

```php:line-numbers=38
    public static function computeCheckDigit(string $partialNumber)
    {
        $checkDigit = self::checksum($partialNumber . '0');

        if ($checkDigit === 0) {
            return '0';
        }

        return (string) (10 - $checkDigit);
    }
```

## 前提知識

- **チェックデジット**: 番号の誤りを見つけるために、最後に付ける 1 桁の数字です。計算で決まるので、利用者が覚える必要はありません。
- **`self::`**: 同じクラスの静的メソッドを呼ぶための書き方です。ここでは `checksum` を呼んでいます。
- **`.`（連結）**: 文字列どうしをつなぐ演算子です。`'7992739871' . '0'` は `'79927398710'` になります。
- **`===`**: 型と値の両方が同じかを調べます。`$checkDigit === 0` は、整数の 0 とだけ一致します。
- **`(string)`**: 値を文字列に変換するキャストです。戻り値は文字列として返すと決まっています。

## 何をしているか

### 1. 仮の 0 を付けて合計を求める

```php:line-numbers=40
        $checkDigit = self::checksum($partialNumber . '0');
```

まず、途中までの番号 `$partialNumber` の右に `'0'` を 1 つ付けます。検査の計算では、この右端の桁を「まだ決まっていない桁」として扱います。`checksum` は、その仮の番号の合計を 10 で割った余りを返します。

ここで `checksum` の結果が 0 なら、仮の 0 のままで規則を満たしています。そのため、チェックデジットも 0 です。

### 2. 余りが 0 のときは 0 を返す

```php:line-numbers=42
        if ($checkDigit === 0) {
            return '0';
        }
```

余りが 0 なら、チェックデジットも 0 でよいという意味です。ここで早めに返すので、後の引き算を避けられます。

### 3. 10 から余りを引く

```php:line-numbers=46
        return (string) (10 - $checkDigit);
```

余りが 1 から 9 のときは、`10 - 余り` が答えです。たとえば余りが 7 なら、チェックデジットは 3 です。すると全体の合計は 10 の倍数になります。

具体例として `7992739871` を入れると、仮の 0 を付けた番号の余りは 7 になり、結果は `3` です。`79927398713` の合計が 0（10 の倍数）になることは、前の記事の `checksum` で確かめた値と一致します。

## ここがすごい

- **逆算が 1 回の計算で済む**: 規則を満たす桁を探すために、0 から 9 まで全部を試す必要がありません。合計の余りから、答えが一度に決まります。
- **仮の 0 で計算を揃える**: 検査の関数と、作る関数で同じ `checksum` を使うので、2 つの計算が食い違いません。
- **0 の特別扱い**: 余りが 0 のとき、`10 - 0` の 10 を返すと 2 桁になってしまいます。先に 0 を返すことで、チェックデジットが常に 1 桁になります。
- **文字列で返す**: 戻り値を文字列にしているので、先頭が 0 の番号でも結果が崩れません。

## まとめ

- チェックデジットは、仮の 0 を付けた合計の余りから逆算できる。
- 余りが 0 のときは 0、それ以外は `10 - 余り` が答えになる。
- 検査と生成で同じ合計の関数を使うと、結果が食い違わない。
- 戻り値を 1 桁の文字列にしておくと、番号として扱いやすい。
