# このサイトについて

**ヨクヨム** は、有名な OSS（オープンソースソフトウェア）のソースコードを **関数ひとつ単位** で取り上げ、
「何をしているのか」「なぜこう書くのか」「どこがうまいのか」を日本語でていねいに解説するコードリーディングサイトです。

## 読み方

1. トップページで言語を選びます。
2. 言語ページで、プロジェクト・難易度・タグから気になる関数を探します。
3. 各記事は次の順番で書かれています。
   - **ひとことで** … その関数が何をするか
   - **コード** … 実際のコード（元のファイルの行番号つき）
   - **前提知識** … その言語を知らない人向けに、読むのに必要な文法や概念
   - **何をしているか** … 1 行ずつ、または処理のかたまりごとの解説
   - **ここがすごい** … 工夫・ハック・設計のうまさ
   - **まとめ** … 持ち帰れる学び

その言語をまったく書いたことがなくても読めることを目指しています。

## 難易度

| 表示 | 目安 |
| --- | --- |
| 入門 | プログラミングの基本（変数・if・ループ）がわかれば読める |
| 中級 | 関数・データ構造・その言語の基本的な仕組みに触れる |
| 上級 | ビット演算、メモリ、並行処理、言語の深い仕様などを使う |

## コードの引用とライセンス

- 掲載しているコードは、各 OSS プロジェクトのリポジトリから **特定のコミットに固定したリンク** つきで引用しています。
  記事上部と末尾の「引用元」から、元のファイルの該当行を確認できます。
- 引用コードの著作権は各プロジェクトの著作者にあり、そのプロジェクトのライセンス（MIT、Apache-2.0、BSD、GPL など）に従います。
  各記事にライセンス名を明記しています。
- 引用は解説のために必要な最小限の範囲（1 関数・最大 80 行程度）に限り、本文（解説）が主、コードが従となるようにしています。
- 解説文は [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja) で提供します。
