## ひとことで

`ToHeadingArrow` は、角度（度）を受け取り、その方向を **8 方向の矢印** で返す関数です。
たとえば `0` は `↑`、`90` は `→`、`180` は `↓` になります。角度が 45 度ごとの区切りの間にあれば、最も近い矢印になります。

## コード

```csharp:line-numbers=53
    public static char ToHeadingArrow(this double heading)
    {
        var val = (int)(heading / 45 + .5);

        return HeadingArrows[val % 8];
    }
```

## 前提知識

- **角度の区切り**: 360 度を 8 つに分けると、1 つは 45 度です。0 度を中心に、±22.5 度の範囲が `↑` になります。
- **切り捨て（`(int)`）**: 小数を整数にするとき、小数点以下を捨てる操作です。
- **四捨五入の書き方**: 値に 0.5 を足してから切り捨てると、最も近い整数になります。
- **剰余（`%`）**: 割った余りです。`val % 8` は、8 を超えた分を先頭に戻します。360 度と 0 度が同じ方向になるための処理です。
- **配列の添字**: `HeadingArrows[i]` は、8 個の矢印のうち `i` 番目を取り出します。

## 何をしているか

### 1. 45 度ごとの番号を求める

```csharp:line-numbers=55
        var val = (int)(heading / 45 + .5);
```

角度を 45 で割り、0.5 を足して切り捨てます。これで、最も近い 45 度の区切りの番号が得られます。

### 2. 8 で割った余りで矢印を選ぶ

```csharp:line-numbers=57
        return HeadingArrows[val % 8];
```

番号を 8 で割った余りを添字にして、矢印の配列から 1 文字を返します。`8` は `0` に戻るので、360 度と 0 度が同じ `↑` になります。

### 具体例で確かめる

```
0 度    → 0/45 + 0.5 = 0.5 → 0 → ↑
44 度   → 44/45 + 0.5 = 1.47 → 1 → ↗
180 度  → 180/45 + 0.5 = 4.5 → 4 → ↓
350 度  → 350/45 + 0.5 = 8.28 → 8 → 8 % 8 = 0 → ↑
```

## ここがすごい

- **計算が 2 行だけ**: 区切りの番号を求めて、矢印を選ぶだけなので、読みやすく短い関数です。
- **360 度の折り返しを剰余で処理**: 特別な場合分けをせずに、360 度と 0 度を同じ方向として扱えます。
- **配列で矢印を管理**: 方向ごとの矢印を配列に並べておくので、形を変えたいときも、配列の中身だけを変えれば済みます。
- **注意点**: 負の角度は、`(int)` の切り捨てが 0 に向かうため、区切りのずれが起きます。たとえば `-50` 度は `↖` が望ましいですが、この式では `↑` になります。負の角度は、先に 0 から 360 までの値へ直してから渡すのが安全です。

## まとめ

- `ToHeadingArrow` は、角度を 45 度ごとに丸めて、8 方向の矢印の 1 つを返す。
- 0.5 を足して切り捨てると、最も近い区切りの番号になる。
- 負の角度は、そのままでは正しい矢印にならないことがあるので、0 から 360 の範囲に直して使う。
