## ひとことで

`InsertionSort` は、配列の要素を **1 つずつ取り出して、すでに並んだ部分の正しい位置に差し込む** 並べ替えです。
トランプを 1 枚ずつ手に持って、手札の正しい位置に入れていくのと同じ考え方です。

要素数が多いと遅くなりますが、要素が少ないときや、ほぼ並んでいるときには、ほかのどのソートよりも速く動きます。.NET のイントロソートでも、小さな区間の最後に使われています。

## コード

```csharp:line-numbers=258
        private static void InsertionSort(Span<T> keys, Comparison<T> comparer)
        {
            for (int i = 0; i < keys.Length - 1; i++)
            {
                T t = keys[i + 1];

                int j = i;
                while (j >= 0 && comparer(t, keys[j]) < 0)
                {
                    keys[j + 1] = keys[j];
                    j--;
                }

                keys[j + 1] = t;
            }
        }
```

## 前提知識

- **比較関数 `comparer(a, b)`**: `a < b` なら負、`a > b` なら正、等しければ 0 を返す関数です。
- **`Span<T>`**: 並べ替える範囲を指す「窓」です。`keys[i]` で要素を読み書きします。
- **`for` と `while`**: `for` で各要素を順に取り出し、`while` で正しい位置を探します。
- **`T t = keys[i + 1]`**: 差し込む要素を一時的に保存します。配列の中で動かすと、元の値が上書きされてしまうからです。

## 何をしているか

### 1. 次の要素を取り出す

```csharp:line-numbers=260
            for (int i = 0; i < keys.Length - 1; i++)
            {
                T t = keys[i + 1];
```

i 番目の次の要素を `t` に保存し、`j` を `i` にします。`j` は、すでに並んだ部分の中で、今見ている位置です。

### 2. 大きい要素を右にずらす

```csharp:line-numbers=264
                int j = i;
                while (j >= 0 && comparer(t, keys[j]) < 0)
                {
                    keys[j + 1] = keys[j];
                    j--;
                }
```

`t` より後ろにある要素（`t` より大きいもの）は、1 つ右にずらします。`j` を左に進めながら、`t` より大きい要素を次々に右へ動かします。

例: `[3, 5, 1]` を並べるとき、`t = 1` は `5` と `3` より小さいので、どちらも右へずれます。

```
[3, 5, 1] → 1 を取り出す → [3, 5, _] → 5 を右へ → [3, _, 5] → 3 を右へ → [_, 3, 5]
```

### 3. 空いた場所に差し込む

```csharp:line-numbers=271
                keys[j + 1] = t;
```

ループが終わった位置（`j + 1`）に `t` を書き込みます。その場所は、`t` より小さい要素の右、`t` 以上の要素の左になっています。

## ここがすごい

- **穴を動かす**: 交換を繰り返すと、1 回ごとに 3 回の代入が必要です。この方法では、大きい要素を右へ 1 回ずつコピーするだけで、差し込む要素は最後に 1 回だけ書きます。
- **ほぼ並んでいると速い**: 既に並んでいる配列では、内側のループが 1 回も回らないので、要素数に比例する時間で終わります。
- **小さい区間に強い**: 要素数が 16 程度までなら、再帰を使う複雑なソートより軽く速いことが多いです。だから、イントロソートの末端に使われています。
- **安定である**: 等しい値の順番が変わりません。`t` より大きい要素だけを動かし、等しい要素は動かさないからです。

## まとめ

- 挿入ソートは、取り出した要素の空きを作りながら差し込む、単純で速い並べ替えである。
- 交換より、穴を動かしてコピーするほうが代入の回数が少ない。
- 小さい配列やほぼ整列済みの配列では、挿入ソートが最も速いことが多い。
