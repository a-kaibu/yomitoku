## ひとことで

`IsHexChar` は、ある文字が **16 進数の文字（`0` から `9`、`A` から `F`、`a` から `f`）** かどうかを調べる関数です。
ここでは、16 進数の文字の位置だけを 1 にした **64 ビットの定数** を使い、1 回のシフトと 1 回の比較だけで答えを出します。

文字の範囲を `if` で何度も比べる代わりに、ビットの並びを使って判定しています。

## コード

```csharp:line-numbers=575
                ulong i = (uint)c - '0';
                ulong shift = 18428868213665201664UL << (int)i;
                ulong mask = i - 64;

                return (long)(shift & mask) < 0 ? true : false;
```

## 前提知識

- **ビット（0 と 1）**: 数を 2 進数で表したときの 1 桁です。`ulong` は 64 ビットの符号なし整数です。
- **ビットシフト（`<<`）**: 数のビットを左にずらす演算です。左にずらすと、右側に 0 が入ります。
- **ビット積（`&`）**: 両方のビットが 1 のときだけ 1 になる演算です。
- **符号ビット**: 最上位の 1 ビットです。このビットが 1 なら、符号付き整数では負の数になります。
- **文字コード**: `'0'` は 48、`'A'` は 65、`'a'` は 97 です。
- **アンダーフロー**: 符号なしの数で、0 より小さい値を引くと、大きな正の数に折り返される現象です。

## 何をしているか

### 1. 文字を 0 からの番号に直す

```csharp:line-numbers=575
                ulong i = (uint)c - '0';
```

`c` から `'0'`（48）を引いて、番号 `i` を作ります。`'0'` なら `0`、`'9'` なら `9`、`'A'` なら `17` になります。`'0'` より小さい文字は、符号なしの計算で大きな数に折り返されるため、範囲外として扱われます。

### 2. 定数をずらす

```csharp:line-numbers=576
                ulong shift = 18428868213665201664UL << (int)i;
```

定数 `18428868213665201664` を `i` 桁だけ左にずらします。ずらした結果の一番上のビットが、その文字が 16 進数の文字かどうかを表します。

定数のビットは、文字の番号に対応して並べてあります。`'0'` から `'f'` のうち、16 進数の文字に当たる位置だけが 1 です。

### 3. 範囲の印を作る

```csharp:line-numbers=577
                ulong mask = i - 64;
```

`i - 64` を `mask` にします。`i` が 0 から 63 の範囲なら、この値の一番上のビットは 1 になります。範囲外（`i` が 64 以上）なら、一番上のビットは 0 になります。

### 4. 符号を見て判定する

```csharp:line-numbers=579
                return (long)(shift & mask) < 0 ? true : false;
```

ずらした定数と `mask` のビット積の符号を調べます。符号ビットが 1 なら、文字が範囲内で、かつ 16 進数の文字です。

## ここがすごい

- **分岐がない**: `if` で文字の範囲を比べないので、入力の文字がどんな値でも、同じ速さで答えが出ます。
- **1 つの定数に全部入っている**: 22 個の文字の情報を、64 ビットの 1 つの数で表しています。
- **範囲外を自然に弾く**: 符号なしの引き算の折り返しと `mask` の作りで、`'0'` より小さい文字や、`'f'` より大きい文字を別の処理なしで除けます。

## まとめ

- 文字から `'0'` を引いて、番号を作る。
- 16 進数の文字の位置を 1 にした定数を、番号の分だけずらす。
- 符号ビットの 1 / 0 で、16 進数の文字かを判定する。
