## ひとことで

SipHash は、データから短い値（タグ）を作るためのハッシュ関数です。
その中心にあるのが、ここで説明する **1 ラウンド** です。4 つの 64 ビットの値（`v0` から `v3`）を、足し算、ビットの回転、XOR で混ぜ合わせます。

入力の 1 ビットが変わっただけで、結果が大きく変わるようにするのが目的です。

## コード

```csharp:line-numbers=115
                    v0 += v1;
                    v2 += v3;
                    v1 = v1 << 13 | v1 >> 51;
                    v3 = v3 << 16 | v3 >> 48;
                    v1 ^= v0;
                    v3 ^= v2;
                    v0 = v0 << 32 | v0 >> 32;
                    v2 += v1;
                    v0 += v3;
                    v1 = v1 << 17 | v1 >> 47;
                    v3 = v3 << 21 | v3 >> 43;
                    v1 ^= v2;
                    v3 ^= v0;
                    v2 = v2 << 32 | v2 >> 32;
```

## 前提知識

- **ハッシュ**: データから固定の長さの値を作る計算です。同じ入力からは同じ値が出ます。
- **XOR（`^`）**: 2 つのビットが違うときに 1 になる演算です。混ぜ合わせに使われます。
- **ビットの回転**: 左にずらしたビットと、はみ出たビットを右側に戻す操作です。`v << n | v >> (64 - n)` で、64 ビットを左に `n` 回転できます。
- **符号なし整数の溢れ**: `ulong` の足し算は、上限を超えると折り返します。`unchecked` の中で行うので、例外は起きません。
- **状態**: `v0` から `v3` の 4 つの値が、計算の途中の状態です。

## 何をしているか

### 1. 足し算で値を混ぜる

```csharp:line-numbers=115
                    v0 += v1;
                    v2 += v3;
```

`v0` に `v1` を足し、`v2` に `v3` を足します。足し算は、桁上がりによって、ビットの組み合わせを上の位へ広げます。

### 2. ビットを回転させる

```csharp:line-numbers=117
                    v1 = v1 << 13 | v1 >> 51;
                    v3 = v3 << 16 | v3 >> 48;
```

`v1` を 13 ビット、`v3` を 16 ビット回転させます。回転では、どのビットも捨てられずに残るので、情報が失われません。

### 3. XOR で混ぜ合わせる

```csharp:line-numbers=119
                    v1 ^= v0;
                    v3 ^= v2;
```

互いの値を XOR で混ぜます。足し算と XOR を交互に使うことで、ビットの流れが複雑になります。

### 4. 片方の値を半分ずつ入れ替える

```csharp:line-numbers=121
                    v0 = v0 << 32 | v0 >> 32;
```

`v0` を 32 ビット回転させます。上の半分と下の半分が入れ替わります。

### 5. 残りの組み合わせを混ぜる

```csharp:line-numbers=122
                    v2 += v1;
                    v0 += v3;
                    v1 = v1 << 17 | v1 >> 47;
                    v3 = v3 << 21 | v3 >> 43;
                    v1 ^= v2;
                    v3 ^= v0;
                    v2 = v2 << 32 | v2 >> 32;
```

ここまでと同じ流れで、足し算、回転、XOR を続けます。回転の量は、13、16、17、21、32 と、値ごとに違います。

## ここがすごい

- **分岐がない**: 足し算、回転、XOR だけで構成されているので、データの値によって処理の時間が変わりません。
- **ビットを捨てない**: 回転は、はみ出たビットを反対側に戻すので、情報が消えません。
- **小さな変化が広がる**: 足し算の桁上がりと、回転と XOR の組み合わせで、少しの違いが全体に伝わります。

## まとめ

- 足し算、回転、XOR を組み合わせて、4 つの値を混ぜる。
- 回転では情報が失われず、分岐もないので速い。
- この 1 ラウンドを何度も繰り返して、ハッシュの値を作る。
