## ひとことで

`NextPowerOf2(A)` は、`A` より**真に大きい**最小の 2 の累乗を返します。
`NextPowerOf2(5)` は `8`、`NextPowerOf2(8)` は `16`、`NextPowerOf2(0)` は `1` です。

ハッシュテーブルの大きさを 2 の累乗にそろえたいときなどに使われます。LLVM の `StringMap` も、必要なバケット数をこの関数で決めています。

## コード

::: code-group

```cpp:line-numbers=366 [日本語訳]
/// A より真に大きい次の 2 の累乗（64 ビット）を返す。
/// あふれたら 0 を返す。
constexpr uint64_t NextPowerOf2(uint64_t A) {
  A |= (A >> 1);
  A |= (A >> 2);
  A |= (A >> 4);
  A |= (A >> 8);
  A |= (A >> 16);
  A |= (A >> 32);
  return A + 1;
}
```

```cpp:line-numbers=366 [原文]
/// Returns the next power of two (in 64-bits) that is strictly greater than A.
/// Returns zero on overflow.
constexpr uint64_t NextPowerOf2(uint64_t A) {
  A |= (A >> 1);
  A |= (A >> 2);
  A |= (A >> 4);
  A |= (A >> 8);
  A |= (A >> 16);
  A |= (A >> 32);
  return A + 1;
}
```

## 前提知識

- **`constexpr`**: コンパイル時にも計算できる関数です。引数が定数なら、答えもコンパイル時に決まります。
- **`uint64_t`**: 符号なし 64 ビット整数です。
- **`A |= (A >> 1)`**: `A = A | (A >> 1)` の省略形です。`>>` は右シフト、`|` はビットごとの OR です。
- **2 の累乗と 2 進数**: 2 の累乗は 2 進数で `1000...0` のように 1 が 1 個だけの形です。そこから 1 引くと `0111...1` になります。

## 何をしているか

アイデアは「**最上位の 1 から下を全部 1 にすれば、`2^k - 1` の形になる。そこに 1 足せば `2^k`**」です。

### 1. 最上位ビットより下を塗りつぶす

```cpp:line-numbers=369
  A |= (A >> 1);
  A |= (A >> 2);
  A |= (A >> 4);
  A |= (A >> 8);
  A |= (A >> 16);
  A |= (A >> 32);
```

`A = 0b0101000`（40）で追ってみます。

```
A                 = 0101000
A |= A >> 1       = 0111100   ← 最上位の 1 が 2 個並んだ
A |= A >> 2       = 0111111   ← 4 個並んだ（ここで下まで届いた）
A |= A >> 4 以降   = 0111111   ← 変化なし
```

1 回目で最上位の 1 が「2 個並び」になり、2 回目でそれを 2 つずらして「4 個並び」、3 回目で「8 個並び」……と、**1 の並びが倍々に伸びて**いきます。
シフト量 1, 2, 4, 8, 16, 32 の 6 回で 64 個まで伸ばせるので、どんな 64 ビット値でも最上位から下が全部 1 になります。

### 2. 1 を足す

```cpp:line-numbers=375
  return A + 1;
```

```
0111111 + 1 = 1000000   （64）
```

40 より大きい最小の 2 の累乗、64 が得られました。

`A = 8`（`1000`）なら塗りつぶすと `1111`、足して `10000`（16）です。もとから 2 の累乗でも、**必ずそれより大きい**値が返ります。

### 3. あふれる場合

```cpp:line-numbers=367
/// あふれたら 0 を返す。
```

`A` の最上位ビット（2^63）が立っていると、塗りつぶし後は全ビット 1 になり、`+1` で一周して `0` になります。コメントにある「あふれたら 0 を返す」はこの性質です。符号なし整数の足し算は一周するのが規格で決まっているので、未定義動作ではありません。

## ここがすごい

素直に書くなら次のようになります。

```cpp
uint64_t P = 1;
while (P <= A) P <<= 1;
```

これは最悪 64 回ループします。この関数は**入力によらず 12 個の演算**（シフト 6 回と OR 6 回）と足し算 1 回で終わり、分岐もありません。

また、「1 の並びを倍々に伸ばす」発想は、ビット数の対数回で処理が終わる典型的な手法です。64 ビットだから 6 段、32 ビットなら 5 段で済みます。

なお、同じファイルには「`A` 以上の最小の 2 の累乗」を返す `PowerOf2Ceil` もあります。こちらは `Log2_64_Ceil` を使って計算します。**「より大きい」か「以上」か**で関数が分かれているのは、ハッシュテーブルの拡張（今より必ず大きくしたい）のような用途があるからです。

## まとめ

- `x |= x >> 1; x |= x >> 2; ...` で最上位ビットから下を全部 1 にできる。
- 「全部 1」に 1 足すと 2 の累乗になる。
- 倍々に処理範囲を広げると、ビット数の対数回で終わる。
- 符号なし整数のあふれは一周するだけなので、その性質を仕様として使える。
