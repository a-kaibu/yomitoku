## ひとことで

`decimal.at(i)` は、10 進数の桁のうち、`i` 番目の文字を取り出します。ただし、`i` が範囲の外にあれば、エラーにせずに `'0'` 相当の文字を返します。

この関数を使うと、呼び出す側は「桁の数が足りないかどうか」を気にせずに済みます。

## コード

```go:line-numbers=33
func (d *decimal) at(i int) byte {
	if 0 <= i && i < len(d.mant) {
		return d.mant[i]
	}
	return '0'
}
```

## 前提知識

- **`decimal` 型**: `math/big` が、浮動小数点数を 10 進数の文字列として扱うときに使う内部の型です。`mant`（仮数部の数字）と `exp`（小数点の位置）を持ちます。
- **`mant`**: 数字だけを並べた `[]byte` です。例えば `"123"` という値なら、`'1'`、`'2'`、`'3'` の 3 バイトが入ります。
- **範囲外アクセス**: 配列の長さより大きい番号や、負の番号で値を読むと、プログラムが止まってしまいます。これを防ぐ書き方が必要です。
- **`'0'` の文字**: 数字の 0 を表す文字です。コードの値は `48` で、数字の 0 の ASCII 文字です。

## 何をしているか

### 1. 範囲の中かを確かめる

```go:line-numbers=34
	if 0 <= i && i < len(d.mant) {
		return d.mant[i]
	}
```

`i` が 0 以上で、かつ `mant` の長さより小さいかを確かめます。両方を満たすときだけ、その位置の文字をそのまま返します。

ここで `0 <= i` と `i < len(d.mant)` の両方を見ることが大切です。負の番号も、長さを超える番号も、同じ判定で弾かれます。

### 2. 範囲の外なら 0 を返す

範囲の外のときは、`if` の中に入らず、次の行の値が返されます。この値は数字の `'0'` です。

範囲の外の桁は、数としては 0 と同じ意味になります。例えば `"12"` の 100 の位は 0 です。そのため、0 を返すことが正しい答えになります。

## ここがすごい

- **判定を 1 か所に集める**: 範囲を確かめる処理が、この関数だけにあります。呼び出す側が、同じ判定を繰り返す必要はありません。
- **数の意味を守る**: 範囲外を「エラー」ではなく「0」として扱うので、桁を揃えて計算するときにも、そのまま使えます。
- **短い関数で安全を守る**: 数行の中に、判定と既定の値の両方が入っています。読んでいても、何をするか迷いません。

## まとめ

- `at(i)` は、`i` 番目の桁の文字を返します。
- 範囲の外は、エラーにせず、数字の `'0'` として扱います。
- 範囲の判定を 1 か所にまとめているので、呼び出し側は安全に使えます。
