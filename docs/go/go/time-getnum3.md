## ひとことで

`getnum3(s, fixed)` は、文字列の先頭から、最大 3 桁の数字を読み取ります。例えば `"123abc"` からは `123` と `"abc"` を返します。

`fixed` が真のときは、ちょうど 3 桁であることを求めます。`"12"` のように 2 桁しかなければ、失敗になります。時刻の書式には、「必ず 3 桁で書く」という場合があるので、その区別が必要です。

## コード

```go:line-numbers=942
func getnum3(s string, fixed bool) (int, string, error) {
	var n, i int
	for i = 0; i < 3 && isDigit(s, i); i++ {
		n = n*10 + int(s[i]-'0')
	}
	if i == 0 || fixed && i != 3 {
		return 0, s, errBad
	}
	return n, s[i:], nil
}
```

## 前提知識

- **桁数の上限**: 数字を読む回数を決めておくと、長すぎる入力で読み過ぎることを防げます。ここでは 3 回までです。
- **`isDigit`**: 位置 `i` の文字が数字かを調べる、内部の関数です。
- **`fixed`**: 桁数をぴったり決めるかどうかを表す真偽値です。
- **`'0'` を引く**: 数字の文字から `'0'` を引くと、数字そのものの値になります。`'7' - '0'` は `7` です。

## 何をしているか

### 1. 最大 3 桁の数字を読む

```go:line-numbers=944
	for i = 0; i < 3 && isDigit(s, i); i++ {
		n = n*10 + int(s[i]-'0')
	}
```

位置 `i` を 0 から進めながら、数字が続く間、最大 3 回だけ読みます。読むたびに、今までの値を 10 倍して、新しい桁を足します。

### 2. 桁数が条件に合うかを確かめる

```go:line-numbers=947
	if i == 0 || fixed && i != 3 {
		return 0, s, errBad
	}
```

1 桁も読めなければ失敗です。`fixed` が真で、読んだ桁数が 3 でないときも失敗です。どちらのときも、元の文字列を返して、エラーを知らせます。

### 3. 数字と残りを返す

```go:line-numbers=950
	return n, s[i:], nil
```

読めた数字と、数字の後ろの残りの文字列を返します。残りは、次の書式の要素を読むために使われます。

## ここがすごい

- **読む量に上限がある**: 3 桁で止まるので、どんなに長い入力でも、必要以上に読みません。
- **同じ関数で 2 通りを扱う**: `fixed` の値で、「最大 3 桁」と「ちょうど 3 桁」を切り替えられます。
- **残りを返す**: 数字だけを取り出して、残りの文字列を次の読み取りに渡すので、書式を順番に読み進められます。

## まとめ

- `getnum3` は、最大 3 桁の数字を読み取ります。
- `fixed` が真なら、ちょうど 3 桁であることを求めます。
- 数字の値と、残りの文字列を返します。
