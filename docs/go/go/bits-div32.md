## ひとことで

`bits.Div32(hi, lo, y)` は、上位 `hi` と下位 `lo` の 32 ビット、合計 64 ビットの値を、32 ビットの `y` で割ります。戻り値は、商 `quo` と余り `rem` です。例えば `hi = 0`、`lo = 10`、`y = 3` なら、商は `3`、余りは `1` です。

大きな数の割り算を、より大きな整数型なしで書けるように、この関数があります。

## コード

```go:line-numbers=505
func Div32(hi, lo, y uint32) (quo, rem uint32) {
	if y != 0 && y <= hi {
		panic(overflowError)
	}
	z := uint64(hi)<<32 | uint64(lo)
	quo, rem = uint32(z/uint64(y)), uint32(z%uint64(y))
	return
}
```

## 前提知識

- **上位と下位**: 64 ビットの値を、32 ビットの 2 つに分けた表し方です。`hi` が上の 32 ビット、`lo` が下の 32 ビットです。
- **商の範囲**: 32 ビットの商に収まるように、`hi` が `y` より小さい必要があります。`hi >= y` だと、商は 32 ビットに入らなくなります。
- **シフトと OR**: `uint64(hi)<<32` は、`hi` を上の 32 ビットに移します。`| uint64(lo)` で、下の 32 ビットを入れます。
- **名前付き戻り値**: `(quo, rem uint32)` と書くと、`return` だけで結果を返せます。

## 何をしているか

### 1. 商があふれないかを確かめる

```go:line-numbers=506
	if y != 0 && y <= hi {
		panic(overflowError)
	}
```

`hi` 以上の除数で割ると、商が 32 ビットに収まりません。その場合はパニックします。`y == 0` のときは、Go の整数の割り算の規則に任せて、後の割り算でパニックさせます。

### 2. 64 ビットの値に組み立てて割る

```go:line-numbers=509
	z := uint64(hi)<<32 | uint64(lo)
	quo, rem = uint32(z/uint64(y)), uint32(z%uint64(y))
	return
```

`hi` を 32 ビット左にずらして、`lo` と OR します。これで 64 ビットの値 `z` ができます。`z` を `y` で割ると、商と余りが 64 ビットで求まります。商は、前の確認で 32 ビットに収まることが分かっているので、`uint32` に変換しても壊れません。

## ここがすごい

- **より大きな型なしで割る**: 64 ビットの整数型を使えば、普通に割り算ができます。`Div32` は、その 64 ビットの割り算を、32 ビットの 2 つの値から行う形にしています。
- **溢れを先に防ぐ**: 商が 32 ビットを超えるかどうかを、割る前に確かめています。結果が静かに壊れることを防ぎます。
- **商と余りを同時に**: 1 回の処理で、商と余りの両方を求めます。

## まとめ

- `Div32` は、64 ビットの値を 32 ビットの除数で割り、商と余りを返します。
- 上位が除数以上なら、商が 32 ビットに収まらないので、パニックします。
- 上位と下位を組み立てて、64 ビットの割り算として行います。
- 商と余りを同時に返します。
