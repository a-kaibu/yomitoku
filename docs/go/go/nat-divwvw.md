## ひとことで

`divWVW(z, xn, x, y)` は、大きな数 `x` を 1 ワードの数 `y` で割ります。商は `z` に書き込まれ、余りが返されます。`xn` は、一番上に付ける余りの初期値です。

大きな数を小さな数で割るのは、筆算と同じ流れです。上の桁から順に割って、余った分を次の桁に運びます。

## コード

```go:line-numbers=579
func divWVW(z []Word, xn Word, x []Word, y Word) (r Word) {
	r = xn
	if len(x) == 1 {
		qq, rr := bits.Div(uint(r), uint(x[0]), uint(y))
		z[0] = Word(qq)
		return Word(rr)
	}
	rec := reciprocalWord(y)
	for i := len(z) - 1; i >= 0; i-- {
		z[i], r = divWW(r, x[i], y, rec)
	}
	return r
}
```

## 前提知識

- **筆算の割り算**: 上の桁から順に割り、余りを次の桁に送って、同じ操作を繰り返します。`math/big` でも、この考え方をワード単位で行います。
- **商と余り**: 割り算の結果は、商（何回割れたか）と余り（割り切れなかった分）の 2 つです。
- **ワード**: 大きな数を分けて入れる、機械の整数の箱です。1 ワードの数で割ると、1 つの桁の割り算になります。
- **`bits.Div`**: 128 ビットの値を 64 ビットで割る、機械の割り算を行う関数です。

## 何をしているか

### 1. 割る数が 1 ワードなら専用の割り算を使う

```go:line-numbers=582
		qq, rr := bits.Div(uint(r), uint(x[0]), uint(y))
```

`x` が 1 ワードだけなら、`bits.Div` で、一回の割り算で商と余りを求めます。`r` は上の桁の余り、`x[0]` は下の桁の数です。

### 2. 割る数の逆数を先に作る

```go:line-numbers=586
	rec := reciprocalWord(y)
```

大きな数を何回も割るので、`y` の逆数を先に計算しておきます。逆数を使うと、毎回の割り算を、掛け算と調整で済ませられます。

### 3. 上の桁から順に割る

```go:line-numbers=587
	for i := len(z) - 1; i >= 0; i-- {
		z[i], r = divWW(r, x[i], y, rec)
	}
```

一番上の桁から、下の桁へ向かって、一つずつ割ります。`divWW` は、上の余り `r` と、今の桁 `x[i]` を合わせて割り、商を `z[i]` に、新しい余りを `r` に入れます。余りが次の桁の割り算へ渡されるので、筆算と同じ流れになります。

最後に `r` を返して、全体の余りを呼び出し側に伝えます。

## ここがすごい

- **余りを運ぶだけで全部つながる**: 桁ごとの割り算は独立しているように見えて、余りを渡すことで、全体の割り算が正しくなります。
- **逆数で速くする**: 同じ `y` で何度も割るので、逆数を最初に一度だけ作ります。割り算の回数が多いほど、この工夫が効きます。
- **1 ワードの特別扱い**: 割る数が 1 ワードのときは、ループを使わずに済む、専用の割り算を選びます。よくある場面を、速く処理できます。

## まとめ

- `divWVW` は、大きな数を 1 ワードの数で割り、商と余りを求めます。
- 上の桁から順に割り、余りを次の桁へ運びます。
- 割る数の逆数を先に作って、割り算を速くしています。
