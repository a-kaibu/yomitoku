## ひとことで

`separator(std)` は、秒の小数部を区切る記号を返します。通常は `.`（ピリオド）で、書式によっては `,`（カンマ）になります。例えば `12:00:01.5` と `12:00:01,5` の違いを決めるのがこの関数です。

書式の指定は、一つの整数に多くの情報を詰めて表されています。この関数は、その整数から、区切り記号を選ぶ情報だけを取り出します。

## コード

```go:line-numbers=503
func separator(std int) byte {
	if (std >> stdSeparatorShift) == 0 {
		return '.'
	}
	return ','
}
```

## 前提知識

- **書式の番号（std）**: 時刻の書式の種類を表す整数です。ビットに、種類や細かい指定が詰め込まれています。
- **`stdSeparatorShift`**: 区切り記号の指定が、何ビット目から始まるかを表す定数です。
- **ビットシフト**: `std >> stdSeparatorShift` は、整数を右にずらして、区切り記号の指定だけを残す操作です。
- **小数点とカンマ**: 数字の区切りに使われる記号です。国や書式によって、どちらを使うかが変わります。

## 何をしているか

### 1. 区切り記号の指定を取り出す

```go:line-numbers=504
	if (std >> stdSeparatorShift) == 0 {
		return '.'
	}
```

`std` を右にずらして、区切り記号の指定だけを取り出します。その値が 0 なら、通常の指定なので、ピリオド `.` を返します。

### 2. それ以外はカンマにする

```go:line-numbers=507
	return ','
```

指定が 0 でなければ、カンマ `,` を返します。ここでは、指定の値が 0 かどうか以外は気にしていません。

## ここがすごい

- **一つの整数に情報を詰める**: 書式の種類と区切り記号の指定を、同じ整数の中に分けて入れています。メモリを小さく保ちながら、多くの指定を表せます。
- **既定の値が先に来る**: 指定がないときの動きが、最初の `return` に書かれています。読み手は、最も普通の場合を最初に理解できます。
- **分岐が 1 つだけ**: 二つの記号を選ぶだけなので、判断の流れがとても単純です。

## まとめ

- `separator` は、秒の小数部を区切る記号を返します。
- 書式の整数から区切り記号の指定を取り出し、ピリオドかカンマを選びます。
- 既定の記号はピリオドです。
