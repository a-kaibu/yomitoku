## ひとことで

`r.seed(seed)` は、乱数生成器に種を設定します。生成器がまだなければ、種を使って新しく作ります。すでにあれば、作り直さずに、その中の種だけを変えます。

乱数生成器の作成は、少し手間がかかることがあります。同じものを使い回せるなら、作り直さない方が速くなります。この関数は、その違いを一つの分岐で扱います。

## コード

```go:line-numbers=545
func (r *lockedSource) seed(seed int64) {
	if r.s == nil {
		r.s = newSource(seed)
	} else {
		r.s.Seed(seed)
	}
}
```

## 前提知識

- **乱数生成器（source）**: 乱数の列を作り出す内部の仕組みです。種を与えると、その列の始まりが決まります。
- **`newSource`**: 種から、新しい乱数生成器を作る関数です。
- **`Seed` メソッド**: 既に作られた生成器に、新しい種を入れるメソッドです。
- **`nil` の判定**: まだ値が作られていないことを確かめるために使います。`r.s == nil` は、生成器がない状態です。

## 何をしているか

### 1. まだ生成器がなければ作る

```go:line-numbers=546
	if r.s == nil {
		r.s = newSource(seed)
	} else {
```

`r.s` が `nil` なら、まだ生成器が作られていません。種を渡して、新しく作ります。

### 2. 既にあれば種だけ変える

```go:line-numbers=549
		r.s.Seed(seed)
	}
```

生成器がすでにあるなら、作り直さずに、その中の種だけを変えます。これにより、生成器の作成の手間を省けます。

## ここがすごい

- **無駄な作成を避ける**: 生成器は一度作れば、あとは種だけを変えれば使い回せます。同じ仕組みの作成を、何度も繰り返しません。
- **遅延して作る**: 最初に使われるまで、生成器を作りません。使わない乱数の生成器は、メモリも取りません。
- **種の変更が同じ経路で**: 最初でも二回目以降でも、呼び出し側は同じ `seed` を使います。違いを、関数の中で吸収しています。

## まとめ

- `seed` は、生成器がなければ作り、あれば種だけを変えます。
- 生成器を作り直す手間を、必要な場合だけに抑えます。
- 呼び出し側は、最初でも二回目以降でも、同じ方法で種を設定できます。
