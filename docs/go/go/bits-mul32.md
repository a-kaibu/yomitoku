## ひとことで

`bits.Mul32(x, y)` は、`x * y` の結果を、上位 32 ビット `hi` と下位 32 ビット `lo` に分けて返します。たとえば `Mul32(0x10000, 0x10000)` は `hi = 1`、`lo = 0` です。

ふつうの `x * y` では、上位の 32 ビットは捨てられてしまいます。この関数は、捨てられる部分も返します。

## コード

```go:line-numbers=459
func Mul32(x, y uint32) (hi, lo uint32) {
	tmp := uint64(x) * uint64(y)
	hi, lo = uint32(tmp>>32), uint32(tmp)
	return
}
```

## 前提知識

- **積のビット数**: 32 ビットの値 2 つの積は、最大で 64 ビットになります。`0xFFFFFFFF * 0xFFFFFFFF` も 64 ビットに収まります。
- **`uint64(x) * uint64(y)`**: 先に 64 ビットに広げてから掛けると、積は途中で溢れません。
- **`hi` と `lo`**: 上位と下位のことです。128 ビットの積を、2 つの 64 ビットに分けるときの呼び名と同じ考え方です。

## 何をしているか

`x = 0x10000`、`y = 0x10000` で追います。

### 1. 64 ビットで掛ける

```go:line-numbers=460
	tmp := uint64(x) * uint64(y)
```

`0x10000 * 0x10000 = 0x100000000`（2 の 32 乗）です。32 ビットに収まらないので、ふつうの `uint32` では 0 になってしまいます。

### 2. 上と下に分ける

```go:line-numbers=461
	hi, lo = uint32(tmp>>32), uint32(tmp)
```

`tmp >> 32 = 1` が `hi` に、`uint32(tmp) = 0` が `lo` に入ります。結果は `hi = 1`、`lo = 0` です。

## ここがすごい

- **積の大きさを先に確かめている**: 32 ビット × 32 ビットは 64 ビットに収まる、という性質を使って、あふれのない計算にしています。特別なチェックは要りません。
- **1 回の掛け算で済む**: 筆算のように部分の積を何回も足すのではなく、広い型で 1 回掛けるだけです。CPU が 64 ビットの掛け算を持っていれば、速く終わります。
- **128 ビットの積の部品**: 32 ビットの積を 2 つの半分で返すので、より大きな数の掛け算を組み立てられます。`Mul64` などの元になる考え方です。

## まとめ

- 掛ける前に、積が収まるビット数を確かめると、あふれを避けられる。
- 広い型で掛けると、上位の部分も残せる。
- 結果を上下に分けて返すと、より大きな計算の部品になる。
