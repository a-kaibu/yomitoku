## ひとことで

`rotate(data, a, m, b)` は、配列の `data[a:m]`（ブロック A）と `data[m:b]`（ブロック B）の **順番を入れ替えます**。
`[1, 2, 3, 4, 5]` で A = `[1, 2]`、B = `[3, 4, 5]` なら、結果は `[3, 4, 5, 1, 2]` です。

一時的な配列にコピーすれば簡単ですが、この関数は **追加のメモリを使わずに**、同じ長さの範囲どうしの入れ替え（`swapRange`）を繰り返して実現します。`slices.SortStableFunc` の内部（`symMerge`）で使われています。

## コード

```go:line-numbers=466
func rotateOrdered[E cmp.Ordered](data []E, a, m, b int) {
	i := m - a
	j := b - m

	for i != j {
		if i > j {
			swapRangeOrdered(data, m-i, m, j)
			i -= j
		} else {
			swapRangeOrdered(data, m-i, m+j-i, i)
			j -= i
		}
	}
	// i == j
	swapRangeOrdered(data, m-i, m, i)
}
```

`swapRange(data, a, b, n)` は、`data[a:a+n]` と `data[b:b+n]` の要素を 1 つずつ入れ替える関数です（331 行目）。

## 前提知識

- **ジェネリクス `[E cmp.Ordered]`**: 比較できる型ならなんでも扱える、という型パラメータです。この関数自体は比較を使いませんが、同じファイルの他の関数とそろえて生成されています。
- **インプレース（その場で）**: 追加の配列を使わず、元の配列の中だけで要素を動かすことです。メモリを節約できます。
- **`i -= j`**: `i = i - j` の省略形です。
- **ユークリッドの互除法**: 2 つの数の最大公約数を「大きいほうから小さいほうを引く（割る）」を繰り返して求める方法です。この関数のループはそれとよく似た形をしています。

## 何をしているか

`i` は「まだ位置が決まっていない A の長さ」、`j` は「まだ位置が決まっていない B の長さ」です。

`[1, 2 | 3, 4, 5]`（`a=0`, `m=2`, `b=5`）で追います。最初 `i = 2`、`j = 3` です。

### 1 回目（i < j）

`swapRange(data, m-i=0, m+j-i=3, i=2)` で、`data[0:2]` と `data[3:5]` を入れ替えます。

```
[1, 2, 3, 4, 5] → [4, 5, 3, 1, 2]
```

B の末尾 2 つと A を入れ替えたので、`1, 2`（A）が最終位置に着きました。残りの問題は `[4, 5 | 3]` を回転させることです。`j = 3 - 2 = 1`。

### 2 回目（i > j）

`i = 2`、`j = 1`。`swapRange(data, m-i=0, m=2, j=1)` で `data[0]` と `data[2]` を入れ替えます。

```
[4, 5, 3, 1, 2] → [3, 5, 4, 1, 2]
```

`3` が先頭に着きました。`i = 2 - 1 = 1`。

### 3. 長さがそろったら最後の入れ替え（480 行目）

`i == j == 1` なので、`swapRange(data, m-1=1, m=2, 1)` で `data[1]` と `data[2]` を入れ替えて `[3, 4, 5, 1, 2]`。完成です。

## ここがすごい

- **追加メモリゼロ**: 一時配列を使わないので、安定ソートを「O(1) の追加メモリ」で実現する部品になります。巨大な配列でもメモリを余計に食いません。
- **互除法と同じ形**: 長いほうから短いほうを引いていく構造は、最大公約数を求めるユークリッドの互除法そのものです。毎回、短いブロックの分だけ要素が最終位置に確定するので、全体の入れ替え回数は要素数に比例する程度で済みます。
- **部品を小さく分けている**: 「同じ長さの範囲を入れ替える」という単純な部品（`swapRange`）を作り、それを組み合わせて回転という少し難しい操作を作っています。

回転の書き方には他に「A を反転、B を反転、全体を反転」という 3 回反転の方法もあり、こちらも追加メモリなしで書けます。

## まとめ

- 隣り合う 2 ブロックの入れ替え（回転）は、追加メモリなしで実現できる。
- 長いほうから短いほうを引いていく構造は、ユークリッドの互除法と同じ考え方。
- 単純な部品を組み合わせて、より複雑な操作を作ると読みやすく正しく書ける。
