## ひとことで

`r.int31n(n)` は、0 以上 `n` 未満の乱数を返します。普通なら、乱数を `n` で割った余りを使います。しかし、この関数は割り算を使わず、掛け算と桁のずらしだけで同じ範囲に写します。

ただし、この方法は、ある範囲の値が出やすくなる偏りを生みます。その偏りを消すために、必要な場合だけ乱数をやり直します。

## コード

```go:line-numbers=161
func (r *Rand) int31n(n int32) int32 {
	v := r.Uint32()
	prod := uint64(v) * uint64(n)
	low := uint32(prod)
	if low < uint32(n) {
		thresh := uint32(-n) % uint32(n)
		for low < thresh {
			v = r.Uint32()
			prod = uint64(v) * uint64(n)
			low = uint32(prod)
		}
	}
	return int32(prod >> 32)
}
```

## 前提知識

- **乱数の範囲**: 乱数は、ある数 `n` より小さい値だけを返すように作ることがよくあります。サイコロなら、1 から 6 の範囲です。
- **剰余による方法**: 乱数を `n` で割った余りを使えば、範囲に収まります。ただし、割り切れない場合は、小さい値が少しだけ多く出てしまう偏りがあります。
- **32 ビットの積**: 32 ビットの数どうしを掛けると、結果は 64 ビットに収まります。上位 32 ビットを取り出すと、`0` から `n-1` の範囲の値になります。
- **`prod >> 32`**: 積を 32 ビット右にずらすと、上位の 32 ビットだけが残ります。

## 何をしているか

### 1. 乱数に範囲を掛ける

```go:line-numbers=162
	v := r.Uint32()
	prod := uint64(v) * uint64(n)
```

乱数 `v` を 32 ビットで作り、`n` と掛けます。積は 64 ビットになります。ここでは、乱数の値を `0` から `2^32` までの区間として見て、それを `n` 倍に伸ばしている、と考えると分かりやすいです。

### 2. 偏りが出るかを確かめる

```go:line-numbers=165
	if low < uint32(n) {
		thresh := uint32(-n) % uint32(n)
		for low < thresh {
```

`low` は、積の下位 32 ビットです。`low` が `n` より小さいときだけ、偏りの可能性があるので、確かめます。`thresh` は、偏りが出る範囲の境目です。

`low` が `thresh` より小さい間は、偏りの範囲に入っているので、乱数をもう一度作り直します。

### 3. 答えを上位ビットから取る

```go:line-numbers=173
	return int32(prod >> 32)
```

最後に、積の上位 32 ビットを取り出して返します。これが `0` 以上 `n` 未満の値になります。

## ここがすごい

- **割り算がない**: 割り算は、掛け算よりずっと遅い処理です。この方法は、乱数を大量に作る場面で速く動きます。
- **偏りを正しく消す**: 普通の剰余よりも、判定が少し複雑です。その代わり、どの値も同じ確率で出るように、やり直しで調整しています。
- **やり直しはまれ**: 偏りの範囲に入るのは、ごく一部だけです。多くの場合、乱数は 1 回で決まります。

## まとめ

- `int31n` は、0 以上 `n` 未満の乱数を、掛け算で作ります。
- 割り算を使わないので、速く動きます。
- 偏りが出る場合だけ、乱数をやり直して、公平な結果にします。
