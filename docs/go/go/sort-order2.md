## ひとことで

`order2(data, a, b, swaps)` は、位置 `a` と `b` の要素を比べて、小さい方が前に来るように並べ直します。並べ直した後の 2 つの位置を、順番に返します。

入れ替えが起きたときは、`swaps` の値を 1 増やします。どれだけ入れ替えが起きたかを数えておくと、並びがどれくらい整っているかを、後で判断できます。

## コード

```go:line-numbers=298
func order2(data Interface, a, b int, swaps *int) (int, int) {
	if data.Less(b, a) {
		*swaps++
		return b, a
	}
	return a, b
}
```

## 前提知識

- **`Less(i, j)`**: 要素 `i` が要素 `j` より小さいかを返すメソッドです。`sort.Interface` の一部です。
- **順番の入れ替え**: 2 つの位置の値を、入れ替えることです。ここでは、`data` の中身を直接動かしません。位置の番号だけを入れ替えて返します。
- **`swaps *int`**: 入れ替えの回数を数えるための、ポインタです。関数の中で増やすと、呼び出し側にその結果が残ります。
- **複数の戻り値**: 2 つの位置を、まとめて返す書き方です。

## 何をしているか

### 1. 後ろの要素が小さいかを比べる

```go:line-numbers=299
	if data.Less(b, a) {
		*swaps++
		return b, a
	}
```

`b` の要素が `a` より小さいなら、順番を入れ替える必要があります。`*swaps++` で入れ替えの回数を増やし、`b` と `a` の位置を逆に返します。

### 2. 入れ替えが不要ならそのまま返す

```go:line-numbers=303
	return a, b
```

`b` が `a` より小さくなければ、今の並びで正しいので、位置はそのままです。

## ここがすごい

- **比べると同時に記録**: 比較と入れ替えの回数の記録が、同じ場所で行われます。別々の処理で数え忘れる心配がありません。
- **位置だけを返す**: 中身を入れ替える代わりに、どの位置が前か後かを返します。呼び出し側が、その結果をもとに、続きの並べ替えを行えます。
- **中央値の計算に使える**: 前の記事の `median` は、この関数を 3 回呼んで中央値を決めます。小さな部品を組み合わせて、大きな処理を作っています。

## まとめ

- `order2` は、2 つの位置を比べて、小さい方が前に来るように返します。
- 入れ替えたときは、`swaps` を 1 増やします。
- 中央値の計算など、より大きな処理の部品として使われます。
