## ひとことで

`math.Floor(-2.5)` は `-3` を返します。床関数（フロア）は、小数を超えない最大の整数を求める関数です。正の数では小数部分を捨てるだけですが、負の数では、少し下へ動かす必要があります。

## コード

```go:line-numbers=21
func floor(x float64) float64 {
	if x == 0 || IsNaN(x) || IsInf(x, 0) {
		return x
	}
	if x < 0 {
		d, fract := Modf(-x)
		if fract != 0.0 {
			d = d + 1
		}
		return -d
	}
	d, _ := Modf(x)
	return d
}
```

## 前提知識

- **`Modf`**: 数を整数部分と小数部分に分けて返す関数です。`Modf(2.5)` は `2` と `0.5` を返します。
- **床関数の意味**: 2.5 の床は 2 で、-2.5 の床は -3 です。負の数では、整数部分の方向へ切ると、値が大きくなってしまいます。
- **`IsNaN` と `IsInf`**: 数でない値と、無限大の値を判定する関数です。こうした値は、そのまま返します。
- **符号の反転**: `-x` で正の数にしてから処理し、最後に符号を戻します。

## 何をしているか

### 1. 特別な値はそのまま返す

```go:line-numbers=22
	if x == 0 || IsNaN(x) || IsInf(x, 0) {
		return x
	}
```

0、NaN、無限大は、切り捨てても結果が変わらないか、意味を持たないものです。そのまま `x` を返します。

### 2. 負の数は正の数に直して処理する

```go:line-numbers=25
	if x < 0 {
		d, fract := Modf(-x)
		if fract != 0.0 {
			d = d + 1
		}
		return -d
```

`Modf(-x)` で、正の数の整数部分 `d` と小数部分 `fract` を取り出します。小数部分が 0 でなければ、`d` を 1 増やします。最後に `-d` を返すと、負の数の床になります。たとえば -2.5 は、2.5 の整数部分 2 に 1 を足して 3 となり、-3 を返します。

### 3. 正の数は整数部分を返す

```go:line-numbers=32
	d, _ := Modf(x)
	return d
```

正の数なら、`Modf(x)` の整数部分をそのまま返します。小数部分を捨てることが、床の値になります。

## ここがすごい

- **符号で処理を分ける**: 負の数だけ特別に扱うので、正の数の処理は最も単純になります。
- **小数部分の有無を見る**: 小数部分が 0 なら、そのまま整数です。0 でないときだけ 1 足すので、余計な 1 を足しません。
- **特別な値を最初に外す**: NaN や無限大を先に返すので、後の計算で意味のない値を扱いません。

## まとめ

- 特別な値（0、NaN、無限大）は、そのまま返す。
- 負の数は、符号を反転してから小数部分の有無で 1 足し、戻す。
- 正の数は、整数部分を返すだけで床になる。
