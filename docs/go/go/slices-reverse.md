## ひとことで

`slices.Reverse(s)` は、スライス `s` の要素の並びを逆にします。`[1, 2, 3, 4]` は `[4, 3, 2, 1]` になります。新しいスライスは作らず、元のスライスを書き換えます。

関数の中身は `for` 文 1 つだけです。先頭と末尾から中央に向かって、要素を 1 組ずつ入れ替えます。

## コード

```go:line-numbers=483
func Reverse[S ~[]E, E any](s S) {
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		s[i], s[j] = s[j], s[i]
	}
}
```

## 前提知識

- **ジェネリクス `[S ~[]E, E any]`**: `E` は要素の型、`S` はスライスの型を表す型パラメータです。`any` はどんな型でもよいという意味で、`int` のスライスでも `string` のスライスでも同じコードが使えます。
- **多重代入 `i, j = i+1, j-1`**: 2 つの変数を同時に更新します。右辺は先に全部計算されてから代入されるので、`i` と `j` を別々に書き換えるより、ずれの心配が少ないです。
- **`len(s)-1`**: 最後の要素の添字です。空のスライスでは `-1` になりますが、その場合は `i < j` が最初から偽なので、ループは回りません。

## 何をしているか

`s = [1, 2, 3, 4]` で追います。

### 1. 両端から中央へ向かう

```go:line-numbers=484
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		s[i], s[j] = s[j], s[i]
	}
```

最初は `i = 0`、`j = 3` です。`s[0]` と `s[3]` を入れ替えて `[4, 2, 3, 1]` になります。次は `i = 1`、`j = 2` で、`s[1]` と `s[2]` を入れ替えて `[4, 3, 2, 1]` です。

### 2. 中央で止まる

`i = 2`、`j = 1` になると `i < j` が偽になり、ループが終わります。要素数が奇数のときは、真ん中の要素は `i == j` で止まり、入れ替える相手がいません。そのまま正しい位置にあるので、問題はありません。

## ここがすごい

- **半分だけ回る**: 全要素を 1 つずつ別の場所へ移すと、コピー用の領域が必要になります。両端から入れ替えれば、ループは要素数の半分で済み、追加の領域も要りません。
- **多重代入で 1 行に**: `s[i], s[j] = s[j], s[i]` は、一時変数を使わずに 2 つの値を入れ替えます。右辺が先に評価されるので、一時変数がなくても安全です。
- **型に縛られない**: `any` を使って、要素の型を問いません。同じ関数を `int`、`string`、構造体のスライスに使えます。

## まとめ

- 両端から中央へ向かって入れ替えると、半分の回数で反転できる。
- 多重代入を使うと、一時変数なしで要素を入れ替えられる。
- ジェネリクスを使うと、要素の型ごとに関数を書き分けなくてよい。
