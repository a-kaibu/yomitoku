## ひとことで

`get2(b)` は、バイト列 `b` の先頭 2 バイトを、一つの整数として読みます。`b` が 2 バイトより短いときは、読まずに 0 を返します。

## コード

```go:line-numbers=394
func get2(b []byte) int {
	if len(b) < 2 {
		return 0
	}
	return int(b[0]) | int(b[1])<<8
}
```

## 前提知識

- **リトルエンディアン**: 数の下の桁のバイトを、並びの先頭に置く書き方です。`b[0]` が最も小さい位になります。
- **時間帯データ**: タイムゾーンの情報を保存したファイルです。短い数値は、この 2 バイトの形で並んでいます。
- **get4 との関係**: 同じ時間帯データの中で、4 バイトを読む `get4` と並んで使われる、短い版です。

## 何をしているか

### 1. 長さを確かめる

```go:line-numbers=395
	if len(b) < 2 {
		return 0
	}
```

2 バイトに満たないと、`b[1]` を読めません。読むとパニックするので、先に確かめて 0 を返します。

### 2. 2 バイトを組み合わせる

```go:line-numbers=398
	return int(b[0]) | int(b[1])<<8
```

`b[0]` を下の 8 ビット、`b[1]` を上の 8 ビットに置いて、`|` で合わせます。結果は `int` として返します。

## ここがすごい

- **読めない場合を値で返す**: 長さが足りないときは 0 を返すので、呼び出し側は、パニックを心配せずに使えます。
- **式が一行で済む**: 二つの位を並べて書くだけなので、どの位に何が入るかが、そのまま見えます。

たとえば `b` が `0x34, 0x12` なら、`0x34` が下の 8 ビット、`0x12` が上の 8 ビットになり、結果は `0x1234` になります。読むバイトは先頭の 2 つだけなので、後ろに続くデータは読まれません。

## まとめ

- `get2` は、先頭 2 バイトを整数として読みます。
- 足りなければ 0 を返します。
- 下の桁のバイトが先頭に来る、リトルエンディアンで読みます。
