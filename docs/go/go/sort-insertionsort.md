## ひとことで

`insertionSort(data, a, b)` は、`a` から `b` の手前までの要素を、小さい順に並べ替えます。トランプを手札に加えるときに、隣と比べて正しい位置に差し込む、あの動きと同じです。

`sort` パッケージは、データの数が少ないときに、大がかりなソートではなく、この単純な方法を使います。単純なほど、小さなデータでは速いからです。

## コード

```go:line-numbers=10
func insertionSort(data Interface, a, b int) {
	for i := a + 1; i < b; i++ {
		for j := i; j > a && data.Less(j, j-1); j-- {
			data.Swap(j, j-1)
		}
	}
}
```

## 前提知識

- **`Interface`**: `Len`、`Less`、`Swap` の 3 つのメソッドを持つ型です。`sort` は、この約束だけで、どんな並びでもソートできます。
- **`Less(i, j)`**: 要素 `i` が要素 `j` より小さいかを返します。
- **`Swap(i, j)`**: 要素 `i` と要素 `j` の位置を入れ替えます。
- **整っている部分**: 先頭から見て、すでに小さい順に並んでいる部分です。挿入ソートは、この部分を少しずつ広げていきます。

## 何をしているか

### 1. 次に入れる要素を選ぶ

```go:line-numbers=11
	for i := a + 1; i < b; i++ {
```

`i` は、これから整っている部分へ入れる要素の位置です。最初の要素 `a` は、1 つだけなので整っているとみなして、`a + 1` から始めます。

### 2. 正しい位置まで入れ替えながら戻す

```go:line-numbers=12
		for j := i; j > a && data.Less(j, j-1); j-- {
			data.Swap(j, j-1)
		}
```

`j` は、今入れている要素の位置です。前の要素 `j-1` より小さい間は、2 つを入れ替えて、`j` を 1 つ前へ戻します。前の要素より小さくなくなったら、そこが正しい位置なので止まります。

`j > a` の判定があるので、先頭を超えて戻ることはありません。

## ここがすごい

- **書き方が短い**: 2 重の `for` と 1 回の `Swap` だけで、ソートが完成します。読んでそのまま理解できる形です。
- **整っていると速い**: すでに正しい並びなら、`Less` が一度も真にならず、ループは一度ずつ回るだけで終わります。ほぼ整っているデータには強いです。
- **データが少ないと有利**: 数十個程度の小さな並びでは、複雑な方法よりも、この単純な方法の方が速く終わることが多いです。だから、`sort` は小さい範囲でこれを使います。

## まとめ

- `insertionSort` は、要素を 1 つずつ、整っている部分の正しい位置へ差し込みます。
- 前の要素と比べて小さい間だけ、入れ替えながら戻します。
- 小さいデータや、ほぼ整っているデータで効果を発揮します。
