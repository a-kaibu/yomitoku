## ひとことで

`math.Trunc(x)` は、浮動小数点数 `x` の小数部分を切り捨てて、整数部分を返します（0 に向かって丸める）。`Trunc(3.7)` は `3`、`Trunc(-3.7)` は `-3` です。

`trunc` はその汎用実装で、**浮動小数点数のビット表現のうち、小数部分を表すビットを 0 にする** ことで答えを出します。足し算も割り算も使いません。

## コード

::: code-group

```go:line-numbers=68 [日本語訳]
func trunc(x float64) float64 {
	if Abs(x) < 1 {
		return Copysign(0, x)
	}

	b := Float64bits(x)
	e := uint(b>>shift)&mask - bias

	// 上位 12+e ビット（整数部分）を残し、残りを消す。
	if e < 64-12 {
		b &^= 1<<(64-12-e) - 1
	}
	return Float64frombits(b)
}
```

```go:line-numbers=68 [原文]
func trunc(x float64) float64 {
	if Abs(x) < 1 {
		return Copysign(0, x)
	}

	b := Float64bits(x)
	e := uint(b>>shift)&mask - bias

	// Keep the top 12+e bits, the integer part; clear the rest.
	if e < 64-12 {
		b &^= 1<<(64-12-e) - 1
	}
	return Float64frombits(b)
}
```

:::

`shift = 52`、`mask = 0x7FF`、`bias = 1023` は同じパッケージで定義された定数です（`float64` の仮数のビット数、指数のマスク、指数のゲタ）。

## 前提知識

- **`float64` のビット**: 最上位 1 ビットが符号、次の 11 ビットが指数、残り 52 ビットが仮数（有効数字）です。値は `1.仮数 × 2^(指数 - 1023)` と表されます。1023 は「ゲタ（bias）」で、負の指数を表すために足してあります。
- **仮数のビットと整数部分**: 指数が `e` なら、`1.仮数` のうち小数点から上の `e` ビットが整数部分、それより下が小数部分になります。
- **`Copysign(0, x)`**: `x` と同じ符号の 0（`+0` か `-0`）を返します。
- **`&^=`**: AND NOT して代入します。`b &^= m` は「`m` が 1 の位置のビットを `b` から消す」です。
- **`1<<k - 1`**: 下位 `k` ビットがすべて 1 の値です。

## 何をしているか

### 1. 絶対値が 1 未満なら 0

```go:line-numbers=69
	if Abs(x) < 1 {
		return Copysign(0, x)
	}
```

`0.7` も `-0.7` も整数部分は 0 です。ただし符号は保って `+0` か `-0` を返します。

### 2. 指数を取り出す

```go:line-numbers=73
	b := Float64bits(x)
	e := uint(b>>shift)&mask - bias
```

`x = 5.75` で追います。5.75 は 2 進数で `101.11`、つまり `1.0111 × 2^2` なので、指数 `e = 2` です。
ビット表現から指数部を取り出し、ゲタ 1023 を引いて `e = 2` を得ます。

### 3. 小数部分のビットを消す

```go:line-numbers=77
	if e < 64-12 {
		b &^= 1<<(64-12-e) - 1
	}
```

符号 1 ビット + 指数 11 ビット = 12 ビットの後に、仮数 52 ビットが並んでいます。整数部分は仮数の上位 `e = 2` ビットです。
つまり、上から `12 + e = 14` ビットを残し、下の `64 - 12 - 2 = 50` ビットを 0 にすればよいのです。

```
1.0111 × 2^2  →  仮数の上位 2 ビット（01）だけ残す  →  1.01 × 2^2 = 101 = 5
```

`e` が 52 以上（コメントでは `64-12` と比較）なら、小数部分のビットはもう存在しない（すでに整数）ので、何もしません。

### 4. float64 に戻す

```go:line-numbers=80
	return Float64frombits(b)
```

## ここがすごい

- **整数への変換を使わない**: `float64(int64(x))` で切り捨てる方法もありますが、`int64` の範囲を超える大きな数（1e300 など）では壊れます。ビットを直接いじる方法なら、どんな大きさの数でも正しく動きます。
- **符号の扱いが自然**: 符号ビットには触らないので、負の数でも「0 に向かって」正しく切り捨てられます。`-5.75` は `-5` になります。
- **NaN と無限大もそのまま**: 指数部がすべて 1 の NaN や無限大は、`e` が大きくなるので入らず、そのまま返ります。特別な `if` を書かずに正しく扱えています。
- **CPU 命令の代わり**: 多くの CPU には切り捨て命令があり、Go はそれを使う実装を別に持っています。この関数は、そうした命令がないときのための汎用版です。

## まとめ

- `float64` では、指数から「仮数のどこまでが整数部分か」がわかる。
- 小数部分のビットをマスクで消せば、切り捨てができる。
- 整数型への変換を使う方法は範囲外の大きな数で壊れるが、ビット操作なら安全。
