## ひとことで

`addTo(z, x)` は、整数 `z` に、整数 `x` を足し込みます。結果は、新しい配列を作らずに、`z` の中に直接書き込まれます。`z` は、`x` より長いか、同じ長さであることが前提です。

大きな数どうしの足し算は、筆算と同じように、下の桁から順に行います。足し算の結果が桁をあふれたときだけ、上の桁に繰り上がりを送ります。

## コード

```go:line-numbers=233
func addTo(z, x nat) {
	if n := len(x); n > 0 {
		if c := addVV(z[:n], z[:n], x[:n]); c != 0 {
			if n < len(z) {
				addVW(z[n:], z[n:], c)
			}
		}
	}
}
```

## 前提知識

- **ワード**: 大きな整数を分けて入れる箱です。足し算は、ワード単位で行います。
- **繰り上がり（carry）**: ワードの上限を超えたときに、上の桁へ送る 1 です。筆算の繰り上がりと同じ考え方です。
- **`addVV`**: 同じ長さの 2 つの配列を、下の桁から足す関数です。最後に出た繰り上がりを返します。
- **`addVW`**: 配列に、1 ワードの値を足す関数です。ここでは、残った繰り上がりを、上の桁へ送るために使います。

## 何をしているか

### 1. 短い方の長さを使う

```go:line-numbers=234
	if n := len(x); n > 0 {
```

`x` の長さを `n` として、`n` が 0 でないときだけ処理をします。`x` が空なら、足すものがないので何もしません。

### 2. 下の桁から足す

```go:line-numbers=235
		if c := addVV(z[:n], z[:n], x[:n]); c != 0 {
```

`z` の下の `n` 個と、`x` の全部を、下の桁から足します。`addVV` は、足し算の結果と、最後に出た繰り上がり `c` を返します。

`c` が 0 なら、上の桁への繰り上がりはないので、ここで終わります。

### 3. 上の桁へ繰り上がりを送る

```go:line-numbers=236
			if n < len(z) {
				addVW(z[n:], z[n:], c)
			}
```

`z` の方が長ければ、残りの上の桁に対して、繰り上がり `c` を 1 ワードの値として足します。`z` の長さが `n` 以下なら、送る先がないので何もしません。

## ここがすごい

- **結果を直接書き込む**: 新しい配列を作らず、`z` の中を書き換えます。大きな数の計算では、メモリの確保を減らすことが速さにつながります。
- **繰り上がりを必要な時だけ送る**: 繰り上がりが 0 のときは、上の桁の計算を省きます。多くの場合、上の桁まで伝わる繰り上がりは少ないので、無駄がありません。
- **筆算の流れをそのまま使う**: 下の桁から順に足して、あふれたものを上へ送る。人が紙の上で行う方法を、そのまま機械の処理にしています。

## まとめ

- `addTo` は、`x` を `z` に足し込みます。結果は `z` に直接入ります。
- 下の桁から足して、繰り上がりが出たときだけ、上の桁に送ります。
- 余計な配列を作らないので、大きな数の計算でも効率よく動きます。
