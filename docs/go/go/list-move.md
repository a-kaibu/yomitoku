## ひとことで

`container/list` は、前と後ろの両方へつながる **双方向連結リスト** です。`move(e, at)` は、リストの要素 `e` を取り外して、要素 `at` の後ろへ差し込み直します。並べ替えや、LRU キャッシュ（最近使ったものを前に寄せる仕組み）などで使われる操作です。

この関数は、要素のデータをコピーせず、つながりを表す矢印（ポインタ）の付け替えだけで移動を終わらせます。

## コード

```go:line-numbers=118
func (l *List) move(e, at *Element) {
	if e == at {
		return
	}
	e.prev.next = e.next
	e.next.prev = e.prev

	e.prev = at
	e.next = at.next
	e.prev.next = e
	e.next.prev = e
}
```

## 前提知識

- **連結リスト**: 要素が「次」と「前」を指すポインタを持ち、それをたどって並びを表すデータ構造です。配列と違い、真ん中の要素を外したり差し込んだりするのが安くできます。
- **`*Element`**: 要素を指すポインタです。`e.next` は次の要素、`e.prev` は前の要素を指します。
- **番兵（sentinel）**: 実際のデータを持たない特別な要素 `l.root` です。リストの先頭と末尾をこの要素につなぐので、「先頭だから前がない」などの特別扱いが不要になります。
- **`if e == at`**: ポインタ同士を比べると、同じ要素を指しているかがわかります。

## 何をしているか

リストが `A ⇄ B ⇄ C ⇄ A`（番兵を含めた輪）で、`B` を `C` の後ろへ移すとします。

### 1. 今の場所から外す

```go:line-numbers=122
	e.prev.next = e.next
	e.next.prev = e.prev
```

`B` の前の `A` は、次を `C` にします。`B` の次の `C` は、前を `A` にします。こうすると、`B` は誰からも指されなくなります。

### 2. 差し込む先に合わせる

```go:line-numbers=125
	e.prev = at
	e.next = at.next
```

`B` の前を `at`（`C`）、次を `at` の次（`A`）にします。まだ `at` や `A` からは `B` を指していません。

### 3. 両側からつなぎ直す

```go:line-numbers=127
	e.prev.next = e
	e.next.prev = e
```

`C` の次を `B`、`A` の前を `B` にします。これで `A ⇄ C ⇄ B ⇄ A` となり、移動が完了します。

### 同じ場所へ移す場合

`e == at` のとき、何もせずに戻ります。

```go:line-numbers=119
	if e == at {
		return
	}
```

もしこの確認がないと、手順 1 で外した `e` を、手順 2 で `e` 自身の前にしてしまい、自分を指すループができてしまいます。

## ここがすごい

- **番兵のおかげで分岐がほぼない**: 先頭や末尾に要素があるかを調べる `if` が要りません。どの要素も必ず前と次を持つので、4 行の代入だけで正しく動きます。
- **データを動かさない**: 要素の中身（`Value`）はコピーしません。ポインタを付け替えるだけなので、大きなデータを入れていても移動は一定の時間で終わります。
- **自分自身への移動を特別扱い**: 1 行の `if` で、移動の途中で壊れる場合を防いでいます。「何もしないことが正しい場合」を先に書くのは、この種の操作で大切な考え方です。

## まとめ

- 双方向リストの移動は、外す 2 行と差し込む 4 行、計 6 行の付け替えで済む。
- 番兵を置くと、端の場合の特別扱いが消えて、コードが短くなる。
- 同じ場所への移動など、途中で壊れる場合は先に確かめる。
