## ひとことで

`ExpFloat64` は、指数分布に従う乱数を返します。指数分布は、待ち時間（次の客が来るまでの時間など）をモデル化するときに使われます。値が小さいほど出やすく、大きな値は少ないという分布です。

この実装は、**ziggurat 法** という方法を使います。曲線の下を、いくつかの長方形で覆う表を用意しておき、ほとんどの乱数は、表の中で 1 回の比較だけで決まります。

## コード

```go:line-numbers=30
func (r *Rand) ExpFloat64() float64 {
	for {
		u := r.Uint64()
		j := uint32(u)
		i := uint8(u >> 32)
		x := float64(j) * float64(we[i])
		if j < ke[i] {
			return x
		}
		if i == 0 {
			return re - math.Log(r.Float64())
		}
		if fe[i]+float32(r.Float64())*(fe[i-1]-fe[i]) < float32(math.Exp(-x)) {
			return x
		}
	}
}
```

## 前提知識

- **指数分布**: 確率の密度が `e^(-x)` で減っていく分布です。平均が 1 の乱数を作るときの基礎になります。
- **ziggurat 法**: 確率分布の曲線の下を、長方形（段）の積み重ねで覆う方法です。ある段の中の点は、そのまま採用できます。段からはみ出した点だけ、追加の計算をします。
- **表 `ke`、`we`、`fe`、`re`**: 段の境界、幅、高さ、尾の位置を入れた定数の表です。この記事では細かい値は省きます。
- **`r.Uint64()`**: 64 ビットの乱数を 1 つ返します。ここでは、下位 32 ビットを値に、上位 8 ビットを段の番号に使います。

## 何をしているか

### 1. 乱数から段と値を取り出す

```go:line-numbers=35
		x := float64(j) * float64(we[i])
		if j < ke[i] {
			return x
		}
```

乱数の下位 32 ビット `j` を、段の幅 `we[i]` で掛けて、候補の値 `x` を作ります。`j` が段の内側の境界 `ke[i]` より小さければ、その点は曲線の下に確実に入っているので、即座に `x` を返します。ほとんどの場合は、ここで決まります。

### 2. 一番下の段は尾の処理

```go:line-numbers=39
		if i == 0 {
			return re - math.Log(r.Float64())
		}
```

段の番号が 0 の段は、曲線の尾の部分を含みます。ここでは、対数を使って尾の値を作ります。`re` は、尾が始まる位置です。ほとんど使われないので、速さより正しさを重視しています。

### 3. 段の境目の判定

```go:line-numbers=42
		if fe[i]+float32(r.Float64())*(fe[i-1]-fe[i]) < float32(math.Exp(-x)) {
			return x
		}
```

段の境目の近くの点は、確率の曲線の中かどうかを、`e^(-x)` と比べて確かめます。曲線の中なら採用し、そうでなければ、もう一度乱数を引き直します。`for` ループが、その再試行を行います。

## ここがすごい

- **ほとんどは 1 回の掛け算で決まる**: 指数の計算は重いので、表を使って避けています。大半の乱数で、対数も指数も計算しません。
- **棄却の仕組みで正しさを保つ**: 段からはみ出した点だけ、曲線との比較をして採用か棄却かを決めます。これで、分布の形が正確に保たれます。
- **1 つの乱数から複数の情報を取る**: 64 ビットの乱数を、段の番号と値に分けて使うので、乱数を無駄にしません。

## まとめ

- `ExpFloat64` は、指数分布に従う乱数を作ります。
- ziggurat 法で、ほとんどの値は表と掛け算だけで決まります。
- 段の外の点は、曲線との比較で採用か棄却かを決めます。
- 尾の部分だけ対数を使い、正しい分布を保ちます。
