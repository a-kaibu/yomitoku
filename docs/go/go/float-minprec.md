## ひとことで

`x.MinPrec()` は、`x` の値を誤差なしで表すのに必要な、最小の精度（ビット数）を返します。例えば `1.0` は、1 ビットの精度で表せます。`0.1` のように、2 進数で割り切れない値は、もっと多くのビットが必要になります。

浮動小数点数の精度は、大きければ細かい値を表せます。この関数を使うと、値を失わずに保存できる最小限の精度が分かります。

## コード

```go:line-numbers=217
func (x *Float) MinPrec() uint {
	if x.form != finite {
		return 0
	}
	return uint(len(x.mant))*_W - x.mant.trailingZeroBits()
}
```

## 前提知識

- **仮数（mant）**: 浮動小数点数の有効数字の部分です。2 進数のビットで表されます。
- **精度（prec）**: 仮数が何ビットまで覚えられるかを表す値です。
- **末尾の 0 ビット**: 仮数の一番下の位にある 0 です。`1000` の末尾の `000` が、これに当たります。末尾の 0 は、値を表すのに必要ありません。
- **有限（finite）**: 値が普通の数であることを表す区分です。無限大や 0 は、仮数を持たないか、特別な形で表されます。

## 何をしているか

### 1. 有限の値だけを対象にする

```go:line-numbers=218
	if x.form != finite {
		return 0
	}
```

値が有限でなければ、仮数を使わないので、0 を返します。無限大や 0 は、精度を必要としないからです。

### 2. 全体のビット数から末尾の 0 を引く

```go:line-numbers=221
	return uint(len(x.mant))*_W - x.mant.trailingZeroBits()
```

仮数の配列の長さに、1 ワードのビット数 `_W` をかけて、全体のビット数を求めます。そこから、末尾にある 0 ビットの数 `trailingZeroBits()` を引きます。

残った部分が、値を表すのに必要な最小のビット数です。末尾の 0 は、無くても値が変わらないので、引いて構いません。

## ここがすごい

- **無駄な精度を省ける**: 値を保存するときに、必要以上の精度を使っていないかを確かめられます。例えば `1.0` を 1000 ビットで持つ必要はありません。
- **ワードの単位で計算する**: 末尾の 0 を、1 ビットずつ数えるのではなく、ワードの単位で数えます。大きな数でも、速く答えが出ます。
- **有限と特別な値を分ける**: 無限大や 0 を先に弾くので、仮数を読む処理が、安全に行えます。

## まとめ

- `MinPrec` は、値を誤差なしで表すための、最小のビット数を返します。
- 有限の値だけが対象です。無限大や 0 は 0 を返します。
- 仮数の末尾にある 0 ビットを除いて計算します。
