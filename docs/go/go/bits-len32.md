## ひとことで

`bits.Len32(1)` は `1`、`bits.Len32(255)` は `8`、`bits.Len32(256)` は `9` を返します。最上位の 1 のビットが、右から何番目にあるかを表します。0 の場合は `0` です。

## コード

```go:line-numbers=324
func Len32(x uint32) (n int) {
	if x >= 1<<16 {
		x >>= 16
		n = 16
	}
	if x >= 1<<8 {
		x >>= 8
		n += 8
	}
	return n + int(len8tab[uint8(x)])
}
```

## 前提知識

- **ビット長**: 値を 2 進数で書いたときの桁数です。`5` は `101` なので、ビット長は 3 です。
- **`len8tab`**: 0 から 255 までの、ビット長を前もって並べた表です。8 ビットの値なら、表を引くだけで答えが出ます。
- **右シフト `>>`**: 値を右へずらして、上位のビットを下位に移します。
- **段階的な判定**: 上位が 0 なら、その分を捨てられるという考え方です。

## 何をしているか

### 1. 上位 16 ビットに値があるか確かめる

```go:line-numbers=325
	if x >= 1<<16 {
		x >>= 16
		n = 16
	}
```

`x` が 65536（`1<<16`）以上なら、上位 16 ビットに 1 があります。そこで、16 ビット右にずらし、答えに 16 を加えます。ずらしたあとは、残りの下位 16 ビットだけを見れば済みます。

### 2. 上位 8 ビットに値があるか確かめる

```go:line-numbers=329
	if x >= 1<<8 {
		x >>= 8
		n += 8
	}
```

同じ考え方で、残りに 256 以上の値があるかを確かめます。あれば 8 ビット右にずらして、答えに 8 を加えます。

### 3. 残りを表で求める

```go:line-numbers=333
	return n + int(len8tab[uint8(x)])
```

ここまでで、残りは 0 から 255 の範囲です。`len8tab` を引けば、その 8 ビットのビット長が得られます。最後に、捨てた分の `n` を足して返します。

## ここがすごい

- **段階を追って範囲を狭める**: 32 ビットの問題を、16 ビット、8 ビットと半分ずつ小さくするので、判定は 2 回の比較と 1 回の表引きで済みます。
- **表の大きさを小さく保つ**: 256 要素の表で、32 ビット全体を扱えるので、メモリの使用が少なくなります。
- **捨てた分を正確に数える**: ずらした量を `n` に足すので、どこから何ビット捨てたかが常に正しく残ります。

## まとめ

- 上位 16 ビットに値があれば、16 ビットずらして 16 を加える。
- 残りの上位 8 ビットも同じように確かめる。
- 最後の 8 ビットは、表を引いて答えを得る。
