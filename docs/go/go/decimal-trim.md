## ひとことで

`trim(x)` は、10 進数の値の末尾にある不要な 0 を取り除きます。例えば `"1200"` は `"12"` になります。値の大きさは変わりません。

`decimal` 型は、数字の文字列と指数で表します。末尾の 0 を削っておくと、後の計算や比べる処理が、ずっと簡単になります。

## コード

```go:line-numbers=261
func trim(x *decimal) {
	i := len(x.mant)
	for i > 0 && x.mant[i-1] == '0' {
		i--
	}
	x.mant = x.mant[:i]
	if i == 0 {
		x.exp = 0
	}
}
```

## 前提知識

- **仮数部（mant）**: 数字だけを並べた文字列です。小数点の位置は、別の値 `exp` で表します。
- **末尾の 0**: 数字の一番後ろにある `'0'` です。`"1200"` の末尾の `"00"` が、ここで言う末尾の 0 です。
- **値が変わらない**: 末尾の 0 を削っても、数の大きさは同じです。`1200` と `12` の違いは、位取りの書き方だけです。
- **`exp` を 0 に戻す**: 仮数部がすべて消えると、残るのは 0 だけになります。そのときは、指数を 0 に戻して、表し方を揃えます。

## 何をしているか

### 1. 末尾から 0 を数える

```go:line-numbers=263
	for i > 0 && x.mant[i-1] == '0' {
		i--
	}
```

`i` は、残す桁の数を表します。最初は、文字列の長さです。末尾の文字が `'0'` である間、`i` を 1 ずつ減らします。

`i > 0` の判定があるので、すべてが 0 になっても、配列の外を読むことはありません。

### 2. 残す部分だけを切り出す

```go:line-numbers=266
	x.mant = x.mant[:i]
```

`mant[:i]` で、先頭から `i` 文字までを残します。末尾の 0 がない部分だけが、新しい仮数部になります。

### 3. すべて消えたら指数を戻す

```go:line-numbers=267
	if i == 0 {
		x.exp = 0
	}
```

仮数部が空になった、つまり値が 0 だった場合は、指数を 0 に戻します。これで、0 の表し方が 1 通りに決まります。

## ここがすごい

- **比べやすい形にする**: 同じ値の数が、同じ表し方になります。`"1200"` と `"12"` を比べるときに、違う文字列として扱われることがなくなります。
- **新しい配列を作らない**: `mant[:i]` は、元の配列の一部を指すだけです。コピーをしないので、速くて軽い処理になります。
- **0 の特別扱い**: 値が 0 のときだけ、指数を戻す決まりがあります。小さなコードで、0 の表し方を統一しています。

## まとめ

- `trim` は、仮数部の末尾の 0 を削ります。
- 値は変わらず、表し方だけが短く揃います。
- 全部が 0 になったときは、指数も 0 に戻します。
