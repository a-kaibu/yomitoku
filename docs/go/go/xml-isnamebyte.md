## ひとことで

`isNameByte(c)` は、XML の名前の中に使える 1 バイトかを調べます。英字、数字、`_`、`:`、`.`、`-` のどれかなら `true` です。例えば `a` や `_` は使えますが、スペースや `!` は使えません。

XML の名前は、タグや属性の名前として使われます。その中に、どの文字が許されるかを、1 文字ずつ判定するための関数です。

## コード

```go:line-numbers=1236
func isNameByte(c byte) bool {
	return 'A' <= c && c <= 'Z' ||
		'a' <= c && c <= 'z' ||
		'0' <= c && c <= '9' ||
		c == '_' || c == ':' || c == '.' || c == '-'
}
```

## 前提知識

- **XML の名前**: `<book>` の `book` や、属性 `id` のような部分です。使える文字は、XML の規格で決められています。
- **1 バイト**: ここでは、ASCII の範囲だけを扱います。英数字と記号は、どれも 1 バイトで表されます。
- **論理和（`||`）**: 条件のどれか一つでも真なら真になる演算です。ここでは、並べた条件のどれかに当たるかを判定します。
- **範囲の比較**: `'A' <= c && c <= 'Z'` のように、文字コードの範囲で英字を判定します。

## 何をしているか

### 1. 英字と数字の範囲を判定する

```go:line-numbers=1237
	return 'A' <= c && c <= 'Z' ||
		'a' <= c && c <= 'z' ||
		'0' <= c && c <= '9' ||
```

英大文字、英小文字、数字の 3 つの範囲を、それぞれ `&&` で一つずつ判定します。どれかに当たれば、そこで真になります。

### 2. 残りの記号を判定する

```go:line-numbers=1240
	c == '_' || c == ':' || c == '.' || c == '-'
```

アンダースコア、コロン、ピリオド、ハイフンは、一文字ずつ比べます。名前の中で使える記号は、これだけです。

## ここがすごい

- **範囲と一覧を組み合わせる**: 連続した文字は範囲で、離れた記号は一つずつ書くことで、短く読みやすくなっています。
- **短絡評価で早く終わる**: `||` は、どれか一つが真なら残りを見ません。英字の多くは、最初の条件で決まります。
- **仕様の一覧そのもの**: 関数の中身を読めば、XML の名前に許される文字が、そのまま分かります。

## まとめ

- `isNameByte` は、XML の名前に使える 1 バイトかを判定します。
- 英字、数字、そして `_`、`:`、`.`、`-` が使えます。
- 範囲と個別の文字を、`||` でつないで判定しています。
