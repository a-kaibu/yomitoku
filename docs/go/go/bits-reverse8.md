## ひとことで

`bits.Reverse8(0b00000001)` は `0b10000000` を返します。ビットの並びを、左右反対にした値です。ネットワークの規格や、画像の処理などで、この並びが必要になることがあります。

## コード

```go:line-numbers=234
func Reverse8(x uint8) uint8 {
	return rev8tab[x]
}
```

## 前提知識

- **ビットの並び**: 8 ビットの値は、最上位（左端）から最下位（右端）へ並んでいます。反転は、その並びを左右で入れ替えることです。
- **表（テーブル）**: 入力と答えを、あらかじめ配列にしておく方法です。`rev8tab[x]` は、`x` の逆順の値です。
- **表を引く速さ**: 256 通りしかないので、表を用意すれば、計算は配列の参照 1 回で済みます。
- **`uint8`**: 8 ビットの符号なし整数です。

## 何をしているか

### 1. 表を引く

```go:line-numbers=235
	return rev8tab[x]
```

`rev8tab[x]` は、`x` のビットを逆にした値を、あらかじめ用意した表から取り出します。計算はしていないので、ビットを 1 つずつ入れ替えるよりずっと速く終わります。

### 2. 結果を返す

```go:line-numbers=234
func Reverse8(x uint8) uint8 {
	return rev8tab[x]
}
```

関数の中では、表を引いて返すだけです。引数の型と戻り値の型は、どちらも `uint8` なので、8 ビットの範囲に収まります。

## ここがすごい

- **表で計算を置き換える**: 入力の数が少ないので、答えをすべて前もって作っておけます。
- **短い関数に見せる**: 利用者は、中身の表を意識せず、ただ逆順の値を得られます。
- **16 ビットの版も表を使う**: `Reverse16` は、この表を 2 回使って組み立てています。表の再利用が、ほかの関数に広がっています。

## まとめ

- 8 ビットの逆順は、256 通りの表を引くだけで得られる。
- 表は、ほかの幅の逆順を作るためにも使われる。
- 利用者からは、単純な関数に見える。
