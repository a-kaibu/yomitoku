## ひとことで

`makeTable(poly)` は、CRC-64 の計算に使う表を作ります。表の 256 個の要素は、0 から 255 までのそれぞれの値を、多項式 `poly` で割ったときの結果です。表があれば、1 バイトごとに、表を引くだけで次の状態を求められます。

多項式 `poly` は、CRC の種類を決める定数です。同じ多項式からは、同じ表が作られます。

## コード

```go:line-numbers=58
func makeTable(poly uint64) *Table {
	t := new(Table)
	for i := 0; i < 256; i++ {
		crc := uint64(i)
		for j := 0; j < 8; j++ {
			if crc&1 == 1 {
				crc = (crc >> 1) ^ poly
			} else {
				crc >>= 1
			}
		}
		t[i] = crc
	}
	return t
}
```

## 前提知識

- **多項式除算**: CRC では、ビットを多項式の係数と見なして割り算をします。普通の割り算とは違い、引き算の代わりに XOR を使います。
- **ビットを 1 つずらす**: `crc >> 1` は、ビットを 1 つ右にずらした値です。下位のビットが押し出されます。
- **最下位ビットの判定**: `crc&1 == 1` は、一番右のビットが 1 かを調べます。これで、多項式を足すかどうかを決めます。
- **`uint64`**: 符号なしの 64 ビット整数です。CRC の値を入れる型です。

## 何をしているか

### 1. 0〜255 のそれぞれから始める

```go:line-numbers=60
	for i := 0; i < 256; i++ {
		crc := uint64(i)
```

表の要素は 256 個で、1 バイトのすべての値に対応します。`i` を、その初期値として `crc` に入れます。

### 2. 1 ビットずつ割り算を進める

```go:line-numbers=62
		for j := 0; j < 8; j++ {
			if crc&1 == 1 {
				crc = (crc >> 1) ^ poly
			} else {
				crc >>= 1
			}
		}
```

8 回繰り返して、1 ビットずつ進めます。一番右のビットが 1 なら、右にずらしてから多項式 `poly` と XOR します。0 なら、ただ右にずらすだけです。これが多項式による割り算の 1 歩に当たります。

### 3. 結果を表に入れる

```go:line-numbers=69
		t[i] = crc
	}
	return t
```

8 回の処理が終わった値を、`t[i]` に保存します。256 個すべてが埋まったら、表を返します。

## ここがすごい

- **表を 1 度作れば何度でも使える**: 表は多項式だけで決まるので、プログラムの初めに 1 回作れば、以降は表を引くだけです。ビット単位の計算をデータごとに繰り返す必要がありません。
- **ビットの処理が単純**: 1 ビットずつの「ずらすか、XOR するか」だけで、割り算の結果が得られます。複雑な分岐がありません。
- **多項式を変えるだけで別の CRC になる**: `poly` を変えれば、別の種類の CRC の表ができます。関数は、そのまま使い回せます。

## まとめ

- `makeTable` は、0〜255 の 256 個の値について、多項式で割った結果を表にします。
- 各値を 8 回ずつ、右にずらして必要なら多項式と XOR します。
- 表は多項式だけで決まるので、初期化の時に 1 回作れば十分です。
- 多項式を変えると、別の CRC の表になります。
