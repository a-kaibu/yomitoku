## ひとことで

`x.isPow2()` は、整数 `x` が 2 のべき乗かを調べます。2 のべき乗なら、`true` と、その指数を返します。例えば `8`（2 の 3 乗）なら `(3, true)` です。

2 進数で考えると、2 のべき乗は「1 のビットがちょうど 1 つだけ」の数です。`8` は `1000` で、1 が 1 つだけです。その性質を使って、短い計算で判定します。

## コード

```go:line-numbers=418
func (x nat) isPow2() (uint, bool) {
	var i uint
	for x[i] == 0 {
		i++
	}
	if i == uint(len(x))-1 && x[i]&(x[i]-1) == 0 {
		return i*_W + uint(bits.TrailingZeros(uint(x[i]))), true
	}
	return 0, false
}
```

## 前提知識

- **2 進数**: 0 と 1 だけで数を表す方法です。`8` は `1000`、`5` は `101` と書きます。
- **2 のべき乗**: 2 を何回かけた数かで表せる数です。`1`、`2`、`4`、`8`、`16` などです。
- **`x & (x-1)`**: 1 つのビットだけが立っているかを調べる、よく使われる方法です。1 を引くと、一番下の 1 のビットが 0 になり、その下が 1 に変わります。両方を `&` で比べて 0 なら、ビットは 1 つだけでした。
- **`bits.TrailingZeros`**: 数の一番下から数えて、0 が何個続くかを返す関数です。その個数が、2 のべき乗の指数になります。

## 何をしているか

### 1. 先頭の 0 でないワードを探す

```go:line-numbers=420
	for x[i] == 0 {
		i++
	}
```

配列の先頭から、0 でないワードを探します。`i` は、その位置です。0 のワードは、値に影響しないので飛ばします。

### 2. 最上位のワードだけで判定する

```go:line-numbers=423
	if i == uint(len(x))-1 && x[i]&(x[i]-1) == 0 {
```

この条件は、2 つのことを確かめています。

- `i` が最後のワードの位置です。つまり、0 でないワードは 1 つだけです。
- `x[i]&(x[i]-1) == 0` は、そのワードのビットが 1 つだけかを確かめています。

両方が真なら、値は 1 つのワードの中で 2 のべき乗になっています。

### 3. 指数を計算する

```go:line-numbers=424
		return i*_W + uint(bits.TrailingZeros(uint(x[i]))), true
```

`i*_W` は、飛ばしたワードの分のビット数です。`bits.TrailingZeros` で、そのワード内での 1 の位置を求めます。2 つを足すと、全体の指数になります。

## ここがすごい

- **1 回の引き算と & で判定**: ビットが 1 つだけかを、短い式で確かめます。ループで全ビットを数えるより、ずっと速いです。
- **指数まで同時に得られる**: 判定の結果が `true` なら、そのときの指数もすぐに分かります。2 度調べる必要がありません。
- **ワードの単位で考える**: 大きな数を、ワードという単位に分けて扱います。上位のワードが 0 なら、飛ばしてよいという考え方です。

## まとめ

- `isPow2` は、整数が 2 のべき乗かを判定します。
- 1 つだけビットが立っていれば、2 のべき乗です。
- 2 のべき乗のときは、その指数も一緒に返します。
