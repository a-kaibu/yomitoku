## ひとことで

`container/ring` は、最後の要素の次が最初の要素に戻る **循環リスト（輪）** です。`Len()` は、その輪に要素がいくつあるかを数えます。

輪には端がないので、「終わりに着いた」を判断する目印が必要です。この関数は、最初の要素に戻ってきたら終わりとしています。

## コード

```go:line-numbers=116
func (r *Ring) Len() int {
	n := 0
	if r != nil {
		n = 1
		for p := r.Next(); p != r; p = p.next {
			n++
		}
	}
	return n
}
```

## 前提知識

- **循環リスト**: 要素が次の要素を指し、最後の要素が最初に戻る構造です。リストのどこから数え始めても、一周すれば全部の要素に着きます。
- **`r.Next()`**: 次の要素を返すメソッドです。内部では `r.next` のポインタをたどっています。
- **`nil` のポインタ**: 値を持たないポインタです。`nil` のレシーバに対してメソッドを呼ぶこともできるので、ここでは `r != nil` の確認をしています。
- **`for` 文の条件 `p != r`**: 元の要素 `r` に戻るまで続けるという意味です。

## 何をしているか

### 1. nil なら 0 を返す

```go:line-numbers=117
	n := 0
	if r != nil {
```

`r` が `nil` なら、輪は空なので `n` は 0 のまま返されます。

### 2. 最初の 1 つを数える

```go:line-numbers=119
		n = 1
```

`r` 自身が 1 つの要素なので、数を 1 から始めます。

### 3. 一周して数える

```go:line-numbers=120
		for p := r.Next(); p != r; p = p.next {
			n++
		}
```

`r` の次から出発して、`r` に戻るまで 1 つずつ数えます。要素が 3 つの輪 `A → B → C → A` で `r = A` なら、`B` と `C` を数えて、`n` は 3 になります。

## ここがすごい

- **端がないので目印で止める**: 循環リストには最後の要素がありません。だから「元の要素に戻ったか」を判定の条件にしています。単純な `for` 文で、一周分だけ確実に回ります。
- **nil を正しい値に変える**: 空の輪を `nil` で表せるようにしておき、`Len()` は `0` を返します。呼び出し側が特別扱いをしなくても、正しく動きます。
- **数える前に 1 を足す**: 最初の要素を数えてから、残りをループで数えています。ループの条件を単純に保つための工夫です。

## まとめ

- 循環リストは端がないので、元の要素に戻ったかで終わりを判定する。
- `nil` のレシーバを扱えるようにすると、空の状態を安全に表せる。
- 数え始めを先に 1 にしておくと、ループの条件がきれいに書ける。
