## ひとことで

挿入ソートは、トランプの札を 1 枚ずつ、すでに並んだ手札の正しい位置へ差し込んでいく並べ替えの方法です。この関数は `sort` パッケージの内部で、**小さな範囲** を並べるために使われます。

関数の中身は 7 行しかありません。並べ替えの対象が配列なのか、ほかのものなのかを知らず、比べるための `Less` と入れ替えるための `Swap` だけを使います。

## コード

```go:line-numbers=10
func insertionSort_func(data lessSwap, a, b int) {
	for i := a + 1; i < b; i++ {
		for j := i; j > a && data.Less(j, j-1); j-- {
			data.Swap(j, j-1)
		}
	}
}
```

## 前提知識

- **挿入ソート**: 左から順に 1 つずつ見て、左側のすでに並んだ部分の正しい位置まで、その要素を入れ替えながら移す並べ替えです。すでにほぼ並んでいるデータに強いです。
- **`lessSwap` 型**: `Less(i, j)` と `Swap(i, j)` という 2 つの関数をまとめた型です。Go では、関数を値として受け取ったり、構造体のフィールドに入れたりできます。
- **`data.Less(j, j-1)`**: 「`j` 番目の要素は `j-1` 番目より小さいか」を調べる関数の呼び出しです。
- **`for` の条件に `&&`**: 左の条件が偽なら、右を評価しません。ここでは `j > a` を先に確かめるので、範囲の外を比べることがありません。

## 何をしているか

`[3, 1, 2]`（範囲は `a = 0`、`b = 3`）で追います。

### 1. 2 番目の要素を左へ移す

`i = 1` のとき、`j = 1` で `Less(1, 0)` を調べます。`1 < 3` なので、`Swap(1, 0)` で `[1, 3, 2]` になります。`j` は 0 になり、`j > a` が偽なので内側のループを抜けます。

```go:line-numbers=12
	for j := i; j > a && data.Less(j, j-1); j-- {
		data.Swap(j, j-1)
	}
```

### 2. 3 番目の要素を正しい位置まで移す

`i = 2` のとき、`j = 2` で `Less(2, 1)` を調べます。`2 < 3` なので入れ替えて `[1, 2, 3]` になります。次に `j = 1` で `Less(1, 0)` を調べます。`2 < 1` は偽なので、ここで止まります。

## ここがすごい

- **比較と交換だけに頼る**: 関数は `data` の中身を見ません。だから、`sort.Sort` に渡された任意の型でも同じコードで動きます。`sort.Slice` のような「関数を渡す」設計をそのまま支えています。
- **短い範囲にだけ使う**: 挿入ソートは要素数が多いと遅くなります（最悪で n² 回の比較）が、要素数が少ないときは、ほかのアルゴリズムより速いことが多いです。そこで、大きな並べ替えの途中で、小さくなった範囲を仕上げる部品として使われています。
- **外側のループは 1 本だけ**: `i` で一度ずつ要素を選び、内側で必要な分だけ動かします。ループの入れ子は 2 段ですが、構造はとても単純です。

## まとめ

- 挿入ソートは、すでに並んだ部分へ 1 つずつ差し込む並べ替えである。
- 比較と交換を関数として渡せば、データの型を知らずに同じコードを使える。
- 小さな範囲や、ほぼ並んだデータに向いている。
