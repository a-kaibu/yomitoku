## ひとことで

`z.Sqrt(x)` は、`x` の平方根の整数部分を `z` に設定します。例えば `x` が 17 なら、平方根は約 4.12 なので、`z` は 4 になります。小数点以下は切り捨てられます。

負の数の平方根は、実数の範囲では存在しません。そのため、負の数を渡すと、この関数はパニックを起こします。

## コード

```go:line-numbers=1448
func (z *Int) Sqrt(x *Int) *Int {
	if x.neg {
		panic("square root of negative number")
	}
	z.neg = false
	z.abs = z.abs.sqrt(nil, x.abs)
	return z
}
```

## 前提知識

- **平方根**: ある数を 2 乗すると元の数になる値です。例えば 16 の平方根は 4 です。
- **整数部分**: 小数点以下を捨てた、整数の部分です。`math/big` の整数は整数だけを扱うので、結果も必ず整数になります。
- **`nat.sqrt`**: 絶対値の配列（`nat`）から、平方根を求める内部の関数です。この関数は、その結果を受け取って、符号などを整えるだけです。
- **`neg` フラグ**: 負の数かどうかを表すフラグです。平方根の結果は正の数になるので、このフラグを 0 に戻します。

## 何をしているか

### 1. 負の数を弾く

```go:line-numbers=1449
	if x.neg {
		panic("square root of negative number")
	}
```

`x` が負の数なら、`panic` を起こします。負の数の平方根は、実数では求められないからです。

この判定は、計算を始める前に行われます。間違った値を使って、途中まで計算してしまうことを防ぎます。

### 2. 結果を正の数にする

```go:line-numbers=1452
	z.neg = false
```

平方根の結果は、0 以上の値です。そのため、`z` の符号を正に決めておきます。`z` が以前に負の値だったとしても、ここで正しく上書きされます。

### 3. 絶対値の平方根を求める

```go:line-numbers=1453
	z.abs = z.abs.sqrt(nil, x.abs)
	return z
```

実際の計算は `nat.sqrt` に任せます。`x.abs` の絶対値を入力にして、その結果を `z.abs` に入れます。最後に `z` を返して、呼び出し元で続けて使えるようにします。

## ここがすごい

- **仕事を分ける**: 符号を整えるのがこの関数、計算そのものが `nat.sqrt` です。大きな数の平方根の計算を、1 か所の関数に集めています。
- **結果を `z` に入れる**: 新しい `Int` を作らず、既存の `z` に結果を入れます。メモリの使い方が、無駄にならない作りです。
- **エラーは早めに**: 負の数は、計算の前に判定されます。問題を見つけやすく、原因の場所も特定しやすくなっています。

## まとめ

- `Sqrt` は、整数の平方根の整数部分を `z` に設定します。
- 負の数は、実数の範囲に平方根がないので、`panic` で知らせます。
- 計算の本体は `nat.sqrt` にあり、この関数は符号を整えて結果を返します。
