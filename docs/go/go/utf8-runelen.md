## ひとことで

`utf8.RuneLen(r)` は、1 文字 `r` を UTF-8 で書くと **何バイトになるか** を返します。`'A'` なら 1、`'é'` なら 2、`'あ'` なら 3、絵文字の `'😀'` なら 4 です。
UTF-8 で表せない値なら `-1` を返します。

この関数のおもしろさは、`switch` の `case` を **範囲の小さい順に並べる** ことで、上限の比較だけで判定している点と、途中にはさまれたサロゲートの判定です。

## コード

```go:line-numbers=347
func RuneLen(r rune) int {
	switch {
	case r < 0:
		return -1
	case r <= rune1Max:
		return 1
	case r <= rune2Max:
		return 2
	case surrogateMin <= r && r <= surrogateMax:
		return -1
	case r <= rune3Max:
		return 3
	case r <= MaxRune:
		return 4
	}
	return -1
}
```

`rune1Max = 1<<7 - 1`（127）、`rune2Max = 1<<11 - 1`（2047）、`rune3Max = 1<<16 - 1`（65535）、`MaxRune = '\U0010FFFF'`、`surrogateMin = 0xD800`、`surrogateMax = 0xDFFF` は同じファイルで定義された定数です。

## 前提知識

- **ルーン（rune）**: Go で 1 文字（Unicode のコードポイント）を表す型で、中身は 32 ビットの符号付き整数です。負の数も入れられてしまうので、チェックが必要です。
- **条件のない `switch`**: `switch { case 条件: ... }` と書くと、上から順に条件を調べ、最初に真になった `case` だけを実行します。`if ... else if ...` の連鎖と同じ意味で、読みやすく書けます。
- **UTF-8 のバイト数**: コードポイントが 127 以下なら 1 バイト、2047 以下なら 2 バイト、65535 以下なら 3 バイト、0x10FFFF 以下なら 4 バイトです。
- **サロゲート**: U+D800〜U+DFFF の範囲は、UTF-16 という別の方式で大きな文字を 2 つに分けて表すために予約された値で、単独では文字ではありません。UTF-8 でこれを書くことは禁止されています。

## 何をしているか

### 1. 負の数は不正（349〜350 行目）

### 2. 小さい順に上限と比べる（351〜354 行目）

`'A'`（65）は `rune1Max`（127）以下なので 1。`'é'`（233）は 127 より大きく 2047 以下なので 2 です。
上から順に調べるので、2 つ目の `case` に来た時点で「127 より大きい」ことはわかっています。だから **上限だけを比べれば** 範囲の判定になります。

### 3. サロゲートをはさむ（355〜356 行目）

3 バイトの範囲（2048〜65535）の途中に、UTF-8 で書いてはいけないサロゲートの範囲があります。そこで 3 バイトの判定の **直前** に、サロゲートなら `-1` を返す `case` を置いています。

`'あ'`（0x3042）はサロゲートの範囲より小さいので、この `case` には当てはまらず、次の `r <= rune3Max` で 3 になります。

### 4. 4 バイトと範囲外（359〜362 行目）

0x10FFFF 以下なら 4、それより大きいと Unicode の範囲外なので `-1` です。

## ここがすごい

- **並べ順が条件の一部になっている**: `case` を小さい順に並べることで、各 `case` は上限の比較 1 回だけで済みます。`r > rune1Max && r <= rune2Max` のような下限の比較を書く必要がありません。
- **例外を適切な場所に差し込む**: サロゲートは 3 バイトの範囲の「穴」です。3 バイトの `case` の直前に置くことで、穴を正しく除外しています。順番を間違えると、サロゲートが 3 バイトとして通ってしまいます。
- **不正な値を 1 つの値で知らせる**: 負の数、サロゲート、範囲外のどれでも `-1` を返します。呼び出し側は「`-1` なら書けない」とだけ考えればよく、扱いが簡単です。

## まとめ

- 条件のない `switch` は、上から順に評価されるので、範囲の判定を上限だけで書ける。
- 範囲の「穴」は、その範囲の判定の直前に置くと正しく除外できる。
- UTF-8 ではサロゲート（U+D800〜U+DFFF）は書いてはいけない。
