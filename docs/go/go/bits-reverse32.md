## ひとことで

`bits.Reverse32(1)` は `0x80000000` を返します。32 ビットの並びを左右反対にします。ビットを 1 つずつ動かさず、組の大きさを 2 倍ずつ広げながら、入れ替えを重ねていきます。

## コード

```go:line-numbers=244
func Reverse32(x uint32) uint32 {
	const m = 1<<32 - 1
	x = x>>1&(m0&m) | x&(m0&m)<<1
	x = x>>2&(m1&m) | x&(m1&m)<<2
	x = x>>4&(m2&m) | x&(m2&m)<<4
	return ReverseBytes32(x)
}
```

## 前提知識

- **ビットマスク定数 `m0`、`m1`、`m2`**: 交互のビットを選ぶ 0 と 1 の並びです。たとえば `m0` は、1 ビットおきに 1 を立てた値です。
- **組の入れ替え**: 隣り合う 1 ビットの組を入れ替え、次に 2 ビットの組、次に 4 ビットの組を入れ替えると、全体が逆順になります。
- **`ReverseBytes32`**: 4 バイトの順序を反転させる関数です。残りは、バイト内のビットの並びを整えるために使われます。
- **シフトと `&`**: 右シフトと左シフトで、組を入れ替えるための移動を行います。

## 何をしているか

### 1. 1 ビットずつの組を入れ替える

```go:line-numbers=246
	x = x>>1&(m0&m) | x&(m0&m)<<1
```

`x>>1&m0` で、奇数の位置のビットを偶数の位置へ動かします。`x&m0<<1` で、偶数の位置のビットを奇数の位置へ動かします。2 つを `|` で合わせると、隣り合うビットが入れ替わります。

### 2. 2 ビットずつの組を入れ替える

```go:line-numbers=247
	x = x>>2&(m1&m) | x&(m1&m)<<2
```

同じ考え方で、2 ビットの組を入れ替えます。`m1` のマスクで、組の境目を選びます。

### 3. 4 ビットずつの組を入れ替える

```go:line-numbers=248
	x = x>>4&(m2&m) | x&(m2&m)<<4
```

さらに、4 ビットの組を入れ替えます。ここまでで、バイトの中のビットの並びは逆になっています。

### 4. バイトの順序を反転する

```go:line-numbers=249
	return ReverseBytes32(x)
```

最後に `ReverseBytes32` で、4 つのバイトの順序を入れ替えます。すると、32 ビット全体が逆順になります。

## ここがすごい

- **少ない手順で全体を逆にする**: 組の大きさを 2 倍ずつ広げるので、5 回ほどの入れ替えで 32 ビットの逆順が完成します。
- **表を使わない**: 表を持たずに、ビットの演算だけで答えを作るので、メモリを使いません。
- **分けて理解できる**: 1 ビット、2 ビット、4 ビット、バイトと段階ごとに処理が分かれているので、どこで何が起きているかを追えます。

## まとめ

- 隣り合う 1、2、4 ビットの組を、マスクとシフトで順に入れ替える。
- 最後にバイトの順序を反転させて、32 ビット全体を逆にする。
- 表を使わずに、ビットの演算だけで逆順を作る。
