## ひとことで

`bits.Add32(x, y, carry)` は、`x + y + carry` の 32 ビットの結果 `sum` と、次の桁への繰り上がり `carryOut`（0 か 1）を返します。

32 ビットの値を 2 つ足すと、結果は 33 ビット必要になることがあります。その 1 ビットが繰り上がりです。この関数は、その 1 ビットを取り出すために、計算を 64 ビットで行います。

## コード

```go:line-numbers=374
func Add32(x, y, carry uint32) (sum, carryOut uint32) {
	sum64 := uint64(x) + uint64(y) + uint64(carry)
	sum = uint32(sum64)
	carryOut = uint32(sum64 >> 32)
	return
}
```

## 前提知識

- **繰り上がり（carry）**: 筆算で、下の桁の和が桁を超えたときに上の桁へ渡す 1 のことです。
- **符号なしのあふれ**: `uint32` の足し算は、上の桁を捨てて折り返します。捨てられた部分が、繰り上がりです。
- **`uint64` への変換**: 32 ビットの値を 64 ビットに広げると、和が 32 ビットを超えても、途中で捨てられません。
- **`>> 32`**: 64 ビットの値の上位 32 ビットを取り出します。ここでは、繰り上がりの 1 ビットになります。

## 何をしているか

`x = 0xFFFFFFFF`、`y = 1`、`carry = 0` で追います。32 ビットで計算すると、`0xFFFFFFFF + 1` は 0 に折り返して、繰り上がりが分からなくなります。

### 1. 64 ビットで足す

```go:line-numbers=375
	sum64 := uint64(x) + uint64(y) + uint64(carry)
```

`sum64 = 0x100000000` です。32 ビットに収まらない部分（bit 32）が、そのまま残ります。

### 2. 下位 32 ビットを結果にする

```go:line-numbers=376
	sum = uint32(sum64)
```

`sum = 0` になります。32 ビットの結果は、下の 32 ビットを取るだけです。

### 3. 上の部分を繰り上がりにする

```go:line-numbers=377
	carryOut = uint32(sum64 >> 32)
```

`sum64 >> 32 = 1` なので、`carryOut = 1` です。あふれたことが、そのまま 1 として返ります。

## ここがすごい

- **あふれを消さずに残す**: 32 ビットで計算すると、あふれは消えてしまいます。広い型で計算すると、あふれた分が上位のビットとして保たれます。
- **比較を使わない**: 「和が元の値より小さくなったか」で繰り上がりを判定する方法もあります。広い型を使えば、比較なしで同じ情報が得られます。
- **64 ビットの CPU なら速い**: 64 ビットの値を扱える環境では、この変換は命令 1 つか 2 つで済みます。

## まとめ

- 足し算のあふれは、広い型で計算すると捨てずに取り出せる。
- 結果の下位と、上位の 1 ビットを分けると、和と繰り上がりがそのまま得られる。
- 繰り上がりを比較で判定しないと、計算の意味が直接読める。
