## ひとことで

`fmtInt(buf, v)` は、符号なし整数 `v` を 10 進数の文字に直して、バッファ `buf` の **末尾から** 書き込みます。書き込み始めた位置を返すので、呼び出し側は `buf[w:]` で結果を取り出せます。例えば `v = 2024` なら、末尾に `2024` が並びます。

時刻の表示は、年や分などの数字を何度も文字にします。そのたびに新しい文字列を作らないように、既存のバッファに直接書き込むための関数です。

## コード

```go:line-numbers=1056
func fmtInt(buf []byte, v uint64) int {
	w := len(buf)
	if v == 0 {
		w--
		buf[w] = '0'
	} else {
		for v > 0 {
			w--
			buf[w] = byte(v%10) + '0'
			v /= 10
		}
	}
	return w
}
```

## 前提知識

- **10 進数の桁の取り出し**: `v % 10` で末尾の 1 桁、`v / 10` で残りの数字が分かります。この 2 つを繰り返すと、桁を後ろから順に取れます。
- **文字コード `'0'`**: 数字 0 の文字の値は、ASCII で 48 です。`byte(d) + '0'` で、0〜9 の数字の文字になります。
- **スライスの後ろからの書き込み**: `w := len(buf)` から始めて、`w--` で 1 つずつ前へ進みながら書きます。
- **書き始めの位置**: 戻り値の `w` は、書いた文字の先頭の添字です。`buf[w:]` が結果になります。

## 何をしているか

### 1. 0 は特別に書く

```go:line-numbers=1057
	w := len(buf)
	if v == 0 {
		w--
		buf[w] = '0'
	} else {
```

`v == 0` のときは、桁を取る処理をすると何も書けません。そこで、末尾に `'0'` を 1 つだけ書きます。

### 2. 桁を後ろから書く

```go:line-numbers=1062
		for v > 0 {
			w--
			buf[w] = byte(v%10) + '0'
			v /= 10
		}
```

`v > 0` の間、末尾の 1 桁を取って、その文字を 1 つ前の位置に書きます。`v /= 10` で桁を 1 つ減らします。`2024` なら、`4`、`2`、`0`、`2` の順に、後ろから前へ書かれます。

### 3. 書き始めの位置を返す

```go:line-numbers=1068
	return w
```

最後に `w` を返します。`buf[w:]` が、書かれた数字の文字列になります。新しいバッファは作らず、既存の領域の一部だけを使っています。

## ここがすごい

- **文字列を作らない**: 数字を `strconv` で文字列にすると、毎回メモリを確保します。バッファを使い回すことで、時刻の表示でのメモリ確保を減らしています。
- **後ろから書けば桁の順番が要らない**: 桁は下の位から取れるので、後ろから書けば正しい順番になります。逆順にしてから反転する必要がありません。
- **呼び出し側が場所を決める**: 戻り値で開始位置を返すので、書式の中のどこにでも数字を入れられます。

## まとめ

- `fmtInt` は、整数を既存のバッファの末尾から書き込みます。
- 10 で割った余りで末尾の桁を取り、後ろから前へ書きます。
- 0 は、桁の処理に入らず、直接 `'0'` を書きます。
- 戻り値は書き始めの位置で、文字列を作らずに数字を扱えます。
