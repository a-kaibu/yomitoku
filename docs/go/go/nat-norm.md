## ひとことで

`z.norm()` は、大きな整数の配列の上位にある 0 のワードを取り除きます。例えば、ワードが `[5, 0, 0]` なら、`[5]` を返します。値は変わりません。

`math/big` では、整数の長さが、そのまま値の大きさを表します。上位に 0 が余分に付いていると、同じ値が違う長さで表されてしまいます。それを防ぐために、計算の後でこの関数を使います。

## コード

```go:line-numbers=48
func (z nat) norm() nat {
	i := len(z)
	for i > 0 && z[i-1] == 0 {
		i--
	}
	return z[0:i]
}
```

## 前提知識

- **ワード**: 大きな整数を分けて入れる箱です。`nat` は、ワードを並べた配列です。
- **上位の桁**: 配列の末尾側です。`nat` では、末尾が最も大きい桁になります。
- **正規化（normalize）**: 同じ値を、決まった 1 つの形で表すことです。ここでは、上位の 0 を取り除いた形が正規の形です。
- **スライス**: 配列の一部を指す値です。`z[0:i]` は、先頭から `i` 個のワードを指す新しいスライスを作ります。コピーはしません。

## 何をしているか

### 1. 上位の 0 を数える

```go:line-numbers=50
	for i > 0 && z[i-1] == 0 {
		i--
	}
```

`i` は、残すワードの数を表します。最初は配列の長さです。末尾のワードが 0 である間、`i` を 1 つずつ減らします。

`i > 0` の判定があるので、すべてが 0 でも、配列の外を読むことはありません。

### 2. 残りの部分を返す

```go:line-numbers=53
	return z[0:i]
```

先頭から `i` 個のワードまでを、新しいスライスとして返します。元の配列を書き換えず、長さだけを変えた見た目を返します。

## ここがすごい

- **長さで値を表す**: 同じ値は、同じ長さの配列で表されます。そのため、長さを比べるだけで、大小を素早く判断できます。
- **コピーをしない**: 返すのは元の配列の一部なので、メモリを新しく使いません。計算の途中で、何度呼んでも軽い処理です。
- **すべて 0 でも正しい**: ワードがすべて 0 なら、`i` は 0 になり、空のスライスが返ります。0 の表し方も、1 通りに決まります。

## まとめ

- `norm` は、配列の上位にある 0 のワードを取り除きます。
- 値は変わらず、同じ値は同じ長さで表されます。
- 新しいメモリを作らず、スライスの長さだけを変えて返します。
