## ひとことで

`bsearch(s, v)` は、昇順に並んだ配列 `s` の中から値 `v` を二分探索で探し、「見つかった位置（または入るべき位置）」と「本当に一致したか」を返します。`strconv` は、表示できる文字の範囲を表にして持っていて、その検索にこの関数を使います。

## コード

```go:line-numbers=502
func bsearch[S ~[]E, E ~uint16 | ~uint32](s S, v E) (int, bool) {
	n := len(s)
	i, j := 0, n
	for i < j {
		h := i + (j-i)>>1
		if s[h] < v {
			i = h + 1
		} else {
			j = h
		}
	}
	return i, i < n && s[i] == v
}
```

## 前提知識

- **二分探索**: 並んだ配列の真ん中と比べて、探す範囲を半分ずつ狭めていく探索法です。要素数 `n` に対して、約 `log2(n)` 回で終わります。
- **半開区間 `[i, j)`**: `i` を含み、`j` を含まない範囲です。`i == j` のとき、範囲は空です。
- **ジェネリクス `[S ~[]E, E ~uint16 | ~uint32]`**: `uint16` と `uint32` のどちらの表にも使える、型パラメータです。`|` は「どちらか」の型の集まりを表します。
- **`>>1` の割り算**: 右に 1 ビットずらすと、2 で割った商になります。`(j-i)>>1` は `(j-i)/2` と同じです。

## 何をしているか

### 1. 真ん中の位置を決める

```go:line-numbers=506
		h := i + (j-i)>>1
```

範囲 `[i, j)` の中央を `h` とします。`i + (j-i)/2` と書くことで、`i + j` の和が大きくなって溢れるのを防いでいます。

### 2. 真ん中の値と比べる

```go:line-numbers=507
		if s[h] < v {
			i = h + 1
		} else {
			j = h
		}
```

`s[h]` が `v` より小さければ、答えは `h` より後ろにあるので、`i` を `h+1` にします。そうでなければ、答えは `h` 以前にあるので、`j` を `h` にします。範囲は毎回半分になります。

### 3. 位置と一致の有無を返す

```go:line-numbers=513
	return i, i < n && s[i] == v
```

ループが終わると、`i` は `v` 以上の最初の位置です。その位置が配列の中にあり、値が `v` と同じなら、一致したと判定します。

## ここがすごい

- **溢れない中央の計算**: `(i+j)/2` ではなく `i + (j-i)>>1` と書くことで、大きな添字でも安全です。
- **比較は 1 種類だけ**: 「小さいか」だけで、範囲を左右に分けます。等しいかどうかは、最後に 1 回だけ確かめます。
- **型で使い分けを表す**: 表の型が `uint16` でも `uint32` でも、同じコードが使えます。ジェネリクスで、重複したコードを書かずに済んでいます。

## まとめ

- `bsearch` は、昇順の表から値 `v` を二分探索で探します。
- 範囲 `[i, j)` を、中央の値との比較で半分ずつ狭めます。
- 中央の計算は、溢れないように `i + (j-i)>>1` と書きます。
- 戻り値は、`v` 以上の最初の位置と、一致したかどうかです。
