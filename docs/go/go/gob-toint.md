## ひとことで

`toInt(x)` は、gob が書き込んだ符号なしの値 `x` を、符号付きの整数に戻します。`x` の最下位のビットが、符号を表しています。

## コード

```go:line-numbers=113
func toInt(x uint64) int64 {
	i := int64(x >> 1)
	if x&1 != 0 {
		i = ^i
	}
	return i
}
```

## 前提知識

- **gob の整数**: 符号付きの整数を、符号を最下位ビットに寄せた符号なしの値として書き込む形式です。
- **右シフト `>>`**: ビットを右にずらします。最下位ビットを捨てるのに使います。
- **ビット反転 `^`**: 各ビットを 0 と 1 で入れ替えます。負の数を元に戻すときに使います。

## 何をしているか

### 1. 最下位ビットを捨てて値を取り出す

```go:line-numbers=114
	i := int64(x >> 1)
```

`x` を一つ右にずらして、最下位のビットを捨てます。残った値を `int64` として `i` に入れます。最下位ビットは符号を表しているので、値の部分とは分けて扱います。

### 2. 符号のビットが 1 なら反転する

```go:line-numbers=115
	if x&1 != 0 {
		i = ^i
	}
```

最下位ビットが 1 なら、その数は負です。`i` のビットを反転して、負の値に戻します。たとえば `x` が 1 なら、`i` は 0 のままの後で反転され、-1 になります。

### 3. 結果を返す

```go:line-numbers=118
	return i
```

戻した整数を返します。

## ここがすごい

- **符号が一つのビットに入る**: 正と負を、最下位の 1 ビットで区別できるので、小さい絶対値は短く書けます。
- **変換が二行で済む**: 右にずらすことと、必要なら反転することだけで、元の値に戻せます。

## まとめ

- `toInt` は、符号を最下位ビットに寄せた値を、符号付きの整数に戻します。
- 最下位ビットが 1 のときだけ、ビットを反転します。
- 書き込みの変換の逆を行う関数です。
