## ひとことで

`RotateLeft64` は、64 ビット整数のビット列を **左に k ビット回転** させます。左端からはみ出したビットは、捨てられずに右端に戻ってきます。
8 ビットで例えると、`1000 0011` を左に 2 回転すると `0000 1110` になります。
`k` に負の数を渡すと右回転になります。ハッシュ関数や暗号でとてもよく使われる操作です。

## コード

```go:line-numbers=217
func RotateLeft64(x uint64, k int) uint64 {
	const n = 64
	s := uint(k) & (n - 1)
	return x<<s | x>>(n-s)
}
```

## 前提知識

- **シフトと回転の違い**: `x << 2` はふつうのシフトで、はみ出したビットは消え、右には 0 が入ります。回転（ローテート）は、はみ出したビットを反対側に入れます。
- **`uint(k)`**: `int` 型の `k` を符号なし整数に変換します。負の数を変換すると、2 の補数表現のまま大きな正の数になります。たとえば `-1` は全ビット 1 の値になります。
- **`& (n - 1)`**: `n` が 2 の累乗（ここでは 64）のとき、`& 63` は「64 で割った余り」と同じ結果になります。割り算よりずっと速い計算です。
- **Go のシフト量**: Go ではシフト量が型の幅（64）以上でもエラーにならず、結果は 0 になります（C 言語では未定義動作です）。

## 何をしているか

### 1. 回転量を 0〜63 に収める（219 行目）

`s := uint(k) & (n - 1)` で、回転量を 64 で割った余りにします。
`k = 2` なら `s = 2`、`k = 66` なら 66 回転は 2 回転と同じなので `s = 2` です。
`k = -2`（右に 2 回転）の場合、`uint(-2)` は `...11111110` という巨大な数で、その下位 6 ビットは `111110` = 62 です。**左に 62 回転 = 右に 2 回転** なので、正しく右回転になります。

### 2. 2 つのシフトを合わせる（220 行目）

`x<<s` で左に s ずらし（はみ出した上位は消える）、`x>>(n-s)` で、消えてしまう上位 s ビットを右端まで降ろします。`|` で合わせれば回転の完成です。

8 ビット、`x = 1000 0011`、`s = 2` で考えると、

```
x << 2       = 0000 1100
x >> (8-2)   = 0000 0010
OR           = 0000 1110
```

### s = 0 のとき

`x >> 64` になりますが、Go では幅以上のシフトは 0 になるので、結果は `x | 0 = x` で正しく動きます。C 言語ではここが未定義動作になるため、わざわざ分岐を入れるのが定番ですが、Go では不要です。

## ここがすごい

- **左右の回転を 1 つの関数で**: 右回転用の関数を別に用意せず、「負の k = 右回転」としています。2 の補数と `& 63` の組み合わせで、負の数の扱いが自然に正しくなるのが見事です。
- **言語仕様を味方につけている**: Go のシフトは幅以上のずらしでも結果が定義されている（0 になる）ので、`s = 0` の特別扱いが要りません。
- **1 命令になる**: `x<<s | x>>(64-s)` という形は、Go のコンパイラが CPU の回転命令（x86 の `ROL` など）1 つに置き換えます。読みやすい Go のコードが、そのまま最速の機械語になります。

## まとめ

- 回転は「左シフト」と「はみ出す部分の右シフト」の OR で書ける。
- 2 の累乗で割った余りは `& (n-1)` で求まり、負の数も自然に扱える。
- Go ではシフト量が型の幅以上でも安全で、C 言語のような特別扱いが要らない。
