## ひとことで

`Mul64` は 64 ビット整数 `x` と `y` を掛けた **128 ビットの結果** を、上位 64 ビット `hi` と下位 64 ビット `lo` に分けて返します。
ふつうの `x * y` では 64 ビットを超えた部分が捨てられてしまいますが、この関数はその捨てられる部分も計算します。
巨大な数の計算や、高速な割り算・乱数生成などの部品として使われます。

## コード

```go:line-numbers=470
func Mul64(x, y uint64) (hi, lo uint64) {
	const mask32 = 1<<32 - 1
	x0 := x & mask32
	x1 := x >> 32
	y0 := y & mask32
	y1 := y >> 32
	w0 := x0 * y0
	t := x1*y0 + w0>>32
	w1 := t & mask32
	w2 := t >> 32
	w1 += x0 * y1
	hi = x1*y1 + w2 + w1>>32
	lo = x * y
	return
}
```

## 前提知識

- **`uint64` の掛け算のあふれ**: Go の `x * y` は結果の下位 64 ビットだけを残し、上の桁は黙って捨てます。
- **`mask32 = 1<<32 - 1`**: 下位 32 ビットがすべて 1 の値です。`x & mask32` で下位 32 ビット、`x >> 32` で上位 32 ビットを取り出せます。
- **`:=`**: 変数の宣言と代入を同時に行う Go の書き方です。型は右辺から自動で決まります。
- **筆算の考え方**: 2 桁 × 2 桁の掛け算 `(10a + b)(10c + d) = 100ac + 10(ad + bc) + bd` と同じことを、「1 桁 = 32 ビット」として行います。

## 何をしているか

`x = x1・2^32 + x0`、`y = y1・2^32 + y0` と、それぞれを上位 32 ビットと下位 32 ビットに分けます。すると

```
x * y = x1*y1・2^64 + (x1*y0 + x0*y1)・2^32 + x0*y0
```

となります。32 ビット同士の掛け算は最大でも 64 ビットに収まるので、**あふれずに** 計算できます。

### 1. 一番下の桁

```go:line-numbers=476
	w0 := x0 * y0
```

`w0 = x0 * y0`。この下位 32 ビットが結果の最下位 32 ビットになります。

### 2. 真ん中の桁の一部と繰り上がり

```go:line-numbers=477
	t := x1*y0 + w0>>32
	w1 := t & mask32
	w2 := t >> 32
```

`t = x1*y0 + w0>>32` で、真ん中の桁に `w0` からの繰り上がり（上位 32 ビット）を足します。`t` は 64 ビットに収まることが保証されています。
`t` の下位 32 ビットを `w1`、上位 32 ビットを `w2` に分けます。

### 3. 真ん中の桁の残り

```go:line-numbers=480
	w1 += x0 * y1
```

`w1 += x0 * y1` で、真ん中の桁のもう一方の項を足します。

### 4. 上位 64 ビット

```go:line-numbers=481
	hi = x1*y1 + w2 + w1>>32
```

`hi = x1*y1 + w2 + w1>>32`。一番上の桁に、真ん中の桁から繰り上がってきた分（`w2` と `w1` の上位 32 ビット）を足すと上位 64 ビットが完成です。

### 5. 下位 64 ビット

```go:line-numbers=482
	lo = x * y
```

下位 64 ビットは、ふつうの `x * y`（あふれた部分が捨てられた値）とちょうど同じなので、そのまま計算します。

## ここがすごい

- **あふれない順番で足している**: 真ん中の 2 項を一度に足すと 64 ビットをあふれる可能性があります。そこで 1 項ずつ足し、そのつど上位 32 ビットを分けて繰り上げることで、どの中間結果も 64 ビットに収まるようにしています。
- **下位はズルをする**: 筆算で下位 64 ビットを組み立てることもできますが、「ふつうの掛け算 = 下位 64 ビット」という事実を使って 1 行で済ませています。
- **専用命令の代わり**: 多くの CPU には 64×64→128 ビットの掛け算命令があり、Go のコンパイラはこの関数をその命令に置き換えます。このコードは、命令がない環境向けの実装であり、同時に「何を計算するか」の明確な定義にもなっています。

## まとめ

- 大きな数の掛け算は、半分の幅に分けた筆算で、あふれずに計算できる。
- 中間結果があふれないように、足す順番と繰り上がりの取り出し方を工夫する。
- 下位の結果がふつうの掛け算と一致するなど、既知の性質を使うと計算を減らせる。
