## ひとことで

`math.Mod(x, y)` は、浮動小数点数 `x` を `y` で割った余りを返します。結果の符号は `x` と同じで、大きさは `y` より小さくなります。例えば `math.Mod(7.5, 2)` は `1.5` です（7.5 は 2 が 3 回入り、残りが 1.5）。

整数なら `%` 演算子 1 つで済みますが、浮動小数点数には割り算の商を整数で求める簡単な方法がありません。この関数は、その代わりに **指数部を使った引き算の繰り返し** で答えを作っています。

## コード

```go:line-numbers=29
func mod(x, y float64) float64 {
	if y == 0 || IsInf(x, 0) || IsNaN(x) || IsNaN(y) {
		return NaN()
	}
	y = Abs(y)

	yfr, yexp := Frexp(y)
	r := x
	if x < 0 {
		r = -x
	}

	for r >= y {
		rfr, rexp := Frexp(r)
		if rfr < yfr {
			rexp = rexp - 1
		}
		r = r - Ldexp(y, rexp-yexp)
	}
	if x < 0 {
		r = -r
	}
	return r
}
```

## 前提知識

- **浮動小数点数**: 小数を「仮数 × 2 の指数乗」の形で持つ数です。`float64` は 2 進数で約 53 ビットの精度を持ちます。
- **余り（剰余）**: `x` が `y` の何倍まで入るかを引いた残りです。商を整数に切り捨てて求めます。
- **`Frexp(x)`**: `x = frac × 2^exp` と分けて、`frac` を 0.5 以上 1 未満、`exp` を整数で返す関数です。指数だけを取り出すのに使います。
- **`Ldexp(frac, exp)`**: `frac × 2^exp` を計算する関数です。`Frexp` の逆です。2 のべき乗をかけるだけなので、仮数はそのまま保たれます。
- **NaN（非数）**: 「数ではない値」です。0 で割ったときなど、意味のある結果がないときに使われます。`IsNaN` で判定します。

## 何をしているか

### 1. 特別な値は先に返す

```go:line-numbers=30
	if y == 0 || IsInf(x, 0) || IsNaN(x) || IsNaN(y) {
		return NaN()
	}
	y = Abs(y)
```

`y` が 0、`x` が無限大、`x` か `y` が NaN のときは、余りが定義できないので NaN を返します。そのあと `Abs` で `y` を正の値にしています。結果の符号は `x` で決まるからです。

### 2. y の指数を取り出す

```go:line-numbers=35
	yfr, yexp := Frexp(y)
```

`y` を `yfr × 2^yexp` に分けます。たとえば `y = 2` なら `yfr = 0.5`、`yexp = 2` です。ここで取り出した指数が、あとで「どれくらい大きく引くか」の目安になります。

### 3. 引き算を繰り返す

```go:line-numbers=41
	for r >= y {
		rfr, rexp := Frexp(r)
		if rfr < yfr {
			rexp = rexp - 1
		}
		r = r - Ldexp(y, rexp-yexp)
	}
```

`r` は絶対値にした `x` です。`r >= y` の間、`r` から `y` を引きます。ただし 1 回ずつ `y` を引くと遅すぎるので、`Ldexp` で `y` を `2^(rexp-yexp)` 倍して、一度に大きな塊を引きます。

`rfr < yfr` の判定は、`r` の仮数が `y` の仮数より小さいときに指数を 1 つ下げるための補正です。これで引く塊が `r` を超えないようになります。引き算のたびに `r` は小さくなるので、ループはいつか終わります。

### 4. 符号を戻して返す

```go:line-numbers=48
	if x < 0 {
		r = -r
	}
	return r
```

`x` が負だったので、最後に符号を付け直します。`math.Mod(-7.5, 2)` は `-1.5` になります。

## ここがすごい

- **整数の余りに頼らない**: `float64` は非常に大きな値も扱えますが、整数型に変換できる範囲は限られます。そのため、指数だけを使って大きさを段階的に扱うという方法が使われています。
- **一度に引く量を選ぶ工夫**: 1 回ずつ `y` を引くと、`x` が `y` の何十億倍もあるとき、ループが何十億回も回ります。`Frexp` で指数をそろえると、1 回で 2 の累乗の塊を引けるので、回数を指数の差程度に抑えられます。
- **割り算をしない**: 商を求めて丸める処理がないので、商の丸め誤差に悩まされません。`Ldexp` は 2 のべき乗を掛けるだけなので、仮数の情報が失われにくいのも特徴です。

## まとめ

- 浮動小数点数の余りは、`%` のように一発では求められないので、指数を使って引き算を繰り返す方法が使われます。
- `Frexp` と `Ldexp` を組み合わせると、2 の累乗単位で大きく引けます。
- 結果の符号は被除数 `x` に従い、大きさは `y` より小さくなります。
- 特殊な値（0、無限大、NaN）は、ループに入る前に先に処理されます。
