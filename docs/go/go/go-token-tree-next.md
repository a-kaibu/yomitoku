## ひとことで

二分探索木の中身を、小さい順に全部たどりたいことがあります。そのとき「今の節点の次に大きい節点」を見つけるのが `next` です。例えば、木が `3`、`5`、`8` を含むとき、`3` の次は `5`、`5` の次は `8` です。

`go/token` は、ファイルの位置を探す木を内部に持っていて、その中を順にたどるために使われます。

## コード

```go:line-numbers=169
func (x *node) next() *node {
	if x.right == nil {
		for x.parent != nil && x.parent.right == x {
			x = x.parent
		}
		return x.parent
	}
	x = x.right
	for x.left != nil {
		x = x.left
	}
	return x
}
```

## 前提知識

- **二分探索木の性質**: 左の子は親より小さく、右の子は親より大きい、という約束の木です。中順（左、自分、右）で並べると、小さい順になります。
- **親へのポインタ**: この木の節点は `parent` を持っています。上へ戻るためです。
- **一番左**: 左の子をたどれるだけたどった先の節点です。その部分木の中で一番小さい値になります。
- **「左から来た」関係**: 親の右の子ではない、つまり親の左の子として上がってきた節点です。その親が、次に大きい節点になります。

## 何をしているか

### 1. 右の子がない場合は親へ上がる

```go:line-numbers=170
	if x.right == nil {
		for x.parent != nil && x.parent.right == x {
			x = x.parent
		}
		return x.parent
	}
```

右の子がなければ、この節点の部分木の中では、これより大きい値がありません。そこで、親へ上がっていきます。親の右から上がってきている間は、まだ大きい値がさらに上にあるわけではないので、上がり続けます。上がりが止まったとき、その親が次に大きい節点です。

### 2. 右の子があれば、その中の一番小さい節点へ

```go:line-numbers=176
	x = x.right
	for x.left != nil {
		x = x.left
	}
	return x
```

右の子があれば、次に大きいのは、その右の部分木の中で最も小さい節点です。右へ 1 つ進み、そこから左を最後までたどります。

## ここがすごい

- **親へのポインタで戻れる**: 木の上から下へしかたどれないと、次の節点を探すのに根から探し直す必要があります。親へのポインタがあれば、今いる場所から直接たどれます。
- **1 回の走査の平均が速い**: 全体を中順で回すと、次々に `next` を呼んで、どれも短い道を進むだけで済みます。すべての節点を回る合計の移動は、節点の数の定数倍になります。
- **場合分けが 2 つだけ**: 右の子があるかどうかで、道が 2 通りに分かれます。考え方が分かりやすい形です。

## まとめ

- `next` は、二分探索木で次に大きい節点を返します。
- 右の子があれば、その部分木の一番左へ進みます。
- 右の子がなければ、左から上がってきた最初の親が答えです。
- 親へのポインタを使うので、根から探し直す必要がありません。
