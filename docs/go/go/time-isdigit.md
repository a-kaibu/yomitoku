## ひとことで

`isDigit(s, i)` は、文字列 `s` の `i` 番目の文字が、数字かどうかを返します。数字なら `true`、そうでなければ `false` です。

時刻の書式を読むときは、数字が続く部分と、そうでない部分を見分ける必要があります。この関数は、その判定を一か所にまとめた小さな部品です。位置が範囲の外でも、安全に `false` を返します。

## コード

```go:line-numbers=915
func isDigit[bytes []byte | string](s bytes, i int) bool {
	if len(s) <= i {
		return false
	}
	c := s[i]
	return '0' <= c && c <= '9'
}
```

## 前提知識

- **位置（`i`）**: 文字列の先頭から数えた番号です。最初の文字は 0 番です。
- **範囲外**: 位置が文字列の長さ以上になると、そこには文字がありません。読めばプログラムが止まるので、先に確かめます。
- **ジェネリクス**: `bytes []byte | string` により、バイト列と文字列のどちらでも使えます。
- **数字の範囲**: `'0'` から `'9'` の文字は、文字コードで連続しています。その範囲で判定します。

## 何をしているか

### 1. 範囲の外なら false を返す

```go:line-numbers=916
	if len(s) <= i {
		return false
	}
```

位置 `i` が長さ以上なら、その位置に文字はありません。数字ではないので、`false` を返します。

### 2. 文字が数字の範囲にあるか調べる

```go:line-numbers=919
	c := s[i]
	return '0' <= c && c <= '9'
```

位置の 1 バイトを取り出し、`'0'` 以上で `'9'` 以下なら数字です。その結果を返します。

## ここがすごい

- **読む前に確かめる**: 範囲の確認を先に行うので、どんな位置を渡されても安全です。呼び出し側は、範囲を気にせずに使えます。
- **ジェネリクスで二つの型に対応**: 同じ関数で、文字列とバイト列の両方を扱えます。書式の読み取りを、型に関係なく書けます。
- **判定が単純**: 文字コードの範囲で判定するので、短く、間違えにくい形になっています。

## まとめ

- `isDigit` は、位置の文字が 0 から 9 の数字かを返します。
- 位置が範囲の外なら、読まずに `false` を返します。
- 文字列とバイト列の両方に使える、ジェネリクスの関数です。
