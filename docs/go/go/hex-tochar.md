## ひとことで

`toChar(b)` は、1 バイトの値 `b` を、画面に表示しても安全な文字に変換します。表示できる範囲なら、その文字をそのまま返し、範囲外なら `.` を返します。

16 進数のダンプを出すときに、右側に文字の並びを添えることがあります。その中に制御文字が混じると、画面が乱れてしまいます。この関数は、その乱れを防ぐための小さな部品です。

## コード

```go:line-numbers=255
func toChar(b byte) byte {
	if b < 32 || b > 126 {
		return '.'
	}
	return b
}
```

## 前提知識

- **ASCII の表示できる範囲**: 32（空白）から 126（`~`）までが、画面に表示できる文字です。それより小さい値は、改行やタブなどの制御文字です。
- **制御文字**: 画面の表示を変えたり、動作を指示したりするための値です。普通の文字として表示すると、表示が乱れます。
- **ダンプ**: バイナリのデータを、16 進数と文字で並べて表示する方法です。
- **`.`**: 表示できない文字の代わりに置く、点の記号です。ダンプ表示でよく使われます。

## 何をしているか

### 1. 範囲外なら点を返す

```go:line-numbers=256
	if b < 32 || b > 126 {
		return '.'
	}
```

値が 32 より小さいか、126 より大きいなら、表示できない文字です。その場合は、点 `.` を返します。

### 2. 範囲内なら値をそのまま返す

```go:line-numbers=259
	return b
```

範囲内なら、その値は表示できる文字です。値を変えずに、そのまま返します。

## ここがすごい

- **1 行の判定で安全を守る**: 2 つの比べ方だけで、表示の安全性が決まります。小さな関数なのに、表示の乱れを確実に防ぎます。
- **表示の役目に限定**: 変換の結果は、表示のためだけに使われます。データそのものを壊さないように、元の値は別に保たれます。
- **範囲を数値で書く**: 文字の一覧を作らず、番号の範囲で表します。ASCII の番号の並びを知っていれば、すぐに読めます。

## まとめ

- `toChar` は、表示できない文字を点 `.` に置き換えます。
- 表示できる範囲は、ASCII の 32 から 126 までです。
- ダンプ表示で、画面の乱れを防ぐために使われます。
