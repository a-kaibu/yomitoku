## ひとことで

`x.IsInt64()` は、大きな整数 `x` が、普通の 64 ビット整数（`int64`）に収まるかを返します。収まれば `true`、収まらなければ `false` です。

`math/big` の整数は、いくらでも大きくできます。一方で、`int64` の範囲は決まっています。この関数で先に確かめておくと、`Int64()` を呼んでも安全かどうかが分かります。

## コード

```go:line-numbers=528
func (x *Int) IsInt64() bool {
	if len(x.abs) <= 64/_W {
		w := int64(low64(x.abs))
		return w >= 0 || x.neg && w == -w
	}
	return false
}
```

## 前提知識

- **`int64`**: 64 ビットの符号付き整数です。おおよそ、マイナス 9 京余りから 9 京余りまでの値を表せます。
- **ワード**: 大きな整数を分けて入れる箱です。1 つのワードは 64 ビット（機械によっては 32 ビット）なので、64 ビット以下の値は、ワード 1 つに収まります。
- **符号（`neg`）**: 負の数かどうかを表すフラグです。負の数は、絶対値で表された数に符号を付けて扱われます。
- **`low64`**: 配列の最も下のワードを、64 ビットの値として取り出す関数です。

## 何をしているか

### 1. ワードが 1 つ以下かを見る

```go:line-numbers=529
	if len(x.abs) <= 64/_W {
		w := int64(low64(x.abs))
```

絶対値のワードの数が、64 ビット以下に収まるかを見ます。`_W` は 1 ワードのビット数で、`64/_W` は、64 ビットに必要なワードの数です。

ワードが 1 つ以下なら、`low64` で値を取り出せます。値が長くなるときは、最初から `int64` に収まらないことが決まっています。

### 2. 符号を考えて範囲を確かめる

```go:line-numbers=531
		return w >= 0 || x.neg && w == -w
```

取り出した値 `w` を使って、判定を行います。

- `w >= 0` なら、正の数で、`int64` に収まります。
- `x.neg && w == -w` は、負の数で、かつ `w` が最小の値のときだけ真になります。最小値は絶対値を符号反転しても、同じ値のままになるからです。

この 1 行で、正の範囲と負の範囲の両方を、正しく判定しています。

## ここがすごい

- **先に長さで弾く**: ワードが 2 つ以上あれば、計算をせずに `false` の判定が決まります。大きな数を扱うときの、無駄な計算を省いています。
- **最小値の特別扱い**: `int64` の最小値は、絶対値にすると `int64` の最大値より 1 大きくなります。そのため、負の数の判定には、符号反転して同じになるかの特別な比べ方が必要です。
- **符号と値を一度に見る**: 1 つの式で、正負と範囲の両方を確かめます。短く書けるので、読み間違えにくくなっています。

## まとめ

- `IsInt64` は、大きな整数が `int64` に収まるかを返します。
- ワードが 2 つ以上なら、先に `false` と決まります。
- 負の数の最小値は、特別な判定で正しく扱われます。
