## ひとことで

`heap.Pop(h)` は、ヒープの先頭（いちばん小さい要素）を取り出して、残りをヒープの形に保ちます。優先度付きキューから、次に処理すべきものを取り出す操作にあたります。

取り出した要素は `any` として返されます。`Pop` を呼ぶ側は、その値を元の型に戻して使います。

## コード

```go:line-numbers=59
func Pop(h Interface) any {
	n := h.Len() - 1
	h.Swap(0, n)
	down(h, 0, n)
	return h.Pop()
}
```

## 前提知識

- **ヒープの先頭**: 最小ヒープでは、根（位置 0）に最小値があります。
- **`h.Pop()`**: 利用者が定義する、スライスの末尾を取り除くメソッドです。`heap.Pop` は、その前に先頭と末尾を入れ替えておきます。
- **`any`**: どんな型の値でも入る型です。`interface{}` と同じ意味です。
- **`down(h, 0, n)`**: 先頭を沈める関数で、`n` より後ろは見ないことで、取り出した要素を無視できます。

## 何をしているか

`h = [1, 3, 2, 7, 5]`（`n = 4` として計算する）で追います。

### 1. 先頭と末尾を入れ替える

```go:line-numbers=60
	n := h.Len() - 1
	h.Swap(0, n)
```

最小値の `1` を末尾へ移します。`h` は `[5, 3, 2, 7, 1]` になります。

### 2. 残りの範囲で沈める

```go:line-numbers=62
	down(h, 0, n)
```

`n = 4` なので、位置 0 から 3 だけを見ます。先頭の `5` は、子の `2` と `3` のうち小さい `2` と入れ替わり、`[2, 3, 5, 7, 1]` になります。最後の `down` の戻り値は使いません。

### 3. 末尾を取り除いて返す

```go:line-numbers=63
	return h.Pop()
```

末尾の `1` を取り除いて返します。残りの `[2, 3, 5, 7]` はヒープの形を保っています。

## ここがすごい

- **取り除く場所を末尾にする**: スライスの先頭を取り除くと、残りを全部ずらす必要があります。先頭を末尾へ動かしてから取り除けば、ずらす処理がいりません。
- **沈める範囲を縮める**: 末尾の要素は、もう取り出し済みなので、`down` の範囲に入れません。範囲を `n` で区切るだけで、取り出し済みの要素を気にせず沈められます。
- **取り出しを 1 行で返す**: 戻り値を `h.Pop()` に任せることで、利用者が取り出した値をそのまま受け取れます。

## まとめ

- 最小値の取り出しは、先頭と末尾を入れ替えて、末尾を取り除くと安く済む。
- 取り出し済みの要素を範囲の外に置けば、ヒープの処理を変えずに済む。
- 優先度付きキューは、この操作の繰り返しで作れる。
