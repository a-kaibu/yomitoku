## ひとことで

`math/big` は、とても大きな整数を扱うパッケージです。その中で、大きさを比べる関数が `nat.cmp` です。`x` と `y` のどちらが大きいかを、`-1`、`0`、`1` のいずれかで返します。

大きな数は、「ワード」と呼ばれる機械語の整数（64 ビットなど）を並べた配列で表されます。配列の長さが長いほど、数が大きいことになります。そのため、比べるときは、まず長さを見るだけで答えが出ることが多いです。

## コード

```go:line-numbers=151
func (x nat) cmp(y nat) (r int) {
	m := len(x)
	n := len(y)
	if m != n || m == 0 {
		switch {
		case m < n:
			r = -1
		case m > n:
			r = 1
		}
		return
	}

	i := m - 1
	for i > 0 && x[i] == y[i] {
		i--
	}

	switch {
	case x[i] < y[i]:
		r = -1
	case x[i] > y[i]:
		r = 1
	}
	return
}
```

## 前提知識

- **ワード（Word）**: 大きな整数を分けて入れる箱です。1 つの箱に、機械が一度に扱える大きさの値が入ります。
- **`nat`**: ワードの並びで、大きな非負の整数を表します。配列の先頭が最も下の桁、末尾が最も上の桁です。
- **上の桁から比べる**: 人が数を比べるときと同じです。`1234` と `1299` なら、千の位と百の位が同じなので、十の位で `3` と `9` を比べます。大きな数でも同じ考え方で比べられます。

## 何をしているか

### 1. 桁数が違えば、それだけで決まる

```go:line-numbers=154
	if m != n || m == 0 {
		switch {
		case m < n:
			r = -1
		case m > n:
			r = 1
		}
		return
	}
```

`m` と `n` は、それぞれの配列の長さです。長さが違う場合は、長いほうが大きい数になります。`0` の場合（長さが 0 の場合）も、ここで答えが決まります。

例えば、2 ワードの数と 3 ワードの数は、2 ワードの数のほうが必ず小さくなります。上の桁がない分だけ、値が小さいからです。

### 2. 長さが同じなら、上の桁から探す

```go:line-numbers=164
	i := m - 1
	for i > 0 && x[i] == y[i] {
		i--
	}
```

長さが同じなら、末尾（最も上の桁）から順に、等しくないワードを探します。`i` は、等しくないワードの位置を指すことになります。ただし、先頭の 1 つは最後まで調べません。

### 3. 違うワードで大小を決める

```go:line-numbers=169
	switch {
	case x[i] < y[i]:
		r = -1
	case x[i] > y[i]:
		r = 1
	}
	return
```

見つかった位置のワードを比べて、答えを決めます。どちらも等しければ、`r` は初期値の `0` のままです。

## ここがすごい

- **大半は一瞬で終わる**: 桁数が違えば、配列の中身を見ずに答えが出ます。大きな数どうしの比較で、ほとんどの場合は長さだけを比べれば済みます。
- **必要な所だけを見る**: 上の桁が一致している間だけ、次の桁を見ます。等しくない桁が見つかった時点で、残りは見ずに終わります。
- **ワードの比べ方に頼る**: 1 ワードは機械の整数なので、ワードどうしは普通の `<` と `>` で比べられます。大きな数の仕組みを、単純な比べ方の繰り返しで作っています。

## まとめ

- `cmp` は、大きな整数 `x` と `y` の大小を `-1`、`0`、`1` で返します。
- 長さが違えば、長さだけで答えが決まります。
- 長さが同じなら、上の桁から等しくないワードを探して比べます。
- 同じ値のときは `0` を返します。
