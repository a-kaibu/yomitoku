## ひとことで

`reverseRange(data, a, b)` は、`a` から `b` の手前までの要素を、逆の順番に並べ替えます。例えば `[1, 2, 3, 4]` は `[4, 3, 2, 1]` になります。

この関数は、ソートの途中で、降順の並びを作るときに使われます。すでに逆に並んでいるかもしれない部分を、短い手数で反転させるための道具です。

## コード

```go:line-numbers=319
func reverseRange(data Interface, a, b int) {
	i := a
	j := b - 1
	for i < j {
		data.Swap(i, j)
		i++
		j--
	}
}
```

## 前提知識

- **範囲**: `a` から `b` の手前まで、という区間です。`b` 自身は含みません。
- **端と中央**: 範囲の両端から、内側に向かって進んでいくと、最後は真ん中で出会います。
- **`Swap`**: 2 つの要素の位置を入れ替える操作です。`Interface` の一部として、どんな並びでも使えます。
- **`b - 1`**: 範囲の最後の要素の位置です。`b` そのものは範囲の外なので、1 つ前から始めます。

## 何をしているか

### 1. 両端の位置を決める

```go:line-numbers=320
	i := a
	j := b - 1
```

`i` は範囲の先頭、`j` は範囲の末尾を指します。この 2 つが、入れ替える要素の組になります。

### 2. 中央で止まるまで、外側から入れ替える

```go:line-numbers=322
	for i < j {
		data.Swap(i, j)
		i++
		j--
	}
```

`i < j` の間、両端の要素を入れ替えます。その後、`i` を 1 つ右へ、`j` を 1 つ左へ動かします。2 つが中央で出会ったら、`i < j` が偽になり、ループは終わります。

## ここがすごい

- **半分の手数で済む**: 入れ替えは、組の数だけ行われます。要素が 10 個なら、5 回の入れ替えで反転が完成します。
- **偶数でも奇数でも正しい**: 要素が奇数個なら、真ん中の要素は動きません。中央で `i` と `j` が同じになって、ループが自然に止まります。
- **1 つの仕組みで範囲を扱う**: 範囲の端を `a` と `b` で指定するので、全体でも一部でも、同じ関数で反転できます。

## まとめ

- `reverseRange` は、範囲の要素を逆順に並べ替えます。
- 両端から中央へ向かって、順に入れ替えていきます。
- 半分の回数の入れ替えで、反転が完成します。
