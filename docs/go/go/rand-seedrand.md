## ひとことで

`seedrand(x)` は、乱数の内部の状態 `x` を、次の値へ進める関数です。`x = 48271 × x mod (2^31 − 1)` という式で、同じ入力からは同じ出力が得られます。これは **線形合同法** の 1 種で、Park と Miller が提案した「最小標準」の乱数生成器です。

`math/rand` は、この関数で種を初期化するときに使われ、初期状態を作ります。

## コード

```go:line-numbers=187
func seedrand(x int32) int32 {
	const (
		A = 48271
		Q = 44488
		R = 3399
	)

	hi := x / Q
	lo := x % Q
	x = A*lo - R*hi
	if x < 0 {
		x += int32max
	}
	return x
}
```

## 前提知識

- **線形合同法**: `x = (a × x + c) mod m` の形の、簡単な乱数生成法です。`a`、`c`、`m` の選び方で、性質が決まります。
- **`int32` の溢れ**: 32 ビットの整数は、`2^31` を超えると溢れます。`48271 × x` は、そのままでは溢れてしまいます。
- **`mod` の代わり**: `x mod Q` の性質を使うと、大きな積を作らずに剰余を計算できます。`A*lo − R*hi` は、その変形です。
- **定数のまとまり**: `const ( A = ...; Q = ...; R = ... )` は、名前付きの定数の並びです。

## 何をしているか

### 1. 商と余りに分ける

```go:line-numbers=194
	hi := x / Q
	lo := x % Q
```

`x` を `Q` で割って、商 `hi` と余り `lo` に分けます。`Q` は `2^31 ÷ A` に近い値で、この分け方が、後の計算が溢れないための鍵です。

### 2. 差の形で剰余を計算する

```go:line-numbers=196
	x = A*lo - R*hi
```

`A*x mod M` を、`A*lo − R*hi` の形に書き換えています。`A*lo` は、`lo` が `Q` より小さいので、`int32` に収まります。`R*hi` も同様です。結果が負になることがあるので、次の処理で補正します。

### 3. 負になったら足して戻す

```go:line-numbers=197
	if x < 0 {
		x += int32max
	}
	return x
```

`x` が負なら、モジュラスの `int32max`（2^31 − 1）を足して、0 から `int32max − 1` の範囲に戻します。そのあと、新しい `x` を返します。

## ここがすごい

- **溢れない計算順序**: 大きな積を先に作らず、商と余りに分けてから掛けるので、32 ビット整数の中だけで計算が終わります。
- **定数の選び方**: 48271 と 2^31 − 1 は、良い乱数の性質を持つことが知られている組です。`Q` と `R` は、その組を分けて計算するための値です。
- **状態が 1 つの整数だけ**: 乱数の状態は `x` の 1 つだけです。小さなメモリで、再現可能な乱数列が作れます。

## まとめ

- `seedrand` は、乱数の状態を `48271 × x mod (2^31 − 1)` で進めます。
- 商と余りに分けて計算すると、32 ビットの中で溢れずに済みます。
- 結果が負のときだけ、モジュラスを足して補正します。
- 同じ種からは、同じ乱数列が再現できます。
