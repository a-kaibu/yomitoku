## ひとことで

`isLeap(2024)` は `true`、`isLeap(1900)` は `false` を返します。閏年の条件を、4 で割れるか、100 で割れないか、400 で割れるか、の組み合わせで表します。この関数は、その判定を割り算を使わずに行います。

## コード

::: code-group

```go:line-numbers=1684 [日本語訳]
func isLeap(year int) bool {
	// うるう年の条件: 4 で割り切れて、かつ（100 で割り切れないか、400 で割り切れる）。
	// 下位 2 ビットが 0 でなければならない。
	// 25 の倍数なら、下位 4 ビットが 0 でなければならない。
	// このやり方は Cassio Neri のアイデアによる。
	mask := 0xf
	if year%25 != 0 {
		mask = 3
	}
	return year&mask == 0
}
```

```go:line-numbers=1684 [原文]
func isLeap(year int) bool {
	// year%4 == 0 && (year%100 != 0 || year%400 == 0)
	// Bottom 2 bits must be clear.
	// For multiples of 25, bottom 4 bits must be clear.
	// Thanks to Cassio Neri for this trick.
	mask := 0xf
	if year%25 != 0 {
		mask = 3
	}
	return year&mask == 0
}
```

:::

## 前提知識

- **閏年の決まり**: 4 で割り切れる年は閏年です。ただし、100 で割り切れる年は除き、400 で割り切れる年は閏年とします。
- **2 進数の下位ビット**: 下位 2 ビットが 0 なら、4 で割り切れます。下位 4 ビットが 0 なら、16 で割り切れます。
- **`&` とマスク**: 特定のビットだけを取り出す計算です。`year & mask == 0` で、そのビットがすべて 0 かを判定します。
- **割り算の代わり**: 2 進数の性質を使うと、割り算より安く判定できます。

## 何をしているか

### 1. 閏年の条件を確認する

```go:line-numbers=1685
	// うるう年の条件: 4 で割り切れて、かつ（100 で割り切れないか、400 で割り切れる）。
```

コメントにある式が、閏年の本来の条件です。ここでは、それをビットの判定に置き換えます。

### 2. 通常の年は下位 2 ビットを見る

```go:line-numbers=1686
	// 下位 2 ビットが 0 でなければならない。
```

下位 2 ビットが 0 なら、4 で割り切れます。

### 3. 25 の倍数はマスクを変える

```go:line-numbers=1687
	// 25 の倍数なら、下位 4 ビットが 0 でなければならない。
	// このやり方は Cassio Neri のアイデアによる。
	mask := 0xf
	if year%25 != 0 {
		mask = 3
	}
```

25 の倍数は、100 の倍数になりうるので、判定を厳しくします。`year%25 != 0` のときは `mask = 3`（下位 2 ビット）です。25 の倍数のときは `mask = 0xf`（下位 4 ビット）になり、16 で割り切れるかを見ます。こうすると、4 と 400 の関係を、マスクだけで表せます。

### 4. マスクで判定する

```go:line-numbers=1693
	return year&mask == 0
```

`year&mask == 0` なら、閏年です。

## ここがすごい

- **割り算をしない**: 割り算の代わりに、ビットのマスクと比べるので、計算が軽くなります。
- **条件を 1 行に畳む**: 通常の年と 25 の倍数で、マスクを 1 つ切り替えるだけで、閏年の全条件を表せます。
- **数学の性質を利用する**: 2 進数の性質を理解すると、割り算を避ける工夫が分かります。

## まとめ

- 閏年の条件は、4 と 100 と 400 の割り切れの組み合わせである。
- 25 の倍数だけ、判定のマスクを 4 ビットに広げる。
- ビットのマスクで判定するので、割り算が要らない。
