## ひとことで

`math.Signbit(x)` は、`x` の符号が負なら `true` を返します。`Signbit(-2.5)` は `true`、`Signbit(2.5)` は `false` です。

ふつうは `x < 0` と比べたくなりますが、それでは `-0` が負と判定されません。この関数は、浮動小数点数のビットを見て符号を判定するので、`-0` も正しく扱えます。

## コード

```go:line-numbers=8
func Signbit(x float64) bool {
	return int64(Float64bits(x)) < 0
}
```

## 前提知識

- **符号ビット**: `float64` の 64 ビットのうち、いちばん上の 1 ビットです。1 なら負、0 なら正を表します。
- **`-0`**: 浮動小数点数には、符号の違う 0 があります。比べると等しいですが、符号ビットは 1 です。
- **`Float64bits`**: `float64` のビットを、そのまま `uint64` として取り出します。値は変わりません。
- **`int64` の符号**: 2 の補数で表された `int64` では、いちばん上のビットが 1 なら負の値になります。

## 何をしているか

### 1. ビットを整数として見る

```go:line-numbers=9
	return int64(Float64bits(x)) < 0
```

`Float64bits(x)` は、`x` のビット列をそのまま取り出します。それを `int64` に変換すると、いちばん上のビットが符号ビットとして扱われます。そして、その値が 0 より小さければ、符号ビットは 1 です。

### 2. 具体例

`x = -2.5` のビットは、いちばん上が 1 です。`int64` にすると負の数になるので `true` です。

`x = -0.0` のビットも、いちばん上が 1 です。`x < 0` は偽ですが、この関数は `true` を返します。

## ここがすごい

- **比較を使わない**: `x < 0` は、`-0` や NaN では期待どおりになりません。ビットを見る方法なら、どんな値でも符号を確実に読み取れます。
- **1 行で済む**: 型の変換と比較を組み合わせるだけなので、分岐がありません。CPU の命令も少なく済みます。
- **符号を値として扱える**: `Copysign` や `Abs` など、符号に関わる関数は、このように符号ビットを直接扱って作られています。

## まとめ

- 浮動小数点数の符号は、比べるより、ビットを見るほうが確実。
- `-0` のような特殊な値も、符号ビットで正しく判定できる。
- 符号ビットの扱いは、絶対値や符号のコピーといった関数の土台になる。
