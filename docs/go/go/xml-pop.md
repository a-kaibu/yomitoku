## ひとことで

`d.pop()` は、開いている XML 要素の記録を、スタックの一番上から取り出して返します。例えば `<a><b>` の中で閉じたときは、`b` の記録が取り出されます。

取り出した記録は捨てずに、空きリストに戻します。次に要素を開くとき、その記録を作り直さずに再利用できます。

## コード

```go:line-numbers=409
func (d *Decoder) pop() *stack {
	s := d.stk
	if s != nil {
		if s.kind == stkStart {
			d.stkDepth--
		}
		d.stk = s.next
		s.next = d.free
		d.free = s
	}
	return s
}
```

## 前提知識

- **スタック**: 後から入れたものを先に取り出す、後入れ先出しの構造です。XML の入れ子の開始と終了の対応に使われます。
- **`stkStart`**: スタックの項目が、開始タグを表すことを示す種類です。
- **`stkDepth`**: 今の入れ子の深さを数える値です。開始タグを取り出したときだけ減らします。
- **空きリスト（`free`）**: 使い終わった記録を、次に再利用できるように繋いでおく一覧です。

## 何をしているか

### 1. 開始タグなら深さを減らす

```go:line-numbers=412
		if s.kind == stkStart {
			d.stkDepth--
		}
```

取り出す項目が開始タグなら、入れ子の深さを一つ減らします。終了タグや他の種類の項目では、深さは変えません。

### 2. スタックの先頭を外して空きリストへ移す

```go:line-numbers=415
		d.stk = s.next
		s.next = d.free
		d.free = s
```

スタックの先頭を、一つ下の項目に進めます。取り出した項目は、空きリストの先頭につないで、次の再利用に備えます。

## ここがすごい

- **記録を作り直さない**: 使い終わった項目を空きリストに戻すので、要素を開くたびに新しく作る必要がありません。メモリの確保が減ります。
- **深さと中身を分けて管理**: 深さは開始タグだけで数えるので、終了タグや文字データの項目によって数がずれることがありません。
- **空でも安全**: スタックが空なら何もせず、`nil` を返します。取り出しの前に、空かどうかを確かめています。

## まとめ

- `pop` は、開いている要素のスタックから一番上を取り出して返します。
- 開始タグを取り出したときは、深さを一つ減らします。
- 取り出した記録は空きリストに戻し、次の要素で再利用します。
