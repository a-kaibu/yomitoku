## ひとことで

`z.Inv(x)` は、分数 `x` の逆数を `z` に設定します。例えば `2/3` の逆数は `3/2` です。分子と分母を入れ替えるだけで、逆数が求まります。

ただし、`x` が 0 のときは逆数が存在しません。そのとき、この関数はパニックを起こして、0 で割ったことを知らせます。

## コード

```go:line-numbers=385
func (z *Rat) Inv(x *Rat) *Rat {
	if len(x.a.abs) == 0 {
		panic("division by zero")
	}
	z.Set(x)
	z.a.abs, z.b.abs = z.b.abs, z.a.abs
	return z
}
```

## 前提知識

- **`Rat` 型**: 有理数、つまり分数を表す型です。内部では、分子と分母を、それぞれ整数の値として持っています。
- **逆数**: `x` にかけると 1 になる数です。`2/3` と `3/2` は、互いに逆数になります。
- **ゼロ除算**: 0 で割ろうとする計算です。数学でも、プログラムでも、答えが定義できません。
- **パニック**: Go で、回復できない異常を知らせる仕組みです。`panic` を起こすと、呼び出し元にエラーの内容が伝わります。
- **`z.Set(x)`**: `z` に `x` の値をコピーします。その後で、`z` だけを書き換えることができます。

## 何をしているか

### 1. 0 の逆数を防ぐ

```go:line-numbers=386
	if len(x.a.abs) == 0 {
		panic("division by zero")
	}
```

分子の絶対値の長さが 0 なら、`x` の値は 0 です。0 の逆数は作れないので、ここで `panic` を起こします。

### 2. 値をコピーする

```go:line-numbers=389
	z.Set(x)
```

まず、`x` の値を `z` にコピーします。`z` と `x` が同じ変数でも、ここで値が正しく引き継がれます。

### 3. 分子と分母を入れ替える

```go:line-numbers=390
	z.a.abs, z.b.abs = z.b.abs, z.a.abs
```

分子の `a.abs` と、分母の `b.abs` を入れ替えます。`2/3` は `3/2` になり、逆数が完成します。

入れ替えは、2 つの値を一度に代入して行います。一時的な変数を使わなくても、安全に入れ替えられます。

## ここがすごい

- **計算をしない**: 逆数を求めるのに、割り算を行う必要がありません。分子と分母を入れ替えるだけなので、とても速いです。
- **0 だけを特別扱い**: 0 以外のどの値でも、同じ方法で逆数が求まります。例外になるのは、0 の場合だけです。
- **値のコピーを使う**: `z.Set(x)` でコピーしてから入れ替えるので、`z` と `x` が同じ変数でも、正しく動きます。

## まとめ

- `Inv` は、分数の分子と分母を入れ替えて、逆数を作ります。
- 0 のときは、逆数がないので `panic` を起こします。
- 値をコピーしてから入れ替えるので、`z` と `x` が同じでも使えます。
