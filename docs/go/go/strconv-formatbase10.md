## ひとことで

`formatBase10(a, u)` は、整数 `u` を 10 進数の文字列にして、バイト列 `a` に **右詰めで** 書き込みます。`a` の長さは、あらかじめ `u` の桁数ちょうどに用意されています。

素直な方法は「10 で割った余りを 1 桁ずつ書く」ですが、割り算はコンピュータにとって重い計算です。この関数は **2 桁ずつ** 書き、さらに 64 ビットの割り算を 8 桁に 1 回に減らしています。

func formatBase10(a []byte, u uint64) {
	nd := len(a)
	for nd >= 8 {
		// 下 8 桁（4 組）を書き出す。
		x3210 := uint32(u % 1e8)
		u /= 1e8
		x32, x10 := x3210/1e4, x3210%1e4
		x1, x0 := (x10/100)*2, (x10%100)*2
		x3, x2 := (x32/100)*2, (x32%100)*2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		a[nd-3], a[nd-4] = smalls[x1+1], smalls[x1]
		a[nd-5], a[nd-6] = smalls[x2+1], smalls[x2]
		a[nd-7], a[nd-8] = smalls[x3+1], smalls[x3]
		nd -= 8
	}

	x := uint32(u)
	if nd >= 4 {
		// 下 4 桁（2 組）を書き出す。
		x10 := x % 1e4
		x /= 1e4
		x1, x0 := (x10/100)*2, (x10%100)*2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		a[nd-3], a[nd-4] = smalls[x1+1], smalls[x1]
		nd -= 4
	}
	if nd >= 2 {
		// 下 2 桁を書き出す。
		x0 := (x % 1e2) * 2
		x /= 1e2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		nd -= 2
	}
	if nd > 0 {
		// 最後の 1 桁を書き出す。
		a[0] = byte('0' + x)
	}
}

	for nd >= 8 {
		// Format last 8 digits (4 pairs).
		x3210 := uint32(u % 1e8)
		u /= 1e8
		x32, x10 := x3210/1e4, x3210%1e4
		x1, x0 := (x10/100)*2, (x10%100)*2
		x3, x2 := (x32/100)*2, (x32%100)*2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		a[nd-3], a[nd-4] = smalls[x1+1], smalls[x1]
		a[nd-5], a[nd-6] = smalls[x2+1], smalls[x2]
		a[nd-7], a[nd-8] = smalls[x3+1], smalls[x3]
		nd -= 8
	}

	x := uint32(u)
	if nd >= 4 {
		// Format last 4 digits (2 pairs).
		x10 := x % 1e4
		x /= 1e4
		x1, x0 := (x10/100)*2, (x10%100)*2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		a[nd-3], a[nd-4] = smalls[x1+1], smalls[x1]
		nd -= 4
	}
	if nd >= 2 {
		// Format last 2 digits.
		x0 := (x % 1e2) * 2
		x /= 1e2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		nd -= 2
	}
	if nd > 0 {
		// Format final digit.
		a[0] = byte('0' + x)
	}
}

:::

`smalls` は `"00010203...9899"` という 200 文字の定数で、数 `n`（0〜99）の 2 文字は `smalls[n*2]` と `smalls[n*2+1]` にあります。

## 前提知識

- **`1e8`**: 10 の 8 乗（1 億）です。Go では整数の文脈で使うと整数定数として扱われます。
- **`%` と `/`**: 割り算の余りと商です。`12345678 % 100 = 78`、`12345678 / 100 = 123456`。
- **`uint32` と `uint64`**: 32 ビットと 64 ビットの符号なし整数です。多くの CPU で、64 ビットの割り算は 32 ビットより遅くなります。
- **多重代入 `a, b = x, y`**: 2 つの変数に同時に代入します。
- **`'0' + x`**: 文字 `'0'` の文字コードに `x` を足すと、数字 `x` の文字になります。

## 何をしているか

`u = 1234567890`（10 桁）で追います。`a` の長さ `nd = 10` です。

### 1. 下 8 桁をまとめて処理

```go:line-numbers=194
	for nd >= 8 {
		// 下 8 桁（4 組）を書き出す。
		x3210 := uint32(u % 1e8)
		u /= 1e8
		x32, x10 := x3210/1e4, x3210%1e4
		x1, x0 := (x10/100)*2, (x10%100)*2
		x3, x2 := (x32/100)*2, (x32%100)*2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		a[nd-3], a[nd-4] = smalls[x1+1], smalls[x1]
		a[nd-5], a[nd-6] = smalls[x2+1], smalls[x2]
		a[nd-7], a[nd-8] = smalls[x3+1], smalls[x3]
		nd -= 8
	}
```

`x3210 = u % 1e8 = 34567890`、`u = 12` になります。ここで 64 ビットの割り算は終わりで、以降は 32 ビットで計算します。

8 桁を 4 桁ずつに分け（`x32 = 3456`、`x10 = 7890`）、さらに 2 桁ずつに分けます。`x0 = 90*2`、`x1 = 78*2`、`x2 = 56*2`、`x3 = 34*2` です（`*2` は `smalls` の位置を求めるため）。
そして、右から 2 文字ずつ書き込みます。

```
a = [?, ?, '3', '4', '5', '6', '7', '8', '9', '0']
```

`nd = 2` になります。

### 2. 4 桁単位

```go:line-numbers=209
	if nd >= 4 {
		// 下 4 桁（2 組）を書き出す。
		x10 := x % 1e4
		x /= 1e4
		x1, x0 := (x10/100)*2, (x10%100)*2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		a[nd-3], a[nd-4] = smalls[x1+1], smalls[x1]
		nd -= 4
	}
```

`nd = 2` なので飛ばします。

### 3. 2 桁単位

```go:line-numbers=218
	if nd >= 2 {
		// 下 2 桁を書き出す。
		x0 := (x % 1e2) * 2
		x /= 1e2
		a[nd-1], a[nd-2] = smalls[x0+1], smalls[x0]
		nd -= 2
	}
```

`x = 12`。`x0 = 12*2 = 24` なので、`smalls[24] = '1'`、`smalls[25] = '2'` を書き込みます。

```
a = ['1', '2', '3', '4', '5', '6', '7', '8', '9', '0']
```

### 4. 最後の 1 桁

```go:line-numbers=225
	if nd > 0 {
		// 最後の 1 桁を書き出す。
		a[0] = byte('0' + x)
	}
```

桁数が奇数のときだけ、最後に残った 1 桁を `'0' + x` で書きます。

## ここがすごい

- **割り算の回数が 4 分の 1 以下**: 1 桁ずつなら 10 桁で 10 回の割り算が要りますが、2 桁ずつなら 5 回程度です。しかも定数での割り算は、コンパイラが掛け算とシフトに置き換えるので、さらに速くなります。
- **64 ビットの割り算を最小限に**: 8 桁ごとに 1 回だけ 64 ビットで割り、残りの細かい分割は速い 32 ビットで行います。1 億未満の値は必ず 32 ビットに収まるという性質を利用しています。
- **2 桁を表から書く**: `smalls` の表を使えば、2 桁ぶんの文字を「計算」せずに「コピー」できます。200 バイトの表で、割り算と足し算をまとめて省いています。
- **右から書くので反転不要**: 下の桁から求まるので、配列の右端から書いていけば、最後に並べ替える必要がありません。

## まとめ

- 整数の文字列化は、2 桁ずつ表を引くと割り算の回数を半分以下にできる。
- 大きな数はまず 8 桁単位に分け、細かい処理は速い 32 ビット演算で行う。
- 下の桁から順に求まる値は、バッファの右端から書けば反転がいらない。
