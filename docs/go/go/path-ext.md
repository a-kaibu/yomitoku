## ひとことで

`path.Ext("main.go")` は `".go"` を返します。ファイル名の最後の「.」から後ろの部分が拡張子です。拡張子がなければ空の文字列を返します。

探し方のポイントは、**後ろから** 探すことと、**「/」に当たったら止まる** ことです。だから、`"dir.d/file"` のようにディレクトリ名に「.」があっても、拡張子とは見なされません。

## コード

```go:line-numbers=179
func Ext(path string) string {
	for i := len(path) - 1; i >= 0 && path[i] != '/'; i-- {
		if path[i] == '.' {
			return path[i:]
		}
	}
	return ""
}
```

## 前提知識

- **パスの区切り**: `path` パッケージの区切りは「/」だけです。
- **後ろから探す**: `for i := len(path) - 1; ...; i--` のように、添字を末尾から減らしながら見ていく書き方です。最初に見つかったものが、もっとも後ろにあるものになります。
- **部分文字列 `path[i:]`**: `i` の位置から末尾までを切り出します。コピーを作らず、元の文字列の一部を指します。
- **`Ext` と複数の拡張子**: `"file.tar.gz"` のように「.」が複数あるとき、最後のものだけが拡張子になります。

## 何をしているか

`path = "dir.d/file.tar.gz"` で追います。

### 1. 末尾から「/」か先頭まで進む

```go:line-numbers=180
	for i := len(path) - 1; i >= 0 && path[i] != '/'; i-- {
		if path[i] == '.' {
			return path[i:]
		}
	}
```

末尾から 1 文字ずつ戻ります。途中で「/」に当たると、ループの条件が偽になって止まります。`"file.tar.gz"` の部分では、最初に見つかる「.」は末尾近くの `".gz"` の前の点です。その位置から切り出すと `".gz"` になります。

### 2. ディレクトリの「.」は見ない

`"dir.d/file"` では、末尾から `"file"` を見て、「/」に当たります。`dir.d` の「.」には届かないので、結果は空の文字列です。

### 3. 拡張子がなければ空

```go:line-numbers=185
	return ""
```

先頭まで「.」がなければ、拡張子はありません。

## ここがすごい

- **止める条件が 2 つ**: 「.」を見つけた時点と、「/」に当たった時点の 2 か所で探索を止めます。ディレクトリ名と拡張子を、1 つの走査で区別しています。
- **後ろから見つけると 1 回で終わる**: 最後の「.」を求めるなら、前から全部見るより、後ろから見ついた時点で止めるほうが速いです。
- **部分文字列を返す**: 拡張子は元の文字列の一部なので、コピーなしで返せます。

## まとめ

- 拡張子は、最後の区切りより後ろにある最後の「.」から後ろで決まる。
- 探索は後ろから行い、区切りに当たったら止める。
- 切り出しは部分文字列で行えば、コピーなしで済む。
