## ひとことで

`small(i)` は、0〜99 の小さな整数を文字列に変換する内部関数です。`small(7)` は `"7"`、`small(42)` は `"42"` を返します。
ポイントは、**新しい文字列を作らず、あらかじめ用意した定数の文字列から切り出して返す** ことです。メモリの確保が起きません。

`strconv.Itoa` や `strconv.FormatInt` で、値が 100 未満のときに使われます。

## コード

```go:line-numbers=169
func small(i int) string {
	if i < 10 {
		return digits[i : i+1]
	}
	return smalls[i*2 : i*2+2]
}
```

`digits` は `"0123456789abcdefghijklmnopqrstuvwxyz"`、`smalls` は `"00010203040506070809101112...9899"` という 200 文字の文字列定数です（同じファイルで定義）。

## 前提知識

- **文字列のスライス式 `s[a:b]`**: 文字列の a バイト目から b バイト目の手前までを取り出します。Go の文字列は変更できないので、**元の文字列のメモリを共有するだけで、コピーは作りません**。
- **定数の文字列**: プログラムに直接書いた文字列は、実行ファイルの中に埋め込まれていて、実行中に確保されることはありません。
- **メモリ確保（アロケーション）**: 新しい値のために、実行中にメモリを用意することです。Go ではガベージコレクタ（不要なメモリを回収する仕組み）の負担にもなるので、少ないほど速くなります。

## 何をしているか

### 1. 1 桁の場合

```go:line-numbers=170
	if i < 10 {
		return digits[i : i+1]
	}
```

`i = 7` なら `digits[7:8]` で `"7"` を返します。`digits` の 7 番目の文字が `'7'` だからです。

### 2. 2 桁の場合

```go:line-numbers=173
	return smalls[i*2 : i*2+2]
```

`smalls` は `"00"`, `"01"`, ..., `"99"` を 2 文字ずつ順に並べた文字列です。数 `i` の表現は `i*2` 文字目から 2 文字です。

`i = 42` なら `smalls[84:86]` です。`smalls` の 84〜85 文字目は `"42"` です。

```
smalls = "00 01 02 ... 41 42 43 ..."
          0  2  4      82 84 86
```

### 3. 呼び出し元

`FormatInt` は、値が 0 以上 100 未満なら `small` を使い、それ以外ならふつうに文字を組み立てます。

## ここがすごい

- **メモリ確保ゼロ**: 小さな数の文字列化は、ログ出力やテンプレートなどで非常に頻繁に起きます。そのたびにメモリを確保すると、ガベージコレクタの仕事が増えます。切り出しだけで済ませれば、確保は一切起きません。
- **1 つの表を 2 つの目的に使う**: `smalls` は、`small` 関数だけでなく、大きな数を 2 桁ずつ文字にする処理（`formatBase10` など）でも使われています。「2 桁ずつ変換する表」を、そのまま「小さな数の答え」としても使い回しているのです。
- **Go の文字列の性質を活用**: Go の文字列が変更不可能で、部分文字列がメモリを共有するという性質があるからこそ、安全にこの手が使えます。

## まとめ

- よく使う小さな値の文字列は、あらかじめ並べた定数から切り出せばメモリ確保がいらない。
- Go の部分文字列はコピーを作らないので、定数の一部を返すのは安くて安全。
- 同じ表を複数の処理で使い回すと、無駄がない。
