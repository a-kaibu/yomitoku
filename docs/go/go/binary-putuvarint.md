## ひとことで

`binary.PutUvarint(buf, 300)` は、`300` を 2 バイトに書いて、`2` を返します。小さい数ほど少ないバイトで書けるので、ファイル形式などでよく使われます。

## コード

```go:line-numbers=51
func PutUvarint(buf []byte, x uint64) int {
	i := 0
	for x >= 0x80 {
		buf[i] = byte(x) | 0x80
		x >>= 7
		i++
	}
	buf[i] = byte(x)
	return i + 1
}
```

## 前提知識

- **可変長整数（varint）**: 値の大きさに応じてバイト数が変わる整数の書き方です。
- **7 ビットのかたまり**: 1 バイトの下位 7 ビットに、値を分けて入れます。残りの 1 ビットは、続きがあるかの印です。
- **最上位ビットの印 `0x80`**: 続きのバイトであることを示すビットです。
- **`x >>= 7`**: 値を 7 ビット右にずらして、次の 7 ビットを使えるようにします。

## 何をしているか

### 1. 続きがある間は印を付けて書く

```go:line-numbers=52
	i := 0
	for x >= 0x80 {
		buf[i] = byte(x) | 0x80
		x >>= 7
		i++
	}
```

`x` が `0x80` 以上の間は、下位 7 ビットを書き、続きの印 `0x80` を立てます。書いたあと、`x` を 7 ビット右にずらして、次のかたまりへ進みます。`i` は書いたバイト数を数えます。

### 2. 最後のかたまりを書く

```go:line-numbers=58
	buf[i] = byte(x)
```

残りの値は `0x80` より小さいので、印を付けずに書きます。これで、続きが無いことを示します。

### 3. 書いたバイト数を返す

```go:line-numbers=59
	return i + 1
```

`i + 1` は、書いた総バイト数です。呼び出し側は、この数を使って、続きの書き込み位置を決められます。

## ここがすごい

- **小さい値は短く書く**: 127 までは 1 バイトで済みます。多くの数が小さい場合に、全体の大きさを抑えられます。
- **続きの印で読み方が分かる**: 読む側は、最上位ビットを見るだけで、値がどこまで続くかを判断できます。
- **書いた量を返す**: バッファの中で、どこまで使ったかが分かります。

## まとめ

- 7 ビットずつに分け、続きがあるバイトには最上位ビットの印を付ける。
- 最後のバイトには印を付けず、続きが無いことを示す。
- 書いた総バイト数を返し、続きの位置を決められるようにする。
