## ひとことで

`hash/fnv` は、データから短い数（ハッシュ値）を作る FNV というハッシュ関数を提供します。ハッシュ値は、同じデータからは必ず同じ値になり、違うデータからは違う値になりやすいものです。

`sum64a.Write` は、そのうち 64 ビットの FNV-1a を計算する部分です。データを渡すと、その内容をハッシュ値に取り込みます。

## コード

```go:line-numbers=130
func (s *sum64a) Write(data []byte) (int, error) {
	hash := *s
	for _, c := range data {
		hash ^= sum64a(c)
		hash *= prime64
	}
	*s = hash
	return len(data), nil
}
```

## 前提知識

- **ハッシュ値**: 任意の長さのデータを、固定の長さの数に変換したものです。辞書の検索や、データの同一性の判定に使われます。
- **XOR（`^`）**: 桁ごとに、違えば 1、同じなら 0 にする演算です。
- **乗算による混ぜ方**: 素数を掛けると、下の桁から上の桁へ影響が広がります。XOR と組み合わせることで、ビットが混ざり合います。
- **`io.Writer` の実装**: `Write` メソッドを持つ型は、データを書き込めます。`hash.Hash64` は、この `Write` で少しずつデータを取り込み、最後にハッシュ値を取り出せます。

## 何をしているか

`s` を初期値、`data = "a"` を書き込むとして、1 バイトの処理を追います。

### 1. 作業用に値を取り出す

```go:line-numbers=131
	hash := *s
```

ポインタの先の値を、ローカル変数にコピーします。計算はこの変数で行い、最後にまとめて書き戻します。

### 2. 1 バイトずつ取り込む

```go:line-numbers=132
	for _, c := range data {
		hash ^= sum64a(c)
		hash *= prime64
	}
```

`'a'` を XOR で取り込み、素数 `prime64` を掛けます。次のバイトがあれば、同じことを繰り返します。

### 3. 書き戻して、書いた量を返す

```go:line-numbers=136
	*s = hash
	return len(data), nil
```

結果を `*s` に戻します。`Write` は、書いたバイト数と、エラーの `nil` を返します。

## ここがすごい

- **とても単純な更新**: 1 バイトごとに、XOR と掛け算の 2 つだけです。コードは短く、計算も速いので、ハッシュテーブルの鍵などに向いています。
- **「XOR してから掛ける」の順番**: FNV-1a では、先に XOR してから掛けます。先に掛けてから XOR する FNV-1 より、下の桁の変化がよく混ざると言われています。ここでは、その FNV-1a の形が使われています。
- **ローカル変数で作業する**: 途中の計算をポインタ経由で行うと、毎回メモリを読み書きすることになります。一度ローカルへ取り出すことで、ループが速くなります。

## まとめ

- ハッシュ値は、データの 1 バイトごとに「XOR してから掛ける」で更新できる。
- 計算の途中は、ローカル変数で行うと速い。
- 書き込みの API は、書いた量とエラーを返す決まりに従うと使いやすい。
