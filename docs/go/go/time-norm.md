## ひとことで

`norm(hi, lo, base)` は、「上の桁 `hi`」と「下の桁 `lo`」を、`base` 進法として正しくそろえる関数です。例えば、秒が 75 なら分を 1 増やして秒を 15 にし、秒が -10 なら分を 1 減らして秒を 50 にします。`time.Time` の計算で、時・分・秒の桁上がりを正しく処理するために使われます。

## コード

```go:line-numbers=1700
func norm(hi, lo, base int) (nhi, nlo int) {
	if lo < 0 {
		n := (-lo-1)/base + 1
		hi -= n
		lo += n * base
	}
	if lo >= base {
		n := lo / base
		hi += n
		lo -= n * base
	}
	return hi, lo
}
```

## 前提知識

- **繰り上がりと繰り下がり**: 下の桁が `base` 以上なら上の桁へ繰り上げ、0 より小さければ上の桁から借ります。
- **Go の割り算の切り捨て**: Go では、負の数の割り算は 0 に向かって切り捨てられます。`-7 / 2` は `-3` で、`-7 % 2` は `-1` です。そのため、負の数の余りを正の範囲にそろえるには、補正が必要です。
- **`base`**: 桁を区切る数です。秒と分は 60、分と時は 60 などのように使われます。
- **名前付き戻り値**: `(nhi, nlo int)` のように名前を付けると、`return` だけで結果を返せます。

## 何をしているか

### 1. 負の下の桁を上から借りる

```go:line-numbers=1701
	if lo < 0 {
		n := (-lo-1)/base + 1
		hi -= n
		lo += n * base
	}
```

`lo` が負なら、必要な `base` の個数 `n` を求めて、上の桁 `hi` から `n` を引きます。`lo` には `n * base` を足して、0 以上にします。

`(-lo-1)/base + 1` は、負の数を正の数に直してから割る形です。切り捨ての方向を正しく扱うための書き方です。`lo = -1` なら `n = 1` で、借りるのは 1 回だけです。

### 2. 下の桁が base 以上なら上へ繰り上げる

```go:line-numbers=1706
	if lo >= base {
		n := lo / base
		hi += n
		lo -= n * base
	}
	return hi, lo
```

`lo` が `base` 以上なら、`lo / base` の個数を上の桁へ移します。残りの `lo - n*base` は、0 以上 `base` 未満になります。

## ここがすごい

- **負の数の切り捨てを考慮**: 単純に `lo % base` を使うと、負の数の余りが負になります。この関数は、負のときだけ特別に借りる形にして、正しい範囲を保っています。
- **1 回の計算で済ませる**: `n` を求めてから一度に足し引きするので、1 ずつ繰り返す必要がありません。大きな値でも、計算は 1 回です。
- **2 つの場合を分けて書く**: 負のときと、大きすぎるときを、別々の `if` で扱います。どちらか一方しか起きないので、読みやすい形です。

## まとめ

- `norm` は、上の桁と下の桁を、区切りの `base` に合わせてそろえます。
- 下の桁が負なら、上の桁から必要な分だけ借ります。
- 下の桁が `base` 以上なら、上の桁へ繰り上げます。
- Go の負の割り算の切り捨てを考えて、余りが正の範囲になるようにしています。
