## ひとことで

`get4(b)` は、バイト列 `b` の先頭 4 バイトを、一つの整数として読みます。`b` が 4 バイトより短いときは、読まずに 0 を返します。

## コード

```go:line-numbers=386
func get4(b []byte) int {
	if len(b) < 4 {
		return 0
	}
	return int(b[0]) | int(b[1])<<8 | int(b[2])<<16 | int(b[3])<<24
}
```

## 前提知識

- **リトルエンディアン**: 数の下の桁のバイトを、並びの先頭に置く書き方です。`b[0]` が最も小さい位になります。
- **時間帯データ**: タイムゾーンの情報を保存したファイルです。数値は、この形式で並んでいます。
- **ビットのずらし `<<`**: バイトを、それぞれの位置に合わせてずらします。

## 何をしているか

### 1. 長さを確かめる

```go:line-numbers=387
	if len(b) < 4 {
		return 0
	}
```

4 バイトに満たないと、読めるバイトが足りません。`b[3]` などを読むと、範囲外になってパニックします。そのため、先に確かめて、0 を返します。

### 2. 4 バイトを組み合わせる

```go:line-numbers=390
	return int(b[0]) | int(b[1])<<8 | int(b[2])<<16 | int(b[3])<<24
```

`b[0]` を最も小さい位に、`b[3]` を最も大きい位に置きます。それぞれを `int` に広げてから、ずらして `|` で組み合わせます。

たとえば `b` が `0x01, 0x02, 0x00, 0x00` なら、`b[0]` の 1 はそのまま、`b[1]` の 2 は 8 ビット左にずれて、結果は 513 になります。バイトの並びは、そのまま数の下の桁から上の桁へ対応します。そのため、読む順番を入れ替える処理は要りません。

## ここがすごい

- **読めない場合を値で返す**: 長さが足りなければ 0 を返すので、呼び出し側は、パニックを心配せずに使えます。
- **読み方が一行で分かる**: 4 つの位を並べて書くので、どの位に何が入るかが、そのまま見えます。

## まとめ

- `get4` は、先頭 4 バイトを整数として読みます。
- 足りなければ、0 を返します。
- 下の桁のバイトが先頭に来る、リトルエンディアンで読みます。
