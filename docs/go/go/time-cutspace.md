## ひとことで

`cutspace(s)` は、文字列の先頭にあるスペースを取り除いて返します。例えば `"   Jan 2"` からは `"Jan 2"` が返ります。

時刻の書式を読むときは、要素の間にスペースが入ることがあります。その空白を、次の要素を読む前に取り除くための、小さな関数です。

## コード

```go:line-numbers=953
func cutspace(s string) string {
	for len(s) > 0 && s[0] == ' ' {
		s = s[1:]
	}
	return s
}
```

## 前提知識

- **スペース**: 文字 `' '` です。ここでは、先頭に続く空白だけを対象にします。
- **スライス**: `s[1:]` は、先頭の 1 文字を除いた残りを指す値です。コピーは作りません。
- **先頭だけを見る**: 文字列の途中の空白は触りません。取り除くのは、先頭に続くものだけです。
- **書式の読み取り**: 時刻の書式は、要素を順に読みながら進みます。各要素の前に空白があっても、読み取りを続けられるようにします。

## 何をしているか

### 1. 先頭が空白である間は取り除く

```go:line-numbers=954
	for len(s) > 0 && s[0] == ' ' {
		s = s[1:]
	}
```

文字列が空でなく、先頭が空白の間は、先頭の 1 文字を取り除きます。`len(s) > 0` を先に書くことで、空の文字列の先頭を読まないようにしています。

### 2. 残りを返す

```go:line-numbers=957
	return s
```

空白でない文字に出会った時点で、残りの文字列をそのまま返します。

## ここがすごい

- **範囲外を読まない**: 空かどうかを先に確かめるので、安全に先頭を読めます。
- **コピーなし**: `s[1:]` は元の文字列の一部を指すだけです。空白が多くても、新しい文字列は作りません。
- **意味を限定**: 取り除くのは先頭のスペースだけです。タブや改行は扱わず、書式が求める空白の意味を、そのまま守っています。

## まとめ

- `cutspace` は、先頭のスペースを読み飛ばして残りを返します。
- 空の文字列の先頭を読まないように、最初に長さを確かめます。
- コピーを作らず、元の文字列の一部を指して返します。
