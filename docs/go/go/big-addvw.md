## ひとことで

`math/big` は、普通の整数型に入りきらない大きな整数を、「語（Word）」と呼ばれる機械語の大きさの値の配列で表します。`addVW(z, x, y)` は、その配列 `x` に 1 語の値 `y` を足して、結果を `z` に入れる関数です。戻り値は、最後の桁上がりです。

大きな整数の足し算の中では、よく使われる処理です。

## コード

```go:line-numbers=103
func addVW(z, x []Word, y Word) (c Word) {
	if len(x) != len(z) {
		panic("addVW len")
	}

	if len(z) == 0 {
		return y
	}
	zi, cc := bits.Add(uint(x[0]), uint(y), 0)
	z[0] = Word(zi)
	if cc == 0 {
		if &z[0] != &x[0] {
			copy(z[1:], x[1:])
		}
		return 0
	}
	for i := 1; i < len(z); i++ {
		xi := x[i]
		if xi != ^Word(0) {
			z[i] = xi + 1
			if &z[0] != &x[0] {
				copy(z[i+1:], x[i+1:])
			}
			return 0
		}
		z[i] = 0
	}
	return 1
}
```

## 前提知識

- **語（Word）**: CPU が一度に扱える整数の大きさです。64 ビットの環境では 64 ビットの値になります。
- **多倍長整数**: 語を並べた配列で、桁の位置が配列の添字に対応します。下の語が先頭にあります。
- **桁上がり（キャリー）**: 足し算で、語の最上位ビットを超えて 1 が出る現象です。次の語へ 1 を送ります。
- **`bits.Add`**: 2 つの値と、入力の桁上がりを足して、結果と出力の桁上がりを返す関数です。

## 何をしているか

### 1. 先頭の語を足す

```go:line-numbers=111
	zi, cc := bits.Add(uint(x[0]), uint(y), 0)
	z[0] = Word(zi)
```

最下位の語に `y` を足します。`cc` が、この足し算で出た桁上がりです。結果を `z[0]` に入れます。

### 2. 桁上がりがなければ残りをそのまま写す

```go:line-numbers=113
	if cc == 0 {
		if &z[0] != &x[0] {
			copy(z[1:], x[1:])
		}
		return 0
	}
```

桁上がりがなければ、残りの語は `x` と同じです。`z` と `x` が別の配列なら、残りをまるごとコピーして終わります。同じ配列なら、コピーは不要です。

### 3. 桁上がりが続くかを語ごとに確かめる

```go:line-numbers=121
		if xi != ^Word(0) {
			z[i] = xi + 1
			if &z[0] != &x[0] {
				copy(z[i+1:], x[i+1:])
			}
			return 0
		}
		z[i] = 0
```

2 語目以降では、語が全部 1 のビットでないかを確かめます。全部 1 でなければ、1 足すだけで桁上がりが止まり、残りをコピーして終わります。全部 1 なら、その語は 0 になり、桁上がりが次へ続きます。

### 4. 最後まで続いたら桁上がりを返す

```go:line-numbers=130
	return 1
```

配列の先頭から末尾まで、すべての語が全部 1 だったときだけ、最上位から桁上がりが出ます。その値を `1` として返します。

## ここがすごい

- **止まったら残りは読まない**: 桁上がりは、ふつうすぐ止まります。途中から先は、値の変更がないのでコピーするだけで済みます。
- **同じ配列への足し算を区別**: `&z[0] != &x[0]` で、別の配列かを確かめています。同じ配列なら、コピーを省けます。
- **語単位の計算**: 1 ビットずつではなく、CPU が一度に扱える大きさで足すので、大きな整数でも速く処理できます。

## まとめ

- `addVW` は、語の配列に 1 語の値を足します。
- 桁上がりが止まれば、残りはコピーして終わります。
- 語が全部 1 のときだけ、桁上がりが次の語へ続きます。
- 最後の桁上がりを戻り値で返します。
