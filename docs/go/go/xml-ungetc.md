## ひとことで

`d.ungetc(b)` は、読んだ 1 バイト `b` を、「次に読み直すもの」として記録します。例えば、名前の終わりを見つけるために 1 バイト先を読んでしまったときに、それを元に戻すために使われます。

読み戻しをすると、行の数や位置の番号も、元に戻す必要があります。この関数は、その戻し方も一緒に行います。

## コード

```go:line-numbers=976
func (d *Decoder) ungetc(b byte) {
	if b == '\n' {
		d.line--
	}
	d.nextByte = int(b)
	d.offset--
}
```

## 前提知識

- **先読み**: 文字が区切りかどうかを判断するため、一つ先の文字を読むことです。読み過ぎた文字は、戻しておかなければなりません。
- **`nextByte`**: 次に読み直すバイトを覚えておく欄です。値がある間は、入力より先にこの値が使われます。
- **行番号（`line`）**: エラーの位置を伝えるために、今何行目かを数えています。改行を戻すときは、行番号も一つ減らします。
- **オフセット（`offset`）**: 入力全体の中での、読み取り位置の番号です。

## 何をしているか

### 1. 改行なら行番号を戻す

```go:line-numbers=977
	if b == '\n' {
		d.line--
	}
```

戻すバイトが改行なら、その改行で行を一つ進めていたはずです。その分を取り消すため、行番号を一つ減らします。

### 2. 次に読むバイトとして覚える

```go:line-numbers=980
	d.nextByte = int(b)
	d.offset--
```

`nextByte` に戻すバイトを入れて、次の読み取りでそれが使われるようにします。位置の番号 `offset` も一つ減らして、読み取りの位置を元に戻します。

## ここがすごい

- **位置の情報を一緒に戻す**: 行番号と位置の番号を、同じ関数で戻します。読み直したときに、エラーの位置がずれません。
- **一つだけ覚える**: 戻せるバイトは一つだけなので、欄も一つで済みます。先読みは一文字ずつ行う、という前提に合わせた設計です。
- **入力を読み直さない**: 戻したバイトは、入力の代わりに `nextByte` から取られます。同じ入力を二度読む必要がありません。

## まとめ

- `ungetc` は、読み過ぎた 1 バイトを次に読み直せるように記録します。
- 改行なら行番号を戻し、位置の番号も一つ戻します。
- 位置の情報が食い違わないように、一緒に元へ戻します。
