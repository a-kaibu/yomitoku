## ひとことで

`state.decodeInt()` は、gob の形式で書かれた符号つき整数を読みます。gob は、負の数も小さなバイト数で書けるように、符号を最下位のビットに入れて送ります。

読む側は、まず符号なしの値 `x` を読み、その最下位のビットで符号を判断します。ビットを右に一つずらすと、残りが数の大きさになります。

## コード

```go:line-numbers=173
func (state *decoderState) decodeInt() int64 {
	x := state.decodeUint()
	if x&1 != 0 {
		return ^int64(x >> 1)
	}
	return int64(x >> 1)
}
```

## 前提知識

- **ビットの最下位**: 2 進数の一番右のビットです。`x&1` で、その値（0 か 1）を取り出せます。
- **右シフト**: `x >> 1` は、ビットを一つ右にずらすことです。最下位のビットが消えて、残りが数の大きさになります。
- **ビット反転**: `^` は、全部のビットを反対にする演算です。Go の整数では、負の数の表し方を作るのに使えます。
- **`decodeUint`**: 符号なしの整数を読む、この読み取り器の関数です。

## 何をしているか

### 1. 符号なしの値を読む

```go:line-numbers=174
	x := state.decodeUint()
	if x&1 != 0 {
		return ^int64(x >> 1)
	}
```

まず `decodeUint` で、符号なしの値を読みます。その最下位のビットが 1 なら、符号は負です。その場合は、一つずらした値を反転させて、負の数にします。

### 2. 0 以上なら右にずらすだけ

```go:line-numbers=178
	return int64(x >> 1)
```

最下位のビットが 0 なら、正の数です。一つ右にずらした値をそのまま返します。

## ここがすごい

- **符号を一ビットで表す**: 符号のための別の欄が要りません。最下位のビットだけで、正と負を区別できます。
- **絶対値が小さい数は短い**: 大きさがゼロに近い数は、符号込みでも少ないビットで書けます。送るデータが小さくなります。
- **反転で負の数を作る**: `^` で作る値は、マイナスの値と同じ仕組みで扱えます。計算のための特別な手順が要りません。

## まとめ

- `decodeInt` は、最下位のビットを符号として、符号つきの整数を読みます。
- 負の数は、ずらした値を反転して作ります。
- 符号を別の欄に持たず、一つのビットで表すので、データが小さくなります。
