## ひとことで

`BitUtil.isPowerOfTwo(value)` は、`value` が **2 のべき乗**（1, 2, 4, 8, 16…）かどうかを判定します。2 進数で考えると、**1 のビットがちょうど 1 つだけ** ある数です。

判定はたった 1 行で、ループも割り算も使いません。`value & (~value + 1) == value` という形で、「いちばん下の 1 のビットだけを残した値が、元の値と同じか」を確かめています。

## コード

```java:line-numbers=325
    public static boolean isPowerOfTwo(final int value)
    {
        return value > 0 && ((value & (~value + 1)) == value);
    }
```

## 前提知識

- **2 のべき乗**: `2^k` の形の数です。2 進数では `1` が 1 つだけあり、あとは全部 `0` です（`8` は `1000`）。
- **2 の補数**: 負の数の表し方です。`-x` は `~x + 1`（ビットを反転して 1 を足す）で作れます。
- **`~`（ビット反転）**: すべてのビットを反転します。
- **`&`（AND）**: 両方が 1 の桁だけ 1 にします。
- **`value > 0`**: 0 と負の数を先に弾きます。

## 何をしているか

### 1. 負の値を作る

`~value + 1` は、2 の補数で `-value` と同じです。`value = 12`（`0000 1100`）なら、`-12` は `1111 0100` です。

### 2. いちばん下の 1 だけを残す

```java:line-numbers=327
        return value > 0 && ((value & (~value + 1)) == value);
```

`value & -value` は、`value` の **いちばん下（最下位）の 1 ビットだけを残した値** になります。

- `12`（`0000 1100`）と `-12`（`1111 0100`）の AND は `0000 0100`（4）です。12 の最下位の 1 は 4 の位にあるからです。

### 3. 元の値と比べる

`4` は `12` と等しくないので、判定は偽です。`12` は 2 のべき乗ではありません。

`value = 8`（`0000 1000`）では、`-8` は `1111 1000` で、AND は `0000 1000`（8）です。8 と元の値が等しいので、判定は真です。

### 4. 具体的な値で確かめる

| `value` | 2 進数 | `value & -value` | 等しいか | 判定 |
| --- | --- | --- | --- | --- |
| `1` | `0001` | `1` | はい | 真 |
| `6` | `0110` | `2` | いいえ | 偽 |
| `8` | `1000` | `8` | はい | 真 |
| `12` | `1100` | `4` | いいえ | 偽 |

## ここがすごい

- **1 行で「1 が 1 つだけ」**: ふつうは `while (value % 2 == 0)` のようにループで調べるか、`Integer.bitCount(value) == 1` のように数えます。この式は、最下位の 1 を取り出すだけなので、どんな大きさの値でも一瞬で終わります。
- **`value & (value - 1) == 0` との違い**: 2 のべき乗の判定によく使われる別の式もあります。どちらも正しいですが、この式は「最下位の 1 だけ」を直接取り出す形なので、意味が読み取りやすいです。
- **符号の扱い**: `value > 0` の条件で、0 と負の数を除いています。`Integer.MIN_VALUE` は、絶対値は 2 のべき乗ですが、負なので偽になります。
- **ハッシュ表などでの使い道**: 2 のべき乗かどうかを知ると、剰余の代わりにビット AND でインデックスを求められます。Agrona のような高速な並行処理ライブラリでは、このような判定が多く使われます。

## まとめ

- 2 のべき乗は、1 のビットが 1 つだけの数。
- `value & -value` は、いちばん下の 1 のビットだけを残す。その結果が元の値と同じなら、1 のビットは 1 つだけ。
- 負の数と 0 は、事前に除外する。
