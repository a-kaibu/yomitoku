## ひとことで

`BitUtil.zigZagEncode(i)` は、符号付きの `int` を **符号なしの数に並べ替える** 関数です。`0` は `0`、`-1` は `1`、`1` は `2`、`-2` は `3`、`2` は `4` になります。

絶対値が小さい数ほど、結果も小さくなるのが特徴です。Google の Protocol Buffers という仕組みで使われている方法で、Lucene では数値を小さくまとめて保存するときに使われます。

## コード

```java:line-numbers=281
  public static int zigZagEncode(int i) {
    return (i >> 31) ^ (i << 1);
  }
```

## 前提知識

- **符号付き整数**: 正と負を両方表せる整数です。Java の `int` はこれにあたり、負の数は 2 の補数で表されます。
- **`i >> 31`**: 符号を全体に広げる右シフトです。`i` が負なら全ビットが `1`（`-1`）、0 以上なら全ビットが `0`（`0`）になります。
- **`i << 1`**: 1 ビット左にずらすことで、値を 2 倍にします。
- **`^`（XOR）**: 桁ごとに「違えば 1、同じなら 0」です。ある値のビットを全部反転させたいときに、全部 1 の値と XOR を取ります。
- **なぜ並べ替えるか**: 負の数を 2 の補数のまま保存すると、`-1` は全ビットが `1` なので、とても大きな値に見えてしまいます。並べ替えておくと、小さい数は小さいビットで表せます。

## 何をしているか

### 1. 符号を広げた値を作る

```java:line-numbers=282
    return (i >> 31) ^ (i << 1);
```

ここでは 2 つの部分を XOR します。

- `i >> 31`: 正なら `0`、負なら `-1`（全ビット 1）
- `i << 1`: 値を 2 倍にした値

### 2. 正の数の場合

`i >> 31` が `0` なので、XOR は何もしません。結果は `i << 1`、つまり `2i` です。

`i = 2` なら `4`、`i = 5` なら `10` です。正の数は偶数に写されます。

### 3. 負の数の場合

`i >> 31` が全ビット 1 なので、XOR は **全ビットを反転** します。`2i` を反転させると、その結果は `-2i - 1` になります。

- `i = -1`: `2i = -2`。反転すると `1`。
- `i = -2`: `2i = -4`。反転すると `3`。
- `i = -3`: `2i = -6`。反転すると `5`。

負の数は奇数に写されます。

### 4. 対応をまとめると

| `i` | `i << 1` | `i >> 31` | 結果 |
| --- | --- | --- | --- |
| `0` | `0` | `0` | `0` |
| `-1` | `-2` | `-1` | `1` |
| `1` | `2` | `0` | `2` |
| `-2` | `-4` | `-1` | `3` |
| `2` | `4` | `0` | `4` |

絶対値が小さい数ほど、結果も小さい非負の数になっています。

### 5. 元に戻す

同じファイルの `zigZagDecode` は、@@L 297-297@@ の式で元の値に戻します。偶数なら半分にし、奇数なら負にして 1 を引く形です。

## ここがすごい

- **分岐がない**: 「負なら変換する」を `if` で書くと分岐が増えますが、この式は符号ビットの広がりと XOR だけで、正負の両方を同時に処理します。
- **小さい数の表現が小さい**: 2 の補数のままでは `-1` が大きな数になり、可変長の保存（小さい値ほど少ないバイトで書く方法）が効きません。並べ替えると `-1` は `1` になり、少ないバイトで済みます。
- **可逆**: どの整数もちょうど 1 つの非負の数に写り、逆変換で元に戻ります。情報が失われないので、保存と読み出しの両方で安全に使えます。
- **プロトコルとの共通性**: コメントに書かれているとおり、Protocol Buffers の符号付き整数（`sint32`）と同じ形式です。異なるシステムどうしでデータをやり取りするときに、同じ規則が役に立ちます。

## まとめ

- 符号付きの数は、ZigZag の並べ替えで小さい非負の数に写せる。
- `(i >> 31) ^ (i << 1)` の 1 行で、正負の両方を分岐なしで扱える。
- 小さい数が小さく表せると、保存のサイズが減る。
