## ひとことで

`EndianUtils.swapInteger(value)` は、`int` の 4 バイトの並びを逆にして返します。たとえば、リトルエンディアンで書かれたデータを、ビッグエンディアンとして読み直すときに使えます。

ビットを 1 つずつ動かさずに、バイト単位で取り出して組み直すのが特徴です。`Integer.reverseBytes` と同じ結果になりますが、一行ずつ何をしているかが見えるように書かれています。

## コード

```java:line-numbers=305
    public static int swapInteger(final int value) {
        return
            ((value >> 0 & 0xff) << 24) +
            ((value >> 8 & 0xff) << 16) +
            ((value >> 16 & 0xff) << 8) +
            ((value >> 24 & 0xff) << 0);
    }
```

## 前提知識

- **エンディアン**: 複数バイトの数値を、どの順番でメモリや通信に並べるかの決まりです。ネットワークではビッグエンディアンが多く使われます。
- **`>>`（符号つき右シフト）**: 右へずらし、左端は元の符号ビットで埋めます。`>>` と `& 0xff` を組み合わせると、目的のバイトだけを取り出せます。
- **`0xff`**: 2 進数で `1111 1111`、つまり 1 バイト分のマスクです。
- **`<<`（左シフト）**: 値を左へずらし、バイトを上の位置へ移します。
- **`+`**: ここでは `|` と同じく、重ならないバイトを 1 つの整数にまとめるために使われています。

## 何をしているか

### 1. 下から 4 つのバイトを取り出す

```java:line-numbers=307
            ((value >> 0 & 0xff) << 24) +
            ((value >> 8 & 0xff) << 16) +
            ((value >> 16 & 0xff) << 8) +
            ((value >> 24 & 0xff) << 0);
```

各行は、1 つのバイトを取り出して、新しい位置へ移します。`value >> 0 & 0xff` は最下位バイト、`value >> 8 & 0xff` は下から 2 番目のバイトを取り出します。取り出したあと、`<< 24`、`<< 16`、`<< 8`、`<< 0` で、逆の位置へ置き直します。

### 2. 位置を逆にして足す

最下位のバイトは最上位へ、最上位のバイトは最下位へ移ります。真ん中の 2 バイトも、互いに入れ替わります。各バイトは重ならない位置に置かれるので、足し算で 1 つの `int` になります。

## ここがすごい

- **何をしているかが読める**: 1 行ごとに 1 つのバイトを扱うので、どのバイトがどこへ移るかを、目で追いやすくなっています。
- **マスクの意味が明確**: `& 0xff` で必ず 1 バイトだけを取り出しています。`>>` で符号が広がっても、マスクで余分なビットが消えます。
- **足し算で組み立てる**: 各バイトは重ならない位置にあるため、`+` と `|` は同じ結果になります。書き方を揃えるために `+` を選んでいます。
- **移植性を守る**: 機器ごとに違うバイトの並びを、この関数で統一できます。プログラムの書き方は同じでも、動く機械に依存しません。

## まとめ

- `value >> n & 0xff` で、取り出したいバイトを 1 つ取り出す。
- 取り出したバイトを逆の位置へ置き直し、足して 1 つの `int` にする。
- 機器によってバイトの並びが違うデータを、同じ順番に揃えられる。
