## ひとことで

`Integer.lowestOneBit(i)` は、`int` の中で一番下（最も小さい桁）にある 1 のビットだけを残した値を返します。たとえば `12`（`1100`）なら `4`（`0100`）になります。他のビットはすべて 0 になります。

1 行で書けるのに、ループを使わずに「最下位の 1」を取り出せるので、ビット集合の操作やタイマーホイール、ビットマップの走査でよく使われます。

## コード

::: code-group

```java:line-numbers=1566 [日本語訳]
    public static int lowestOneBit(int i) {

```

    public static int lowestOneBit(int i) {

## 前提知識

- **2 の補数**: Java の整数が負の数を表す方法です。正の数 `x` のビットを反転させて 1 を足すと `-x` になります。
- **`&`（AND）**: 同じ桁がどちらも 1 のときだけ 1 になる演算です。特定のビットだけを残すときに使います。
- **最下位ビット**: 2 進数の一番右側の桁です。値の大きさとは関係なく、もっとも小さな位の 1 を指します。
- **`-i`**: 符号を反転させた値です。ビットで書くと「反転して 1 を足す」ことになります。
- **Hacker's Delight**: Henry S. Warren Jr. によるビット演算の本です。この関数のコメントは、その 2-1 節を参照しています。

## 何をしているか

### 1. 負の数を作る

```java:line-numbers=1568
        return i & -i;
```

`-i` は、`i` を 2 の補数で負の数にします。`i` のビットを反転して 1 を足すと得られます。`12` は `0000 1100` なので、`-12` は `1111 0100` です。

### 2. 同じ位置のビットだけを残す

`i & -i` は、2 つの値の同じ桁を AND します。`12` と `-12` を並べると、下から 3 桁目（値 4）だけが両方 1 です。それより下は、`i` 側が 0 か `-i` 側が 0 になっています。結果として `0100`、つまり `4` が残ります。

### 3. 1 が無いときは 0

`i` が 0 のときは、`0 & -0` で 0 になります。最下位の 1 が存在しないので、0 を返すのが自然な結果です。

## ここがすごい

- **1 命令の式で済む**: 最下位の 1 を探すループや、桁を順に調べる処理が要りません。`-` と `&` の 2 つの演算だけで答えが出ます。
- **負の数の性質を使う**: 2 の補数では、`-i` は `i` の最下位の 1 より下をすべて 0 にし、その 1 と上側を反転させます。これがあるので AND を取るだけで、下位の 1 だけが残ります。
- **最下位の 1 を取り出す基本形**: ビットマップで次の空きを探したり、タイマーの仕組みで今の時刻に近い要素を選んだりする場面で、この一行が使われます。
- **Integer.MIN_VALUE も正しく扱える**: `Integer.MIN_VALUE` は `1000...0` で、`-i` も同じ値になります。その結果 AND は `MIN_VALUE` を返し、最上位の 1 だけが残るという正しい答えになります。

## まとめ

- `i & -i` で、最も下位にある 1 のビットだけを取り出せる。
- 2 の補数の性質により、負の数との AND がこの結果を作る。
- 1 が無いとき（0 のとき）は 0 を返す。
