## ひとことで

UTF-8 では、絵文字のような 65536 より大きい文字は 4 バイトで表されます。😀（U+1F600）は `F0 9F 98 80` です。

`decode4` は、この 4 バイトから、文字の番号（コードポイント）を求めます。`char` 1 つには収まらないので、結果は `int` で返します。UTF-16 に直すには、この番号をさらに上位と下位の 2 つの `char` に分ける必要があります。

## コード

```java:line-numbers=1222
    private static int decode4(int b1, int b2, int b3, int b4) {
        return ((b1 << 18) ^
                (b2 << 12) ^
                (b3 <<  6) ^
                (b4 ^
                        (((byte) 0xF0 << 18) ^
                                ((byte) 0x80 << 12) ^
                                ((byte) 0x80 <<  6) ^
                                ((byte) 0x80 <<  0))));
    }
```

## 前提知識

- **UTF-8 の 4 バイト文字**: 1 バイト目は `11110xxx`、2 から 4 バイト目は `10xxxxxx` の形です。`x` の部分に、文字の番号のビットが入ります。
- **コードポイント**: Unicode の文字の番号です。補助面の文字は `0x10000` 以上です。
- **XOR と定数**: 前の `decode2` や `decode3` と同じ考え方で、目印のビットを定数の XOR で消します。
- **`<< 18`、`<< 12`、`<< 6`**: 各バイトを、番号のビットの位置へずらします。

## 何をしているか

### 1. 4 つのバイトを、位置をずらして重ねる

```java:line-numbers=1223
        return ((b1 << 18) ^
                (b2 << 12) ^
                (b3 <<  6) ^
```

`b1 << 18`、`b2 << 12`、`b3 << 6` で、3 つのバイトを番号の上の位置へずらします。`b4` はずらさずに、XOR に加わります。

### 2. 目印を定数の XOR で消す

```java:line-numbers=1226
                (b4 ^
                        (((byte) 0xF0 << 18) ^
                                ((byte) 0x80 << 12) ^
                                ((byte) 0x80 <<  6) ^
                                ((byte) 0x80 <<  0))));
```

`(byte) 0xF0 << 18` などは、4 バイト文字の目印（`11110`、`10`、`10`、`10`）を、符号拡張つきで作った定数です。この定数を XOR に含めると、目印が消え、番号だけが残ります。

例として、😀（`F0 9F 98 80`）を計算すると、`0x1F600` になります。これは U+1F600 の番号と一致します。

## ここがすごい

- **4 バイトを 1 つの式で扱う**: `decode3` と同じく、分岐なしで番号が求まります。
- **目印の定数を式で示す**: 4 つの目印が、それぞれどの位置のビットかが、式からそのまま読めます。
- **番号を返す**: 結果が `char` に収まらないので `int` にしています。その後の上位・下位への分割は、呼び出し側が行います。
- **符号拡張の対応**: 前の 2 つの関数と同じく、バイトと定数を同じ方法で符号拡張するので、上の桁の打ち消しが正しく働きます。

## まとめ

- `decode4` は、4 バイトを `<< 18`、`<< 12`、`<< 6`、そのままで重ね、目印を定数の XOR で消す。
- 結果は補助面の文字の番号（`int`）で、😀 は `F0 9F 98 80` から `0x1F600` になる。
- UTF-16 にするには、この番号をさらに 2 つの `char` に分ける必要がある。
