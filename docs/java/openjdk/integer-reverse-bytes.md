## ひとことで

`Integer.reverseBytes(i)` は、`int` の 4 バイトの並び順を逆にします。たとえば `0x12345678` は `0x78563412` になります。ネットワーク通信やファイルの形式で、バイトの順番が違う機器同士のデータをやり取りするときに使われます。

ビットの 1 つ 1 つを入れ替える `Integer.reverse` とは違い、バイトの単位で並べ替えるのが特徴です。

## コード

```java:line-numbers=1965
    public static int reverseBytes(int i) {
        return (i << 24)            |
               ((i & 0xff00) << 8)  |
               ((i >>> 8) & 0xff00) |
               (i >>> 24);
    }
```

## 前提知識

- **バイト**: 8 ビットのまとまりです。`int` は 4 バイトからできています。16 進数では、2 桁ずつが 1 バイトにあたります。
- **エンディアン**: 複数バイトの数値を、どちらの端から並べるかの決まりです。上位バイトから並べる方式をビッグエンディアン、下位バイトから並べる方式をリトルエンディアンと呼びます。
- **`<<`, `>>>`**: ビットを左または符号なしで右へずらす演算です。バイトを目的の位置へ動かすために使います。
- **`0xff00`**: 2 進数で `1111 1111 0000 0000` です。真ん中の 2 バイトを取り出すマスクとして使われます。
- **`|`（OR）**: 別々の位置に置いたバイトを、1 つの整数に合わせるための演算です。

## 何をしているか

### 1. 最下位バイトを最上位へ送る

```java:line-numbers=1966
        return (i << 24)            |
```

`i << 24` で、一番下のバイトを一番上へ移します。下位 3 バイトは上へ押し出されて消えますが、ここでは最下位バイトだけが必要なので問題ありません。

### 2. 真ん中の 2 バイトを入れ替える

```java:line-numbers=1967
               ((i & 0xff00) << 8)  |
               ((i >>> 8) & 0xff00) |
```

`(i & 0xff00) << 8` は、下から 2 番目のバイトを 1 つ上の位置へ移します。`(i >>> 8) & 0xff00` は、上から 2 番目のバイトを 1 つ下へ移します。2 つは同じ真ん中の位置を入れ替えています。

### 3. 最上位バイトを最下位へ送る

```java:line-numbers=1969
               (i >>> 24);
```

`i >>> 24` で、一番上のバイトを一番下へ移します。ここでは上位へのずれを気にせず、すべて下へ送ります。

4 つの結果を `|` でまとめると、バイトの並びが完全に逆になります。

## ここがすごい

- **分岐もループもない**: 4 バイトを順番に入れ替える処理を、シフトと OR の組み合わせだけで書いています。命令数が少なく、とても速く動きます。
- **マスクが必要なところだけ使う**: 最下位と最上位のバイトは、シフトだけで位置が決まるのでマスクを使いません。真ん中の 2 バイトだけに 0xff00 のマスクを使っています。
- **CPU 命令が対応している**: JDK では `@IntrinsicCandidate` という注釈が付いています。これは、一部の CPU では専用の命令で、この関数を置き換えて動かせることを示します。
- **`reverse` との違い**: `Integer.reverse` はビットを 1 つずつ逆にし、`reverseBytes` はバイト単位で入れ替えます。目的がエンディアンの変換なら、こちらを使います。

## まとめ

- `reverseBytes` は、`int` の 4 バイトの順番を逆にする。
- 2 つのシフトと 1 つのマスクで、真ん中の 2 バイトを入れ替える。
- エンディアンの変換など、バイトの並びを変える場面で使う。
