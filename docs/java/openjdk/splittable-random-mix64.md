## ひとことで

`SplittableRandom` は、Java 8 で追加された高速な乱数生成器です。内部では、ある数（`gamma`）を **ただ足していくだけ** の値を作り、それを `mix64` に通して乱数にします。

`mix64` は 64 ビットの値を「かき混ぜる」関数です。入力が 1 ビット違うだけで、出力の約半分のビットが変わります。連番 `1, 2, 3…` を入れても、出てくるのはでたらめに見える値です。

## コード

```java:line-numbers=186
    private static long mix64(long z) {
        z = (z ^ (z >>> 30)) * 0xbf58476d1ce4e5b9L;
        z = (z ^ (z >>> 27)) * 0x94d049bb133111ebL;
        return z ^ (z >>> 31);
    }
```

## 前提知識

- **`long`**: 64 ビットの整数です。掛け算があふれても例外にならず、下位 64 ビットだけが残ります（2^64 で割った余り）。
- **`z ^ (z >>> 30)`**: `z` を 30 ビット右にずらしたものと XOR します。**上位ビットの情報が下位ビットに混ざります**。
- **大きな奇数の掛け算**: `0xbf58476d1ce4e5b9L` のような定数を掛けると、下位ビットの情報が上位ビットに広がります。末尾の `L` は `long` の定数という意味です。
- **`private static`**: クラスの中だけで使う、オブジェクト不要の関数です。
- **乱数生成器の構造**: 多くの乱数生成器は「内部の状態を進める」部分と「状態から出力を作る」部分に分かれます。`SplittableRandom` では前者がただの足し算で、後者がこの `mix64` です。

## 何をしているか

### 3 つの段

1. `z ^ (z >>> 30)` で上位 → 下位へ混ぜ、`* 0xbf58476d1ce4e5b9L` で下位 → 上位へ広げる（187 行目）
2. `z ^ (z >>> 27)` で再び上位 → 下位へ混ぜ、`* 0x94d049bb133111ebL` で広げる（188 行目）
3. 最後に `z ^ (z >>> 31)` で仕上げ（189 行目）

### なぜ 2 種類の操作を交互にするのか

- **掛け算** は、ある桁のビットが、それより **上の桁にだけ** 影響します（繰り上がりは上に向かうため）。下位ビットはほとんど混ざりません。
- **右シフトして XOR** は、上位ビットを **下の桁へ** 持ってきます。

この 2 つを交互に使うと、どの位置のビットもすべての位置に影響するようになります。片方だけでは混ざらない方向を、もう片方が補っています。

### 元に戻せる

XOR シフトも、奇数の掛け算も、どちらも **逆算できる** 操作です（奇数には 2^64 を法とする逆数がある）。つまり `mix64` は 64 ビットの値の「並べ替え」で、違う入力は必ず違う出力になります。連番を入れれば、重複のない値の列が出てきます。

## ここがすごい

- **探索で見つけた定数**: コメントにあるとおり、これは「Stafford variant 13」と呼ばれる混ぜ方です。MurmurHash3 の仕上げ関数（fmix64）を元に、David Stafford 氏がシフト量と定数の組み合わせを大量に試し、混ざり具合がよいものを選びました。数字に見た目の意味はありませんが、測定にもとづいて選ばれています。
- **単純な状態 + 強い仕上げ**: 状態を進めるのは足し算 1 回なので、とても速く、しかも「n 個先の状態」を掛け算で一発で計算できます。これが、乱数生成器を 2 つに分ける（split する）機能を、並列処理で安全に使える理由です。乱数としての質は、すべてこの `mix64` が担っています。
- **少ない命令**: シフト 3 回、XOR 3 回、掛け算 2 回だけです。分岐もメモリアクセスもありません。

この関数は SplitMix64 という乱数生成器の出力関数としても知られ、ほかの乱数生成器の初期値を作るのにもよく使われます。

## まとめ

- 掛け算は下位から上位へ、右シフト XOR は上位から下位へビットを混ぜる。交互に使うと全体が混ざる。
- XOR シフトと奇数の掛け算は逆算できるので、混ぜても値が重複しない。
- 「単純に進める状態」と「強力に混ぜる出力関数」に分けると、速くて分割しやすい乱数生成器が作れる。
