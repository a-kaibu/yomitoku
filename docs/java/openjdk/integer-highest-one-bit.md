## ひとことで

`Integer.highestOneBit(i)` は、`i` を 2 進数にしたとき **いちばん上（左）にある `1` だけを残し、ほかを全部 0 にした値** を返します。

たとえば `100` は 2 進数で `0110 0100` なので、いちばん上の 1 だけを残した `0100 0000` = `64` が答えです。これは「`i` 以下で最大の 2 のべき乗」でもあり、ハッシュ表の大きさを決めるときなどに使われます。

## コード

```java:line-numbers=1549
    public static int highestOneBit(int i) {
        return i & (MIN_VALUE >>> numberOfLeadingZeros(i));
    }
```

## 前提知識

- **`MIN_VALUE`**: `Integer.MIN_VALUE` のことで、`int` で表せる最小値 `-2147483648` です。2 進数では `1000…0000`（最上位ビットだけが 1）です。同じクラスの中なので `Integer.` を省略して書けます。
- **`>>>`（符号なし右シフト）**: 右にずらし、左端には `0` を入れます。`MIN_VALUE >>> 3` は `0001 0000…0000` です。もし `>>`（左端に符号ビットをコピーする）を使うと、`1111 0000…` になってしまうので、ここでは `>>>` でなければいけません。
- **`numberOfLeadingZeros(i)`**: 同じクラスの関数で、上位から `0` が何個続くかを返します。`100` なら上位 25 ビットが 0 なので `25` です。
- **Java のシフト量**: Java の `int` のシフトは、シフト量の **下位 5 ビットだけ** を使います（0〜31 に丸められる）。`x >>> 32` は `x >>> 0` と同じ、つまり何もずらさない意味になります。

## 何をしているか

### 1. いちばん上の 1 の位置を知る

`numberOfLeadingZeros(i)` は、上位の 0 の数です。これは「いちばん上の 1 が、最上位から何ビット下にあるか」と同じです。`i = 100` なら `25` です。

### 2. その位置に 1 だけ立ったマスクを作る

`MIN_VALUE >>> 25` は、最上位にある 1 を 25 ビット右へ動かした値です。最上位は 31 ビット目なので、`31 - 25 = 6` ビット目だけが 1 の値、つまり `64` になります。ちょうど `i` のいちばん上の 1 と同じ位置です。

### 3. AND で確かめる

最後に `i & マスク` を取ります。マスクの位置には必ず `i` の 1 があるので、結果はマスクと同じ `64` です。

### 0 のときはどうなるか

`i = 0` のとき `numberOfLeadingZeros(0)` は `32` です。前提知識のとおり Java では `>>> 32` は「ずらさない」なので、マスクは `MIN_VALUE` のままです。でも `0 & MIN_VALUE` は `0` なので、答えは正しく `0` になります。**最後の `i &` が、このずれを吸収する安全装置** になっているのです。

負の数では先頭の 0 が 0 個なので、マスクは `MIN_VALUE` で、答えは `MIN_VALUE` です。

## ここがすごい

- **既存の部品を組み合わせて 1 行に**: 昔の JDK では、この関数は `i |= (i >> 1); i |= (i >> 2); …` と 5 段のシフトと OR で「上の 1 から下を全部 1 で埋めて」から計算していました。現在は、CPU 命令に置き換わりやすい `numberOfLeadingZeros` を土台にすることで、短く速いコードになっています。
- **一見ムダな `i &` が意味を持つ**: マスクの位置には必ず 1 があるのだから、`i &` は不要に見えます。でも 0 のときだけはマスクが `MIN_VALUE` になってしまうので、この AND が答えを 0 に補正しています。1 つの演算で特別なケースを処理する、よく考えられた書き方です。
- **`>>>` でなければならない理由が明確**: 最上位ビットを動かすので、符号を広げる `>>` では壊れます。2 つのシフト演算子の違いを示す良い例です。

## まとめ

- 「いちばん上の 1 の位置」がわかれば、`MIN_VALUE >>> 位置` で 1 ビットだけのマスクが作れる。
- Java のシフト量は 0〜31 に丸められる。境界ケースでは特に注意する。
- 一見不要な演算が、特別な入力を正しく処理するために置かれていることがある。
