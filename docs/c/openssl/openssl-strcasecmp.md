## ひとことで

`OPENSSL_strcasecmp(s1, s2)` は、大文字と小文字を区別せずに 2 つの文字列を比べます。等しければ 0、`s1` が辞書順で前なら負の数、後ろなら正の数を返します。
`OPENSSL_strcasecmp("Hello", "hELLO")` は `0` です。
標準の `strcasecmp` を使わず自前で持っているのは、OS の「ロケール」（言語や地域の設定）によって結果が変わらないようにするためです。

## コード

```c:line-numbers=471
int OPENSSL_strcasecmp(const char *s1, const char *s2)
{
    int t;

    while ((t = ossl_tolower(*s1) - ossl_tolower(*s2++)) == 0)
        if (*s1++ == '\0')
            return 0;
    return t;
}
```

`ossl_tolower` は crypto/ctype.c の 296〜301 行目にあり、ASCII の大文字（A〜Z）だけを小文字にします。

```c
int ossl_tolower(int c)
{
    int a = ossl_toascii(c);

    return ASCII_IS_UPPER(a) ? c ^ case_change : c;
}
```

## 前提知識

- **C の文字列とポインタ**: 文字列は最後に `'\0'` が付いた文字の並びで、`const char *s1` はその先頭を指すポインタです。`*s1` で今の文字を読み、`s1++` で次の文字へ進みます。
- **`*s2++`**: 「`s2` が指す文字を読んでから、`s2` を 1 つ進める」という意味です。
- **代入は値を持つ**: C では `t = 式` そのものが値（代入された値）を持ちます。そのため `(t = a - b) == 0` と書くと、「`a - b` を `t` に入れ、それが 0 かどうかを調べる」を 1 つの式で行えます。
- **文字は整数**: C の `char` は小さな整数です。`'a'` は 97、`'b'` は 98 なので、`'a' - 'b'` は `-1` です。比較関数は、この差の符号で大小を表すのが慣例です。
- **ロケール**: 国や言語ごとの文字の扱いの設定です。たとえばトルコ語のロケールでは、大文字の `I` を小文字にすると点のない `ı` になります。標準の `tolower` や `strcasecmp` はロケールの影響を受けます。

## 何をしているか

### 1. 1 文字ずつ小文字にして引き算する（475 行目）

`while` の条件で、

1. `ossl_tolower(*s1)` と `ossl_tolower(*s2++)` を計算する（`s2` はここで次へ進む）
2. その差を `t` に入れる
3. `t == 0`（同じ文字）ならループの本体へ進む

という 3 つのことを一度に行っています。

### 2. 文字列の終わりなら等しい（476〜477 行目）

同じ文字だった場合、それが `'\0'` なら両方の文字列が同時に終わったということなので、`0`（等しい）を返します。`*s1++` で比べたあと `s1` を進めるので、次の周では両方とも次の文字を指しています。

### 3. 違う文字が出たら差を返す（478 行目）

`t` が 0 でなくなった時点でループを抜け、その差を返します。

`s1 = "abc"`、`s2 = "ABD"` で追うと、

- `'a'` と `'a'`（`'A'` を小文字化）: 差 0、終端ではないので続行。
- `'b'` と `'b'`: 差 0、続行。
- `'c'` と `'d'`: 差 `99 - 100 = -1`。ループを抜けて `-1` を返します。`"abc"` のほうが前、という結果です。

## ここがすごい

- **条件式に仕事をまとめる**: 比較、差の保存、ポインタの前進を 1 行の条件式に詰め込み、本体は終端チェックだけです。C の「代入は値を持つ」「後置 `++`」という性質を活かした、古くからある書き方です。
- **片方だけ短い場合も自然に処理できる**: `s1 = "ab"`、`s2 = "abc"` なら、3 文字目で `'\0'`（0）と `'c'`（99）を比べて差が `-99` になり、短いほうが前と判定されます。長さの比較を別に書く必要がありません。
- **ロケールに依存しない**: 証明書のホスト名や暗号アルゴリズムの名前（`"SHA256"` と `"sha256"` など）は、どの国のロケールでも同じ結果で比べなければなりません。`ossl_tolower` は ASCII の A〜Z だけを変換し、`c ^ case_change`（ASCII では `0x20` との XOR）で大文字を小文字にします。ASCII では大文字と小文字の違いがちょうど 1 ビットだけなので、XOR 1 回で変換できます。
- **差を返す慣例を守る**: 0 か 1 ではなく差を返すので、`qsort` の比較関数や二分探索など、「大小」が必要な場面でもそのまま使えます。

## まとめ

- `while ((t = 差) == 0)` のように、条件式の中で代入と比較を同時に行える。
- 終端の `'\0'` も文字として比べると、長さの違いを特別扱いせずに済む。
- 大文字小文字の変換をロケールに任せると、環境によって結果が変わる危険がある。
- ASCII の大文字と小文字は 1 ビット違いなので、XOR で変換できる。
