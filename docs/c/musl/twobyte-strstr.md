## ひとことで

`twobyte_strstr(h, n)` は、文字列 `h` の中から 2 文字の文字列 `n` を探す、musl 内部の関数です。`strstr` が針の長さを調べ、2 文字のときにこの関数を呼びます。
`"ab"` を探すなら、`'a'` と `'b'` を並べた 16 ビットの数 `0x6162` を作り、山から読んだ 2 文字の数と比べます。
2 文字の比較が、整数の比較 1 回になります。

## コード

```c:line-numbers=4
static char *twobyte_strstr(const unsigned char *h, const unsigned char *n)
{
	uint16_t nw = n[0]<<8 | n[1], hw = h[0]<<8 | h[1];
	for (h++; *h && hw != nw; hw = hw<<8 | *++h);
	return *h ? (char *)h-1 : 0;
}
```

## 前提知識

- **C の文字列**: 文字の並びの最後に値 0 のバイトを置いたものです。`*h` が 0 なら山の終わりです。
- **`unsigned char`**: 文字を 0〜255 の数として扱う型です。`'a'` は 0x61、`'b'` は 0x62 です。
- **`uint16_t`**: ちょうど 16 ビット（2 バイト）の符号なし整数型です。入りきらない上位のビットは自動的に捨てられます。
- **シフト `<<` と OR `|`**: `x<<8` は `x` を 8 ビット（1 バイト）左にずらします。`|` はビットを合成します。`0x61<<8 | 0x62` は `0x6162` です。
- **`*++h`**: `h` を 1 つ進めてから、その場所の文字を読みます。
- **カンマで区切った `for` の中身**: `for (h++; 条件; 更新);` は、最初に `h++` を 1 回行い、条件が真の間は更新式だけを繰り返す、本体のないループです。
- **`(char *)h-1`**: `h` を `char *` に変換したうえで 1 つ前の位置を指すポインタです。

## 何をしているか

`h = "xabc"` の中から `n = "bc"` を探す例で追います（実際には `strstr` が先に最初の文字まで進めますが、動きは同じです）。

### 1. 針と最初の窓を作る

```c:line-numbers=6
	uint16_t nw = n[0]<<8 | n[1], hw = h[0]<<8 | h[1];
```

- `nw = n[0]<<8 | n[1]` は `'b'<<8 | 'c'` で `0x6263` です。
- `hw = h[0]<<8 | h[1]` は山の最初の 2 文字 `'x'`、`'a'` で `0x7861` です。

`hw` は、山の上に置いた「2 文字ぶんの窓」です。

### 2. 窓を 1 文字ずつずらす

```c:line-numbers=7
	for (h++; *h && hw != nw; hw = hw<<8 | *++h);
```

最初に `h++` で、`h` を窓の **右端の文字** に合わせます。そのあと、

- `*h`（右端が終端でない）かつ `hw != nw`（窓と針が違う）の間、
- `hw = hw<<8 | *++h` で、窓を 1 文字右にずらす

を繰り返します。`hw<<8` で古い左の文字が 16 ビットの外へ押し出され、新しい文字が右から入ります。

- `0x7861` → `0x6162`（`"ab"`）→ `0x6263`（`"bc"`）で一致して止まる。

### 3. 結果を返す

```c:line-numbers=8
	return *h ? (char *)h-1 : 0;
```

止まったとき `*h` が 0 でなければ、一致で止まったということです。`h` は窓の右端を指しているので、1 つ戻した `h-1` が一致した場所の先頭です。`*h` が 0 なら、山の終わりまで見つからなかったので 0 を返します。

## ここがすごい

- **2 回の比較が 1 回に**: 素直に書けば、山の各位置で `h[0]==n[0] && h[1]==n[1]` の 2 回の比較をします。整数に詰めておけば 1 回の比較で済みます。
- **窓の更新が 1 文字読むだけ**: ずらすたびに 2 文字読み直す必要はありません。シフトで古い文字を捨て、新しい 1 文字を足すだけです。山の各文字は 1 回しか読まれないので、山の長さに比例する時間で終わります。
- **型の幅で古い文字を自動的に捨てる**: `hw` を `uint16_t` にしているので、`hw<<8` ではみ出た上位のビットは代入のときに消えます。マスク（`& 0xffff`）を書かなくても、型が窓の幅を決めてくれます。
- **終端の判定と兼用**: 窓の右端 `*h` が終端なら、もう 2 文字の窓が作れません。ループの条件 `*h` が、そのまま「山が尽きた」判定になっています。

## まとめ

- 短い文字列は整数に詰めると、比較が整数 1 回になる。
- 「窓」をシフトと OR でずらすと、各文字を 1 回読むだけで全位置を調べられる（ローリングの考え方）。
- 固定幅の整数型を使うと、はみ出たビットの処理を型に任せられる。
