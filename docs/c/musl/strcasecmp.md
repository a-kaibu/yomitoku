## ひとことで

`strcasecmp(a, b)` は、大文字と小文字を同じとみなして 2 つの文字列を比べます。`"Hello"` と `"hELLO"` は等しい（0）と判定されます。
戻り値は `strcmp` と同じく、`a` が小さければ負、等しければ 0、大きければ正です。
ループの中身はありません。比較の処理はすべて `for` の条件式に書かれています。

## コード

```c:line-numbers=4
int strcasecmp(const char *_l, const char *_r)
{
	const unsigned char *l=(void *)_l, *r=(void *)_r;
	for (; *l && *r && (*l == *r || tolower(*l) == tolower(*r)); l++, r++);
	return tolower(*l) - tolower(*r);
}
```

## 前提知識

- **C の文字列**: 文字の並びの最後に値 0 のバイトを置いたものです。`*l` が 0 なら終端です。
- **ポインタ**: `const unsigned char *l` は文字を 0〜255 の数として読むポインタです。`l++` で次の文字へ進みます。引数の `const char *` を `(void *)` 経由で変換しています。
- **`tolower(c)`**: 大文字なら小文字にして返し、それ以外はそのまま返す標準関数です。`tolower('H')` は `'h'` です。
- **`&&` と `||` の短絡評価**: `A && B` は `A` が偽なら `B` を評価しません。`A || B` は `A` が真なら `B` を評価しません。この性質で「必要なときだけ計算する」書き方ができます。
- **本体が空の `for`**: `for (...; 条件; 更新);` のように最後に `;` を置くと、本体のないループになります。条件が真の間、更新だけが繰り返されます。
- **比較関数の戻り値**: 値の大きさではなく、符号（負・0・正）が意味を持ちます。

## 何をしているか

### 1. 条件の中身

```c:line-numbers=7
	for (; *l && *r && (*l == *r || tolower(*l) == tolower(*r)); l++, r++);
```

ループの条件は次の 3 つの「かつ」です。

- `*l`: 左がまだ終端でない
- `*r`: 右がまだ終端でない
- `(*l == *r || tolower(*l) == tolower(*r))`: 2 文字が同じか、小文字にすれば同じ

すべて真の間、`l++, r++` で両方を 1 文字進めます。

### 2. 例で追う

`"Hello"` と `"hELp"` を比べます。

- `'H'` と `'h'`: そのままでは違うが、小文字にすると同じ → 進む
- `'e'` と `'E'`: 同様に進む
- `'l'` と `'L'`: 進む
- `'l'` と `'p'`: 小文字にしても違う → 止まる

### 3. 結果を返す

```c:line-numbers=8
	return tolower(*l) - tolower(*r);
```

止まった位置の文字を小文字にして引き算します。`'l' - 'p'` は負なので、`"Hello"` のほうが小さいと判定されます。
片方が先に終わった場合は、終端の 0 と相手の文字を比べることになり、短いほうが小さくなります。両方同時に終わったら `0 - 0` で 0 です。

## ここがすごい

- **安い比較を先に**: `*l == *r` はただの比較ですが、`tolower` は関数呼び出しです。英文の比較ではまったく同じ文字が続くことが多いので、まず `==` で比べ、違ったときだけ `tolower` を呼ぶことで、無駄な呼び出しを減らしています。`||` の短絡評価のおかげで、この順番が自然に実現されます。
- **終端の判定は片方だけでも済むが…**: 実は `*r` のチェックがなくても、`*l` が 0 でなく `*r` が 0 なら文字が一致しないので止まります。それでも明示的に書くことで、読み手にとって意図がはっきりします。
- **最後の 1 行が全部の場合をまかなう**: 「途中で違った」「片方が短い」「完全に同じ」の 3 つの終わり方を、`tolower(*l) - tolower(*r)` の 1 行で処理しています。終端の 0 は `tolower` しても 0 のままなので、特別扱いが要りません。
- **符号なしで読む理由**: `char` が符号付きの環境では、`0x80` 以上の文字が負の値になり、`tolower` に渡すと未定義の動作になる可能性があります。最初に `unsigned char` として読むことで、これを避けています。

## まとめ

- `||` と `&&` の短絡評価を使うと、「安い判定で決まらないときだけ高い判定をする」が自然に書ける。
- 比較関数は、止まった位置の差を返すだけで、すべての終わり方を表現できる。
- 文字を関数に渡す前に `unsigned char` にそろえるのは、C の文字処理の基本。
