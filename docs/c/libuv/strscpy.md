## ひとことで

`uv__strscpy(d, s, n)` は、文字列 `s` を大きさ `n` バイトの領域 `d` にコピーする関数です。
収まればコピーした文字数を、収まらなければ **入るところまでで切って、必ず終端の `'\0'` を付けたうえで** エラー値 `UV_E2BIG` を返します。
Linux カーネルの `strscpy` と同じ考え方の関数で、C の標準関数 `strncpy` の使いにくさを解消しています。

## コード

```c:line-numbers=31
ssize_t uv__strscpy(char* d, const char* s, size_t n) {
  size_t i;

  for (i = 0; i < n; i++)
    if ('\0' == (d[i] = s[i]))
      return i > SSIZE_MAX ? UV_E2BIG : (ssize_t) i;

  if (i == 0)
    return 0;

  d[--i] = '\0';

  return UV_E2BIG;
}
```

## 前提知識

- **C の文字列**: 文字（`char`、1 バイト）が並び、最後に値 0 のバイト `'\0'` が置かれたものを文字列として扱います。`"abc"` は `a b c \0` の 4 バイトです。
- **ポインタと配列**: `char* d` は文字が並ぶ領域の先頭を指すポインタで、`d[i]` と書くと `i` 番目の文字を読み書きできます。
- **`size_t` と `ssize_t`**: `size_t` は大きさを表す符号なし（負にならない）整数型です。`ssize_t` はその符号付き版で、負の値でエラーを表せます。`SSIZE_MAX` は `ssize_t` の最大値です。
- **代入は値を持つ**: C の `x = y` は式で、代入した値そのものになります。`(d[i] = s[i])` は「コピーして、コピーした文字」を意味します。
- **三項演算子**: `条件 ? A : B` は条件が真なら A、偽なら B になる式です。
- **`--i`**: `i` を 1 減らしてから、その値を使います。

## 何をしているか

### 1. 1 文字ずつコピーしながら終端を探す

```c:line-numbers=34
  for (i = 0; i < n; i++)
    if ('\0' == (d[i] = s[i]))
      return i > SSIZE_MAX ? UV_E2BIG : (ssize_t) i;
```

`for` ループで `i` を 0 から `n-1` まで進め、`d[i] = s[i]` でコピーします。コピーした文字が `'\0'` なら、文字列の終わりまでコピーできたので、その位置 `i`（＝文字数）を返します。
`'\0' == (d[i] = s[i])` と定数を左に書いているのは、`==` を `=` と書き間違えたときにコンパイルエラーになるようにする、昔からの書き方です。

`s = "abc"`、`n = 8` なら、`i = 3` で `'\0'` をコピーした時点で `3` が返ります。

### 2. 収まらなかった場合

```c:line-numbers=38
  if (i == 0)
    return 0;

  d[--i] = '\0';

  return UV_E2BIG;
```

ループを最後まで回ったということは、`n` バイトの中に終端が現れなかった、つまり収まらなかったということです。
`n` が 0 なら 1 バイトも書けないので、そのまま 0 を返します。
そうでなければ、`d[--i] = '\0'` で最後の 1 バイト（`d[n-1]`）を `'\0'` で上書きします。これで `d` は必ず正しい文字列になります。そして `UV_E2BIG`（大きすぎる、という意味の負のエラー値）を返します。

`s = "hello"`、`n = 4` なら、`d` には `h e l l` がコピーされたあと、`d[3]` が `'\0'` になり、`d` は `"hel"` になります。戻り値は `UV_E2BIG` です。

### 3. 戻り値のはみ出し対策

```c:line-numbers=36
      return i > SSIZE_MAX ? UV_E2BIG : (ssize_t) i;
```

文字数 `i` は `size_t` ですが、戻り値は `ssize_t` です。極端に長い場合に負の値と区別がつかなくならないよう、`SSIZE_MAX` を超えるときは `UV_E2BIG` を返します。

## ここがすごい

- **`strncpy` の 2 つの罠を避けている**: 標準の `strncpy` は、収まらなかったとき終端の `'\0'` を **書きません**。そのまま文字列として使うと、終わりが見つからずメモリの先まで読み進めてしまいます。また、切り詰めが起きたかどうかも教えてくれません。`uv__strscpy` は、どんな場合でも `d` を正しい文字列にし、切り詰めをエラーとして伝えます。
- **余計な処理をしない**: `strncpy` は短い文字列のとき残りを全部 0 で埋めますが、この関数はしません。必要な分だけ書きます。
- **呼び出し側が楽になる**: 戻り値が負かどうかだけを見れば、収まったかどうかがわかります。たとえば `inet.c` の IP アドレス変換では、この関数で一時バッファから結果をコピーしています。

## まとめ

- C の文字列コピーでは「終端の `'\0'` を必ず付ける」ことと「切り詰めを知らせる」ことが大事。
- 収まらないときは最後の 1 バイトを `'\0'` にして、エラー値を返す。
- 定数を `==` の左に書くと、`=` との書き間違いをコンパイラが見つけてくれる。
- 符号なしの長さを符号付きで返すときは、最大値を超えないかを確かめる。
