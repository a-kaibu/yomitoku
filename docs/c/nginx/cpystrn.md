## ひとことで

`ngx_cpystrn` は、文字列 `src` を `dst` にコピーする関数です。コピー先の大きさ `n`（終端の 0 を含むバイト数）を超えないように止まり、**最後に必ず 0 を書き込みます**。
そして戻り値として、**書き込んだ終端の 0 の位置**を返します。たとえば `n = 4` で `"hello"` をコピーすると、`dst` には `"hel"` と 0 が入り、戻り値は 0 を書いた場所（`dst + 3`）を指します。

## コード

```c:line-numbers=50
u_char *
ngx_cpystrn(u_char *dst, u_char *src, size_t n)
{
    if (n == 0) {
        return dst;
    }

    while (--n) {
        *dst = *src;

        if (*dst == '\0') {
            return dst;
        }

        dst++;
        src++;
    }

    *dst = '\0';

    return dst;
}
```

## 前提知識

- **C の文字列**: C の文字列は「文字の並び＋最後に値 0 のバイト（`'\0'`）」です。`"hi"` はメモリ上では `h`, `i`, `0` の 3 バイトです。
- **`u_char`**: nginx が使う `unsigned char`（符号なしの 1 バイト）の別名です。0〜255 の値を持ちます。
- **ポインタ**: メモリ上の場所（アドレス）を表す値です。`u_char *dst` は「バイトが並ぶ場所を指すポインタ」です。`*dst` と書くとその場所の 1 バイトを読み書きでき、`dst++` で次のバイトへ進みます。
- **`size_t`**: 大きさや個数を表す符号なし整数の型です。負の値になりません。
- **`--n`（前置デクリメント）**: `n` を 1 減らしてから、その減った値を式の値として使います。`while (--n)` は「1 減らして、0 でなければ続ける」という意味になります。
- **`while` の条件と 0**: C では、0 は「偽」、0 以外は「真」として扱われます。

## 何をしているか

### 1. 大きさ 0 なら何もしない

```c:line-numbers=53
    if (n == 0) {
        return dst;
    }
```

`n == 0` のときは、終端の 0 すら書く場所がありません。そのため何も書かずに `dst` をそのまま返します。この確認がないと、次の `while (--n)` で `n` が 0 から 1 減って、`size_t` の最大値（とても大きな数）になってしまいます。

### 2. 最大 n-1 文字をコピーする

```c:line-numbers=57
    while (--n) {
        *dst = *src;

        if (*dst == '\0') {
            return dst;
        }

        dst++;
        src++;
    }
```

`while (--n)` は、`n` を減らしながら最大 `n - 1` 回だけ回ります。最後の 1 バイトは終端の 0 のために取っておくためです。
ループの中では 1 バイトをコピーし（`*dst = *src;`）、それが 0 だったら（＝ `src` の文字列が終わったら）、その位置を返します（`return dst;`）。

`n = 10`、`src = "abc"` で追ってみます。

- 1 周目: `a` をコピー。0 ではないので進む。
- 2 周目: `b`、3 周目: `c`。
- 4 周目: 0 をコピー。0 なので、0 を書いた位置 `dst + 3` を返す。

### 3. 途中で打ち切ったら 0 を書く

```c:line-numbers=68
    *dst = '\0';

    return dst;
```

`n = 4`、`src = "hello"` なら、ループは 3 回で終わり、`h e l` までコピーした状態で抜けます。`*dst = '\0';` で 4 バイト目に 0 を書き、その位置を返します。こうして結果は必ず正しい C 文字列になります。

## ここがすごい

- **戻り値が「次に書く場所」になっている**: 標準の `strcpy` や `strncpy` は、コピー先の先頭（`dst` そのもの）を返します。これは呼び出し元がすでに知っている値なので、ほとんど役に立ちません。`ngx_cpystrn` は終端の位置を返すので、`p = ngx_cpystrn(p, a, ...); p = ngx_cpystrn(p, b, ...);` のように、**長さを数え直さずに次々とつなげて書けます**。文字列を何度も連結する処理で、毎回 `strlen` で末尾を探すムダがなくなります。
- **`strncpy` の 2 つの落とし穴を避けている**: 標準の `strncpy` は、文字列が長すぎると **終端の 0 を書きません**。逆に短いと、残りを全部 0 で埋めるので、大きなバッファでは余計な書き込みが起きます。`ngx_cpystrn` は「必ず 0 で終わる」「0 を書いたらすぐ止まる」の両方を満たします。
- **`n` の意味がはっきりしている**: `n` は「0 を含めたバッファの大きさ」です。`sizeof(buf)` をそのまま渡せば安全になる、という使い方がしやすい設計です。
- **`n == 0` を最初に弾く防御**: `size_t` は符号なしなので、0 から 1 を引くと巨大な数になります。最初の 3 行がこの事故を防いでいます。

## まとめ

- C の文字列コピーでは、「終端の 0 を必ず書くか」と「どこまで書くか」が安全性の要になる。
- コピー関数は「書き終えた位置」を返すと、連結処理が簡単で速くなる。
- `while (--n)` で「最後の 1 バイトを残す」ループが短く書ける。
- 符号なし整数の 0 から 1 を引くと巨大な値になるので、先に 0 を弾く。
