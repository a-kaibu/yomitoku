## ひとことで

`ull2string` は、`unsigned long long`（符号なし 64 ビット整数）を 10 進数の文字列に変換します。
たとえば `value = 12345` なら、バッファに `"12345"` と終端の `'\0'` を書き、戻り値として長さ `5` を返します。
ふつうは 1 桁ずつ「10 で割った余り」を取り出しますが、この関数は **100 で割って 2 桁ずつ** 書くのが特徴です。

## コード

```c:line-numbers=392
/* Convert a unsigned long long into a string. Returns the number of
 * characters needed to represent the number.
 * If the buffer is not big enough to store the string, 0 is returned.
 *
 * Based on the following article (that apparently does not provide a
 * novel approach but only publicizes an already used technique):
 *
 * https://www.facebook.com/notes/facebook-engineering/three-optimization-tips-for-c/10151361643253920 */
int ull2string(char *dst, size_t dstlen, unsigned long long value) {
    static const char digits[201] = "0001020304050607080910111213141516171819"
                                    "2021222324252627282930313233343536373839"
                                    "4041424344454647484950515253545556575859"
                                    "6061626364656667686970717273747576777879"
                                    "8081828384858687888990919293949596979899";

    /* Check length. */
    uint32_t length = digits10(value);
    if (length >= dstlen) goto err;
    ;

    /* Null term. */
    uint32_t next = length - 1;
    dst[next + 1] = '\0';
    while (value >= 100) {
        int const i = (value % 100) * 2;
        value /= 100;
        memcpy(dst + next - 1, digits + i, 2);
        next -= 2;
    }

    /* Handle last 1-2 digits. */
    if (value < 10) {
        dst[next] = '0' + (uint32_t)value;
    } else {
        int i = (uint32_t)value * 2;
        memcpy(dst + next - 1, digits + i, 2);
    }
    return length;
err:
    /* force add Null termination */
    if (dstlen > 0) dst[0] = '\0';
    return 0;
}
```

## 前提知識

- **`char *dst` と `size_t dstlen`**: 書き込み先のメモリ（バッファ）を指すポインタと、その大きさ（バイト数）です。C の関数は「どこに、何バイトまで書いてよいか」を引数でもらうのが一般的です。
- **C の文字列と `'\0'`**: C の文字列は文字の並びの最後に値 0 のバイト（`'\0'`）を置いたものです。414 行目でまず終端を書いています。
- **`static const char digits[201]`**: `static` を関数の中の変数に付けると、その変数はプログラム全体で 1 つだけ作られ、呼び出しのたびに作り直されません。`const` は書き換えないという意味です。隣り合う文字列リテラル `"00…19" "20…39"` は、C では自動的に 1 本につながります。200 文字＋終端で 201 です。
- **`memcpy(dst, src, n)`**: `src` から `n` バイトを `dst` にコピーする標準関数です。ここでは 2 文字をまとめてコピーします。
- **`%` と `/`**: 整数の割り算の余りと商です。`12345 % 100` は `45`、`12345 / 100` は `123` です。
- **`goto err`**: 指定したラベル（430 行目の `err:`）へジャンプする命令です。C ではエラー処理を 1 か所にまとめるためによく使われます。
- **`'0' + 数`**: 文字 `'0'` の文字コードに 0〜9 を足すと、`'0'`〜`'9'` の文字になります。

## 何をしているか

### 1. 長さを先に決める（408〜414 行目）

`digits10(value)` で桁数を求めます。`12345` なら `5` です。終端の `'\0'` を含めて 6 バイト必要なので、`length >= dstlen` ならバッファ不足として `err` へ飛びます。
足りるなら、`next = 4`（最後の数字を書く位置）とし、`dst[5]` に `'\0'` を書きます。

### 2. 100 で割りながら後ろから 2 桁ずつ書く（415〜420 行目）

`value = 12345` で追います。

- 1 周目: `i = (12345 % 100) * 2 = 90`。表の 90 文字目からの 2 文字は `"45"` です。`value` は `123` になり、`dst[3..4]` に `"45"` を書きます。`next` は `2` に。
- 2 周目: `value = 123` なので、`i = 23 * 2 = 46`。表の 46 文字目は `"23"` です。`value` は `1` になり、`dst[1..2]` に `"23"` を書きます。`next` は `0` に。
- `value = 1` は 100 未満なのでループを抜けます。

表は「`00` `01` `02` …」と 2 文字ずつ並んでいるので、数 `n` の 2 文字は `n * 2` 文字目から始まる、というしくみです。

### 3. 残り 1〜2 桁を書く（423〜428 行目）

残った `value` が 1 桁なら `'0' + value` で 1 文字書きます。今回は `1` なので `dst[0] = '1'`。これで `"12345"` が完成し、`5` を返します。2 桁残った場合は、表から 2 文字コピーします。

### 4. 失敗時（430〜433 行目）

バッファが足りないときは、念のため先頭に `'\0'` を書いて空文字列にし、`0` を返します。呼び出し側は戻り値が 0 かどうかで失敗を判定できます。

## ここがすごい

**割り算が半分になる**: 1 桁ずつ書く方法では、20 桁の数に約 20 回の割り算が必要です。この方法なら約 10 回で済みます。整数の割り算は CPU にとって重い命令なので、ここを減らす効果は大きいです。表引きは単なるメモリの読み出しで、200 バイトの表は CPU のキャッシュにすぐ乗ります。

**後ろから書くための「先に長さ」**: 数字は下の桁から順に求まるので、素直に前から書くと最後に文字列を反転する必要があります。先に `digits10` で長さを出しておけば、最初から正しい位置（末尾）に書き込めます。

**バッファ溢れを最初に防ぐ**: 書き始める前に長さとバッファの大きさを比べているので、途中で溢れることがありません。失敗時にも終端を書いておくのは、呼び出し側が戻り値を確認し忘れても、ゴミの文字列を読まないようにするための防御です。

コメントにあるとおり、この 2 桁ずつの手法自体は既存の技法を紹介した記事に基づいています。

## まとめ

- 「100 で割って 2 桁ずつ」で、重い割り算の回数を半分にできる。
- `00`〜`99` を並べた 200 文字の表なら、数 `n` の 2 文字は `n*2` の位置にある。
- 先に桁数を求めれば、末尾から書いて反転を省ける。
- 書く前にサイズを確かめ、失敗時も文字列を空にしておくと安全。
