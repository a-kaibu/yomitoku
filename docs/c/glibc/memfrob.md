## ひとことで

`memfrob(s, n)` は、アドレス `s` から `n` バイトの **各バイトを 42 と XOR（排他的論理和）** する GNU の拡張関数です。
同じ領域にもう一度 `memfrob` を呼ぶと、元のデータに戻ります。
鍵が固定なので暗号にはなりませんが、わずか 10 行の中に C のイディオムがぎゅっと詰まっています。

## コード

```c:line-numbers=20
void *
memfrob (void *s, size_t n)
{
  char *p = (char *) s;

  while (n-- > 0)
    *p++ ^= 42;

  return s;
}
```

## 前提知識

- **`void *`**: 型を決めていないポインタ（メモリ上の場所）です。どんなデータの場所でも受け取れますが、そのままでは中身を読み書きできないので、`char *` などに変換（キャスト）して使います。
- **キャスト `(char *) s`**: 値の型を変える書き方です。ここでは「`s` を 1 バイトずつ扱える `char` の場所として見る」という意味です。
- **`size_t`**: 長さを表す符号なし整数型です。符号なしなので負の値になりません。0 から 1 を引くと、最大値に一周します。
- **XOR（`^`）**: 桁ごとに「違えば 1、同じなら 0」とする演算です。`a ^ k ^ k == a` が成り立ちます。
- **`^=`**: `x ^= y` は `x = x ^ y` の省略形です。
- **`*p++`**: 「`p` の指す場所を使い、そのあとで `p` を 1 つ進める」という意味です。`*p++ ^= 42` は「今の 1 バイトを 42 と XOR して、次のバイトに進む」です。
- **`n-- > 0`**: 「`n` が 0 より大きいか調べ、そのあとで `n` を 1 減らす」です。

## 何をしているか

### 1. バイト単位で見る

```c:line-numbers=23
  char *p = (char *) s;
```

引数 `s` は `void *` なので、`char *p` に変換してから 1 バイトずつ扱います。

### 2. 42 と XOR しながら進む

```c:line-numbers=25
  while (n-- > 0)
    *p++ ^= 42;
```

`while (n-- > 0)` は、ちょうど `n` 回繰り返すループです。`n = 3` なら、条件を調べるときの `n` は 3, 2, 1 で真、0 で偽になります。
毎回 `*p++ ^= 42` で、今のバイトを 42 と XOR して次へ進みます。
42 は 2 進数で `00101010` です。たとえば `'A'`（`0x41` = `01000001`）は `01101011` = `0x6b` で `'k'` になります。もう一度 XOR すると `0x41` に戻ります。

### 3. 先頭を返す

```c:line-numbers=28
  return s;
```

`memcpy` などと同じく、受け取った先頭アドレス `s` をそのまま返します。`p` は進んでしまっているので、元の `s` を返すのが大事です。

## ここがすごい

- **XOR は自分自身が逆関数**: 同じ値で 2 回 XOR すると元に戻るので、「隠す」関数と「戻す」関数を別々に作る必要がありません。この性質は、本物の暗号（ストリーム暗号）でも、鍵から作った乱数列とデータを XOR するという形で使われています。ただし `memfrob` のように鍵が固定の 1 バイトだと、誰でも元に戻せるので秘密は守れません。
- **符号なしでも安全な逆数えループ**: `size_t` は負にならないので、`for (; n >= 0; n--)` と書くと条件が常に真になり、無限ループになります。`while (n-- > 0)` は「比べてから減らす」ので、`n = 0` のときも 1 回も実行せずに正しく終わります。最後に `n` は最大値に一周しますが、そのあと使わないので問題ありません。
- **`void *` を受けて `void *` を返す**: どんなデータにも使え、結果をそのまま次の関数に渡せる、標準のメモリ関数と同じ形の API です。
- **42 でなくてもよい**: XOR の値が何であっても「2 回で元に戻る」性質は変わりません。0 だけは何も変わらないので意味がありません。どの値を選んでも、1 バイトの固定値ならたった 255 通りを試すだけで元に戻せてしまう点も、暗号にならない理由です。

## まとめ

- XOR は同じ値で 2 回かけると元に戻る。暗号の基本部品でもある。
- 鍵が固定で短い XOR は、隠しているだけで秘密は守れない。
- `size_t` で逆向きに数えるときは `while (n-- > 0)` が安全な定番の書き方。
- `void *` を `char *` に変えてから 1 バイトずつ処理するのが、汎用メモリ関数の基本形。
