## ひとことで

`swab(from, to, n)` は、`from` から `n` バイトを `to` にコピーしながら、**隣り合う 2 バイトずつを入れ替える** POSIX の関数です。
`"abcd"` を渡すと `"badc"` になります。16 ビット整数のバイト順（エンディアン）を変換するときに使われてきました。
わずか 10 行ほどですが、奇数の長さの扱いと、読み書きの順序に工夫があります。

## コード

```c:line-numbers=20
void
swab (const void *bfrom, void *bto, ssize_t n)
{
  const char *from = (const char *) bfrom;
  char *to = (char *) bto;

  n &= ~((ssize_t) 1);
  while (n > 1)
    {
      const char b0 = from[--n], b1 = from[--n];
      to[n] = b0;
      to[n + 1] = b1;
    }
}
```

## 前提知識

- **`void *` とキャスト**: `void *` は型を決めていないポインタ（メモリ上の場所）です。中身を 1 バイトずつ扱うため、`(const char *) bfrom` のように `char *` に変換して使います。
- **`ssize_t`**: 符号付きの長さの型です（負の値も入れられます）。`size_t` の符号付き版です。
- **配列の添字とポインタ**: `from[i]` は「`from` から `i` バイト先の値」です。
- **`--n`（前置デクリメント）**: 先に `n` を 1 減らしてから、その値を使います。
- **ビットマスク `n &= ~((ssize_t) 1)`**: `~1` は「一番下のビットだけ 0、ほかは全部 1」の値です。これと AND を取ると、一番下のビットが 0 になり、**偶数に切り下げ** られます。`7 & ~1 = 6`、`8 & ~1 = 8` です。
- **宣言の中の初期化の順番**: `const char b0 = 式1, b1 = 式2;` のように 1 つの宣言で複数の変数を初期化すると、C では `式1` の評価が終わってから `式2` が評価されます。

## 何をしているか

### 1. 偶数に切り下げる

```c:line-numbers=26
  n &= ~((ssize_t) 1);
```

2 バイトずつ入れ替えるので、奇数の長さの最後の 1 バイトは相手がいません。`n &= ~1` で一番下のビットを消し、偶数にします。`n = 5` なら 4 です。

### 2. 後ろから 2 バイトずつ

```c:line-numbers=27
  while (n > 1)
    {
      const char b0 = from[--n], b1 = from[--n];
      to[n] = b0;
      to[n + 1] = b1;
    }
```

`n > 1` の間、次のことを繰り返します。

- `b0 = from[--n]` で `n` を 1 減らして、その位置のバイトを読む。
- `b1 = from[--n]` でさらに 1 減らして、その手前のバイトを読む。
- `to[n] = b0; to[n + 1] = b1;` で、2 つを **逆の位置** に書く。

`"abcd"`（`n = 4`）の例です。

- 1 周目: `b0 = from[3] = 'd'`、`b1 = from[2] = 'c'`、`n = 2`。`to[2] = 'd'`、`to[3] = 'c'`。
- 2 周目: `b0 = from[1] = 'b'`、`b1 = from[0] = 'a'`、`n = 0`。`to[0] = 'b'`、`to[1] = 'a'`。
- `n = 0` でループが終わり、`to` は `"badc"` です。

## ここがすごい

- **1 命令で偶数に**: `if (n % 2 == 1) n--;` と書く代わりに、AND 1 回で切り下げています。分岐がなく、意図も「最下位ビットを消す」と明快です。
- **2 つを読んでから書く**: 1 周の中で、まず 2 バイトを変数に読み込み、それから書き込みます。このため `from` と `to` が **同じバッファ** でも、書き込みが読み込み前のデータを壊すことがありません。`to[n] = from[n + 1]; to[n + 1] = from[n];` と直接書くと、同じバッファのときに 2 つ目の代入で書き換え済みの値を読んでしまいます。
- **カウンタが添字を兼ねる**: 残りの長さ `n` をそのまま添字に使い、`--n` で減らしながら読むので、別のループ変数が要りません。
- **負の長さにも安全**: `n` は符号付きなので、負の値が渡されても `while (n > 1)` が偽になり、何もせずに終わります。

## まとめ

- `n & ~1` で、分岐なしに偶数へ切り下げられる。
- 入れ替えは「全部読んでから書く」と、入力と出力が同じ場所でも壊れない。
- 1 つの宣言で複数の変数を初期化すると、左から順に評価される。
- 残りの長さを添字として使うと、逆向きのループが短く書ける。
