## ひとことで

`av_ceil_log2_c(x)` は、**log2(x) を切り上げた整数**、言い換えると「x 以上の最小の 2 のべき乗が 2 の何乗か」を返します。
`x = 5` なら 5 以上の最小の 2 のべき乗は 8 = 2^3 なので `3`、`x = 8` ならちょうど 2^3 なので `3`、`x = 9` なら `4` です。
中身は、切り捨て版の `av_log2` に `(x - 1) << 1` を渡すだけの 1 行です。

## 前提知識

- **log2 の切り捨てと切り上げ**: `av_log2(v)` は floor(log2(v))、つまり「v の最上位の 1 が何桁目にあるか」を返す FFmpeg の関数です。`av_log2(5) = 2`（5 は 2 進数で `101`、最上位は 2 桁目）、`av_log2(8) = 3` です。この関数は切り上げ版 ceil(log2(x)) を作ります。
- **`<<`（左シフト）**: ビットを左にずらす演算です。`v << 1` は `v * 2` と同じです。
- **`1U` と符号なし整数**: `1U` は符号なし（`unsigned`）の 1 です。`x - 1U` は符号なしの引き算になり、結果も符号なしになります。
- **`static`、`av_always_inline`、`av_const`**: ファイル内専用の関数で、必ず呼び出し元に埋め込んでほしい（インライン展開）、副作用がなく引数だけで結果が決まる、という指定です。
- **`/** ... */`**: ドキュメント用のコメントです。

## 何をしているか

### 1. 1 を引く

```c:line-numbers=427
    return av_log2((x - 1U) << 1);
```

切り上げの log2 がやっかいなのは、`x` が **ちょうど 2 のべき乗のときだけ** 切り捨てと同じ値になり、それ以外は切り捨て + 1 になる点です。
`x - 1` を考えると、この場合分けが消えます。2 のべき乗 8 から 1 を引くと 7（`111`）で最上位の桁が 1 つ下がり、9 から 1 を引いた 8（`1000`）は最上位の桁が変わりません。
つまり ceil(log2(x)) = floor(log2(x − 1)) + 1 です（x ≥ 2 のとき）。

### 2. 2 倍して +1 の代わりにする

```c:line-numbers=427
    return av_log2((x - 1U) << 1);
```

「+1」を足し算でやる代わりに、`av_log2` に渡す値を **2 倍（`<< 1`）** しています。値を 2 倍すると最上位の 1 が 1 桁上がるので、floor(log2(2v)) = floor(log2(v)) + 1 になります。

具体的に追います。

- `x = 5`: `(5 - 1) << 1 = 8` → `av_log2(8) = 3`
- `x = 8`: `(8 - 1) << 1 = 14`（`1110`）→ `av_log2(14) = 3`
- `x = 9`: `(9 - 1) << 1 = 16` → `av_log2(16) = 4`

### 3. x = 1 の端

```c:line-numbers=427
    return av_log2((x - 1U) << 1);
```

`x = 1` のとき、`(1 - 1) << 1 = 0` を `av_log2` に渡します。FFmpeg の `av_log2` は 0 に対して 0 を返すように作られているので、結果は `0` = ceil(log2(1)) で正しくなります。
もし「`av_log2(x - 1) + 1`」と書いていたら、`x = 1` で `av_log2(0) + 1 = 1` となり間違えます。2 倍する書き方なら、`0 * 2 = 0` なので +1 が発生せず、端も自然に正しくなります。

## ここがすごい

- **場合分けの消去**: 素直に書くと「x が 2 のべき乗かを調べ（`(x & (x - 1)) == 0`）、そうでなければ +1」となり、分岐か追加の演算が要ります。「1 引く」で 2 のべき乗の特別扱いを消し、「2 倍」で +1 を消しているので、関数本体は `av_log2` 1 回の呼び出しだけになります。
- **端の値まで正しい**: `+1` をシフトに置き換えたことで、x = 1 という一番の端も特別扱いなしで正しい値が出ます。式の形を少し変えるだけで、境界の扱いがきれいになる好例です。
- **符号なしで計算**: `x - 1U` と符号なしで計算しているので、シフトで最上位ビットまで使っても符号付き整数のオーバーフロー（C では未定義動作）を心配しなくて済みます。
- **既存の部品の再利用**: `av_log2` は CPU によっては 1 命令（先頭の 0 の数を数える命令）で計算されます。新しいビット演算を書かず、速い部品に入力を合わせるだけで切り上げ版を作っています。

## まとめ

- ceil(log2(x)) = floor(log2(x − 1)) + 1。「1 引く」で 2 のべき乗の特別扱いが消える。
- floor(log2(2v)) = floor(log2(v)) + 1。「+1」は「入力を 2 倍」に置き換えられる。
- 式の変形で、分岐も端の特別扱いもなくせることがある。
- 速い既存の関数があるなら、入力を変形してそれに任せるのが一番簡単で速い。
