## ひとことで

`int_sqrt(x)` は、`x` の平方根を切り捨てた整数を返す関数です。`int_sqrt(10)` は `3`、`int_sqrt(16)` は `4` です。
カーネルの中では浮動小数点数（小数）を気軽に使えないため、整数の演算だけで計算します。
やり方は、昔の算数で習う「開平法（筆算で平方根を求める方法）」を 2 進数で行うものです。

## コード

::: code-group

```c:line-numbers=14 [日本語訳]
/**
 * int_sqrt - 整数の平方根を計算する
 * @x: 平方根を求めたい整数
 *
 * 計算するもの: floor(sqrt(x))
 */
unsigned long int_sqrt(unsigned long x)
{
	unsigned long b, m, y = 0;

	if (x <= 1)
		return x;

	m = 1UL << (__fls(x) & ~1UL);
	while (m != 0) {
		b = y + m;
		y >>= 1;

		if (x >= b) {
			x -= b;
			y += m;
		}
		m >>= 2;
	}

	return y;
}
```

## 前提知識

- **`unsigned long`**: 0 以上の整数を表す型です。
- **`1UL`**: 値が 1 の `unsigned long` の定数です。`1UL << k` は 2 の `k` 乗です。
- **`__fls(x)`**: `x` のいちばん上に立っている 1 が何ビット目か（0 から数える）を返すカーネルの関数です。`__fls(10)` は `3`（`10` は `1010`）です。
- **`& ~1UL`**: 最下位ビットを 0 にします。つまり、偶数に切り下げます。
- **`>>=`、`<<`**: ビットを右・左にずらす演算です。`m >>= 2` は 4 で割るのと同じです。
- **`x -= b`、`y += m`**: それぞれ `x = x - b`、`y = y + m` の短い書き方です。

## 何をしているか

### 考え方

答え `y` を、上の桁から 1 ビットずつ決めていきます。2 進数の平方根の 1 桁は、元の数の 2 桁ぶんに当たります。そこで `m` は 4 のべき乗（`...64, 16, 4, 1`）として、2 ビットずつ下へ動かします。
各段階で「この桁を 1 にしても、2 乗が `x` を超えないか」を試し、超えなければ 1 に確定し、その分を `x` から引きます。

### 0 と 1

```c:line-numbers=24
	if (x <= 1)
		return x;
```

`x` が 0 か 1 なら、平方根はそれ自身です。

### 最初の `m` を決める

```c:line-numbers=27
	m = 1UL << (__fls(x) & ~1UL);
```

`__fls(x) & ~1UL` で、`x` の最上位ビットの位置を偶数に切り下げます。`m` はその位置の 4 のべき乗、つまり「`x` 以下で最大の 4 のべき乗」になります。

### 1 桁ずつ確定する

```c:line-numbers=28
	while (m != 0) {
		b = y + m;
		y >>= 1;

		if (x >= b) {
			x -= b;
			y += m;
		}
		m >>= 2;
	}
```

`y` には、決まった答えのビットが「`m` の分だけ左にずれた形」で入っています。

- `b = y + m;`: `b = y + m` が、「この桁を 1 にしたら追加で必要になる量」です。
- `y >>= 1;`: `y` を 1 ビット右にずらし、次の桁のための位置合わせをします。
- `if (x >= b)`: 残りの `x` が `b` 以上なら、この桁は 1。`x` から `b` を引き、`y` に `m` を足します。
- `m >>= 2;`: `m` を 4 で割り、次の桁へ。

### 具体例: `x = 10`

- `__fls(10) = 3`、偶数に切り下げて `2`、`m = 4`。
- 1 周目: `b = 0 + 4 = 4`、`y = 0`。`10 >= 4` なので `x = 6`、`y = 4`。`m = 1`。
- 2 周目: `b = 4 + 1 = 5`、`y = 2`。`6 >= 5` なので `x = 1`、`y = 3`。`m = 0`。
- ループを抜けて `3` を返します。√10 ≒ 3.16 なので正しい答えです。

### 具体例: `x = 16`

- `m = 16`。1 周目で `x = 0`、`y = 16`。2 周目は `b = 20`、`y = 8`、`0 < 20` なので何もしない。3 周目は `b = 9`、`y = 4`、何もしない。答えは `4` です。

## ここがすごい

- **掛け算も割り算もない**: ループの中身は足し算・引き算・シフト・比較だけです。ニュートン法のように割り算を何度も使う方法より、命令が単純です。
- **ループ回数が決まっている**: `m` は 2 ビットずつ下がるので、64 ビットの数でも最大 32 周です。入力によって回数が大きくぶれず、カーネルで扱いやすい性質です。
- **`y` の二役**: `y` は「途中の答え」でありながら、ずらし方を工夫することで「次に引くべき量」の計算にもそのまま使えます。開平法の「2 倍して次の桁を足す」計算が、`y + m` と `y >>= 1` の 2 つの操作に溶け込んでいます。
- **開始位置を 1 命令で決める**: `__fls` で最初の `m` を決めるので、大きな `m` から始めて空回りする無駄がありません。ファイル冒頭のコメントにあるとおり、Guy L. Steele の shift-and-subtract 法に基づく実装です。

## まとめ

- 整数の平方根は、開平法を 2 進数で行えば、足し算・引き算・シフトだけで求まる。
- 2 進数の平方根の 1 桁は、元の数の 2 桁に対応する（だから `m` は 4 のべき乗で動く）。
- 最上位ビットの位置（`__fls`）を使うと、計算の開始点をすぐに決められる。
- 回数が入力の大きさで決まるループは、カーネルのような環境で扱いやすい。
