## ひとことで

`__sw_hweight32(w)` は、32 ビットの整数 `w` の中で **1 になっているビットの数**（ハミング重み、popcount とも呼ばれます）を返す関数です。`0b1011` なら `3` です。
1 ビットずつ 32 回調べる代わりに、**隣どうしの組をまとめて同時に足す**ことをくり返し、わずか数ステップで数えます。
CPU に専用命令がないときに使われるソフトウェア版（`sw` は software の意味）です。

## コード

::: code-group

```c:line-numbers=6 [日本語訳]
/**
 * DOC: __sw_hweightN - N ビットの語のハミング重みを返す
 * @w: 重みを量る語
 *
 * 数のハミング重みとは、その中で立っているビットの総数のこと。
 */

unsigned int __sw_hweight32(unsigned int w)
{
#ifdef CONFIG_ARCH_HAS_FAST_MULTIPLIER
	w -= (w >> 1) & 0x55555555;
	w =  (w & 0x33333333) + ((w >> 2) & 0x33333333);
	w =  (w + (w >> 4)) & 0x0f0f0f0f;
	return (w * 0x01010101) >> 24;
#else
	unsigned int res = w - ((w >> 1) & 0x55555555);
	res = (res & 0x33333333) + ((res >> 2) & 0x33333333);
	res = (res + (res >> 4)) & 0x0F0F0F0F;
	res = res + (res >> 8);
	return (res + (res >> 16)) & 0x000000FF;
#endif
}
```

## 前提知識

- **`unsigned int`**: 32 ビットの符号なし整数として使われています。
- **16 進数の定数**: `0x55555555` は 2 進数で `0101…0101`、`0x33333333` は `0011…0011`、`0x0f0f0f0f` は `00001111…` です。決まった位置のビットだけを取り出すマスクとして使います。
- **`>>`**: ビットを右にずらします。
- **`&`**: ビットごとの AND で、マスクの 1 の位置だけ残します。
- **`#ifdef CONFIG_ARCH_HAS_FAST_MULTIPLIER`**: 「この CPU は掛け算が速い」という設定のときだけ使う部分です。`#else` 以下は掛け算が遅い CPU 向けです。
- **符号なし整数の掛け算**: 結果が 32 ビットを超えると、上の桁は捨てられます。

## 何をしているか

32 ビットを「小さな箱」の集まりとみなし、箱の中に「その範囲の 1 の数」を入れていきます。箱の大きさを 2 → 4 → 8 ビットと倍にしていきます。

### 2 ビットずつ数える

```c:line-numbers=16
	w -= (w >> 1) & 0x55555555;
```

2 ビットの箱の中身 `ab`（値は `2a + b`）を、1 の数 `a + b` に変えたいとします。
`(2a + b) − a = a + b` なので、「上のビットを 1 つ右にずらして引く」だけで済みます。`(w >> 1) & 0x55555555` が各箱の上のビット `a` です。

たとえば箱が `11` なら `3 − 1 = 2`、`10` なら `2 − 1 = 1`、`01` なら `1 − 0 = 1` になります。

### 4 ビットずつ

```c:line-numbers=17
	w =  (w & 0x33333333) + ((w >> 2) & 0x33333333);
```

`0x33333333` で各 4 ビットの下の 2 ビットを、`>> 2` してから同じマスクで上の 2 ビットを取り出して足します。各 4 ビットの箱に、0〜4 の個数が入ります。

### 8 ビットずつ

```c:line-numbers=18
	w =  (w + (w >> 4)) & 0x0f0f0f0f;
```

`w + (w >> 4)` で隣の 4 ビットの箱を足し、`0x0f0f0f0f` で各バイトの下半分だけ残します。各バイトに 0〜8 の個数が入ります。8 は 4 ビットに収まるので、足す前にマスクする必要がなく、マスクは 1 回で済みます。

### 掛け算で 4 バイトを合計

```c:line-numbers=19
	return (w * 0x01010101) >> 24;
```

`w * 0x01010101` は、`w` を 0、8、16、24 ビットずらしたものを足したのと同じです。すると一番上のバイトに、4 つのバイトの合計が集まります。`>> 24` でそれを取り出せば答えです。

### 掛け算が遅い CPU 向け

```c:line-numbers=21
	unsigned int res = w - ((w >> 1) & 0x55555555);
	res = (res & 0x33333333) + ((res >> 2) & 0x33333333);
	res = (res + (res >> 4)) & 0x0F0F0F0F;
	res = res + (res >> 8);
	return (res + (res >> 16)) & 0x000000FF;
```

途中まで同じで、最後の合計を `res + (res >> 8)`、`res + (res >> 16)` の 2 回の足し算で行い、下位 8 ビットを取り出します。

### 具体例: `w = 0xF0`（下位バイトが `11110000`）

- `w -= (w >> 1) & 0x55555555;`: 2 ビットの箱 `11 11 00 00` が `10 10 00 00`（2, 2, 0, 0）になります。
- `w =  (w & 0x33333333) + ((w >> 2) & 0x33333333);`: 4 ビットの箱が `0100 0000`（4, 0）になります。
- `w =  (w + (w >> 4)) & 0x0f0f0f0f;`: バイトが `00000100`（4）になります。
- `return (w * 0x01010101) >> 24;`: 合計 4 が一番上のバイトに集まり、答えは `4` です。

## ここがすごい

- **分岐もループもない**: 1 ビットずつ数えるとループが 32 回回ります。この方法は、シフト・AND・足し算・引き算・掛け算が十数回だけで、入力によって命令の数が変わりません。
- **1 つの整数の中で並列計算**: 1 回の足し算で 16 組、8 組、4 組を同時に処理しています。整数を小さな箱の集まりとみなす SWAR（SIMD Within A Register）の代表例です。
- **箱があふれない理由**: 2 ビットの箱には最大 2、4 ビットには最大 4、8 ビットには最大 8 しか入りません。どれも箱の大きさで表せるので、隣の箱へ繰り上がることがありません。`w =  (w + (w >> 4)) & 0x0f0f0f0f;`でマスクを 1 回に減らせるのもこの余裕のおかげです。
- **CPU に合わせた最後の一手**: 掛け算 1 回で合計できるのは、掛け算が速い CPU だけで得をする方法です。遅い CPU ではシフトと足し算で代用しています。同じファイルの 64 ビット版も同じ形です。

## まとめ

- 2 ビットの 1 の数は「値 − 上のビット」で求まる。
- 箱の大きさを倍々にしながら隣どうしを足すと、ビット数の対数回のステップで数え終わる。
- `0x01010101` を掛けると、各バイトの合計が一番上のバイトに集まる。
- 専用命令がない環境のために、分岐のない速いソフトウェア版を用意している。
