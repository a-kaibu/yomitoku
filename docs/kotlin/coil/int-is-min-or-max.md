## ひとことで

`isMinOrMax` は、`Int`（整数）の値が **`Int.MIN_VALUE`（最小値）か `Int.MAX_VALUE`（最大値）のどちらかかを調べる** 拡張関数です。たとえば `Int.MAX_VALUE` は約 21 億で、普通の寸法としては使われない大きさです。

Coil は、画像を表示するときに、目的の大きさ（幅や高さ）を決めます。その中で、特別な値が「大きさが決まっていない」という意味で使われることがあり、この判定がそれを見分けるために使われます。

## コード

```kotlin:line-numbers=98
internal fun Int.isMinOrMax() = this == Int.MIN_VALUE || this == Int.MAX_VALUE
```

## 前提知識

- **`Int.MIN_VALUE` と `Int.MAX_VALUE`**: `Int` で表せる最小の値と最大の値です。32 ビットの整数では、およそマイナス 21 億からプラス 21 億までです。
- **`==`**: 値が等しいかを比べる演算子です。`||` で「どちらか」を表します。
- **拡張関数**: `Int` に後から関数を足す書き方です。`this` が、呼び出した `Int` の値を指します。
- **式の本体**: `= ...` の形で書くと、関数の値がその式の結果になります。`return` は不要です。
- **`internal`**: 同じモジュールの中からだけ使える指定です。

## 何をしているか

### 1. 最小値か最大値かを比べる

```kotlin:line-numbers=98
internal fun Int.isMinOrMax() = this == Int.MIN_VALUE || this == Int.MAX_VALUE
```

`this`（呼び出した整数）が最小値か、最大値のどちらかと等しければ `true` を返します。どちらでもなければ `false` です。

### 2. 呼び出し側での使われ方

Coil の画像のデコード処理では、目的の幅や高さがこの特別な値の場合、その方向の大きさの計算を行わない、という判断に使われています。特別な値は、「この方向の大きさは決まっていない」という印として働くと読めます。

## ここがすごい

- **特別な値を名前で扱う**: 「最小値か最大値」という条件を、`isMinOrMax` という名前にしたことで、呼び出し側の意図が読みやすくなります。数字そのものを何度も書く必要がありません。
- **1 行で判定が完結する**: 2 つの比較を `||` でつないだだけの、短い関数です。判定の仕組みが、ひと目で分かります。
- **型安全**: `Int` の拡張関数なので、他の型の値に誤って使うことはありません。
- **境界の値を使った印**: 普段は現れない大きな値を、「未指定」の目印として使う方法は、数値の設計でよく見られます。ただし、本当にその値が入ると区別できなくなるので、印として使う値は慎重に選ぶ必要があります。

## まとめ

- 特別な境界値を判定する処理は、名前付きの関数にすると、呼び出し側の意図が伝わる。
- 普段は使われない値を「未指定」の印にする設計は、数値でよく使われる。
- 印として使う値は、本物の値と区別がつかなくならないように選ぶ。
