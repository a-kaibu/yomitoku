## ひとことで

`parseHexDigit()` は、16 進数の **1 文字** を、0 から 15 の値に変える関数です。16 進数の文字でなければ、例外を投げずに `-1` を返します。

OkHttp（HTTP クライアントのライブラリ）の内部で、16 進数の 1 文字を読むために使われる小さな関数です。

## コード

```kotlin:line-numbers=197
internal fun Char.parseHexDigit(): Int =
  when (this) {
    in '0'..'9' -> this - '0'
    in 'a'..'f' -> this - 'a' + 10
    in 'A'..'F' -> this - 'A' + 10
    else -> -1
  }
```

## 前提知識

- **16 進数の 1 文字**: 0〜9 と、a〜f または A〜F の 16 種類です。1 文字で 0 から 15 の値を表します。
- **文字の差で値を求める**: `'7' - '0'` は 7 になります。文字コードの並びを使うと、表を書かずに値が求まります。
- **`when` の範囲指定**: `in '0'..'9'` は、その範囲の文字に当てはまるかを調べます。
- **拡張関数 `Char.parseHexDigit()`**: `Char` という型に後から足された関数です。`c.parseHexDigit()` と呼べます。
- **`-1` を印にする**: 0 から 15 のどれとも重ならない値です。呼び出し側は、この値を見て「不正な文字」と判断できます。

## 何をしているか

### 数字の文字

```kotlin:line-numbers=199
    in '0'..'9' -> this - '0'
```

`'0'` から `'9'` は、そのまま 0 から 9 の値になります。`this - '0'` は、2 つの文字の差を整数で返します。

### 小文字と大文字

```kotlin:line-numbers=200
    in 'a'..'f' -> this - 'a' + 10
```

小文字の `a` から `f` は、10 から 15 の値になります。

```kotlin:line-numbers=201
    in 'A'..'F' -> this - 'A' + 10
```

大文字も同じ考え方で、10 から 15 の値になります。

### 不正な文字

```kotlin:line-numbers=202
    else -> -1
```

どの範囲にも当てはまらなければ、`-1` を返します。例外は投げません。

## ここがすごい

- **例外を使わない判定**: 不正な文字が見つかるたびに例外を投げると、処理が重くなり、読む側も流れを追いにくくなります。`-1` を返すだけなら、呼び出し側が自然に判断できます。
- **同じ仕事の別の書き方**: Okio の `decodeHexDigit` は、不正な文字で例外を投げます。こちらは `-1` を返します。どちらを選ぶかは、呼び出し側が「不正な入力をどう扱うか」で決まります。
- **大文字と小文字を対称に**: 小文字と大文字の枝の形がそろっているので、読み違いが起きにくくなっています。
- **短い分岐**: 4 つの枝だけで、受け入れる文字の範囲が一目で分かります。

## まとめ

- `parseHexDigit` は、16 進数の 1 文字を 0 から 15 の値に変え、不正な文字は `-1` で知らせる。
- 例外ではなく戻り値で判断させるので、ヘッダーを読むような、不正な入力が普通にありうる場面で使いやすい。
- 文字の範囲と差を使った単純な分岐で、受け入れる文字がすぐ分かる。
