## ひとことで

`formatDuration` は、ナノ秒（10 億分の 1 秒）で表された時間を、**人が読みやすい単位と桁数で表す** 関数です。大きさに応じて `s`（秒）、`ms`（ミリ秒）、`µs`（マイクロ秒）を使い分け、最後に 6 文字の幅にそろえます。

OkHttp のタスクのログには、処理にかかった時間を記録します。その時間が `1234567890 ns` のような数字のままでは読みにくいので、この関数で単位を付けて整えています。

## コード

```kotlin:line-numbers=76
fun formatDuration(ns: Long): String {
  val s =
    when {
      ns <= -999_500_000 -> "${(ns - 500_000_000) / 1_000_000_000} s "
      ns <= -999_500 -> "${(ns - 500_000) / 1_000_000} ms"
      ns <= 0 -> "${(ns - 500) / 1_000} µs"
      ns < 999_500 -> "${(ns + 500) / 1_000} µs"
      ns < 999_500_000 -> "${(ns + 500_000) / 1_000_000} ms"
      else -> "${(ns + 500_000_000) / 1_000_000_000} s "
    }
  return String.format("%6s", s)
}
```

## 前提知識

- **ナノ秒、マイクロ秒、ミリ秒**: 1 秒は 1000 ミリ秒、1 ミリ秒は 1000 マイクロ秒、1 マイクロ秒は 1000 ナノ秒です。ナノ秒の値を 1000 で割ると、単位が 1 つ大きくなります。
- **負の値**: 時間の差は、負になることもあるので、符号も考えて単位を選びます。
- **四捨五入のための加算**: 割り算の前に、単位の半分（たとえば 500）を足すと、結果が四捨五入されます。
- **`String.format("%6s", s)`**: 文字列を、幅 6 文字に右寄せでそろえる書き方です。
- **`when` の条件**: 上から順に調べ、最初に当てはまった単位を使います。

## 何をしているか

### 1. 大きさに応じて単位を選ぶ

```kotlin:line-numbers=79
      ns <= -999_500_000 -> "${(ns - 500_000_000) / 1_000_000_000} s "
      ns <= -999_500 -> "${(ns - 500_000) / 1_000_000} ms"
```

負の値では、絶対値が大きいものから順に秒やミリ秒を選びます。数字の 999_500_000 のような境界は、表示したときに 1000 にならないように選んだ値です。

### 2. 正の値も同じ考え方で表す

```kotlin:line-numbers=81
      ns <= 0 -> "${(ns - 500) / 1_000} µs"
      ns < 999_500 -> "${(ns + 500) / 1_000} µs"
```

0 に近い値はマイクロ秒で表し、符号に応じて、500 を足すか引いて四捨五入します。

### 3. 幅をそろえて返す

```kotlin:line-numbers=86
  return String.format("%6s", s)
```

どの単位で表しても、最後に幅 6 文字で右寄せにします。ログの表で、時間の数字の位置がそろうようにするためです。

## ここがすごい

- **境界で表示の桁数を保つ**: 999.5 ミリ秒などの境界を使って、表示が「1000 ms」のような中途半端な形にならないように、単位を切り替えています。
- **四捨五入を割り算で行う**: 半分の値を足してから割るだけで、四捨五入ができます。小数を使わず、整数の計算だけで済みます。
- **単位の選び方が表に見える**: `when` の各行が、どの範囲でどの単位を使うかを表しています。仕様の確認が、1 か所で済みます。
- **表示の幅をそろえる**: 桁数が違う値が並んでも、列がずれないように、最後に幅をそろえています。

### 注意点: 幅を超える値はそのまま長くなる

コメントにもあるように、大きい値や負の値の表示は 6 文字を超えることがあります。幅は「そろえるための目安」であり、切り詰めはしません。

## まとめ

- 時間の表示は、大きさに応じて単位を切り替えると、読みやすくなる。
- 四捨五入は、単位の半分を足してから割ると、整数の計算だけで済む。
- 表の中の数字をそろえるには、最後に幅をそろえる処理を入れる。
