## ひとことで

`read14BitInt` は、文字列の **連続する 2 文字を、1 つの 14 ビットの整数として読み出す** 関数です。1 文字に 7 ビットずつ、数の上位と下位を分けて入れてあります。

OkHttp は、国際化されたドメイン名（IDN）を扱うために、Unicode の変換表を持っています。その表は、数の列を文字列の形で持つと、ソースコードやメモリを小さくできます。この関数は、その表から数を取り出す入口です。

## コード

```kotlin:line-numbers=271
internal fun String.read14BitInt(index: Int): Int {
  val b0 = this[index].code
  val b1 = this[index + 1].code
  return (b0 shl 7) + b1
}
```

## 前提知識

- **ビット**: 数を 2 進数で表したときの 1 桁です。7 ビットなら、0 から 127 までの値を表せます。
- **`shl`（左シフト）**: 数のビットを左にずらす演算です。`x shl 7` は、`x` に 128 を掛けるのと同じです。
- **`Char.code`**: 文字を、その文字コードの整数として取り出します。`this[index].code` は、`index` の文字の番号です。
- **14 ビット**: 7 ビットを 2 つ並べた大きさです。0 から 16383 までを表せます。
- **表（テーブル）**: 大量のデータを、決まった形で並べて持つものです。ここでは、文字列の中に数が詰められています。

## 何をしているか

### 1. 2 文字を読む

```kotlin:line-numbers=272
  val b0 = this[index].code
  val b1 = this[index + 1].code
```

`index` の文字と、その次の文字を、文字コードの整数として読みます。それぞれが、14 ビットのうちの上位 7 ビットと下位 7 ビットを持っています。

### 2. 上位を左にずらして、下位を足す

```kotlin:line-numbers=274
  return (b0 shl 7) + b1
```

`b0` を 7 ビット左にずらして、上位の位置に移します。そこに `b1` を足すと、2 文字ぶんの 14 ビットの数になります。`+` を使うのは、2 つの値の範囲が重ならないからです。`b1` は 0 から 127 までなので、上位の 7 ビットとぶつかりません。

## ここがすごい

- **1 つの文字に 7 ビット**: 文字は 1 つの `Char` で 16 ビットを持ちますが、ここでは 7 ビットずつしか使っていません。その分、表に入る数を、文字列の形で安全に運べます。
- **シフトと足し算だけで組み立てる**: 掛け算や割り算を使わず、ビットのずらしと足し算だけで数を作っています。短く速い処理です。
- **範囲が重ならないように設計されている**: 上位と下位の値の範囲を 7 ビットずつに分けているので、足し算でも正しい値になります。`or` を使っても同じ結果になります。
- **呼び出す側が位置を決める**: この関数は、どの位置から読むかを引数で受け取るだけです。表の構造は呼び出し側が知っていれば、この関数は単純な部品のままです。

## まとめ

- 数を 7 ビットずつに分けて、文字の列に詰めると、表をコンパクトに持てる。
- 上位をずらして下位を足すと、2 文字から 14 ビットの数を組み立てられる。
- 値の範囲が重ならないように分けておくと、足し算でも `or` でも同じ結果になる。
