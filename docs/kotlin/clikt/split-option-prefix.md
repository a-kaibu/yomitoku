## ひとことで

`splitOptionPrefix` は、コマンドラインの引数 1 つを、**「前置き」と「名前」の 2 つに分ける** 関数です。たとえば `--verbose` なら `"--"` と `"verbose"` に、`-v` なら `"-"` と `"v"` に分けます。

Clikt は、オプションを `--verbose` や `-v` のように書くと、どの名前かを判断して受け取ります。この関数は、その判断の最初の一歩で、引数の先頭を見て前置きを決めています。

## コード

```kotlin:line-numbers=133
internal fun splitOptionPrefix(name: String): Pair<String, String> =
    when {
        name.length < 2 || name[0] !in "-@/+" -> "" to name
        name.length > 2 && name[0] == name[1] -> name.slice(0..1) to name.substring(2)
        else -> name.substring(0, 1) to name.substring(1)
    }
```

## 前提知識

- **オプション（option）**: `--verbose` や `-v` のように、名前の前に記号が付いた引数です。コマンドを実行するときの設定を表します。
- **前置き（prefix）**: オプションの名前の前に付く記号の部分です。ここでは `-`、`@`、`/`、`+` のどれかが 1 文字目に来るものを対象にしています。
- **`Pair<String, String>`**: 2 つの文字列を組にした値です。`a to b` と書くと `Pair(a, b)` になり、`first` と `second` で取り出せます。
- **`when` の条件**: 上から順に条件を調べ、最初に当てはまった分岐の値を返します。`else` は、どれにも当てはまらないときの分岐です。
- **`in`**: 文字列の中に文字が含まれるかを調べる書き方です。`name[0] !in "-@/+"` は「先頭の文字が `-@/+` のどれでもない」という意味です。
- **`slice` と `substring`**: どちらも文字列の一部を取り出す関数です。`slice(0..1)` は位置 0 と 1 の文字、`substring(2)` は位置 2 から後ろを取り出します。

## 何をしているか

### 1. 記号で始まらない、短い引数はそのまま名前

```kotlin:line-numbers=135
        name.length < 2 || name[0] !in "-@/+" -> "" to name
```

1 文字以下の引数や、先頭が前置きの記号ではない引数は、前置きを空の文字列にして、引数全体を名前として返します。通常の位置引数（ファイル名など）がここに入ります。

### 2. 同じ記号が 2 つ続くなら、前置きは 2 文字

```kotlin:line-numbers=136
        name.length > 2 && name[0] == name[1] -> name.slice(0..1) to name.substring(2)
```

`--verbose` のように、先頭の 2 文字が同じ記号なら、前置きを 2 文字に、名前を 3 文字目以降にします。`name.length > 2` の条件は、`--` だけの引数を、この分岐から外すためにあります。

### 3. それ以外は 1 文字だけが前置き

```kotlin:line-numbers=137
        else -> name.substring(0, 1) to name.substring(1)
```

`-v` のように、先頭の 1 文字だけが記号なら、それを前置きにします。`--` だけの引数は、この分岐に入り、前置きが `-`、名前も `-` になります。

## ここがすごい

- **条件の順番で場合を分ける**: 「記号ではない」「2 文字続く」「それ以外」の順に調べるので、どの引数もちょうど 1 つの分岐に入ります。順番を入れ替えると、結果が変わってしまう作りです。
- **長い前置きを、同じ文字の繰り返しで判定**: `--` を特別な記号として登録せず、「同じ記号が 2 つ続く」という形で見分けています。`-@` のような組み合わせも、同じ規則で扱えます。
- **結果を組で返す**: 前置きと名前を 1 回の呼び出しで返すので、呼び出し側は両方をまとめて使えます。
- **引数の形だけを見る**: 中身の意味は知らずに、先頭の文字だけを見て分けるので、関数が小さく、テストもしやすい作りです。

### 注意点: `--` だけの引数

`--` だけの引数は、前置きが `-`、名前も `-` になります。慣習では `--` は「ここから後ろは位置引数」という区切りの印ですが、この関数は名前として扱うだけです。区切りの特別扱いは、呼び出し側の別の処理が担当しています。

## まとめ

- 引数の先頭の記号を見て、前置きと名前に分けると、オプションの形を単純に扱える。
- 同じ記号が 2 つ続くかで、長い前置きと短い前置きを見分けられる。
- 条件は順番に意味があるので、場合を重ならないように並べる。
