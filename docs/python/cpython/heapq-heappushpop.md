## ひとことで

`heappushpop(heap, item)` は、**ヒープに `item` を追加して、そのあと最小値を取り出す** という 2 つの操作を、まとめて効率よく行う関数です。
「上位 10 件だけを保ちながらデータを流し込む」といった処理で、1 件ごとに呼ばれることを想定しています。
わずか 4 行ですが、「やらなくていい仕事は最初から見抜いて省く」という考え方が凝縮されています。

## コード

```python:line-numbers=164
def heappushpop(heap, item):
    """Fast version of a heappush followed by a heappop."""
    if heap and heap[0] < item:
        item, heap[0] = heap[0], item
        _siftup(heap, 0)
    return item
```

`_siftup` は同じファイルの 274 行目にある関数で、ヒープのある位置に置いた値を正しい位置まで沈め直します。

## 前提知識

- **ヒープ**: いちばん小さい値をすぐ取り出せるデータ構造です。Python の `heapq` では、ふつうのリストを「`heap[0]` が常に最小」というルールで並べて使います。
- **ヒープのルール**: 位置 `i` の値は、その子（`2*i+1` と `2*i+2`）以下であること。
- **リストの真偽値**: 空のリスト `[]` は偽、要素があるリストは真として扱われます。`if heap` は「ヒープが空でなければ」という意味です。
- **`and` の短絡評価**: `A and B` は、`A` が偽なら `B` を評価しません。空のリストに `heap[0]` でアクセスしてエラーになるのを防げます。
- **多重代入（スワップ）**: `a, b = b, a` と書くと、2 つの値を入れ替えられます。右辺がすべて計算されてから代入されます。

## 何をしているか

### 1. 新しい値がヒープの最小値より大きいか調べる（166 行目）

`heap = [2, 5, 3]`（最小値は 2）とします。

- `item = 1` の場合: `2 < 1` は偽なので、何もせず `1` をそのまま返します。ヒープは変わりません。
- `item = 4` の場合: `2 < 4` は真なので、次に進みます。

### 2. 先頭と入れ替えて沈める（167〜168 行目）

`item, heap[0] = heap[0], item` で、`item` は `2`（取り出す最小値）に、`heap[0]` は `4` になります。ヒープは `[4, 5, 3]` で、先頭だけがルール違反です。
`_siftup(heap, 0)` で `4` を正しい位置へ沈めると、`[3, 5, 4]` になります。

### 3. 取り出した値を返す（169 行目）

`2` を返します。

## ここがすごい

### 「追加 → 取り出し」を素直にやると無駄が多い

素直に書くと、

```python
heappush(heap, item)   # 末尾に追加して、上へ浮かせる
return heappop(heap)   # 末尾の値を先頭に移して、下へ沈める
```

となり、値を浮かせる処理と沈める処理の両方が走ります。リストの長さも一度伸びてから縮みます。

### 「入れた値がいちばん小さければ、入れる意味がない」

`item` がヒープの最小値以下なら、追加しても次の取り出しで `item` 自身が出てくるだけです。つまり **ヒープに触れずに `item` を返せば同じ結果** になります。166 行目の条件 1 つで、この場合の処理を丸ごと省いています。

### 入れ替えなら沈める処理は 1 回だけ

そうでない場合も、`item` と `heap[0]` を入れ替えて沈めるだけで済みます。リストの長さは変わらず、沈める処理（`_siftup`）が 1 回走るだけです。

### `<` しか使わない

条件は `heap[0] < item` と書かれています。`item <= heap[0]` のような書き方をしないことで、要素が `__lt__` を定義していれば動くという、`heapq` 全体の約束を守っています。

## まとめ

- 2 つの操作を組み合わせた専用関数を用意すると、途中の無駄を省ける。
- 「結果が変わらない場合」を先に見つけて早く返すと、多くの入力で処理がゼロになる。
- 空のリストへのアクセスは `and` の短絡評価で防げる。
