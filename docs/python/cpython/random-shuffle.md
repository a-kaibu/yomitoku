## ひとことで

`shuffle(x)` は、リスト `x` の要素をランダムに並べ替える（シャッフルする）メソッドです。新しいリストは作らず、`x` そのものを書き換えます。
中身は **Fisher-Yates（フィッシャー–イェーツ）法** という有名なアルゴリズムで、n 個の要素のすべての並び方（n! 通り）が、どれも同じ確率で出るようになっています。

## コード

```python:line-numbers=356
    def shuffle(self, x):
        """Shuffle list x in place, and return None."""

        randbelow = self._randbelow
        for i in reversed(range(1, len(x))):
            # pick an element in x[:i+1] with which to exchange x[i]
            j = randbelow(i + 1)
            x[i], x[j] = x[j], x[i]
```

`self._randbelow(n)` は、0 以上 n 未満の整数をランダムに 1 つ返すメソッドです。

## 前提知識

- **メソッドと `self`**: `def shuffle(self, x)` の `self` は、このメソッドを呼んだ乱数生成器そのものです。`random.shuffle(x)` と書くと、内部で用意されている生成器の `shuffle` が呼ばれます。
- **`range(1, n)`**: 1, 2, ..., n-1 の整数の並びです。
- **`reversed(...)`**: 並びを逆順にします。`reversed(range(1, 5))` は 4, 3, 2, 1 です。
- **スワップ**: `x[i], x[j] = x[j], x[i]` で、2 つの要素を入れ替えます。
- **その場で書き換える（in place）**: 戻り値は `None` で、渡したリスト自体が変わります。

## 何をしているか

`x = ["A", "B", "C", "D"]` で追います。

### 1. 生成器のメソッドをローカル変数に入れる（359 行目）

ループの中で何度も使うので、`self._randbelow` を `randbelow` に取り出しておきます。

### 2. 後ろから順に、入れ替え相手を選ぶ（360〜363 行目）

| i | 選ぶ範囲 | j（例） | 入れ替え後 |
| --- | --- | --- | --- |
| 3 | 0〜3 | 1 | A, **D**, C, **B** |
| 2 | 0〜2 | 2 | A, D, **C**, B（自分自身と交換） |
| 1 | 0〜1 | 0 | **D**, **A**, C, B |

各ステップで、位置 `i` に来る要素を「まだ確定していない `x[0]`〜`x[i]` の中から」ランダムに選んで確定させています。`i = 0` のときは選択肢が 1 つしかないので、ループは 1 で止めています。

## ここがすごい

### すべての並び方が等しい確率になる

最後の位置には 4 個のどれもが 1/4 で入り、次の位置には残り 3 個のどれもが 1/3 で入り……となるので、特定の並び方が出る確率は `1/4 × 1/3 × 1/2 = 1/24`。4 個の並び方はちょうど 24 通りなので、**どの並び方も等しく出ます**。

### よくある間違いとの違い

素朴に「各位置について、リスト全体からランダムな相手と入れ替える」と書くと、

```python
for i in range(len(x)):
    j = randbelow(len(x))   # 毎回 0〜n-1 から選ぶ
    x[i], x[j] = x[j], x[i]
```

選び方が n^n 通りになります。4 個なら 256 通りで、24 で割り切れないので、**並び方によって出やすさに偏りが出てしまいます**。362 行目で範囲を `i + 1` に絞っているのが、正しさのかなめです。

### 余分なメモリを使わない

新しいリストを作らず、入れ替えだけで並べ替えるので、追加のメモリはほぼゼロです。計算量も O(n) で、ソートを使ったシャッフル（O(n log n)）より速くなります。

### 偏りのない乱数を土台にしている

`randbelow` は「0〜n-1 の整数を正確に等確率で返す」関数です。`int(random() * n)` のように小数から作ると、n が大きいときにわずかな偏りが生まれることがあるため、専用の関数を使っています。

## まとめ

- Fisher-Yates 法は「後ろから 1 つずつ、残りの中から選んで確定する」シャッフル。
- 選ぶ範囲を毎回 1 つずつ狭めることが、偏りをなくすポイント。
- 正しく見える乱数の使い方でも、場合の数が割り切れないと偏りが出る。
