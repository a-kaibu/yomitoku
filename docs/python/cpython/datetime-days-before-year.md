## ひとことで

`_days_before_year(year)` は、**西暦 1 年 1 月 1 日から、`year` 年の 1 月 1 日の前日までに何日あるか** を返す関数です。
`_days_before_year(1)` は `0`、`_days_before_year(2)` は `365` です。
うるう年を 1 年ずつ調べずに、たった 1 行の式で答えを出しています。

## コード

```python:line-numbers=51
def _days_before_year(year):
    "year -> number of days before January 1st of year."
    y = year - 1
    return y*365 + y//4 - y//100 + y//400
```

## 前提知識

- **`//`**: 割り算の結果を切り捨てて整数にする演算子です。`7 // 4` は `1` です。
- **`y*365`**: Python では `*` が掛け算です。
- **グレゴリオ暦のうるう年**: 4 で割り切れる年はうるう年（2 月が 29 日まで）。ただし 100 で割り切れる年は平年。ただし 400 で割り切れる年はうるう年。2000 年はうるう年、1900 年は平年です。
- **docstring**: 関数の最初に書かれた文字列（ここでは `"year -> number ..."`）は、その関数の説明として扱われます。

## 何をしているか

### 1. 数える年数を決める

```python:line-numbers=53
    y = year - 1
```

`year` 年の 1 月 1 日より前にあるのは、1 年から `year - 1` 年までの丸ごとの年です。その年数を `y` とします。

### 2. 平年として数え、うるう年の分を足す

```python:line-numbers=54
    return y*365 + y//4 - y//100 + y//400
```

- `y*365`: 全部平年だったとしたときの日数
- `+ y//4`: 1〜y 年のうち 4 の倍数の年の数（うるう年候補）
- `- y//100`: そのうち 100 の倍数の年の数（うるう年ではない）
- `+ y//400`: そのうち 400 の倍数の年の数（やっぱりうるう年）

たとえば `year = 2001`（`y = 2000`）なら、

- `2000 * 365 = 730000`
- `2000 // 4 = 500`
- `2000 // 100 = 20`
- `2000 // 400 = 5`

で、`730000 + 500 - 20 + 5 = 730485` 日です。1〜2000 年の中にうるう年は `500 - 20 + 5 = 485` 回あった、ということです。

## ここがすごい

### 「1 から y までに k の倍数はいくつあるか」は `y // k`

1 から 2000 までに 4 の倍数は `4, 8, ..., 2000` で、ちょうど `2000 // 4 = 500` 個です。この性質を使えば、うるう年のルール（4 の倍数を足し、100 の倍数を引き、400 の倍数を足し戻す）が、そのまま 3 つの割り算になります。数学でいう **包除原理**（重なりを引いて、引きすぎを足し戻す数え方）の身近な例です。

### ループがないので、どんな年でも一瞬

素直に書くと次のようになります。

```python
days = 0
for y in range(1, year):
    days += 366 if is_leap(y) else 365
```

これは 2000 年なら 2000 回ループします。1 行の式なら年がいくつでも計算量は同じです。

### ほかの計算の土台になる

この関数は、同じファイルで「400 年が何日か」（`_DI400Y = _days_before_year(401)`）のような定数を作るのにも使われています。基本の関数を正しく作っておけば、そこから周期の長さなども **計算で導き出せる** ので、手で数字を書いて間違えることがありません。

## まとめ

- 「1 から y までの k の倍数の個数」は `y // k` で求まる。
- 例外の例外があるルールは、足して・引いて・足し戻す（包除原理）で数えられる。
- 基本の関数から定数を導くと、手書きの数字のミスを防げる。
