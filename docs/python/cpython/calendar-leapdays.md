## ひとことで

`leapdays(y1, y2)` は、**範囲 `[y1, y2)` の中にある閏年の数** を返す関数です。
`leapdays(2000, 2005)` は `2` を返します。2000 年と 2004 年が閏年だからです。ループで 1 年ずつ調べなくても、計算だけで求められます。

## コード

::: code-group

```python:line-numbers=167 [日本語訳]
def leapdays(y1, y2):
    """範囲 [y1, y2) に含まれる閏年の数を返す。
       y1 <= y2 であると仮定する。"""
    y1 -= 1
    y2 -= 1
    return (y2//4 - y1//4) - (y2//100 - y1//100) + (y2//400 - y1//400)
```

```python:line-numbers=167 [原文]
def leapdays(y1, y2):
    """Return number of leap years in range [y1, y2).
       Assume y1 <= y2."""
    y1 -= 1
    y2 -= 1
    return (y2//4 - y1//4) - (y2//100 - y1//100) + (y2//400 - y1//400)
```

:::

## 前提知識

- **範囲 `[y1, y2)`**: `y1` を含み、`y2` を含まない範囲です。
- **割り算の商 `//`**: 整数の割り算で、小数点以下を切り捨てた商です。`2000 // 4` は `500` です。
- **倍数の個数**: `1` から `n` までに、`k` の倍数が `n // k` 個あります。これを使って、範囲の中の個数を数えます。
- **包除原理**: 「4 の倍数」の個数から「100 の倍数」を引き、「400 の倍数」を足す、という数え方です。二重に引いた分を戻します。

## 何をしているか

### 1. 範囲の端を 1 つずらす

```python:line-numbers=170
    y1 -= 1
    y2 -= 1
```

`[y1, y2)` を、「1 から `y - 1` まで」の個数の差として扱うために、両端から 1 を引きます。これで、倍数の個数を `//` だけで数えられます。

### 2. 4、100、400 の倍数を数える

```python:line-numbers=172
    return (y2//4 - y1//4) - (y2//100 - y1//100) + (y2//400 - y1//400)
```

4 の倍数の個数を足し、100 の倍数の個数を引き、400 の倍数の個数を足します。4 の倍数には、100 の倍数も含まれるので、その分を引きます。さらに、400 の倍数は引きすぎなので、戻します。

## ここがすごい

### ループなしで答えが出る

範囲が何百年あっても、割り算の回数は数回で済みます。1 年ずつ閏年を判定するループより、ずっと速く動きます。

### 包除原理で二重の数え漏れを防ぐ

4 の倍数と 100 の倍数は重なっているので、足し引きで正しい数になるよう調整しています。式は 1 行ですが、数え方は数学の定理に基づいています。

### 閏年の規則と対応している

`isleap` の規則（4 の倍数で、100 の倍数は除き、400 の倍数は含む）を、個数の計算で表したものです。同じ規則を、判定ではなく数える方向に書き換えたと考えると分かりやすくなります。

## まとめ

- 範囲の中の個数は、倍数の個数の差し引きで求められる。
- 重なる条件は、包除原理で足し引きの順番を決めると正しく数えられる。
- 判定の規則を、数える計算に置き換えると、ループなしで答えが出る。
