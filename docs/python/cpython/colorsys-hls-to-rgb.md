## ひとことで

`hls_to_rgb(h, l, s)` は、**色相 `h`・明るさ `l`・彩度 `s`** から、赤・緑・青の 3 つの値を返す関数です。
`hls_to_rgb(0.0, 0.5, 1.0)` は `(1.0, 0.0, 0.0)` を返します。`rgb_to_hls` の逆の変換です。

## コード

```python:line-numbers=99
def hls_to_rgb(h, l, s):
    if s == 0.0:
        return l, l, l
    if l <= 0.5:
        m2 = l * (1.0+s)
    else:
        m2 = l+s-(l*s)
    m1 = 2.0*l - m2
    return (_v(m1, m2, h+ONE_THIRD), _v(m1, m2, h), _v(m1, m2, h-ONE_THIRD))
```

`_v` は、2 つの基準値と色相から、1 つの成分の値を求める内部関数です。`ONE_THIRD` は、1/3 を表す定数です。

## 前提知識

- **基準値 `m1`、`m2`**: 明るさと彩度から作る、一番暗い値と一番明るい値のような 2 つの数です。
- **色相のずらし**: 赤・緑・青は、色相が 1/3 ずつずれた位置にあると考えられます。`h + ONE_THIRD`、`h`、`h - ONE_THIRD` の 3 つで、それぞれの成分を求めます。
- **`_v` の役割**: 色相の位置に応じて、`m1` と `m2` のどちらか、または両者の間の値を返します。

## 何をしているか

### 1. 彩度が 0 の場合

```python:line-numbers=100
    if s == 0.0:
        return l, l, l
```

彩度が 0 なら、灰色です。明るさの値を 3 つの成分にそのまま入れます。

### 2. 基準値 `m2` を作る

```python:line-numbers=102
    if l <= 0.5:
        m2 = l * (1.0+s)
    else:
        m2 = l+s-(l*s)
```

明るさが 0.5 以下なら `l * (1.0+s)`、それより明るければ `l+s-(l*s)` を使います。どちらも、明るさと彩度から作った、上の基準値です。

### 3. 基準値 `m1` を作る

```python:line-numbers=106
    m1 = 2.0*l - m2
```

`m1` は、`2.0*l - m2` で求めます。`m1` と `m2` は、明るさの平均がちょうど `l` になるように組まれています。

### 4. 3 つの成分を求める

```python:line-numbers=107
    return (_v(m1, m2, h+ONE_THIRD), _v(m1, m2, h), _v(m1, m2, h-ONE_THIRD))
```

色相を 1/3 ずらした 3 つの位置で、`_v` を呼びます。その結果が、赤・緑・青の順になります。

## ここがすごい

### 3 つの成分を 1 つの式で作る

赤・緑・青は、色相を 1/3 ずつずらした同じ式で求められます。成分ごとに別の計算を書かず、位置だけを変えて同じ関数を呼びます。

### 基準値を 2 つにまとめる

明るさと彩度を、最初に 2 つの基準値へまとめています。以降の計算は、その 2 つの値だけを使うので、式がシンプルになります。

### 逆変換と対応している

`rgb_to_hls` で求めた明るさ、彩度、色相を入れると、もとの RGB に戻ります。2 つの関数は、互いの逆になるように作られています。

## まとめ

- 明るさと彩度は、2 つの基準値にまとめると扱いやすい。
- 色相を 1/3 ずつずらすと、3 つの成分を同じ式で求められる。
- 変換の関数は、逆向きの関数と合わせて読むと理解が深まる。
