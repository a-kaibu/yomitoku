## ひとことで

`rgb_to_hsv(r, g, b)` は、赤・緑・青の強さ（それぞれ 0.0〜1.0）で表した色を、**色相（H）・彩度（S）・明度（V）** の表し方に変換する関数です。
`rgb_to_hsv(1.0, 0.5, 0.0)`（オレンジ）は、だいたい `(0.083, 1.0, 1.0)` になります。
HSV を使うと「色はそのままで少し暗くする」「鮮やかさだけを下げる」といった操作が簡単になります。

## コード

```python:line-numbers=125
def rgb_to_hsv(r, g, b):
    maxc = max(r, g, b)
    minc = min(r, g, b)
    rangec = (maxc-minc)
    v = maxc
    if minc == maxc:
        return 0.0, 0.0, v
    s = rangec / maxc
    rc = (maxc-r) / rangec
    gc = (maxc-g) / rangec
    bc = (maxc-b) / rangec
    if r == maxc:
        h = bc-gc
    elif g == maxc:
        h = 2.0+rc-bc
    else:
        h = 4.0+gc-rc
    h = (h/6.0) % 1.0
    return h, s, v
```

## 前提知識

- **RGB**: 赤（R）、緑（G）、青（B）の光の強さで色を表す方法です。ここでは 0.0（なし）〜1.0（最大）の小数で表します。
- **HSV**:
  - 色相（Hue）: 色の種類。色の輪（色相環）の上の位置で、赤 → 黄 → 緑 → シアン → 青 → マゼンタ → 赤と一周します。ここでは 0.0〜1.0 で一周です。
  - 彩度（Saturation）: 鮮やかさ。0 なら灰色。
  - 明度（Value）: 明るさ。0 なら黒。
- **`max` と `min`**: 引数の中の最大値・最小値を返します。
- **複数の値を返す**: `return h, s, v` はタプル `(h, s, v)` を返します。
- **`%`（余り）**: Python の `%` は、負の数に使っても結果が 0 以上になります。`-0.25 % 1.0` は `0.75` です。

## 何をしているか

オレンジ `(r, g, b) = (1.0, 0.5, 0.0)` で追います。

### 1. 明度と彩度（126〜132 行目）

最大 `maxc = 1.0`、最小 `minc = 0.0`、差 `rangec = 1.0` です。明度は最大値そのもの（`v = 1.0`）です。
最大と最小が同じなら灰色（白や黒も含む）で、色相も彩度もないので `(0, 0, v)` を返します。
彩度は「差 ÷ 最大」なので `1.0` です。

### 2. 各色が最大値からどれだけ離れているか（133〜135 行目）

`rc = 0.0`、`gc = 0.5`、`bc = 1.0` です。

### 3. 最大の色で場合分けして色相を出す（136〜141 行目）

色相環を 6 つに分け、赤が最大なら赤のあたり（0 付近）、緑なら 2 付近、青なら 4 付近を基準にします。今は赤が最大なので `h = bc - gc = 0.5` です。

### 4. 0〜1 に収める（142 行目）

`0.5 / 6 = 0.0833...` で、色相環の 30 度（オレンジ）にあたります。

## ここがすごい

### 3 つの場合分けで色相環を表現

色相環は「赤 → 黄 → 緑 → シアン → 青 → マゼンタ → 赤」の 6 区間です。どの色が最大かで 3 つの「中心」（赤 0、緑 2、青 4）を選び、残り 2 色の差で前後にずらす、という形で 6 区間すべてを 3 つの式で表しています。

### `% 1.0` で輪をつなぐ

赤が最大で、青が緑より強い（マゼンタ寄り）とき、`h = bc - gc` は負になります。そのまま 6 で割ると -0.1 のような値になりますが、`% 1.0` によって 0.9 になり、**色相環の反対側から回り込んだ位置** に正しく収まります。Python の `%` が負の数でも 0 以上を返す性質を、そのまま「輪」の表現に使っています。

### 割り算の前に灰色をはじく

130〜131 行目で `minc == maxc` を先に処理しているので、後の `rangec`（0 になりうる）や `maxc` での割り算でゼロ除算が起きません。黒（0, 0, 0）を渡しても安全です。

### 最小限の計算

`rc`、`gc`、`bc` の 3 つをまとめて計算しておき、場合に応じて 2 つを組み合わせるだけにしているので、式が短く、どの分岐も同じ形になっています。

## まとめ

- HSV は、RGB の最大値・最小値と、どの色が最大かから計算できる。
- 輪のように一周する値は、`% 1.0` で 0〜1 に折り返すと扱いやすい。
- 割り算の前に、分母が 0 になる場合を先に処理しておく。
