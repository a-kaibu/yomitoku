## ひとことで

`escapeRegex(str)` は、文字列の中の正規表現の記号（`.`、`*`、`+` など）の前に `\` を付けて、**ただの文字として扱われるようにする** 関数です。

```ts
const word = 'a.b'
new RegExp(escapeRegex(word)).test('a.b')  // true
new RegExp(escapeRegex(word)).test('axb')  // false（. が任意の 1 文字として扱われない）
```

ユーザーの入力を正規表現に入れると、意図しない記号が働いてしまいます。この関数は、その問題を防ぐために使います。

## コード

```ts:line-numbers=640
export function escapeRegex(str: string): string {
  return str.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}
```

## 前提知識

- **正規表現の特殊文字**: `.`、`*`、`+`、`?`、`^`、`$`、`{`、`}`、`(`、`)`、`|`、`[`、`]`、`\` は、正規表現の中で特別な意味を持ちます。
- **バックスラッシュによるエスケープ**: 特殊文字の前に `\` を付けると、その記号そのものとして扱われます。たとえば `\.` は「ドット 1 文字」です。
- **`replace` と `$&`**: 置換文字列の中の `$&` は、一致した部分そのものを表します。`"\\$&"` は、一致した文字の前に `\` を付けることになります。

## 何をしているか

### 1. 特殊文字の集合を正規表現で表す

```ts:line-numbers=641
  return str.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
```

角かっこの中に、特殊文字を並べています。`]` と `\` は、角かっこの中でも特別なのでエスケープしています。

### 2. 一致した文字の前に `\` を付ける

```ts:line-numbers=641
  return str.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
```

`"\\$&"` は、一致した 1 文字の前にバックスラッシュを付けた文字列です。

`'a.b*c'` は次のように変わります。

```
'.' → '\.'
'*' → '\*'
結果: 'a\.b\*c'
```

## ここがすごい

- **「1 文字ずつ」の置換で済む**: 特殊文字の 1 文字ごとに、同じルールで前に `\` を付けるだけです。特殊文字ごとに分岐を書く必要がありません。
- **`$&` で一致そのものを使える**: 置換先に一致した文字をそのまま入れる書き方で、対応表を作らずに済みます。
- **文字の対応を 1 か所にまとめている**: 正規表現の仕様が変わっても、この 1 行の集合を直せばよい設計です。

## まとめ

- ユーザーの文字列を正規表現に埋め込むときは、特殊文字の前に `\` を付けてから使う。
- `replace` の `$&` を使うと、一致した文字をそのまま参照できる。
- 特殊文字は正規表現の仕様で決まっているので、1 か所にまとめておくと保守しやすい。
