## ひとことで

`esc(str)` は、文字列を JavaScript のコードの中に書ける形（引用符で囲まれた形）にする関数です。zod は、スキーマの定義から JavaScript のコードを文字列として組み立てることがあります。その中に、利用者の文字列を入れるときに使われます。

```ts
esc('hello')    // "hello"（両端が引用符で囲まれる）
esc('say "hi"') // "say \"hi\""（中の引用符が \" になる）
```

## コード

```ts:line-numbers=496
export function esc(str: string): string {
  return JSON.stringify(str);
}
```

## 前提知識

- **文字列のエスケープ**: 文字列の中の引用符（`"`）や改行などは、そのままコードに書くと文法を壊します。そのため、`\"` のように前に `\` を付けて書きます。これをエスケープと呼びます。
- **`JSON.stringify`**: 値を JSON の形式の文字列に変えるメソッドです。文字列の場合は、両端を `"` で囲み、中の特殊文字を正しくエスケープします。
- **JSON と JavaScript の文字列**: JSON の文字列は、JavaScript の文字列として読めるように作られています。そのため、コードの中に JSON の形式で書いても、ほとんどの場合は正しく読めます。
- **コード生成**: 実行時に、コードの文字列を組み立てて `new Function` などで使う手法です。zod の一部の高速化で使われています。

## 何をしているか

### 1. 文字列を JSON として変換する

```ts:line-numbers=497
  return JSON.stringify(str);
```

`JSON.stringify(str)` は、文字列の前後に `"` を付け、中の引用符や改行を `\"` や `\n` に直します。`esc('say "hi"')` の結果は、画面上では `"say \"hi\""` のようになります。

### 2. 生成されたコードの中に入れる

ここで作った文字列を、生成中のコードの一部として埋め込みます。埋め込まれた値は、1 つの文字列リテラルとして読まれるので、中身が文法として解釈されることはありません。

## ここがすごい

- **自分でエスケープしない**: 引用符や改行、制御文字を、1 つずつ置き換える処理を書く必要がありません。`JSON.stringify` が、その仕事をすべて引き受けます。
- **文法を壊さない**: 利用者の文字列に `"` や `;` が入っていても、コードは文字列の中の文字として扱われます。コードを組み立てるときに起きやすい、注入の問題を防げます。
- **1 行の関数**: 関数の中身は 1 行だけです。名前の `esc` が、「エスケープする」という意図を短く伝えています。
- **安全な既定の選択**: 生成するコードに入る値を、すべてこの関数を通す約束にすると、一か所の確認で安全性が保てます。

## まとめ

- コードを文字列で組み立てるときは、利用者の値を文字列リテラルとして安全に入れる必要がある。
- `JSON.stringify` は、引用符と改行を正しくエスケープしてくれる。
- 自分でエスケープの処理を書くより、標準の仕組みに任せた方が間違いが少ない。
- 生成するコードに入る値は、必ず同じ関数を通すという約束にすると、安全性を保ちやすい。
