## ひとことで

`remove(arr, el)` は、配列 `arr` から値 `el` を 1 つだけ取り除く関数です。同じ値が複数あっても、最初に見つかった 1 つだけを取り除きます。値が無ければ、何もしません。Vue の中で、イベントの登録を解除するときなどに使われています。

```ts
const list = ['a', 'b', 'c']
remove(list, 'b')  // list は ['a', 'c'] になる
remove(list, 'z')  // 見つからないので、何も変わらない
```

## コード

```ts:line-numbers=26
export const remove = <T>(arr: T[], el: T): void => {
  const i = arr.indexOf(el)
  if (i > -1) {
    arr.splice(i, 1)
  }
}
```

## 前提知識

- **`indexOf`**: 配列の中で、指定した値が最初に現れる位置（添字）を返します。見つからなければ `-1` を返します。
- **`splice(位置, 個数)`**: 配列の途中の要素を取り除く（または入れる）組み込みメソッドです。元の配列を直接書き換えます。
- **添字（インデックス）**: 配列の何番目かを表す数です。最初の要素は `0` です。
- **ジェネリクス `<T>`**: 配列の要素の型を、呼び出しごとに決められる書き方です。
- **`void`**: 戻り値がないことを表す型です。

## 何をしているか

### 1. 値の位置を探す

```ts:line-numbers=27
  const i = arr.indexOf(el)
```

`indexOf` で、`el` が最初に現れる位置を `i` に入れます。見つからなければ `-1` です。

### 2. 見つかったときだけ取り除く

```ts:line-numbers=28
  if (i > -1) {
    arr.splice(i, 1)
  }
```

`i` が `-1` より大きい（見つかった）ときだけ、`splice(i, 1)` で、その位置の要素を 1 つ取り除きます。`1` は「1 個だけ」の意味です。

## ここがすごい

- **見つからないときに例外を投げない**: `-1` の判定を入れているので、存在しない値を消そうとしても、エラーになりません。呼び出し側は安心して使えます。
- **1 個だけ消す**: `splice(i, 1)` の `1` のおかげで、同じ値が複数あっても、必要な分だけを消せます。登録を 1 回ずつ解除する場面に合っています。
- **配列を直接変える**: 新しい配列を作らず、元の配列を書き換えます。登録リストのような、同じ場所を参照し続ける場合に、コピーの手間を省けます。
- **短い関数に名前を付ける**: 3 行の処理を `remove` という名前にまとめるだけで、呼び出し側は何を消すのかが一目で分かります。

## まとめ

- 配列から値を消すときは、`indexOf` で位置を探し、見つかったときだけ `splice` する。
- `splice(位置, 1)` は、その位置の要素を 1 つだけ消す。
- 存在しない値を消そうとしても、`-1` の判定で何も起きないように守れる。
- 元の配列を直接書き換えるかどうかは、参照の仕組みに応じて決める。
