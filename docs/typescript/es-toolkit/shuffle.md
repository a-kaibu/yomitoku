## ひとことで

`shuffle` は配列の要素をランダムな順番に並べ替えた **新しい配列** を返す関数です。
たとえば `[1, 2, 3]` を渡すと `[2, 3, 1]` や `[3, 1, 2]` などが返ります。

ポイントは、6 通りある並び方のどれもが **ちょうど同じ確率（6 分の 1）** で出ることです。簡単そうに見えて、素朴に書くと偏りが出てしまう有名な問題を、短いループで正しく解いています。

## コード

```ts:line-numbers=15
export function shuffle<T>(arr: readonly T[]): T[] {
  const result = arr.slice();

  /**
   * https://en.wikipedia.org/wiki/Fisher%E2%80%93Yates_shuffle#The_modern_algorithm
   */
  for (let i = result.length - 1; i >= 1; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }

  return result;
}
```

## 前提知識

- **`function shuffle<T>(arr: readonly T[]): T[]`**: TypeScript の関数宣言です。`<T>` は「ジェネリクス（型を後から決められる仕組み）」で、数値の配列を渡せば数値の配列が、文字列の配列を渡せば文字列の配列が返ることを表します。
- **`readonly T[]`**: 「この関数は受け取った配列を書き換えません」という約束を型で示したものです。中身を変更するコードを書くとコンパイルエラーになります。
- **`arr.slice()`**: 引数なしで呼ぶと配列の浅いコピーを作ります。元の配列を壊さないための定番の書き方です。
- **`Math.random()`**: 0 以上 1 未満の小数をランダムに返します。`Math.floor` は小数点以下を切り捨てます。
- **`[a, b] = [b, a]`**: 分割代入（配列の形で左右を対応させて代入する書き方）を使った「入れ替え」です。一時変数を使わずに 2 つの値を交換できます。

## 何をしているか

### 1. コピーを作る（16 行目）

`arr.slice()` でコピーを作り、以降はコピーだけを操作します。呼び出し元の配列はそのまま残ります。

### 2. 後ろから順に「くじ引き」をする（21〜24 行目）

`i` を配列の最後の位置から 1 まで 1 つずつ減らしながら、次のことを繰り返します。

1. `0` 以上 `i` 以下の位置 `j` をランダムに選ぶ（22 行目）。`Math.random() * (i + 1)` は 0 以上 `i + 1` 未満なので、切り捨てると `0`〜`i` の整数になります。
2. 位置 `i` と位置 `j` の要素を入れ替える（23 行目）。

`[a, b, c, d]` で追ってみます。

```
i = 3: 0〜3 から j = 1 を選ぶ → [a, d, c, b]   （位置 3 は b で確定）
i = 2: 0〜2 から j = 2 を選ぶ → [a, d, c, b]   （自分自身と交換。位置 2 は c で確定）
i = 1: 0〜1 から j = 0 を選ぶ → [d, a, c, b]   （位置 1 と 0 が確定）
```

ループが進むたびに、配列の右側に「確定済みの区画」が 1 つずつ増えていきます。まだ確定していない左側の要素から 1 つを公平に選んで、確定区画の先頭に置いていくイメージです。

## ここがすごい

- **偏りがない**: 各ステップで「残りの中から公平に 1 つ選ぶ」ので、`n` 個の要素なら `n × (n-1) × … × 1 = n!` 通りの選び方がそれぞれ 1 回ずつ起こり、全部の並びが同じ確率になります。よくある間違いは `j` を毎回 `0〜n-1` の全体から選ぶ書き方で、これだと `n^n` 通りの結果を `n!` 個の並びに割り振ることになり、割り切れないので必ず偏りが出ます。
- **`sort(() => Math.random() - 0.5)` を使わない**: 「ランダムな比較でソートする」書き方もよく見かけますが、ソートの比較関数が矛盾した答えを返すため、結果の偏りがエンジンの実装次第になります。フィッシャー–イェーツ法は理論的に正しいことが証明されている方法です。
- **速い**: ループは 1 回だけで、計算量は `O(n)` です。ソートを使う方法（`O(n log n)`）より速く、追加のメモリもコピー 1 つぶんだけです。
- **出典を書いている**: 18〜20 行目のコメントで、Wikipedia のアルゴリズムの項目を示しています。読む人が「なぜこれで正しいのか」をすぐ調べられます。

## まとめ

- シャッフルは「残りの候補から公平に 1 つ選んで確定させる」を繰り返すと偏りなくできる。
- ランダムな比較関数で `sort` するのはシャッフルとして正しくない。
- `slice()` でコピーしてから操作すれば、引数の配列を壊さずに済む。
- `[a, b] = [b, a]` で一時変数なしに値を入れ替えられる。
