## ひとことで

`uniq(arr)` は、配列から重複した値を取り除いた新しい配列を返す関数です。`uniq([1, 2, 2, 3, 1])` は `[1, 2, 3]` になります。最初に現れた順序は、そのまま残ります。

```ts
uniq([1, 2, 2, 3, 1])     // [1, 2, 3]
uniq(['a', 'b', 'a'])     // ['a', 'b']
```

## コード

```ts:line-numbers=16
export function uniq<T>(arr: readonly T[]): T[] {
  return [...new Set(arr)];
}
```

## 前提知識

- **`Set`**: 同じ値を 2 つ持てない、組み込みのコレクションです。値を追加しても、既にあれば何も起きません。
- **スプレッド構文 `[...x]`**: 反復できるもの（`Set` など）の要素を、1 つずつ取り出して新しい配列にします。
- **同値の判定**: `Set` は値の同じかどうかを、`Object.is` に近い規則で判定します。数の `1` と文字列の `'1'` は別の値です。
- **`readonly T[]`**: 読み取り専用の配列の型です。この関数は、受け取った配列を書き換えないことを型で示しています。

## 何をしているか

### 1. 配列を Set に入れる

```ts:line-numbers=17
  return [...new Set(arr)];
```

`new Set(arr)` は、配列の要素を 1 つずつ入れます。同じ値が 2 回目以降に来ても、無視されます。この時点で、重複はもう消えています。

### 2. 配列に戻す

同じ行の `[...]` の部分です。スプレッド構文で `Set` の要素を並べ直し、新しい配列を作ります。`Set` は入れた順序を保つので、結果は最初の出現順になります。

## ここがすごい

- **1 行で書き切る**: 重複を調べる二重ループや、一時的な連想配列を書く必要がありません。`Set` の性質に任せています。
- **順序を保つ**: `Set` は挿入順を覚えているので、最初に出た順で並んだ結果が得られます。並べ替えは行いません。
- **元の配列を変えない**: 新しい `Set` と新しい配列を作るので、入力は書き換わりません。
- **速さ**: 重複の判定を `Set` の仕組みに任せるので、要素数が多くても、1 回ずつの検索より速く処理できます。

## まとめ

- 重複の除去は、`Set` に入れて配列に戻すと 1 行で書ける。
- `Set` は挿入した順序を保つので、結果の順序は予測しやすい。
- 元の配列を変えない書き方にすると、呼び出し元を壊さない。
- 組み込みのコレクションの性質を知っていると、短い書き方が見えてくる。
- 配列から重複を消す方法には、`filter` と `indexOf` を組み合わせる書き方もある。ただし要素数が多いと、同じ値を何度も探すため遅くなる。`Set` なら 1 回の追加で重複を判定できるので、大きな配列でも速く動く。
- 関数の入力を書き換えず、新しい配列を返すことは、ライブラリの関数の基本的な約束事。
