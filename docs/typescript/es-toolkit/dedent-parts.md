## ひとことで

`dedent` は、コードの中に書いた複数行の文字列から **共通の字下げ（インデント）を取り除く** 関数です。タグ付きテンプレートとして使うと、埋め込み値（`${…}`）を含む文字列にも使えます。

```ts
const html = dedent`
    <div>
      ${content}
    </div>
`
// "<div>\n  …\n</div>"
```

`dedentParts` はその内部関数で、テンプレートの「埋め込み値の間の文字列の断片」を受け取り、字下げを取った断片を返します。断片を **入力に絶対含まれない文字でいったんつないで**、まとめて処理するのがポイントです。

## コード

```ts:line-numbers=83
function dedentParts(strings: ArrayLike<string>): string[] {
  assertTemplateShape(strings);

  const parts = Array.from(strings);

  if (parts.length === 1) {
    return [dedentImpl(parts[0])];
  }

  let placeholder = '\x00';
  const joinedParts = parts.join('');

  while (joinedParts.includes(placeholder)) {
    placeholder += '\x00';
  }

  return dedentImpl(parts.join(placeholder)).split(placeholder);
}
```

`dedentImpl` は 1 つの文字列から共通インデントを取り除く関数、`assertTemplateShape` は「最初と最後の行が空行であること」を確かめる関数です。

## 前提知識

- **タグ付きテンプレート**: `` dedent`…` `` のように関数名の直後にテンプレート文字列を書くと、関数には「`${}` で区切られた文字列の断片の配列」と「埋め込まれた値」が別々に渡されます。`` `a${x}b${y}c` `` なら断片は `['a', 'b', 'c']` です。
- **`ArrayLike<string>`**: 配列のように `length` と番号でアクセスできるものの型です。`Array.from` で本物の配列に変換できます。
- **`'\x00'`**: 文字コード 0 の文字（ヌル文字）です。普通の文章にはまず現れません。
- **`join` と `split`**: `join(区切り)` は配列を区切り文字でつないだ 1 つの文字列に、`split(区切り)` はその逆に分けます。

## 何をしているか

### 1. 断片が 1 つならそのまま処理（88〜90 行目）

埋め込み値がない場合です。

### 2. 区切り文字を決める（92〜97 行目）

まず `'\x00'` を区切りの候補にします。すべての断片をつなげた文字列にその候補が含まれていたら、`'\x00\x00'`、`'\x00\x00\x00'` と伸ばしていき、**入力のどこにも現れない文字列** が見つかるまで続けます。

### 3. つないで処理して、分け直す（99 行目）

断片を区切りでつなぎ、1 つの文字列として字下げを取り、最後に同じ区切りで分け直します。

```
断片: ['\n    <div>\n      ', '\n    </div>\n']
つなぐ: '\n    <div>\n      \x00\n    </div>\n'
字下げ除去: '<div>\n  \x00\n</div>'
分け直す: ['<div>\n  ', '\n</div>']
```

## ここがすごい

- **「共通インデント」は全体を見ないと決まらない**: どの行がいちばん浅いかは、断片をまたいで文字列全体を見ないとわかりません。断片ごとに処理すると、ある断片では 4 文字、別の断片では 6 文字と、ばらばらに削ってしまいます。いったんつなげることで、全体で 1 つの基準を使えます。
- **区切りが入力と衝突しないことを保証**: 区切り文字が入力に含まれていたら、分け直したときに断片の数が変わってしまいます。95〜97 行目のループで「含まれていない」ことを確かめてから使うので、どんな入力でも壊れません。めったに起きないことにもきちんと備えた、防御的な書き方です。
- **埋め込み値はあとで差し込む**: 値そのものはつながず、字下げを取った断片の間に後から挟みます。値の中に改行や空白が入っていても、それに引きずられて字下げの計算が狂うことはありません。

## まとめ

- 部分に分かれたデータを全体の基準で処理したいときは、いったんつないでから分け直す手がある。
- そのときの区切りは、入力に含まれないことを確かめてから使う。
- タグ付きテンプレートでは、文字列の断片と埋め込み値が別々に届く。
