## ひとことで

`escapeRegExp(str)` は、文字列の中の正規表現の記号を、そのまま文字として扱えるように書き換える関数です。利用者が入力した文字列を、正規表現の中に安全に入れるときに使います。

```ts
escapeRegExp('a.b')  // 'a\.b'（. が普通の文字として扱われる）
```

## コード

```ts:line-numbers=12
export function escapeRegExp(str: string): string {
  return str.replace(/[\\^$.*+?()[\]{}|]/g, '\\$&');
}
```

## 前提知識

- **正規表現の記号**: `.` や `*` や `(` などは、正規表現の中では特別な意味を持ちます。例えば `.` は任意の 1 文字を表します。
- **バックスラッシュ**: 記号の前に `\` を付けると、その記号を普通の文字として扱えます。
- **`replace` と置換パターン**: 第 2 引数で、一致した文字列を別の文字列に置き換えます。`$&` は、一致した部分そのものを表します。

## 何をしているか

### 1. 特別な記号を探す

```ts:line-numbers=13
  return str.replace(/[\\^$.*+?()[\]{}|]/g, '\\$&');
```

正規表現で、特別な意味を持つ記号を探します。`g` の指定により、文字列の中のすべての一致が対象です。

### 2. 記号の前に印を付ける

置換の文字列 `\$&` は、一致した記号の前に `\` を付けるという意味です。`.` は `\.` になり、正規表現の中で普通の点として扱われます。

## ここがすごい

- **利用者の入力を安全に**: 検索語に `.` や `*` が含まれていても、正規表現としての意味を持たずに済みます。
- **1 回の置換で完結**: 記号を 1 つずつ確かめる代わりに、1 つの正規表現で全部を処理しています。
- **置換の仕組みを使う**: `$&` で一致部分を再利用するので、記号の種類ごとに書き分けなくて済みます。

## まとめ

- `escapeRegExp` は、正規表現の特別な記号の前に `\` を付けて、普通の文字にする。
- 利用者の入力を、正規表現に安全に埋め込める。
- 1 回の置換で、すべての記号をまとめて処理する。
