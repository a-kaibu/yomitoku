## ひとことで

`reverseString(value)` は、文字列の文字の並びを逆にする関数です。`'abc'` は `'cba'` になります。普通の `split('')` で分けると絵文字が壊れてしまいますが、この関数はスプレッド構文を使うので、絵文字も正しく 1 文字として扱います。

```ts
reverseString('abc')    // 'cba'
reverseString('a😀b')   // 'b😀a'（絵文字が壊れない）
```

## コード

```ts:line-numbers=14
export function reverseString(value: string): string {
  return [...value].reverse().join('');
}
```

## 前提知識

- **UTF-16 とサロゲートペア**: JavaScript の文字列は UTF-16 で作られます。16 ビットに収まらない絵文字は、2 つの単位（サロゲートペア）で表されます。
- **`split('')`**: 文字列を 1 単位（UTF-16 の 1 単位）ずつに分けます。サロゲートペアの絵文字は、真ん中で切れてしまいます。
- **スプレッド構文 `[...value]`**: 文字列を反復すると、1 つのコードポイント（1 文字）ずつ取り出されます。絵文字も 1 つにまとまります。
- **`reverse()`**: 配列の要素の順番を逆にするメソッドです。元の配列を書き換えます。
- **`join('')`**: 配列の要素を、区切りなしでつないで文字列にします。

## 何をしているか

### 1. 文字列を文字の配列にする

```ts:line-numbers=15
  return [...value].reverse().join('');
```

`[...value]` で、文字列をコードポイント単位の配列にします。`'a😀b'` は `['a', '😀', 'b']` になります。

### 2. 逆にして、つなぎ直す

同じ行の `.reverse().join('')` の部分です。配列を逆順にしてから、区切りなしで 1 つの文字列にします。

## ここがすごい

- **絵文字の破損を防ぐ**: `split('')` では、絵文字の 2 単位が別々に扱われ、反転後に文字化けします。スプレッド構文は、コードポイント単位で分けるので、この問題を避けられます。
- **1 行で完結**: 変換、反転、結合の 3 段階を、1 つの式に並べています。読み手は、流れを一度で追えます。
- **新しい配列を作る**: スプレッド構文で新しい配列を作ってから反転するので、元の文字列（JavaScript の文字列は変えられない値）に影響はありません。
- **限界もある**: 結合文字（例えば、ベースの文字に付く濁点など）は、1 つのコードポイントとして分かれてしまうことがあります。文字の見た目の単位で扱うには、`Intl.Segmenter` などが必要です。

## まとめ

- 文字列を逆順にするには、コードポイント単位で分けてから反転すると安全。
- `split('')` は、サロゲートペアを壊すので、絵文字を含む文字列には向かない。
- 反転は、`reverse` と `join` の組み合わせで書ける。
- 結合文字の扱いのような限界は、知っておくと誤用を防げる。
