## ひとことで

`combinations(arr, r)` は、配列 `arr` から `r` 個を選ぶ **組み合わせをすべて** 返す関数です（順番は区別しません）。
たとえば `combinations(['a', 'b', 'c', 'd'], 2)` は次の 6 通りを返します。

```
[a,b] [a,c] [a,d] [b,c] [b,d] [c,d]
```

Python の `itertools.combinations` と同じ考え方で、「どの位置を選んだか」を表す添字の配列を、数を数えるように少しずつ進めていきます。

## コード

```ts:line-numbers=32
export function combinations<T>(arr: readonly T[], r: number): T[][] {
  if (!Number.isInteger(r) || r < 0) {
    throw new Error('r must be a non-negative integer.');
  }

  const n = arr.length;

  if (r > n) {
    return [];
  }

  if (r === 0) {
    return [[]];
  }

  const indices = Array(r);
  for (let i = 0; i < r; i++) {
    indices[i] = i;
  }

  const result: T[][] = [];

  while (true) {
    const tuple: T[] = Array(r);
    for (let i = 0; i < r; i++) {
      tuple[i] = arr[indices[i]];
    }
    result.push(tuple);

    let i = r - 1;
    while (i >= 0 && indices[i] === i + n - r) {
      i--;
    }

    if (i < 0) {
      return result;
    }

    indices[i]++;
    for (let j = i + 1; j < r; j++) {
      indices[j] = indices[j - 1] + 1;
    }
  }
}
```

## 前提知識

- **`Number.isInteger(r)`**: `r` が整数かどうかを調べます。`2.5` や `NaN` は `false` です。
- **`Array(r)`**: 長さ `r` の空の配列を作ります。
- **`while (true)`**: 条件なしの無限ループです。ループの中の `return` で抜け出します。
- **添字（インデックス）**: 配列の何番目かを表す数で、0 から数えます。
- **組み合わせ**: `n` 個から `r` 個を選ぶとき、選ぶ順番は区別しません。`[a,b]` と `[b,a]` は同じ組み合わせです。

## 何をしているか

### 1. 特別な場合（33〜45 行目）

`r` が負や小数ならエラー、`r` が要素数より大きければ選べないので空配列、`r = 0` なら「何も選ばない」が 1 通りなので `[[]]` を返します。

### 2. 最初の組み合わせ（47〜50 行目）

添字の配列 `indices` を `[0, 1, …, r-1]` にします。これは「先頭から `r` 個を選んだ」状態で、辞書順でいちばん最初の組み合わせです。

### 3. 今の組み合わせを記録して、次へ進む（54〜74 行目）

`indices` が指す要素を取り出して結果に追加します（55〜59 行目）。そのあと、次の組み合わせに進めます。

- **右から見て、まだ増やせる位置を探す**（61〜64 行目）。位置 `i` の添字が取れる最大値は `i + n - r` です。たとえば `n = 4, r = 2` なら、右端（`i = 1`）は最大 3、左（`i = 0`）は最大 2 です。最大に達している位置は増やせないので飛ばします。
- 全部が最大なら終わり（66〜68 行目）。
- 見つけた位置を 1 増やし、その右側を「すぐ隣の値」で詰め直します（70〜73 行目）。

`n = 4, r = 2` で追うと、`indices` は次のように変わります。

```
[0,1] → [0,2] → [0,3] → (右端が最大なので左を増やす) [1,2] → [1,3] → [2,3] → 終了
```

数字の繰り上がりに似ていますが、「右側は必ず左より大きい」という制約があるので、繰り上がったあとは右側を `左 + 1, 左 + 2, …` と詰め直すのが違いです。

## ここがすごい

- **再帰を使わない**: 組み合わせは再帰で書くのが定番ですが、`r` が大きいと呼び出しが深くなります。この方法はループだけで、使うメモリも添字の配列 `r` 個ぶんだけです。
- **辞書順に並ぶ**: 添字が常に小さい順に進むので、結果は自然に辞書順になります。並べ替えの手間がいりません。
- **各位置の上限を式で表す**: `i + n - r` という上限は「位置 `i` のあとに残り `r - 1 - i` 個を置ける余地が必要」という条件から出てきます。条件を式 1 つにまとめることで、判定がシンプルになっています。
- **重複のチェックがいらない**: 添字が常に増加列なので、同じ組み合わせが 2 回出ることも、`[b,a]` のような並び違いが出ることも構造上ありえません。

## まとめ

- 組み合わせは「増加する添字の並び」として表せる。
- 「右から増やせる場所を探して 1 増やし、右側を詰め直す」で次の組み合わせに進める。
- 各位置の上限 `i + n - r` を使うと、終了判定も繰り上げ判定も 1 つの比較で済む。
